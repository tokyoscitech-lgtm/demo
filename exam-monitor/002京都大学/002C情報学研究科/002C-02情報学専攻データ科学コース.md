## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 8月入试：出願时提交 TOEFL iBT 的 Test Taker Score Report 或 TOEIC L&R 的公式认定证的复印件。配点 50 分。
- 换算：TOEFL＝0.5×分数；TOEIC＝0.5×（0.134×分数－32.66）；小数点以下进位，上限50分。例如 TOEFL 90＝45分，TOEIC 860＝42分。
- 成绩须为出願截止日前2年以内受检。TOEFL iBT Home Edition 可以；TOEFL Essentials、TOEFL ITP、TOEIC IP 不受理。考过多次的只交1份。
- 出願时没交成绩单的，英语按0分处理，不接受考试当天补交。
- 第2次募集：官方予告确认2026年夏期以后的入试都用 TOEFL 或 TOEIC，IELTS 不认，不接受当天补交。
- 变更点：2026年度（2025年8月实施）的8月入试本コース只收 TOEFL，2027年度改为 TOEFL 和 TOEIC 都可以。

### 日本語要件
- 要项没有要求提交日语成绩。8月入试的笔试题日英并记，可用日文或英文作答。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 情報学基礎（100分，120分钟） | 线性代数·微分积分 2题＋算法与数据结构 2题，4题全答 | 2027募集要项 |
| 専門科目（100分，120分钟） | 统计学、模式识别与机器学习、信息理论、信号处理 各1题，选2题作答 | 2027募集要项 |
| 第2次募集（2027年2月起）：基礎科目（数学），200分 | 微积分、线性代数；専門科目不实施 | 2026/3/23 予告 |

- 8月入试总分 250（情報学基礎 100＋専門科目 100＋英语 50）。按笔试和英语的得分，加上各志望区分可接收的人数综合决定合格者。
- 题目倾向（体验记，非官方）：考试日和试题与知能情報学コース相同；算法部分常出堆排序、二叉搜索树、最短路径等图算法、动态规划；专门科目多数人准备3科、当天挑2科。

### 口述試験 / 面接
- **官方形式**：8月入试没有口头试问。冬入试从2027年2月起新增口头试问（200分，含研究计划发表，一部分用日语进行）。
- **実際に聞かれた内容**：冬入试的新形式是第一年，没有先例。

## 📝 详细信息
### 出願資格 / 定員
- 8月入试的募集人员为16名。第2次募集的人数未公布（2025年度为10名）。
- 出願资格：大学毕业或2027年3月底前预计毕业、在外国完成16年学校教育、在外国取得相当于学士的学位（3年以上课程）等1–10项之一。
- 志望区分按志望顺序填写，数量不限；没有填的区分不会被分配，即使分数高于合格最低分也可能不合格。願書受理后不能修改。
- 出願书类（8月入试）：入学願書·写真票·受験票、成绩证明书、志望说明书（A4 2页以内，写学习研究经过、志望动机、入学后的研究抱负，做过毕业研究的写明题目和内容）、在留卡正反面或护照复印件（外国人）、检定料缴纳证明、TOEFL/TOEIC 成绩单复印件、受験票和合否通知用信封等。书类只收日文或英文。
- 国内出願必须用纸质募集要项所附的用纸（教務掛窗口领取或邮寄索取），不能用电子文件；只有海外出願可以从研究科网站下载。出願为邮寄（書留速達或レターパックプラス）或窗口提交，没有网上出願。
- 检定料 30,000 日元＋手续费 671 日元，通过京都大学决济系统支付（信用卡、便利店、Pay-easy）。国费留学生也要先缴，入学确定后退还。
- 一次只能报一个コース。8月入试合格者不能再报本年度的第2次募集。
- 外国大学毕业者在合格发表后可能被确认入学资格，不符合京都大学规定的，即使合格也不受理入学手续。外国人留学生的教育研究内容受安全保障出口管理的限制。
- 资格10（个别出願资格审查）者须事先受审，8月入试的申请截止为 2026/5/18（已过）。
- 入学料 282,000 日元，授業料 年 535,800 日元（均为预定额）；国费外国人留学生免缴。
- 笔试只能用铅笔、自动铅笔、橡皮、尺、仅有计时功能的手表等，不能用词典。迟到30分钟内可入场；缺考2科以上失格。
- 研究生（外国人留学生）是另一条路线：随时募集，须先经京都大学 AAO 确认资格并取得指导教员的内诺。这不是修士入试的要求。
- 咨询：情報学研究科教務掛（総合研究8号館1階），jyoho-kyomu@mail2.adm.kyoto-u.ac.jp，Tel 075-753-4894／5500（平日 9:00–17:00，12:00–13:00 除外）。
- 可以申请成绩提供（8月入试的申请方法见出願状况·合格发表页）。

### 研究室 / 指導教員
- 事前連絡要否：不要。要项没有要求出願前联系教员；各研究室的联系方式见志望区分案内。
- 2027年度志望区分（共9个，デ－4 本年度不配属）：
  - デ－1 统计数理：下平 英寿 教授、本多 淳也 准教授｜统计学、机器学习、数据科学的方法与理论（语言模型的统计解析、多臂老虎机、强化学习）｜[研究室](http://stat.sys.i.kyoto-u.ac.jp)
  - デ－2 统计推论：原 尚幸 教授（国际高等教育院）｜图模型、统计因果模型、贝叶斯推断、计算代数统计，与人文社会科学的融合研究
  - デ－3 信息论学习：田中 利幸 教授、小渕 智之 准教授｜信息统计力学、压缩感知、深度学习的数理｜[研究室](http://www-adsys.sys.i.kyoto-u.ac.jp/)
  - デ－4 信号信息处理：林 和則 教授｜本年度不募集
  - デ－5 动态智能：明石 望洋 特定准教授｜储备池计算、时间序列预测、力学系重构、软体机器人与物理计算｜[主页](https://sites.google.com/view/nozomiakashi/)
  - デ－6 应用机器学习：鹿島 久嗣 教授、竹内 孝 准教授、新 恭兵 助教｜机器学习·数据挖掘方法及应用、人机协作计算
  - デ－7 医疗健康数据科学：田村 寛 教授｜医疗影像AI、诊疗报酬数据的流行病学研究。研究用数据集原则上由学生自己确保；用京大医院的数据需要高水平日语和对日本法令的理解｜[受入方针](https://sites.google.com/kyoto-u.ac.jp/ds7)
  - デ－8 物理智能：森本 淳 教授、山森 聡 特定助教｜机器人学×机器学习，强化学习、模仿学习，人形机器人实机实验｜[研究室](https://lm.sys.i.kyoto-u.ac.jp/)
  - デ－9 计算智能系统（NTT コミュニケーション科学基礎研究所连携）：岩田 具治 连携教授｜元学习、利用归纳偏置的学习
