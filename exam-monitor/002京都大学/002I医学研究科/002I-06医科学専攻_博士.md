## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 不另设英语笔试，出願时提交 TOEFL iBT 或 TOEIC L&R 公开考试成绩，只认出願截止日前2年以内（2024/12/24 以后）受检的成绩，计入综合判定。
- TOEFL iBT：ETS 直送（DI 9501）＋Test Taker Score Report 复印件，或 Test Taker Score Report 原件（自行打印的 PDF 不算原件）；Home Edition、ITP、MyBest 不受理。
- TOEIC L&R：交数字公式认定证复印件；所在国家·地区不发数字认定证的，由考试机构直接寄原件；IP 不受理。

#### 日本語要件
- 要项没有要求提交日语成绩。

### 筆記試験（专门科目）
- 不设笔试，按外部英语成绩、口頭試問和出願书类综合判定。

### 口述試験 / 面接
- **官方形式**：2027/1/19 口頭試問：用约10分钟发表迄今的研究内容（含修士论文），之后答辩；发表用 PDF 须在 2027/1/17 23:59 前上传到指定位置。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：若干名（2027年4月入学，3年制博士後期，只有1月一轮）；本課程外部招生到 2028年4月入学为止。
- 出願资格：修士或专门职学位（含2027/3预计）、外国相当学位等之一；外国大学毕业需确认资格的，经 AAO 后 2026/11/18 17:00 前申请（非独立出願，已截止）；资格6–8须 2026/11/27 17:00 必达申请个别审查（国内 11/23 前邮戳的迟到也受理，非独立出願）；常勤在职者须在 2027/3/31 前离职。
- 要提前准备的书类：志望教授的出願同意；研究概要（所定样式，约1,500字）；志望理由书（所定样式）；资格6–8另交研究経過報告書；TOEFL iBT/TOEIC L&R 成绩。
- 出願：京都大学 WEB 出願系统（2026/12/16 起可输入）登录并缴检定料 30,000 日元（另付手续费），书类以簡易書留速達邮寄或窗口提交，期限内必达（国内 12/23 前邮戳的迟到也受理）。
- 并愿：尚未核实是否可同时报考其他专攻或选拔类别。请以本年度募集要项或招生窗口答复为准。
- 咨询：具体招生窗口尚未核实。请通过[研究科入试信息（含合格发表）](https://www.med.kyoto-u.ac.jp/apply/exam/)查找联系方式。
