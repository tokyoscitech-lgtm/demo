## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 8月实施和1-2月实施相同：外国語（英语）配点 100 分，不设笔试，用 TOEIC L&R、TOEFL iBT（含 Home Edition）或 IELTS Academic 的成绩评价。出願书类表里英语成绩单标的是「全员」提交，社会人特別選抜也要交。
- 成绩的受检时期：8月实施须为 2024年7月以后受检；1-2月实施须为 2025年1月以后受检。
- 提交方式（全学共通办法）：TOEIC 交数字版公式认定证（在 Web 出願系统里录入邮件中的 URL，并打印后随书类寄出；在日本国内受检的必须用这一方式，无法发行数字证书的国家受检者交公式认定证原件）；TOEFL iBT 交 Test Taker Score Report 原件，没有纸质版的要让考试机构直送 Official Score Report（Institution 代码 9995，Department 代码 99）并另交 PDF 打印件；IELTS 要把 Additional TRF 数据直送筑波大学并交 Test Report Form 复印件。直送的数据要在书类截止日前到达，办理可能要几周。
- 不受理：TOEIC IP、TOEFL ITP、IELTS General、IELTS Academic 线上版、IELTS One Skill Retake。截止日前没交有效成绩的，按出願不受理或缺考处理，不进入选拔。
- 换算方法：公衆衛生学的注记没有写分数怎样换算成 100 分，也没有写最低分。同一份要项里フロンティア医科学的注记写有「TOEIC L&R 850、TOEFL iBT 96、IELTS 6.5 以上按满分计」，这条是否也用于公衆衛生学没有读到明确说法。
- 海外居住者特別選抜：英语不是母语、且大学不是全英语授课的人要交 TOEFL、TOEIC 或 IELTS 成绩（入学前2年以内，可交复印件，没有最低分）；全英语完成学位的人可改交在读学校出具的授课语言证明。

### 日本語要件
- 要项没有要求提交 JLPT、EJU 等日语成绩，一般入学試験也没有针对外国人留学生另设区分。
- 试验使用的语言在 Web 出願时从日语和英语中选一种，専門科目和口述試験都按所选语言进行；出願后和考试当天都不能改。
- 必修科目用英语开课，海外居住者特別選抜全程用英语。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 外国語（100分，无笔试；8月实施·1-2月实施相同） | 用 TOEIC L&R、TOEFL iBT、IELTS Academic 成绩评价；换算方法官方没有写 | 2027募集要项 |
| 専門科目·一般入学試験（100分，60分钟；8月实施·1-2月实施相同） | 与公衆衛生学等有关的专门科目，从「公衆衛生学基礎」和「統計学」中选一科，出願时选定，之后不能改；各科题数要项没有写 | 2027募集要项 |
| 専門科目·社会人特別選抜（100分，60分钟；8月实施·1-2月实施相同） | 从「公衆衛生学応用」和「統計学」中选一科，出願时选定，之后不能改；各科题数要项没有写 | 2027募集要项 |
| 口述試験（200分；8月实施·1-2月实施相同） | 个别面接，问公共卫生方面的内容和志望动机 | 2027募集要项 |

- 两轮的总分都是 400 分：外国語 100＋専門科目 100＋口述試験 200，口述占一半。根据提交的书类和学力检查的结果综合判定，要项没有公布合格最低分。要项的科目表里，社会人特別選抜一行的外国語和口述試験两栏是空白，プログラム官网写明社会人特別選抜同样是外国語、専門科目加口述試験。
- 「統計学」是新设的选考科目，プログラム官网说明其水平相当于統計検定2级（含数学）。选統計学的人考试时用大学发的计算器，不能自带。
- 海外居住者特別選抜不考笔试，按成绩等书类和口述试验（含面试中的英语能力）选拔。
- 大学过去问页上的2025年度实施试题，本次因网站限制没能打开 PDF，题数和题型没有读到。
- 题目倾向（体验记，非官方）：没有找到本プログラム的考生体验记，暂无可写的内容。

### 口述試験 / 面接
- **官方形式**：个别面接，配点 200 分，就公共卫生和志望动机提问。8月实施 2026/8/25 和1-2月实施 2027/1/26 都安排在専門科目当天下午 13:00–18:00 之间，每人的时长要项没有写；使用出願时选定的语言（日语或英语）。プログラム官网说明口述看的是逻辑分析能力、构想力和学习意愿。海外居住者特別選抜的口述试验原则上线上进行，书类审查通过后用邮件约时间。
- **実際に聞かれた内容**：没有找到本プログラム的面接体验记，实际提问内容不明。
