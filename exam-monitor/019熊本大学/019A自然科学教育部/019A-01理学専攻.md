## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 不另设英语笔试，用外部成绩评价；成绩须是考试第一天前2年以内受检的。TOEIC L&R 原则上交公式认定证原件（不得已时可交清晰打印的数字认定证）；TOEFL iBT 交 Test Taker Score Report，并须在出願书类提交前从 ETS 账户向熊本大学（DI 代码 0135）办理在线送分。TOEIC IP、TOEFL ITP 不受理。
- 一般入试（8月）：
  - 各コース都在考试当天交成绩：数学、地球環境科学收 TOEIC L&R 或 TOEFL iBT（Home Edition 不认）；生物科学收 TOEIC L&R 或 TOEFL iBT（含 Home Edition）；物理科学、化学只收 TOEIC L&R。
- 第2期募集（1月）：
  - 数学、物理科学、化学コース不要求英语成绩。
  - 地球環境科学コース考试当天交 TOEIC L&R 或 TOEFL iBT（Home Edition 不认）原件。
  - 生物科学コース须在出願时交 TOEIC L&R 或 TOEFL iBT 原件；出願时交不了的交申立书，考试当天仍交不出的，英语按0分或按缺席处理。
- 外国人留学生入试（第2期）：出願时交日语或英语能力证明之一（见日本語要件）。

#### 日本語要件
- 一般入试·第2期募集：外国人志愿者须提交日本語能力試験的认定书或日本留学試験成绩通知书（复印件，任何等级均可）；日本国内大学毕业（含预计）者免交。
- 外国人留学生入试（第2期）：日本語能力試験认定书、日本留学試験成绩通知书、TOEIC L&R 公式认定证、TOEFL 成绩单等任交其一（复印件可）。
- 外文书类（英文除外）须附日文译文。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 数学コース：専門基礎科目 | 线性代数、微分积分、集合与位相（一般入试和第2期相同） | 9:00–11:00，120分钟 |
| 物理科学コース：専門科目（一般入试） | 力学、电磁学、热统计力学、量子力学；可带仅有运算功能的计算器 | 9:00–11:30，150分钟 |
| 物理科学コース：記述試験（一般入试） | 就志望理由、研究计划等写文章 | 11:30– |
| 地球環境科学コース：専門科目（一般入试） | 地球环境科学一般 | 9:00–11:30，150分钟 |
| 生物科学コース：専門科目（一般入试） | 生物科学一般 | 9:00–11:00，120分钟 |

- 一般入试化学コース、第2期募集除数学以外的各コース都不设笔试，改为口述试验。
- 合否按各コース的考试成绩和提交书类综合判定。
- 变更点：数学コース一般入试从本年度起取消「専門科目」，笔试只考専門基礎科目。

### 口述試験 / 面接
- **官方形式**：一般入试：数学、地球環境科学、生物科学コース为个人面接（含对志望理由书等的提问），化学コース为口述试验（分析化学、无机化学、有机化学、物理化学），物理科学コース没有面接、以记述试验代替；第2期募集：数学コース为面接，物理科学コース为口述试验（力学、电磁学、热统计力学、量子力学，并问研究计划、志望动机），化学コース为口述试验（专门科目、毕业研究），地球環境科学·生物科学コース为口述试验（专门科目、毕业研究、研究计划、志望动机）；社会人入试为口述试验（专门科目、毕业研究、研究计划、志望动机）；推薦入试（仅化学コース）：学校推薦型面接、自己推薦型口述试验。

- 募集人员：一般入试110名（5コース合计，含推薦入试；化学コース学校推薦型15名左右）；第2期募集20名左右（5コース合计）；社会人入试、外国人留学生入试各コース若干名。
