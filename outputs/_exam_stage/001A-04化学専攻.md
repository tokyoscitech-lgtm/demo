## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 2027年度入试（2026年8月实施）：专攻页说明本年度仍沿用以往做法，即笔试当天在本校考场考 TOEFL ITP。本年度是否像上一年度那样也可以用事先提交的成绩代替，未能核对（要项 PDF 无法读取）。
- 上一年度（2026年度入试）的做法，供参考：可以在考场考 ITP，也可以事先提交 TOEFL iBT 或 TOEIC L&R 的正式成绩；两者都有时取较高的一方。TOEFL iBT 只收会场受験型，Home Edition 和 MyBest 不受理，把 Test Taker Score Report 的 PDF 上传到 WEB 出願系统的マイページ；TOEIC L&R 只收在日本国内考的公開テスト，要通过 IIBC 的成绩确认服务向本専攻提交并上传数字版公式认定证。成绩须为 2023/9/1 以后受检，只能上传一种，截止日为出願截止日前后。
- 官方没有公布最低分、换算方法和英语的配点。
- 变更点：2028年度入试（2027年度实施）起取消考场的 TOEFL ITP，只收 TOEFL iBT 或 TOEIC L&R 公開テスト的正式成绩（二选一）。

### 日本語要件
- 要项没有要求提交日语成绩。専攻页说明修士、博士课程用英语授课。
- 笔试的作答语言：专攻的旧版入试案内（博士课程用，2022年）写明可用日文或英文作答；本年度修士的规定未能核对。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 専門科目（配点官方未公布，时长未获取到） | 共9题选答5题：化学6题（物理化学、有機化学、無機·分析化学各有「基礎」「標準」两题）＋数理科学1题＋地球科学1题＋生物化学1题。这是上一年度要项的构成，本年度过去问页的科目构成与之相同，但本年度的题数与选答规则未能从要项核对 | 参考：令和8年度要项／过去问页 |
| 作文（约400字，配点官方未公布） | 笔试当天写：入学后希望进入的领域和研究计划（上一年度的做法） | 参考：令和8年度要项 |

- 各领域的出题方向（令和8年度「出題意図」）：物理化学以量子化学、热力学为基础；有機化学以结构式和有机电子论为基础，考反应与立体结构；無機·分析化学以配位化学、光谱法为基础；数理科学考物理化学所需的数学和物理；地球科学考矿物、岩石、水溶液等物质；生物化学考蛋白质、核酸等。
- 总分构成和合否判定方法官方没有公布。笔试得分可以申请开示（见下文）。
- 题目倾向（体验记，非官方）：论述题的题型与过去问接近；無機·分析化学的基礎题每年内容相近，分析方法的说明题几乎每年都出；物理化学和無機·分析化学被认为比较容易拿分；专门科目的比重大于英语。

### 口述試験 / 面接
- **官方形式**：有口述试验。上一年度要项写明线上进行，考察研究所需的基础学力、报考动机是否妥当以及适应性；配点和时长官方没有公布。本年度修士的口述日期和对象未获取到（博士要项对 2026年10月入学者写的是“仅限事先通知的对象者”）。
- **実際に聞かれた内容**：没有找到可以公开阅读的具体问答记录；找到的1篇合格体验记（外部生）的口头试问部分是付费内容，无法确认。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：2027年4月入学以要项为准，令和8年度为72名（令和4–8年度一直是72名）。另设 2026年10月入学枠，上一年度写的是“若干名”。
- 10月入学：本専攻是研究科里唯一设10月入学的修士选拔，与4月入学用同一次8月考试。上一年度规定：选10月入学的人，出願资格里的毕业期限提前到9月30日，并且不能同时以次年4月入学为目的报考本研究科任何専攻。本年度专攻的ガイダンス标题写明对象是“令和8年10月入学·令和9年4月入学”。
- 出願资格：大学毕业或入学前预计毕业、在外国完成16年学校教育等，具体各项以要项为准（本年度要项 PDF 无法读取，未逐项核对）。
- 出願书类：WEB 出願系统填写入学願書；成绩证明书（读过多所大学的要交全部，编入学者还要交编入前的；東京大学理学部毕业预定并报考与所属学科对应的専攻者不用交）；检定料缴纳证明；専攻另行指定的其他书类。上一年度本専攻出願时不要求小论文，作文在笔试当天写。
- 出願方式：只能通过 WEB 出願系统，没有邮寄或窗口出願。
- 检定料 30,000 日元（本年度缴纳期间 2026/6/1–6/23，已截止）；在本校就读的日本政府（文部科学省）奨学金留学生免缴。
- 入学料 282,000 日元（预定额）。授業料：上一年度修士要项为年 535,800 日元（前期 267,900 日元）；本年度修士要项的金额未能核对。国费留学生免缴入学料和授業料。
- 入学手续：合格者自己在マイページ下载入学許可通知書，书类不邮寄；辞退入学要提交入学辞退届。
- 笔试得分开示：考试实施年度的 11/1 以后、笔试后2年以内，带填好的「大学院入試情報開示申請書」和受験票到化学本館1階1101室化学事務室窗口申请（平日 10:00–12:00、13:00–16:00；3、4、8、9月不受理），约一周后在窗口交付。
- 外国人特別選考、国際卓越大学院コース（GSGC）和大学院研究生是另外的路线，各有单独的要项。这不是修士一般入试的要求。
- 咨询：考试内容问化学専攻入試実施事務局（〒113-0033 東京都文京区本郷7-3-1），nyushi@chem.s.u-tokyo.ac.jp，Tel 03-5841-4321；出願手续问理学系研究科学務課教務チーム（大学院担当），daigakuin.s@gs.mail.u-tokyo.ac.jp，Tel 03-5841-4080。合否不接受电话询问。
