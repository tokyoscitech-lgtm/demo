## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 三个轮次都不设英语笔试，用出願时提交的外部英语检定成绩评分。配点：7月实施（推薦）25分；8月实施 200分；1-2月实施 200分。
- 受理的考试：TOEIC Listening & Reading、TOEFL iBT（含 Home Edition）、IELTS Academic（机考的 CD IELTS 可以）。不受理：TOEIC IP、TOEFL ITP、IELTS General Training、IELTS 在线版（IELTS Online）、IELTS One Skill Retake。成绩单上须印有本人照片。
- 提交方式：TOEIC 交デジタル公式認定証（在 Web 出願系统里填写 URL 并附打印件；只有在不发行数字认定证的国家受检的才交纸质公式認定証原件）；TOEFL iBT 交 Test Taker Score Report 原件，或让 ETS 直送 Official Score Report（机构代码 9995，部门代码 99）并附 PDF 版打印件，2026年1月起纸质成绩单已废止，没有纸质版的只能走直送；IELTS 须让考试机构把 Additional TRF 数据直送 University of Tsukuba，并交 Test Report Form 复印件。直送数据要在出願截止日前到达大学，处理需要数周。
- 有效期：7月实施须为2024年6月以后受检；8月实施须为2024年7月以后受检；1-2月实施须为2025年1月以后受检。
- 换算：达到基准分的换算为英语满分——TOEIC 860、TOEFL iBT（含 Home Edition）98、IELTS 7.0。低于基准分时怎样换算，要项没有公布公式。
- 没有在出願时提交有效成绩的，英语按缺考处理，不进入选考。
- 与数学等同研究群其他プログラム不同，化学学位プログラム的推薦入学試験（7月实施）也要交英语成绩。

### 日本語要件
- 要项没有要求提交 JLPT、EJU 等日语成绩，也没有针对外国人留学生的另设区分，留学生与日本学生参加同一场考试。
- 要项没有写明化学试题和作答所用的语言，面接使用的语言也没有写。

- 总分构成：8月实施共 1200 分（化学 600＋英语 200＋口述 400）。1-2月实施按要项英语版是化学 600＋英语 200＋口述 800，共 1600 分；口述的 800 分只在英语版读到，日文版的1-2月日时表没有读到，报考前请对照日文要项确认。7月实施（推薦）共 200 分（英语 25＋専門科目 75＋口述 100）。要项没有公布合格最低分和具体判定方法。
- 社会人特別選抜与一般入学試験在同一张试验日时表里，科目和配点相同；另外要交研究计划书。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：7月实施（推薦入学試験）10名；8月实施 一般入学試験35名、社会人特別選抜若干名；1-2月实施 一般入学試験5名（由6名订正）、社会人特別選抜若干名。各数字都包含连携大学院方式（産業技術総合研究所的教员）的招收人数。10月实施本プログラム不举行。
- 出願资格：日本的四年制大学毕业或2027年3月底前预计毕业、在外国完成16年学校教育、在外国3年以上的课程取得相当于学士的学位等。22岁以上、希望被认定为“与大学毕业同等以上学力”的人，要先申请个别出願资格审查。外国学历是否符合资格可事先向入試課确认。
- 个别出願资格审查的申请截止日：7月实施 2026/5/20（已过）；8月实施 2026/7/3（已过）；1-2月实施 2026/11/24（周二）。向数理物質エリア支援室大学院教務申请。
- 推薦入学試験（7月实施）的资格：已修得的学分中 A（優）评价占总学分70%以上的人，或在特定研究领域特别优秀的人；须由所属学部长或指导教员等推荐，并承诺合格后一定入学。
- 社会人特別選抜的资格：除一般的出願资格外，到入学前一个月为止有1年以上的社会经验。联系教员时要说明是报社会人特別選抜。
- 志望指导教员：在 Web 出願系统里选择志望的指导教员；出願前必须已经取得该教员的内诺（见下一小节）。教员研究分野一览里用〔 〕括起来的教员不能选作指导教员。
- 出願书类：出願者調書、学历·研究历·职历調書、毕业（预计）证明书、成绩证明书、外部英语成绩单（三个轮次都要）、推薦書（7月推薦）、研究计划书（7月推薦和社会人特別選抜）、研究历证明书（有的人才交），以及 Web 出願系统生成的受験票、收件人标签、出願书类提出明细票。证明书须为原件或发行机构认证的副本，原则上不退还。
- 出願方式：在 Web 出願系统录入出願信息、选择志望指导教员、支付检定料并提交，之后把书类用書留寄到数理物質エリア支援室，截止日必达，也可以送到窗口。光在 Web 上录入不算完成出願。
- 检定料 30,000 日元，信用卡或便利店支付，手续费由出願者负担，缴纳后不退。国费外国人留学生不收。
- 外国籍的出願者须按安全保障出口管理的规定，由志望指导教员取得「リファレンス番号」并在 Web 出願系统里填写；取得需要时间，要尽早联系教员。
- 入学料 282,000 日元（缴纳后不退）。授業料每学期 267,900 日元（年额 535,800 日元）；在留资格为「留学」的外国人留学生每学期 304,400 日元（年额 608,800 日元）。金额在入学前或在学期间可能改定。入学手续的资料在合格发表当天发到出願时登记的邮箱；入学手续的具体日期没有读到。
- 试场：筑波大学筑波キャンパス（茨城県つくば市天王台1-1-1），具体建筑和教室在受験者须知里另行通知。可携带物品、迟到规定没有读到。
- 需要受験上配虑（残疾等）的人要事先申请，申请期限没有读到；要项注明不一定能满足全部要求。
- 成绩开示：只对不合格的本人开放，只开示总分；有缺考科目的人不在对象内。2027年度入试的受理期间是 2027/5/1–5/31，受理结束后邮寄。
