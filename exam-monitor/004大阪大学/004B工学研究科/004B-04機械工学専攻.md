## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 一般選抜：出願时提交 TOEIC L&R 或 TOEFL iBT 的成绩1份（本専攻不收 IELTS）。TOEIC 交数字公式认定证的打印件（QR 码要能读取），TOEFL 交 ETS 账户下载的 Test Taker Score Report 打印件；TOEFL iBT Home Edition 可以。
- 有效期：2024/8/1 以后受检、且能在出願期间内交出证明的成绩。
- 不受理：TOEIC IP、TOEIC S&W、TOEIC Speaking、TOEIC Bridge、TOEFL ITP。
- 配点和最低分官方没有公布；英语成绩计入总分（成绩开示的总分包含 TOEIC 等）。没有校内英语笔试。
- 外国人留学生特別選抜（只有夏季）：同样只收 TOEIC 或 TOEFL iBT（不收 IELTS）；有效受检期间为 2024/8/1–2026/5/31。
- 英語コース：非英语母语且最终学历不是英语授课的，须提交 TOEIC、TOEFL、IELTS 或 CPE 之一的成绩；要项没有写最低分。

### 日本語要件
- 一般選抜：要项没有要求提交日语成绩（JLPT、EJU 都没有规定）。
- 外国人留学生特別選抜：出願资格里写明要有修学所需的日语能力，出願时从下面5种里交1种证明——拟接收的指导教员出具的证明（格式不限）、日本留学试验（EJU）成绩通知书复印件、日本语能力试验（JLPT）等的成绩通知书复印件、日语学校的成绩证明、大阪大学国际教育交流中心出具的证明。要项没有规定等级或分数线。
- 本専攻的笔试用日语出题（留学生特別選抜要项的科目表也标明日语出题）；要项没有写可以用英语作答。想用英语就读的走另一条路线「英語による学位取得コース」。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 力学と機械力学（配点官方未公布，90分钟） | 质点的力学、质点系的力学、刚体的力学、多自由度振动系的力学、旋转机械的力学 | 2027一般選抜募集要项 |
| 専門科目（配点官方未公布，4科各45分钟，全部作答） | （1）材料力学：拉压、热应力、扭转、梁的弯曲与挠度、屈曲、薄壁圆筒与球壳、超静定、组合应力；（2）热力学：第一·第二定律、一般关系式、理想气体、エクセルギー、蒸汽与湿空气、化学反应、气体循环、冷冻循环、蒸汽循环；（3）流体力学：静止流体、连续方程与伯努利方程、动量·角动量守恒、管内流动、理想流体、粘性流体（仅层流）；（4）控制工学：传递函数与状态方程、响应·结构·稳定性分析、反馈控制系设计 | 2027一般選抜募集要项 |
| 数学（配点官方未公布，90分钟） | 线性代数、微积分、微分方程、复变函数、矢量分析、傅里叶分析、概率统计 | 2027一般選抜募集要项 |
| 英語コース冬季（参考） | 在日本国内的申请者以面试和/或学力考试选拔，科目和日期要项没有写，向拟指导教员确认；在海外的以书类审查为主 | 英語コース募集要项 |

- 合否判定：按学力试验（笔试和口头试问）成绩与出願书类的审查结果综合判定；规定的考试缺一项即不判定。各科配点、合格线官方都没有公布。
- 産学官共創コース的考试内容与机械工学コース相同。本専攻的機械工学コース不能填第2、第3志望。
- 变更点：留学生特別選抜的科目变更告知（2025年12月）写明，2027年4月入学起热力学新增エクセルギー、化学反应、冷冻循环，其余科目范围不变。
- 题目倾向（体验记，非官方）：数学3道大题，线性代数几乎每年占一整题，复变函数多考留数定理，概率统计近年变难；力学と機械力学3道大题，最后一题多是多自由度振动或旋转体；专门科目约七成是基础题，流体力学被认为最难、新题型多，控制工学流程固定较容易。

### 口述試験 / 面接
- **官方形式**：一般選抜和留学生特別選抜夏季都有口头试问（2026/8/19 13:45 起），与笔试一起计入综合评价；配点、时长、使用语言要项没有写。推薦入学以口头试问为主，必要时加笔试。
- **実際に聞かれた内容**（体验记，非官方，仅1人提及）：2024年8月的外部考生称面试约5分钟，被问到哪些科目答得好或不好、现在的研究和今后研究的关系、TOEIC 的准备情况。
