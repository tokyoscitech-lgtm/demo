## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般入学（夏期·春期相同）：
  - 不另设英语笔试，用出願时提交的 TOEFL iBT、TOEIC L&R、TOEFL ITP 或 TOEIC L&R（IP）成绩换算成75分计入合否；没交成绩的英语按0分处理。
  - 只认2024年4月以后受检的成绩。TOEIC 交デジタル公式認定証打印件或带二维码的公式認定証原件，TOEIC IP 在线版不可用；TOEFL iBT 须交 Test Taker Score Report 打印件，同时让 ETS 把 Official Score Report 直送同志社大学（代码 7078），MyBest 不可用；ITP、TOEIC IP 交成绩证明原件。
  - 同一份成绩入学后用于修士学位的语学资格认定。
- 外国人留学生入试：本コース不要求英语成绩。

#### 日本語要件
- 一般入学：要项没有要求提交日语成绩。
- 外国人留学生入试：须提交下列之一（学内进学者免交）：EJU「日本語」（2025年度或2026年度）的受験票复印件或成绩确认书打印件；JLPT N1「認定結果及び成績に関する証明書」原件（2025年度以后，合否明信片不收）；大学教育用日语进行的证明。小論文须用日语和英语作答，面接也用日语和英语进行。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 専門科目：生命科学（100分）、電気回路（100分）、情報（100分） | 生命科学＝数学·物理·化学；電気回路；情報＝编程·信息处理；三科在同一时段作答 | 10:00–12:00，120分钟 |
| 外国人留学生入试：小論文 | 用日语和英语作答 | 10:00–11:30，90分钟 |

- 一般入学：生命科学100＋電気回路100＋情報100＋英语75，加面接综合判定。
- 専門科目免除：同志社大学医情報学科应届毕业生、指定高专专攻科修了预定者，以及（春期）外校应届毕业生可申请；春期须在 2026/11/26–12/4 必达提交成绩证明书、毕业预定证明书、研究概要、志望研究室調査票，12/17 寄出结果。免除者的専門科目分数不用于合否，但用于奖学金选考。
- 外国人留学生入试：国内居住的正规学生按出願书类、小論文和面接综合判定；国外居住者只能报特别学生，书类选考。

### 口述試験 / 面接
- **官方形式**：一般入学：笔试当天 13:00 起面接，走専門科目免除路线的外部生另加口头试问（出願书类和专攻领域知识），其他人只面接；外国人留学生入试：小論文当天 13:00 起面接（含口头试问），用日语和英语进行。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：夏期一般入学45名；春期一般入学若干名；外国人留学生入试（4月入学、9月入学）各若干名。
- 出願资格：大学毕业（含2027年3月预计）或外国16年学校教育等；外国3年制学士等须先做资格认定（春期 2026/11/26–12/4 必达，结果 12/17）；外国人留学生入试限外国籍，前期正规学生只收日本国内居住者，资格认定须事先联系研究科事務室（9月入学 2026/11/25 截止）；出願后不能更改志望专攻·コース。
- 要提前准备的书类：研究概要（所定用纸，入学理由和希望研究题目·概要，2页以内单面）、志望研究室調査票（第1–3希望）、TOEFL/TOEIC 成绩；留学生入试另需推荐信（所定样式，推荐人密封）、研究計画書（日文或英文，A4横写12号字，2页以内）、与希望指导教员往来的邮件、中国大学毕业者的学信网 Online Verification Report、日语证明。
- 出願：一般入学用纸质願書（志願票随纸质要项发放，不能下载），简易書留速達邮寄或窗口提交，检定料 35,000 日元；留学生入试先在网上出願系统登记再寄书类，检定料正规学生 15,000 日元、特别学生 10,000 日元。
