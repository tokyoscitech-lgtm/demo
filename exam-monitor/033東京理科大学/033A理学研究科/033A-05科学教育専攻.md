## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 不另设英语笔试，用外部成绩评价。
- 卒業見込者対象：
  - 交 TOEIC 或 TOEFL 成绩单原件一份：TOEIC L&R 公开考试或 IP 均可（公开考试只收 Digital 公式認定証打印件），TOEIC Bridge 不可；TOEFL iBT 和 ITP 均可，TOEFL iBT Home Edition 不可。
  - TOEFL iBT 须由 ETS 直送大学（理学研究科 Institution Code G277）。
  - 须为出願截止前 2 年以内受验；只能交一份，交后不能更换；出願时来不及的可在考试当天带来。
  - 在日本国外考 TOEIC、交不出 Digital 公式認定証的，交成绩单原件、能看出考场的受验票等复印件和护照照片页复印件。
- 現職教員対象：只交研究计划和在职证明，不收英语成绩。

#### 日本語要件
- 要项没有要求提交日语成绩。出願书类使用大学的日文所定用纸。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 小論文（事先布置） | 结合教育与数学、或教育与理科专门知识的课题；课题向志望指导教员或専攻主任索取，随出願书类提交 |  |

- 卒業見込者対象：书类审查、面接、口頭試問（围绕小论文）和外部英语成绩综合判定。
- 現職教員対象：书类审查和面接判定；修了时可取得数学或理科的专修免许。

### 口述試験 / 面接
- **官方形式**：卒業見込者対象：面接及び口頭試問，内容为事先提交的小论文；現職教員対象：面接。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：40名（専攻入学定员，含学内選考、現職教員対象等 2027年度全部入试）。
- 出願资格：大学毕业（含 2027年3月预计）或外国 16 年学校教育等，且须符合以下之一：①高中·初中现职专任教员或教育机构在职者；②有产业界理工业务经验、希望从事中等教育或科学教育者；③热切希望从事中等教育（数学·理科）者；現職教員対象须有 1 年以上教员经历，出願时和修了时都在职（有期雇用除外）；出願后不能变更専攻。
- 要提前准备的书类：小论文、外部英语成绩单、科学教育専攻专用履历书（所定用纸）、志望理由書（所定用纸，800字左右）；想在本専攻新取得一种教员免许的须事先找専攻主任商量；現職教員対象另交研究計画又は研修課題（格式自由）和在職証明書；国外居住者请希望指导教员填写「事前相談シート」。
- 出願：简易书留·速达邮寄或窗口提交，邮戳有效（国外寄出须最后一天必达）；检定料 35,000 日元（银行窗口电汇或便利店）。

### 研究室 / 指導教員
- 事前連絡要否：必须。要项规定出願前必须联系希望的指导教员（未定时联系専攻幹事或専攻主任）并接受指示，小论文课题也只能通过志望指导教员或専攻主任取得；国外居住者须请教员填写事前相談シート。
