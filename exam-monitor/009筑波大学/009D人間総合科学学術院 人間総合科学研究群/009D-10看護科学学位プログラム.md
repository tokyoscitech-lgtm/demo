## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 7月实施（推薦）、8月实施（一般·社会人）都一样：科目名「外国語」，配点 100 分，不考笔试，用出願时提交的外部英语成绩评分。1-2月实施如果举行，要项里英语成绩的有效期已经按三轮分别写好，可以看出同样要交。
- 收的考试：TOEIC L&R、TOEFL iBT（含 Home Edition）、IELTS Academic。不受理：TOEIC IP、TOEFL ITP、IELTS General Training、IELTS Academic 线上版、IELTS One Skill Retake。
- 有效期（考试日往前2年以内）：7月实施须为2024年6月以后受检，8月实施须为2024年7月以后，1-2月实施须为2025年1月以后。
- 提交方式：TOEIC 交 Digital Official Score Certificate（在 Web 出願系统填证书 URL，并打印出来随书类提交；在不发行数字证书的国家受检的才交纸质公式认定证原件）。TOEFL 交 Test Taker Score Report 原件，没有纸质成绩单的（2026年1月起停发）让 ETS 直送 Official Score Report（Institution 代码 9995，Department 代码 99）并打印 PDF 版一起交。IELTS 让考点把 Additional TRF 数据发到筑波大学，并附 Test Report Form 复印件。纸质件贴在 Web 出願后下载的「英語スコア票貼付台紙」上寄出，成绩单不退还。
- 英语成绩是全员必交的出願书类，期限内没交齐就不受理出願或按缺考处理。直送数据可能要几周才到，要提前办。
- 换算方法和最低分：要项没有写看護科学的换算基准（同一份要项里 TOEIC 850、TOEFL iBT 96、IELTS 6.5 的基准只写在フロンティア医科学和公衆衛生学两个プログラム下）；全学共通的处理办法里也没有本プログラム的换算规定。
- 变更点：2026年度（2025年8月实施）以前是プログラム自己出的英语笔试（100分），2027年度起改为评价外部英语成绩。

### 日本語要件
- 要项没有要求提交 JLPT、EJU 等日语成绩，也没有为外国人留学生另设选拔区分，留学生和日本学生走同样的推薦、一般、社会人三个区分。
- 没有笔试，所以不存在试题语言的问题；口述試験使用的语言要项没有写。小論文、研究計画書的字数只给了日文字数（见下）。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 外国語（100分；7月实施·8月实施相同，不设考试时间） | 不出题，按提交的 TOEIC L&R／TOEFL iBT／IELTS Academic 成绩评分；换算方法未公布 | 2027募集要项 |
| 口述試験（200分；7月实施·8月实施相同，10:00–17:00 之间个别进行） | 个别面接，就与看護学有关的专门知识和本人的志望等进行试问；每人的时长没有写 | 2027募集要项 |
| 専門科目 | 本年度起废止。上一年度（2025年8月实施）是与看護学有关的基础课题 100 分，社会人特別選抜另考小論文和英语 | 令和9年度入试变更通知 |
| 1-2月实施 | 科目和配点未公布（截至 2026-10-11），以11月公布的要项为准 | 博士前期課程募集要项 |

- 7月实施和8月实施的总分都是 300 分：外国語 100＋口述試験 200。推薦入学試験、一般入学試験、社会人特別選抜的科目和配点相同，区别在出願条件和提交的文书。根据书类和考试结果综合判定，要项没有公布合格最低分。
- 出願时要在 Web 表单里写文书，它是面接的材料而不是独立计分的科目：推薦入学試験和一般入学試験写「小論文」约1,200字；社会人特別選抜写「研究計画書」约800字（志望理由和入学后的研究计划）。小論文的题目要求没有读到。
- 题目倾向（体验记，非官方）：没有找到本プログラム的考生体验记；而且今年是新制度（只有英语成绩和面接）的第一年，没有可参考的先例。

### 口述試験 / 面接
- **官方形式**：个别面接，配点 200 分（上一年度是 100 分），问与看護学有关的专门知识和本人的志望等。7月实施在 2026/7/3、8月实施在 2026/8/24，都在 10:00–17:00 之间，每人的时段另行通知。考场是筑波大学筑波キャンパス（茨城県つくば市天王台1-1-1），具体建筑写在考试约1周前掲載的「受験者心得」里。每人的面接时长、面接语言、是否要做发表，要项没有写。
- **実際に聞かれた内容**：没有找到本プログラム的面接体验记，实际提问内容不明。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：7月实施（推薦入学試験）10名；8月实施（一般入学試験）5名，社会人特別選抜若干名（プログラム的说明会资料写明这若干名包含在一般入学試験的5名之内）；1-2月实施的人数未公布，是否实施也未定。合计入学定员15名。
- 变更点：上一年度没有推薦入学試験，一般入学試験（含社会人特別選抜）15名全部在8月实施；本年度拆成推薦10名＋一般5名。
- 出願资格（各区分共通）：日本的四年制大学毕业或入学前预计毕业、由大学改革支援·学位授与機構授予学士学位、在外国完成16年学校教育、在外国3年以上的课程取得相当于学士的学位、经个别出願资格审查认定有同等以上学力且满22岁等。要项的出願资格里没有写必须持有看護師免許或必须是看護系大学毕业。助産師養成科目和診療看護師コース另有的选修条件没有读到。
- 推薦入学試験的追加条件：出願时为止取得的学分里，成绩为 A（優）以上的科目占总学分的70%以上，或与此相当并在看護科学的特定领域特别优秀；并且保证合格后一定入学。要交本人填写的「推薦要件確認書」（规定样式）。要项里没有要求教员写的推荐信。
- 社会人特別選抜的追加条件：到入学前一个月为止有2年以上的社会经验。常勤、非常勤都算，企业、官公厅、教育机构的工作和家务劳动都算；以学生身份为主时打的工不算。联系指导教员时要说明自己报的是社会人名额。
- 个别出願资格审查的申请截止：7月实施 2026/5/20（周三）（已过）；8月实施 2026/7/3（周五）（已过）；1-2月实施 2026/11/24（周二）。要交出願者調書、学歴·研究歴·職歴調書、毕业证明书、成绩证明书等，社会人还要交研究計画書。
- 志望指导教员：在 Web 出願系统里选第1志望的指导教员，第2志望可以不填；填了的教员都必须事先联系并取得承诺。
- 出願书类：毕业（预计）证明书和成绩证明书（都要授予学士学位的大学出具的原件）、外国大学毕业者的学位取得证明书、外部英语成绩单（全员）、推薦要件確認書（仅推薦）、在学或在职者的受験·就学承認書（2027年3月毕业者和非常勤、打工者除外）、检定料收纳证明或信用卡支付结果画面的打印件、国费留学生证明书（符合者）。姓名与证明书不一致的要附户籍抄本等。小論文、研究計画書原则上在 Web 表单里填，只有含数学式等无法录入时才交纸质版。要项里没有要求交看護師免許的复印件。
- 出願方式：在 Web 出願系统录入信息、上传证件照（JPEG，3个月以内）、选指导教员、填写安全保障出口管理（みなし輸出）的确认事项、支付检定料后提交；然后打印受験票、收件人标签、英語スコア票貼付台紙和出願书类提出明细票，把书类邮寄（截止日必达）或送到医学医療エリア支援室。受験票自己打印，考试当天带去。
- 检定料 30,000 日元，在 Web 出願期间内用信用卡或便利店支付，缴纳后不退。
- 入学料 282,000 日元（缴纳后不退）。授業料年额 535,800 日元（每期 267,900 日元）；外国人留学生年额 608,800 日元（每期 304,400 日元）。入学手续的具体期限写在合格发表当天发出的邮件里，要项没有写日期。
- 在职的人可以申请長期履修，把修业年限延到3年或4年，授業料总额按标准修业年限计算后分摊；新生在入学手续期间申请，要先取得プログラムリーダー和指导教员的同意。要项里夜间（18:00 起）开课的教育方法特例只适用于フロンティア医科学和公衆衛生学，没有列入看護科学。

- 成绩开示：只对不合格的本人开放总得点，缺考1科以上的人不在对象内。受理期间是 2027/5/1–5/31，把入試情報開示請求書、受験票（或代替的身份证件复印件）和贴好460日元邮票的回信信封寄到入試課大学院入試担当。
