## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 1-2月实施：没有单独的英语笔试。出願时提交外部英语成绩：TOEIC 公式認定証（或デジタル公式認定証）、TOEFL 受験者用スコア票、IELTS（Academic）公式成绩证明书之一，并在 Web 出願系统里填写分数。
- 有效期：1-2月实施须为 2025年1月以后受检的成绩。
- 要项没有规定最低分，也没有把外部英语成绩单独列为配点或给出换算方法；英语能力在口述試験1里考查（用英语出题和作答）。
- 免除：母语是英语的人、用英语接受高等教育的人不用交。没有英语成绩的人，推薦書里必须有对英语能力的评价。
- 按全学共通的处理办法：TOEIC 只认 L&R 公开考试，IP 不受理（在日本考的交数字版认定证，把 URL 填进系统并打印邮寄）；TOEFL 认 iBT 和 iBT Home Edition，ITP 不受理（交 Test Taker Score Report 原件，没有纸质版时由考试机构直送，机构代码 9995、Department code 99，并附打印的 PDF 成绩单）；IELTS 只认 Academic，General、在线版、One Skill Retake 不受理（送 Additional TRF 并交 Test Report Form 复印件）。这些种类限制是全学共通文件的规定，本プログラム的要项没有逐条重复。
- 8月实施：官网写的提交物同样是 TOEIC 公式認定証或 TOEFL 成绩单等，没有最低分；这一轮的有效期起算月没有读到。

### 日本語要件
- 要项没有要求提交 JLPT、EJU 等日语成绩，可以只用英语受験。
- 口述試験1 用英语出题、用英语作答，之后的问答可以用英语或日语；口述試験2 的发表和问答可以选英语或日语。研究计划书用英语写（约 1,000 词）。

| 口述試験2（200分；1-2月实施；发表约 10 分钟＋问答约 10 分钟是 2026年1月和8月实施的做法） | 就研究计划（必须是医学·人間生物学与理工情報学·物質科学的融合研究）和入学后的职业规划做发表，再接受问答 | 2027募集要项／受験者心得 |

- 1-2月实施总分 300（口述試験1 100＋口述試験2 200），根据提交的书类和学力检查的结果综合判定；要项没有公布合格最低分。

- 任何一科没考就按缺考处理，不进入选拔。
- 题目倾向（体验记，非官方）：没有找到本プログラム的考生体验记，暂无可写的内容。

### 口述試験 / 面接
- **官方形式**：1-2月实施在 2027/1/22（周五）9:00–17:00 之间进行，每人的时段另行通知，1/25（周一）是予備日。口述試験1（100分）用英语问专业知识，问答部分可用日语；口述試験2（200分）是研究计划与职业规划的发表加问答，英语或日语均可，要自带存好发表资料的笔记本电脑（场内有投影仪，HDMI 接口，转接器自备）。按 2026年8月实施的受験者心得：口述試験Ⅰ 试问 20 分钟，口述試験Ⅱ 发表约 10 分钟＋问答约 10 分钟；发表资料要在考试 3 天前（那一轮是 8/24 9:00）发到指定邮箱，之后不能改，当天另带 A4 打印件 1 份；会场是筑波大学 4B棟（医学エリア）。1-2月实施的受験者心得在考试 1 周前掲載，届时以它为准。海外居住者可在出願期限内交「海外居住者対象のオンライン入試に係る申告書」改为在线受験，时间另行协调；住在日本而有事不能到场的人要在出願期限内咨询。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：1-2月实施（一般入学試験）要项写的是若干名；全学的令和9年度募集人员表里本プログラム（一貫制博士課程）全年为 8 名。8月实施的募集人员没有读到（プログラム官网写的是春入学、秋入学、社会人合计约 15 名，这是改组前的说法）。
- 课程性质：5 年一貫制博士課程，只招 1 年次入学，没有单独的修士課程；要项和官网都没有 3 年次編入学的募集。入学时期：1-2月实施可选 2027年4月或10月，出願期间结束后不能改；8月实施只有 2027年4月入学。
- 取得学位：改组后为博士（医理工学）。修了要件按官网 Q&A 是通过 QE（博士論文研究基礎力審査）、修得 45 学分以上并达到规定的达成度；不强制要求已发表论文，但要有相当于一篇原著论文的成果。
- 出願资格：日本的四年制大学毕业或入学前预计毕业；由大学改革支援·学位授与機構授予学士学位；在外国完成 16 年学校教育（含预计）；在外国 3 年以上的课程取得相当于学士的学位（出願前要先确认资格）；经本大学院个别审查认定与大学毕业同等以上学力、且满 22 岁的人（要先申请个别出願资格审查）。面向的是医学·生命系（含 6 年制学部）想做理工情报融合研究的人、理工情报系想做生命医科学融合研究的人，以及临床医、企业研究者等有实务经验的社会人。
- 个别出願资格审查和出願资格咨询的截止日：1-2月实施 2026/11/24（周二）。8月实施的截止日没有读到（已过）。
- メンター的填写：在 Web 出願系统里填研究领域、主メンター和副メンター各 1 名（两人分属医学·人間生物学和理工情報学·物質科学两侧），都要事先取得同意；副メンター入学后才正式确定，入学后也可以更换。
- 出願书类：Web 录入的内容有证件照（JPEG，3 个月以内）、英文研究计划书（约 1,000 词）、英语成绩、学历·研究经历·职历。邮寄或窗口提交的原件有毕业（预计）证明书、外国大学毕业者的学位取得证明书、成绩证明书（读过大学院的还要交大学院的）、英语成绩单、在学或在职者的受験·就学承认书（样式不限）、国费留学生证明书（符合者）、需要退还原件时的申请书。中国的大学毕业者要交 CHSI 出具的英文认证报告。改过姓名的人附户籍抄本等。
- 推薦書：1 份，由毕业大学的学部长、专攻长、指导教员写（毕业已久的可以由现在的指导教员或上司写），用带抬头的 A4 或 Letter 纸并亲笔签名，由推荐人直接用書留邮寄或邮件附件寄给 SIGMA 事務室，须在书类截止日（1-2月实施为 2026/12/11）前到，缺了或有不备就不受理。
- 出願方式：在 Web 出願系统注册邮箱 → 录入信息、上传照片 → 支付检定料 → 点「出願」→ 打印受験票和收件人标签，把书类用書留寄到或送到 SIGMA 事務室。一个账号只能报一个学位プログラム，同一邮箱不能注册多个账号。
- 检定料 30,000 日元，信用卡或便利店支付，缴纳期间与出願期间相同（1-2月实施为 2026/11/30–12/10），缴纳后不退。国费外国人留学生不收。
- 入学料 282,000 日元（缴纳后不退）。授業料每学期 267,900 日元（年额 535,800 日元）；外国人留学生每学期 304,400 日元（年额 608,800 日元）。入学手续的说明在合格发表当天（1-2月实施为 2027/2/15）发到登记的邮箱，10月入学的人大约在 2027年6月下旬收到。外国籍的人要在入学手续前取得可以在大学院就读的在留资格。
