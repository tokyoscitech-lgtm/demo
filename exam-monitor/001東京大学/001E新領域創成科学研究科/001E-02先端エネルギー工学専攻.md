## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般選抜·外国人等特別選考：
  - 交 TOEFL iBT（含 Home Edition，不用 MyBest）或 TOEIC L&R 公开测试的官方成绩之一，専攻不另设英语笔试；出願时上传或 2026/7/30 前补交（已截止）。
  - TOEFL 向 ETS 送分（DI 代码 8001，Department 代码 99）并上传 Test Taker Score Report；TOEIC 上传 Official Score Certificate。TOEFL ITP、TOEIC IP 和 S&W、IELTS 不受理；须为 2024/9/1 以后受检。
- 特別口述試験：不要求英语成绩。
- ADB-JSP 特別選考：TOEFL iBT 或 IELTS 成绩单建议提交，不是必须。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 特別口述的研究计划可用日文或英文写；口述基础学力例题有日文版和英文版。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 専門科目（小論文） | 出願后向每位考生通知课题，在家写好按指定方式提交，不交即不合格；第2次口述时须备好答案原件或复印件 | |
| 学部成绩（GPA） | 按专攻规定方法计算，与小論文同时提交，不交即不合格 | |
| 外国语 | TOEFL／TOEIC 成绩，见英語要件 | |

- 一般選抜·外国人等特別選考：第1次按英语、GPA、小論文评价；第1次合格者参加第2次口述，第2次合格者参加研究室マッチング面接；重视理工系素养，综合判断。
- 特別口述試験：书类审查（GPA＋研究计划，A4 1页，日文或英文，写研究目的、方法、特色与独创之处）→ 特別口述；合格者免一般選抜的英语和小論文，落选者可直接参加一般選抜，不用重新出願。
- 核融合研究教育プログラム志望者与其他考生一起按成绩顺位判定。

### 口述試験 / 面接
- **官方形式**：日程A 特別口述試験：线上，发表修士研究计划并接受质疑；日程A 一般選抜·外国人等特別選考：线上口述三项——基础学力口述（数学〔线性代数、微积分〕和物理〔力学、电磁学、热力学〕，按履修科目出2–3个小问）、小論文口述、専門口述，第2次合格者另有线上研究室マッチング面接（考察研究意欲和适性）；ADB-JSP 特別選考：只审书类，无口述。
- **実際に聞かれた内容**：特別口述约30分钟、约5位教员，只问研究计划，重点追问技术可行性，没问志望动机（2024年夏，1人提到）。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：24名（日程A 一般選抜，含特別口述試験）；日程A 外国人等特別選考若干名；日程B 一般選抜·外国人等特別選考均不募集。
- 出願资格：大学毕业（含 2027/3/31 前预计）或外国16年学校教育等；外国人等特別選考须在外国或用日语以外语言接受高中和大学教育；特別口述試験限以本専攻为唯一第一志望、合格必入学者；研究科内只能报1个専攻；外国籍或有外国工作经历者须在出願前填专攻表单（本年度特別口述 5/4、一般選抜 5/20 前，非独立出願）；ADB-JSP 限 ADB 借款成员国国籍、申请时35岁以下、学士后2年以上相关全职工作经验、未持修士学位，并须承诺修了后回国工作2年以上。
- 要提前准备的书类：TOEFL iBT 或 TOEIC L&R 成绩；GPA、小論文、志望研究室票（出願后通知，提交期短）；特別口述另需研究计划；中国大学毕业者须交 CHSI 学历学位认证英文版；ADB-JSP 需指定申请表、Field of Study and Research Plan 和2封推荐信（推荐人直接发邮件给国际交流室）。
- 出願：日程A 只能通过研究科网上出願系统上传 PDF，检定料 30,000 日元（文部科学省奖学金留学生免缴）；ADB-JSP 书类 2026/12/10 前上传 Google 表单或寄达。
