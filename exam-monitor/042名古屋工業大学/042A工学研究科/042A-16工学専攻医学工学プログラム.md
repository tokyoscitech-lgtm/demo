## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般選抜·私費外国人留学生選抜：
  - 不另设英语笔试，用 TOEFL iBT 或 TOEIC L&R 成绩换算为外国語（英語）得分，满分 100 分；两种都交的取换算后较高者。
  - TOEFL iBT 经 ETS 直接送分（DI code 8549），用 Test Date 成绩，不用 MyBest；考试前一天之前申请送分免费。TOEIC L&R 交公式認定証原件，打印的デジタル公式認定証也可以。
  - 成绩须在书类截止（2026/7/17 16:00）前到达，否则按书类不备处理；只认出願期间前 2 年以内受检的成绩。
  - 不受理 TOEFL ITP、TOEIC IP 等团体特别受験成绩和 TOEIC Speaking & Writing。
  - 换算表两端：TOEIC 990＝TOEFL iBT 120＝100 分，TOEIC 10＝iBT 0＝0 分，中间各档按要项换算表；2026年1月起的 TOEFL 新分数（1–6）仍按旧 0–120 分换算。
  - 选「社会人口述試験」的社会人（现不在大学就读者）不交英语成绩，英语在口述中考查。
- 推薦選抜：不要求英语成绩。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 一般選抜的専門試験用日语出题，可用日语或英语作答（英文版要项）；私費外国人留学生選抜日英并记出题，可用日语或英语作答。日文·英文以外的书类须附日文或英文译文。
