## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 须提交 TOEFL iBT（含 Home Edition）的公式成绩，或者改交 TOEIC L&R 公开考试的“デジタル公式認定証”。専攻不另设英语笔试。
- 有效成绩：两种都只认 2024年9月以后受检的成绩。
- TOEFL 的提交期限是 2026/8/5（周三）。须完成三件事，缺一项就不受理：让 ETS 把公式成绩送到研究科（DI 代码 8596，Department 代码 99）；在 WEB 出願系统的マイページ登记 Appointment Number 和受检日；上传 Test Taker Score Report 的 PDF。采用 Test Date Scores，不用 MyBest scores；TOEFL ITP 不受理；英语母语者也要交。
- TOEIC 须在出願时（6/4 前）提交，不能事后补交；赶不上的只能改用 TOEFL iBT。只认在日本国内受检的公开考试，IP、Bridge、S&W 不受理；纸质认定证的扫描件不受理。
- 变更点：2026年度入试本専攻只收 TOEFL，2027年度起 TOEIC L&R 也可以（依据専攻汇总页和研究科要项）。
- 官方没有公布英语的配点和合格线。TOEFL 没按期交的人仍可参加其他科目，但外国語和専門科目必须全部应考，缺任何一科即失格。

### 日本語要件
- 要项和専攻入试案内都没有要求提交日语成绩。口述试验可用日语或英语。
- 専攻入试案内只有日文版，研究科要项页上没有本専攻的英文版入试案内；笔试题目是否附英文、可否用英文作答，官方未记载。
- 以英语授课为主的途径是另行招生的 G30 Architecture and Urban Design 课程，不属于本入试。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 専門課題Ⅰ（3小时，全员必考） | 建築学的基础性课题；题数和配点官方未记载 | 2027専攻入试案内 |
| 専門課題Ⅱ 第1群（4小时） | 建築設計課題（当场设计制图）；可带物品以専攻网站的清单为准 | 2027専攻入试案内 |
| 専門課題Ⅱ 第2群（3小时） | 建築計画·建築史·構法系课题 | 2027専攻入试案内 |
| 専門課題Ⅱ 第3群（3小时） | 建築環境系课题 | 2027専攻入试案内 |
| 専門課題Ⅱ 第4群（3小时） | 建築構造·建築材料系课题 | 2027専攻入试案内 |

- 専門課題Ⅱ 从4个群里选1个，出願时在 WEB 出願系统里选定。官方不指定哪个研究室对应哪个群，但 Q&A 建议选与志望教员专业相近的群。
- 研究科共通的一般教育科目（数学·物理学·化学）不适用于本専攻；特别口述试验也不适用于本専攻。
- 考试开始30分钟后不能入场。9/1、9/2 两天须在 8:35 前就座，8:40 开始说明。
- 各科配点、合格最低分官方都没有公布；本人成绩可在考后申请开示。
- 题目倾向（体验记，非官方）：専門課題Ⅰ为构造力学、环境工学、构法·材料、建築計画、建築史 5 个大题，范围广而浅，以背诵和基础计算为主，有人提前1小时做完；2025年8月那次环境改成了十几到二十个数值小题，計画是四选一小题约20个，建築史是看照片选关键词加写设计者。専門課題Ⅱ 多数人选第1群（当场设计），据说更看重计划的合理性。

### 口述試験 / 面接
- **官方形式**：每人数分钟的面接，使用日语或英语；不参加即失格。出願时上传的“別紙1（希望研究テーマ）”是面接的参考资料。面接按志望研究室分组进行，填了第二志望的人还要去第二志望的会场；想放弃第二志望面接的，须在第一志望组面接结束后到第二志望会场向监考人员说明。
- **実際に聞かれた内容**：体验记（非官方）称，约10名教员呈コ字形就座，时长从几分钟到10分钟左右，提问约5个；公开部分没有写出具体问题，按官方说明应围绕希望研究主题和选择该研究室的理由。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员 32 名。每位教员可接收的人数有上限。
- 出願资格：日本的大学毕业或 2027/3/31 前预计毕业、在外国完成16年学校教育、在外国取得相当于学士的学位（3年以上课程）等研究科要项(1)–(6)项之一；専攻不限专业和资格取得年次。第(6)项（个别入学资格审查）须事先受审，申请截止为 2026/4/21（已过）。
- 入学时期：一般为 2027年4月；2026年9月前毕业（见込）者可选 2026年10月入学。専攻强烈建议外国籍考生选 2027年4月入学，因为在留资格认定证明书的签发容易延迟。
- 出願全部在 WEB 出願系统完成，书类转成 PDF 上传：入学願書、证件照数据、检定料缴纳证明、卒業証明書（已毕业者）、成績証明書、安全保障輸出管理チェックシート（外国籍者等）。日文、英文以外的证明须附出身大学盖章的英译。
- 専攻独有的提交物：指導教員第一、第二、第三志望各1名（从専攻入试案内的一览里选，在系统里填写）；専門課題Ⅱ 的群；別紙1（希望研究テーマ，写研究内容和选择该研究室的理由，限1页）。别纸的 Word 模板在専攻汇总页下载。
- 检定料 30,000 日元（便利店、Pay-easy、网银、中国决济、信用卡；手续费自付），国费留学生免缴；缴纳后不退。
- 受験票 2026/7/3（周五）15:00 前后在マイページ交付，自行打印带到考场。
- 不能同时报考本研究科的两个以上専攻或课程。
- 外国人留学生及部分日本人学生入学前须通过安全保障出口管理审查，即使合格也可能不被许可入学或研究活动受限。
- 入学料 282,000 日元，授業料 年 535,800 日元（前期 267,900 日元），均为预定额；国费留学生不收。
- 咨询：専攻入试 exam@arch1.t.u-tokyo.ac.jp；留学生的入学·出願咨询 query-fas@arch1.t.u-tokyo.ac.jp；要项相关用研究科网站的咨询表单。

- 事前連絡要否：推荐。要项没有把事前联系列为出願条件，但専攻入试案内要求，志望带“留意事项”的教员（任期届满或预定退职）时必须事先咨询并确认指导方针；Q&A 也建议事先联系志望教员确认入学后的情况。说明会当天有集体相谈会和研究室个别访问。
