## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 8月入试和第2次募集都没有英语笔试，出願时提交 TOEFL iBT 或 TOEIC Listening & Reading 的成绩，换算成 100 分满分。
- 换算（TOEIC 和 2026/1/20 以前的 TOEFL iBT，两点之间线性插值，小数四舍五入）：TOEIC 225 以下＝0分、550＝50分、785 以上＝100分；TOEFL iBT 旧评分 17 以下＝0分、42＝50分、72 以上＝100分。例如 TOEIC 700 约为 82 分。
- 换算（2026/1/21 以后的 TOEFL iBT 新评分，按表取值）：2 以下＝0分、2.5＝25分、3＝50分、3.5＝75分、4 以上＝100分。
- 成绩有效期：8月入试为 2024/7/1 以后受检；第2次募集为 2024/10/1 以后受检。考过多次的只交自认为最有利的1份。
- TOEFL：只认 iBT（含 Home Edition、Special Home Edition），只用 Test Date Scores，不用 MyBest scores。必须同时在 ETS 账户里向理学研究科电子送分（Institution Code G112；8月入试 2026/7/9 截止，第2次募集 10/8 截止）并提交 Test Taker Score Report 或 Examinee Score Record 的 PDF 打印件；只交 PDF 不受理。
- TOEIC：提交数字版公式认定证（L&R）的 A4 打印件（黑白可）。纸质认定证、邮件发送 PDF 都不受理；TOEIC IP、TOEIC Bridge、Speaking & Writing 不受理。没有照片的成绩单不受理。
- 出願时来不及取得成绩的可以出願，但英语按 0 分计；出願后不能换成新的成绩单。
- 研究科共通规定里“数学専攻可用外部成绩免考英语笔试”只适用于数学専攻，不适用于本専攻。

### 日本語要件
- 要项没有要求提交日语成绩（JLPT、EJU 等）。试题语言和可用的作答语言，要项和専攻页都没有写。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|

- 8月入试的合否判定：综合物理笔试、口头试问、学业成绩证明书、英语成绩、研究分野等希望調書。先按笔试和英语成绩分コース判定谁有资格参加口头试问（可能只拿到其中一个コース的资格），最后连同配属研究グループ一起决定。除英语 100 分外，各项配点和合格线官方没有公布。
- 第2次募集的定位：専攻案内说明，第1次募集重视基础物理，第2次募集面向天文学、地球物理、地质、岩石矿物、生物、工学等各种背景的学生，看重对研究对象的兴趣和热情。
- 题目倾向（体验记，非官方，均为同一套试题的物理学専攻考生）：备考集中在力学、电磁学、量子力学、统计力学四个领域；有人提到统计力学单独成一道大问，2019年以后的题目初见能做到六七成；有外部考生估计约三四成的人在口头试问资格发表时被刷掉（仅1人提及）。

### 口述試験 / 面接
- **官方形式**：8月入试按志望的面接コース分别进行，第1希望コース在 2026/8/27、第2希望コース在 8/28；不能带资料，原则上口头回答，有时会被要求用黑板。専攻页列出的提问范围：志望动机和想做的研究等一般面试内容、测试物理学等科学能力的提问、与其他大学或其他専攻的并愿情况、研究グループ的志望顺序。缺席第2希望コース的口头试问不影响第1希望コース的合否，也可以只考其中一个コース。配点和每人时长官方没有公布。第2次募集：对全体受験者进行口头试问，每人约30分钟，结合希望配属的研究グループ提问；配点官方没有公布。
- **実際に聞かれた内容**：（体验记，非官方，物理学専攻考生）有人说只被问了研究兴趣、志望理由这类固定问题，第二、第三志望的教员问的也差不多；另有人说被问到说明会上预告过的一般物理学问题。没有找到宇宙地球科学専攻研究グループ和第2次募集口头试问的体验记。

## 📝 详细信息
### 出願資格 / 定員
- 8月入试（第1次募集）的募集人员为 28 名（物理学専攻另有 68 名，两専攻合同考试）。第2次募集为若干名。
- 出願资格：大学毕业或 2027/3/31 前预计毕业、学位授予机构授予学士、在外国完成 16 年学校教育、在外国取得相当于学士的学位（3年以上课程）等（1）–（10）项之一。
- 第2次募集的限制：2026年夏的宇宙地球科学専攻·物理学専攻合同入试（9/7 发表）的合格者不能出願。第1次募集的追试对象者可以把第2次募集的考试当作追试来考（不用再出願和缴检定料）；第2次募集本身没有追试。
- 按资格（9）（10）出願的须先受个别资格审查：8月入试 2026/6/12（周五）必达（已过）；第2次募集 2026/9/18（周五）必达（已过），结果 9/30 前通知。
- 面接コース和志望的填法（8月入试）：从 A1、A2、B1、B2、C1、C2 六个コース里选第1希望和第2希望两个コース，每个コース里给研究グループ排志望顺序（出願书类的用纸每コース有第1–第6志望栏，不想填的可以空着；物理学専攻的グループ也可以填）。願書的“志望専攻”栏按第1希望コース里第1志望グループ所属的専攻来写：属于本専攻的写“宇宙地球科学専攻（物理学専攻）”。无论考几个コース，最后只配属到一个研究グループ。専攻页上关于每コース可填グループ数的说明前后不一致，以订正后的出願书类为准。
- 第2次募集只能志望宇宙地球科学専攻的研究グループ，専攻页写最多填 3 个。
- 研究分野等希望調書还要写：选这两个コース的理由、大学4年级的学习和讨论班内容（指导教员名）、自学的内容、特别感兴趣的事、今后想做的事、毕业论文或毕业计划的题目和概要。可以手写楷书或直接在 Word 里录入。出願手续后不能更改记载事项。
- 出願书类：入学願書、学业成绩证明书、毕业（预定）证明书（须为带公章的日文或英文证明）、TOEFL 或 TOEIC 成绩证明、研究分野等希望調書、受験者写真票和受験票（照片纵4cm×横3cm，3个月内拍摄）、检定料收纳证明书（PDF 打印成 A4）、レターパックライト 2 枚（海外出願者不需要）、在留卡正反面复印件或住民票或护照复印件（外国人）、国费留学生证明书（仅国费生）、出願书类核对表。全部用 A4 白纸单面打印，用黑色墨水或黑色圆珠笔填写（可擦笔不可）。
