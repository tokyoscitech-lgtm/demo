## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 夏季入试：数学専攻不需要提交 TOEIC 等外部英语成绩，而是在笔试当天考専攻自己出的「英語」（2026/8/19 15:00–15:30，30分钟）。配点官方未公布。
- 研究科共通规定里的 TOEIC L&R 公開テスト成绩（笔试日前2年内有效、不收 IP、只能交1次）只适用于物理学、化学、生物学、惑星学4个専攻，不适用于数学専攻。
- 英語考试不能带词典。出题形式要项没有说明。
- 冬期追加募集：未公布（截至 2026-10-07）。

### 日本語要件
- 一般選抜：要项没有要求提交日语成绩。
- 外国人留学生特別選抜：必须提交「日语水平足以不妨碍修学」的证明书，要项举的例子是日本語能力試験的成绩证明书；没有规定具体等级或分数。
- 试题语言和可用的作答语言要项没有写明。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 数学Ⅰ（150分钟，配点官方未公布） | 要项只写科目名，没有写出题范围和题数 | 2027募集要项 |
| 数学Ⅱ（90分钟，配点官方未公布） | 要项只写科目名，没有写出题范围和题数 | 2027募集要项 |
| 英語（30分钟，配点官方未公布） | 要项只写科目名，没有写出题形式；不能带词典 | 2027募集要项 |
| 冬期追加募集 | 是否实施及科目均未公布（截至 2026-10-07） | 研究科入试信息 |

- 选拔方法：综合学力检查（笔试、口头试问）和成绩证明书决定合格者。选考分两步：第一次选考为笔试；第二次选考为面接。总分和合格线官方没有公布。
- 外国人留学生特別選抜的科目和时间与一般選抜相同（数学Ⅰ、数学Ⅱ、英語＋面接）。
- 题目倾向（第三方解答网站的归纳，非官方，仅1处来源）：2026年度（2025年8月实施）数学Ⅰ为3题，涉及线性代数（特征值与对角化）、代数（整数矩阵与商群）、微积分（重积分）；数学Ⅱ为4题，涉及代数（体的扩张、环）、位相几何、微分几何。数学Ⅱ是全答还是选答没有查到。

### 口述試験 / 面接
- **官方形式**：夏季入试在笔试次日（2026/8/20 9:30 起）进行面接，数学専攻对第一次选考的全体受験者都实施；要项把它作为学力检查中的口头试问，面接的内容、时长、配点和使用语言都没有写明（要项里“就毕业研究或研究计划做3分钟以内口头发表”的规定是别的専攻的，数学専攻没有这句）。冬期追加募集未公布。
- **実際に聞かれた内容**：没有找到数学専攻大学院入试的考生体验记，实际提问内容不明。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：夏季入试的一般選抜为22名，外国人留学生特別選抜为若干名。冬期追加募集的人数未公布（是否实施也未公布，截至 2026-10-07）。
- 一般選抜的出願资格共11项，满足其一即可：大学毕业或2027年3月31日前预计毕业、被授予学士学位、在外国完成16年学校教育、在外国取得相当于学士的学位（3年以上课程）、専修学校専門課程修了、经本研究科个别审查认定具有大学毕业同等以上学力且2027年3月31日前满22岁、大学在学3年以上且成绩优秀（跳级）等。
- 外国人留学生特別選抜的资格：持有在留资格「留学」的外国人（含预计2027年4月取得者），并满足大学毕业（含预计）、在外国完成16年课程、外国3年以上课程的学士相当学位、个别审查认定等之一。
- 需要个别出願资格审查的人，夏季入试的申请截止日是 2026/6/5（周五）（已过）。
- 出願方式：先在 Web 出願网站登记、上传证件照数据并缴纳检定料，再把纸质书类在书类提交期间内送达理学研究科教務学生係。邮寄用レターパックプラス或書留速達；窗口受理时间为 9:00–12:00、13:00–17:00。海外寄送的要求相同。
- 出願书类（一般選抜）：入学願書·履历书（从 Web 出願网站打印）、成绩证明书、毕业（预计）证明书（出身大学的学部长或校长出具）；住在日本的外国人另交住民票的复印件等。数学専攻不需要入学理由书（只有物理学専攻要），也不需要 TOEIC 受験情報確認票。
- 外国人留学生特別選抜另需：日语能力证明书、出身大学指导教员的推薦状（研究科所定样式）、国费外国人留学生证明书（仅该当者）。
- 外国学历的注意事项：中国的大学毕业者须办理中国高等教育学生信息网（CHSI）的认证，提交认证过的英文报告。日文、英文以外的证明书必须附上由日本或外国政府驻外机构等公的机关出具翻译证明的日文译文。
- 检定料 30,000 日元，在 Web 出願网站上支付，手续费由考生负担。已交的书类和检定料原则上不退还。
- 并愿限制：不能与同一天实施的理学研究科博士課程前期課程其他入试（10月入学的一般選抜·外国人留学生特別選抜等）同时报考。
- 受験票从 Web 出願网站的个人页面下载，彩色打印后考试当天带来。考场在神戸大学理学部学舎（神戸市灘区六甲台町1-1），考场和面接室当天贴在理学部Y棟1階的掲示板上。手表只能用仅有计时功能的；大学不介绍住宿。身体有障碍需要特别照顾的，要在出願2周前提出。
- 入学手续预定在2027年3月中旬，详情在2027年2月中旬左右通知。入学料 282,000 日元，授業料 年 535,800 日元（前期 267,900 日元，学费改定时适用新金额）。
- 成绩开示：要项规定的入试成绩开示（不合格者可邮寄申请）只面向化学専攻和生物学専攻，数学専攻不在对象内。
- 10月入学：2026年度10月入学的募集要项里数学専攻募集若干名，考试与4月入学同日（2026/8/19–8/20）。2027年度10月入学的要项未公布（截至 2026-10-07）。
- 数学専攻的第一次选考结果要项没有写单独发表，只写最终合格发表。
- 咨询：神戸大学大学院理学研究科教務学生係，〒657-8501 神戸市灘区六甲台町1-1，Tel 078-803-5767，sci-kyomu@office.kobe-u.ac.jp。数学専攻的说明会通知上另有専攻的电话 078-803-5608。

### 研究室 / 指導教員
- 事前連絡要否：不要。要项没有要求出願前联系教员。数学専攻在 Web 出願时不需要填写志望指导教员的姓名（化学、生物学、惑星学専攻才必须事先联系教员）。
- 神戸大学面向留学生的英文介绍页另写有“建议事先找好指导教员”，但该页内容是旧年度的，以本年度要项为准。
- 教员按3个講座分组（据数学専攻教员一览和講座介绍；本年度各教员是否接收学生官方没有记载）：
  - 解析数理講座：伊藤 健一 教授｜偏微分方程式论、Schrödinger 方程式
  - 解析数理講座：太田 泰広 教授｜非线性可积分系、应用数理
  - 解析数理講座：高岡 秀夫 教授｜非线性分散型方程式
  - 解析数理講座：本田 あおい 教授｜测度积分论、信息理论、机器学习
  - 解析数理講座：檜垣 充朗 准教授｜流体力学相关的偏微分方程式
  - 構造数理講座：佐治 健太郎 教授｜映射的奇点理论、微分几何学
  - 構造数理講座：佐藤 進 教授｜曲面纽结理论
  - 構造数理講座：谷口 隆 教授｜代数的整数论、ゼータ函数
  - 構造数理講座：吉岡 康太 教授｜向量丛的模空间
  - 構造数理講座：ラスマン ウェイン 教授｜平均曲率一定曲面
  - 構造数理講座：佐野 太郎 准教授｜代数簇、Fano 簇
  - 構造数理講座：森本 和輝 准教授｜保型 L 函数、表现论
  - 構造数理講座：和田 康載 准教授｜纽结理论
  - 応用数理講座：首藤 信通 教授｜数理统计、缺失数据分析
  - 応用数理講座：福山 克司 教授｜一样分布论、概率论
  - 応用数理講座：藤 博之 教授｜数理物理、矩阵模型
  - 応用数理講座：岩政 勇仁 准教授｜组合优化
  - 応用数理講座：村山 拓也 講師｜概率论、复分析
- 講座内的分组：解析数理分関数方程式（太田、本田、檜垣）和関数解析（伊藤、高岡）；構造数理分代数学（谷口、吉岡、佐野、森本）和幾何学（佐治、佐藤、ラスマン、和田）；応用数理分確率数理（福山、村山）和計算数理（首藤、藤、岩政）。
