## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各日程相同：不另设英语笔试，用 TOEFL iBT（含 Home Edition）成绩评价；所属团体实施的 ITP 不受理，MyBest Scores 不采用。
- 在有效期间内受检，并在同期间内向 ETS 申请把 Institutional (Official) Score Report 送到研究科（DI code 1113，其他代码无效）；出願时在 WEB 系统填写 Appointment Number、受检日和分数，不必交 Test Taker Score Report。送过多份的只指定其中一次。
- 有效期间：A日程 2024/8/1–2026/6/13；B日程 2025/2/1–2026/11/15（均已过）。
- 变更点：2026年度入试 A日程在研究科内考 TOEFL ITP，2027年度起 A、B 两日程都改为提交 TOEFL iBT 成绩。

#### 日本語要件
- 要项没有要求提交日语成绩。
- A日程専門科目日英并记出题，B日程英文出题；两个日程都可以用日语或英语作答。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 応用動物科学（必答） | 2026年度试题和出题意图：パートⅠ 2题必答——问1 生物·化学·数学基础知识（英文填空），问2 小论文（逻辑思考与文章构成）；パートⅡ 从免疫学、遗传学、动物细胞制御学、细胞生化学、兽医动物行为学 5 类中选 1 类，答该类问1（主要机制·解析方法与实验结果解释）和问2（专业术语·基础事项） | A日程 13:30–16:30，180分钟 |

- 由 TOEFL 成绩、専門科目、口述和书类综合选拔；成绩不足时可能录不满。
- WEB 出願时须在“専門科目”栏填「応用動物科学」，不填按书类不全处理。

### 口述試験 / 面接
- **官方形式**：A日程、B日程均线上进行，日时和连接方法由受験者心得通知。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：19名（A日程）；B日程若干名；A日程可选 2026年10月入学、B日程可选 2027年10月入学，其余为 2027年4月入学。
- 出願资格：大学毕业（含 2027/3/31 前预计）或外国 16 年学校教育等；个别入学资格审查 A日程 2026/5/7、B日程 2026/10/7 截止（非独立出願，已过）；同一日程只能报研究科一个専攻；入学时期出願时选定、之后不能改；志望按「教員並びに専門分野一覧」最多填到第3志望，第2、第3志望可填同一分野的其他教员。
- 要提前准备的书类：推荐书 1 份以上（请熟悉本人研究生活和研究内容的人写；出願时在 WEB 系统「その他」栏填推荐人姓名和邮箱，系统把上传链接发给推荐人，由推荐人上传 PDF）；TOEFL iBT 送分；日英以外的证明书附日译或英译。
- 出願：只能通过 WEB 出願系统上传 PDF；检定料 30,000 日元（银行汇款〔邮储除外〕、便利店、信用卡、Pay-easy；B日程缴纳期间 2026/10/5–11/25），日本政府奖学金留学生免缴。
- 并愿：同一日程只能报研究科的一个専攻。
- 咨询：専攻的问题问専攻主任·入试担当 田中 智 教授（Tel 03-5841-5472）或入试担当 片岡 直行 准教授（Tel 03-5841-5372）；出願手续问农学生命科学研究科教務課学生支援チーム大学院学生担当（〒113-8657 東京都文京区弥生1-1-1，Tel 03-5841-5010，daigakuin.a@gs.mail.u-tokyo.ac.jp）。
