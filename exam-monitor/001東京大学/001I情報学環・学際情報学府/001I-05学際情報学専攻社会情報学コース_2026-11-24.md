## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 不另设英语笔试，用外部成绩评价；TOEFL iBT（含 Home Edition）、TOEIC L&R、IELTS Academic（含 Computer Delivered）三选一，願書上只能勾选一种。
- 冬季：
  - 有效期：2025/1/1 以后到出願截止前受检。
  - TOEFL iBT：由 ETS 直送官方成绩（Institution Code 0440，Department Code 99），2027/1/5（周二）前到达；願書填 Appointment Number，以前寄过的也要重新申请，学府不回答是否收到的询问。
  - TOEIC L&R：上传 Official Score Certificate（数字版或扫描 PDF）。IELTS：上传 Test Report Form 扫描件，或由 IELTS 机构直送（1/5 前到达）。来不及随出願提交的，事先联系学府，2027/1/5（周二）正午前用邮件提交。
- 不受理：TOEFL ITP、TOEFL Test Taker Score Report、TOEIC S&W／Speaking／Writing／Bridge／IP、IELTS General Training。

#### 日本語要件
- 外国人（日本的大学毕业或预计毕业者除外）须提交「日本語学力証明書」，原则上用コース入试案内所附样式，由日语教员等就说、听、写、读四项评价；用其他样式时须写明四项评价及评价方法。
- 口述的问答用日语进行；夏季笔试用日语作答。出願书类和论文原则上用日文或英文。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 冬季：书类选考（无笔试） | 英语成绩＋研究计划书、自己推薦書、毕业论文（可交草稿）或同等研究论文（日文或英文）、成绩证明书、指導教員希望調査書 | |
| 夏季：専門科目 | 考查媒体、传播、社会信息方面的研究能力，以及法学、政治学、经济学、社会学、媒体·新闻研究、社会心理学等人文社会科学知识；用日语作答（已结束） | |

- 一次选考合格者进入二次选考（口述），最终结果与一次选考合并综合判定。
- 变更点：2027年度夏季起恢复一次选考的専門科目笔试，取消出願书类里的小论文（学府 2025/6/27 告知）；冬季仍不考笔试。

### 口述試験 / 面接
- **官方形式**：冬季：只有一次选考合格者参加，用线上会议系统远程进行（需带摄像头、能联网的电脑），先做7分钟以内的发表，再用日语问答，考查基础与专门学力、研究能力和研究计划；夏季：同样形式，可能就笔试専門科目提问，社会人特别选考枠另问社会经验和志望动机（已结束）。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：16名（夏季、冬季合计，夏季含社会人特别选考枠若干名；冬季不设特别选考枠），学際情報学専攻全体100名（含アジア情報社会コース13名），合格人数可能不足募集人员。
- 出願资格：大学毕业（含 2027/3/31 前预计）或外国16年学校教育等；资格(6)个别审查书类 2026/10/16 截止（已截止，非独立出願）；同一时期只能报学府一个コース，也不能同时报修士和博士。
- 要提前准备的书类：研究计划书（所定样式）；自己推薦書（所定样式，有信息学相关业绩的写上公开网址）；冬季另交毕业论文（可交草稿）或同等研究论文；英语成绩；日本語学力証明書（外国人）。本コース不需要推薦書。
- 出願：只能在指定网站填写和上传，12/4 12:00 前上传完成；检定料 30,000 日元（日本政府奖学金留学生免缴）。
