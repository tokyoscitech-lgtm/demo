## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 推薦入试、一般入试：不另设英语笔试，用外部 TOEIC 成绩评价，出願时随书类提交成绩复印件；社会人入试、外国人留学生入试不交。
  - 可用：TOEIC L&R 公开测试的公式认定证复印件（数字认定证 PDF 打印件也可）；对面实施的 TOEIC L&R IP 测试 score report 复印件。在线 IP 成绩不受理。
  - 只认 2024/4/1 以后受验的成绩；考过多次的交最高分一份，受理后不能更换；只收纸质复印件，不接受邮件或 URL 提交，误交原件不退还。
- 下一年度（2028年4月·2027年10月入学）：可用种类相同，只认 2025/4/1 以后受验的成绩；交不出成绩就不能出願。

#### 日本語要件
- 要项没有要求提交日语成绩。外国人留学生入试的面接及口头试问可用日语或英语；数理科学領域希望用英语考试的，须在出願受理开始日1周前邮件联系工学部入試担当（yu-kounyu@jm.kj.yamagata-u.ac.jp）。授课主要用日语进行。
- 日英以外语言的证明书须附日译或英译。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 数学（情報工学領域） | 微分积分、线性代数 | 10:00–11:30，90分钟 |
| 電気電子工学（電気電子工学領域） | 电磁学、电路 | 10:00–11:30，90分钟 |

- 試験領域由希望指导教员决定（对应关系见博士前期课程担当教员表），在入学願書上填写。
- 一般入试：外部英语（TOEIC）、笔试（数理科学領域为口述试验）、面接及口头试问、成绩证明书综合判定；推薦入试：面接及口头试问、TOEIC、成绩证明书、推荐书；社会人、外国人留学生入试：面接及口头试问＋书类审查。

### 口述試験 / 面接
- **官方形式**：推薦入试：面接及口头试问约20分钟，问毕业研究和入学后的研究计划，不能用电脑和资料（经许可可用黑板）；第1回一般入试：情報工学·電気電子工学領域面接及口头试问约10分钟，数理科学領域面接（志望动机、修了后出路）＋口述试验约20分钟，自带电脑和打印的PDF 3份、备份U盘，用HDMI投影仪，PDF以外的资料（动画、PowerPoint、预备幻灯片、笔记）不能用；社会人入试：约20分钟，数理科学問基础知识、研究计划和职务经验，情報工学当场从微分积分或线性代数、電気電子工学从电磁学或电路中选1个分野口头试问；外国人留学生入试：约30分钟，数理科学問基础知识和研究计划，情報工学問微分积分与线性代数，電気電子工学問电磁学与电路，都兼问毕业研究，日语或英语。
