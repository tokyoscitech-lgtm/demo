## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各轮次都不另设英语笔试，用外部成绩评分，配点 100分。
- 一般入試：只收在日本国内实施的 TOEIC L&R 公开テスト，2023/4/1 以后受验有效；2023/4/1–2024/8/24 受验的交 A4 打印的数字公式認定証，2024/8/25 以后受验的须在出願期间内从 TOEIC 申込サイト「大学・企業等へのスコア提出」提交（申请代码 00010407），期间内没提交的不受理出願。TOEIC-IP、日本国外实施的 TOEIC 不受理。
- 外国人留学生特別入試：TOEIC（规则同上）或 TOEFL iBT 均可；TOEFL 交带照片的 Test Taker Score Report 原件和 A4 复印件（或 PDF 版打印件），并让 ETS 把 Official Score Report 送到神戸大学（DI 代码 B071），ITP、Home Edition 不受理。
  - 第一期：TOEIC 2023/4/1 以后、TOEFL 2024/8/25 以后受验有效。
  - 第二期：TOEIC 2024/4/1 以后受验有效（2025/1/20 前受验的交数字公式認定証，2025/1/21 以后的从申込サイト提交），TOEFL 2025/1/21 以后受验有效。
- 推薦入試：出願资格要求 TOEIC L&R 公开テスト 600分以上。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 外国人留学生特別入試（第一期・第二期）可在調査シート上申请英文试题：本専攻申请者只拿到英文试题。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 専門科目(一) 数学（100分） | 线性代数、微积分、常微分方程、复变函数论、傅里叶解析 | 9:30–11:00，90分钟 |
| 専門科目(一) 電気回路・電子回路（60分） | 电路基础、交流复数计算、网络定理、互感与变压器、RLC 过渡现象；二极管与晶体管、整流电源、小信号等效电路与放大、负反馈与功率放大、运算放大器、数字电路（CMOS/TTL 等） | 11:30–12:30，60分钟 |
| 専門科目(二) 電子物理（180分） | 第一志望分野1–5指定：电磁气学（静电场、导体电介质、静磁场、电感、麦克斯韦方程）、量子物性工学（薛定谔方程、定态微扰、晶体结构与X射线衍射、一维晶格振动）、半导体器件工学（能带与费米统计、金属-半导体接合、pn接合、MIS结构） | 14:00–16:00，120分钟 |
| 専門科目(二) 電子情報（180分） | 第一志望分野6–10指定，4领域选3：论理回路（卡诺图化简、组合电路、触发器、计数器与寄存器）、信息通信工学（信息量与熵、信源/信道编码、调制、多址接入、OSI 与 TCP/IP）、数据结构与算法（用C语言描述，复杂度、递归、图与树、表栈队列堆、排序、搜索、图算法、字符串匹配、动态规划）、数据科学（线性回归、监督/无监督学习、概率模型与推断） | 14:00–16:00，120分钟 |

- 总分 440（専門科目(一) 160＋専門科目(二) 180＋英语 100），一般入試和外国人留学生特別入試（第一期・第二期）相同；笔试、口頭試問和成绩证明书综合判定，缺考指定科目或口頭試問的不进入选考。
- 除笔记用具外不能带任何物品（不能用计算器）。

### 口述試験 / 面接
- **官方形式**：一般入試・外国人留学生特別入試（第一期・第二期）在笔试后进行口頭試問，只判合否、不计分；推薦入試为口頭試問加书类审查（含 TOEIC 成绩），合格者的分野配属 2026/9/4 发表。

- 出願资格：大学毕业（含2027/3/31前预计）、外国16年学校教育或外国3年以上课程取得学士相当学位等；外国人留学生特別入試限持有或2027年4月前取得「留学」在留资格的外国人；短大・高专・专修学校等毕业者须先过个别资格审查（第二期 2026/11/25–11/27 17:00 必达，12/7 前通知，非独立出願）；只能报一个専攻，出願后不能改内容；神戸大学工学部毕业生和在籍者不能报本専攻外国人留学生特別入試（走一般入試）；推薦入試须 TOEIC L&R 600分以上。

- 咨询：神戸大学大学院工学研究科 学務課教務学生グループ（〒657-8501 神戸市灘区六甲台町1-1），eng-kyomugakusei@office.kobe-u.ac.jp，Tel 078-803-6350。
- 并愿：只能报一个専攻。
