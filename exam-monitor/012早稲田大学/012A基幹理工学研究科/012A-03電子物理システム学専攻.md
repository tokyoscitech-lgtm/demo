## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 7月入试没有英语笔试，英语外部考试成绩是出願资格的一部分，不达标不能出願。官方没有公布英语成绩是否换算进总分。
- 一般入试的门槛（三选一）：TOEIC L&R 550 以上；TOEFL iBT 57 以上（新计分方式为 3.5 以上）；IELTS Academic 5.5 以上。飛び級入试在基幹理工学研究科的门槛相同。問題一覧里本専攻没有另加英语要求。
- 成绩须为出願开始日（2026/5/25）前2年以内受检。
- 提交方式（沿用 2026-10-07 的核对结果）：TOEIC 国内受检者通过报名网站提交数字版公式认定证，国外受检者交原件；TOEFL 由 ETS 直送并附 Test Taker Score Report；IELTS 由考试机构直送并附 Test Report Form（可复印件）。
- 不受理的种类：TOEIC IP、TOEIC S&W、TOEIC Bridge；TOEFL iBT Home Edition、MyBest Scores、TOEFL ITP、PBT；IELTS Online、One Skill Retake、General Training。
- 直送用的机构代码未读取到，出願时须按要项原文操作。

### 日本語要件
- 要项没有要求提交 JLPT、EJU 等日语成绩。
- 笔试和面接原则上用日语进行；志願票须用日语在电脑上填写，各类证明书只收日文或英文。問題一覧的本専攻页没有写可用的作答语言。
- 用英语授课取得学位的 English-based Graduate Program 是另一套入试（另有英文要项），不在这份要项之内。

- 7月入试的専門科目就是以上三科，在同一场笔试里考。問題一覧的本専攻页没有写题数、必答还是选答、考试时长和能否用计算器；要项所载的笔试时间段是 10:00–13:00，本専攻实际用多少分钟官方资料里没有单独写明。
- 配点、总分和合否判定方法官方都没有公布；要项只写按笔试和面接（含口述試験）选拔。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：7月入试（一般入试）本専攻 45 名，这个数字包含推薦入试等其他入试的名额；9月入学和飛び級入试（仅4月入学）在基幹理工学研究科为若干名（要项的表在读取时列对应不清，45 名属于4月入学一栏是按表头顺序判断的）。本年度没有冬季募集。
- 出願资格（一般入试）：大学毕业或入学前一日之前预计毕业、取得学士学位、在外国完成16年学校教育、在外国取得3年以上课程的学士相当学位、文部科学大臣指定者、经个别入学资格审查认定且入学前满22岁者，六项之一；同时必须持有达标的英语外部考试成绩。
- 飛び級入试：出願时为4年制大学3年级在学（休学除外），2年级结束时修得毕业所需学分的二分之一以上且其中三分之二以上为最高评价、3年级结束时预计修得四分之三以上，并取得出願専攻和指导教员的许可。飛び級合格入学者拿不到学士学位。
- 只能报1个専攻。出願时要填写研究指導代码（1个字母＋2位数字），代码在本専攻的研究指導一览（Excel）里；要项对本専攻没有特别的填写规定（填3个志望的要求只针对情報理工・情報通信専攻）。同一教员兼任多个研究指導的主担当时，实际指导教员可能是副担当，出願前要向教员确认。
- 出願书类：志願票①②③（所定样式，A4 单面，电脑填写，日语）、毕业（预定）证明书或在学证明书原件、成绩证明书原件、英语成绩、チェックリスト；外国籍者加交护照复印件，在日本居住者加交在留卡正反面复印件；需要申请在留资格认定证明书的国外居住者加交申请书、経費支弁書、存款余额证明原件；飛び級者加交学部要项复印件和受験许可书。要项的书类清单里没有单独的研究计划书，研究相关内容写在志願票里，没有规定字数；但本専攻面接会问研究计划，要事先准备好口头说明。
- 中国大陆的大学毕业（预定）者不交学校开具的毕业证明，改为由 CSSD（学信网）把 Online Verification Report（英文）直接发送给大学。
- 出願方式：在线申请表登录＋检定料缴纳＋书类邮寄三步都要完成。书类国内用簡易書留，国外用 DHL 等，寄到「〒169-8555 東京都新宿区大久保3-4-1 西早稲田キャンパス51号館1階 早稲田大学理工センター入試・広報オフィス」。从国外出願可以先寄书类再缴费和登录。
- 检定料 30,000 日元，通过 e-shiharai.net 支付：日本国内居住者在便利店缴纳，国外居住者用信用卡。缴费时登记的邮箱必须和在线申请表的邮箱相同。最不发达国家等一部分国家的国籍者或居住者可以申请免除。
- 个别入学资格审查：须在出願书类提交开始日的1个月前联系理工センター入試・広報オフィス。
- 外国籍注意事项：国外居住者自行申请短期滞在签证来日应考，大学不做招聘人或保证人，拿不到签证缺考的不退检定料；入学手续完成后大学只代办「留学」的在留资格认定证明书。留学生的教育研究内容要接受安全保障出口管理审查，可能受限制。
- 入学金 300,000 日元（早稲田大学的在学・毕业・修了者免除）。2027年度入学者第1年度：春学期 授業料 495,500＋実験演習料 35,000＋学生健康増進互助会費 1,500，秋学期 授業料 495,500＋実験演習料 48,000＋互助会費 1,500；外校出身者第1年度合计 1,677,000 日元（含入学金）。这组金额是 2026-10-07 从情報理工・情報通信専攻的学费表读到的，実験演習料各専攻可能不同，本専攻的数额本次没有单独核对，以学费 PDF 为准。

- 其他路线：推薦入试（另有要项，与一般入试同为 2026年9月・2027年4月入学）、特別選考入试（社会人等，另有要项）。这些不是一般入试的要求。
- 咨询：早稲田大学理工センター入試・広報オフィス（西早稲田キャンパス51号館1階），fsegraduate@list.waseda.jp，Tel 03-5286-3808；受理时间要项没有写。専攻方面的联络处是電子物理システム学科連絡事務室，Tel 03-5286-3011。
