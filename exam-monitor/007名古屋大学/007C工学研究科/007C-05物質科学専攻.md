## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 8月入试（笔试免除者选拔、一般選抜）：
  - 不另设英语笔试，用 TOEFL iBT（含 Home Edition）或 TOEIC Listening & Reading 公开考试的成绩评价，成绩单贴在所定「スコアシート提出用紙」上随出願书类提交。笔试免除者选拔出願时也要交（要项只免除電気電子情報工学系3専攻，不适用于本専攻）。
  - TOEIC：只收公式认定证原件（Official Score Certificate）；不发行该证的国家交 Official Score Report 和 Certificate of Achievement 两份。不收 TOEIC IP。
  - TOEFL：须由 ETS 把 Institutional/Official Score Report 直送名古屋大学（Institution Code D377，Department Code 69 Engineering, other），并提交 Test Taker Score Report 复印件；两样有一样没在出願截止前到达就视为没交。只采用 Test Date Scores，不采用 MyBest。不收 TOEFL ITP。
  - 有效期：只认 2024/6/1 以后实施的考试。没交成绩也能出願和应考，但英语不予评价。配点、最低分和换算方法要项没有公布。
  - 没获得笔试免除而转入一般選抜的，可在 2026/7/29（周三）17:00 前重新提交成绩（TOEIC 限 5/31 以前实施、TOEFL 限 7/3 以前发行）（已截止）。
- 外国人留学生入试：
  - 本専攻不在“用外部成绩评价英语”的専攻之列，出願时不要求交 TOEFL/TOEIC；学力检查含学内语学考试（英语），科目、时间由専攻通知（2025年度留学生要项起同样如此）。

#### 日本語要件
- 8月入试（笔试免除者选拔、一般選抜）：要项没有要求提交日语成绩；笔试和口頭試問都用日语进行，不提供英语出题。
- 外国人留学生入试：
  - 须提交「日本語能力を証明するもの」：日语教员或相当人员出具的证明书（原件），或 JLPT、JPT 成绩（复印件即可）；没有规定最低等级。本学工学部毕业预定者和本研究科研究生免交。
  - 专门科目笔试题日文、英文并记；语学考试、口頭試問中可能检定日语能力。
