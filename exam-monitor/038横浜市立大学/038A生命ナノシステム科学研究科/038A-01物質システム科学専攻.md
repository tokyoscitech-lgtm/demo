## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 不设学内英语笔试，所有轮次都用外部英语资格成绩换算计分，出願时提交证明原件（一般選抜·外国人特別選抜·社会人特別選抜B；社会人特別選抜A 第1期不交）。
- 配点：第1期 200分（总分600分中）；第2期 100分（总分300分中）。
- 可用的考试：TOEIC（L&R、IP）、TOEFL（iBT、ITP）、IELTS（Academic Module）。持有多份成绩的要全部提交，按本校基准换算后取最高的一份。
- 换算：要项只给出一个基准点——TOEFL iBT 61＝TOEIC 600＝IELTS 5.0（各部分4.5以上）＝本校换算点，第1期为130分（满分200），第2期为65分（满分100）。完整换算表和最低分数线官方没有公布；英文 Application Guide 把这几个分数写成换算基准，没有写成出願门槛。
- 提交方式：TOEIC L&R 交带姓名·出生日期·照片的公式认定证（2023年4月以后的数字认定证打印带 QR 码的 PDF）；TOEFL iBT 在 ETS 账户里指定机构代码 0416 直送大学，同时交 Test Taker Score Report 打印件并写上直送申请日；TOEFL ITP 交 Score Report 原件；IELTS 把 Test Report Form 直送大学，同时交成绩单复印件并写上送付申请日。提交的证明不退还。
- TOEIC-IP 在线版可以用，但必须同时提交实施团体盖章的「受験状況に関する証明書」（证明在监考下受检），否则可能不予评价；マークシート版 IP 没有这个附加要求。本校在金沢八景キャンパス实施 TOEIC-IP（マークシート版），2026年为 6/13、8/8、11/7，受验费 6,000 日元。
- 成绩有效期：要项和英文 Application Guide 都没有写受检日期限制。
- 变更点：与 2026年度相比，选拔方法和英语配点没有查到变化。

### 日本語要件
- 要项没有要求提交 JLPT、EJU 等日语成绩，外国人特別選抜也没有日语门槛的规定。
- 専門科目的题目只用日文出，但可以用英文作答。志望理由书在英文 Application Guide 中可用日文或英文写；面接使用的语言要项没有规定。
- 在日本国内居住的外国籍考生使用日文要项，交在留卡正反面和护照照片页复印件；海外在住者使用英文 Application Guide，交护照复印件，并要提供一个日本国内联系人的地址用于收受験票和合格通知（日文要项写明原则上不受理以海外地址出願）。第2期出願者中，2027/4/1 以后没有「留学」在留资格的外国人要另交在留资格认定证明书交付申请书。

### 口述試験 / 面接
- **官方形式**：第1期面接100分，第2期面接200分，学内推薦为书类审查＋口述。评价内容为志望动机、对专门领域的适性和意欲、研究能力、发表能力的综合评价。社会人特別選抜A 的面接（第1期300分）要求说明在职单位的研究内容和入学后的研究计划，用口头试问考查研究能力；社会人特別選抜B 要求说明以往的研究内容和入学后的研究计划。面接时长、是否需要准备幻灯片、使用的语言，要项都没有记载。面接在所定集合时刻未到者不能受验。
