## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各轮次相同：不另设英语笔试，出願时提交外部英语成绩之一（出願截止日前2年以内受检）：TOEFL iBT、TOEFL iBT Home Edition、TOEFL ITP Plus for China Solution、revised TOEFL Paper-delivered Test、TOEIC L&R、IELTS Academic。
- TOEFL-ITP、TOEIC-IP 等团体考试成绩和 TOEIC S&W 不受理。
- 提交方式：TOEFL iBT 打印网上 PDF 成绩单并在 ETS 账户设定 DI code 8195；TOEIC L&R 打印数字公式认定证（在日本国外受检的可交寄给本人的原件）；IELTS 交寄给本人的原件；考试机构直送大学的不受理。
- 本校医学部保健衛生学科看護学専攻的应届毕业预定者可用学部3年级考的 TOEFL-ITP 成绩，不必另交。

#### 日本語要件
- 外国人留学生须提交出願截止日前2年以内受检的日本語能力試験（JLPT）結果通知原件，不限等级。
- 2026年度试题注明外国人留学生可以用英语作答。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 専門科目 | 志望分野1题＋志望以外分野任选1题，共2题，每题用1张答题纸 | 10:00–11:30，90分钟 |

- 出题分野：ヘルスサービスリサーチ看護学、公衆衛生看護学、成人看護学、精神保健看護学、小児・家族発達看護学、リプロダクティブヘルス看護学、在宅・緩和ケア看護学、国際看護開発学、看護管理・高齢社会看護学、災害・クリティカルケア看護学；第1次、第2次募集相同。
- 按笔试、面试和出願书类（含英语成绩）综合判定。
- 题目倾向（2026年度过去问·出題の意図）：各分野为论述题，考专业基础知识、对社会课题的理解和逻辑表达，如知情同意与アセント、麻醉分娩、护理DX、疫情后的灾害与感染应对。

### 口述試験 / 面接
- **官方形式**：第1次、第2次募集都在笔试当天下午面试，评价适性、意欲和沟通能力。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：19名（第1次·第2次合计，含社会人大学院コース若干名）；高度実践看護師コース从災害・クリティカルケア看護学志望者中最多3名（含在定员内）；本年度不招助産師教育コース。
- 出願资格：大学毕业（含2027年3月预计）或外国16年学校教育等；资格⑼–⒁须事先受出願资格审查（第2次募集 2026/10/6–10/8 申请，已截止）；外国学历者事先向入試課确认；只报一个志望分野；4月以后继续在职者须按社会人大学院コース出願。
- 要提前准备的书类：指导教员的出願许可（日期填进 Web 出願系统）；外部英语成绩原件；JLPT 結果通知原件（外国人留学生）；入学願書里约200字的「志望する研究内容」；外国学历者的履歴書（様式 C-2）；社会人大学院コース另交勤务单位承诺书（様式 C-1）、志願理由書（A4约1页）和学会发表·业务内容说明。
- 出願：先在 Web 出願系统登记、上传书类并缴检定料 36,000 日元（另收手续费），再把原件用書留速達寄到入試課，期限内必达；海外寄送须用可追踪方式。
- 咨询：教育推進部入試課湯島大学院入試グループ（〒113-8510 東京都文京区湯島1-5-45），Tel 03-5803-4924，nyu-grad-02.adm@tmd.ac.jp（原则上用邮件、由考生本人联系；官网另有问询表单）。
