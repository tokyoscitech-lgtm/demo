## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 7月入试（一般入试）：英语不在考场考，而是出願资格的一部分，必须提交达到下列分数的外部试验成绩：TOEIC L&R 550 以上、TOEFL iBT 57 以上（新评分为スコアバンド 3.5 以上）、IELTS Academic 5.5 以上，三者任一。本専攻没有另设更高的専攻别门槛。
- 成绩须为出願开始日（2026/5/25）往前2年以内受检。
- 提交方式：TOEIC 国内受检者在申请网站上提交分数并打印デジタル公式認定証 PDF，海外受检者交 Official Score Certificate 原件；TOEFL 由 ETS 直送并附 Test Taker Score Report；IELTS 由考试机构把成绩数据直送早稲田并附 Test Report Form。
- 不受理：TOEIC IP、TOEIC S&W、TOEIC Bridge、TOEFL ITP、TOEFL PBT、IELTS General Training，以及可在家受检的 TOEFL iBT Home Edition、Paper Edition、IELTS Online 等。
- 要项没有写英语成绩的配点或换算方法，官方只把它作为门槛。
- 飛び級入试：先進理工学研究科的门槛更高，为 TOEIC L&R 640、TOEFL iBT 68（スコアバンド 4.0）、IELTS Academic 6.0 以上（基幹、創造两个研究科与一般入试相同）。

### 日本語要件
- 要项没有要求提交 JLPT、EJU 等日语成绩。
- 出願书类规定用日语填写。笔试、发表和面接的使用语言官方资料没有写明。英语授课的学位项目是另一条路线（理工学術院英語プログラム），不在本要项内。

### 口述試験 / 面接
- **官方形式**：7月入试在笔试次日（2026/7/12）进行，内容是关于今后研究计划等的口述试验。每人先发表 5 分钟（含接线和准备的时间），之后接受面接提问。发表必须包含两部分：到目前为止的学业和研究内容（不要涉及有保密义务的内容）；志望本専攻的理由、希望做的研究和将来的展望。幻灯片最多 2 张（2 画面），要同时存成 PowerPoint 和 PDF 两种格式，文件名为「受験番号_ローマ字氏名」，放在 USB 存储器里带来；另外打印 5 份 A4 纸质版备用。投影仪、屏幕、指示笔和 Windows 电脑由大学准备；用非 Windows 环境做的文件要确认能在 Windows 上播放，避免非标准字体或把字体嵌入；含视频等没有把握时可自带有 RGB 模拟输出的电脑。配点、面接时长、面试官人数官方没有公布。
- **実際に聞かれた内容**：没有找到本専攻的体验记，暂无可写内容。
