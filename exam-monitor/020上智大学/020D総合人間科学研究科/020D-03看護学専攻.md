## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 学内设英語笔试（见筆記試験），不收外部英语成绩；考查准确阅读研究论文、把握论点并批判性检讨的英语能力（出题意图）。可带辞典和电子辞典。

#### 日本語要件
- 外国人须提交 JLPT N1 合格的「認定結果及び成績に関する証明書」或「合否結果通知書」原件（或经原本证明的复印件）；在日本的大学主要用日语授课取得（或预定取得）学位的人免交，在出願书类チェックリスト上注明。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 英語 | 看护研究论文阅读；可带辞典和电子辞典 | 9:30–10:30，60分钟 |
| 専門科目 | 出願时从基礎、成人、老年、小児、母性、在宅、地域、養護中选1科；考查希望研究分野的基础知识和对该分野现状课题的问题意识（出题意图） | 10:45–11:45，60分钟 |
| 小論文 | 精读课题文，多角度思考并有逻辑地表述见解，同时考查以人的存在与尊严为基础的看护职姿态（出题意图） | 13:00–14:00，60分钟 |

- 合否按出願书类、笔试和口述试验综合判定；9月入試和2月入試的科目相同，不设社会人入試。

### 口述試験 / 面接
- **官方形式**：9月入試、2月入試：笔试当天 14:15 起口述试验。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：9名（9月入試与2月入試合计）。
- 出願资格：大学毕业（含预计）或外国16年学校教育等，且须持有保健師、助産師、看護師之一的资格（含取得预定）；看护系短大毕业、有5年以上临床经验并符合规定条件之一的人，须在 Web 出願开始日2周前用邮件申请个别出願资格审查（非独立出願）；2月入試只受理出願时住在日本（短期滞在除外）的人，住在海外的人只能报9月入試。
- 要提前准备的书类：志望动机·研究兴趣论述（A4 1页40字×40行，不能手写；写希望指导教员名、志望动机约400字、想做的研究主题约800字）；看护相关资格执照复印件（缩印为A4）；外国人的 JLPT N1 成绩证明；在职入学者交所属长的受験承諾書；中国大学出身者须在截止前让 CHSI 把学位和成绩认证报告直送上智；2月入試的外国籍考生交在留卡正面复印件。
- 出願：先在 Web 出願系统登记、选定専門科目并缴检定料 35,000 日元（另加手续费 1,100 日元），再把书类用简易书留·速达邮寄（海外用 EMS 等国际快递，截止日必达），窗口不收。

### 研究室 / 指導教員
- 事前連絡要否：必须。要项要求志愿者必须参加入试说明会并与希望指导的教员（未定的与専攻主任）面谈；参加不了说明会的，须发邮件给看護学専攻（dp-nurse@sophia.ac.jp）申请事前面谈。
