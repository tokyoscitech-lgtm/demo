## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 第1回、第2回相同：不另设英语笔试，出願时必须提交 TOEIC L&R 公开测试、TOEFL iBT 或 IELTS 的成绩原件，按别表换算成 0–50 分计入合否判定。
- 换算：满分线 TOEIC 800、TOEFL iBT 90、IELTS 6.5，零分线 TOEIC 300、TOEFL iBT 30、IELTS 3.0，中间按直线比例计算，例如 TOEIC 600＝30分、TOEFL iBT 72＝35分；换算后为0分的没有出願资格，不交成绩的不受理出願。
- 有效期：口述试验日前2年以内受检（以受检日为准）；考过多种的只交换算分最高的1份。
- 提交：TOEIC 交公式认定证（2023年4月以后国内受检的交数字认定证打印件，背面写 URL；团体 IP、韩国 TOEIC 网页成绩不受理）；TOEFL iBT 须在出願期内经 ETS 电子送分到 DI code B212，并附 Test Taker Score Report 的 A4 打印件，邮寄原件不收；IELTS 交 Test Report Form 原件。

#### 日本語要件
- 要项没有要求提交日语成绩，外国人留学生也按一般选拔报考；口述试验会对母语不是日语的考生充分照顾。
- 入学願書、履歴書、志願理由説明書可以用日文或英文填写；日英以外的证明书须附日文译文。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 第1回·第2回：不设笔试 | 理科大学教养水平的知识；生命情報系考分子或个体·种层面的生物学专门基础，自然情報系考物理学、化学、数学、情報科学之一的专门基础，都放在口述试验里考查 |  |

- 合否判定：英语外部成绩换算分（50分）＋口述试验（面接），志願理由説明書作参考资料。
- 第1希望教员的接收人数满了时，可能按成绩分到第2希望教员。

### 口述試験 / 面接
- **官方形式**：第1回、第2回相同：口述试验（面接），在滝子（山の畑）キャンパス进行，考理科教养知识、志望系的专门基础知识和交流能力，并参照志願理由説明書；考试时住在国外、来日困难的人经研究科认可可以改为线上面接，须在出願前1–2个月向希望的指导教员邮件确认。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：35名（一般选拔，第1回和第2回合计，含外国人留学生）；变更点：2026年度为25名。
- 出願资格：大学毕业（含2027年3月预计）或外国16年学校教育等①–⑧；不符合的走⑨个别资格审查（第2回 2026/11/4–11/12 必达，非独立出願）；可以和理学研究科外国人研究生并愿；国外出願须由日本国内的代理人办理。
- 要提前准备的书类：英语外部成绩原件；志願理由説明書（兼自己推薦書，所定样式，日文或英文，有研究实绩的写上）；外国籍者交住民票（无个人番号），国外在住者交护照复印件。
- 出願：角形2号信封速达挂号邮寄到学生課理学研究科入試担当，期限内必达，不设窗口；检定料 30,410 日元（含速达邮费410日元），在银行窗口用所定振込依頼書汇款，ATM 和ゆうちょ銀行不可。

### 研究室 / 指導教員
- 事前連絡要否：必须。要项规定出願截止前必须联系第1、第2希望的指导教员，就研究内容充分面谈；用研究科网站「教員紹介」的邮箱联系，不用邮件时打电话给山の畑事務課（052-872-5802）；国外或远方考生可以申请网络会议面谈。
