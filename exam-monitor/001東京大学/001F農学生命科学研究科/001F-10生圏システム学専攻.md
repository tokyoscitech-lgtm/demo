## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各日程相同：不另设英语笔试，用 TOEFL iBT（含 Home Edition）成绩评价；B日程书类选考看出身大学成绩和 TOEFL 成绩。
- 须在有效期内受检并向 ETS 申请把 Institutional (Official) Score Report 送到研究科（DI code 1113）：A日程 2024/8/1–2026/6/13，B日程 2025/2/1–2026/11/15；出願时在 WEB 出願系统填写 Appointment Number、受检日和分数，送过多次也只指定一次。
- TOEFL ITP 不受理，MyBest Scores 不采用；要项里 B日程部分免交 TOEFL 的规定只适用于応用生命化学·応用生命工学専攻，不适用于本専攻。
- 变更点：2026年度还要上传 Test Taker Score Report，2027年度改为只填 Appointment Number、由 ETS 直送。

#### 日本語要件
- 要项没有要求提交日语成绩。
- A日程専門科目日英并记出题，可用日语或英语作答；B日程的志望理由书和口述都可用日语或英语。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| A日程：専門科目①専攻共通科目 | 生态学、进化学、统计学的基础与应用，3题选2，考试时选 | 13:30–16:30，180分钟（①②合计） |
| A日程：専門科目②生圏システム学 | 5题选1，考试时选 |  |

- ①②都必须作答；B日程不考笔试，书类选考不合格检定料也不退。
- 2026年度出题（出题意图）：生态学考生态系统服务、生态系统多样性、互补效应、外来种和种间相互作用；进化学考适应进化与中性进化、假说检验；统计学考费舍尔三原则、协方差与回归、置信区间；②分生物多样性（行列模型）、绿地创成（生态系统服务供给地与受益地）、森林管理（鹿密度）、水域保全（岩礁带状分布）、保全生态（乱获、生态陷阱）5个方向。

### 口述試験 / 面接
- **官方形式**：A日程 2026/8/7 对面进行，问志望动机、修学所需基础学力和适性、希望研究领域的基础能力，综合评价研究能力；B日程只限书类选考合格者，用事先准备的资料做 15 分钟发表（志望动机、毕业论文研究、入学后想做的研究，没写毕业论文的讲大学所学内容），再进行含专业内容的问答，评价专业视野与知识、逻辑思考、研究意欲和计划性，可用日语或英语。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：A日程（2026年10月入学＋2027年4月入学）25名；B日程（2027年4月入学＋2027年10月入学）若干名。
- 出願资格：大学毕业（含 2027/3/31 前预计）或外国 16 年学校教育等 6 项之一；个别入学资格审查 A日程 2026/5/7、B日程 2026/10/7 截止（非独立出願，均已过）；同一日程只能报本研究科一个専攻；入学时期在出願时选定，之后不能改；志望专门分野和教员最多填到第3志望；考试时在海外、B日程想4月入学的，要注意在留资格可能来不及。
- 要提前准备的书类：TOEFL 送分；B日程另交志望理由书（A4，英文约 1,500–2,000 words 或日文约 3,000–4,000 字，写志望动机和入学后想做的研究，多页加页码），出願期间内用邮件发到専攻邮箱，标题写「B日程出願：姓名」。
- 出願：只能通过 WEB 出願系统上传 PDF；检定料 30,000 日元（银行汇款、便利店、信用卡、Pay-easy，B日程缴纳期间 2026/10/5–11/25），日本政府奖学金留学生免缴。
- 并愿：同一日程只能报研究科的一个専攻；要项写两个日程都有资格时可以都报，A日程合格者能否再报 B日程本専攻没有写明。
- 咨询：専攻的问题问 橋本 禅 教授（Tel 03-5841-5472，ahash@g.ecc.u-tokyo.ac.jp）；出願手续问农学生命科学研究科教務課学生支援チーム大学院学生担当（〒113-8657 東京都文京区弥生1-1-1，Tel 03-5841-5010，daigakuin.a@gs.mail.u-tokyo.ac.jp）。
