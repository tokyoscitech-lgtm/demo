## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- Ⅰ期募集、Ⅱ期募集相同：不另设英语笔试，用外部成绩评价。出願时提交 TOEFL iBT 或 IELTS（Academic Module）由考试机构发出的成绩证明（可以交复印件），并在 Web 出願登録画面录入分数。
- 有效期：出願截止日往前 2 年以内受检、且能在出願期间内提交的成绩；Ⅱ期募集即 2024/11/20 以后受检的成绩。
- 不受理 TOEFL 的 MyBest Scores 和 IELTS 的 One Skill Retake。TOEIC 不在可用之列。TOEFL iBT Home Edition、IELTS Online 能否使用，要项没有写。
- 要项没有规定最低分，也没有写配点和换算方法。
- 交不出符合条件的英语成绩就没有出願资格，不能事后补交。

#### 日本語要件
- 要项没有要求提交日语成绩（JLPT、EJU 都没有提到），外国人考生也不用交日语证明；本研究科没有另设的外国人留学生特别选拔，外国人考生走同一个一般入试。
- 小論文试题日文、英文并记，可以用日文或英文作答。修士課程的课程用日语讲授（英文入试页写明 conducted in Japanese）。
- 出願书类用日文或英文书写；其他语言的证明书要附日文或英文译文，并经大使馆或公证处证明译文无误。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 小論文（配点官方未公布，90分钟） | 论述题，不考专门科目。要项注明有时需要大学1年级程度的生物学知识。公开的过去问每期2题、全部必答，主题是医学·医疗与社会的关系和研究者的素养（医疗技术进步带来的伦理问题、先进医疗的公平获得、AI 进入医疗现场的影响与误诊责任、研究不正、团队研究中的署名、研究的独创性）；2025年度実施的题目每题要求日文约200字或英文约100 words | 2027募集要项／过去问页 |
| 国外居住者（Ⅰ期·Ⅱ期） | 不到场考小論文，改为提交研究科指定的事先课题；具体做法在受験票公开后用邮件通知 | 2027募集要项 |

- 合否按筆記試験（小論文）、面接和志望動機等书类综合判定，从学问适性、研究遂行能力、志望动机的妥当性等多方面评价；各项比重按専攻特点设定，配点和合格线官方都没有公布。
- 「出題の意図」说明小論文看的是：能否从伦理、经济、法律、社会制度等多个角度理解医疗和研究上的问题，并有条理地写出自己的看法；不考细的专门知识。
- 题目倾向（体验记，非官方）：没有找到考生本人写的体验记，暂时没有官方资料以外可归纳的倾向。

### 口述試験 / 面接
- **官方形式**：Ⅰ期募集、Ⅱ期募集都有面接，与志望動機等书类一起综合评价，配点、时长、面试官人数和使用语言要项都没有写；集合时刻和地点通过受験票上的网址通知，过了集合时刻不能应考；国外居住者改为线上面接，详情在受験票公开后用邮件通知。
- **実際に聞かれた内容**：没有找到本専攻考生写的体验记，实际问了什么没有可靠来源。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：医科学専攻修士課程 20 名（2027年4月入学，Ⅰ期募集和Ⅱ期募集合计，要项没有按期拆分）。
- 出願资格（各轮次相同）：①大学毕业或 2027/3/31 前预计毕业；②由大学改革支援·学位授与机构取得学士学位；③在外国完成16年学校教育；④修完文部科学大臣指定的4年以上専修学校専門課程；⑤文部科学大臣指定者；⑥在大学就读3年以上、以优秀成绩修得所定单位者（到2027年3月底在学满3年，预计取得90单位以上，其中60单位以上前一年度前已取得最高评语）；⑦在外国大学完成3年以上课程并取得相当于学士的学位；⑧经认定具有与大学毕业同等以上学力、入学时满22岁者。専攻介绍页写明招收对象是齿学、兽医学以外的自然科学系以及人文·社会科学系的学部毕业生。
- 出願資格認定：资格⑥和⑧必须先申请认定（Ⅰ期 2026/4/13–4/17 已截止；Ⅱ期 2026/10/26–10/30）。把出願資格認定申請書（所定用纸）、履历书（学历从小学写起）、最终学历证明、申请理由书（写明研究经历与业绩、认为自己具有同等学力的理由）、最终学历学校的课程资料做成 PDF，用邮件发给大学院入試担当；不收费，约2周后用邮件通知结果。
- 希望指导教员：只能从 Web 出願登録画面「希望指導教員・講座」里列出的教员中选；出願前必须得到希望指导教授的许可；多位教员共同指导时写主指导教授。
- 出願书类（Ⅰ期、Ⅱ期各自都要交全套，Ⅰ期不合格再报Ⅱ期也不能省）：出願書類チェックリスト、入学志願者調書（Web 登録后下载打印）、入学志願者調書B、入学志願者履歴書、志望動機（所定用纸，可手写或用 Word 输入后打印，本人亲笔签名；没有规定字数）、出願確認書（请希望分野的研究科委員亲笔签名，可交签名后扫描往来的复印件）、学部（及大学院）成绩证明书、毕业（预定）证明书、志願者に関する報告書（由出身学部的指导教员等填写并密封）、TOEFL iBT 或 IELTS 成绩复印件；外国大学毕业证明上没写学位的另交学位取得证明，资格⑥另交在学证明。中国大陆的大学毕业者还要交「教育部学历证书电子注册备案表」英文版（提交时 Web 认证有效期还剩6个月以上）。
- 书类规定：证明书只收原件或经官方证明与原件相同的副本，不收普通复印件或电子证明书的打印件；A4 单面；所有签名必须手写，不接受电子签名（含指导教授的签名）。

- 检定料 35,000 日元，另付手续费，按 Web 出願时指定的方式支付。只有没有出願或重复缴纳时才退，须在出願期间最后一天起1周内申请。
