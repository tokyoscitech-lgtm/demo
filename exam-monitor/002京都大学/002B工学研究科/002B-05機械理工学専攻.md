## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 8月入试：英语用 TOEFL iBT 成绩计分，配点 120 分（总分 850 分），群自己不出英语题。只认 TOEFL iBT 的 Test Date Scores；Home Edition、TOEFL ITP 不受理；TOEIC、IELTS 不在受理范围内。
- 提交方式（8月入试）：①从 ETS 账户下载 Test Taker Score Report 打印后交到 Cクラスター事務区教務掛（機械工学群），2026/7/16（周四）17:00 必达（7/14 以前邮戳的書留速達可受理）；②同时向 ETS 指定 Institution Code B431 电子送分（不用填 Department Code），2026/7/27（周一）前送达。均已截止。専攻不回答“成绩是否已到”的查询。
- 有效范围：8月入试只认 2024/8/2 以后受检的成绩。交了多份的取最高分。2026/1/21 以后受检的（新的成绩刻度）按 0–120 的原始分计算。
- 没有提交成绩的，英语按 0 分处理。英语为母语的人可以交「英語を母国語とする旨の宣誓書」申请免交，须事先向教務掛确认。
- 2月入试（仅外国人留学生，上次的规定）：TOEFL iBT（Home Edition 除外），考试日前2年以内受检，配点 120 分（总分 600 分），Test Taker Score Report 复印件随専攻书类在 2026/1/29 17:00 前必达。
- 研究科共通规定里的 TOEIC 公式认定证機械工学群不受理，那是别的専攻的提交书类，不适用于本専攻。

### 日本語要件
- 要项没有要求提交日语成绩（JLPT 等）。试题语言和可用的作答语言，要项里没有写明；特別選考和2月入试的口头试问用什么语言也没有写。

- 8月入试一般選考总分 850：英语（TOEFL）120＋数学 180＋機械力学 150＋専門科目 400。特別選考总分同为 850：英语 120＋口头试问 730，免笔试。
- 合否判定（8月入试）：原则上总分 425 分以上为有资格者（会按试题难度调整），从有资格者中按成绩从高到低取合格者；有人辞退时从有资格者中递补。
- 2月入试（上次）：总分 600（英语 120＋専門科目 240＋口头试问 240），300 分以上为有资格者。
- 各科目的题数和必答/选答方式要项没有写明；考场不能用尺、圆规、词典、计算器。
- 题目倾向（体验记，非官方）：本次没有找到可核实的考生体验记，备考以専攻公开的近3年过去问为准。

### 口述試験 / 面接
- **官方形式**：8月入试一般選考没有口头试问和面试。特別選考（面向志望博士課程前後期連携教育プログラム 高度工学コース的人，免笔试）先在 2026/5/27 进行约 20 分钟的予備選考面接，结果邮寄通知，没通过的可以转考一般選考；通过者在 2026/8/3 14:30 起参加口头试问（730 分），先做研究计划发表，再就研究计划和专业知识接受提问。2月入试（仅外国人留学生，上次）的口头试问 240 分，问专业学识、志望理由和研究计划。使用语言要项没有写。
