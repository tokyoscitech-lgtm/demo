## 🎯 入試内容（考什么）

### 語学 / 英語要件
- A日程、B日程都须提交 TOEFL iBT（含 Home Edition）的官方成绩，研究科自己不出英语笔试。
- 送分方式：向 ETS 申请把 Institutional（Official）Score Report 送到 DI 代码 1113；不需要另交考生本人用的成绩单。出願时在 WEB 出願系统里填写 Appointment Number、受验日和分数；送过多次的只选填一次的成绩。
- 有效期：A日程为 2024/8/1–2026/6/13 之间受验（已过）；B日程为 2025/2/1–2026/11/15（周日）之间受验，考试和送分申请都要在这个期间内完成。
- 团体实施的 ITP 和 MyBest 分数不受理。
- 要项和専攻案内都没有写最低分、换算方法和配点。B日程的书类选考明确以成绩证明书和 TOEFL 分数为依据。
- 要项里提到的 B日程 TOEFL 部分免除只适用于応用生命化学·応用生命工学専攻，不适用于本専攻。

### 日本語要件
- 要项没有要求提交日语成绩。
- A日程的专门科目试题日英并记，可用日文或英文作答；B日程的口述试验可用英文或日文进行；志望理由书可用日文或英文写。
- 日文、英文以外的证明书要附日文或英文译文。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| A日程：专门科目①専攻共通科目（配点官方未公布；①②合计 180 分钟） | 生态学、进化学、统计学的基础与应用，共3题，选2题作答 | 2027専攻入试案内 |
| A日程：专门科目②生圏システム学（配点官方未公布；与①在同一时段内作答） | 共5题，选1题作答；案内没有写各题对应的领域 | 2027専攻入试案内 |
| B日程（冬入试）：没有笔试 | 书类选考（出身大学的成绩证明书＋TOEFL 分数），通过者参加口述试验 | 2027専攻入试案内 |

- A日程①②都必须作答，也就是一共答3题。官方没有公布总分构成和各项配点；合否按笔试、TOEFL 和口述综合判定。
- A日程的考试时间可能变更，会场和细节以受验者心得为准（A日程 7月上旬邮件发送）。
- 题目倾向（体验记，非官方）：没有找到本専攻的考生体验记，无法归纳。可以确认的只有官方公开的 2026年度 A日程试题（扫描件 PDF），建议直接对照做。

### 口述試験 / 面接
- **官方形式**：A日程在笔试次日对面进行，问志望动机、修学所需的基础学力和适性、希望研究领域的基础能力和资质，综合评价研究能力；时长和配点官方未公布。B日程（冬入试）只面向书类选考通过者：先用事先准备的资料做 15 分钟发表（志望动机、毕业论文研究、入学后想做的研究；没有毕业论文的讲在大学学过的内容），然后是包含专门领域内容的问答，评价对专门领域的整体视野和相关知识、逻辑思考力、研究意欲和计划性，可用英文或日文。B日程是对面还是线上，案内没有写，以 2027年1月上旬的受验者心得为准。
- **実際に聞かれた内容**：没有找到本専攻的口述体验记，暂无可归纳的内容。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：A日程 25 名，B日程若干名。成绩不够时可能录取不满。
- 出願资格：日本的大学毕业或 2027/3/31 前预计毕业；在外国完成16年学校教育；在外国经过评价的学校修完3年以上课程并取得相当于学士的学位；文部科学大臣指定者；由学位授与機構授予学士学位者；经个别入学资格审查认定且 2027/3/31 时满22岁者，共6项之一（均含预计者）。
- 志望填写：对照「教员及专门分野一览」，在願書里选专门分野和教员名，最多到第3志望；第2、第3志望可以选同一分野的其他教员，没有也可以不填。教员会因调动变更，出願前要看最新版一览。
- 出願书类：ア 入学願書（WEB 输入，上传3个月内的正面证件照）；イ 成绩证明书（带公章的原件扫成 PDF 上传）；ウ 毕业（预计）证明书（须写明学位名和授予日）；エ 检定料缴纳证明；オ 国费留学生证明书（只限对象者）；カ TOEFL 成绩；キ 専攻指定的书类。A日程交ア–カ，B日程交ア–キ。
- B日程的「キ」是志望理由书：写志望动机和入学后想做的研究，A4，英文约 1500–2000 词或日文约 3000–4000 字，多页要加页码；在出願期间内用邮件发到専攻的邮箱，标题写「B日程出願：姓名」。
- 出願方式：只能通过 WEB 出願系统（https://webentry.ofc.a.u-tokyo.ac.jp/）在出願期间内申请并上传书类，没有纸质出願。成绩证明书和毕业证明书的纸质原件在入学手续时提交，交不出可能取消合格。
- 检定料 30,000 日元，可用银行汇款（ゆうちょ不可）、便利店、信用卡、Pay-easy、网络银行支付，手续费自付；缴纳期间 A日程为 2026/4/13–6/23（已过），B日程为 2026/10/5–11/25。国费留学生不用缴。缴后不退，B日程书类选考不通过也不退。
- 并愿：同一日程内不能报本研究科的两个以上専攻。两个日程都报是否可以，要项写的是“専攻允许时可以”，本専攻案内没有明写，A日程合格者能否再报B日程也没有记载，需要向専攻确认。
- 10月入学：符合资格者 A日程可选 2026年10月入学，B日程可选 2027年10月入学，在 WEB 出願系统里选择，出願后不能改。
- 外国人须在入学前取得不妨碍入学的在留资格；考试时人在海外、B日程想4月入学的，要注意入境可能来不及。外国人留学生等入学前要接受安全保障出口管理审查，不符合规定的即使最终合格也可能不能入学或研究受限。
- 个别入学资格审查（资格6）和受验上的照顾申请：A日程 2026/5/7（周四）截止（已过），B日程 2026/10/7（周三）截止（已过）。
- 入学料 282,000 日元，授業料 年 535,800 日元（前期 267,900 日元），均为预定额；国费留学生免缴。
- 考试当天：受验票从 WEB 系统打印成 A4 带去。受验者心得 A日程在7月上旬、B日程在 2027年1月上旬用邮件发送；B日程到 2027/1/13 还没收到要联系教務課。可带物品等考场规则要项没有写，以受验者心得为准。
- 成绩开示：募集要项没有记载；研究科入试案内页写明可以申请得点开示，A日程在考后的 10/1–10/31、B日程在考后的 5/1–5/31 必达，用研究科的申请书。
- 咨询：専攻方面为 橋本 禅 教授，Tel 03-5841-5472，ahash@g.ecc.u-tokyo.ac.jp；研究科入试方面为 農学生命科学研究科 教務課 学生支援チーム 大学院学生担当（〒113-8657 東京都文京区弥生1-1-1），daigakuin.a@gs.mail.u-tokyo.ac.jp，Tel 03-5841-5010。官方建议出願前留足时间咨询。
