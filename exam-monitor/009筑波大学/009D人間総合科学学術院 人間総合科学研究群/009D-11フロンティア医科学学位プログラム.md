## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 8月实施和1-2月实施相同：「外国語」100分，不另设英语笔试，用外部成绩评价；英语成绩单是全员必交书类。
- 收 TOEIC L&R、TOEFL iBT（含 Home Edition）、IELTS Academic；不受理 TOEIC IP、TOEFL ITP、IELTS General、IELTS Academic 线上版、IELTS One Skill Retake。
- 换算：达到 TOEIC L&R 850、TOEFL iBT 96、IELTS 6.5 的按满分 100 分计；低于基准时的换算方法官方没有公布。
- 受检时期：8月实施须2024年7月以后；1-2月实施须2025年1月以后。
- 提交方式：TOEIC 在 Web 出願系统填デジタル公式認定証 URL 并打印提交（日本国内受检者必须用这种方式）；TOEFL 交 Test Taker Score Report 原件，没有纸质版的让 ETS 直送 Official Score Report（DI 代码 9995，Department 代码 99）并交 PDF 打印件；IELTS 把 Additional TRF 数据直送大学并交 Test Report Form 复印件。纸质件贴在 Web 出願系统下载的台纸上，书类截止日前必达；期限内没交的不受理出願或按缺考处理。
- 海外居住者特別選抜：英语非母语且大学不是全英语授课的人交 TOEFL、TOEIC 或 IELTS 成绩（入学前2年以内，可交复印件，没有最低分）。

#### 日本語要件
- 要项没有要求提交 JLPT、EJU 等日语成绩，一般入学試験也没有外国人留学生的另设区分。
- プログラム入学试验页写明考试语言可按希望选日语或英语；约一半课程用英语授课。海外居住者特別選抜全程英语。
