## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 10月实施·一般入学試験：
  - 科目「外国語」150分，不另设英语笔试，用 TOEIC L&R 或 TOEFL iBT（含 Home Edition）成绩评价。
  - 换算：TOEIC 879、TOEFL iBT 100 以上记满分150，低于基准的按分数换算，换算公式要项没有写。
  - 提交：成绩单原件贴在指定台纸上；在日本考 TOEIC 的交デジタル公式認定証打印件并在 Web 系统填 URL；TOEFL iBT 交 Test Taker Score Report 原件，2026年1月起纸质版废止，没有纸质版的须由 ETS 直送 Official Score Report（DI 代码 9995、Department 代码 99）并交 PDF 打印件。
  - 不受理：TOEIC IP、TOEFL ITP 等团体考试成绩。全学共通办法列有 IELTS Academic，但体育学的评分只写 TOEIC 和 TOEFL iBT 两种。
  - 成绩有效期要项没有写。
- 10月实施·社会人特別選抜、7月实施·推薦（一般·社会人）：没有外国語科目，不需要英语成绩。

#### 日本語要件
- 要项没有要求提交 JLPT、EJU 等日语成绩，也没有为外国人另设选拔区分，留学生与日本学生参加同一考试。
- 10月实施的専門科目规定用日语作答，试题全是日文；研究计划可用日文（约2,000字）或英文（约800词），個人調書可用日文或英文；口述使用的语言要项没有写。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 10月实施·一般入学試験：外国語（150分，无笔试） | 按 TOEIC L&R 或 TOEFL iBT 成绩换算 | 2027募集要项 |
| 10月实施·一般入学試験：専門科目（200分，90分钟） | 论述题。38个研究領域分 A、B、C 三群，每領域出1题（A群10题、B群11题、C群17题）；専門科目①从自己志望領域所在的群选1题，②③从另外两群各选1题，共答3题，日语作答 | 2027募集要项／过去问 |
| 10月实施·社会人特別選抜：専門科目（200分，90分钟） | 论述题，与一般入学試験同一时段；选题规则要项没有另写 | 2027募集要项 |

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：7月实施·推薦（一般）30名；7月实施·推薦（社会人特別選抜）5名；10月实施·一般入学試験 75名；10月实施·社会人特別選抜 10名（合计120名，2027年4月入学）；冬季不募集。
- 出願资格（各区分共通）：日本四年制大学毕业或入学前预计毕业、学位授与機構授予学士学位、在外国完成16年学校教育、在外国3年以上课程取得相当于学士的学位（须先向入試課确认）、经个别审查认定同等学力且满22岁者（须先申请审查）。
- 10月实施·社会人特別選抜：须已毕业（预计毕业不能报），要项对工作年数没有另设条件。
- 7月实施·推薦（一般）：校长或所属长推荐并确约入学，且学士课程学分中 A 以上占70%以上，或 A 以上占40%以上并有显著竞技或指导经历。
- 7月实施·推薦（社会人）：2名推荐人推荐并确约入学，且满足其一：2年以上工作经历并在体育·运动·健康方面有优秀业绩；职业体育等显著竞技经历；显著的运动指导业绩（国家队等监督·教练、JOC ナショナルコーチアカデミー修了或同等最高级指导资格）。
- 个别出願资格审查和资格咨询截止：7月实施 2026/5/20（周三）、10月实施 2026/8/25（周二）（均已过），邮件标题写「出願資格審査希望」发给体育芸術エリア支援室大学院教務。
- 志望指导教员：Web 出願系统选第1志望，第2志望可不填；填了的都要事先取得承诺。
- 出願书类：毕业（预计）证明书和成绩证明书、個人調書（按选拔区分用不同样式，日文或英文）、推薦書（推薦一般1份；推薦社会人2名推荐人各1份，均密封）、英语成绩单原件贴台纸（仅10月一般）、检定料缴纳证明、在学或在职者的受験·就学承认书、国费留学生证明书（符合者）。
- 研究计划：原则上直接在 Web 表单填写，日文约2,000字或英文约800词（含参考文献）；只有打不出所需符号时才用规定样式，不能超框或附纸。
- 出願方式：Web 出願系统注册 → 录入信息并上传证件照 → 选志望指导教员 → 支付检定料 → 点击「出願」（之后不能改）→ 打印受験票和收件人标签，书类用書留寄到体育芸術エリア支援室（截止日必达）或送到窗口。
- 检定料 30,000 日元，信用卡或便利店支付，缴纳后不退；国费外国人留学生免缴。
- 入学料 282,000 日元；授業料年额 535,800 日元，在留资格「留学」的外国人留学生年额 608,800 日元。外国籍考生办入学手续时须持有可就学的在留资格。
- 试场：筑波大学筑波キャンパス；建筑和可携带物品写在考试1周前掲載的「受験者心得」里。
- 入学后按「系列」编排课程：スポーツ文化・経営政策、健康・スポーツ教育、ヘルスフィットネス、アスレティックコンディショニング、コーチング、ナショナルリーディングコーチ養成；可申请长期履修制度。
- 咨询：考试相关找体育芸術エリア支援室体育学担当 tg-taiikugaku@un.tsukuba.ac.jp（标题写「受験に関する問い合わせ（志願者氏名）」）；出願资格审查找体育芸術エリア支援室大学院教務 taigeiin.admission@un.tsukuba.ac.jp；外国学历事先确认找入試課大学院入試 admission.grad@un.tsukuba.ac.jp。
