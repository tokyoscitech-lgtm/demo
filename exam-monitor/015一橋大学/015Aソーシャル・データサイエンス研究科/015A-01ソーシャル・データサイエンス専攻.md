## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 不另设英语笔试，出願时交 TOEFL iBT 或 IELTS（Academic Module）成绩，作为一次选考（书类审查）的材料；只认2024年9月以后实施的考试。
- 两样都要：①由实施机构直送一橋大学的正式成绩（TOEFL：DI Code 0436、Department Code 99；IELTS 寄研究科事務室）；②本人成绩单复印件或网页打印的 PDF，随出願书类上传。
- TOEFL 用 Test Date 成绩，不用 MyBest；Home Edition 可以，TOEFL ITP 不受理。
- 英语为母语者（交国籍证明）和毕业于全英语学士课程者（交课程证明）免交。

#### 日本語要件
- 一般選考：出願期间开始日（2026/7/27）同时满足“没有日本国籍也没有永住许可”和“在日本居住未满3年”的人，须交 JLPT N1（旧1级）的「日本語能力試験認定結果及び成績に関する証明書」；证明书发行至少约需2周。
- 外国人特別選考：对象条件相同（没有永住许可、在日未满3年），交 JLPT N1 或 N2 的上述证明书。
- 外国人特別選考笔试试题日英并记，口述可用英语或日语；一般選考口述用日语。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 統計学·情報学 | 統計学2题、情報学2题，4题选2题作答；知识要求学部2–3年级、运用能力要求学部3–4年级程度 | 10:30–12:30，120分钟 |
| 社会科学 | 経営学、経済学、法学、政治学各1题，选1题论述；知识为教养程度、论述能力要求学部3–4年级程度 | 14:30–15:30，60分钟 |

- 三阶段选拔：一次选考为书类审查（研究计划书、成绩证明、英语·日语证明），只在志愿者超过约180名时淘汰；二次选考为上表笔试，结合一次结果选拔；三次选考为口述，按二次和口述结果决定合否。
- FAQ 推荐教科书：統計学＝竹村彰通『現代数理統計学』、久保川達也『現代数理統計学の基礎』；情報学＝Guttag『Python言語によるプログラミングイントロダクション』、平井有三『はじめてのパターン認識』；経営学＝入山章栄『世界標準の経営理論』等；経済学＝アセモグル等『ミクロ経済学』『マクロ経済学』；法学＝宍戸常寿等『法学入門』等；政治学＝久米郁男等『政治学』等。
- 题目倾向（体验记，非官方）：统计学偏重定义和定理的理解与证明，経営学要求结合具体例子说明概念（仅1人提及）。

### 口述試験 / 面接
- **官方形式**：三次选考口述，国立キャンパス，一般選考每人约20分钟、用日语（外国人特別選考用英语或日语）；围绕研究计划书的问题意识和用数据解决该问题的理解提问；出願时上传的证明书原件当天提交。
- **実際に聞かれた内容**：（体验记，非官方）考官3名，围绕研究计划书逐点追问判断理由，全程细问研究主题。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：36名（一般選考、外国人特別選考、社会人特別選考、内部選考合计）。
- 出願资格：大学毕业（含2027年3月预计）或外国16年学校教育并取得学士学位等；外国人特別選考限无日本国籍者；需个别资格审查的人须在 2026/6/30 前提交材料（非独立出願）。
- 要提前准备的书类：研究计划书（研究科指定 Word 样式，直接转 PDF，不可扫描）、TOEFL iBT/IELTS 正式成绩直送、对象者的 JLPT 证明；中国的大学毕业者另交学信网（CHSI）学历和学位在线验证报告。
- 出願：只能通过一橋大学大学院 WEB 出願页面上传 PDF，并把入学志願票和缴费证明用邮件发给研究科，没有需要邮寄的书类；检定料 30,000 日元（海外只能用信用卡）。
