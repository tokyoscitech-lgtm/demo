## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 夏期、冬期一般入试和 IEMP 规定相同：
  - 不另设英语笔试，出願时上传外部成绩，配点100分；没交的英语按0分。
  - 原则上交 TOEFL iBT（含 Home Edition）的 Test Taker Score Report，也可改交 TOEIC L&R 公开考试的公式认定证或 IELTS Academic 的 Test Report Form；只能交1种，须为 2023/4/1 以后受检。
  - 全部换算成 TOEFL iBT 分数：TOEIC 按要项换算表，例如 600＝62、730＝79、865＝98、989 以上＝111（冬期要项的表还列出 TOEFL iBT 1–6 新分段的对应）；IELTS 按 ETS 的 TOEFL iBT·IELTS 对照表。
  - 不受理 TOEFL CBT、TOEFL ITP、TOEIC IP、TOEIC Bridge、IELTS General Training；ETS 直送大学的 Official Score Report 不能代替考生本人的成绩表。
  - 合格者在入学手续时交原件；用 TOEFL iBT、IELTS 或可在线核验的 TOEIC 数字公式认定证出願的不用再交。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 夏期、冬期一般入试：口头试问语言在出願时从日语、英语中选一种，出願后不能改；课题论文和书类用日语或英语，其他语言的书类附公的机关译文。IEMP 是英语授课项目。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 地球环境相关课题论文（出願时提交，计入口头试问400分的评价） | 夏期、冬期一般入试：按志望分野指定的题目写，正文 A4 4页以内（日语约5,000字，英语约2,000 words），开头写志望分野和姓名，参考文献不计 |  |
| 学士论文或研究报告（IEMP，出願时提交） | 没有或不是日英文的，改交英语 1,500 words 以内的研究概要 |  |

- 夏期、冬期一般入试没有笔试：总分500（英语100＋口头试问400，含出願书类），按分野判定，总分不到250分或口头试问不到200分不列入合格对象。
- IEMP：总分500（英语100＋面试400），合计不到300分或面试不到240分不合格。
- 冬期课题论文举例：環境史・環境人文論写环境史方向的修士研究计划书；環境調和型産業論概述水卫生问题并写自己的研究计划；社会基盤適応設計論论述风、雪对土木结构的影响和气候变化对现行设计法的影响；親環境フォトセラミック材料化学論从该分野 2014 年以后的论文中选3篇说明背景、成果和意义。

### 口述試験 / 面接
- **官方形式**：夏期、冬期一般入试：有，每人约35分钟，400分（含出願书类），问地球环境知识、志望分野知识（社会人特别选拔改为基于实务实绩的内容）、入学后的研究与学习计划、アドミッション・ポリシー要求的资质能力，用出願时选定的日语或英语，在吉田キャンパス総合研究5号館进行、海外考生线上，时刻另行邮件通知（冬期 2027/1/26）；IEMP：全部 Zoom 线上，每人约35分钟，面试（含出願书类）400分，内容同上，时刻邮件通知且不能更改，面试过程录像。
- 冬期「志望分野知识」出题范围：地球益経済論 环境政策与经济；環境史・環境人文論 环境史与环境人文学；環境教育論 可持续发展教育、社区韧性、低碳循环社会等；環境調和型産業論 环境工学；社会基盤親和技術論 地盘环境工学为主的社会基盘工学；生物材料化学論 环境计测与生物材料科学；社会基盤適応設計論 风雪等气象作用对土木结构设计的影响；親環境フォトセラミック材料化学論 基础数学、物理化学、无机化学；生産環境微生物学論 微生物分类、系统、遗传、生理和生物间相互作用；生態系連環論 森林、里地、沿岸河口生态系统及其连环。
