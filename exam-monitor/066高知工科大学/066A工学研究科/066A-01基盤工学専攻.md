## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各轮次相同：不另设英语笔试，也不要求提交英语成绩。
- 研究概要可用英文或日文写。

#### 日本語要件
- 一般选拔·社会人特别选拔·长期履修：要项没有要求提交日语成绩。
- 外国人留学生特别选拔：入学选拔不要求日语成绩；修士课程用日语授课，办理在留资格时须提交 CEFR B2 以上的日语能力证明。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 知能機械・航空宇宙工学コース 面接（300分）＋提出書類（100分） | 口头试问：機械工学、航空工学 | 30分钟 |
| 電子・光工学コース 面接（300分）＋提出書類（100分） | 口头试问：電磁気学、回路学 | 30分钟 |
| 建築・都市デザインコース 面接（300分）＋提出書類（100分） | 口头试问：土木工学、建築学 | 30分钟 |
| 理工学コース 面接（300分）＋提出書類（100分） | 口头试问：応用物理、機能化学、生命情報中的任一专门分野 | 30分钟 |
| 情報学コース 面接·提出書類（合计400分） | 口头试问：数学（微分积分、线性代数）和信息科学·信息工学 | 30分钟 |
| デジタルイノベーションコース 面接·提出書類（合计400分） | 以志望动机、挑战意欲、研究计划，以及对数据科学、经营学、地域科学中某一分野的关心与理解为中心提问 | 30分钟 |

- 没有笔试：一般选拔、社会人特别选拔、长期履修都按面接（含口头试问）和提出书类综合判定，社会人另看经历书。
- 本校学士课程直升者无论是否免试都须出願。

### 口述試験 / 面接
- **官方形式**：Ⅰ期·Ⅱ期：各コース面接约30分钟（含口头试问），在香美キャンパス实施，入室时间迟到不能受验，范围和配点见上表；外国人留学生特别选拔：书类审查后原则上在线个别面接约30分钟，评价专门学力、沟通能力和研究概要，书类审查可能直接不合格。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：入学定员150名，一般选拔Ⅰ期130名、Ⅱ期20名（均含其他选拔区分），社会人特别选拔、长期履修、外国人留学生特别选拔各若干名；本年度招生的是知能機械・航空宇宙工学、電子・光工学、建築・都市デザイン、理工学、情報学、デジタルイノベーション6コース，起業マネジメント、高度教育実践コース停招。
- 出願资格：大学毕业（含2027/3/31前预计）或外国16年学校教育等；资格⑨（飞级）⑩（个别审查，2027/3/31前满22岁）须事先审查，Ⅰ期 2026/4/17、Ⅱ期 9/11 必达（非独立出願）；社会人特别选拔要求在职或毕业后2年以上实务经验；外国人留学生特别选拔限非日本国籍、持有或入学时取得「留学」在留资格者。
- 要提前准备的书类：自我推荐书（自笔）、研究概要（迄今研究或入学后研究计划，英文或日文，A4约1页，右上写姓名）；社会人另交经历书，长期履修另交经指导预定教员签名的长期履修计划书。
- 出願：网上出願登记并缴检定料15,000日元后，书类用书留速达寄入试课，截止日17:00必达；外国人留学生特别选拔检定料同为15,000日元，书类寄国际交流课。
- 并愿：2027年度春季入学募集要项没有关于跨コース或跨选拔区分并愿、同年度再报考的规定。
- 咨询：一般选拔·社会人·长期履修：高知工科大学入试课（〒782-8502 高知県香美市土佐山田町宮ノ口185），Tel 0887-57-2222，query@ml.kochi-tech.ac.jp；外国人留学生特别选拔：国际交流课，Tel +81-887-53-1130，international@ml.kochi-tech.ac.jp。

### 研究室 / 指導教員
- 事前連絡要否：必须。要项要求出願前与指导希望教员协议能否接收，没有协议就出願的会由入试课（留学生为国际交流课）联系确认；指导教员原则上限工学研究科的教授·准教授·讲师（含特任），入学后2年内退休的教员不能选。
- 本年度招生的6コース（各コース教员见コースHP）：

  - 電子・光工学コース：牧野 久雄 教授（コース长）｜电磁学、电路、半导体、薄膜工学、光电子｜[コースHP](http://www.ele.kochi-tech.ac.jp/)
  - 建築・都市デザインコース：大内 雅博 教授（コース长）｜土木工学、建筑学、混凝土工学、城市设计｜[コースHP](http://www.infra.kochi-tech.ac.jp/)
  - 理工学コース：西脇 永敏 教授（コース长）｜应用物理、功能化学、有机合成、生命信息｜[コースHP](http://www.scsci.kochi-tech.ac.jp/graduate_school.html)

  - デジタルイノベーションコース：古澤 浩 教授（コース长）｜数据科学、经营学、地域科学、统计物理｜[教员页](https://www.kochi-tech.ac.jp/profile/ja/frusawa-hiroshi.html)
