## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 须提交 TOEFL iBT（含 TOEFL iBT Home Edition）的公式成绩，没有专攻自己的英语笔试。TOEIC、IELTS 本専攻不收（募集要项里有关 TOEIC·IELTS 的规定不适用于本専攻）。
- 送达截止：2026/8/12（周三）前到达工学系研究科（已截止）。须同时完成三件事：通过 ETS 向 DI 代码 8596、Department 代码 99 送分；在 WEB 出願系统的マイページ登记 Appointment Number 和受检日；上传 Test Taker Score Report 的 PDF。
- 采用 Test Date Scores，不采用 MyBest scores。有效期：受检日在 2024年9月以后。TOEFL ITP 等团体受检的成绩不受理，考场也不实施 ITP。母语是英语的人也要提交。
- 官方没有公布最低分、配点和换算方法。
- 考多次的可以都送分，只有マイページ登记的那一次被采用；截止前可以反复修改登记。

### 日本語要件
- 募集要项和専攻入试案内都没有要求提交日语成绩（JLPT 等）。
- 専攻网站公开了専門科目试题的英文版（2026年度），数学试题也有英文版；作答语言官方没有明文规定。専攻说明会和 Q&A 只有日语版。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 専門科目·航空宇宙工学（配点官方未公布，180分钟） | 4科中任选3科作答：流体力学（流体力学、高速空气力学）／固体力学（材料力学、结构力学）／航空宇宙システム学（飞行力学、控制）／推進工学（机械力学、热力学、电磁学） | 2027専攻入试案内 |
| 一般教育科目·数学（配点官方未公布，150分钟） | 研究科共通题，6题中任选3题：微积分与微分方程；级数·傅里叶分析·积分变换；向量·矩阵·特征值；曲线·曲面；复变函数；概率统计·信息数学等 | 2027専攻入试案内／修士募集要项别纸 |

- 合否按 TOEFL 成绩、数学、専門科目、口述和提交书类综合判定；原则上包括口述在内的全部科目都必须参加。各部分的配点和合格线官方没有公布。没有书类选考（第一阶段筛选）。
- 可带物品：打印的受験票、黑色铅笔或自动铅笔、橡皮、卷笔刀（桌上式不行）、笔芯、只有计时功能的手表；圆珠笔不能带。
- 考场：研究科在 2026/8/28（周五）10:00 前公布；専門科目和口述的考场同一时间在工学部7号館大厅和専攻网站公布。
- 题目倾向（体验记，非官方）：各科都会出难题，完全放弃某一科风险大，不少人4科都准备、当天挑3科。流体常考支配方程的推导变形，含不可压和可压；固体的材料力学计算量大，结构力学是薄壁加强结构；推進的热力学常结合喷气发动机，机械力学以振动为主；システム学覆盖古典·现代控制和飞行力学，偶尔出轨道力学。旧年度曾分上午·下午两场，官方公开的 2025、2026年度试题已是单场。

### 口述試験 / 面接
- **官方形式**：2026/9/1（周二）进行，内容是入学后想研究的领域和本科毕业论文相关事项。各人的时间在考试期间公布。配点、时长、面试官人数、使用语言官方没有公布。
- **実際に聞かれた内容**：（体验记，非官方）面试官 2–3 名，气氛温和。被问到的有：毕业研究的内容和进展、志望航空宇宙的理由、进大学院后想做什么研究、今年笔试的感受、専門科目没选哪一科及原因。考生普遍认为笔试对合否影响更大，但缺考口述就不合格。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：修士課程 37 名（出願日程A，4月入学和10月入学合计）。本年度没有冬入试。
- 出願资格：日本的大学毕业或 2027/3/31 前预计毕业；在外国完成16年学校教育；在外国取得相当于学士的学位（3年以上课程）；文部科学大臣指定者；学位授与機構授予学士者；个别入学资格审查合格且满22岁者，共6项之一。2026年10月入学者把期限读作 2026/9/30。
- 个别入学资格审查（资格6）的书类截止为 2026/4/21（周二）（已截止）。
- 指导教员的填写规则：一般的4月入学日本人考生出願时不填志望教员，合格后 9 月做希望调查（Google Forms），11 月底前决定。日本国籍以外的考生要交「指導教員希望調査書」（指定样式）。日本人10月入学希望者要交「指導教員希望調査票」，最多填5个志望，在出願期间（2026/5/29–6/4）用邮件发给専攻事務室。
- 10月入学：本専攻可以选 2026年10月入学，但出願后不能在4月和10月之间更改，而且只有名单上的17位教员可以接收（见下节）。
- 出願书类：入学願書（WEB 输入）、证件照数据、检定料缴纳证明、毕业证明书（已毕业者，東大工学部毕业者除外）、成绩证明书（東大工学部毕业·预计毕业者除外）、安全保障出口管理チェックシート（外国籍、双重国籍、入学前所属为海外机构者）、国费留学生证明（该当者）。全部做成 PDF 上传。日语·英语以外的证明要附出身大学盖章的英译。
- 出願方式：只能通过 WEB 出願系统，不收纸质邮寄。受験票 2026/7/3（周五）15:00 左右在マイページ交付，自己打印带去考场。
- 检定料 30,000 日元，可用便利店、Pay-easy、网银、中国决济或信用卡支付，手续费自付，任何情况不退。国费留学生免缴。
- 并愿限制：不能同时报工学系研究科的两个以上専攻或课程。
- 外国籍考生：入学手续前要有不妨碍入学的在留资格；新申请在留资格通常要 2–3 个月，要项建议这类考生考虑4月入学。受安全保障出口管理审查，即使合格也可能不被许可入学，或者不能配属到希望的教员。
- 入学料 282,000 日元，授業料 年 535,800 日元（前期 267,900 日元），都是预定额；国费留学生不收。4月入学者的入学手续截止预定为 2027/3/9（周二）。
- 在职入学的社会人，入学手续时要交单位出具的同意书。
- 成绩开示：専攻在 2026/9/10 公布了笔试分数开示的手续（要填「大学院入試情報開示申請書」），对象和受理期间以専攻网站上的手续说明为准。
- 咨询：募集要项的问题用研究科网站的问询表单（工学系研究科学務課大学院チーム）；専攻的问题找航空宇宙工学専攻事務室（工学部7号館，Tel 03-5841-6610，koku@office-aero.t.u-tokyo.ac.jp）。
