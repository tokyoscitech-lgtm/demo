## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 一般选考（第1期·第2期）：英语由研究科自己出题笔试，外国语（英语）60分钟。100分配点和阅读、书写学术论文的考查目的为2026年度官方判定方法与出题目的；2027年度要项未单列配点。
- 不要求提交 TOEFL/TOEIC 等外部英语成绩；2027年度全学留学生选拔要项中工学研究科也不在要求外部英语成绩的研究科之列。
- 社会人特别选拔和2027年度外国人留学生入试只考口述试验，没有专业或英语笔试。
- 过去问：令和7·8年度各期的英语问题和解答都在官网公开。

- 当前2027英语授课 International Engineering Program 只列土木・建筑・机械3专攻；本专攻不在该项目名单，不可套用其全英语教学或免日语说明。

### 日本語要件
- 一般选考要项没有要求提交日语成绩。
- 外国人留学生入试：2027年度留学生选拔要项对工学研究科没有要求提交日语能力考试或日本留学考试的成绩，只采用本校考试；须提交经受入指导教员确认的研究计划书。
- 专业过去问以日语写成；要项未统一明确可用的其他作答语言，因此不能据此认定所有专攻均可用英文作答。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 専門科目（120分钟；200分为2026年度参考） | コンピュータアーキテクチャ、データ構造とアルゴリズム、情報数学、オペレーティングシステム 4科目中选3科目作答 | 2027募集要项／令和8年度合否判定方法一览 |
| 外国語・英語（60分钟；100分为2026年度参考） | 英语学术论文的阅读与书写能力 | 2027募集要项／令和8年度出题意图 |

- 一般选考综合专业知识、英语笔试及口述评价判定。2026年度参考标准是笔试合计300分（专业200＋英语100）与口述3阶段评价；2027年度要项没有单列配点和合格线。
- 可带电池式或太阳能关数电卓（不得有电子辞典或编程功能）；除计时以外带其他功能的手表不能带。
- 题目倾向（据官方公开过去问归纳）：令和8年度第1期——计算机体系结构5大题（逻辑电路真值表、2的补数加法、流水线性能、磁盘访问时间、术语填空）；数据结构与算法2大题（二叉搜索树的探索次数、归并排序的递归过程）；信息数学2大题（剩余类集合运算、矩阵逆·特征值·特征向量·正交矩阵，须写过程）；操作系统3大题（时间片轮转甘特图与平均等待时间、进程状态与CPU利用率、LRU页面置换与物理地址）。基本属本科教科书水平的计算题。

### 口述試験 / 面接
- **官方形式**：一般及社会人是試問及び面接，按专攻实施，13:30起；留学生仅口述，2026/11/13在工学部校舍实施。2027年度要项没有统一写明每人时长、面试人数或单项配点。参考2026年度官方出题目的，围绕既往研究内容及入学后研究计划问答，考查研究理解与研究素养。
- **実際に聞かれた内容**：用日文和中文检索都没有找到本専攻的合格体验记，没有可参考的先例。

## 📝 详细信息
### 出願資格 / 定員
- 博士前期课程的入学定员为25名（全部入试合计，要项未分期写人数）；社会人特别选拔为若干名，留学生要项未单列本专攻人数。
- 出願资格（一般选考）：大学毕业或2027年3月前预计毕业、取得学士学位、在外国或通过指定教育设施完成16年课程等；22岁以上或大学在学3年以上成绩优秀者须经个别审查。
- 个别资格审查：须用邮件向教务课（ceb.nyushi1@nihon-u.ac.jp）咨询，第1期截止 2026/8/18（周二）（已过），第2期截止 2026/12/7（周一）。
- 社会人特别选拔：除上述学历外，须在2027/4/1时点最终学历毕业后满2年。
- 出願书类（一般）：大学院入学志愿票（所定）、成绩证明书（厳封）、研究内容调书（所定，须受入指导教员确认并盖认印）、毕业（预定）证明书、出願资格确认书（经资格审查者）。社会人另交志望调书。
- 出願方式：把书类装入角2信封贴上出願用地址标签，以简易书留寄到日本大学工学部教务课（大学院入试係），截止日必达；本校在学生可在教务课窗口直接提交。要项没有网上出願。
- 检定料 35,000 日元，用邮局的普通为替证书随书类一起提交（收款人栏留空），已交书类和检定料不退。
- 学内选考（工学部学生）另行募集，只凭口述试验判定（令和8年度合否判定方法一览）。
- 外国人留学生：须外国籍，满足外国16年教育或3年以上学士学位等资格；不满足规定资格或中国高等教育自学考试毕业者须个别入学资格审查，工学研究科申请截止2026/8/24（已过）。
- 留学生出願必须先联系研究科，取得事前連絡確認書原本，再网上登记及缴费、邮寄纸质材料；另附本研究科所定研究计划书并经受入教員确认，以及通用出願确认票、本人记入表、毕业证明、全学年成绩、护照复印件和材料清单等。证明原则上为日文或英文原本；不能提交原本时按要项准备certified true copy，其他语言须按规定附译文。
- 留学生检定料35,000日元，付款方式按Web出願流程选择，不能套用一般选考的普通為替証書方式。材料邮寄日本大学入试センター，〒101-0062東京都千代田区神田駿河台1-7-3，境外可用EMS/DHL等可追踪方式，2026/10/16必达。入学手续截止2027/1/29（周五）。
- 入学手续：第1期合格者中非日本大学出身者第一次截止 2026/11/17（周二），全员最终截止 2027/3/18（周四）；办完手续后辞退须在 2027/3/31 17:00 前电话告知教务课，4/1 以后不退入学时缴纳金。
- 初年度学费：学外者 1,290,000 日元（入学金 200,000、授業料 700,000、施設設備資金 300,000、実験実習料 80,000、校友会费 10,000），本校毕业生免入学金为 1,090,000 日元；入学时缴 750,000（学内者 550,000），9月缴 540,000。
- 考场：日本大学工学部（福岛县郡山市田村町徳定字中河原1），郡山站乘「日本大学」行巴士约20分钟；受験票考试当天在教务课窗口领取。需要考试或修学照顾的考生须在出願前尽早联系教务课。
- 咨询：工学研究科教务课（大学院入试係），Tel 024-956-8623，ceb.nyushi1@nihon-u.ac.jp。
