## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 不另设英语笔试，用出願时提交的 TOEFL iBT（含 Home Edition）成绩做外国语审查；只认 2024/8/1 以后受检的成绩。
- 提交三步缺一不可：①在 ETS 账户把 Official Score Report 送到研究科（DI Code 8426 University of Tokyo Faculty MED，Division: Graduate Organization，Department 42 Medicine）；②在 WEB 出願系统登记 Appointment Number 和受检日；③上传同一次的 Test Taker Score Report PDF（考后约8天可下载）。
- 考过多次也只能上传 1 份；官方成绩未确认、上传件与官方成绩不一致、受检日早于有效期的，按没有参加外国语审查处理；研究科不回答成绩是否送达。
- 变更点：2026年度及以前由専攻自己出英语题，2027年度起改为提交 TOEFL iBT 成绩。

#### 日本語要件
- 外国人（日本的大学毕业或预计毕业者除外）须提交日本語能力証明書：指导教员或相当的人出具的证明，也可用日语学校等的证明或日语考试合格证明的复印件代替。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：30名（2年コース约20名、1年コース约10名）；只有 8 月一次募集。
- 出願资格：大学毕业（含 2027/3/31 前预计）或外国 16 年学校教育等；个别入学资格审查须先联系研究科，2026/6/5 前提交材料（非独立出願，已截止）；1年コース另需出願时有保健医疗相关实务经验——4年制大学毕业者3年以上，6年制（医·齿·兽医·药）毕业者或修士修了者2年以上（医师等临床研修算实务），想事先确认的须在 2026/6/5 前必达提交履历书和全部任职单位的在职期间证明书（已截止）。
- 要提前准备的书类：TOEFL iBT 成绩；在职期间证明书（1年コース）；学习计划书（在职入学者，A4 2页）；日本語能力証明書（外国人）；海外大学的毕业证明须为英文或附公证英译，并写明学位名。
- 出願：只能通过 WEB 出願系统上传；检定料 30,000 日元（银行汇款、便利店、Pay-easy 或信用卡，手续费自付；日本政府奖学金留学生免缴）。
- 咨询：医学系研究科学務チーム大学院担当（〒113-0033 東京都文京区本郷7-3-1），in.m@gs.mail.u-tokyo.ac.jp；研究科入试页另有咨询表单。
- 并愿：尚未核实是否可同时报考其他专攻或选拔类别。请以本年度募集要项或招生窗口答复为准。
