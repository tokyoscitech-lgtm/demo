## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各轮次相同：不另设英语笔试，用外部成绩换算「英語」得分（100分）：TOEIC L&R 730＝满分、230＝0分；TOEFL iBT 2026/1/20 以前受检的 80＝满分、25＝0分，2026/1/21 以后受检的（1–6分制）4.5＝满分、2＝0分；中间按比例换算。
- TOEFL iBT：由 ETS 直送（DI Code 5132，本専攻 Department Code 66），并在出願书类チェックリスト上写 Appointment number 和直送手续日；Home Edition、MyBest、本人收到的 Test Taker Score Report 不受理。
- TOEIC L&R：交纸质 Official Score Certificate 原件，或日本国内受检（2024年4月以后）带 QR 码的数字认定证 PDF 打印件；提交后不能更换。
- 成绩须为出願截止日前2年以内受检，且必须在出願期间内送到；没送到、或成绩上的姓名等与志願者信息不一致、没有照片的，英语按0分处理。
- 变更点：2027年度Ⅰ·Ⅱ期起不再接受考试当天提交成绩。

#### 日本語要件
- 要项没有要求提交日语成绩。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：82名（学内選考、Ⅰ期、Ⅱ期、飛び入学等年度内全部入试合计）。
- 出願资格：大学毕业（含2027/3/31预计）或外国16年学校教育等；外国人留学生入学試験要求非日本国籍、初中等教育全部在外国修完，在日者须能取得「留学」等在留资格；需个别资格审查的人须先申请（Ⅰ期 2026/4/15、Ⅱ期 10/15 必达，均已截止，非独立出願）；飛び入学（仅Ⅱ期，面向强烈希望升读博士後期的人）须出願时在本専攻对应学科3年级在读（或在外国修完15年课程）并能交ゼミ担当者或学科长的推荐书，须先受出願资格审查，入学时所属学科成绩须在前3%以内。
- 要提前准备的书类：研究计划书（所定用纸A4 1页以内，写入学后的研究计划和将来去向）、外部英语成绩；外国籍者（本学理工学部·研究科出身者和特别永住者除外）另交出身大学指导教员等的推荐书1份（格式自由，日文或英文）和経費支弁計画書；中国（港澳台除外）的大学毕业者须申请 CHSI 学位和成绩认证并由 CHSI 直送 sst@mics.meiji.ac.jp；飛び入学另交2年级末为止的成绩证明书和推荐书。
- 出願：只收邮寄（角2号信封贴所定封面，速達·簡易書留，国内邮戳有效；海外用 EMS 等，最后一天必达），不收窗口和网上出願；检定料 35,000 日元（金融机构窗口电汇、便利店、信用卡·银联或海外汇款，Ⅱ期缴纳期间 2026/10/1–12/4）。
- 并愿：2027年度募集要项没有说明跨专攻并愿、一般入试与飛び入学并愿以及Ⅰ期合格者再报Ⅱ期的规则。
- 咨询：明治大学理工学部事務室 大学院入試係，〒214-8571 神奈川県川崎市多摩区東三田1-1-1，Tel 044-934-7600，Fax 044-934-7901，sst@mics.meiji.ac.jp（平日 9:00–11:30、12:30–16:30，周六 9:00–12:00；8/1–9/19 时间不同）。
