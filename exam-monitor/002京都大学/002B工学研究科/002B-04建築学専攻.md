## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各轮次都只认 TOEFL iBT，不另设英语笔试；TOEIC、IELTS 不受理（研究科共通部分里的 TOEIC 公式认定证不适用于本専攻）。
- 8月入试：
  - 只认 2024/8/1 以后受检的 Test Date Scores；MyBest Scores、Home Edition、团体受检的 TOEFL ITP 无效。
  - 向 ETS 申请把 Institutional Score Report 直接寄到本専攻，Institution Code B472，2026/7/31（周五）17:00 前送达（已截止）；専攻不回答是否送达的查询。
  - 换算成 100 分（总分 800）；2026/1/21 以后受检的按 0–120 的原始分计算，更细的换算式官方没有公布。交了多份的取最高分，没有送达的英语按 0 分。
- 2月入试（仅外国人留学生）：2027年2月实施分未公布。2026年2月实施分同样只认 TOEFL iBT（Home Edition、ITP 无效），2024/2/1 以后受检的 Test Date 成绩，B472 直送，2026/2/6（周五）17:00 必达，换算 100 分（总分 400），没交按 0 分。

#### 日本語要件
- 各轮次的要项都没有要求提交日语成绩（JLPT 等），也没有写明试题语言和可用的作答语言。

- 8月入试总分 800：英语（TOEFL）100＋設計製図 100＋計画系·構造系·環境系科目 600。三个系各自的配点、题数、选答方式和每科的考试时长，要项都没有写明，只给了两天的时间段。
- 8月入试合否判定：总分 400 分以上为有资格者。各志望区分的第1志望有资格者中总分最高、且总分在全体前75名以内的人为优先合格者；其余有资格者按总分从高到低，依志望顺序分配到还有名额的志望区分。同分时先比計画·構造·環境三系合计分，再比第1志望区分对应科目的得分率。
- 2月入试（2026年2月实施分）：总分 400（英语 100＋専門科目 300），200 分以上为有资格者，再综合得分和志望区分决定合格者。
