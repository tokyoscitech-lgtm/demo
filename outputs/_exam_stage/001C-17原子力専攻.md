## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 须提交 TOEIC Listening & Reading Test（公开考试）的公式认定证，用它代替英语笔试；TOEIC IP 不受理。
- 只认 2025年1月以后受检的成绩，须在 2027/1/19（周二）24:00 前送达。
- 提交方式：原则上把数字公式认定证的电子文件上传到 WEB 出願系统，并登记认定证的 URL；没有数字认定证时才可以上传纸质认定证的扫描件，同时把原件用書留寄到东海村的専攻入试担当（〒319-1188 茨城県那珂郡東海村白方白根2-22）。
- 官方没有写最低分，也没有公布换算方法和配点。
- 修士課程要项里的 TOEFL iBT 规定不适用于本専攻，本専攻的入试案内里没有提到 TOEFL。
- 与上一年度相比做法相同，只是日期顺延（2026年度为 2024年1月以后受检、2026/1/20 截止）。

### 日本語要件
- 要项没有要求提交日语成绩。除英语以外，全部考试原则上用日语进行，小論文和口述实际上需要相当的日语能力。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 英語 | 不设笔试，提交 TOEIC L&R 公开考试成绩；配点官方未公布 | 2027専攻入试案内 |
| 数学（120分钟） | 微分方程、线性代数、概率·统计等，达到学习原子力工学所需的基础水平；题数和配点官方未公布 | 2027専攻入试案内／専攻入试信息页 |
| 小論文（90分钟） | 考查逻辑思考能力；题目、题数和配点官方未公布 | 2027専攻入试案内／専攻入试信息页 |

- 按笔试（英语、数学、小論文）、口述试验的成绩和提交书类综合判定；成绩不够时可能录取不满募集人员。
- 笔试可带：受験票、黑色铅笔、自动铅笔及笔芯、卷笔刀（桌上式不可）、橡皮、只有计时功能的手表。
- 题目倾向（体验记，非官方）：没有找到公开的受験体验记，倾向只能靠向専攻索取的标准问题来把握。

### 口述試験 / 面接
- **官方形式**：2027/1/23（周六）在工学部8号館进行口头试问，问包括原子力在内的理工学、社会科学等方面的知识，以及兴趣、学习意愿、入学后的学习计划；只需带受験票。时长、考官人数和配点官方未记载。
- **実際に聞かれた内容**：未获取到。没有找到公开的体验记。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员为15名。
- 对象：主要面向有2年以上实务经验的社会人，实务经验不满2年的人和 2027年3月底前预计大学毕业的人也可以报考。
- 出願资格（满足其一）：大学毕业或 2027/3/31 前预计毕业；在外国完成16年学校教育；在外国大学完成3年以上课程并取得相当于学士的学位；文部科学大臣指定的人或指定教育设施的修了者；由大学改革支援·学位授与機構授予学士学位；经个别入学资格审查认定具有同等以上学力且 2027/3/31 时满22岁。
- 个别入学资格审查：审查书类在 2026/10/27（周二）前交到工学系研究科学務課大学院チーム，通过的人才能出願。
- 出願书类（全部做成 PDF 上传）：入学願書（在系统里填写）、证件照数据（3个月内拍摄）、出身大学的毕业证明书（已毕业者；东大工学部毕业者免）、成绩证明书（东大工学部毕业或预计毕业者免；编入学者还要交编入前的成绩）、日本政府奖学金留学生证明书（该当者）、安全保障輸出管理チェックシート（外国籍、重国籍、此前所属为海外机构的人）。合格后在入学手续时提交纸质原件。日语、英语以外的书类要附出身大学出具的英文或日文译本。
- 専攻另外要求：経歴書（全员，本人写，大学入学以后的学历和职历，职历写所属部门和业务内容，A4、格式自由）；在职证明书类（在职入学者，由现所属机构出具，证明在职和业务经验，A4、格式自由）；TOEIC 公式认定证。官方没有要求志望理由書或研究计划书。
- 検定料 30,000 日元，手续费自付，可在 2026/11/20–12/3 通过便利店、Pay-easy、网上银行、信用卡等缴纳，缴纳证明上传到 WEB 出願系统；日本政府奖学金留学生免缴；缴纳后不退。
- 受験票：2026/12/22（周二）15:00 前后在 WEB 出願系统的个人页面交付，自行打印带到考场。
- 入学手续：另行邮件通知，须在 2027/3/9（周二）（预定）前办完。在职入学者在入学手续时提交勤务单位的承诺书（写明在职入学并专心学业没有妨碍，格式自由）。
- 入学料 282,000 日元，授業料 年 535,800 日元（前期 267,900 日元），均为预定额；日本政府奖学金留学生免缴。
- 不能同时报考本研究科的两个以上専攻或课程。外国籍者须在入学手续前取得可以就读的在留资格；东京大学按安全保障出口管理规则进行审查，即使合格也可能不被许可入学或研究活动受限。
- 课程信息：标准修业年限1年，修了授予“原子力修士（専門職）”。指定科目成绩达标的修了者，原子炉主任技術者考试的笔试除法令以外的科目可以免除并取得口答考试的受験资格，核燃料取扱主任者考试除法令以外的科目可以免除。
- 咨询：考试和教学内容问原子力専攻事務室（〒319-1188 茨城県那珂郡東海村白方白根2-22，nyushijimu@tokai.t.u-tokyo.ac.jp，或専攻咨询表单）；出願手续问工学系研究科学務課大学院チーム（本郷，工学部8号館1階），要项要求通过研究科入试咨询表单提问，不接受电话询问合否。

### 研究室 / 指導教員
- 事前連絡要否：要项没有要求出願前联系教员。本専攻是以授课、演习和实验实习为主的1年制専門職課程，出願时不填志望研究室或指导教员。
- 入试案内没有列教员名单；教员和课程安排见専攻主页和専攻案内手册。
- 官方强烈建议参加入试说明会，标准问题也要在说明会之后才能索取。
- 专攻事務室在茨城县东海村，考试在本郷校区进行；授课地点的具体安排入试案内没有写明，见専攻案内手册。
