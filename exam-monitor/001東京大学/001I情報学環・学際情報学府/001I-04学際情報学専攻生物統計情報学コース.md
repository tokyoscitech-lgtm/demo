## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 不另设英语笔试，用外部成绩评价；TOEFL iBT（含 Home Edition）、TOEIC L&R、IELTS Academic（含 Computer Delivered）三选一，願書上只能勾选一种。
- 有效期：2024/9/1 以后到出願受付结束（2026/7/10）之间受检。
- TOEFL iBT：由 ETS 直送官方成绩（Institution Code 0440，Department Code 99），原则上 2026/7/24（周五）前到达；願書填 Appointment Number，以前寄过的也要重新申请送分。
- TOEIC L&R：上传 Official Score Certificate（数字版或扫描 PDF）。IELTS：上传 Test Report Form 扫描件，或由英检协会管辖办公室直送（7/24 必达）。来不及随出願提交的，事先联系学府，2026/7/24（周五）正午前用邮件提交。
- 不受理：TOEFL ITP、TOEFL Test Taker Score Report、TOEIC S&W／Speaking／Writing／Bridge／IP、IELTS General Training。

#### 日本語要件
- 外国人（日本的大学毕业或预计毕业者除外）须提交「日本語学力証明書」，原则上用コース入试案内所附样式，由日语教员或相当的人就说、听、写、读四项评价；用其他样式时须写明四项评价及评价方法。
- 笔试用日语作答，口述的问答用日语进行；出願书类原则上用日文或英文。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 専門科目 | 大学基础程度的统计学和医齿药学领域的统计学（依据統計関連学会連合「統計学の各分野における教育課程編成上の参照基準」2014年8月），考基础知识和运用思考力；共3题，第1题选择题，第2、3题记述题，全部必答 |  |

- 一次选考按笔试、英语成绩和书类综合判定；一次选考合格者进入二次选考（口述），最终结果与一次选考合并判定。
- 特別選考枠（若干名）的考试科目与一般选拔相同。

### 口述試験 / 面接
- **官方形式**：夏季：只有一次选考合格者参加，用线上会议系统远程进行（需带摄像头、能联网的电脑），就受験者心得给出的课题发表并问答（日语），综合考查基础与专门学力、研究能力和研究计划、提交书类，特别问作为生物统计家的素养和长期规划，可能试问笔试范围的内容（已结束）。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：10名（只在夏季募集，其中特別選考枠若干名），学際情報学専攻全体100名（含アジア情報社会コース13名），合格人数可能不足募集人员。
- 出願资格：大学毕业（含 2027/3/31 前预计）或外国16年学校教育等；资格(6)个别审查书类 2026/6/1（周一）前书留邮寄（邮戳有效，已截止，非独立出願）；同一时期只能报学府一个コース，也不能同时报修士和博士；特別選考枠限在国内大学·研究机构从事临床试验、临床研究或流行病学研究实务，或修了后预定在该机构从事临床试验相关工作的人。
- 要提前准备的书类：研究計画書（所定样式）；自己推薦書（所定样式，可写生物统计、临床试验、流行病学方面的实绩和网址，有統計検定合格证等证明的一并提交）；推薦書（上司或毕业论文指导教员等撰写，本人取得受付番号后委托其直接上传）；英语成绩；日本語学力証明書（外国人）。本コース不交指導教員希望調査書。
- 出願：只能在指定网站填写和上传，7/10 12:00 前上传完成；检定料 30,000 日元（日本政府奖学金留学生免缴）。
- 咨询：学際情報学府 事務部学務チーム（〒113-0033 東京都文京区本郷7-3-1），Tel 03-5841-8769／8768，gakumu@iii.u-tokyo.ac.jp。合否不接受电话和邮件查询。
- 并愿：同一时期只能报学府一个コース，也不能同时报修士和博士。
