## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 1-2月实施：出願须提交TOEIC、TOEFL或IELTS外部成绩，英语不设校内测试；简易版 Guidelines 要求是 2025年1月以后受验的成绩。
- 要项没有写最低分数线，也没有给出换算表或英语的单独配点，英语成绩作为书类审查的材料使用。
- 可以用「英语授课课程修了证明」（A4，格式自由）代替成绩单，条件是授予学位的大学在非英语圈国家。
- 全学共通的规定：TOEIC 只收 Listening & Reading 公开考试，IP 不收；TOEFL 只收 iBT（含 Home Edition），ITP 不收；IELTS 只收 Academic，General、线上版、One Skill Retake 都不收。
- 提交方式（全学共通）：TOEIC 在 Web 系统里填数字公式认定证的 URL 并打印提交；TOEFL iBT 可交ETS邮寄给考生的Test Taker Score Report原件；2026年1月起纸本停发，没有原件时须ETS直送Official Score Report（Institution code 9995，Department code 99），同时打印PDF版Test Taker Score Report；IELTS 把 Additional TRF 的成绩数据送到大学并交 Test Report Form 复印件。成绩数据到达大学要几周，逾期未到按出願不受理处理。

### 日本語要件
- 1-2月实施：不要求日语成绩。课程和面试使用英语，研究计划约800英文词。证明文件接受日文或英文；其他语言须由注册翻译者译为日文或英文，不把课程语言误写为所有证书只能英文。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 1-2月实施：笔试不实施 | 没有专门科目笔试，也没有英语笔试 | 2027募集要项（英语版网页） |
| 1-2月实施：书类审查（100分，无考试时间） | 对个人经历（学历、职历、研究活动）和研究计划作综合评价 | 2027募集要项（英语版网页） |
| 1-2月实施：口述试验（300分，时长未公布） | 以个人经历和研究计划为基础的英语个别面试，Zoom 线上 | 2027募集要项（英语版网页） |

- 1-2月实施的总分为 400 分（书类审查 100＋口述试验 300），按总分综合判定合格者。要项没有写合格最低分。

### 口述試験 / 面接
- **官方形式**：1-2月实施：Zoom 线上个别面试，全程英语，围绕个人经历和研究计划提问，配点 300 分。考试日为 2027/1/27（周三）–1/28（周四），时间段 9:00–17:00（日本时间），每人的场次由大学安排。受験者心得在 2027/1/8（周五）前后发布在入试网站的通知栏。
- **実際に聞かれた内容**：没有读到公开的面试体验记（日文、英文、中文都检索过）。

## 📝 详细信息
### 出願資格 / 定員
- 1-2月实施的募集人员为 8 名（2027年10月入学）。本プログラム没有社会人特別選抜等其他选拔区分。
- 出願资格：日本的四年制大学毕业或 2027年9月底前预计毕业；由大学改革支援·学位授与机构授予学士学位或 2027年9月底前预计取得；在外国完成 16 年学校教育或 2027年9月底前预计完成，等等。不符合这些条件的人（满 22 岁的个别审查）要在 2026/11/24（周二）之前用邮件向 TIAS Admissions Office 申请出願资格审查。
- 修业年限：2027年10月–2029年9月，共 24 个月；入学日为 2027/10/1（周五）。
- 出願方式分两步。第一步在 Web 出願系统里录入本人信息、职历、研究活动和研究计划（约800英文词，参考文献计入字数；普通输入不放表格图形。必须用公式或特殊字符时，使用系统指定一页表格，不能改变格式或超框）；一个账号只能报一个学位プログラム。第二步把证明书类的原件用挂号邮件寄到（或亲自交到）体育芸術エリア支援室大学院教務，2026/12/11（周五）17:00 必达。
- 出願书类：毕业（预计）证明书原件；学位证明书（在日本以外毕业的人）；成绩证明书（英文或日文，已读研究生院的另交研究生院成绩单；有硕士学位的人还要交学士学位证明）；英语成绩单或英语授课课程修了证明；Motivation letter（Word 格式，用邮件发到 tias-admin@un.tsukuba.ac.jp）；在职或在学者的受験承认书；国费留学生的证明书（该当者）；检定料缴纳证明；Web 系统打印出的照合票和地址标签。交上去的书类原则上不退还。
- 检定料 30,000 日元，缴纳后不退。信用卡所有人可用，便利店支付只限日本国内居住者；缴纳期间与 Web 出願期间相同（2026/11/30–12/10）。国费外国人留学生和双学位项目的副学位プログラム出願者免缴。
- 学费：入学料 282,000 日元，授業料 年 535,800 日元；简易版 Guidelines 另注明以「留学」在留资格在日本的外国人留学生授業料为年 608,800 日元。国费外国人留学生免缴入学料和授業料。金额在入学时或在学中可能改定。
- 奖学金：TIAS 奖学金页上登的是上一年度（2026年10月入学）的国费外国人留学生大学推薦特别项目，报名截止 2025/12/23、申请书提交 2025/12/24、Zoom 面试 2026/1/28 或 1/29；2027年10月入学的募集没有读到，页面写着后续信息另行公布。
- 咨询：Office of Master's Program in Sport and Olympic Studies（体育芸術エリア支援室内），〒305-8574 茨城県つくば市天王台1-1-1，tias-admin@un.tsukuba.ac.jp，邮件标题写「TIAS Admission Inquiry (Your Name)」；周一至周五 9:00–17:00（日本时间），周六日、节假日和 12/29–1/3 休息。

- 书类补充：若证书仅有电子版，可由授予大学直接发送至taigeiin.admission@un.tsukuba.ac.jp；中国学历可按要项使用CHSI英文认证报告原件替代相应证书；自学考试本科须已完成并交实施机构成绩与学位证明，未完成者不受理。在线考试受験者还须亲笔签署指定Written Agreement，不能漏交。
