## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 8月入试：
  - 出願时提交 TOEFL iBT 的 Test Taker Score Report 或 TOEIC L&R 公式认定证的复印件，配点 60 分。
  - 换算：TOEFL＝0.6×分数；TOEIC＝0.6×（0.134×分数－32.66）；小数点以下进位，上限 60 分，下限 0 分。例如 TOEFL 90＝54 分，TOEIC 860＝50 分。
  - 成绩须为出願截止日前2年以内受检。TOEFL iBT Home Edition（含 Special Home Edition）可以；TOEFL Essentials、TOEFL ITP、TOEIC IP 不受理；IELTS 不受理。考过多次的只交1份。
  - 出願时没交成绩单的，英语按 0 分处理；不接受当天补交。
- 第2次募集：予告把 TOEFL/TOEIC 成绩单列为出願书类，配点和换算方法未公布（2026年2月的第2次募集为 60 分）。研究科通知写明 2026年夏期以后的入学考试只认 TOEFL/TOEIC、不接受当天补交。
- 变更点：2026年8月入试起英语定为 60 分，只认 TOEFL/TOEIC。

#### 日本語要件
- 要项没有要求提交日语成绩（JLPT 等），一般选拔对外国人也没有另设日语门槛。
- 8月入试：笔试用日语出题，可用日语或英语作答；口头试问用日语进行，可以用英语回答。
- 第2次募集：口头试问的一部分用日语进行，用来评价学习所需的日语能力；研究计划发表和回答可用日语或英语。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 数学（200分，120分钟） | 微积分、线性代数；题数要项没有写 | 2027募集要项 |
| 専門科目（200分，120分钟） | 复变函数论（复平面、正则函数、复积分、留数与实定积分、级数展开、保角映射）、概率统计（概率与推断统计基础）、控制工学（传递函数、伯德图、稳定判别、根轨迹、相位超前滞后补偿等古典控制，不含非线性控制和采样控制）、信号处理（傅里叶分析、Z变换、线性滤波器）4个领域，答题时选2个，每个100分 | 2027募集要项 |
| 第2次募集（2027年2月起）：基礎科目（数学），200分 | 微积分、线性代数；専門科目不实施 | 2026/3/23 予告 |

- 8月入试：
  - 配点为数学 200＋専門科目 200＋英语 60；口头试问对象者另加口头试问 80 分。
  - 按笔试、英语、口头试问（仅对象者）的得分和出願书类的内容，加上各志望区分可接收的人数综合决定合格者。
- 第2次募集：按出願书类（成绩证明书、志望说明书、TOEFL/TOEIC 成绩单）、数学和口头试问综合判定；可能先用出願书类做第一次选考（两阶段选拔）。
- 变更点：2026年2月的第2次募集是数学 100 分＋専門科目（4个领域选2个，各 50 分）、没有口头试问；2027年2月起改为数学 200 分＋口头试问 200 分。
- 变更点（2028年度入学）：2027年夏期的8月入试起，视志願者人数可能实行两阶段选拔——先按志望说明书、成绩证明书、英语成绩等做书类审查，通过者才参加学力检查（2026/6/24 予告）。
- 题目倾向（体验记，非官方）：两篇体验记都是 2020–2021 年的内部生，当时配点和领域划分与现在不同。共同的说法是数学时间紧、偏难，専門科目相对好拿分；备考以过去问为主，数学用マセマ和题集，控制用本科教材。

### 口述試験 / 面接
- **官方形式**：8月入试在笔试第二天进行口头试问，配点 80 分，只叫按笔试、英语得分和出願书类选出的对象者（名单 8/2 13:00 前掲示），问与志望区分相关的学识和希望做的研究，用日语进行、可用英语回答；第2次募集从2027年2月起口头试问 200 分，问志望动机、在本科学了什么、希望的专门领域、入学后的研究计划和专业能力，含考生的研究计划发表，一部分用日语进行。
- **実際に聞かれた内容**：现行形式（只叫一部分人、80 分）从 2026年8月开始，还没有找到这一次的体验记。旧形式下的两篇体验记（2020、2021 年）：2–3 名教员对 1 名考生，其中有第一志望的教员；一人写时间约 7 分钟；问了现在的研究、进研究生院后想做的研究、毕业后的打算，研究的目的和必要性被追问得比较深。第2次募集的新形式没有先例。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：8月入试28名；第2次募集未公布（2026年度第2次募集为若干名）。
- 出願资格：大学毕业或2027年3月底前预计毕业、在外国完成16年学校教育、在外国取得相当于学士的学位（3年以上课程）等 1–10 项之一；资格10须事先受审（8月入试的申请截止为 2026/5/18，已过）。
- 志望区分按志望顺序填写，数量不限，不希望的区分不用填；没填的区分不会被分配，即使分数高于合格最低分也可能不合格。願書受理后原则上不能修改。シ－９ 要写到细目，如“シ－９(a)”。
- 8月入试：
  - 出願书类：入学願書·写真票·受験票（圆珠笔填写，照片 4cm×3cm、3个月内拍摄）、成绩证明书、志望说明书（A4 2页以内，开头写姓名，写学习研究经过、志望动机、入学后的研究抱负，做过毕业研究的写明题目和内容）、在留卡正反面或护照复印件（外国人）、检定料缴纳证明、TOEFL/TOEIC 成绩单复印件、受験票邮寄用信封（贴 760 日元邮票）、合否通知用信封、入学手续书类用地址贴。书类用日语或英语写，其他语言要附译文。
  - 窗口提交只在 6/19 当天 10:00–12:00、13:30–17:00（情報学研究科教務掛）。
- 国内出願必须用纸质募集要项所附的用纸（教務掛领取或邮寄索取）；只有海外出願可以从研究科网站下载。出願为邮寄（書留速達、レターパックプラス等）或窗口提交，没有网上出願。
- 检定料 30,000 日元＋手续费 671 日元，通过京都大学决济系统支付（国内可用便利店、信用卡、Pay-easy，海外只能用信用卡）。国费留学生也要先缴，入学确定后退还。
- 一人只受理一份願書，不能同时报多个コース。8月入试合格者不能再报本年度的第2次募集等 2027年度4月期入学的其他募集。
- 入学料 282,000 日元，授業料 年 535,800 日元（均为预定额）；国费外国人留学生免缴。
- 考场在総合研究8号館。笔试只能用铅笔、自动铅笔、卷笔刀、橡皮、尺、仅有计时功能的手表等，不能用词典（含电子词典）。迟到 30 分钟内可入场；缺考 1 科记 0 分，缺考 2 科以上失格；口头试问对象者缺席即失格。8月入试的预备日为 2026/8/3（周一）。
