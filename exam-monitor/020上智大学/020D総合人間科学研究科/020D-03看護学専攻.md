## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 看護学専攻设有英语笔试（「英語」），而不是像理工学研究科那样提交外部检定成绩。共通要项里没有看到看護学専攻需要提交 TOEFL 等成绩的规定。
- 出题意图：考查准确阅读研究论文、把握论点并批判性地加以检讨所需的英语运用能力。
- 考试时长、可否带词典、题型（翻译或要约等），本次没能从研究科要项读出。过去问 PDF 是扫描图像，也没能读出题目构成。

### 日本語要件
- 共通要项里没有找到对看護学専攻外国人考生的 JLPT 要求；但出願资格要求持有日本的保健師·助産師·看護師资格之一（或取得预定），实际上需要能用日语应考。
- 试题语言和作答语言，要项里没有找到说明。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 英語（时长未核实，配点官方未公布） | 看护研究论文阅读；考查读懂论点并批判性检讨的英语运用能力 | 出题意图／说明会案内 |
| 専門科目（时长未核实，配点官方未公布） | 分野为基礎、成人、老年、小児、母性、在宅、地域、養護、国際看護学；考查希望研究分野的基础知识，以及对该分野现状课题的问题意识。推定按志望分野作答，选答规则未核实 | 过去问公开一览／出题意图 |
| 小論文（时长未核实，配点官方未公布） | 精读给定文章，从多角度思考并有逻辑地表述自己的见解；同时考查以人的存在与尊严为基础的看护观 | 出题意图 |

- 9月入試与2月入試的科目相同（英語、専門科目、小論文，另加口述）。
- 要项没有公布配点、总分和合否判定方法。
- 出题意图 PDF 里専門科目一栏只举了「老年·地域」作为示例分野，该 PDF 对应哪一年度、哪一次入试没有写明。
- 过去问的 PDF 是扫描图像，本次没能读出各题的具体构成，所以这里不写题数和题目内容。
- 题目倾向（体验记，非官方）：没有找到看護学専攻的体验记。

### 口述試験 / 面接
- **官方形式**：9月入試、2月入試都有口述试验（专攻说明会资料列为「口述試験」）。共通要项列出的全体考试日为 9/9·9/10 和 2/16·2/17，看護学専攻的口述在哪一天、几点、问什么、是否以研究计划书为基础，本次没能从研究科要项读出。配点和时长官方没有公布。
- **実際に聞かれた内容**：没有找到看護学専攻的体验记。

## 📝 详细信息
### 出願資格 / 定員
- 看護学専攻（修士課程）的募集人员是 9 名（一般入試，9月入試与2月入試合计）。共通要项的社会人入試一栏对看護学専攻读作「募集なし」，即不设社会人入試；也没有学内推荐类入试。
- 出願资格：除博士前期課程的共通资格（大学毕业或预定毕业、在外国完成16年学校教育、取得相当于学士的学位、专修学校4年以上专门课程毕业、文部科学大臣指定者、经个别审查认定且满22岁者等之一）外，还必须**持有保健師、助産師、看護師之一的资格（含取得预定）**。
- 共通要项里没有读到对临床实务经验年数的要求。
- 看護系短期大学毕业等需要个别审查（共通出願资格第6项）的人，须事先通过看護学専攻的出願资格审查：在 Web 出願开始日的2周前，用邮件（件名「看護学専攻出願資格審査申請書類送付希望」）向入学センター（admission-g-co@sophia.ac.jp）索取申请用纸。
- 专攻不设「研究コース／専門看護師（CNS）コース」之类的区分，官方网站上也没有提到 CNS 课程；修了后取得修士（看護学）。研究指导领域为基礎、成人、老年、小児、母性（ウィメンズ）、在宅、地域、養護、国際看護学。
- 研究计划书是否要求、字数多少，以及看護学専攻特有的出願书类，本次没能从研究科要项读出。共通的出願书类包括志願票（Web 出願后打印）、最终学校的毕业（预定）证明书和成绩证明书等。
- 出願书类不得使用 ChatGPT 等生成 AI 撰写。
- 出願方式：先在 Web 出願系统建立マイページ并登记，缴检定料，打印志願票，再把书类以「簡易書留·速達」寄到 〒102-8554 東京都千代田区紀尾井町7-1 上智大学入学センター。
- 检定料 35,000 日元，另加支付手续费 1,100 日元。
- 2月入試不接受海外出願；在海外的考生只能报9月入試。
- 学费：共通要项写明 2027年度学费未定，2026年7月决定后载入『入学手続要項』（截至 2026-10-14 本次没有找到公开版本）。参考的 2026年度金额中，看護学専攻所在的列因 PDF 文字错位没能可靠对应；最接近的修士課程一列为入学金 200,000 日元、第一年合计 1,493,400 日元（春学期 847,400＋秋学期 646,000，含在籍料 30,000、授業料 482,000、教育充実費 90,000、実験実習研究費 44,000／学期及保险料 1,400），使用前请对照原表。上智大学、上智短期大学（现上智大学短期大学部）、聖母大学毕业生的入学金有减额规定。
- 考场是四谷キャンパス（東京都千代田区紀尾井町7-1）。
- 咨询：入试手续问上智大学学事局入学センター（Tel 03-3238-3517，admission-g-co@sophia.ac.jp，平日 10:00–11:30、12:30–16:00）；课程和事前面谈问看護学専攻事務室（Tel 03-3238-3278，dp-nurse@sophia.ac.jp）。
