## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 一般·飛び入学·外国人留学生·社会人·多様分野人材入试：提交 TOEIC L&R、TOEFL iBT（含 Home Edition）、IELTS Academic Module 中任意一种的成绩证明复印件，代替英语笔试（考试机构发行的、有姓名·日期·分数的成绩单；网上发行的打印该页）。
- 有效期：TOEIC L&R 须 2023/4/1 以后受检（含所属团体或大学的 IP 考试）；TOEFL iBT、IELTS 须 2024/8/1 以后受检。
- 只能交一种考试；同时附上多种成绩可能导致书类不被受理。
- 换算：参照 CEFR 换算表折成100分满分，再计入学力检查；一般·外国人留学生入试英语配点 300 分，社会人·多様分野人材入试英语 300 分。要项没有公布具体的分数与 CEFR 等级对应表和最低分。
- リカレント教育入試和推薦入试不交英语成绩。

### 日本語要件
- 要项没有要求提交 JLPT、EJU 等日语成绩，外国人留学生入试也一样。
- 成绩证明书和毕业证明书须为日文或英文，其他语言须附日译或英译，并由大使馆或公证处证明与原件一致。要项没有写面接用什么语言，也没有写专门科目可以用英文作答，报考前宜向教員和教務係确认。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| CS プログラム「情報科学」（600分，120分钟） | 从数学·数理系（微积分、线性代数、集合与概率、代数学、图论、信息论与编码、自动机与语言、数理逻辑）、ソフトウェア系（算法与数据结构〔C语言〕、知能系统〔人工智能、数字信号处理〕）、ハードウェア系（数的表示、布尔代数、逻辑电路、计算机组成、机器指令）、OSとネットワーク、ヒューマンサイエンス系（认知科学、人间信息学、心理学）5领域中选3个作答 | 2027募集要项 |
| BI プログラム「行動情報学」（600分，120分钟） | 情報処理（算法、数据结构、编程〔Java〕、OS、网络、安全）和情報システムとデータ分析（信息系统基础、建模与UML、开发方法论、软件质量、数据库与SQL、概率统计与数据分析）2领域都要答 | 2027募集要项 |
| ID プログラム「情報社会デザイン」（600分，120分钟） | 1个领域的论述：从媒体／传播、社会／公共、生活／社区任一观点，基于基础知识论述对信息社会课题的看法 | 2027募集要项 |
| 多様分野人材·リカレント·社会人·推薦 | 没有笔试 | 2027募集要项 |

- 一般·飛び入学入试配点：专门科目 600＋英语 300＋面接·口头试问 300（外国人留学生入试的配点表面接栏写为 900）。原则上学力检查和面接·口头试问都达到配点50%以上者按总分排名录取；填了第2志望コース的，第1志望不合格时再按第2志望判定。
- 要项为各领域列出了参考书（如 CS 的『理工系のための離散数学』、BI 的『データ構造とアルゴリズム』等）。
- 题目倾向（体验记，非官方）：没有找到公开的体验记；官方公开的令和2–8年度过去问是最直接的备考材料。

### 口述試験 / 面接
- **官方形式**：一般·飛び入学·外国人留学生入试：面接·口头试问（300分），依据志望理由并びに学習・研究計画書判断志望动机、目标、热情、逻辑思维和表达能力，并参考成绩证明书。多様分野人材入试（第2回 2026/12/5 10:00–）：约15分钟发表（以往在非信息学领域所学内容和入学后研究计划，可用笔记本电脑 HDMI 输出）后口头试问，英语 300＋面接·口头试问 300，两项均须达50%。リカレント教育入試（12/5 10:00–）：面接（志望动机、目标、热情）900 分＋口头试问（实务经验、专业知识、逻辑与表达，含约10分钟发表）900 分，两项均须达50%。社会人入试：含约10分钟发表。推薦入试二次选拔面接·口头试问 900 分，含按所修科目的学力确认。
- **実際に聞かれた内容**：没有找到考生的面接体验记。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员（2027年度）合计85名：基盤情報学コース 推薦40名·一般10名；领域情報学コース 推薦20名·一般15名（一般名额中含多様分野人材入试和リカレント教育入試的若干名）；飛び入学·社会人·外国人留学生各コース若干名。
- 本専攻分2コース3プログラム：基盤情報学コース（CS·BI）和领域情報学コース（ID 等，重视与其他领域融合和实务）；多様分野人材和リカレント只招领域情報学コース。
- 多様分野人材入试出願资格：大学毕业或2027年3月前预计毕业等，但本校情報学部毕业（预计）者除外；第1回和第2回只能报一次。リカレント·社会人入试：大学毕业且到2027年3月底有3年以上实务经验，或经个别审查且2027/3/31前满25岁。外国人留学生入试：不具有日本国籍，外国16年课程修了等。
