## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 学内选考（9月）和一般选考（9月·2月）出愿时必须提交外部英语成绩，以此换算外语得分、当天没有英语笔试：TOEIC L&R、TOEIC L&R IP、TOEFL iBT、TOEFL ITP、IELTS 任一种。
- 成绩须为出愿截止日起往前2年以内受检，出愿时交实施团体发行的成绩单复印件，口头试问当天必须带成绩原件。
- TOEIC 和 IELTS 的线上受验成绩不收。
- 成绩换算成外语得分（令和8年度判定基准中英语为100分），换算方法不公开，要项也没有写最低分。
- 社会人选考不要求英语成绩。

### 日本語要件
- 要项没有要求提交 JLPT/EJU 等日语成绩，也没有设日语门槛。
- 笔试和口头试问按日语进行（要项没有提供英语作答的说明）；外国籍考生实际需要能用日语应试和交流。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 专攻基础科目（100分，90分钟，10:00–11:30） | 出题范围：线性代数、概率统计、数据结构与算法、网络技术、面向对象设计·编程（含 Java）、机器学习、网络安全、人机智能体交互（HAI） | 2027募集要项／判定基准 |
| 结构（令和8年度出題の意図） | 问题1 共通（基础：矩阵、排序算法、网络技术）；问题2 共通（编程：设计模式、Java）；问题3–5 为选择题（机器学习／网络安全／HAI，各3小题）；要选几题官方未写 | 过去问 |
| 外语（外部英语成绩换算，100分） | TOEIC/TOEFL/IELTS 换算，当天不考 | 2027募集要项／判定基准 |

- 一般选考按书类、专攻基础科目、口头试问综合判定。令和8年度判定基准：专攻基础科目100＋英语100，合计 9月募集 110/200 以上、2月募集 120/200 以上，且口头试问 C 评价以上；学内选考口头试问 C 评价以上。2027年度的判定基准尚未公布。
- 题目倾向（官方「出題の意図」）：9月和2月的题型几乎相同，只有 HAI 第1小题由自然语言理解换成 IoT；机器学习题涉及 SVM·交叉验证·过拟合、强化学习、深度学习，网络安全题涉及网络安全、密码协议、密码技术。体验记未找到。

### 口述試験 / 面接
- **官方形式**：一般选考在笔试当天 13:30 起口头试问，学内选考和社会人选考 10:00 起；内容主要是志望的专修科目和研究计划。须达到 C 评价以上（令和8年度判定基准）。配点和时长要项未写。
- **実際に聞かれた内容**：研究科2026年新设，未查到公开体验记。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：修士课程入学定员 35 名，含学内·一般·社会人全部选考的入学者；9月和2月募集没有分开列人数。
- 一般入学选考出愿资格：修完与志望专攻相关课程，且大学毕业或 2027年3月前预计毕业、学位授与机构授予学士、在外国完成16年教育、指定教育设施或专修学校修了等（1）–（9）项之一。
- 资格（7）–（9）须个别资格审查（（8）要求 2027/3/31 前满22岁），出愿截止前2个月以前联系情報学部学生センター并提交书类。
- 2月募集只限出愿时持中长期在留资格在日本居住者。本研究科要项只有学内·一般·社会人三种选考，没有单独的外国人留学生入试。
- 学内入学选考（仅9月）：2027年3月近畿大学预计毕业，有学科长或演习·毕业研究指导教员推荐，并满足成绩基准；另交致校长的推荐书。
- 社会人入学选考（9月·2月）：大学毕业后（或取得资格后）在职满2年，有单位领导推荐；交在职证明书、致研究科长的单位推荐书、研究报告·计划书（过去研究 A4 1页＋大学院研究内容 A4 2页以内）。出愿前须联系情報学部学生センター大学院入试係。
- 出愿书类（一般）：网上登录的出愿确认票、履历书（从出愿网站下载）、毕业（预计）证明书和成绩证明书（出愿前3个月内开具）、宛名标签（A4）、TOEIC 等成绩复印件、研究计划书（格式自由，A4 2页以内，写已做研究如毕业研究、大学院研究的背景·目的·计划）；海外大学毕业者另交学士学位（预计）证明（毕业证明写明学位的可免），中国大学毕业者可用学信网学位在线验证报告。同一年度第二次出愿时证明书不必重交。照片以数据上传。
- 出愿方式：只接受网上出愿（UCARO 账号）。登录后支付检定料，再把书类用简易书留·速达从邮局寄出，截止日必达；全部完成才算出愿。
- 检定料 32,000 日元（另需手续费），信用卡、便利店、Pay-easy、网银支付，原则上不退。
- 网上出愿时「志望专修科目及指导教员名」一栏须对照研究科概要的教员一览选择并填写教员姓名。
- 入学金 200,000 日元（近畿大学 2027年3月毕业预计者 100,000），授业料 1年级 950,000 日元，学生健保共济会费 4,500 日元，另需校友会终身会费 30,000 日元；以上是令和8年度金额，可能变动。
- 考场：东大阪校区（大阪府東大阪市小若江3-4-1），教室见受验票。须在开考前30分钟到场，迟到限30分钟内。
- 外国人留学生须经安全保障出口管理审查，可能被要求变更研究内容；入学时签署遵守外汇法的誓约书。
- 需要考试或修学照顾的考生须在出愿开始日1个月前提出申请。
- 咨询：情報学部学生センター（E館1階），Tel 06-4307-3116，info-f@itp.kindai.ac.jp。
