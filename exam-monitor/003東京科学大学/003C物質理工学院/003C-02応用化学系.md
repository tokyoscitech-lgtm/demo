## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各轮次相同（A日程、B日程都必须）：不另设英语笔试，用外部成绩评价，B日程配点 100 分。
- 可用 TOEIC L&R、TOEFL iBT（含 Home Edition），须为 2024/6/11 以后受检的成绩。
- 提交物：网上下载的 PDF 打印件。TOEIC 须为带真伪确认 QR 码的デジタル公式認定証；TOEFL 须为 PDF 版 Test Taker Score Report，并在 ETS 账户里给该成绩设定 DI code G179。
- 不受理：ETS 寄来的纸质成绩单、TOEFL ITP、TOEIC IP 等团体考试；IELTS 不在可用范围内。
- 応用化学系规定出願时必须一并提交，出願截止后提交的不受理；交过的不能替换，也不退还。截止前没交的没有受験资格。
- 换算：要项附录给出 TOEIC→TOEFL-PBT 换算式（(PBT－296)÷0.348＝TOEIC，TOEIC 300分以下不适用）和 iBT→PBT 对照表（如 iBT 80＝PBT 550）；换算成100分的具体算法和最低分没有公布。

#### 日本語要件
- 要项没有要求提交 JLPT、EJU 等日语成绩，一般选拔对外国人也没有另设日语门槛。
- 要项和系的通知都没有说明试题语言和可用的作答语言；A日程和 B日程的试问以日语进行为前提，可对照过去问 PDF 确认题面语言。
- 国際大学院プログラム(C) 是英语授课项目，没有日语要求。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| B日程 第Ⅰ限（70分钟） | 有機化学、無機化学、物理化学、化学工学、高分子科学 5科中选2科作答 | 2027募集要项、系通知 |
| B日程 第Ⅱ限（70分钟） | 同样5科中选2科作答；可以和第Ⅰ限选同样的科目，也可以选不同的科目 | 2027募集要项、系通知 |
| B日程 英语（100分） | 外部成绩换算，不另考 | 2027募集要项 |
| A日程 | 没有笔试 | 2027募集要项 |

- B日程总分 500（筆答専門試験两限合计 400＋英语 100），各科、各限的分配没有公布；先按笔试结果决定口頭試問受験资格者，再结合口頭試問和出願书类综合判定；教员人均合格者数可能受限。
- A日程由系根据出願书类决定对象，考生不能选；凭出願书类和口述試験决定“合格内定”，内定者不再考 B日程，没内定的可以考 B日程。出願资格(9)（飞び入学）只能走 B日程。
- 考场规则：桌上只能放受験票、书写用具、橡皮、卷笔刀、手表、眼镜；计算器、尺、圆规、带计算功能的手表不能用。不必穿西装、打领带。
- 2026年的科目和时间割与2025年相同，没有变更。
- 题目倾向（体验记，非官方）：没有找到可用的体验记。

### 口述試験 / 面接
- **官方形式**：A日程口述試験 2026/7/11 线上进行，试问应用化学分野的专门内容（如学士论文研究、修士想做的研究），评价为 A–E 五级；B日程口頭試問 2026/8/25 用 Zoom 线上进行（需带摄像头和麦克风的电脑），只有笔试后公布的受験资格者参加，试问学士论文研究和修士想做的研究等，评价为 A–E 五级；时长和语言要项没有写明。
- **実際に聞かれた内容**：没有找到応用化学系考生写的体验记，无可归纳内容。
