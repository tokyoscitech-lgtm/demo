## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 8月入试（一般選考、特別選考相同）：英语用 TOEFL iBT 成绩代替笔试，配点 120 分，直接用 0–120 的得分。只用 Test Date Scores，考过多次的取最高分。
- 成绩须为 2024/8/2 以后受检。TOEFL ITP 和 TOEFL iBT Home Edition 不受理；要项只列 TOEFL iBT，TOEIC、IELTS 不在要项所列范围内。
- 提交方式有两步：①从 ETS 账户下载 Test Taker Score Report 打印后，与志望研究区分申告票一起在 2026/7/16（周四）17:00 前書留寄到（7/14 以前日本国内邮戳的書留速達可受理）；②让 ETS 电子送分，Institution Code 填 B431，2026/7/27（周一）前送达。官方不答复送分是否到达的询问。
- 没有提交成绩的，英语按 0 分处理。以英语为母语的人可事先咨询后提交宣誓書（様式4）申请免交。
- 第2次募集（仅外国人留学生，上次的做法）：同样提交 TOEFL iBT（Home Edition 不可，2年以内），配点 120 分，不交为 0 分。
- 变更点：2026/1/21 以后受检的 TOEFL iBT 采用新的成绩表示，要项写明仍取 0–120 标度的得分。

### 日本語要件
- 共通要项和機械工学群的入学試験詳細都没有要求提交日语成绩（JLPT 等）。试题语言和作答语言官方没有写明。
- 留学生另有路线上的提示：日本的大学毕业（含预定）的留学生建议考8月入试，其他留学生建议考2月入试，两种情况都要在出願前向教務掛确认。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 数学（180分，120分钟） | 要项没有写出题范围和题数 | 2027機械工学群入学試験詳細 |
| 機械力学（150分，90分钟） | 工業力学、振動工学；题数未写 | 2027機械工学群入学試験詳細 |
| 専門科目（400分，210分钟） | 流体力学、熱力学（含統計熱力学）、材料力学、制御工学；题数与选答规则未写 | 2027機械工学群入学試験詳細 |
| 第2次募集（仅外国人留学生，上次）：専門科目（240分，120分钟） | 機械力学、流体力学、熱力学、材料力学 | 2026年2月機械工学群入学試験詳細 |

- 8月入试一般選考总分 850（英语 120＋数学 180＋機械力学 150＋専門科目 400）。原则上总分 425 分以上为有資格者（基准分会按题目难度调整），再从有資格者中按成绩从高到低决定合格者；有人辞退时从有資格者中递补。
- 特別選考（前後期連携教育プログラム 高度工学コース）免笔试，总分同为 850（英语 120＋口头试问 730）。
- 第2次募集（上次）总分 600，300 分以上为有資格者。
- 合格者的研究室按「志望研究区分申告票」的志望顺序和成绩分配，所以考试是三専攻同一套题、同一条合格线，进哪个専攻取决于分到的研究室。
- 题目倾向（体验记，非官方）：没有找到可用的公开体验记，可直接看官方公开的近3年过去问。

### 口述試験 / 面接
- **官方形式**：8月入试的一般選考没有口头试问。特別選考先在 2026/5/27 做约20分钟的预备选考面接（结果邮寄通知，不合格的可改考一般選考），8/3 的口头试问 730 分，考生先发表研究计划，再就研究计划和专门知识接受提问。第2次募集（仅外国人留学生，上次）有口头试问 240 分，问专门学识、志望理由、研究计划。
- **実際に聞かれた内容**：没有找到本専攻口头试问的公开体验记。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：8月入试 本専攻 30 名；機械工学群三専攻合并募集，合计 113 名（機械理工学 59、マイクロエンジニアリング 30、航空宇宙工学 24，含前後期連携教育プログラム若干名）。第2次募集（仅外国人留学生）人数未公布，上次为機械工学群若干名。
- 出願资格：大学毕业或 2027年3月底前预计毕业等。外国学历（资格3–6项）须先把履歴書用邮件发给大学院掛做出願资格确认，截止 2026/5/11（周一）17:00（已过）。
- 志望研究区分申告票（様式1）要把機械工学群全部 26 个区分按第1到第26志望不重复地填满；有重复或空栏时顺位由機械工学群决定。願書上的志望区分栏不用填。
- 出願书类（共通）：网上出願系统打印的入学願書、履歴書、受験票和合格者番号一览的寄送用标签、检定料相关材料；京都大学工学部以外的人加交成绩证明书和毕业（预定）证明书原件；外国大学毕业者再加学位证明和推荐信；外国籍的交在留卡复印件。
- 另行提交给機械工学群的书类（一般選考）：TOEFL 成绩单打印件和志望研究区分申告票，2026/7/16（周四）17:00 必达。留学生还要交有指导预定教员确认印或签名的「志望する指導教員調書」（様式6），期限与出願书类相同（2026/6/10 17:00）。
- 出願方式：先在网上出願系统登记并缴费，再把书类邮寄（書留速達，6/8 以前日本国内邮戳的可受理）或投入校内专用投递箱；不受理窗口当面提交。
- 检定料 30,000 日元＋手续费 671 日元，可用便利店、信用卡、Pay-easy ATM、网上银行支付；国费留学生确定后退还。
- 不能同时报工学研究科的多个入试区分。
- 外国人留学生的教育研究内容受安全保障出口管理限制，可能进不了希望的研究；留学生须在 2027/4/1 前取得留学签证。
- 个别出願资格审查（资格9、10项）的书类截止为 2026/5/18（周一）17:00 必达（已过）。特別選考的受入承諾書等也是同一天截止。
- 入学料 282,000 日元，授業料 年 535,800 日元（均为预定额）；国费外国人留学生免缴。
- 考场在桂キャンパス Cクラスター。开考20分钟前入室，迟到30分钟以上不能入场，原则上不能中途离场。只能带仅有计时功能的手表，尺、圆规、词典、计算器都不能带。
- 一般選考的合格者想进前後期連携教育プログラム（融合工学コース）的，分配研究室后在 2026/10/26（周一）前交「教育プログラム志望調書」（様式5），须有预定教员的内诺。
- 咨询：入试内容问 Cクラスター事務区教務掛（機械工学群），Tel 075-383-3521，090kckyomu2@mail2.adm.kyoto-u.ac.jp；出願手续问工学研究科教務課大学院掛，Tel 075-383-2040／2041，090kdaigakuin-nyushi@mail2.adm.kyoto-u.ac.jp。
