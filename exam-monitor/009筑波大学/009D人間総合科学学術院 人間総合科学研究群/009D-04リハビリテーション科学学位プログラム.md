## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 8月实施：不另设英语笔试，也不需要提交 TOEIC、TOEFL、IELTS 等外部英语成绩；试验科目只有书类审查、论述试验和口述试验。

#### 日本語要件
- 8月实施：外国人出願者（永住者、特別永住者除外）须提交 JLPT N1（旧1級）或 J.TEST 実用日本語検定 特A級·A級的认定书原件；没有为外国人另设选拔区分。
- 论述试验和口述试验都用日语进行，论述用日语作答。
- 东京キャンパス不接收外国人研究生，没有先当研究生再考的路线。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 書類審査（20分） | 根据出願书类评分 | 2027募集要项 |
| 論述試験（100分，90分钟） | 与リハビリテーション有关的课题，日语作答。2025、2026年度入试均为2道大题各2小问、4问全答，每问一张600字格答题纸：第1题读政府统计表归纳（400字以内）后结合专业提出课题和对策（600字以内）；第2题归纳论说文论点（400字以内）后联系自己的リハビリテーション实践论述（400–600字） | 2027募集要项／过去问 |

- 总分 200：书类审查 20＋论述试验 100＋口述试验 80，合格最低分未公布。
- 出题意图（2026年度入试，官方）：第1题考准确读取和概括数据，并从リハビリテーション专业角度提出预防、早期发现和对策；第2题考把握论说文逻辑、把抽象概念与自身实践联系，并讨论科学验证方法。素材是孤独死、孤独孤立、自我决定、社会公正教育等社会性题目，不是医学知识默写。
- 题目倾向（体验记，非官方）：没有找到本プログラム的考生体验记。

### 口述試験 / 面接
- **官方形式**：8月实施有口述试验，80分，2026/8/23 进行，围绕研究计划（研究計画書A·B）提问，日语进行，试场为东京キャンパス文京校舎；每人时长、考官人数、个别或集团要项没有写。
- **実際に聞かれた内容**：没有找到本プログラム的口述试验体验记。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：8月实施 23名（本年度唯一一轮，没有其他选拔区分）。
- 出願资格①（不需审查）：大学毕业或入学前预计毕业、取得学士学位、在外国完成16年学校教育等（1）–（8）项之一，其中（6）项须出願前先咨询。出願资格②（须事先审查）：跳级入学，或经个别审查认定有大学毕业同等以上学力者；审查通过后拿认证号码才能 Web 出願。
- 共通条件：到入学为止有约1年以上工作经验（常勤、非常勤都算，学生打工不算），没有工作经验的不受理；工作经历写在学歴·職歴調書和職務内容調書里。
- 出願书类：毕业（预计）证明书和成绩证明书、学位授与证明书（符合者）、日语认定书原件（外国人）、住民票抄本（住在日本的外国人）、改姓者的户籍证明、检定料收纳证明、国费留学生证明书（符合者）；下载样式填写学歴·職歴調書、職務内容調書、研究計画書A、研究計画書B（按记入例填写，手写或电脑均可）。不需要推荐信和所属单位的受験承认书。
- 出願方式：东京キャンパス用 Web 出願系统录入（上传3个月内证件照）→ 支付检定料 → 发送出願数据（之后不能改）→ 7/11 17:00 前打印受験票、收件人标签等 → 书类装角形2号信封用書留邮寄，只收邮寄。Web 出願时不填指导教员。
- 检定料 30,000 日元，信用卡或便利店支付，缴纳后不退；国费外国人留学生免缴。
- 入学料 282,000 日元；授業料年额 535,800 日元，外国人留学生年额 608,800 日元。入学手续说明预定 2027年1月中旬–2月中旬发送。
- 上课时间：平日夜间（周二至周五 18:20–21:00）和周六（10:20–19:35），在东京キャンパス文京校舎；1年级修完大部分学分，2年级写修士论文。
- 咨询：筑波大学东京キャンパス文京校舎 社会人大学院等支援室教務担当（〒112-0012 東京都文京区大塚3-29-1），businessentrance@un.tsukuba.ac.jp，只接受邮件咨询。
