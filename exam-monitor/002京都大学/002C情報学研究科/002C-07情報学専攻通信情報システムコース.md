## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 8月入试：出願时提交 TOEFL iBT 的 Test Taker Score Report 或 TOEIC L&R 的公式认定证的复印件。配点 200 分，占总分的五分之一。
- 换算：TOEFL＝2×分数；TOEIC＝2×（0.134×分数－32.66）；小数点以下进位，上限200分。例如 TOEFL 90＝180分，TOEIC 860＝166分。
- 成绩须为出願截止日前2年以内受检。TOEFL iBT Home Edition 可以；TOEFL Essentials、TOEFL ITP、TOEIC IP 不受理。考过多次的只交1份。
- 出願时没交成绩单的，英语按0分处理，不接受考试当天补交。
- 第2次募集（2026年度参考）：TOEFL 或 TOEIC，换算为200分；TOEFL 先按 min（990，7.453×TOEFL＋237）换成 TOEIC 分数。注意：研究科已通知2026年夏期以后的入试不接受英语成绩当天提交，这条旧规定不再适用。

### 日本語要件
- 要项没有要求提交日语成绩。笔试题日英并记，可用日文或英文作答。本コース设有可以只用英语修完的国际项目。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 専門基礎A（150分钟） | 微分积分、线性代数、逻辑电路、信息理论 各1题，4题必答 | 2027募集要项 |
| 専門基礎B（150分钟） | 5个领域各1题，选2题：计算机科学基础（算法与数据结构、图论、语言·自动机、算法论）／软件与计算机网络（编程语言、语言处理系、操作系统、计算机网络）／通信系统工程（通信基础论、通信网络、信息传输工程）／计算机系统工程（计算机体系结构、计算机系统）／地球电波工程（电波工程〈电磁波·天线·传播〉、数字信号处理〈离散傅里叶变换、离散时间系统、数字滤波器〉） | 2027募集要项 |
| 第2次募集（2026年度参考）：専門基礎（150分钟） | 数学（微分积分、线性代数）、逻辑电路、信息理论、计算机体系结构 各1题，4题必答 | 2026年度第2次要项 |

- 8月入试的合格判定：笔试 800 分＋英语 200 分＝1000 分，按合计定出「有资格者」，再按成绩顺序和志望分配研究室；分配到研究室的有资格者为合格。
- 第2次募集（2026年度参考）：笔试 600＋英语 200＋口头试问 200。
- 变更点：2026夏起A改为微积分、线性代数、逻辑电路、信息理论各1题必答，B改为5领域各1题选2；2025年9月官方变更通知明确2月入试不在这次变更范围内。2025夏及更早经历采用旧科目范围，不能据此备考2026夏后的题目。
- 题目倾向（体验记，非官方）：2027年度4月入学的内部生shogo自述以讲义复习、过去问及模拟演练准备，TOEIC860，笔试备考约346小时，并称合格后第一志望研究室配属同时掲示；仅一人经历，不构成合格所需时数、分数或官方配属保证。

### 口述試験 / 面接
- **官方形式**：8月入试不设口头试问。第2次募集（2026年度参考）就志望区分相关的学识和希望的研究做口头试问，日语或英语。
- **実際に聞かれた内容**：未收集到第2次募集口头试问的体验记。

## 📝 详细信息
### 出願資格 / 定員
- 8月入试的募集人员为48名（含国际项目若干名）。第2次募集的人数未公布（2026年度为若干名，含国际项目）。
- 出願资格：大学毕业或2027年3月底前预计毕业、在外国完成16年学校教育、在外国取得相当于学士的学位（3年以上课程）等1–10项之一。
- 志望区分按志望顺序填写，数量不限；没有填的区分不会被分配。願書受理后不能修改。
- 出願书类（8月入试）：入学願書·写真票·受験票、成绩证明书、志望说明书（A4 2页以内，写学习研究经过、志望动机、入学后的研究抱负，做过毕业研究的写明题目和内容）、在留卡正反面或护照复印件（外国人）、检定料缴纳证明、TOEFL/TOEIC 成绩单复印件、受験票和合否通知用信封等。书类只收日文或英文。
- 国内出願必须用纸质募集要项所附的用纸（教務掛窗口领取或邮寄索取），不能用电子文件；只有海外出願可以从研究科网站下载。出願为邮寄（書留速達或レターパックプラス）或窗口提交，没有网上出願。
- 检定料 30,000 日元＋手续费 671 日元，通过京都大学决济系统支付（信用卡、便利店、Pay-easy）。国费留学生也要先缴，入学确定后退还。
- 一次只能报一个コース。8月入试合格者不能再报本年度的第2次募集。
- 外国大学毕业者在合格发表后可能被确认入学资格，不符合京都大学规定的，即使合格也不受理入学手续。外国人留学生的教育研究内容受安全保障出口管理的限制。
- 资格10（个别出願资格审查）者须事先受审，8月入试的申请截止为 2026/5/18（已过）。
- 入学料 282,000 日元，授業料 年 535,800 日元（均为预定额）；国费外国人留学生免缴。
- 笔试只能用铅笔、自动铅笔、橡皮、尺、仅有计时功能的手表等，不能用词典。迟到30分钟内可入场；缺考2科以上失格。
- 研究生（外国人留学生）是另一条路线：随时募集，须先经京都大学 AAO 确认资格并取得指导教员的内诺。这不是修士入试的要求。
- 咨询：情報学研究科教務掛（総合研究8号館1階），jyoho-kyomu@mail2.adm.kyoto-u.ac.jp，Tel 075-753-4894／5500（平日 9:00–17:00，12:00–13:00 除外）。
- 可以申请成绩提供（8月入试的申请方法见出願状况·合格发表页）。
