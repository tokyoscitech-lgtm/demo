## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般入试（A日程、B日程都要）：
  - 不另设英语笔试，用 TOEIC L&R 或 TOEFL iBT（含 Home Edition）成绩评价，B日程配点 100 分。
  - 本系要求出願时必须提交在线版成绩单打印件，出願截止后一律不收，交后不能更换、不退还；没交的没有受験资格。
  - 只认 2024/6/11 以后受检的成绩。TOEIC 须为带真伪确认 QR 码的数字公式认定证 PDF 打印件；TOEFL 须为 Test Taker Score Report PDF 打印件，并在 ETS 账户为该成绩设定 DI code G179。ETS 邮寄的纸质成绩单、TOEFL ITP、TOEIC IP 等团体考试不受理；在海外考的 TOEIC 也可以（系 FAQ）。
  - 要项附録3的换算基准：TOEFL iBT 先按对照表换成 PBT，再用（PBT－296）÷0.348＝TOEIC L&R，例如 iBT 80→PBT 550→TOEIC 约 730，iBT 100→PBT 600–603→TOEIC 约 874–882（TOEIC 300 分以下不适用）。
- IGP(C)：申请材料不要求英语成绩；面试和考试用英语进行。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 本系 A日程口述、B日程筆答和口頭試問都写明只用日语进行，筆答试题为日文。
- IGP(C) 全英语授课，不要求日语。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 専門科目（400分） | 材料力学、機械力学（不含機構学）、熱力学（不含伝熱工学）、流体力学的基础知识与理解；全部为共通题，没有选择题 | 9:30–12:30，180分钟 |
| 英语（100分） | 用外部成绩评价，见英語要件 | |

- A日程：系根据出願书类决定受験资格者（考生不能自选），凭出願书类和口述试验决定“合格内定”；没有内定的照常考 B日程；出願资格(9)（飞级）只能考 B日程。
- B日程：系可先凭出願书类选拔筆答受験资格者（8/11 前在系网站公布，2026年没有实施）；按筆答结果决定口頭試問受験资格者，再综合筆答、口頭試問和出願书类判定；每位教员的指导学生数有上限；筆答中止时可能改为凭出願书类选拔口頭試問受験资格者。
- 题目倾向（体验记，非官方）：四科各约 100 分、都是写过程的计算题，2024年8月材料力学出了热应力、機械力学出了过阻尼系统的初期响应，2025年8月熱力学偏难、流体力学偏易（2人提及）；有考生建议写出推导过程而不只写答案。

### 口述試験 / 面接
- **官方形式**：A日程：口述試験，考查学力和适性，只用日语，原则对面（遇到无法对面的情况可能线上）；B日程：口頭試問，考查研究能力和适性，只用日语，只有筆答后公布的受験资格者参加，候场时填补充调查（熱流体／材料・加工／機械力学・ロボティクスメカトロニクス三个分野的志望顺序、配不到志望教员时是否仍入学，9月入学者另填コース志望顺序）；IGP(C)：系或志望导师安排的英语面试和/或考试，原则线上。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：機械系受入可能予定人数 185 名（2026年9月和2027年4月入学合计，工学院合计 477 名，コース不分名额）；IGP(C) 各系若干名。
- 出願资格：大学毕业（含 2027/3/31 前预计）或外国16年学校教育等，(9)(10)(11) 项须先做出願资格审查；只能报一个系，一个出願出结果前不能再报理工学系其他募集（含 IGP(C)）；外国籍考生选9月入学须出願时住在日本且在留资格有效到 2026/9/28，否则只能4月入学；志望教员只能从要项名单选，最多10位。
- 要提前准备的书类：志望理由书（所定样式 A4 1张，只写第1志望的志望理由和修士研究题目的意义、要解决的问题与方法）；TOEIC L&R 或 TOEFL iBT 成绩单（出願时必交）；IGP(C) 另需导师同意书（10/4 前交入試課）、研究计划和推荐人直接提交的推荐信。
- 出願：一般入试网上登记缴费后把书类以速達書留寄入試課（6/10 必达，不收窗口提交），检定料 30,000 日元＋手续费 990 日元；IGP(C) 全程网上提交，检定料 30,000 日元（信用卡）。
- 并愿限制：只能报一个系；同一入学期不能报理工学系修士的多个募集，一个出願结果出来之前不能再报理工学系其他募集。
- 咨询：出願手续问入試課大学院入試グループ（inquiries.grad.se@adm.isct.ac.jp）；本系入试内容问機械系大学院入試担当（Daigakuin-Nyuushi@mech.e.titech.ac.jp）。
