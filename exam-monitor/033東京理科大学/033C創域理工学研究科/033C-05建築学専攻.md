## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 不另设英语笔试，用外部成绩评价。
- 一般入试：
  - TOEIC L&R（公开考试或 IP，TOEIC IP オンライン不可）或 TOEFL iBT（Home Edition 不可）·ITP 的成绩单原件一张；TOEIC 公开考试只收打印的数字公式认定证。
  - 须为出願截止日前2年以内受验，出願时提交，不退还，提交后不能更换。
- 外国人留学生入试：
  - 只收 TOEFL iBT（考场受验）或 TOEIC L&R 公开考试一张，须为第二次选考出願截止（2026/12/2）前2年以内受验，12/2 前必达入試課。
  - TOEFL iBT 交 Test Taker Score Report 和已向大学直送（Institution Code 0438）的画面或邮件打印件；TOEIC 在日本考的交带 QR 码的数字公式认定证打印件，在国外考的交 Official Score Certificate 原件和能看出考场的受验票等复印件。
  - 变更点：从2027年度起不再受理 TOEFL ITP 和 TOEIC IP（一般入试仍可用）。

#### 日本語要件
- 一般入试：要项没有要求提交日语成绩。
- 外国人留学生入试：
  - 第一次选考须交大学所定样式的「日本語能力認定書」，请日语教师、日本驻外使领馆人员或日语熟练者填写，不能用日语能力考试的证书代替；入学願書须全部用日语填写。
  - 第二次选考的笔试和口头试问用日语或英语。

- 一般入试：按出願书类、专门科目笔试、面接和英语成绩综合判定；考场教室当天在野田キャンパス正门前公布。
- 外国人留学生入试：第一次选考只审书类，第二次选考考笔试、小论文和口头试问，加外部英语成绩判定。

### 口述試験 / 面接
- **官方形式**：一般入试：笔试次日 10:00 起面接，选建築設計学的展示自己的作品2件；外国人留学生入试：第二次选考口头试问（希望专攻分野相关事项），用日语或英语。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：70名（専攻入学定员，含学内选考等2027年度全部修士入试）；外国人留学生入试若干名。本専攻不实施推薦入学和社会人特別選抜。
- 出願资格：学士学位（含2027年3月预计）或外国16年学校教育等，资格(6)个别审查者须出願前咨询创域理工学事務課；本専攻实施大学3年在读或外国15年学制修了者的特别选拔（资格(5)，另有要项）；外国人留学生入试限外国籍、没在日本读过4年本科、入学时能取得「留学」在留资格者，15年学制等须在出願开始1个月前交齐资格审查材料（非独立出願）；在日本读完本科的留学生只能报一般入试。
- 要提前准备的书类：一般入试为志望理由書（所定用纸，800字左右）和 TOEIC/TOEFL 成绩单原件；外国人留学生入试为日本語能力認定書、出身大学校长或指导教员的推荐信（所定用纸，3个月内，亲笔签名）、参考資料（所定样式⑦）；国外居住者都要请希望指导教员填写「事前相談シート」。
- 出願：一般入试可简易书留·速达邮寄或到创域理工学事務課窗口提交，邮戳有效（国外寄出须最后一天必达），附贴速达邮票的受験票用明信片，检定料 35,000 日元（银行窗口或日本国内便利店，不能用 ATM·网银）；外国人留学生入试只能邮寄到入試課（国外用 EMS 等可追踪方式），两次都必达，检定料第一次 18,000 日元＋第二次 17,000 日元（国外居住者用信用卡）。
- 并愿：一般入试可并愿笔试日不同的専攻，本専攻笔试 7/31，与同日考试的专攻不能并报，并愿时面接时间由各専攻指示；願書只填一个専攻，出願后不能变更研究科·専攻；外国人留学生入试只能报1个専攻。
- 咨询：一般入试为创域理工学事務課（〒278-8510 千葉県野田市山崎2641，Tel 04-7122-9728，邮箱 rkj（at）admin.tus.ac.jp，出願期间窗口 9:00–12:00、14:00–16:00，周末节假日除外）；外国人留学生入试为入試課（Tel +81-3-3260-4271，[咨询表单](https://faq.admissions.tus.ac.jp/hc/ja/requests/new)）。
