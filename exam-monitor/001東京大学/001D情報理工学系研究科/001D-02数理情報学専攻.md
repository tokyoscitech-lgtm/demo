## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 不另设英语笔试，用 TOEFL iBT（含 Home Edition）成绩评价；英语母语者也要交。MyBest scores 不采用，Test Taker Score Report 不受理，研究科不实施 TOEFL ITP。
- 送分：在 ETS 账户把 Official Score Report 直接送到 University of Tokyo IS&T（Institution Code 8445，Division: Graduate Organization，Department Code 99）；出願时填写该次考试的 Appointment Number 和受检日，只采用这一次成绩，出願后原则上不能更换。
- 有效期：受检日在 2024/9/1 至出願截止之间，出願时须已取得成绩；成绩数据须在 2026/6/30 前到达研究科（已截止），送分后约两周才能到达。
- 期限前研究科确认不到成绩或成绩不合规的，TOEFL 提交无效，同时失去笔试和口述的受験资格。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 书类选考课题可用日文或英文写；専門科目试题有日文版和英文版；口述用日语或英语，在出願系统的専攻指定记入栏2里选择。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 书类选考课题 | 举一个感兴趣的研究主题说明志望动机，写明主题背景与近年进展、感兴趣的理由、想取得的成果和社会价值；用専攻网页的 Word／LaTeX 模板，日文或英文，正文 2 页以内（参考文献可放第 3 页以后），出願时提交 |  |
| 一般教育科目（数学） | 线性代数、解析（微积分、常微分方程等）、概率统计各 1 题，3 题全答；只有书类选考合格者参加 | 13:00–15:30，150分钟 |
| 専門科目「数理情報学」 | 代数、解析、几何、离散、概率、统计、算法等领域共 5 题，选答 3 题 | 10:00–13:00，180分钟 |
| 専門科目「システム情報学」（可代替上一行） | 出願时与「数理情報学」二选一；日期、范围按システム情報学専攻入试案内书（信号処理、電子回路、制御 3 题选 2） | 10:00–12:00 |

- 选拔流程：书类选考 → 数学 → 専門科目和口述，综合判定；没考数学或専門科目的人不能参加口述，缺考任何一场视为弃权。
- 变更点（2028年度入试起）：研究科 2026/7/16 公告，本専攻夏入试的専門科目只能考「数理情報学」，「システム情報学」二选一取消；本年度不受影响。
- 题目倾向（体验记，非官方）：専門科目里线性代数、解析、最优化、概率统计几乎每年都出，5 题中约 4 题来自这些范围，不少人放弃算法和几何；数学第 1 题常是带引导的知名结论；没有完全解出时把思路写在答卷上也有分。

### 口述試験 / 面接
- **官方形式**：夏入试：2026/8/27 原则上线上进行，实施方法 8 月上旬通知，时间表 8/12 正午前通知且不能调整；用日语或英语（出願时选定）。
- **実際に聞かれた内容**：（体验记，非官方）每人约 5 分钟：先确认事务事项，再陈述志望动机，然后由有问题的教员逐个提问，内容围绕书类选考课题里的技术内容、对该主题感兴趣的契机、第二志望研究室的志望理由及该领域基础，多由第一、第二志望的教员提问。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：40名（夏入试；本専攻修士没有冬入试）。
- 出願资格：大学毕业（含 2027/3/31 前预计）或外国 16 年学校教育等；个别入学资格审查材料 2026/5/13 截止（非独立出願，已截止）；同一次入试不能并报研究科内两个以上専攻；可申请 2026年10月早期入学，但需新办在留资格的外国籍考生研究科强烈推荐 2027年4月入学。
- 要提前准备的书类：书类选考课题解答（専攻模板）、TOEFL iBT 送分、安全保障输出管理检查表（外国籍、双重国籍或最终学历为外国机构者，在出願系统填写）；日文、英文以外的证明须附日译或英译。
- 出願：只能通过 WEB 出願系统上传 PDF，提交后不能修改；检定料 30,000 日元（银行汇款、便利店、Pay-easy 或信用卡，手续费自付；国费留学生免缴）。
