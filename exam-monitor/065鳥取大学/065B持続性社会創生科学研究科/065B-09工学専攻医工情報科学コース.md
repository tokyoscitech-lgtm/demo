## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 推荐·一般入试：
  - 出願时提交 TOEIC 成绩证明原件或打印的数字公式认定证，不另设英语笔试；可用 TOEIC 公开测试、TOEIC-IP（含カレッジTOEIC），线上版不受理；须为出願开始日前 3 年以内受验；出願后可在第1个考试科目开始前在考场替换为更高分数。
  - 一般入试 TOEIC 配点随志望領域：機械宇宙工学 200（满分 600）、情報エレクトロニクス 100（满分 400）、化学バイオ 200（满分 900）、社会システム土木 100（满分 500）。
- 外国人留学生特别入试：不收英语成绩，也不考英语。

#### 日本語要件
- 推荐·一般入试：要项没有要求提交日语成绩。
- 外国人留学生特别入试：出願时须提交日语教师等出具的日语能力证明书（无所定样式）；要项写明授课大多用日语，强烈希望具备「日本語教育の参照枠」B2 以上的日语能力。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |

| 機械宇宙工学領域：数学（200分） | 线性代数、微积分、常微分方程、向量解析、傅里叶解析、复变函数 | 9:00–11:00，120分钟 |
| 機械宇宙工学領域：機械物理（200分） | 机械工学所用基础物理：质点系、刚体、弹性体、振动、流体、热 | 12:30–14:30，120分钟 |
| 情報エレクトロニクス領域：数学（200分） | 微分积分、线性代数 | 9:00–11:00，120分钟 |
| 化学バイオ領域：専門（每组 300分，选2组） | 有机化学·分析化学、无机化学·物理化学、微生物学·分子生物学、生化学·构造生物学 4 组中选 2 组，出願时在志願票上选定；须带关数电卓 | 9:00–12:00，180分钟 |
| 社会システム土木領域：専門（200分） | 土木工学（构造力学、混凝土构造学、水理学、土质力学）和社会经营工学（经营科学、环境工学、防灾工学、地域都市计划、经济学）中选 1 科目；须带关数电卓 | 9:00–11:00，120分钟 |

### 口述試験 / 面接
- **官方形式**：推荐入试：面接（含口头试问），按研究实绩和研究计划质疑应答，从在本研究科开展教育研究所需素质的角度评价，与出願书类合计总分排序判定；一般入试：笔试后面接，情報エレクトロニクス·化学バイオ·社会システム土木領域各 100 分，機械宇宙工学領域只判合否；外国人留学生特别入试：Oral Examination（时间同一般入试）。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：医工情報科学コース 18名（推荐·一般·外国人留学生特别入试合计，不按領域和区分分配；留学生特别入试各領域「a few」）。
- 出願资格：大学毕业（含2027年3月预计）或外国16年学校教育等；资格(9)(10)须先经个别出願资格审查（10/26–10/29 已截止，11/17 寄出结果，非独立出願）；推荐入试限日本的大学（学校教育法第83条）或高专专攻科毕业（含预计）、成绩人品优秀且合格后确约入学；外国人留学生特别入试限非日本国籍；志望領域只能选 1 个。
- 要提前准备的书类：一般入试须志望理由书（A4 约2页，任意格式，写志望动机、入学后研究计划、修了后抱负）和 TOEIC 成绩证明原件；推荐入试改交学科长或指导教员出具并密封的推荐书（拿不到可交自我推荐书）；外国人留学生特别入试须日语能力证明书，成绩证明由毕业学校密封。
- 出願：持参或書留邮寄到工学部教務係，期间内必达，信封朱书「大学院持続性社会創生科学研究科博士前期課程工学専攻出願書類等在中」；检定料 30,000 日元，用大学指定振込用纸在日本的银行或邮局窗口汇款（不能用 ATM），推荐 10/22–10/29、一般和留学生 11/20–12/3。

- 咨询：工学部教務係（G 栋 1 楼，平日 8:30–17:15，旧版记录），Tel 0857-31-5186，en-kyoumu@ml.adm.tottori-u.ac.jp；外国人留学生特别入试的咨询也是同一窗口；纸质要项可寄角形2号回邮信封（贴 320 日元邮票）向工学部教務係（〒680-8552 鳥取市湖山町南4丁目101番地）索取。
