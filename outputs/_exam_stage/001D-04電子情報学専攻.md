## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 须提交 TOEFL iBT 的官方成绩（含 Home Edition），修士出願者全员都要交，英语母语者也不例外；研究科和専攻都不另设英语笔试。
- 送分方式：由 ETS 直接送到研究科。Institution Name 为 University of Tokyo IS&T，Institution Code 8445，Department Code 99。送到别的代码的，研究科查不到成绩。出願时还要在 WEB 出願系统里填考试日和 Appointment Number。
- 期限：成绩须在出願时已经取得；ETS 的成绩数据须在 2026/6/30（周二）前到达研究科（已截止）。
- 有效期：2024/9/1 起到出願截止日之间受检的成绩。
- 不受理：MyBest scores 不采用，考生自己手里的 Test Taker Score Report 不能代替官方送分；其他英语考试一律不收。
- 没有有效成绩就不能完成出願；成绩被判无效的，失去笔试和口述的受験资格。出願后原则上不能更换成绩。
- 官方没有规定最低分，也没有公布英语的配点和换算方法。

### 日本語要件
- 要项和専攻案内书都没有要求提交日语成绩，也没有关于日语能力的条文。
- 过去问以日文版和英文版两种形式公开；研究计划书可以用日文或英文写。作答语言和口述使用的语言，案内书没有写明。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 一般教育科目（数学）（150分钟，配点官方未公布） | 研究科共通题。线性代数、解析（微分积分、常微分方程等）、概率·统计三个领域各1题，3题全答 | 2027修士募集要项／过去问页 |
| 専門科目（150分钟，配点官方未公布） | 从电气电子电路、计算机体系结构、逻辑电路、算法与数据结构、最优化·机器学习、信息通信、信号处理、信息论这8个领域里出5题，选3题作答 | 2027専攻入试案内书 |

- 选拔分三步：书类选考（成绩证明、TOEFL、研究计划书、推薦書等）→ 笔试（数学＋専門科目）→ 口述。只有书类选考合格者才能参加笔试；口述对象再按数学和専門科目的成绩选出。各项的配点和综合判定的权重，官方没有公布。
- 可带物品、迟到处理等考场规则不在案内书里，随受験票和会场考试须知通知。
- 题目倾向（体验记，非官方）：5题对应的领域每年会有变动，考生一般准备4个左右自己学过的领域，当天挑3题；计算机体系结构常见缓存、有限状态机，算法题会结合具体程序，电路题有时被控制类内容替代（仅1人提及，2020年度冬入试）。
- 配点的说法（体验记，非官方，仅1人提及，2020年度冬入试的成绩开示）：英语120、数学300、専門300、面试100。现行配点是否相同无法确认。

### 口述試験 / 面接
- **官方形式**：夏入试在线上进行，只面向按笔试成绩选出的人。内容是针对笔试答卷的提问、目前的研究题目、进入大学院后的打算等。每人的时长、使用语言、配点，案内书没有写；具体做法另行通知。
- **実際に聞かれた内容**：没有找到近年本専攻修士口述的公开体验记（一篇 2024年度入学的合格记把口述部分放在收费段落里）。相邻的工学系研究科電気系工学専攻（教员有重合，但不是同一场考试）的体验记提到：面试官5人，问志望动机和毕业后的去向、选研究室的理由、毕业研究的新颖性和进展、为什么选那几道题、请当场解释笔试里的某个公式（仅1人提及，仅供参考）。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：夏入试 60 名（2027年度修士募集要项）。本専攻修士没有冬入试。
- 出願资格：日本的大学毕业或 2027年3月31日前预计毕业；在外国完成16年学校教育；在外国取得相当于学士的学位（修业3年以上，且该校受过官方评估）；文部科学大臣指定者；或经个别入学资格审查认定具有同等学力、2027年3月31日满22岁者等。
- 个别入学资格审查的材料截止日：夏入试为 2026/5/13（已截止）。
- 志望教员的填写规则：在 WEB 出願系统里填 10 名教员；不足 10 名的，视为可以接受任何教员。提交后原则上不能改顺位；顺位之间没有明显差别时可以在说明栏注明（例如“第3位到第10位相同”）。还可以从専攻给的清单里选最多3个志望研究领域（人工智能、元启发式、图像处理、自然语言处理、处理器架构、高性能计算、量子计算、通信·网络、IoT、数据库、用户界面、VR·AR、信息安全），也可以不选。
- 出願书类（研究科共通）：入学願書（系统内填写）、证件照（jpeg，出願前3个月内拍摄）、出身大学的成绩证明书、毕业证明书或预计毕业证明书、TOEFL 成绩、检定料支付证明、安全保障出口管理检查表（外国籍者等）。全部扫描成 PDF 上传；纸质原件在办入学手续时提交。
- 専攻独有的书类：①研究计划书，全员提交，用専攻的 2027 版样式；第1–3项（研究题目、姓名、入学目的）A4 1页以内，第4–6项（研究计划、参考文献、其他特记事项）A4 3页以内，字号 11pt 以上，引用他人文献要列出处，可用日文或英文。②推薦書（业绩评价书），用専攻的 2027 版样式，推荐人签名或盖章后由推荐人本人上传到指定网站，截止 2026/6/11（周四）23:59（已截止）；推荐人不一定是指导教员，了解本人的人即可。
- 出願方式：只有 WEB 出願，没有邮寄和窗口受理。书类不齐不受理，提交后不能更改。
- 检定料 30,000 日元，可用银行转账、便利店、Pay-easy、信用卡支付，手续费自付，缴后不退；日本政府（文部科学省）奖学金留学生免缴。
- 并愿限制：同一期只能报一个専攻。夏入试合格者不能再报同年度的冬入试。
- 外国籍者须在入学手续前取得可以在学的在留资格；安全保障出口管理的审查可能使入学许可推迟或受限。在职者要交所属机构负责人的同意书。
- 入学料 282,000 日元，授業料 半年 267,900 日元（年 535,800 日元），均为预定额；日本政府奖学金留学生免缴。
- 受験票用邮件发送（夏入试到 2026/7/17 17:00 仍没收到的要联系入试担当）。考试的变更通知发在带密码的専攻入试网站和 WEB 出願系统里，要随时查看。
- 咨询窗口：専攻入试事务室（工学部2号館4楼電気系事務室内），ice-admission@ee.t.u-tokyo.ac.jp，Tel 03-5841-6712；研究科入试担当，johoriko.t@gs.mail.u-tokyo.ac.jp，Tel 03-5841-7926（平日 9:00–17:00），地址 〒113-8656 東京都文京区本郷7-3-1。
- 成绩开示：要项和案内书里没有找到相关说明。
