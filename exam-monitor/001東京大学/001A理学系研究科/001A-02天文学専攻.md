## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 8月入试：提交 TOEFL iBT、TOEFL iBT Home Edition、TOEIC Listening & Reading 公開テスト三者之一的正式成绩，只能登记 1 个成绩。考场不再进行英语考试。
- 提交方式有两步，都要在出願截止 2026/6/23（周二）15:00 前完成：①在考试机构网站办理向本専攻送分——TOEFL 的机构代码（DI コード）为 B996，Department 代码不用填；TOEIC 的申请代码为 00027409；②在研究科 WEB 出願系统登记考试日和分数并上传 PDF——TOEFL 传 Test Taker Score Report，TOEIC 传デジタル公式認定証。
- 有效期：考试日在 2024/10/1 以后的成绩。TOEFL 的分数按考试日登记：2026/1/21 之前考的填 0–120，2026/1/21 以后考的填 1–6。
- 不受理：在日本国外考的 TOEIC、TOEFL 的 MyBest スコア、2024/10/1 之前的成绩。TOEIC IP、TOEFL ITP、IELTS 不在可提交的种类之内。
- 最低分、换算方法、配点，以及没交成绩怎么处理，専攻的说明里都没有写。専攻提醒考试可能因设备故障重考或延迟出分，要留出余量。
- 变更点：上一年度（2026年度入试）为止是在考场考 TOEFL ITP，2027年度入试起改为事先提交上述成绩。

### 日本語要件
- 専攻入学案内和専攻网站没有要求提交日语成绩（JLPT 等）；研究科募集要项的 PDF 未能读取，其中对日语的规定未获取到。
- 试题语言和可用的作答语言，専攻公开资料里没有写。入学后有留学生在场的讲义基本用英语进行。

### 口述試験 / 面接
- **官方形式**：线上进行，对象是第一段階選抜通过者。第1天由第1希望教员所在的组（A–D）考，第2天视需要由其他组的教员考。内容是考察从事天文学研究所需的思考能力。配点、每人时长、使用语言官方没有公布。不能参加指定时间段的，须在第一段階发表次日（今年为 8/25（周二））之前联系専攻的紧急联络处。

## 📝 详细信息
### 出願資格 / 定員
- 8月入试的募集人员为 23 名；専攻注明根据考试成绩，入学许可人数可能多于或少于这个数。本年度没有冬季/第2次募集。
- 出願资格的具体条目写在研究科募集要项里，该 PDF 未能读取，未获取到。
- 指导教员的填写规则：教员分 A（理论）、B（光赤外·银河）、C（电波·毫米波）、D（重力波·太阳·观测卫星等）四组，各组接收大致固定的人数（具体人数未公布），每位教员原则上最多接收 1 名。志望調書里最多可填到第10希望，第1希望必填，每位教员要写上所属组名。
- 専攻独有的提交物是「志望調書」，与入学願書一起以 PDF 上传到 WEB 出願系统，样式（Word）在専攻网站下载。第1部分是志望指导教员（开头写姓名和邮箱）；第2部分是志望动机，写入学后想做的研究领域和内容，12pt、A4 1 页以内，可以用图，样式里的 2 行说明文字要删掉。书写语言没有指定。
- 其他出願书类按研究科的「提出書類確認一覧表」准备；证件照须为未经修改的本人照片，否则可能失格。
- 出願方式：只能通过研究科 WEB 出願系统，截止为最后一天 15:00（日本时间）。
- 检定料及支付方式、入学料、授業料：写在研究科募集要项里，未获取到。
- 合格后：入学許可通知書在マイページ公开，入学手续的通知发到願書登记的邮箱，不邮寄纸质材料；指导教员等接收信息以入学許可通知書为准。放弃入学要提交入学辞退届。
- 咨询窗口：天文学専攻（本郷，东京都文京区本郷7-3-1，Tel 03-5841-4251），専攻网站设有咨询页 https://www.astron.s.u-tokyo.ac.jp/contacts/ ；入学手续方面找理学系研究科学務課大学院担当。专门的入试咨询邮箱官方页面没有列出。
