## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各分野相同：不另设英语笔试，用外部成绩评价；出願时提交 TOEIC L&R 或 TOEFL iBT（含 Home Edition）之一，只认这两种。
- TOEIC：在申请网站向机构代码 00030521 送分，并交「デジタル公式認定証」PDF 打印件；两者不齐时交公式认定证原件和复印件（核对后退还）。
- TOEFL iBT：在 My TOEFL Home 向机构代码 G065 送分，并交 Test Taker Score Report 打印件。
- 成绩须为考试日往前4年以内受检。
- 变更点：2025年度追加募集只收 TOEFL iBT；2026年度起 TOEIC L&R 也可以，2027年度沿用。

#### 日本語要件
- 外国大学等毕业（含修了）的外国人须提交 JLPT N1 或 EJU（日本語）的成绩通知书复印件，考试当天带原件；日本国内大学毕业的外国人不需要。

- **官方形式**：8月入试：面接（各分野相同），评价入学目的与将来志向的热情和态度、科学思维和逻辑表达能力；用様式6在对面（保健学科中校舎）和 Zoom 中选一，线上的接续测试和开始时间另行邮件通知；开始时刻可能按出願人数调整。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：20名（看護学、検査技術科学、理学・作業療法学3分野合计，不按分野分配）；追加募集人数未公布（2025年度第3次募集为若干名）。
- 出願资格：4年制大学毕业或2027年3月预计、外国16年学校教育修了等(1)–(7)；(8)–(13)（飞跃入学、个别审查认定且2027/3/31前满22岁、大学在学3年以上成绩优秀、外国15年教育等）须先向医学部大学院係咨询并受入学资格审查（2026/6/8–6/12 必达，6/26 寄出结果，已结束，非独立出願）。看護学分野授修士（看護学），検査技術科学分野和理学・作業療法学分野授修士（保健学）。
- 要提前准备的书类：受験承諾書（様式3，事先联系志望分野·領域教员并由其填写）、志望理由書（様式2，写志望理由和入学后研究志向）、外国人留学生申請書（様式5，外国人）、受験及び修学承諾書（様式4，入学后继续在职者，由所属长填写）、面接試験方法選択票（様式6）、TOEIC/TOEFL 送分及打印件、JLPT N1 或 EJU（日本語）成绩复印件（外国大学毕业的外国人）。
- 出願：先在网上出願站登录并付检定料 30,000 日元＋系统使用费 900 日元（信用卡等），再把书类装入角形2号信封用简易书留速达寄送或窗口提交（平日 9:00–17:00），期限内必达；只在网上登录不算完成出願，受験票自行打印。
- 并愿：2027年度保健学専攻要项没有说明跨分野或与医科学専攻并愿的规则；本专攻只设一种选拔，不另设社会人入试或外国人留学生特别选拔。
- 咨询：信州大学大学院医学系研究科入試事務室（医学部大学院係），〒390-8621 松本市旭3-1-1，Tel 0263-37-3376（直通），Fax 0263-37-3080，mdaigak@shinshu-u.ac.jp；合否不接受电话或邮件询问。
