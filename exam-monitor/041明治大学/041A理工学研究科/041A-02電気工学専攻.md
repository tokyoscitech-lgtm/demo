## 🎯 入試内容（考什么）

### 語学 / 英語要件
- Ⅰ期、Ⅱ期相同：不设英语笔试，提交 TOEIC L&R 或 TOEFL iBT 的成绩，换算成「英语」的得分。要项没有写明英语一科在总分里占多少分。
- 换算方法：TOEIC L&R 730 分以上按满分、230 分以下按 0 分；TOEFL iBT 2026/1/20 以前受检的 80 分按满分、25 分以下按 0 分，2026/1/21 以后受检的（新分制）4.5 按满分、2 以下按 0 分；中间按比例换算。
- TOEIC 提交 Official Score Certificate（公式认定证）原件或数字认定证的打印件；TOEFL iBT 必须由 ETS 直送，机构代码 5132，本専攻的 Department Code 为 66。
- 有效期：以出願截止日为基准，过去 2 年以内受检的成绩有效。成绩上的姓名、出生日期等与出願信息不一致，或成绩单上没有本人照片的，英语按 0 分处理。
- 不受理：TOEFL iBT Home Edition、MyBest スコア；TOEFL 只认 iBT；雅思成绩只有建築·都市学専攻国際建築都市デザイン系可以用，本専攻不受理。
- 成绩必须在出願期间内送到；赶不上的，英语按 0 分处理。
- 变更点：从 2026 年度秋季入试和 2027 年度Ⅰ期起取消了考试当天提交成绩的做法；本専攻原来就使用外部成绩。

### 日本語要件
- 要项没有要求提交日语成绩（JLPT、日本留学試験等都没有提及）。外国人留学生入学試験（A 方式）与一般入学試験同一天、同样的科目在生田キャンパス当面考试；出願书类用日语或英语填写（外国大学的证明书须为日文或英文或附认证译文），要项没有写笔试能否用英文作答。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 基礎科目·専門科目（200分，120分钟，9:00–11:00） | 「電気磁気学」2 题＋「電気回路」2 题，共 4 题全部作答（没有选答）；要项没有公布每题配点。Ⅰ期、Ⅱ期相同 | 2027募集要项 |
| 飛び入学試験（仅Ⅱ期，2027/2/22） | 选拔方法为外部英语成绩、口头试问和书类选考；要项写明飛び入学只有情報科学専攻考笔试，本専攻的飛び入学不考笔试 | 2027募集要项 |

- 合否判定：笔试（200分）、外部英语成绩、口头试问（100分）加书类选考综合判定。要项没有公布英语的满分和合格最低分。
- 社会人特別入学試験、外国人留学生入学試験（A 方式）的选拔方法与一般入学試験相同，没有免考笔试的规定。
- 题目倾向（体验记，非官方）：没有找到本専攻的考生体验记；可以参考 Web 公开的 2026年度Ⅰ期·Ⅱ期试题与解答、窗口阅览的过去 3 年试题和官方サンプル問題。

### 口述試験 / 面接
- **官方形式**：Ⅰ期、Ⅱ期都有口头试问，配点 100 分，笔试当天下午在生田キャンパス进行，开始时刻见随受験票寄来的通知；迟到就不能受验。要项没有写时长和提问内容，也没有要求做研究发表；出願时提交的研究計画書（A4 1 页）写入学后的研究计划和毕业后去向。
- **実際に聞かれた内容**：没有找到本専攻的体验记（截至 2026-10-17）。

### 出願資格 / 定員
- 募集人员：博士前期課程 電気工学専攻入学定员 82 名。这是本年度全部入试（学内選考、Ⅰ期、Ⅱ期、飛び入学）的合计，要项没有给出各轮次各自的人数。
- 入试区分：一般入学試験、社会人特別入学試験、外国人留学生入学試験（A 方式）在Ⅰ期和Ⅱ期都实施；飛び入学試験只在Ⅱ期实施，对象是本専攻和情報科学専攻；外国人留学生 B 方式（只做书类选考）只有建築·都市学専攻国際建築都市デザイン系实施。学内選考（出願 2026/6/1–6/3，考试 7/4 口头试问，已结束）只面向明治大学理工学部 4 年级学生。前期课程的秋季（9 月）入学只有応用化学専攻，本専攻没有。
- 飛び入学試験：出願时在大学学科 3 年级在读、所属学科成绩前 3% 以内，并且入学资格同样要求成绩前 3% 以内；出願时交 2 年级末为止的成绩证明书和推荐书，入学前还须提交学部 3 年级为止的成绩证明书以确认仍在前 3% 以内；并须先受出願资格审查（Ⅱ期 2026/10/15 截止，已过）。要项写明飛び入学面向强烈希望升读博士後期課程的人。
