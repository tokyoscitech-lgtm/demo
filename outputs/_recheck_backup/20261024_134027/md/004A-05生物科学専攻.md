## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 8月入试：没有英语笔试，出願时提交 TOEFL iBT 或 TOEIC Listening & Reading 的成绩，计入综合判定。英语的配点和换算成多少分，要项没有写；要项只给了 TOEFL 与 TOEIC 之间的对照表，没有最低分要求。
- 对照表（要项称为“换算的大致标准”）：TOEFL iBT 新评分 6＝旧评分 102 以上＝TOEIC 900 以上；5＝88–101＝800–899；4＝76–87＝700–799；3＝62–75＝600–699；2.5＝52–61＝500–599；2＝40–51＝400–499；再往下每档约差 100 分 TOEIC。
- 成绩有效期：2024/7/1 以后受检的成绩。考过多次的只交自认为最有利的1份。
- TOEFL：只认 iBT（含 Home Edition、Special Home Edition），只用 Test Date Scores。必须同时在 ETS 账户里向理学研究科电子送分（Institution Code G112，2026/7/9 截止）并提交 Test Taker Score Report 或 Examinee Score Record 的 PDF 打印件；只交 PDF 不受理。
- TOEIC：提交纸质的公式认定证（Official Score Certificate，L&R）原件，数字版认定证不受理。原则上要公开考试的认定证；实在交不出时，本専攻可以交 TOEIC IP 的 Score Report（这一点和其他専攻不同）。TOEIC Bridge 不受理。没有照片的成绩单不受理。
- 出願时来不及取得成绩的可以出願，但英语按 0 分计；出願后不能换成新的成绩单。
- 特別選抜：同样提交 TOEFL 或 TOEIC 成绩（2024/6/1 以后受检），没有最低分。
- 第2次募集：研究科预告出願必须提交 TOEFL iBT（含 Home Edition）或 TOEIC 公开考试成绩（IP 无效），有效期从出願期间首日所在月份往前推2年的同月1日算起；细节以新要项为准。
- 研究科共通规定里“数学専攻可用外部成绩免考英语笔试”只适用于数学専攻，不适用于本専攻。

### 日本語要件
- 要项没有要求提交日语成绩（JLPT、EJU 等）。过去问的题面只有日文，没有英文并记；要项没有写可用的作答语言。研究分野等希望調書只收黑色笔手写的楷书，不能用 Word 录入。

- 合否判定（8月入试）：综合笔试、口头试问、学业成绩证明书、TOEFL 或 TOEIC 成绩、研究分野等希望調書来决定。各项配点和合格线官方没有公布。
- 题目倾向（据公开的过去问归纳）：选答题里有一题偏物理化学和生物物理（分子间相互作用、热力学、蛋白质折叠），化学、物理背景的考生可以选；官方每年附解答例。
- 题目倾向（体验记，非官方）：大学院入试塾 INSHI 登有本専攻合格者的对策文章（选答科目与参考书），正文没能读取，内容未核实。

### 口述試験 / 面接
- **官方形式**：8月入试在笔试次日（2026/8/2 13:30–17:00 左右）进行口头试问，对象是当天 10:00 掲示的有资格者；専攻页说明口头试问看逻辑思考力和研究意愿。配点、每人时长、使用语言官方没有公布。特別選抜的口头试问问自己推薦书的内容和与研究有关的基础知识。第2次募集是用 PowerPoint 发表毕业研究后接受口头试问（发表时长上一年度要项没有写）。
- **実際に聞かれた内容**：没有找到本専攻口头试问的体验记。

- 特別選抜的资格限制：自己推薦只限大阪大学理学部生物科学科 2027年3月预计毕业者（院试GPA 2.60/4.00 以上）；奨励面向日本国内其他大学 2027年3月预计毕业者和高専専攻科2年生（院试GPA 2.50/3.00 以上）。外国大学的毕业生不能走这条路线。

- 研究分野等希望調書（本専攻用纸）：写志望本専攻的理由、希望配属的研究室名及理由（可写多个，要标希望顺序）、毕业论文或毕业计划的题目。只收黑色笔手写。出願手续后不能更改记载事项。
- 出願书类：入学願書、学业成绩证明书、毕业（预定）证明书（须为带公章的日文或英文证明）、TOEFL 或 TOEIC 成绩证明、研究分野等希望調書、受験者写真票和受験票（照片纵4cm×横3cm，3个月内拍摄）、检定料收纳证明书（PDF 打印成 A4）、レターパックライト 2 枚（海外出願者不需要）、在留卡正反面复印件或住民票或护照复印件（外国人）、国费留学生证明书（仅国费生）、出願书类核对表。全部用 A4 白纸单面打印，用黑色墨水或黑色圆珠笔填写（可擦笔不可）。
- 募集要项和願書没有印刷品，全部从研究科主页下载。出願方式为大学院係窗口提交或書留速達邮寄，没有网上出願。
- 检定料 30,000 日元，通过检定料缴纳系统支付（8月入试的缴纳期间为 2026/6/15–7/9），手续费自付。入学时为日本政府国费外国人留学生的不用缴。
- 外国籍且毕业于外国大学（含预计毕业）的人，要通过大学的アドミッション支援デスク（AAD）联系希望的指导教员，申请结果要 3 周到 1 个月，要留足时间。
- 安全保障出口管理：属于管制事项时，即使合格也可能不被允许入学，或教育研究内容受限。
- 8月入试合格者能否再报第2次募集，上一年度的第2次募集要项没有写；第2次募集写明成绩不够时即使名额未满也可能不录取。
