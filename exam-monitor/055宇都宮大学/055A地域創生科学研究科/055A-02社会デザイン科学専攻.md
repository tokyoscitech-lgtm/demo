## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 所有选拔区分都不考学校自己的外语笔试，用外部成绩换算。
- 英语：TOEIC L&R（公开考试或 IP 考试都可以，交公式认定证或成绩表原件，受理后退还）或 TOEFL iBT。TOEIC S&W、TOEIC Bridge 不认。
- TOEFL iBT 只认 ETS 直接寄到大学的 Official Score Report（宇都宫大学的代码 7976），只用 Test Date 成绩；出願时另附 Test Taker Score Report 的复印件。
- 有效期：上一年度第1期要求 2023年4月以后的成绩，今年的起算日以新要项为准。
- 国费外国人留学生、外国政府派遣留学生、JICA 留学生免学力检查。

### 日本語要件
- 外国人留学生特别选拔的外语可以在英语和日语中任选一种。日语用日本语能力试验（N1 或 N2 合格）或日本留学试验「日本語」的成绩。
- 日本留学试验只认入学考试日之前2年以内的成绩。
- 一般选拔只能用英语成绩。
