## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 必须提交 TOEIC L&R 或 TOEFL iBT（含 Home Edition）的成绩，须是考试日之前2年以内受检的。要项没有写最低分，成绩计入综合评价。
- 不认的成绩：TOEIC IP、TOEIC S&W、TOEIC Bridge、TOEFL ITP、TOEFL 的 My Best Score（只用 Test Date Score）。
- TOEIC：上传数字公式认定证（二维码要能读取），或上传纸质认定证并在考试当天交原件。
- TOEFL：上传 Test Taker Score Report 的 PDF 时，必须同时请 ETS 向金沢大学送分（Institution Code：G170），没办送分视为失格；上传邮寄版原件时，考试当天交原件。
- 出願期内来不及上传的，只要考试当天能交就可以出願；当天交不出则失格。
- 配点和换算方法官方未公布。

### 日本語要件
- 不要求 JLPT、EJU 等日语成绩。外国人留学生特别选拔在要项里明写“不问日语能力”。
- 小论文可用日文或英文写。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 笔试（各轮都不实施） | 夏入试、秋入试、冬入试都没有笔试；选拔材料是出願时提交的小论文2篇、口头发表、口述试验、成绩证明书和英语外部成绩，专门基础知识在口述试验里口头考 | 2027募集要项 |

- 配点官方未公布。合否按小论文、口头发表、口述试验的结果综合评价，重视本科阶段的基础专门知识和“创造综合知的意愿”，按一般、社会人、外国人留学生各区分的基准判定。
- 题目倾向（体验记，非官方）：没有找到体验记。

### 口述試験 / 面接
- **官方形式**：夏入试、秋入试、冬入试相同，都是口头发表 10 分钟以内＋口述试验 20 分钟以内，同一天进行；配点官方未公布。
- 口头发表：围绕出願时提交的小论文。发表用的资料在考试日2天前以 PDF 发到大学院係邮箱；考场电脑里会放好这份资料。为防故障，另带5份打印件（A4 纵向、每页2张幻灯片、双面、左上角装订）。
- 口述试验：就发表内容质疑，并就“接受希望的研究指导教员指导所需的专门分野基础内容”口头出题。具体的出题分野在受験票开放打印之后另行发送。
- 海外在住、考试当天难以来日的，出願时提出后可以用 Zoom、Webex 等线上应试，形式相同。
- 社会人特别选拔还会问实务经验的内容。
- **実際に聞かれた内容**：没有找到本専攻的考生体验记（截至 2026-10-06），实际问题未核实。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员为32名（一般选拔，夏入试·秋入试·冬入试三轮合计；要项原写 15 名并注明“正在构想增员”，研究科入试信息页注明改为 32 名）。社会人特别选拔和外国人留学生特别选拔各若干名。
- 各轮的事务日程：出願资格认定申请（资格⑥⑨⑩⑪者，PDF 邮件提交）夏入试 2026/5/25–5/29（已结束）、秋入试 2026/8/28–9/3（已结束）、冬入试 2026/11/30–12/4 16:30 截止；检定料支付期间 冬入试为 2026/12/7（周一）–12/18（周五）；受験票在 Web 出願系统自行打印，秋入试 2026/10/7（周三）9:00 起、冬入试 2027/1/13（周三）9:00 起；入学手续在 2027年3月中旬，用网上入学手续系统办理。Web 出願系统可在出願开始前1周起先登记信息。
- 外国人留学生特别选拔：没有日本国籍、且没有在日本取得学士学位的人。在日本的大学毕业的外国人走一般选拔。
- 社会人特别选拔：出願时在教育研究机构、官公厅、企业等在职，或到入学时有3年以上在职经验（含创业、个体经营、家务从事者），另交「社会经验概要」。
- 出願资格：大学毕业或2027/3/31前预计毕业、在外国完成16年学校教育等①–⑪项之一。以⑥（在外国3年以上课程取得相当于学士的学位）、⑨、⑩（大学3年在学、外国15年课程等）、⑪（个别入学资格审查）报考者，出願前须通过出願资格认定。
- 出願书类：证件照数据（3个月内，jpg 或 png）、出願確認票和宛名ラベル（从系统打印）、志願者調書（様式1，写明希望的研究指导教员）、成绩证明书、毕业（预计）证明书、小论文2篇、英语外部成绩。外国籍者交护照姓名页复印件，在日本的再交在留卡正反面复印件。外国学校的证明书须是日文或英文。
- 小论文：课题①「至今学过的内容·做过的研究（毕业研究等）」，课题②「入学后想做的研究内容·研究计划（含综合知创出的观点）」。每篇日文约 1,000 字或英文约 600 词，10.5 磅，含图在内不超过1页。
- 出願方式：只能 Web 出願。登记信息并缴费后，上传证件照和全部书类，再把书类原件邮寄（書留速達）或送到窗口，三步都完成才算出願。邮寄须在出願最后一天前到达；过期到达的，只有盖着“最后一天的前两天”国内邮戳的書留速達才受理。信息确认后不能更改。
- 海外在住、难以按期寄到的，缴检定料之前先联系大学院係，另行指示提交方法。
- 检定料 30,000 日元，另收 Web 出願系统服务费 990 日元；可用便利店、Pay-easy 的银行 ATM、信用卡、网银支付，不能在银行窗口缴。国费外国人留学生免缴。
- 提交地：〒920-1192 金沢市角間町 金沢大学融合系事務部学生課大学院係。
- 费用：入学料 282,000 日元，授業料 年 535,800 日元（均为预定额）。经大学申请在留资格认定证明书的留学生另缴手续费 20,000 日元。须加入学研災等学生保险。
- 经济支援：入学料·授業料免除制度；金沢大学对私费外国人留学生有独自的奖学制度。
- 在职入学者须提交所属长的同意书。以“预计毕业”合格者在入学手续时提交毕业证明书。
- 咨询：金沢大学融合系事務部学生課大学院係（角间校区南地区 自然科学本館1階），Tel 076-264-5971，s-yugo@adm.kanazawa-u.ac.jp。
- 学位为修士（学术）。课程设「变革先导」「价值设计」「信息创成」3个学修コア，选1个为主；高度信息专门特别项目为必修，多数科目含数据科学和数字技术的内容。
