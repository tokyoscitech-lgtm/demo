## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 学環要项的出願书类清单里列有「外部試験成績証明書（TOEFL、TOEIC 等）」，但英语怎么计分取决于指導教員所属的考试区分。
- 環境情報学府区分（人工環境専攻·情報環境専攻的教员）：不考英语笔试，用 TOEIC L&R（公开考试）、TOEFL iBT、IELTS 的成绩换算成外国語（英語）100 分；考试当天带带照片的成绩证明书原件提交，复印件和下载的 PDF 不行（TOEIC 国内受检可用带二维码的数字公式认定证打印件）；有效期为考试日前2年以内；TOEIC IP、TOEIC Bridge、TOEIC S&W、TOEFL ITP 不受理；TOEFL iBT 不用 My Best Score，交 Test Date Score 最高的一次；没有提交的判为不合格。换算公式与環境情報学府相同，例如 TOEIC 650＝75 分、IELTS 5.5＝75 分。
- 経済学専攻区分：学環要项的经济学专攻考试表里没有英语计分。経済学専攻自己的 2027 要项把 TOEIC L&R 550 分以上或 TOEFL iBT（2年以内）的成绩列为「该当者」提交书类，TOEFL 须由 ETS 直送（Institution Code 0410，2026/8/3 必达）；对经由学環报考的人是否必交、如何计分，要项没有写清，未核实。
- 経営学専攻区分：经营学専攻自己的要项要求提交 TOEFL iBT（含 Home Edition）或 TOEIC L&R 的正式成绩（口述日前2年以内），TOEFL 须 ETS 直送；TOEIC S&W、Bridge、IP 不受理；没有写最低分。学環要项的经营学专攻考试表里没有提英语，是否适用于学環考生未核实。
- 社会人特別選抜：要项没有英语考试，也没有英语计分的记载。

### 日本語要件
- 外国人出願者如果志望経済学専攻的教员，必须已通过日本語能力試験 N1 或 N2，提交日本国際教育支援協会出具的「認定結果及び成績に関する証明書」原件（复印件不行）；按出願资格（1）出願、且在日本以日语授课的大学毕业的人免交。一般選抜和社会人特別選抜都适用。
- 志望経営学専攻或環境情報学府教员的人，要项没有要求提交日语成绩。
- 研究（希望）計画書必须用日语写（1,000 字以内）。经济学专攻笔试用日语出题、外国人可用英语作答；经营学专攻笔试必须用日语作答；经济学专攻的面试原则上用日语。

- 一般選抜：考生参加志望指導教員所属学府·専攻的选拔，按笔试、口述试验和出願书类综合判定；只要缺考任何一科就不能合格。環境情報学府区分是専門科目 200＋英語 100＋口述 200；経済学·経営学区分要项没有公布配点和合格线。
- 本テーマ的教员分属経済学、経営学、国際経済法学、人工環境、情報環境五个専攻，所以同一テーマ的考生考的科目可能完全不同，选教员就等于选考试科目。
- 特別選抜·女子特別選抜不合格或没有受験资格的人，不用另办手续即可再参加一般選抜。
- 题目倾向（体验记，非官方）：没有找到报考本テーマ的考生写的体验记，出题倾向只能参考各学府的过去问。

### 口述試験 / 面接
- **官方形式**：所有选拔区分都有口述试验。一般選抜按志望教员所属学府进行：経済学専攻原则上用日语面试（2026/9/11，预备日 9/14）；経営学専攻第2次選抜（只限第1次合格者，2026/9/4 10:00 起）根据出願书类问以往学业、研究计划的可行性和与专攻的契合度，用日语回答；環境情報学府是与希望研究领域相关的口述试验（200 分）。特別選抜在 2026/7/5 实施，内容和语言要项没有写。社会人特別選抜在 2026/12/5 实施，就学习意愿、研究业绩、研究计划等进行问答，与出願书类综合判定，没有公布配点和时长。
- **実際に聞かれた内容**：没有找到本テーマ考生公开的口述试验记录。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：要项按研究テーマ列出人数，但本テーマ那一行在 PDF 文本里只有选拔区分的○标记，没能读出具体数字（未核实）；学環整体的募集人员近三年都是 42 名（大学公布的实施状况），含特別選抜合格者。社会人特別選抜为若干名。女子特別選抜只设在「集積エレクトロニクスと社会展開」，本テーマ不适用。
- 一般選抜出願资格：大学毕业（含 2027/3 预计毕业）、学位授与机构授予学士、外国 16 年学校教育修完、専修学校専門課程修了、个别资格审查认定且入学前满 22 岁等；按（5）の2 和（8）出願的人须先做入学资格审查（2026/5/13–5/14 必达，结果 5/19 邮件通知，已结束）。
- 特別選抜：面向日本大学的应届毕业生，须有在读大学推荐，并满足3年级结束时成绩在学科前 1/3 以内，或已修学分中 80 分以上的评价占一半以上；合格后必须入学。
- 社会人特別選抜：在满足基础资格的同时，须满足（A）大学毕业后到 2027/3/31 在同一单位作为正式职员工作原则上2年以上，（B）在职派遣并能提交所属长推荐书，（C）学環认定的社会人（需入学资格审查）之一；合格后必须入学。长期履修制度只对社会人特別選抜合格者开放，希望利用的要在出願前告诉指導教員。
- 出願书类：送付内訳書、入学願書·受験票（4cm×3cm 照片2张，3个月内拍摄、不得用 App 修饰）、研究（希望）計画書（日语 1,000 字以内，须写研究主题、具体内容、如何实现文理融合·异领域融合、对 Society 5.0 的贡献）、毕业（预计）证明书、成绩证明书、检定料缴纳证明、外部考试成绩证明书、在留卡或护照复印件；外国人留学生另交修学年数调书；志望经济学专攻教员的外国人交 JLPT 证明书；特別選抜另交出願资格证明书、推荐书、志望理由书（A4 1页）和入学确约书。
- 出願方式：只收邮寄，用一般書留、簡易書留、特定記録等可查询投递的方式，角形2号以上信封贴学環的地址标签，期间内必达；海外用 EMS 等可追踪方式。没有网上出願，也没有窗口受理。
- 检定料 30,000 日元：国内在 7-Eleven、Lawson、Ministop、FamilyMart 店内终端支付（社会人特別選抜还可用 e-apply 信用卡），海外用 Flywire；手续费自付，原则上不退。
- 只能报一个研究テーマ、一位教员，不能同时报多个；特別選抜和女子特別選抜不能并愿。被录取后也可能因选拔结果分到非第一志望的教员。
- 外国人留学生的接收按《外国為替及び外国貿易法》严格审查，希望的研究可能受限，出願前须和志望教员商量；全体入学者入学时要提交遵守誓约书。
- 入学料 282,000 日元，授業料半期 267,900 日元（年额 535,800 日元），均为现行额；入学手续期间 2027/3/8（周一）–3/12（周五），书类预定 2027年1月下旬寄出。
- 有在职者的「教育方法の特例」（可利用夜间等时段上课），但两年中原则上有1年要全日到校。
