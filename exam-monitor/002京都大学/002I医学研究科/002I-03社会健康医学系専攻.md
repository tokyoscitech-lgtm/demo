## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 不另设英语笔试，出願时提交 TOEFL iBT 或 TOEIC L&R 成绩，计入综合判定；英语母语者也须提交。
- 成绩须为出願截止日前2年以内受检；出願后不能更换。
- TOEFL iBT：由 ETS 直送（DI 代码 9501）并附 Test Taker Score Report 打印件，或交 Test Taker Score Report 原件（自己打印的 PDF 不算原件）；采用 Test Date 成绩，不用 MyBest。
- TOEIC L&R：交数字公式认定证复印件；所在国家·地区不发数字认定证的，由考试机构直接寄 Official Score Certificate 原件。
- 不受理：TOEFL iBT Home Edition、TOEFL ITP、TOEIC IP、TOEIC S&W、TOEIC Speaking、TOEIC Bridge、IELTS。
- 正式成绩来不及：出願期内先交理由书和网上成绩打印件（TOEFL 须四项都已出分），考试前一天 17:00 前补交正式成绩，否则不能参加考试。
- 变更点：2027年度 TOEFL iBT 新增 ETS 直送方式；TOEIC 改为交数字公式认定证复印件（2026年度还可交纸质认定证原件）。

#### 日本語要件
- 要项没有要求提交日语成绩，也不设外国人留学生特别选拔，留学生与日本考生同场考试。
- 英文版要项写明：除部分课程外，本课程大部分课程用日语授课。
- 成绩证明和毕业证明须为日文或英文。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：34名（2年制 MPH、1年制 MPH、MCR、遺伝カウンセラー、臨床統計家育成各コース合计，不单列）；只有8月入试一轮。
- 出願资格：大学毕业（含2027年3月底前预计）或外国16年学校教育、外国3年以上课程取得学士相当学位等；外国大学毕业者资格拿不准的，先经 AAO 后在 2026/6/1 17:00 前邮件申请出願资格确认（非独立出願），资格9·10须 2026/6/8 17:00 必达申请出願资格审查（非独立出願）；社会人特別選抜须出願时常勤累计1年以上且在职，1年制 MPH 须6年制医齿兽药毕业或修士·専門職修了且有2年以上实务经验，MCR 限临床经验2年以上或完成卒后临床研修的医师·牙医；1年制 MPH、MCR 各自只能与2年制 MPH 并愿，其余不能并愿。
- 要提前准备的书类：志望理由书（所定用纸，不能另附纸）、TOEFL/TOEIC 成绩；社会人特別選抜加在职期间证明书和受験許可証（入学后继续在职者）；1年制 MPH 加志望分野教授推荐书、所属机构上司推荐书、研究活动经历（A4 约2页）、在职期间证明书；MCR 加在职期间证明书、执照复印件和研究計画書（所定用纸）。
- 出願：WEB出願系统登记（上传照片，渡日前的留学生另传护照页）并缴检定料 30,000 日元＋手续费（信用卡、便利店、Pay-easy），书类装角形2号信封以簡易書留速達邮寄或窗口提交，期限内必达。
