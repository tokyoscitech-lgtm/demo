## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各日程相同：不另设英语笔试，用 TOEFL iBT（含 Home Edition）成绩评价。
- 送分：受检后向 ETS 申请把 Institutional (Official) Score Report 送到研究科（DI code 1113），送到其他代码无效；出願时在 WEB 出願系统里填写 Appointment Number、受检日和分数，不必交 Test Taker Score Report。
- 有效受检期间（向 ETS 申请送分也须在此期间内完成）：A日程 2024/8/1–2026/6/13（已过）；B日程 2025/2/1–2026/11/15。
- 考过多次可以送多份，出願时只能指定其中一次。所属机构团体实施的 TOEFL ITP 不受理，MyBest Scores 不采用，其他英语成绩也不能代替。
- 要项没有规定最低分、换算方法和配点；TOEFL 是全员必交书类，本専攻没有免除规定。B日程的书类选考会用到 TOEFL 分数。

#### 日本語要件
- 要项和専攻案内都没有要求提交日语成绩（JLPT 等），外国人考生走一般选拔也不用交；研究科不设单独的外国人留学生特别选拔。
- A日程専門科目的试题日英并记，可用日语或英语作答；口述使用的语言官方没有写明。
- 从初等、中等教育起都在日语以外的语言环境中受教育的课程毕业（预定）者，出願前须接受出願对象审查：A日程截止 2026/5/7（已过），B日程截止 2026/10/7（已过）。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：A日程（2026年10月入学＋2027年4月入学）28名，B日程（2027年4月入学＋2027年10月入学）若干名（要项募集人员表本専攻只有这两格）；考试成绩不足时可能录不满。
- 出願资格：日本的大学毕业或 2027/3/31 前预计毕业；在外国完成 16 年学校教育；在外国取得相当于学士的学位（3 年以上课程，须经该国政府或相关机构评估）；文部科学大臣指定者；大学改革支援·学位授与機構授予学士学位者；经个别入学资格审查认定且 2027/3/31 满 22 岁者。个别入学资格审查申请截止：A日程 2026/5/7、B日程 2026/10/7（均已过）。
- 入学时期：A日程可选 2026年10月入学（限 2026年9月前毕业或预计毕业者）或 2027年4月入学；B日程可选 2027年4月或 2027年10月入学。在 WEB 出願系统的「入学時期」里选择，出願后不能更改。
- 志望填写：按「教員並びに専門分野一覧」最多填到第3志望，每个志望选专门分野和教员；第1到第3志望必须是不同专门分野的教员，没有第2、第3志望可以不填。一览会更新，出願前看最新版。
- 出願书类：入学願書（WEB 填写，上传 3 个月内的照片）、出身大学成绩证明书、毕业（预定）证明书（写明学位名和授予日）、检定料缴纳证明、国费留学生证明书（仅国费生）、TOEFL 成绩、専攻指定书类；证明书 PDF 上传，日语和英语以外的要附日译或英译，原件在入学手续时提交。
- 専攻指定书类：A日程没有；B日程交毕业论文研究（或代替物）的要旨，格式自由、A4 1 页以内，2027年1月底前用邮件发到 aeb-chief@ab.a.u-tokyo.ac.jp。
- 出願方式：只能通过 WEB 出願系统，受験票自己用 A4 纸打印，考试当天带上。没有纸质要项。
- 检定料 30,000 日元，银行汇款（邮储银行·邮局除外）、便利店、信用卡、Pay-easy 均可，手续费自付；缴纳期间 A日程 2026/4/13–6/23（已过），B日程 2026/10/5–11/25。国费留学生免缴；缴后不退。
- 并愿：同一日程只能报研究科的一个専攻。要项允许有资格的人 A、B 两个日程都报，本専攻案内没有另设限制。
- 外国人须在入学前取得可以就读大学院的在留资格；B日程合格后 4月入学的，合格发表到入学时间短，注意入境时间。
- 入学料 282,000 日元，授業料 年 535,800 日元（前期 267,900 日元），均为预定额；国费留学生免缴。入学许可通知：4月入学者 2027年2月下旬，3月上旬办手续；B日程 10月入学者 2027年9月上旬。
- 受験者心得以邮件发送：B日程 2027年1月上旬发出，到 2027/1/13 还没收到的要联系教務課。
- 咨询：出願手续问农学生命科学研究科教務課学生支援チーム大学院学生担当（〒113-8657 東京都文京区弥生1-1-1，Tel 03-5841-5010，daigakuin.a@gs.mail.u-tokyo.ac.jp）；専攻内容问井澤 毅 教授（Tel 03-5841-5063，takeshizawa@g.ecc.u-tokyo.ac.jp）或専攻主任邮箱 aeb-chief@ab.a.u-tokyo.ac.jp。
