## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 不另设英语笔试，用外部成绩评价。
- 一般入试：
  - 只收 TOEIC Listening & Reading Test，交 Digital 公式認定証打印件，须为出願截止前2年以内受验；有更新的成绩可在笔试时交给试验委员；提交后不退还。
- 推薦入学、社会人特別選抜：不收英语成绩。
- 外国人留学生入试：
  - 只收 TOEFL iBT（考场受验）或 TOEIC L&R 公开考试；Home Edition、TOEFL ITP、TOEIC IP 不受理。须为第二次選考出願截止前2年以内受验，2026/12/2（周三）前必达入試課。
  - TOEFL iBT 交 Test Taker Score Report 和已向大学直送（Institution Code 0438）的画面或邮件打印件；TOEIC 在日本考的交 Digital 公式認定証打印件，在国外考的交 Official Score Certificate 原件和考场证明。
  - 变更点：从2027年度起外国人留学生入试不再受理 TOEFL ITP 和 TOEIC IP（2026/4/6 通知）。

#### 日本語要件
- 一般入试、推薦入学、社会人特別選抜：要项没有要求提交日语成绩。
- 外国人留学生入试：
  - 第一次選考须交大学所定样式的「日本語能力認定書」，请日语教师、日本驻外使领馆人员或日语熟练者填写，不能用日语能力测试的证书代替。
  - 専門科目只用日语出题，面接也只用日语。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 専門科目 | 物理化学、無機及び分析化学、有機化学、化学工学各2题共8题，选6题作答；函数电卓由考场借出 | 10:00–13:00，180分钟 |
| 外国人留学生入试：専門科目 | 一般化学及与希望专攻分野相关的专门科目，日语出题 |  |

- 一般入试：出願书类、専門科目、TOEIC 成绩和面接综合判定。
- 推薦入学：书类审查和面接；社会人特別選抜：书类审查和口頭試問，没有笔试。
- 外国人留学生入试：第一次书类审查（本専攻须交参考資料）；第二次専門科目、外部英语成绩和面接综合判定。

### 口述試験 / 面接
- **官方形式**：一般入试：笔试次日面接；推薦入学：书类审查＋面接；外国人留学生入试：第二次選考面接，只用日语；社会人特別選抜：2027/1/7 13:30 起口頭試問。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：60名（専攻入学定员，含学内選考等2027年度全部入试）；推薦入学、社会人特別選抜、外国人留学生入试各若干名。
- 出願资格：大学毕业（含2027年3月预计）或外国16年学校教育等，资格⑹个别审查者须出願前咨询工学事務課；推薦入学须所属学部长或指导教员推荐、原则上2027年3月取得学士学位（或修完外国16年课程）；社会人特別選抜须入学时有1年以上企业等工作经历；外国人留学生入试限外国籍、没在日本读过4年本科、入学时能取得「留学」在留资格者，15年学制等须在出願开始1个月前交齐资格审查材料（非独立出願）；在日本读完本科的留学生不能报外国人留学生入试。
- 要提前准备的书类：一般入试为志望理由書（所定用纸，800字左右）和 TOEIC 成绩单；推薦入学为推薦書（所定用纸）和研究计划书（A4 1页，约1,000字，须含志望理由）；社会人特別選抜为志望理由书（A4 1页，约1,000字，写工作内容与研究的关系）；外国人留学生入试为日本語能力認定書、出身大学校长或指导教员的推荐信（所定用纸）、参考資料；国外居住者都要请希望指导教员填写「事前相談シート」。
- 出願：一般入试、推薦入学、社会人特別選抜简易书留·速达邮寄或窗口提交（工学事務課），邮戳有效（国外寄出须最后一天必达），须附レターパックライト2个，检定料 35,000 日元（银行窗口电汇或便利店）；外国人留学生入试只能邮寄（国外用 EMS 等可追踪方式），两次都必达，检定料第一次 18,000 日元＋第二次 17,000 日元。
- 并愿：一般入试可以并愿笔试日不同的専攻，工学研究科各専攻笔试都在 2026/8/1，同日笔试的不能并愿；推薦入学须合格后确定入学（専願）；外国人留学生入试只能报1个専攻；出願后不能变更研究科·専攻。
- 咨询：工学事務課（葛飾キャンパス共創棟2楼，〒125-8585 東京都葛飾区新宿6-3-1，Tel 03-5876-1571，窗口 9:00–12:00、14:00–16:00，周末节假日除外；k1_tus@admin.tus.ac.jp）；外国人留学生入试的出願手续问入試課（官网问询表单 https://faq.admissions.tus.ac.jp/hc/ja/requests/new）；需要考试特别照顾的，须在出願开始1个月前联系。
