## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 不另设英语笔试，用外部成绩评价；TOEFL iBT（含 Home Edition）、TOEIC L&R、IELTS Academic（含 Computer Delivered）三选一，願書上只能勾选一种。
- 冬季：
  - 有效期：2025/1/1 以后到出願截止前受检。
  - TOEFL iBT：由 ETS 直送官方成绩（Institution Code 0440，Department Code 99），2027/1/5（周二）前到达，成绩一般考后约两周可送；願書填 Appointment Number，以前寄过的也要重新申请。
  - TOEIC L&R：上传 Official Score Certificate（数字版或扫描 PDF）。IELTS：上传 Test Report Form 扫描件，或由 IELTS 机构直送（1/5 前到达）。来不及随出願提交的，事先联系学府，2027/1/5（周二）正午前用邮件提交。
- 不受理：TOEFL ITP、TOEFL Test Taker Score Report、TOEIC S&W／Speaking／Writing／Bridge／IP、IELTS General Training。

#### 日本語要件
- 外国人（日本的大学毕业或预计毕业者除外）须提交「日本語学力証明書」，原则上用コース入试案内所附样式，由日语教员等就说、听、写、读四项评价；用其他样式时须写明四项评价及评价方法。
- 専門科目试题为日文附英译（以日文为准），可用日文或英文作答。出願书类原则上用日文或英文。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 冬季：书类选考（无笔试） | 英语成绩＋研究计划书、推薦書、成绩证明书、指導教員希望調査書 | |
| 冬季：専門科目（口述可能试问的范围） | 必答“数学基礎”（线性代数、微积分等）和“プログラミング・アルゴリズム基礎”（编程、数据结构、算法、抽象数据类型、计算量、图论），再从“分析情報学基礎1（统计、数据分析、机器学习）”“分析情報学基礎2（空间信息学、GIS、IoT／泛在计算）”“計算機科学基礎1（编程语言、OS、网络）”“計算機科学基礎2（逻辑电路、计算机体系结构、网络／分布式系统）”中选2个，共4个领域 | |
| 夏季：専門科目 | “数学基礎”（线性代数、微积分、统计、数据分析）和“情報学基礎”（Python／C 编程基础、数据结构、算法、信息数学、数理语言学、计算机与网络基础）各2题，共4题全答（已结束） | |

- 冬季要项和入试案内都写明一次选考按英语成绩和书类判定，日程里没有笔试日，研究科共通要项的选拔方法也只有书类和口述；入试案内说明口述可能就専門科目栏的内容提问，所以冬季按上表领域准备口述。
- 一次选考合格者进入二次选考（口述），最终结果与一次选考合并综合判定。
- 特别选考枠（夏季、冬季都设，若干名）：面向有社会实务经验、在信息或电气电子领域有技术活动经验和高度专业性的人，提交书类和考试科目与一般选拔相同。

### 口述試験 / 面接
- **官方形式**：冬季：只有一次选考合格者参加，用线上会议系统远程进行（需带摄像头、能联网的电脑），全体考生就共通主题各做7分钟以内的发表，之后问答，考查基础与专门学力和研究能力，可能问到専門科目领域的内容，主题和要求写在随受験票发送的受験者心得里；夏季：同样形式（已结束）。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：18名（夏季、冬季合计，含特别选考枠若干名），学際情報学専攻全体100名（含アジア情報社会コース13名），合格人数可能不足募集人员。
- 出願资格：大学毕业（含 2027/3/31 前预计）或外国16年学校教育等；资格(6)个别审查书类 2026/10/16 截止（已截止，非独立出願）；同一时期只能报学府一个コース，也不能同时报修士和博士。
- 要提前准备的书类：研究计划书（所定样式）；推薦書（上司或指导教员等撰写，本人取得受付番号后委托其直接上传）；英语成绩；日本語学力証明書（外国人）。
- 出願：只能在指定网站填写和上传，12/4 12:00 前上传完成；检定料 30,000 日元（日本政府奖学金留学生免缴）。
