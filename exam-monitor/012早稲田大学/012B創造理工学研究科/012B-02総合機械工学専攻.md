## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 7月入试：英语不单独考试，外部考试成绩是出願资格之一。需达到以下任一项：TOEIC L&R 550 以上；TOEFL iBT 57 以上（新评分方式为スコアバンド 3.5 以上）；IELTS Academic 5.5 以上。本専攻没有另外的英语基准。
- 有效期：出願开始日（2026/5/25）的2年前以后受检的成绩。
- 提交方式：TOEIC 交公式认定证（日本国内受检的交数字公式认定证 PDF 的打印件），申请代码 00019702；TOEFL iBT 由 ETS 直送（Institution code 2874）并提交 Test Taker Score Report；IELTS 由考试机构直送成绩数据并提交 Test Report Form。
- 不受理：TOEIC IP、TOEIC S&W、TOEIC Bridge；TOEFL iBT Home Edition、My Best scores、TOEFL ITP；IELTS Online、One Skill Retake、General Training。
- 提交的成绩不符合资格要求时出願无效。要项没有写英语成绩是否换算进总分。
- 飛び級入試在創造理工学研究科的英语基准与一般入试相同（更高的基准只适用于先進理工学研究科，不适用于本専攻）。

### 日本語要件
- 要项没有要求提交 JLPT 等日语成绩。
- 选考（笔试和面接）原则上用日语进行；笔试第一部分是小論文，要项和問題一覧都没有写可以用英语作答。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 共通科目：小論文（配点官方未公布，60分钟） | 与机械工学有关的题目1题，题目在考试当场给出，必答 | 2027問題一覧 |
| 選択科目（配点官方未公布，90分钟） | 下面4个科目里共选2题作答；2题可以出自同一科目，也可以两个科目各1题；答了3题以上的不予评分 | 2027問題一覧 |
| 　(1) 熱と流れの工学 | 热力学第一·第二法则、各种热力循环、能量与㶲（エクセルギー）守恒、蒸气、传热基础；静止流体力学、完全流体、粘性流、旋转与涡、连续方程、动量守恒、流体损失、量纲分析、边界层、管内流动 | 2027問題一覧 |
| 　(2) 材料の力学 | 应力、应变、材料的力学性质、截面内力、拉伸、压缩、扭转、弯曲、组合应力、能量原理、屈曲 | 2027問題一覧 |

- 笔试时间为 10:00–13:00，中间有30分钟休息：先小論文60分钟，再選択科目90分钟。
- 要自带能做计算的计算器，带程序功能的计算器不能用。
- 官方没有公布各科目的配点、合格最低分，也没有写面接和书类在总评里占多少。合否按书类审查、笔试、面接综合判定。問題一覧里没有笔试免除制度的记载。
- 題目的具体形式可以看入学センター公开的本専攻过去问（共通、選択两份）。
- 题目倾向（体验记，非官方）：没有找到本専攻考生本人写的可核实的体验记。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：本専攻 7月入试 4月入学 100名（这个数字包含推薦入試等其他入试的名额）。要项的募集人员表里本専攻只读到这一个数字；9月入学、飛び級入試两栏的写法（若干名或不募集）本次没能从表里确认。
- 出願资格：大学毕业或预计毕业、学位授与机构授予学士学位、在外国完成16年学校教育、外国大学3年以上课程毕业、文部科学大臣指定者、个别审查认定且入学前满22岁——以上之一，并且同时满足英语外部考试的基准。
- 只能报1个専攻；本専攻不设第2志望（第2志望只适用于物理学及応用物理学専攻第1志望、共同原子力専攻第2志望的人），也不属于笔试可以选其他専攻题目的専攻。出願时要填志望的研究指导。
