## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 不另设英语笔试，用 TOEFL iBT（含 Home Edition）或 IELTS Academic 成绩做外国语审查；只认 2024/8/1 以后受检的成绩，IELTS General Training 和 One Skill Retake 成绩不受理。本専攻要求具备英语授课和讨论所需的沟通能力。
- TOEFL：①在 ETS 账户把 Official Score Report 送到研究科（DI Code 8426 University of Tokyo Faculty MED，Division: Graduate Organization，Department 42 Medicine）；②在 WEB 出願系统登记 Appointment Number 和受检日；③上传同一次的 Test Taker Score Report PDF。三步缺一或上传件与官方成绩不一致都按无效处理；以前已用同一代码送过有效成绩的不必再送。
- IELTS：在 WEB 出願系统上传 Test Report Form，并在出願前向 IELTS 事务局申请把同一次的成绩单寄到研究科学務チーム大学院担当（寄到晚于出願截止也受理）。
- 考过多次也只能上传 1 份。
- 免交：学士毕业于澳大利亚、加拿大、爱尔兰、新西兰、英国、美国的大学，或毕业大学出具全校英语授课证明的，须事先联系研究科并在 2026/6/5 前提交审查材料（已截止）；逾期即使母语是英语也不免除。
- ADB-JSP：在 Google 表单提交 TOEFL iBT 官方成绩或 IELTS 成绩（经 Result Verification System 核验）。

#### 日本語要件
- 本専攻是从入试到修了都不需要日语能力的「英語で学位のとれる課程」，课程全部用英语；要项没有要求提交日语成绩，一般选拔和 ADB-JSP 都一样。
- 笔试题目全部用英语出，可用英语或日语作答。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：21名（只有 8 月一次募集）。
- 出願资格：大学毕业（含 2027/3/31 前预计）或外国 16 年学校教育等；个别入学资格审查须先邮件联系研究科，2026/6/5 前提交材料（非独立出願，已截止）；ADB-JSP 限所列 ADB 成员国国籍、学士毕业后有 2 年以上卫生·医学相关全职工作经验、未满35岁、目前住在本国且学成回国、无留学经历且不是读第二个修士的人，优先女性和低收入者；同时报 ADB-JSP 和一般修士入试的两边都无效。
- 要提前准备的书类：志望理由书（英文 400–500 词，A4，格式自由）、研究计划书（A4 2页，格式自由）、指导教员同意指导的邮件、TOEFL 或 IELTS 成绩；海外大学的毕业证明须为英文或附公证英译，并写明学位名。
- 出願：一般选拔只能通过 WEB 出願系统上传；检定料 30,000 日元（银行汇款、便利店、Pay-easy 或信用卡，手续费自付；日本政府奖学金留学生免缴）。
- 咨询：医学系研究科学務チーム大学院担当（〒113-0033 東京都文京区本郷7-3-1），in.m@gs.mail.u-tokyo.ac.jp；研究科入试页另有咨询表单。
- 并愿：同时报 ADB-JSP 和一般修士入试的两边都无效。
