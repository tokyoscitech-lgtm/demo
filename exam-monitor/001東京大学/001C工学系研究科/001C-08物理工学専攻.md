## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 只有夏季一轮。専攻不另设英语笔试，用外部成绩评价：只收 TOEFL iBT（含 Home Edition）的官方成绩；募集要项共通规定里的 TOEIC L&R、IELTS 不适用于本専攻。
- 提交截止 2026/7/31（周五）（已截止）。三步都要完成：通过 ETS 向 DI 代码 8596、Department 代码 99 送分；在 WEB 出願系统マイページ登记 Appointment Number 和受检日；上传 Test Taker Score Report 的 PDF。
- 只采用 Test Date Scores，不采用 MyBest Scores；受检日在 2024年9月以后有效。TOEFL ITP 等团体受检成绩不受理。母语是英语的人也要交。考过多次的只认マイページ登记的那一次。
- 配点、最低分和换算方法官方没有公布；英语成绩与笔试一起用于中间选拔。

#### 日本語要件
- 募集要项和専攻入试案内都没有要求提交日语成绩（JLPT 等），外国人考生不交日语证明；本専攻没有另设的外国人留学生选考。
- 数学（研究科共通题）有日英两版过去问；物理学和口述的使用语言、作答语言入试案内没有写明。専攻说明会以日语进行。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 数学·一般教育科目（配点官方未公布，150分钟） | 6题选3题：微积分与微分方程、级数·傅里叶分析·积分变换、向量·矩阵·特征值、曲线·曲面、复变函数、概率统计·信息数学等 | 2027専攻入试案内／修士募集要项别纸 |
| 物理学·専門科目（配点官方未公布，240分钟） | 4题全答；以力学、电磁学、统计热力学、量子力学为基本，也含光学、固体物理 | 2027専攻入试案内 |

- 选拔依据是提交书类、笔试（含英语）和口述。先按笔试（含英语）做中间选拔，通过者才能参加口述；各部分配点和合格线官方没有公布。
- 募集要项共通表里的一般教育科目“物理学”“化学”不适用于本専攻，一般教育科目只考数学。
- 题目倾向（体验记，非官方）：数学常出非线性常微分方程，线性代数以对角化为主，复变函数范围广，多数人准备4个领域当场选3题。物理学计算量大，力学近年偏刚体和振动，电磁学多是时变电磁波和光学，量子力学常见谐振子、散射、自旋和角动量，统计力学常见伊辛模型、德拜模型、玻色凝聚；有人说 2026年度计算量比往年少。

### 口述試験 / 面接
- **官方形式**：夏季入试有口述，只限中间选拔通过者；每人发表7分钟＋质疑应答13分钟，讲毕业研究或相当的内容（没做毕业研究的讲入学后想研究的领域），资料为 A4 横向单面4张以内、可彩印，不能带笔记和参考书；评价对发表内容的理解度、基础物理知识、表达能力；配点和使用语言官方没有公布。
- **実際に聞かれた内容**：（体验记，非官方）考官约7–8人，含第一、第二志望研究室的教员；提问3–4个，多是追问发表里含糊的地方，再顺着问到相关基础物理（如讲开放量子系统的考生被问映射的定义、反例和详细平衡条件）。气氛平和。名单前一天下午才邮件发来，资料要在笔试前准备好。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：夏季入试（出願日程A，2027年4月入学和2026年10月入学合计）42 名；本年度没有冬入试。
- 出願资格：日本的大学毕业或 2027/3/31 前预计毕业；在外国完成16年学校教育；在外国取得相当于学士的学位（3年以上课程）；文部科学大臣指定者；学位授与機構授予学士者；个别入学资格审查合格且满22岁者，共6项之一。个别入学资格审查（资格6）的书类截止 2026/4/21（周二）（已截止）。
- 志望教员：在「志望シート M」上从研究室名单里按顺序填8位志望教员（8个都要填），另在“实验系教员”“理论系教员”“哪里都可以”中勾1项，并具体写志望领域。志望シート不在出願时上传，而是 2026/8/31 考试当天带到考场，数学考完后回收。

- 10月入学：本専攻可能认可 2026年10月入学（资格日期改为 2026/9/30）。新申请在留资格通常要 2–3 个月，研究科建议需要新办在留资格的外国籍考生考虑4月入学。
- 入学料 282,000 日元，授業料 年 535,800 日元（前期 267,900 日元），均为预定额；国费留学生免缴。4月入学者的入学许可通知书 2026/10/29（周四）在マイページ交付，入学手续截止预定 2027/3/9（周二）。
- 特别口述考试（免笔试的选拔）不适用于本専攻。
- 专攻 Q&A：外校和理学部出身在入试中没有不利，只看考试成绩。
- 咨询：募集要项的问题用研究科网站的问询表单（工学系研究科学務課大学院チーム）；専攻事务室 Tel 03-5841-6800，office@ap.t.u-tokyo.ac.jp。
