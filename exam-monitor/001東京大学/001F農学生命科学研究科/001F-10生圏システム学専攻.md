## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各日程相同：不另设英语笔试，用 TOEFL iBT（含 Home Edition）成绩评价。
- 送分：向 ETS 申请把 Institutional (Official) Score Report 送到研究科（DI code 1113）；出願时在 WEB 出願系统里填写 Appointment Number、受检日和分数，不必交 Test Taker Score Report。
- 有效受检期间（向 ETS 申请送分也须在此期间内完成）：A日程 2024/8/1–2026/6/13（已过）；B日程 2025/2/1–2026/11/15。
- 送过多次的只指定一次。TOEFL ITP 不受理，MyBest Scores 不采用。
- 官方没有规定最低分、换算方法和配点；B日程的书类选考以成绩证明书和 TOEFL 成绩为依据。
- 要项里 B日程部分免交 TOEFL 的规定只适用于応用生命化学·応用生命工学専攻，不适用于本専攻。

#### 日本語要件
- 要项和専攻案内都没有要求提交日语成绩（JLPT 等），外国人考生走一般选拔也不用交；研究科不设单独的外国人留学生特别选拔。
- A日程専門科目日英并记出题，可用日语或英语作答；B日程的口述和志望理由书都可以用日语或英语。

- A日程①②都必须作答，合计答 3 题；按笔试、TOEFL 和口述综合判定，配点和合格线官方没有公布。
- 题目倾向（体验记，非官方）：没有找到本専攻修士笔试的公开体验记。

### 口述試験 / 面接
- **官方形式**：A日程在笔试次日 2026/8/7 对面进行，问志望动机、修学所需的基础学力和适性、希望研究领域的基础能力，综合评价研究能力，时长和配点官方未公布；B日程只限书类选考合格者，先用事先准备的资料做 15 分钟发表（志望动机、毕业论文研究、入学后想做的研究，没有毕业论文的讲大学所学内容），再进行含专门领域内容的问答，评价专门领域的视野和知识、逻辑思考力、研究意欲和计划性，可用英语或日语，对面还是线上案内没有写明。
- **実際に聞かれた内容**：没有找到本専攻修士口述的公开体验记。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：A日程 25名，B日程若干名；符合资格者 A日程可选 2026年10月入学、B日程可选 2027年10月入学，其余为 2027年4月入学。
- 出願资格：日本的大学毕业或 2027/3/31 前预计毕业；在外国完成 16 年学校教育；在外国取得相当于学士的学位（3 年以上课程）；文部科学大臣指定者；学位授与機構授予学士学位；经个别入学资格审查认定且 2027/3/31 满 22 岁。个别入学资格审查和受验照顾申请截止：A日程 2026/5/7、B日程 2026/10/7（均已过）。
- 入学时期在 WEB 出願系统里选择，出願后不能更改。
- 志望填写：在 WEB 出願系统里按「教員並びに専門分野一覧」选专门分野和教员，最多填到第3志望；第2、第3志望可以选同一分野的其他教员，没有可以不填。一览会因人事变动更新，出願前要看最新版。
- 出願书类：入学願書（WEB 填写，含 3 个月内照片）、出身大学成绩证明书、毕业（预定）证明书（写明学位名和授予日）、检定料缴纳证明、国费留学生证明书（仅该当者）、TOEFL 成绩；B日程另加専攻指定书类。证明书不是日文或英文的要附译文，原件在入学手续时提交。
- B日程：
  - 専攻指定书类为志望理由书：写志望动机和入学后想做的研究，A4，英文约 1500–2000 词或日文约 3000–4000 字，多页要加页码。
  - 在出願期间内用邮件发到専攻邮箱，标题写「B日程出願：姓名」。
  - 受験者心得 2027年1月上旬邮件发送，到 2027/1/13（周三）还没收到的要联系教務課。
- 出願方式：只能通过 WEB 出願系统；书类不齐不受理。受験票自己用 A4 纸打印，考试当天带上。
- 检定料 30,000 日元，银行汇款（邮储银行除外）、便利店、信用卡、Pay-easy 均可；缴纳期间 A日程 2026/4/13–6/23（已过），B日程 2026/10/5–11/25。国费留学生免缴；缴后不退。
- 并愿：同一日程只能报研究科的一个専攻；要项写两个日程都有资格时可以都报，A日程合格者能否再报 B日程本専攻没有写明。
- 入学料 282,000 日元，授業料 年 535,800 日元（前期 267,900 日元），均为预定额；国费留学生免缴。考试时在海外、B日程想 4月入学的，要注意在留资格和入境可能来不及。
- 咨询：専攻的问题问 橋本 禅 教授（Tel 03-5841-5472，ahash@g.ecc.u-tokyo.ac.jp）；出願手续问农学生命科学研究科教務課学生支援チーム大学院学生担当（〒113-8657 東京都文京区弥生1-1-1，Tel 03-5841-5010，daigakuin.a@gs.mail.u-tokyo.ac.jp）。
