## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 心理学コース（夏季一般、冬季一般、冬季外国人留学生）：
  - 不另设英语笔试，用 TOEIC L&R 或 TOEFL 的成绩评价；TOEIC L&R IP、TOEFL ITP 等团体考试成绩也可以；IELTS 不在对象内。
  - 成绩须为出願截止日前2年以内受检：夏季为 2024/7/22 以后，冬季为 2024/12/24 以后。
  - 一般选拔的成绩单交原件（寄受験票时归还）、经公证的复印件（含数字认证）或由考试机构直送（TOEFL 的 DI 代码 C988，原则上须在出願期间内送达）。
  - 要项没有写最低分、换算方法和配点。
- 健康·スポーツ科学コース（各轮次、各选拔）：
  - 不交外部英语成绩，当天考学内英语（9:30–11:30，120分钟）。社会人和外国人留学生特别选拔写明可带纸质辞书、不可带电子辞书；夏季一般选拔同样可带辞书，冬季一般选拔的科目表没有写辞书规定。
  - 变更点：夏季外国人留学生特别选拔的外国语是"英语及日语"；冬季外国人留学生特别选拔的科目表只列"英语（可带辞书）"。

#### 日本語要件
- 一般选拔和社会人特别选拔（两コース，夏季·冬季）：要项没有要求提交 JLPT、EJU 等日语成绩，外国人走一般选拔也一样；要项为日文，没有写明试题和作答语言，笔试与口述实际以日语进行。
- 心理学コース冬季外国人留学生特别选拔：须交"日本語能力についての証明書"，原则上由外務省或在外公館指定的机构（或可替代的机构）发行；要项没有指定考试种类和等级。心理学コース夏季没有留学生特别选拔。
- 健康·スポーツ科学コース外国人留学生特别选拔：不要求提交日语证明；夏季的外国语笔试含日语，冬季科目表只列英语。

### 口述試験 / 面接
- **官方形式**：夏季：心理学コース有，须带12份说明研究经过和研究计划的资料（资料本身也是审查对象），可用考场的 Windows 电脑和投影仪（PowerPoint 存 USB 带去），健康·スポーツ科学コース有，内容和时长要项未写；冬季心理学コース（一般·外国人留学生）：有，以面接形式就追加出願书类质疑应答，须带 A4 4页以内的研究经过和研究计划说明资料10部（资料不是报告书的简单补充，也是审查对象），可用既设 Windows 电脑和投影仪（PowerPoint 存 USB）；冬季健康·スポーツ科学コース（一般·社会人·外国人留学生）：有，围绕提交的论文等出願书类和专攻分野提问；配点均未公布。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：本専攻17名（心理学コース、健康·スポーツ科学コース合计，夏季·冬季合计，含社会人和外国人留学生特别选拔，不分コース和轮次）；健康·スポーツ科学コース社会人特别选拔夏季、冬季各若干名，心理学コース不设社会人特别选拔；外国人留学生特别选拔：健康·スポーツ科学コース夏季若干名，冬季两コース都实施，学府全体12名程度。
- 选拔设置：心理学コース夏季只有一般选拔，冬季有一般和外国人留学生；健康·スポーツ科学コース夏季、冬季都有一般、社会人、外国人留学生三种。本専攻只有4月入学，没有10月入学募集。
- 一般选拔出願资格：大学毕业或2027年3月底前预计毕业、在外国完成16年学校教育（含预计）等；资格(9)(10)(11)须个别出願资格审查，冬季书类 2026/11/18（周三）截止，结果 11/30（周一）寄出。
- 社会人特别选拔（健康·スポーツ科学コース）：除一般资格外，出願时须有大学毕业后1年以上相关领域的活动经历；以最终学校成绩证明或所属机构介绍信（所定样式）代替成绩证明。
- 外国人留学生特别选拔：没有日本国籍，在外国完成16年学校教育或取得相当学士学位的人；在日本的大学毕业（预计）的要走一般选拔。成绩证明和毕业证明须附英译或日译。
- 本専攻追加出願书类：
  - 心理学コース一般选拔：TOEIC L&R 或 TOEFL 成绩证明、研究経過報告書（所定样式，2,000字以内，写卒业论文概要和正在进行的研究；没有卒论的写在学期间的研究）、研究計画書（所定样式，3,000字以内）、卒業論文或其复印件（没有可不交，出願时未完成的口述当天带来），有其他研究业绩的须一并提交。
  - 健康·スポーツ科学コース一般选拔：研究経過報告書（2,000字以内）、研究計画書（3,000字以内）；冬季要项写明不需要交卒业论文，有其他研究业绩的可以提交。
  - 健康·スポーツ科学コース社会人：研究経過報告書（2,000字以内）、研究計画書（3,000字以内），其他研究业绩可任意提交。
  - 心理学コース冬季外国人留学生：研究経過報告書（2,000字以内）、研究計画書（3,000字以内）、卒業論文或复印件（同上）、TOEIC L&R 或 TOEFL 成绩证明（IP/ITP 可）、日语能力证明书。
  - 健康·スポーツ科学コース外国人留学生：研究経過報告書（2,000字以内）、研究計画書（3,000字以内），其他研究业绩可任意提交。
- 共通书类：入学願書·履历书·受験票·照合票（贴3个月内照片）、成绩证明书和毕业（预定）证明书（全部交原件）、检定料缴纳证明、受験票回邮信封（長形3号，贴410日元速达邮票）、住所票；願書上要写希望指导教员和事前商谈日期。
- 出願方式：纸质书类交到或用书留邮寄到人文社会科学系事务部学务课（人環·教育担当），用角形2号信封贴学府的宛名标签；用纸从学府网站下载，单面打印；不是网上出願。
- 检定料 30,000 日元，在 e-支払サイト 申请后用便利店或信用卡·银联缴纳（海外只能用信用卡·银联），冬季缴纳期 2026/12/11（周五）–12/23（周三）；受理后不退；日本政府国费留学生免缴，须附国费留学生证明。
- 需要考试或修学照顾的残障考生，冬季须在 2026/11/27（周五）前向学务课提交相谈申请书和诊断书。
- 入学料 282,000 日元，授業料年 535,800 日元（半期 267,900 日元），均为预定额；入学手续书类 2027年2月中旬寄出，手续期 2月下旬–3月上旬（预定）。有长期履修制度，可分3年或4年修完。
- 考场规则：考场在伊都キャンパス イーストゾーン；笔试开始20分钟前入室，开考后30分钟内迟到可以入场；口述的迟到限度各コース另行通知；没带受験票不能入场；出願后不能变更志望内容。
- 咨询：九州大学人文社会科学系事务部学务课（人環·教育担当），〒819-0395 福冈市西区元冈744，Tel 092-802-6362，jbkkyomu1ed@jimu.kyushu-u.ac.jp。
