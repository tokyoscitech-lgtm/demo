## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 夏期一般入学：
  - 不另设英语笔试，用出願时提交的 TOEFL iBT、TOEIC L&R、TOEFL ITP 或 TOEIC L&R（IP）成绩换算成100分计入合否；交多种成绩的取换算后最高的一个；没有出願门槛（门槛只适用于医生命システム専攻）。
  - 只认2024年4月以后受检的成绩。TOEIC 交デジタル公式認定証打印件或带二维码的公式認定証原件，TOEIC IP 在线版不可用；TOEFL iBT 须交 Test Taker Score Report 打印件，同时让 ETS 把 Official Score Report 直送同志社大学（代码 7078），截止前缺一不受理，MyBest 不可用；ITP、TOEIC IP 交原件。
  - 出願时没交成绩的英语按0分处理；同一份成绩入学后用于修士学位的语学资格认定。
- 社会人特別選抜（夏期·春期）：英语成绩不用于合否，只用于修士学位的语学资格认定。
- 飛び入学：英语门槛写在出願资格里，不另计分。
- 外国人留学生入试：交语学能力证明原件，四选一——TOEIC L&R 或 TOEFL iBT（4月入学要求2024年4月以后、9月入学要求2024年10月以后受检；Home Edition 不认，TOEFL 须直送代码 7078）；日语能力证明（见日本語要件）；大学教育用英语进行的证明；大学教育用日语进行的证明。没有最低分；学内进学者免交。
- 国際科学技術コース：TOEFL iBT 79分以上（2026/1/21以后受检为 band 4 以上）、TOEIC L&R 750分以上、IELTS Academic 6.0以上，或英语授课的学士课程毕业（含预计）；成绩须在出願截止前2年以内，交原件。

#### 日本語要件
- 一般入学·社会人特別選抜·飛び入学：要项没有要求提交日语成绩；2026年度过去问为日文出题。
- 外国人留学生入试：日语证明只是语学能力证明的选项之一（EJU「日本語」2025或2026年度，或 N1 的认定结果及成绩证明书原件，合否通知明信片不行）；面接用日语或英语。
- 国際科学技術コース：英语授课，申请材料用英语。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 夏期一般入学·春期飛び入学：数学（代数学・微分積分学）（100分） | 2026年度过去问4题（极限、泰勒展开、积分、逆矩阵、矩阵对角化），全部作答 | 10:00–11:30，三科共90分钟 |
| 夏期一般入学·春期飛び入学：力学・制御工学（100分） | 2026年度过去问力学2题（两质点系动量守恒与相对运动、有摩擦斜面上滚动的圆盘）、制御工学2题（质量–弹簧–阻尼系响应、反馈系统阶跃响应与伯德图） | 同上 |
| 夏期一般入学·春期飛び入学：材料力学（100分） | 2026年度过去问2题（杆的变形与应力；L形梁的反力、截面力、应力、挠度与扭转角） | 同上 |
| 社会人特別選抜（夏期·春期）：関係論文 | 与专攻领域相关的论述 | 10:00–11:30，90分钟 |

- 夏期一般入学：数学100＋力学・制御工学100＋材料力学100＋英语100（换算）＝400分，加面接（含口頭試問）综合判定。
- 飛び入学：専門基礎科目三科各100分加面接综合判定，英语不计分。
- 社会人特別選抜：関係論文和面接综合判定。
- 外国人留学生入试（4月·9月入学）：本コース不考笔试和小論文，按出願书类和面接判定（小論文只考医情報学コース和医生命システム専攻）。
- 国際科学技術コース：按申请材料综合审查，必要时在线面谈或用邮件问答。
- 専門科目免除（只限夏期一般入学，已结束）：同志社大学医工学科、同志社大学其他学部及同志社女子大学、指定高専専攻科的应届毕业生中人物·成绩优秀者可申请；免除者也被建议参加笔试，分数不用于合否。
- 变更点：2026年度试题中力学和制御工学分开出卷；2027年度要项合为「力学・制御工学」一科（100分）。

### 口述試験 / 面接
- **官方形式**：一般入学·社会人特別選抜·飛び入学：笔试当天 13:00 起面接，含口頭試問，问出願书类所写事项和专攻领域相关知识；外国人留学生入试（4月·9月入学）：只有面接（含口頭試問），用日语或英语，国外居住者通过网络远程面接，日时邮件通知；国際科学技術コース：书类审查，必要时在线面谈。
