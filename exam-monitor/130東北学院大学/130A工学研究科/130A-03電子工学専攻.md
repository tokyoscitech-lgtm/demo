## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 一般選考（秋季·春季）：当天进行英语笔试（科目名“英語”，9:00–10:00，60分钟），工学研究科只能选英语；配点官方未公布，要项没有写词典能否带入。
- 不需要提交 TOEFL、TOEIC、IELTS 等外部成绩，要项里也没有用外部成绩代替英语笔试的规定。
- 社会人特別選考没有英语笔试，只有面接・口述。
- 推薦選考A日程没有英语笔试（小论文＋面接）。

### 日本語要件
- 外国人出願者须提交 日本語能力試験（JLPT）的成绩证明书，工学研究科要求 N2 相当；另需在留卡复印件和外国人出願申请书。
- 试题与面接用日语进行；研究计划书（社会人特別選考）须用日语书写。
- 官方没有设外国人留学生特别选拔，留学生与日本人走同一套一般選考。

## 📝 详细信息
### 出願資格 / 定員
- 一般選考的募集人员为8名（2027年度募集起适用，秋季·春季合计，要项没有分开写）；社会人特別選考为若干名；推薦選考为若干名；本校生的特別選考人数未公布。
- 一般選考出願资格：大学毕业或2027年3月预计毕业、由大学改革支援・学位授与機構授予学士、在外国完成16年学校教育、经个别入学资格审查认定且到2027年3月底满22岁等，共9项之一。
- 社会人特別選考：满足一般選考资格之一，并且是在企业、政府机关等作为正式职员可在职入学的人，或大学毕业后有3年以上社会经验（含家庭主妇/主夫）的人。
- 推薦選考A日程：2027年3月大学毕业预定，或高专2年制专攻科修了预定并预计取得学士；须所属学部长或高专校长推荐、合格后必定入学；大学生专门科目平均80分以上（GPA 2.5 相当），高专生4–5年级及专攻科的专门科目平均80分以上。工学研究科不设推薦B日程。
- 特別選考（A/B日程）只面向满足成绩基准的东北学院大学毕业预定者，要项只在学内网站公开，这不是一般考生的路线。
- 出願书类（一般選考）：入学志愿书、成绩证明书、毕业（预定）证明书、最终学历为大学院者的修了证明书、在职者的通学证明书；外国人另交在留卡复印件、外国人出願申请书、JLPT 成绩证明书。工学研究科一般選考不需要研究计划书。证明书须为发行后3个月以内。
- 社会人特別選考须另交研究计划书：用文字处理软件制作，A4 横排单面，1,200–2,000 字左右（每行40字、每页36行），使用本校规定封面并注明字数，用日语写研究课题、研究方法及相关业绩。
- 出願方式：先在 WEB 出願系统登记并缴费，再把书类用角2信封以邮局窗口“简易书留速达”寄送（期限内必达），或在平日 9:00–17:00（最后一天到 15:00）送到入試部アドミッションズ・オフィス。只做 WEB 登记不算出願完成。受験票不邮寄，考试日7天前起在 WEB 出願系统的 My Page 自行打印。
- 检定料 33,000 日元（另加支付手续费），通过 WEB 出願系统支付，任何理由都不退还。
- 没有大学毕业资格的人须先接受出願資格事前審査（免费，以书类为主，必要时笔试或面接）：秋季申请 2026/6/8–6/17（已截止），春季 WEB 2026/11/24（周二）–12/2（周三）22:59，书类 2026/12/4（周五）15:00 截止。
- 入学手续：秋季合格者 2026/12/11（周五）15:00 截止，春季合格者 2027/3/12（周五）15:00 截止，以缴纳入学时纳付金为完成。博士前期可申请日本学生支援机构贷与奖学金相关的授業料后付制度。
- 学费：本次能查到的官方页面只列出文系四研究科2027年度的参考额（年 867,000 日元，不含入学金），工学研究科的入学金和授業料没有在公开页面列出，以入学手续要项为准。
- 考场：土樋キャンパス（仙台市青葉区土樋一丁目3-1）。考场规则见2027年度受验注意事项。
- 咨询：选拔相关为入試部アドミッションズ・オフィス（Tel 022-264-6455，ao-sec@g.tohoku-gakuin.ac.jp）；大学院整体与研究室联系为学務部大学院課（仙台市若林区清水小路3-1，Tel 022-354-8202，daigakuin@g.tohoku-gakuin.ac.jp）。合否不接受电话查询。
