## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各轮次（推薦、一般8月、一般1-2月、社会人特别选拔）都必须在出願时提交外部英语成绩单；一般入试作为「外国語」评分，配点 100 分，不另设英语笔试。
- 可用 TOEIC Listening & Reading（公开）、TOEFL iBT（含 Home Edition）、IELTS Academic（纸笔或机考）；须为 2024年7月以后受检、成绩单印有本人照片。在日本以外受检的 TOEIC 公式认定证贴在 Web 出願系统下载的台纸上。
- 不受理 TOEIC IP、TOEFL ITP、IELTS General Training、IELTS Academic 在线版；成绩单不退还。
- 出願时没有交齐符合条件的成绩单，外国語按缺考处理，不进入选考。
- 免除：英语为第一语言或母语者、来自以英语为官方语言的国家者、完整修完英语授课的本科课程者，可以提交免除申请书（格式自由；第3种须附证明原件）。
- 要项没有公布换算方法；一般入试没有最低分。推薦（已结束）另有门槛：TOEIC 470、TOEFL iBT 42 或 IELTS 4.0 以上。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 研究计划可用日文（约1000字）或英文（约500词）；口述试验的应答语言要项和当日注意都没有规定。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 没有专门科目笔试（一般8月、一般1-2月） | 数学基础学力在口述试验1中口头考：线性代数（向量、矩阵、行列式、线性空间、线性映射、内积空间、特征值与特征向量）、解析（数列、函数与极限、微分、积分、级数、微分方程、复变函数） | 口述试验1出题范围页 |
| 外国語（100分） | 外部英语成绩换算 | 2027募集要项 |

- 一般入试总分 400（外国語 100＋口述 300）；口述1和口述2各占多少分、合格最低分都没有公布。
- 题目倾向（体验记，非官方）：没有找到本プログラム考生写的体验记。

### 口述試験 / 面接
- **官方形式**：一般8月、一般1-2月：对面，300分，口述试验1为数学基础学力的口头试问（自带铅笔、橡皮），口述试验2为 5 分钟发表（志望理由、今后的研究计划、毕业研究的题目与内容；4分钟一次铃、5分钟两次铃立即结束），之后提问；发表资料打印在 A4 纸上用实物投影仪逐张投影，张数不限，不能用电脑，不发给考官讲义；开场前30分钟可入场，集合时刻不在可能失去资格；社会人特别选拔（8月、1-2月）：线上口述，须交誓约书。
- **実際に聞かれた内容**：没有找到本プログラム的体验记。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：推薦（7月）60名；一般8月 57名、社会人特别选拔8月 3名；一般1-2月 12名、社会人特别选拔1-2月 3名。
- 入学时期：推薦和一般8月为 2027年4月；一般1-2月可选 2027年4月或10月。
- 出願资格：日本4年制大学毕业（含预计）、在外国完成16年学校教育、在外国取得相当于学士的学位（3年以上课程，须事前确认）、或年满22岁并通过个别资格审查者等。个别资格审查的截止：1-2月期 2026/11/24（周二），向システム情報エリア支援室大学院教務邮件申请。
- 所有出願者都要事先取得志望指导教员的内诺；填第2志望教员的也要取得其内诺。合格后没有另行通知就配属第1志望教员的研究室。只能任副指导的连携教员须与主指导配对并取得两人的内诺。
- 外国籍考生（永住者等除外）须由志望教员告知「リファレンス番号」并在 Web 出願时输入；全员都要在 Web 出願时回答みなし輸出的特定类型确认。
- 出願书类：Web 入力（证件照 JPEG、志望教员、研究计划——日文约1000字或英文约500词，不能含图表）、毕业（预定）证明书和成绩证明书原件（日文或英文）、外部英语成绩单（或免除申请书）、检定料收纳证明；在学或在职者交受験·就学承认书；中国大学毕业者交学信网（CHSI）英文学历认证报告。
- 出願方式：先在 Web 出願系统入力，再把书类装角形2号信封贴宛名シート，書留邮寄或送窗口（最后一天 17:00 前）至システム情報エリア支援室，截止日必达。一个账号只能报一个学位プログラム。
- 检定料 30,000 日元（信用卡或便利店，手续费自付，缴后不退）；国费外国人留学生免缴。
- 入学料 282,000 日元；授業料 年 535,800 日元，外国人留学生（留学签证）年 608,800 日元。
- 受験者心得在考试一周前登在入试网站「お知らせ」栏；受験票自行打印带到考场。1-2月入试可能有追加合格，4月入学者在 2027年3月中旬前后电话等联系。
- 研究生是另一条路线，按大学的研究生制度申请。这不是修士入试的要求。
- 咨询：出願资格事前确认 admission.grad@un.tsukuba.ac.jp；プログラム的问题通过官网咨询渠道或直接联系志望教员。
