## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 1-2月实施：不另设英语笔试，须提交 TOEIC、TOEFL 或 IELTS 外部成绩作为书类审查材料；成绩须为2025年1月以后受检（简易版要项）。
- 没有最低分、换算表或英语单独配点。
- 可用「英语授课课程修了证明」（A4，格式自由）代替成绩单，条件是本科或研究生课程全程英语授课（远程教育除外）、授予学位的大学在非英语官方语言国家。
- 受理种类（全学共通）：TOEIC L&R 公开考试（IP 不收）；TOEFL iBT（含 Home Edition，ITP 不收）；IELTS Academic（General、线上版、One Skill Retake 不收）。
- 提交方式（全学共通）：TOEIC 在 Web 系统填数字公式认定证 URL 并交打印件；TOEFL iBT 2026年1月起纸质成绩单废止，须由 ETS 直送 Official Score Report（DI 代码 9995、Department 代码 99），同时交 PDF 版 Test Taker Score Report 打印件；IELTS 须把 Additional TRF 数据送到大学并交 Test Report Form 复印件。直送数据要几周，书类截止前没到按不受理或缺席处理。

#### 日本語要件
- 1-2月实施：要项没有要求日语成绩；课程和面试使用英语，正式要项只有英文版。证明文件接受日文或英文，其他语言须附注册翻译者的日文或英文译本。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 1-2月实施：笔试不实施 | 没有专门科目笔试，也没有英语笔试 | 2027募集要项 |
| 1-2月实施：书类审查（100分） | 综合评价个人经历（学历、职历、研究活动）和研究计划 | 2027募集要项 |
| 1-2月实施：口述试验（300分） | 以个人经历和研究计划为基础的英语个别面试，Zoom 线上 | 2027募集要项 |

- 总分 400（书类 100＋口述 300），按总分综合判定，合格最低分未公布。

### 口述試験 / 面接
- **官方形式**：1-2月实施有口述试验，Zoom 线上个别面试，全程英语，围绕个人经历和研究计划提问，配点300分，每人时长未公布；在线受验须提交亲笔签名的 Written Agreement。
- **実際に聞かれた内容**：没有找到公开的面试体验记。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：1-2月实施（一般入試）8名（2027年10月入学，英语授课）；没有社会人特別選抜等其他区分。
- 出願资格：日本四年制大学毕业或2027年9月底前预计毕业；学位授与機構授予学士学位或2027年9月底前预计取得；在外国完成16年学校教育或2027年9月底前预计完成；在外国3年以上课程取得相当于学士的学位等。不符合的人（满22岁的个别审查）须在截止日前向体育芸術エリア支援室（taigeiin.admission@un.tsukuba.ac.jp）申请资格审查，通过后取得 Web 系统 passcode。
- 修业年限：2027/10/1 入学，到2029年9月，共24个月。
- 出願第一步：Web 出願系统录入本人信息、职历、研究活动和研究计划（英文约800词，含参考文献；需要公式或特殊符号时用指定一页样式，不能改格式或超框）；一个账号只能报一个学位プログラム；指导教员填第1志望，第2志望可选。
- 出願第二步：证明书原件或公证副本用挂号邮件或可追踪快递寄到体育芸術エリア支援室大学院教務，2026/12/11 17:00 必达。
- 出願书类：毕业（预计）证明书；学位证明书（日本以外毕业者）；成绩证明书（读过研究生院的另交；有硕士学位者也要交学士学位证明）；英语成绩或英语授课修了证明；Motivation letter（Word 样式，用邮件发到 tias-admin@un.tsukuba.ac.jp）；在职或在学者的受験承认书；国费留学生证明书（该当者）；检定料缴纳证明；在线考试 Written Agreement（亲笔签名）；Web 系统打印的照合票和地址标签。
- 书类补充：证书只有电子版的可由授予大学直接发到 taigeiin.admission@un.tsukuba.ac.jp；中国学历可用 CHSI 英文认证报告原件代替相应证书；自学考试本科须已完成并交实施机构的成绩与学位证明，未完成者不受理。
- 检定料 30,000 日元，缴纳期间 2026/11/30–12/10，缴纳后不退；信用卡均可，便利店支付限日本国内居住者；国费外国人留学生和双学位项目副学位出願者免缴。
- 入学料 282,000 日元；授業料年额 535,800 日元，以「留学」在留资格在籍的外国人留学生年额 608,800 日元；国费外国人留学生免缴。
- 奖学金：TIAS 奖学金页目前登的是2026年10月入学的国费外国人留学生大学推薦特别项目（报名 2025/12/23 截止、申请书 12/24 截止、Zoom 面试 2026/1/28 或 1/29），2027年10月入学的募集写明另行公布。
- 咨询：Office of Master's Program in Sport and Olympic Studies（体育芸術エリア支援室），〒305-8574 茨城県つくば市天王台1-1-1，tias-admin@un.tsukuba.ac.jp（标题写「TIAS Admission Inquiry (Your Name)」），周一至周五 9:00–17:00（日本时间），周末、节假日和 12/29–1/3 休息。
