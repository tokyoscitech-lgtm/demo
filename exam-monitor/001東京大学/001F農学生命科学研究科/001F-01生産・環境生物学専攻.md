## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 须提交 TOEFL iBT 成绩（Home Edition 也可以），研究科不另外举行英语考试，A日程和 B日程相同。
- 送分方式：向 ETS 申请把 Institutional (Official) Score Report 送到东京大学农学生命科学研究科，DI code 为 1113，用其他代码送的无效。Test Taker Score Report 不需要提交。出願时在 WEB 出願系统里填写 Appointment Number、受检日和分数。
- 有效受检日：A日程为 2024/8/1–2026/6/13（已过）；B日程为 2025/2/1–2026/11/15（周日）。送分申请也要在同一期间内完成。
- 考过多次的可以送多份，但出願时只能选定其中一次的成绩填写。
- 团体受检的 ITP 成绩和 MyBest 分数不受理。
- 要项没有写最低分数线，也没有公布换算方法和配点。要项没有单独写未提交时的处理，但成绩属于必交的出願书类（提出書類 カ），本専攻没有免除规定。
- B日程的书类选考会用到成绩证明书和 TOEFL 分数。

### 日本語要件
- 要项和専攻案内都没有要求提交日语成绩。
- A日程専門科目的试题日英并记，可以用日语或英语作答。口述试验使用的语言官方未记载。

- 2026年度 A日程各科考查的领域（出题意图归纳）：栽培学考农业技术的构成和农业的温室气体排放；植物分子遺伝学考水稻的正向遗传学、基因组编辑与反向遗传学；育種学考转基因与基因组编辑的差别及各国规则、自交不亲和与 F1 育种；植物病理学考产毒素病原菌的生活史、植物病毒基因的功能；応用昆虫学考昆虫分类、杀虫剂的作用机制；作物学考水稻与大豆的形态生理差异、韧皮部的同化产物运输；園芸学考顶端优势、芸薹属的遗传（禹氏三角）；昆虫遺伝・病理学考家蚕突变体的遗传学方法、杆状病毒与 Bt 的利用；生物測定学考随机区组的方差分析、连锁不平衡与基因组选择·GWAS。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：要项的表里本専攻写的是“28名”和“若干名”两个数字。表分为 A日程（2026年10月入学／2027年4月入学）和 B日程（2027年4月入学／2027年10月入学）共 4 栏，读取到的文本无法判断这两个数字各对应哪一栏，报考 B日程的人请直接看要项原表。考试成绩不够时可能录不满。
- 出願资格：日本的大学毕业或 2027年3月底前预计毕业；在外国完成 16 年学校教育；在外国取得相当于学士的学位（3 年以上课程）；文部科学大臣指定者；大学改革支援·学位授与機構授予学士学位者；经个别入学资格审查认定且 2027年3月底满 22 岁者。
- 个别入学资格审查（第 6 项）的申请截止：A日程 2026/5/7（周四，已过），B日程 2026/10/7（周三，已过）。
- 入学时期：A日程可以选 2026年10月入学，B日程可以选 2027年10月入学，都在 WEB 出願系统里选择，出願后不能更改。
- 志望教员的填写：按“教员及专门分野一览”最多填到第 3 志望，每个志望选专门分野和教员名；第 1 到第 3 志望必须是不同专门分野的教员；没有第 2、第 3 志望可以不选。教员信息会更新，出願前要看最新版。
- 出願书类：入学願書（WEB 填写，上传 3 个月内的照片）、出身大学的成绩证明书、毕业（预定）证明书、检定料缴纳证明、国费留学生证明书（仅国费生）、TOEFL 成绩、専攻指定书类。日语和英语以外的证明书要附译文，原件在入学手续时提交。
- 専攻指定书类：A日程没有。B日程要交毕业论文研究（或代替物）的要旨，格式自由、A4 1 页以内，2027年1月底前用邮件发到 aeb-chief@ab.a.u-tokyo.ac.jp。
- 出願方式：只能通过 WEB 出願系统，书类在系统里上传。
- 检定料 30,000 日元，可用银行汇款（邮储银行除外）、便利店、信用卡、Pay-easy 支付；国费留学生免缴。缴纳期间：A日程 2026/4/13–6/23（已过），B日程 2026/10/5–11/25。缴纳后不退，B日程书类选考不合格也不退。
- 并愿限制：同一日程内只能报研究科的一个専攻。要项允许有资格的人 A、B 两个日程都出願，但写明个别専攻可能不允许；本専攻案内对此没有记载。
- 外国人出願者要在入学前取得可以在大学院就读的在留资格。东京大学实行安全保障出口管理，部分考生需要事前审查，合格后也可能不能入学或研究内容受限。
- 入学料 282,000 日元，授業料半期 267,900 日元（年 535,800 日元），均为预定额；国费留学生免缴。
- 入学手续：2027年4月入学者在 2027年2月下旬收到通知，3月上旬办理；A日程的 2026年10月入学者已在 2026年9月上旬办理。
- 考试当天要带自己打印的 A4 受験票。受験者心得没有按时收到的要联系教務课（B日程以 2027/1/13 为限）。
- 成绩开示：只收邮寄申请。A日程的申请期间为考试结束后的 10/1–10/31 必达，B日程为 5/1–5/31 必达。
- 咨询：出願手续问农学生命科学研究科教務課学生支援チーム大学院学生担当（〒113-8657 東京都文京区弥生1-1-1，Tel 03-5841-5010，daigakuin.a@gs.mail.u-tokyo.ac.jp）；専攻内容问井澤 毅 教授（Tel 03-5841-5063，takeshizawa@g.ecc.u-tokyo.ac.jp）或専攻主任邮箱 aeb-chief@ab.a.u-tokyo.ac.jp。
