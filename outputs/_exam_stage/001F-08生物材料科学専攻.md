## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 须提交 TOEFL iBT（含 Home Edition）的公式成绩，研究科和専攻都不另设英语笔试。
- 送分方式：向 ETS 申请把 Institutional（Official）Score Report 送到东京大学农学生命科学研究科，DI 代码 1113；同时在 WEB 出願系统里填写 Appointment Number、受检日和分数。Test Taker Score Report 不用交。
- 有效成绩：A日程只认 2024/8/1–2026/6/13 之间受检的成绩。
- TOEFL ITP 和 MyBest スコア不受理。可以送多次成绩，但在出願系统里只能填一个分数。
- 官方没有公布最低分、换算方法和英语的配点。

### 日本語要件
- 要项没有要求提交日语成绩。
- 専門科目的试题语言在出願时从日语和英语中选一种，出願后不能更改。口述试验使用的语言官方未记载。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：A日程 17 名；本専攻不实施 B日程（要项的募集人员表里本専攻的 B日程一栏为“×”）。这个数字读自要项的募集人员表，表格文字提取时栏位略有错位，建议对照要项原表再确认一次。
- 出願资格：日本的大学毕业或 2027年3月31日前预计毕业、在外国完成16年学校教育、在外国取得相当于学士的学位（3年以上课程）等（1）–（6）项之一；第（6）项为个别入学资格审查合格且 2027/3/31 时满22岁。
- 入学时期：A日程可以选 2026年10月入学或 2027年4月入学。10月入学只限 2026年9月以前已毕业或预计毕业的人，在 WEB 出願系统的入学时期栏里选择，出願后不能更改。
- 志望填写规则：对照“教员及专门分野一览”，在出願系统里填专门分野和教员姓名，最多填到第3志望；第2、第3志望可以填同一分野的其他教员，没有就不填。填写前要确认一览是最新版（本年度 2026/6/9 更新过）。
- 出願书类：入学願書（在系统里填写并上传照片）、出身大学的成绩证明书（含全部在学期间）、毕业（预定）证明书（写明学位名和授予日）、检定料缴纳证明、国费留学生证明书（仅该当者）、TOEFL 成绩。本専攻的修士入试案内没有另外指定専攻独有的提交物。入学手续时要交成绩证明书和毕业证明书的原件。
- 出願方式：只能通过 WEB 出願系统。期限内书类不齐的不受理，出願后原则上不能修改。受験票自己在考试前一天之前从系统打印并带到考场。
- 检定料 30,000 日元（国费留学生不用缴），A日程的缴纳期间为 2026/4/13–6/23（最后一天网上支付到 23:00、便利店终端到 23:30），可用便利店或信用卡支付，缴纳后不退。
- 并愿限制：同一日程内不能报研究科内的两个以上専攻。
- 外国人入学时须持有不妨碍读大学院的在留资格。依据外汇法的安全保障出口管理，入学前后会受审查，属于管制对象的即使合格也可能不能入学或研究活动受限。
- 个别入学资格审查（资格6）的申请截止为 2026/5/7（已过）；有障碍等需要受验照顾的申请截止同为 2026/5/7（已过）。
- 入学料 282,000 日元，授業料 年 535,800 日元（前期 267,900 日元），均为 2027年度预定额。在职入学的人在入学手续时要交单位的承诺书。
- 入学手续：10月入学者 2026年9月上旬；4月入学者 2027年2月下旬收到通知、3月上旬办理。
- 木造建築コース是另一条路线：只招社会人（要求2年以上相关实务经验），用单独的要项，専門科目为建築学、木材科学、木材利用システム学三选二，并且要交需事先联系志望教员才能准备的确认书。这不是本専攻一般修士入试的要求。
- 咨询：専攻方面找生物材料科学専攻 斎藤 幸恵 教授（03-5841-5251，aysaito@g.ecc.u-tokyo.ac.jp）；研究科方面找教務課学生支援チーム大学院学生担当（〒113-8657 東京都文京区弥生1-1-1，daigakuin.a@gs.mail.u-tokyo.ac.jp，TEL 03-5841-5010）。
- 成绩开示：A日程在入试结束后的 2026/10/1–10/31（必达）用规定的申请表邮寄申请。
