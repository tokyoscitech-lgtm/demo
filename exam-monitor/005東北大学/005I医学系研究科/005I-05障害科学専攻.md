## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 2027年度8月一般要项PDF第10页明确：TOEIC仅收デジタル公式認定証PDF，纸质扫描件不受理；TOEFL除指定DI 3332使学校在出願截止前可阅外，还须把Test Taker Score Report PDF上传TAO。以下夏季规定不直接作为尚未公布的1月入试条件。
- 8月入试：没有英语笔试，用外部考试成绩换算计分。可用 TOEIC L&R、TOEFL iBT（含 Home Edition）、IELTS（Academic）、Duolingo English Test。
- 有效期：2024/6/29 以后受检的成绩。成绩单须在 2026/7/10（周五）16:00 前送达。
- 提交方式：TOEIC 交デジタル公式認定証；TOEFL 须向ETS指定DIコード3332使大学在出願截止前可阅，并将Test Taker Score Report PDF上传TAO；IELTS 邮寄原件；Duolingo 由考试方把结果直接发到研究科。来不及拿到原件时可以先交网上成绩页面的复印件，之后补换原件。
- 可以交多份成绩，取换算后的最高分；交了之后不能替换。
- 团体受检的 TOEFL ITP、TOEIC IP 不受理。
- 要项没有写最低分数线，只写要求“相当于大学毕业生的英语能力”；换算公式和配点官方没有公布。
- 1月入试（総合医学専攻）的英语要求未公布（截至 2026-10-21）。

### 日本語要件
- 要项没有要求提交日语成绩（JLPT 等）。
- 过去问的小論文题目日英对照；作答可用的语言在本次读到的资料里没有写明。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 小論文（配点官方未公布，60分钟） | 全研究科修士·前期2年共用，不考専攻别的专门科目。2025年度第1次的过去问是 2 道论述题：一道就一个生命科学现象说明理由，一道围绕健康观念随社会的变化作论述，并联系自己研究生阶段的研究能做什么贡献 | 2027募集要项／过去问 |
| 书类等审查（配点官方未公布） | 各志望分野按志望动机·理由与抱负、学历·研究经历等评价基础学力、动机和适性 | 2027募集要项 |
| 1月入试（総合医学専攻） | 预定日程只列了书类等审查·口试，科目未公布 | 入试日程 |

- 合否判定：把书类等审查、小論文和英语外部考试成绩综合起来判定，各部分配点官方没有公布。障害科学専攻要求英语能力、专门知识·思考力、志望动机·适性都超过基准，并且特别重视书类等审查的结果。
- 分野配属：不按分野设定员；志望集中时按入试成绩顺序决定，可以填第2、第3志望（任意）。
- 题目倾向（体验记，非官方）：没有找到本専攻的体验记。

### 口述試験 / 面接
- **官方形式**：8月入试的要项里没有统一的面接科目，写的是各志望分野实施的「书类等审查」（2026/7/21–8/5），怎么实施要在 7/21 以后向分野确认；1月入试的预定日程写的是“书类等审查、口试（各志望分野实施）”，配点和时长未公布。
- **実際に聞かれた内容**：没有找到本専攻的体验记，各分野实际问什么没有公开信息。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：8月入试时障害科学専攻（博士課程前期2年）为 20 名（包含一般選抜、海外在住者対象特別選抜第1·2次等全部路线的合计），只设一般コース。再编后，前期2年课程全体（総合医学専攻）获批募集人员110名（现行 3 个前期课程·修士课程合计 92 名），各コース的人数在本次读到的通知里没有分列。
- 出願资格：大学毕业或 2027年3月底前预计毕业、取得学士学位、在外国完成 16 年学校教育等（1）–（8）项之一；（9）–（11）项（在大学 3 年以上以优秀成绩修满规定学分者、个别审查认定具有同等学力且到 2027年3月底满 22 岁者等）须在出願前接受入学资格审查。
- 入学资格审查的申请：8月入试为 2026/6/1（周一）–6/10（周三）16:00（已过）；1月入试预定 2026/11/4（周三）16:00 截止。
- 出願书类（8月入试）：照片（3 个月内，jpeg/png）、成绩证明书、毕业（预定）证明书（本学医学部出身者这两项免交）、受験信息登记（在 TAO 上填写并宣誓）、在留卡复印件（在留超过 90 天的外国人）、检定料汇款确认、英语成绩单。
- 另外要交给志望分野教授的两份：「志望动机·理由与抱负」（所定用纸，约 1,000 字）和「学历·职历·研究经历」（从 TAO 导出 PDF），都在书类等审查之前直接交给指导教授。

- 检定料 30,000 日元（银行汇款，手续费自付）；国费外国人留学生不用缴；2026年度风水灾受灾者有免除措施。
- 并愿限制：同一天实施的 2026年度10月入学、海外在住者対象特別選抜第1次、公衆衛生·遺伝カウンセリングコース特別選抜第1次，不能同时出願。
- 外国人出願前有的情况需要先向教務係确认资格。
- 入学料 282,000 日元（预定）。授業料（预定）：日本人学生 年 535,800 日元；外国人留学生 年 900,000 日元。2027年度起新设面向外国人留学生的奖学金（相当于授業料全额或半额），原来按经济理由的授業料免除到 2026年度为止。
- 入学手续的资料在 2027年3月上旬寄送，3月中旬办理（4月入学者）。
- 学位：现行障害科学専攻前期课程修业 2 年，授予修士（障害科学）；获批再编后移入総合医学専攻医科学コース前期2年，授予修士（医科学）（获批对照表PDF第2页）。
