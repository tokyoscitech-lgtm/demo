## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般選抜（不另设英语笔试，用外部考试成绩，按志望教员所属学府的方式提交；没有有效成绩不能合格）：
  - 環境情報学府区分：TOEIC L&R（公开考试）、TOEFL iBT（含 Home Edition）、IELTS 三选一，考试当天携带有照片的成绩单、按监考指示提交。原则上只收原件，复印件、下载的 PDF 不行；例外是国内受检的 TOEIC 可交带二维码的数字认定证打印件，2026年1月以后受检的 TOEFL iBT 和 IELTS Online 交下载打印的受験者用成绩单。须为考试日前 2 年以内受检；考过多次的交合计分最高的一次；TOEFL 按 Test Date Score，不用 MyBest Score。
  - 環境情報学府区分换算成 100 分：TOEIC 349 以下 0 分，350–500 为（分数−350）÷3，500–800 为（分数−500）÷6＋50，801 以上 100 分；TOEFL iBT 新分数 2 以下（旧 33 以下）0 分、2.5（34–43）40 分、3（44–57）70 分、3.5（58–71）90 分、4 以上（72 以上）100 分；IELTS 3 以下 0 分，3–4 为（分数−3）×50，4–7 为（分数−1）×50÷3，7 以上 100 分。例如 TOEIC 650＝75 分，IELTS 5.5＝75 分。
  - 理工学府区分：只认 TOEIC L&R（公开考试）和 TOEFL iBT（含 Home Edition），不认 IELTS。TOEIC 当天交 Official Score Certificate 原件（国内受检可交数字认定证打印件）；TOEFL 要由 ETS 直送 Official Score Report（机构代码 0410），并在当天交 Test Taker Score Report。成绩单在学科試験Ⅰ时间内回收，须为提交日前 2 年以内受检、带照片；不用 MyBest Score。换算成 100 分，TOEIC 公式与上面相同。
  - 経営学専攻区分：TOEFL iBT（含 Home Edition）或 TOEIC L&R，须为第2次選抜日前 2 年以内且出願开始日前受检。TOEFL 要由 ETS 直送 Official Score Report（Institution Code 0410，Department Code 99），出願开始前就要办好直送手续，并在出願时交 Test Taker Score Report 复印件或网站打印件，按 Test Date Scores 计；TOEIC 交 Official Score Certificate 原件（国内受检可用数字认定证，国外受检交 Official Score Report 原件）。成绩没送到原则上不受理出願。配点学環要项没写。
  - 各区分都不受理 TOEIC IP、TOEFL ITP 等团体考试和 TOEIC Bridge、TOEIC S&W；要项没有规定最低分。
- 特別選抜：本身不按外部成绩计分，口述试验中含英语提问；落选后转考一般選抜的人仍要按所属学府的方式交成绩。
- 社会人特別選抜：要项没有英语成绩要求。

#### 日本語要件
- 要项对応用AI 没有要求提交日语成绩（JLPT N1/N2 只针对志望経済学専攻教员的外国人，応用AI 没有该専攻的教员）。
- 研究（希望）計画書必须用日语写（1,000 字以内），各选拔相同。環境情報学府区分的笔试和口述可以用英语作答；経営学専攻区分的论文必须用日语作答；理工学府区分的作答语言学環要项没写。
