## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 一般選考（秋季·春季）：当天进行英语笔试（科目名“英語”，9:00–10:30，90分钟），只能选英语；可带1本纸质词典，电子词典不可；配点官方未公布。
- 不需要提交 TOEFL、TOEIC、IELTS 等外部成绩，要项里也没有用外部成绩代替笔试的规定。
- 社会人特別選考没有英语笔试。

### 日本語要件
- 外国人出願者须提交 日本語能力試験（JLPT）的成绩证明书。要项表格中経済学研究科与文学研究科排在同一组，显示为 N1 相当（表格合并单元格，读法存在歧义，出願前宜向学務部大学院課确认）。
- 试题与面接用日语进行；研究计划书须用日语书写。官方没有设外国人留学生特别选拔。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 英語（90分钟 9:00–10:30；配点官方未公布） | 英语笔试，可带1本纸质词典 | 2027募集要项 |
| 専門科目（90分钟 11:00–12:30；配点官方未公布） | 从 ミクロ経済学、マクロ経済学、計量経済学、データ科学、コンピュータ科学 中选1科目；要求选与入学后专攻科目相同或相近的科目 | 2027募集要项 |
| 社会人特別選考 | 没有笔试，凭出願书类（论文、研究计划书等）面接・口述 | 2027募集要项 |

- 一般選考由英语、専門科目、面接・口述三部分综合判定，并参考研究计划书；各科配点和合格基准官方未公布。
- 专攻 Q&A 说明出願不要求经济学或数据科学背景，入学后有补习性质的教育。
- 题目倾向（体验记，非官方）：没有找到本専攻的合格体验记；过去问只能到窗口阅览。

### 口述試験 / 面接
- **官方形式**：一般選考在笔试当天 13:30 起进行面接・口述，内容为出願书类的审查和所选专门科目笔试的相关内容；社会人特別選考 9:30 起，以出願书类为基础考查专门领域的基础学力。时长和配点官方未公布，用日语进行。
- **実際に聞かれた内容**：没有找到本専攻的面接体验记。

## 📝 详细信息
### 出願資格 / 定員
- 一般選考的募集人员为4名（2027年度募集起适用，秋季·春季合计，要项没有分开写）；社会人特別選考人数在募集定员页未标明（要项写为若干名）；本校生的特別選考人数未公布；没有推薦選考。
- 一般選考出願资格：大学毕业或2027年3月预计毕业、由大学改革支援・学位授与機構授予学士、在外国完成16年学校教育、经个别入学资格审查认定且到2027年3月底满22岁等，共9项之一。
- 社会人特別選考：满足一般選考资格之一，并且是可在职入学的正式职员，或大学毕业后有3年以上社会经验（含家庭主妇/主夫）的人。
- 特別選考（A/B/C日程）只面向满足成绩基准的东北学院大学毕业预定者，要项只在学内网站公开，这不是一般考生的路线。
- 出願书类（一般選考）：入学志愿书、研究计划书、成绩证明书、毕业（预定）证明书、最终学历为大学院者的修了证明书、在职者的通学证明书；外国人另交在留卡复印件、外国人出願申请书、JLPT 成绩证明书。证明书须为发行后3个月以内。
- 研究计划书：1,200–2,000 字左右（每行40字、每页36行），用文字处理软件制作，A4 横排单面，不得订书钉装订，标页码，使用本校规定封面并注明字数，用日语写研究课题（问题意识尽量详细）、研究方法及相关业绩。
- 出願方式：先在 WEB 出願系统登记并缴费，再把书类用角2信封以邮局窗口“简易书留速达”寄送（期限内必达），或在平日 9:00–17:00（最后一天到 15:00）送到入試部アドミッションズ・オフィス。只做 WEB 登记不算出願完成。受験票不邮寄，考试日7天前起在 My Page 自行打印。
- 检定料 33,000 日元（另加支付手续费），通过 WEB 出願系统支付，任何理由都不退还。
- 没有大学毕业资格的人须先接受出願資格事前審査（免费）：春季 WEB 2026/11/24（周二）–12/2（周三）22:59，书类 2026/12/4（周五）15:00 截止（秋季已截止）。
- 入学手续：秋季合格者 2026/12/11（周五）15:00 截止，春季合格者 2027/3/12（周五）15:00 截止。博士前期可申请日本学生支援机构贷与奖学金相关的授業料后付制度。
- 学费：大学院概要页给出文系四研究科（含経済学研究科）2027年度的参考额为每年 867,000 日元（2年合计 1,734,000 日元），入学金和诸会费另计；长期履修（3年）时每年 578,000 日元，总额不变。
- 在职或有育儿、护理负担者可用长期履修制度（修士最长4年）；有一定雇佣形态的社会人学生可获给付型奖学金，每半期15万日元、年最多30万日元（与本校给付奖学金、TA 雇佣不可兼得）；另有 TA 制度。课程昼夜开设。
- 另有“経済データサイエンス 履修証明プログラム”（2027年度：申请 2027/1/8–1/21，定员4名，书类审查，学费按每2学分4万日元计），这是非学位的进修课程，不是修士入试的路线。
- 考场：土樋キャンパス（仙台市青葉区土樋一丁目3-1）。考场规则见2027年度受验注意事项。
- 咨询：选拔相关为入試部アドミッションズ・オフィス（Tel 022-264-6455，ao-sec@g.tohoku-gakuin.ac.jp）；大学院整体为学務部大学院課（仙台市若林区清水小路3-1，Tel 022-354-8202，daigakuin@g.tohoku-gakuin.ac.jp）；本専攻为 ecdsc_grad@g.tohoku-gakuin.ac.jp。合否不接受电话查询。
