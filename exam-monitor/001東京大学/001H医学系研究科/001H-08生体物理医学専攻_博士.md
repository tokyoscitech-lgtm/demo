## 🎯 入試内容（考什么）

### 語学

#### 英語要件

不另设英语笔试，提交 TOEFL iBT（包括 Home Edition）成绩；受理 **2024/10/1及以后**参加的考试。官方期待超过新量表3.5（旧量表60分），但低于该值仍可出願，不能当作资格最低分；极低成绩可能被判定不具备修读所需英语能力。

出願截止前须完成三项：①向 ETS 申请寄送 Official Score Report，DI Code **8426**、Division「Graduate Organization」、Department **42 Medicine**；②在网申登记该次考试的 Appointment Number 和考试日期；③上传同一次考试的 Test Taker Score Report PDF。报告不一致、未确认收到正式送分或使用有效期外成绩均可能无效。英语文件未给出公开换算公式或配点。

在外国完成或预计完成18年学校教育，且最终医学、齿学、药学或兽医学课程以英语授课者，可申请免交 TOEFL；须按资格审查安排在2026/6/11前提交证明，不能自行认定免除。送分困难者也须在该日前咨询教务；其他考试不可自行替代。

#### 日本語要件

外国籍考生须上传日本語能力証明書；日本大学毕业或预计毕业者免交。可使用指导教员等出具的证明、日语学校证明，或日语检定考试合格证复印件。没有指定JLPT等级或分数门槛。公开要项未逐题规定试题及作答语言；拟使用英语应事先向志望领域确认。

## 📝 详细信息

### 出願資格 / 定員

- 募集人员：17名（本専攻2027年度入学定员）。
- 出願资格：医学・齿学及6年制药学・兽医学毕业、符合条件的外国18年学校教育等；日本大学院修士／专业职学位持有者等也有资格。外国修士、16年教育加研究经历等须对照资格条款，需个别审查者先于2026/6/4邮件联系、6/11前交审查材料（非独立出願）。
- 要提前准备的书类：TOEFL正式送分与本人报告、适用时的日本語能力証明書；外国学历材料附日／英译文，需要时另交学位取得证明、资格审查或利益相反申报材料。
- 出願：2027年度改为网上出願及材料上传，截止当日23:59；检定料30,000日元。

### 研究室 / 指導教員

- 事前連絡要否：必须。募集要项要求出願前与志望指导教员联系，确认拟开展的研究。

生体機能制御学在2027年度受入予定表中未列接收导师，拟选择该领域须先向専攻确认。

- 放射線診断学：阿部修 教授、花岡昇平 准教授｜神经影像、体部影像、医学影像工程、机器学习｜[研究室](https://radiology.m.u-tokyo.ac.jp/)
- 放射線治療学：山下英臣 准教授｜肿瘤放疗、医学物理、放疗工程、姑息治疗｜[研究室](https://radiology.m.u-tokyo.ac.jp/)
- 核医学：高尾英正 准教授｜PET与SPECT、神经核医学、放射免疫治疗、影像解析｜[研究室](https://radiology.m.u-tokyo.ac.jp/)
- システム生理学：[山本希美子](https://researchmap.jp/0358413564) 准教授｜力学生物学、血流感知、血管内皮、循环生理｜[研究室](https://square.umin.ac.jp/bme/)
- 生体情報学：[浦野泰照](https://researchmap.jp/uranokun) 教授、[小嶋良輔](https://researchmap.jp/rkojima) 准教授｜化学生物学、荧光探针、合成生物学、胞外囊泡、肿瘤诊疗、药物递送｜[研究室](https://cbmi.m.u-tokyo.ac.jp/)

- 医療材料・機器工学（原田研究室）：[原田香奈子](https://researchmap.jp/kanakoharada) 教授｜医疗机器人、手术支援、医疗器械、技能评估、机械工程｜[研究室](https://sites.google.com/g.ecc.u-tokyo.ac.jp/cdbim-medical-devices/home)
