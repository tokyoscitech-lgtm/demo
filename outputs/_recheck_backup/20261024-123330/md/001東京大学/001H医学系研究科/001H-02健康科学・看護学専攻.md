## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 须提交 TOEFL iBT（含 Home Edition）或 IELTS Academic 的成绩，専攻不另设英语笔试，以成绩做外国语审查。IELTS General Training 和 One Skill Retake 的成绩不受理。
- 有效期：2024/8/1 以后受检的成绩。
- TOEFL 的送分方式：通过 ETS 账户把 Official Score Report 寄给研究科（DI Code 8426，Division 为 Graduate Organization，Department 为 42 Medicine），在 WEB 出願系统登记 Appointment Number 和考试日期，并上传 Test Taker Score Report 的 PDF。
- IELTS 的送分方式：在 WEB 出願系统上传 Test Report Form，同时向 IELTS 事务局申请把同一次考试的成绩单寄到研究科学務チーム大学院担当。
- 官方成绩没有送达、上传的内容与官方成绩不一致、考试日早于有效期的，成绩无效。成绩送达的具体截止日在本次读到的资料里没有确认到，以英语说明 PDF 为准。
- 官方没有公布最低分和换算方法。
- 免除：在澳大利亚、加拿大、爱尔兰、新西兰、英国、美国的大学取得学士学位（含预计毕业）的人，或在其他国家全英语授课的大学取得学士学位并有证明的人，可以申请免除外国语审查，申请截止为 2026/6/5（周五）（已截止）。只凭硕士、博士学位不能免除。

### 日本語要件
- 外国人出願者须提交「日本語能力証明書」：由指导教员等相关人员出具，或提交日语学校的证明；持有日本語能力試験合格证的可以交复印件。日本的大学毕业或预计毕业的人不用交。
- 官方没有规定 JLPT 的等级或分数线。笔试的作答语言官方资料没有写明。

- 第一次考试按外国语审查、小論文、笔试（保健学·専門領域）综合评价；最终按出身学校成绩、提交书类、笔试和口述的结果综合判定。
- 考试的时间段、线上考试的具体做法只在出願后通过 WEB 出願系统マイページ发放的「受験者心得」里通知，研究科明言不回答事先询问。
- 题目倾向（体验记，非官方）：本次没有获取到可核实的体验记。

### 口述試験 / 面接
- **官方形式**：第二次考试为线上口头试问，对象是第一次考试（笔试）的合格者。希望履修保健師或助産師教育コース的人，其选拔和这场口述一并进行，依据入试成绩和「教育コース履修希望書」判定。提问内容和时长官方没有记载。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员为 25 名。其中保健師教育コース上限约 10 名、助産師教育コース约 5 名（两者不能同时选；须持有或预计取得日本的看護師资格）。
- 出願资格：日本的大学毕业或 2027/3/31 前预计毕业；在外国完成 16 年学校教育；在外国大学修业 3 年以上并取得相当于学士的学位；文部科学大臣指定的教育机构修了、由大学改革支援・学位授与機構授予学士学位；或经个别入学资格审查认定并且入学时满 22 岁的人。
- 个别入学资格审查：研究科通知的联系截止为 2026/5/29（周五），审查材料提交截止为 2026/6/5（周五），均已过。
- 出願书类：入学願書、证件照（jpg）、検定料缴纳凭证、成绩证明书、毕业（预计）证明书、TOEFL 或 IELTS 成绩、小論文、誓約書（指定样式，签名）；只有希望履修教育コース的人交「教育コース履修希望書」（A4 一页，写姓名、志望指导教员、希望的コース名，以及该コース与研究内容的关系）；外国人另交日本語能力証明書；改过姓名的交证明。证明书的原件在合格后办入学手续时提交。
- 検定料 30,000 日元（国费留学生免缴），可用银行汇款、便利店、Pay-easy、信用卡，手续费自付；缴纳按 WEB 出願系统的指示办理。
- 入学料 282,000 日元，授業料 年 535,800 日元（前期 267,900 日元），均为 2027年度预定额。
- 在职的人办入学手续时要交所在单位的同意书（样式不限）。
- 咨询：医学系研究科学務チーム大学院担当（〒113-0033 東京都文京区本郷7-3-1），in.m@gs.mail.u-tokyo.ac.jp；研究科入试页另有咨询表单。书类不能按时提交的须事先用该邮箱联系，出願截止后一律不受理。

### 研究室 / 指導教員
- 事前連絡要否：必须。専攻入试案内写明，提交出願书类之前一定要先联系志望的指导教员；指导教员从志望分野的教授或准教授中选。联系的期限官方没有规定。本年度退休或离职的教员可能无法指导。
- 部分分野在 4 月的全体说明会之后开个别说明会，其余时间想了解的直接联系各教室。
