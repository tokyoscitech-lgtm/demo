## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 8月实施和1-2月实施：不设英语笔试，必须提交外部英语检定成绩，配点 100 分。7月实施（推薦）不考英语，也不用交成绩。
- 受理的考试：TOEIC Listening & Reading、TOEFL iBT（含 Home Edition）、IELTS Academic。不受理：TOEIC IP、TOEFL ITP、IELTS General Training、IELTS 在线版、IELTS One Skill Retake。
- 提交方式：TOEIC 交デジタル公式認定証（Web 上填写 URL 并附打印件）或纸质公式認定証原件；TOEFL iBT 交 Test Taker Score Report 原件，或让 ETS 直送 Official Score Report（机构代码 9995，部门代码 99）；IELTS 须让考试机构把 Additional TRF 数据直送大学，并交成绩单复印件。
- 有效期：8月实施须为2024年7月以后受检，1-2月实施须为2025年1月以后受检。
- 换算：达到基准分的换算为英语满分 100 分——TOEIC 860、TOEFL iBT（含 Home Edition）98、IELTS 7.0。低于基准分时怎样换算，要项没有公布公式。
- 没有在期限内提交有效成绩的，出願不受理或按缺考处理，不进入选考。
- 自2022年度入试起一直是这种“只交外部成绩、没有英语笔试”的做法，本年度没有变更。

### 日本語要件
- 要项没有要求提交 JLPT、EJU 等日语成绩，也没有针对外国人留学生的另设区分，留学生与日本学生参加同一场考试。
- 要项没有写明数学试题和作答所用的语言；公开的过去问是用日文出题的。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 8月实施：専門科目 数学（600分，180分钟） | 共6题、选3题作答，每题一张答题纸。按过去问（2025年8月）和出題意図：[1] 微积分、[2] 线性代数、[3] 代数学（内部二选一）、[4] 几何学（位相·微分几何）、[5] 解析学（复分析·实分析）、[6] 情報数学（数理逻辑/集合论、概率统计、计算机数学，内部三选一）；计算与证明混合，每题3–4个小问 | 2027募集要项／过去问（令和8年度8月期）及出題意図 |
| 1-2月实施：専門科目 数学（600分，180分钟） | 科目、配点、时间与8月实施相同；令和7、令和8年度的1·2月期试题单独公开，题型构成本年度是否与8月完全一致未核实 | 2027募集要项英语版／过去问页 |
| 7月实施（推薦）：筆記試験 小論文（100分，90分钟） | 名为小論文，实际是解答数学题目；令和7、令和8年度的7月期小論文及出題意図已公开 | 2027募集要项／过去问页 |

- 8月实施和1-2月实施的总分是 1000 分：数学 600＋英语 100＋口述 300。7月实施（推薦）总分 200 分：小論文 100＋面接 100。要项没有公布合格最低分和具体判定方法。
- 社会人特別選抜与一般入学試験在同一张试验日时表里，科目和配点相同；另外要交研究计划书。
- 题目倾向（体验记，非官方）：没有找到本プログラム的考生体验记，暂无可写的内容。

### 口述試験 / 面接
- **官方形式**：三个轮次都有个别面接，就专业等内容进行试问。8月实施 2026/8/21 和1-2月实施 2027/1/28 都安排在笔试的次日 10:00–17:00 之间（每人的具体时段另行通知），配点 300 分；7月实施（推薦）在笔试当天 13:00–17:00，配点 100 分。面接使用的语言和每人的时长要项没有写。
- **実際に聞かれた内容**：没有找到本プログラム的面接体验记，实际提问内容不明。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：7月实施（推薦入学試験）5名；8月实施 一般入学試験22名、社会人特別選抜1名；1-2月实施 一般入学試験2名、社会人特別選抜若干名（“若干名”只读到一次，未核实）。10月实施本プログラム不举行。
- 出願资格：日本的四年制大学毕业或2027年3月底前预计毕业、由大学改革支援·学位授与機構授予学士学位、在外国完成16年学校教育、在外国3年以上的课程取得相当于学士的学位等。22岁以上、希望被认定为“与大学毕业同等以上学力”的人，要先申请个别出願资格审查。
- 个别出願资格审查和出願资格咨询的截止日：7月实施 2026/5/20（已过）；8月实施 2026/7/3（已过）；1-2月实施 2026/11/24（周二）。用邮件向数理物質エリア支援室大学院教務申请。
- 推薦入学試験（7月实施）的资格：出願时已修得的学分中，A（優）评价的科目占总学分70%以上的人，或在特定研究领域特别优秀的人；须交所属学部长等签名盖章并密封的推薦書。
- 志望指导教员：在 Web 出願系统里选择志望的指导教员；出願前必须已经取得该教员的内诺（见下一小节）。报社会人特別選抜的要向教员说明是用社会人特別選抜名额。
- 出願书类：毕业（预计）证明书原件、成绩证明书原件（有编入学的要连同编入前的成绩）、外国大学出身者的学位取得（预计）证明书、外部英语成绩（8月·1-2月实施）、推薦書（7月推薦）、研究计划书（7月推薦、8月社会人、1-2月社会人；用 Web 出願后下载的 Word 样式）、检定料收纳证明（便利店支付者）、在学或在职者的受験·就学承认书（所属长签名，样式不限）、出願者調書等。证明书类只收日文或英文。
- 出願方式：在 Web 出願系统注册邮箱 → 录入出願信息并上传证件照（JPEG）→ 选择志望指导教员 → 支付检定料 → 点击「出願」→ 打印受験票等 PDF。之后把书类装进角形2号信封、贴上系统打印的收件人标签，用書留寄到数理物質エリア支援室，截止日必达；送到窗口的话最后一天 17:00 截止。一个账号只能报一个学位プログラム。
- 检定料 30,000 日元，信用卡（VISA、Mastercard、JCB、AMEX）或便利店（ローソン、セブン-イレブン、ファミリーマート、ミニストップ）支付，手续费由出願者负担，缴纳后不退。国费外国人留学生不收。
- 外国人留学生须按安全保障出口管理的规定接受「みなし輸出」确认并取得リファレンス番号；属于限制对象的，可能无法接受希望的教育研究。
- 需要受験上配虑（残疾等）的人要在要项规定的期限前事先申请。
- 入学料 282,000 日元（缴纳后不退）。授業料每学期 267,900 日元（年额 535,800 日元）；外国人留学生每学期 304,400 日元（年额 608,800 日元）。入学手续的资料发到出願时登记的邮箱，合格通知书在线发放；入学手续的具体日期没有读到。
- 试场：筑波大学筑波キャンパス（茨城県つくば市天王台1-1-1），具体建筑和教室另行通知。可携带物品、迟到规定没有读到。
- 成绩开示：只对不合格的本人开放，2027年度入试的受理期间是 2027/5/1–5/31。
