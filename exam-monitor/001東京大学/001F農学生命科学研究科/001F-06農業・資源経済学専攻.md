## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各日程相同：不另设英语笔试，用 TOEFL iBT（含 Home Edition）成绩评价；专攻可能按 TOEFL 成绩做事前选拔，书类选考不合格检定料也不退。
- 须在有效期内受检并向 ETS 申请把 Institutional (Official) Score Report 送到研究科（DI code 1113）：A日程 2024/8/1–2026/6/13，B日程 2025/2/1–2026/11/15；出願时在 WEB 出願系统填写 Appointment Number、受检日和分数，送过多次也只指定一次。
- TOEFL ITP 不受理，MyBest Scores 不采用。
- 变更点：2026年度还要上传 Test Taker Score Report，2027年度改为只填 Appointment Number、由 ETS 直送。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 専門科目试题日英并记，除题目另有指定外可用日语或英语作答；口述语言由考生在日语和英语中选择。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 専門科目（5科选3） | 出願时从農業経営学、経済学、フードシステム学、農政学、開発経済学中选3科；第1志望教员指定了科目的必须全部选上；对面笔试，往年都是小论文 |  |

- 教员指定科目：安藤 光義＝農業経営学＋農政学；小嶋 大造＝農政学；川崎 賢太郎、LIU Jingyu＝経済学＋フードシステム学＋開発経済学；八木 洋憲＝農業経営学。
- 2026年度出题（出题意图）：農業経営学考技术普及理论与政策含义、新事业成长过程；経済学考用微观经济学分析农业·资源问题、农业风险与保险；農政学考农业政策的目的与手段；開発経済学要求精读一篇人力资本·教育·性别差距领域论文并写评论和政策建议。
- 2026年度的科目名是「農業経済学」，2027年度改为「フードシステム学」。
- 变更点：2027年度起専門科目改为本研究科对面笔试（2026年度为线上）。

### 口述試験 / 面接
- **官方形式**：A日程、B日程都对面进行，以志望理由書为基础提问，语言由考生在日语和英语中选择；社会人出願者另就研究計画書问答。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：A日程（2026年10月入学＋2027年4月入学）17名；B日程（2027年4月入学＋2027年10月入学）若干名。
- 出願资格：大学毕业（含 2027/3/31 前预计）或外国 16 年学校教育等 6 项之一；个别入学资格审查 A日程 2026/5/7、B日程 2026/10/7 截止（非独立出願，均已过）；同一日程只能报本研究科一个専攻，A、B 两日程可以都报；10月入学在出願时选定，之后不能改；志望专门分野和教员最多填到第2志望。
- 要提前准备的书类：志望理由書（A4，日文 2,000 字以内或英文 1,000 words 以内，写问题意识和想研究的题目）；社会人另交研究計画書（A4，日文 4,000 字以内或英文 2,000 words 以内）；TOEFL 送分。
- 出願：只能通过 WEB 出願系统上传 PDF；检定料 30,000 日元（银行汇款、便利店、信用卡、Pay-easy，B日程缴纳期间 2026/10/5–11/25），日本政府奖学金留学生免缴。
- 并愿：同一日程只能报研究科的一个専攻；要项允许有资格的人 A、B 两日程都报，本専攻案内没有另设限制。
- 咨询：出願手续问农学生命科学研究科教務課学生支援チーム大学院学生担当（〒113-8657 東京都文京区弥生1-1-1，Tel 03-5841-5010，daigakuin.a@gs.mail.u-tokyo.ac.jp）；専攻事务按要项「各専攻のお問い合わせ先」联系専攻。
