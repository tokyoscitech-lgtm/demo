## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般選抜·私費外国人留学生選抜（两者相同）：
  - 不另设英语笔试，用 TOEFL-iBT 或 TOEIC L&R 成绩换算为英语得分（100分）；两种都交时取换算后较高的一个。
  - 按要项换算表在 TOEIC L&R 10–990、TOEFL-iBT 0–120 的范围内换算为 0–100 分（TOEIC 990＝TOEFL-iBT 120＝100分）；2026年1月起的 TOEFL-iBT 新分数（1–6）仍按旧的 0–120 分制换算，不用 MyBest scores。
  - TOEFL-iBT 由 ETS 直接送分（DI code 8549，考试前一天晚上前申请免费）；TOEIC L&R 交公式認定証原件（数字认定证打印件也可），TOEIC S&W 不认。成绩须在出願书类受理期内到达，未到按书类不备处理。
  - 有效期为出願期间前2年以内；TOEFL-ITP、TOEIC-IP 等团体受验成绩不受理。
- 推薦選抜：不收英语成绩。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 一般選抜的専門試験用日语出题，可用日语或英语作答（英文版要项）；私費外国人留学生選抜的试题日英并记，可用日语或英语作答。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 熱力学・流体力学（問題21） | 热力学（第一·第二定律、理想气体、一般关系式、气体与蒸汽循环、热的有效利用）；流体力学（静力学、含伯努利定理的一维流动、动量理论、量纲分析、管路流动、基础方程）；必答 | 9:00–12:00，180分钟（3题合计） |
| 力学・材料力学（問題22） | 质点与刚体力学、材料变形力学（材料力学、材料加工）、机械材料基础；必答 | 同上 |
| 制御工学B（問題23） | 拉普拉斯变换、传递函数、方框图、响应、频率响应、稳定性；必答 | 同上 |
| 私費外国人留学生選抜：専門試験（300分） | 問題11 力学・材料力学＋問題12 熱力学・流体力学，2题必答；日英并记 | 10:00–12:00，120分钟 |

- 一般選抜：問題21–23 三题全部必答，専門試験合计300分，各题时间自由分配。
- 一般選抜·私費外国人留学生選抜：専門試験 300＋英语 100，结合面接（5级）和成绩证明书按 A·B·C 三级评定，A 为合格；须参加全部科目和面接。推薦選抜按口述試験、推荐书、成绩证明书和志望理由书综合判定。

### 口述試験 / 面接
- **官方形式**：一般選抜：个人面接，考查研究意欲、适性、人物等，按5级评价，不计分，面接中会再确认希望的指导教员；社会人（不在大学就读者）可事先申请（2026/6/19 16:00 截止）以社会人口述試験（专门科目、业绩报告书、英语，8/20 进行）代替専門試験和英语成绩；私費外国人留学生選抜：个人面接，内容和评价方法与一般選抜相同；推薦選抜：口述試験，先用5分钟以内发表毕业研究进展（可用投影仪），再问发表内容和专业基础知识并面接，按5级评价。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：一般選抜 48名程度（受入目安；工学専攻合计386名）；推薦選抜 27名程度（工学専攻合计220名）；私費外国人留学生選抜 若干名。
- 出願资格：大学毕业（含2027/3预计）或外国16年学校教育等；资格(13)个别审查须在2026/5/11 16:00前申请（非独立出願，已过）；私費外国人留学生選抜限没有日本国籍（永住者除外）、持有或可取得「留学」资格、且不是日本的大学毕业（含预计）的人；推薦選抜须成绩优秀、取得学长·学部长·学科长等役职者推荐并确约入学，外国大学预计毕业者也可报。
- 要提前准备的书类：志望理由书（所定样式）；TOEFL-iBT 送分或 TOEIC L&R 原件；類型該当性の自己申告書（安全保障，全员提交）；外国人须事先把所定履歴書交给希望的指导教员（一般·私費 2026/6/12、推薦 4/13 前）；中国的学校出身者的成绩和学历须由 CHSI 直接把英文认证报告发到入試課，官方建议提前2个月以上申请；推薦選抜另需役职者推荐书。
- 出願：网上出願登録并缴检定料 30,000 日元（另付手续费 990 日元）后，书类用書留速達邮寄或在窗口（平日 9:00–16:00）提交，受理期内必达；只做网上登録不算出願。
- 并愿：推薦選抜要项规定推薦不合格者可另按一般選抜要项出願，推薦合格须入学；私費外国人留学生選抜与一般選抜另行募集、同日考试，在日本的大学毕业（含预计）的外国人只能报一般選抜，2027年度一般·私費要项未说明能否同时报两条路线；网上出願登録后不能修改志望内容；推薦選抜可填到第3希望教员，限同一プログラム内，最终不一定分到第1希望。
