## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 不另设英语笔试，用 TOEFL iBT 成绩评价；修士出願者全员提交，英语母语者也要交。
- 只收 TOEFL iBT（含 Home Edition）由 ETS 直送的 Official Score Report；MyBest scores 不采用，Test Taker Score Report 不受理，其他考试不能代替。
- 送分代码：University of Tokyo IS&T，Institution Code 8445，Division 选 Graduate Organization，Department Code 99；出願时填 Appointment Number 和受检日，出願后原则上不能更换。
- 受检日须在 2024/9/1 至出願截止日之间，成绩须在 2026/6/30 前到达研究科；没有有效成绩不能完成出願，成绩无效的失去笔试和口述的受験资格。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 専門科目试题有日文版和英文版，数学日英并记；研究计划书可用日文或英文写。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 一般教育科目（数学） | 线性代数、解析（微分积分、常微分方程等）、概率·统计各1题，3题全答；全研究科共通 | 13:00–15:30，150分钟 |
| 専門科目（電子情報学） | 从电气电子电路、计算机体系结构、逻辑电路、算法与数据结构、最优化·机器学习、信息通信、信号处理、信息论中出5题，选3题作答 | 10:00–12:30，150分钟 |

- 选拔流程：书类选考（成绩、TOEFL、研究计划书、推薦書等）→ 数学＋専門科目笔试 → 按笔试成绩选出口述对象 → 综合判定。
- 题目倾向（体验记，非官方）：5题对应的领域每年会变，考生一般准备4个左右学过的领域，当天挑3题；计算机体系结构常见缓存、有限状态机，算法题结合具体程序。

### 口述試験 / 面接
- **官方形式**：夏入试 2026/8/31 线上，只面向按数学和専門科目成绩选出的人；就笔试答卷、目前的研究题目、入学后的志望等提问。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：60名（夏入试，含 2026年10月和 2027年4月入学）。
- 出願资格：大学毕业（含 2027/3/31 前预计）或外国16年学校教育等；个别入学资格审查 2026/5/13 截止（非独立出願）；同一期只能报研究科内一个専攻；希望者可 2026年10月入学，需新办在留资格的外国籍考生官方强烈推荐 2027年4月入学；志望教员须填满10名（不足10名视为任何教员都可），提交后原则上不能改顺位，另可从清单最多选3个志望研究领域。
- 要提前准备的书类：研究计划书（専攻2027版样式，第1页研究题目和入学目的，第2–4页研究计划、参考文献、特记事项，11pt 以上，日文或英文）、推薦書（専攻样式，推荐人签名或盖章后本人上传，不限指导教员）、TOEFL iBT 成绩（ETS 直送）、安全保障輸出管理チェックシート（外国籍等）。
- 出願：只能通过 WEB 出願系统上传 PDF，没有邮寄和窗口受理；检定料 30,000 日元，日本政府（文部科学省）奖学金留学生免缴。
- 并愿限制：同一期只能报一个専攻、课程或选拔区分。
- 咨询：専攻入试事务室（工学部2号館4楼電気系事務室内），ice-admission@ee.t.u-tokyo.ac.jp，Tel 03-5841-6712；研究科入试担当，johoriko.t@gs.mail.u-tokyo.ac.jp，Tel 03-5841-7926（平日 9:00–17:00，出願咨询原则上用邮件），〒113-8656 東京都文京区本郷7-3-1。
