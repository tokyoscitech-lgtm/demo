## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 要项没有要求提交英语成绩，也不考英语。

#### 日本語要件
- 一般入学試験、社会人入学試験：要项没有要求提交日语成绩。
- 外国人留学生入学試験：出願资格要求 JLPT N1 合格，或 EJU「日本語（記述含む）」270 分以上（须在出願开始日有效）；交 JLPT 合否结果通知书或认定结果·成绩证明书原件，或 EJU 成绩的打印件；日语接近这一水平者可经个别入学资格审查后出願。
- 外国人留学生的志望理由書和研究計画書须用日语写；笔试与一般入学試験相同。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 専門科目①（50分） | 防災・減災的基础问题，记述式，从『社会安全学入門』（关西大学社会安全学部编，ミネルヴァ書房）的内容出题 | 10:00–11:30，与②合计90分钟 |
| 専門科目②（50分） | 与志望演習テーマ相关的基础知识 | 同上 |
| 社会人：専門科目（50分） | 防災・減災的基础问题，记述式 | 10:00–10:45，45分钟 |

- 一般·外国人留学生：専門科目① 50＋② 50＋口頭試問 100＝200分；社会人：専門科目 50＋口頭試問 150＝200分。
- 书类选考、笔试、口頭試問综合判定，按总分高低决定合否；笔试或口頭試問低于基准分的，不论总分都不合格；合格者可能少于定员。

### 口述試験 / 面接
- **官方形式**：笔试后同日口頭試問，一般·外国人留学生 100分，问专业基础知识、入学后的研究题目和研究方法、此前的研究内容；社会人 150分，另问社会人业务和经验与研究的关联。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：入学定员15名（不按入试种别和募集月设定名额）；一般·外国人留学生·社会人入学試験在10月和2月两次募集。
- 出願资格：一般为大学毕业（含预计）或外国16年学校教育、外国学士相当学位等，飞跃入学和同等学力认定须先过个别入学资格审查（2月募集 2026/12/3 必达，结果 12/10 通知，非独立出願）；外国人留学生除日语条件外须满足外国16年学校教育或日本大学毕业等学历条件；社会人另需3年以上社会经验或1年以上在职经历等。
- 要提前准备的书类：志望理由書（所定用纸，写明事前联系的日期和教员姓名）、研究計画書（约1,000字，A4 横写 40字×40行，原件＋复印件3份）；外国人留学生加交日语能力证明原件，外国籍者交在留卡或护照复印件；社会人加交業績報告書（约1,000字）。
- 出願：先在 Web 出願门户登录并缴检定料 35,000 日元（另付系统手续费），再把书类用簡易書留速達邮寄（截止日邮戳有效，海外国际快递截止日必达）或出願期间 10:00–16:00 到高槻ミューズキャンパス窗口提交；只做 Web 登录不算出願。
