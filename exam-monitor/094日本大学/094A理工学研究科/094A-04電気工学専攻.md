## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般第1期·第2期：
  - 研究科统一出题的外国語（英語）笔试，60分钟，全専攻共通；配点官方未公布。
  - 出願时可任意提交 TOEIC L&R 或 TOEIC L&R IP 成绩，按研究科规定换算后与英语笔试得分比较，取高者；这不是免考制度，提交了也要参加英语笔试。换算式官方未公布。
  - 成绩须为入学考试日起3年以内受检，交原件或复印件；数字公式认定证须打印后提交，PDF 不受理。TOEFL、IELTS 不在比较对象之列。
- 一般第3期、社会人入试、外国人留学生入试：不另设英语笔试，也不要求外部英语成绩。

#### 日本語要件
- 要项没有要求提交日语成绩（一般入试和外国人留学生入试相同）；理工学研究科的外国人留学生入试只有学内考试，不采用日本留学试验。
- 笔试和口述以日语进行，要项没有写其他作答语言。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |

| 一般第3期：笔试（120分钟） | ①从「電磁気学」「電気回路」出题；②关于大学院研究的论述 | 选考方法 |
| 外国人留学生：専門科目（120分钟） | 官方页面只写“専門科目”，未写范围 | 选考方法／外国人留学生要项 |

- 一般第1期·第2期按英语、専門科目笔试和面接综合判定；官方没有公布配点和合否判定方法。社会人入试不考笔试。
- 电卓：要项和外国人留学生要项允许使用电卓的専攻名单里没有本専攻，按不能使用准备。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：博士前期课程入学定员35名（全入试区分合计，官方未按期拆分）；社会人入试若干名。
- 出願资格：大学毕业或2027/3/31前预计毕业、取得学士学位、在外国完成16年学校教育等10项之一；以“预计”报考但到期未取得资格的不准入学。
- 个别出願资格审查：资格（10）须事先向理工学部入試事務室申请，一般第2期截止 2026/6/15（周一）邮戳有效、7/10 通知结果（已过）；资格（9）须事先咨询理工学部入試事務室。第3期的截止日随第3期要项公布。
- 出願方式（一般·社会人）：先在大学院入试Web出願系统登录志愿者信息并上传照片，再把书类以简易书留邮寄（截止日邮戳有效）；只做 Web 登录或只寄书类都不算完成出願。准考证从系统下载打印。
- 出願书类（一般）：入学志愿票（所定）、毕业（预定）证明书、成绩证明书、TOEIC 成绩（任意）、出願确认票（所定）、外国学校出身者用出願资格确认票（资格3·4·6者）；社会人另交履历书等。外国籍考生须附指导预定教员签发的事前連絡確認書。
- 检定料 35,000 日元，汇款到要项指定账户（汇款人姓名前加入试区分代码，如一般第2期为「23」），手续费自付；只有未提交书类或出願不受理时退还。
- 外国人留学生：通过日本大学本部的网上出願系统登录（2026/7/17 起受理），出願截止 2026/10/30 书类必达；检定料 35,000 日元；须先联系本専攻确认指导预定教员和研究计划，取得「事前連絡確認書（Pre-Application Consultation Form）」原件随书类提交，没有这份确认的不能在系统上完成出願。入学手续截止 2027/1/7（周四），两段式第2次截止 2027/3/25（周四）。
- 入学手续：一般第1期 7/29、第2期 9/30 截止（可选两段式，第2次截止 2027/1/29（周五））；第3期 2027/3/11（周四）–3/25（周四）；办完手续后辞退须在 2027/3/31（周三）下午前电话告知理工学部入試事務室。
- 初年度纳入金：学外者 1,370,000 日元、本校出身者 1,170,000 日元（含入学金 200,000 日元，仅学外者缴纳）。自费外国人留学生可按经济状况和修得学分申请授業料减免20%（2027年度预定）。
- 考场：日本大学理工学部駿河台校舎（东京都千代田区神田駿河台1-8-14）。
- 本専攻其他路线：学内推薦（2026/7/11 实施，已结束）只限本校学生。
- 咨询：理工学部入試事務室 Tel 03-3259-0578，cst.nyushi@nihon-u.ac.jp；電気工学専攻 Tel 03-3259-0777，cst-denki@nihon-u.ac.jp。
