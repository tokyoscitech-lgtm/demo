## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 一般入试（第1次／第2次）：只认 TOEIC，配点 200 分。可在考试第1天 9:00–11:40 现场参加 TOEIC IP 考试，也可出願时提交已有成绩；两者都有时取高分。
- 已有成绩须为 2025年5月以后受检：IP 考试交成绩报告原件，公开考试交公式认定证原件或用成绩确认服务授权大学查询。出願后不能补交。
- 换算：TOEIC 590 分以上＝200 分；220–589 分＝0.5×分数－95（例：TOEIC 500＝155 分）；未满 220 分＝15 分。没有足切最低分。
- 外国人留学生入试（国内出願）：出願时选日语或英语作为考试语言；选英语的规则与一般入试相同（200 分）。
- 外国人留学生入试（国外出願）：只看书类，没有英语成绩要求。
- 社会人入试：不考笔试，口述试验中包含英语。

### 日本語要件
- 一般入试：要项没有要求提交 JLPT／EJU 等日语成绩，试题用日语。
- 外国人留学生入试（国内出願）：选日语作为考试语言的，在第1天 10:00–11:20 参加大学实施的日语笔试（200 分，替代 TOEIC）；不需要提交 JLPT 等成绩。
- 外国人留学生入试（国外出願）：没有日语成绩要求，书类可用日文或英文。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 英语（200分，第1天 9:00–11:40） | TOEIC 成绩换算（可现场考 IP）；留学生（国内）可选日语笔试 | 2027募集要项 |
| システム情報学コース／共創情報学コースH系 第1天（13:00–15:00） | 情報学基礎和計算機システム领域出题，必答 | 2027募集要项 |
| システム情報学コース／共創情報学コースH系 第2天（9:00–11:00） | 情報数学、確率統計、データ構造とアルゴリズム、プログラミング 各2题共8题，选4题作答 | 2027募集要项 |
| 電気電子工学コース／共創情報学コースI系 第1天（13:00–14:30） | 工業数学，必答 | 2027募集要项 |
| 電気電子工学コース／共創情報学コースI系 第2天（9:00–11:00） | 電磁気学、電気回路、電子回路 3科目选2 | 2027募集要项 |
| 共創情報学コース A〜G系 | 按所选系考对应専攻的科目（如 A系 化学生物システム基礎＋6选3，E系 数学＋机械5科目，G系 力学・热力学・电磁学＋应用物理学），第1天和第2天不能选不同的系 | 2027募集要项 |
| 留学生（国内出願）システム情報学・H系 | 第1天同上；第2天改为情报科学・工学相关小论文（必答，9:00–11:00） | 2027留学生（国内）要项 |

- 一般入试总分 1,000：英语 200＋専門科目 600＋面接 200。要项没有写各科目内部配分和合格最低分。
- 留学生（国内出願）总分 1,000：日语或英语 200＋専門科目 600＋口述试验与最终学历成绩 200。
- 推荐・高专入试：口述试验 300＋学业成绩 200＝500 分，不考笔试。
- 变更点（2028年度予告）：システム情報学・H系第2天改为从情報数学、確率統計、データ構造とアルゴリズム（予告一般入试栏仍列出プログラミング）中"3科目选2"；留学生（国内）的小论文改为上述3科目选2。予告措辞前后不一致，以2027年公布的新要项为准；本年度不受影响。

### 口述試験 / 面接
- **官方形式**：一般入试第2天 13:30 起按コース面接（200 分）；共創情報学コース的面接还会问对信息领域的关心和意欲。留学生（国内出願）口述试验用所选语言进行，与最终学历成绩合计 200 分。要项没有写面接时长和具体提问。
- **実際に聞かれた内容**：没有找到本専攻的体验记。
