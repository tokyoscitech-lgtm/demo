## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般選抜（第1期一般枠、第2期）：
  - 必须提交 TOEIC 或 TOEFL 成绩：TOEIC L&R 的 Official Score Certificate 或 Score Report（含团体 IP，IP 线上方式不受理）、TOEFL iBT 的 Test Taker Score Report（Official Score Report 不受理）、TOEFL ITP 的 Score Report；自宅受验方式不受理。
  - 只认 2024/4/1 以后实施的考试；交原件或可验证真伪的数字公式认定证打印件，交后不退还、不能替换。
  - 出願时交不出的先交「未提出理由書」（所定样式），第2期须在 2027/2/1（周一）前用書留速達补寄、必达，逾期失格；第1期不合格再报第2期的，可以沿用第1期交过的成绩（另附任意样式说明）。
  - 成绩作为书类审查的一部分评价英语交流能力。
- 第1期 学業成績優秀者特別枠的合格内定者免交。
- 社会人特別選抜、外国人留学生特別選抜不交英语成绩；社会人特別選抜在口頭試問里确认英语交流能力。

#### 日本語要件
- 要项没有要求提交日语成绩；人文社会科学専攻对外国人留学生特別選抜的日语门槛不适用于本専攻。
- 外国人留学生特別選抜的口頭試問确认日语或英语的交流能力；志望理由書、研究計画書样式有日文版和英文版，英语以外的外文证明须附日文译文。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|

| 第1期 学業成績優秀者特別枠：无笔试 | 书类审查（志望理由書、履歴書、成绩证明书）＋口頭試問 |  |
| 社会人特別選抜、外国人留学生特別選抜：无笔试 | 书类审查（志望理由書、研究計画書、履歴書、成绩证明书）＋口頭試問 |  |

- 按书类审查和口頭試問综合判定：成绩证明书看专业基础，志望理由書看跨学科视野，研究計画書看问题解决能力和书面表达，TOEIC/TOEFL 看英语能力。
- 出願时出題分野只有 1 个：MJ フィールド科学分野，口頭試問按此确认专业知识。

### 口述試験 / 面接
- **官方形式**：口頭試問以志望理由書和研究計画書为中心，确认所报出題分野的专业知识（第1期特別枠以志望理由書为中心、确认基础知识）；社会人特別選抜另确认英语交流能力，外国人留学生特別選抜另确认日语或英语交流能力；本プログラム的实施方式：一般選抜对面；社会人特別選抜、外国人留学生特別選抜线上；集合时间和开始时刻随「受験案内」通知（第2期 2027/1/22 起下载）。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：15 名（目安，第1期·第2期合计；自然科学専攻合计 507 名）。
- 出願资格：大学毕业（含 2027年3月预计）或外国16年学校教育等；外国3年制学士、外国15年课程、个别审查等须先申请事前資格審査（第2期 2026/11/13 邮寄必达（已截止），12/7 速達通知，非独立出願）；外国人留学生特別選抜限以外国人留学生身份报考者，社会人特別選抜要求 2027/4/1 时在职满2年；第2期不设学業成績優秀者特別枠。
- 要提前准备的书类：志望理由書、研究計画書（所定样式，日文或英文；第2期只能在出願期间内提交）、TOEIC/TOEFL 成绩（一般選抜）、外国籍者的护照和在留卡复印件。
- 出願：先在网上出願站（e-apply）登记，登记当天起4天内缴检定料 30,000 日元（便利店、Pay-easy、网银、信用卡、Flywire），再把彩色打印的願書等用書留速達寄到自然科学研究科学務係，期限内必达，只收邮寄。
- 并愿：本プログラム属新潟学際型：以本プログラム为第1志望、指导预定教员兼任生命環境・食料科学プログラム研究指导时，可把生命環境・食料科学プログラム填作第2志望（兼任与否在事前商量时向教员确认）；考试只按第1志望实施，第1志望合格就不判定第2志望，志望理由書和研究計画書只交第1志望的。第1期 学業成績優秀者特別枠受験不许可或未获合格内定者，无需重新出願即可参加同期一般枠（须在 2026/8/3 前补交语言成绩和研究計画書，已过）；第1期不合格者可重新出願、重新缴检定料报第2期。
- 咨询：入试和出願由自然科学研究科学務係（総合学術研究科自然科学専攻担当）负责，z-gakumu@adm.niigata-u.ac.jp，Tel 025-262-7387（平日 8:30–17:15，12:00–13:00 除外）；不知道志望教员联系方式或对プログラム、出題分野有疑问的，用要项第44页的「問い合わせ希望フォーム」（https://forms.office.com/r/AEUnXnhigz）询问。
