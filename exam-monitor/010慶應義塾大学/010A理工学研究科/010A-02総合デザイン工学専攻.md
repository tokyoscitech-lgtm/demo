## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 8月入试：出願时必须提交 TOEFL、TOEIC Listening & Reading、TOEIC Speaking & Writing 三者之一的成绩单原件 1 份，不收复印件；书类里没有原件的按书类不全处理。成绩单不退还，也不接受分数查询。
- 有效期：出願时起 2 年以内受检，即考试日在 2024/7/21 以后。
- TOEFL 可以交从 ETS 账户下载的 Test Taker Score Report，也可以让 ETS 把 Official Score Report 直送大学，直送的须在出願截止日必达。TOEIC 交公式认定证，或数字公式认定证的 PDF 打印件。
- TOEIC L&R 的 IP 成绩原则上不算公式成绩单；例外是慶應义塾内实施的指定回次（英语成绩资料里列出），这些回次的成绩单可以代替公式认定证。
- 要项没有写最低分、换算方法和配点，也没有写英语成绩在合否判定里占多少。TOEFL 的 iBT Home Edition、ITP 是否受理，要项没有逐一写明（未核实）。IELTS 等其他考试不在可提交之列。
- 6月入试：提交书类里没有英语成绩单。飛び級入试：同样要交 TOEFL 或 TOEIC 成绩单原件，考试日须在 2025/1/27 以后。
- 留学生入试（IGP）：以英语授课；Application Guide 里对英语成绩的具体要求本次没有读到（未核实）。

### 日本語要件
- 要项没有要求提交日语成绩（JLPT、EJU 等都没有提到）。
- 8月入试的記述試問原则上用日语出题；要项里提到英语出题的只有别的専攻（人間・社会システム情報科学専攻）的分野，本専攻三个分野的出题说明里都没有提到用英语出题。口述試問用什么语言要项没有另外规定。
- 外国大学毕业者可以走留学生入试（IGP），该路线用英语授课，没有把日语作为入学条件。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 8月入试·G）機械工学：記述試問（配点官方未公布，120分钟） | 基础学力题分两个领域——「機械力学·材料力学」和「熱力学·流体力学」，两个领域里选一个作答；另有一道论述题，写毕业研究的内容及其相关学术领域 | 2027入试要项 |
| 8月入试·H）電気情報工学：記述試問（配点官方未公布，120分钟） | 電気回路、情報工学、物性工学（含量子力学基础）、数学各 1 题，共 4 题，全部作答 | 2027入试要项 |
| 8月入试·I）システムデザイン工学：記述試問（配点官方未公布，120分钟） | 基础学力的记述题共 5 题——材料力学·構造力学、熱·環境工学、電気回路、電磁気工学、建築計画，5 题里选 2 题作答；另有一道论述题，考察与毕业研究有关的学力和逻辑思考力 | 2027入试要项 |
| 6月入试·飛び級入试·留学生入试 | 没有笔试。6月入试是书类审查（必要时加口述試問）；飛び級入试是口述試問，可能要求事先交课题或在口述时做发表；留学生入试只看书类 | 2027入试要项／IGP Application Guide |

- 只能报 1 个教育研究分野：記述試問考哪个分野，由出願时选定的希望指导教员所属的分野决定；有的教员同时属于多个分野，也只能选其一。
- 120分钟是整场考试的时间，要项没有写基础题和论述题各占多少时间和分数。
- 8月入试按記述試問、口述試問和入学志願者調書等出願书类综合判定；各部分的配点和合格线官方都没有公布。
- 6月入试的书类审查会把考生分成三类：只凭书类就合格、再参加口述試問后判定、转到8月入试判定。被转到8月入试的人要重新办出願手续才能考，同一専攻不用再缴检定料，换専攻则算新出願、要缴。
- 記述試問只能用书写用具，笔袋、计算器、尺子、词典都不能放在桌上；带时钟的话只能是没有通信功能、只显示时间的。
- 题目倾向（体验记，非官方）：没有找到新専攻体制下本専攻考生写的体验记，暂时没有可归纳的倾向。

### 口述試験 / 面接
- **官方形式**：8月入试的口述試問在 2026/8/28 分上午（9:30–12:00）和下午（13:00–16:00）两个时段进行，结束时刻会随进度前后变动。内容是四项：記述試問范围内的提问、志望专门分野的提问、适性和意欲、其他；可能被要求在黑板上写着回答。报システムデザイン工学分野的人可以带建筑图纸等到场，尺寸不超过 A1。配点和每人时长官方没有公布。6月入试的口述試問只对书类审查后被指定的人进行，看意欲、基础知识和专门学力。飛び級入试以口述試問为主，可能要求事先提交课题或当场做发表。留学生入试（IGP）没有面试。
- **実際に聞かれた内容**：没有找到本専攻考生的体验记。辅导机构类账号的概述（非官方，1 处来源）只笼统地说会看研究计划是否具体、专门知识、研究意欲和表达沟通，没有给出具体问题。

## 📝 详细信息
### 出願資格 / 定員
- 本専攻修士課程的募集人员为 220 名。这是 6月入试、8月入试、飛び級入试等合在一起的数字，要项没有按入试区分、入学时期或教育研究分野拆分。研究科四个専攻分别是：先端数物科学 100 名、化学・生命情報科学 130 名、総合デザイン工学 220 名、人間・社会システム情報科学 150 名。
- 出願资格（6月入试和8月入试相同）：大学毕业或 2027年3月前预计毕业；由大学改革支援·学位授与机构取得学士学位（含预计）；在外国完成 16 年学校教育（含 2027年3月前预计完成）；文部科学大臣指定者；在外国大学完成 3 年以上课程并取得相当于学士的学位；或经本研究科个别审查认定具有同等以上学力、入学时满 22 岁者。校内生、其他大学的在读生和毕业生、外国大学毕业生都可以报 6月入试和 8月入试。
- 入学时期：2027年4月入学对所有考生开放；2026年9月入学只限已经大学毕业或 2026年9月预计毕业的人。
- 教育研究分野：本専攻设 G）機械工学、H）電気情報工学、I）システムデザイン工学 三个教育研究分野，出願时从教員リスト里选定希望的指导教员，分野随教员而定。要项对本専攻希望招收的人的描述是：在機械工学、電気情報工学、システムデザイン工学等基盘工学上有扎实的基础学力，愿意推进基盘工学并向交叉领域展开，有意在国际上活动、关心新技术的社会应用。
- 出願书类：入学志願票、履历书（彩色打印，照片在 Web エントリー上传）、入学志願者調書（在 Web エントリー上填写后打印，须在和希望指导教员商量之后再写）、成绩证明书原件、毕业（预定）证明书原件、单位修得证明书（本校理工学部在读生以外的考生），8月入试另加写真カード和英语成绩单原件。证明书类不收复印件。要项没有另外要求研究计划书或推荐信。
- 出願方式：先在 Web エントリー（web-entry.st.keio.ac.jp/master/）录入并打印一部分书类，再把全部书类装进角形2号信封、贴上指定的收件标签，在邮局窗口用简易書留·速達寄出，寄出才算出願完成；国内以截止日邮戳为准，从国外寄的要用国际快递并在截止日必达。没有窗口受理。
- 检定料 35,000 日元。可以在金融机构窗口用指定的汇款依赖书缴纳，或在便利店缴纳（另收手续费）。只有没有寄出书类、重复缴纳等少数情况才退还，须在出願截止日起 1 个月内联系 Admissions Office。留学生入试（IGP）的检定料是 10,000 日元，不减免、不退还。
- 并愿与再报：6月入试之后可以再报 8月入试；被书类审查转到 8月入试的人同専攻再出願免检定料。
- 个别出願资格审查（只适用于“同等以上学力”的第 6 类资格，出願前要先联系 Admissions Office，审查本身不收费）：8月入试的申请期是 2026/6/22（周一）–6/25（周四），结果 7月上旬通知；6月入试是 4/9–4/15；飛び級入试是 2026/11/25（周三）–11/27（周五），结果 12月中旬通知。提交认定申请书和申请用履历书等。
- 外国人与出口管理：需要新办签证的人，出願前必须先联系 Admissions Office。研究科按外汇及外贸法做安全保障出口管理，可能因此不能接受希望的教育或研究，或被要求更改研究内容。
- 入学手续：8月入试合格者 2026年9月入学的手续期是 2026/9/3–9/6，2027年4月入学的是 2027/3/1（周一）–3/5（周五）；6月入试合格者 9月入学的手续期是 2026/8/18–8/19。学费金额要项里没有写；大学的「大学院学费」页只挂了 2026年度和 2025年度的学费 PDF，2027年度的金额未公布（截至 2026-10-11），本次没有读到 PDF 里的具体数字。
- 考场规则：受験票从 Web エントリー下载（8月入试的打印期是 8/20–8/25），用 A4 纸打印带去；考场在矢上キャンパス。迟于集合时刻原则上按缺席处理、不能应考；公共交通大面积延误时可能推迟开考。記述試問中途原则上不能离场。手机、电脑、平板、智能手表等电子设备从集合时刻起一律关机收进包里。
- 飛び級入试（这不是一般考生的路线）：对象是到 2027/3/31 在大学就读满 3 年的学部3年生，要求成绩优秀、已修单位与毕业所需单位相差大致 30 以内。检定料在 2027/1/14–1/20 缴纳，不用 Web エントリー。以此入学者在学部按退学处理。
- 留学生入试（IGP，这不是一般入试的要求）：面向外国大学毕业者，英语授课，只做书类选考。Period I（2026/9/1–10/31 出願）可以选 2027年4月入学或 9月入学，结果都在 2027年1月中旬通知；Period II（2027/2/1–3/31 出願）只对应 2027年9月入学，结果 6月中旬通知。
