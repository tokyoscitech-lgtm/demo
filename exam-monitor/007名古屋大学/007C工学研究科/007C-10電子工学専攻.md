## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般選抜、外国人留学生入试相同：不另设英语笔试，用 TOEFL iBT（含 Home Edition）或 TOEIC L&R 公开考试成绩评价，可交其一或两种；只认 2024/6/1 以后实施的考试，TOEFL ITP、TOEIC IP 不受理。
- TOEFL：ETS 直送 Institutional 或 Official Score Report（Institution Code D377，Department Code 69「Engineering, other」），另交 Test Taker Score Report 复印件；两者任一没在出願截止前到达就按未提交处理；只用 Test Date Scores，不用 MyBest。
- TOEIC：Official Score Certificate 原件贴在所定「スコアシート提出用紙」上随出願书类寄出；数字公式认定证自行打印后按原件处理。
- 没交或无效：可以出願和应考，但英语不计分（留学生入试按0分）。
- 笔试免除者选拔出願时不用交；没获免除转一般選抜的人须在 2026/7/29（周三）17:00 前补交（TOEIC 限 5/31 以前实施，TOEFL 的 Test Taker Score Report 须 7/3 前发行）（已截止）。
- 外国人留学生入试：8月入试时已向本研究科交过有效原件的，交复印件即可。

#### 日本語要件
- 一般選抜（含笔试免除者选拔）：要项没有要求提交日语成绩。
- 外国人留学生入试：须提交日语能力证明（日语任课教员等出具的证明原件，或日语能力考试成绩复印件），没有最低等级；考过日语能力考试的可附合否通知书或成绩单复印件作参考，大学院学习所需的日语能力在口頭試問中判定。专门科目笔试试题用日文和英文书写。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 一般選抜：基礎部門 | 数学3题（一元·多元微积分、线性代数〔矩阵与向量空间、联立方程、特征值与对角化〕、常微分·偏微分方程）＋電磁気学2题（静电场与电介质、静磁场与磁性体、恒定电流及其磁场、电磁感应与电感、麦克斯韦方程、电磁波传播与辐射），5题选3 | 8/18 13:30–16:30，180分钟 |
| 一般選抜：専門部門 | 6科目各1题选3，グループ1最多选2题。グループ1：電気回路（交流与复阻抗、谐振与变压器、过渡现象含拉普拉斯变换、分布常数电路）、電子回路（放大与偏置、小信号等效电路、功率放大、负反馈、振荡·调制·解调、运放）、論理回路（布尔代数、触发器、组合·时序电路、计数器、运算电路、半导体存储器）；グループ2：電気エネルギー（三相交流、送电特性、稳定度、变压器）、電子物性（量子力学基础、晶体与能带、固体中的电子、pn结）、情報理論（熵、信道容量、信源编码、信道编码） | 8/19 9:00–12:00，180分钟 |
| 外国人留学生入试：専門科目 | 考查博士前期学习所需的专业基础；具体科目由専攻通知 | 11/18–11/20 期间 |

- 電気工学、電子工学、情報・通信工学3専攻共用同一套题；按外语（英语成绩）、基础学力和专门知识、口頭試問综合判定。出願时可在3専攻间排第1–第3志望，可能以第2、第3志望専攻（電気工学、情報・通信工学）合格。
- 笔试免除者选拔：面向学业成绩优秀、志望意欲高的人，书类选考＋面接；获免除者不考笔试，和一般選抜考生一起参加8月口頭試問；没获免除的自动转入一般選抜，不用重新出願。

### 口述試験 / 面接
- **官方形式**：一般選抜：笔试后口頭試問，现场实施，集合时间地点由研究科网站或専攻另行通知；笔试免除者选拔：书类选考通过者参加面接，免除者再参加8月口頭試問；外国人留学生入试：专门科目笔试＋口頭試問，均现场实施，口頭試問中同时判定日语能力。
