## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各轮次相同：不另设英语笔试，用 TOEFL iBT（含 Home Edition）或 TOEIC Listening & Reading 公开考试的成绩评价，成绩单贴在所定「TOEFL/TOEICスコアシート提出用紙」上随出願书类提交。可以只交一种，也可以两种都交。
- TOEIC：只收公式认定证原件（Official Score Certificate）；不发行该证的国家交 Official Score Report 和 Certificate of Achievement 两份。不收 TOEIC IP，没有照片的成绩单原则上不收。
- TOEFL：须由 ETS 把 Institutional/Official Score Report 直送名古屋大学（Institution Code D377，Department Code 69 Engineering, other），并提交 Test Taker Score Report 复印件；两样有一样没在出願截止前到达，就视为没交。只采用 Test Date Scores，不采用 MyBest。不收 TOEFL ITP。
- 有效期：只认 2024/6/1 以后实施的考试。
- 没交成绩也能出願和应考，但英语不予评价。配点、最低分和换算方法要项没有公布。
- 笔试免除者选拔：出願时就要交成绩；没获得免除而转入一般選抜的，可在 2026/7/29（周三）17:00 前重新提交（TOEIC 限 5/31 以前实施、TOEFL 限 7/3 以前发行）（已截止）。
- 外国人留学生入试：参加过本研究科 2026年8月入试、已交过有效成绩原件的，可以只交复印件（TOEFL 不必重新直送）。

#### 日本語要件
- 8月入试（笔试免除者选拔、一般選抜）：要项没有要求提交日语成绩；笔试和口頭試問都用日语进行，不提供英语出题。
- 外国人留学生入试：
  - 须提交「日本語能力を証明するもの」：日语教员或相当人员出具的证明书（原件），或 JLPT、JPT 成绩（复印件即可）；没有规定最低等级。本学工学部毕业预定者和本研究科研究生免交。
  - 专门科目笔试题日文、英文并记；语学考试、口頭試問中可能检定日语能力。

### 筆記試験（专门科目）

| 一般選抜：基礎部門（120分钟，配点官方未公布） | 基礎無機・物理化学、基礎有機化学、基礎生化学 各2题，共6题任选4题 | 2027募集要项 |
| 一般選抜：専門部門（120分钟，配点官方未公布） | 無機・物理化学、有機化学、生化学 各2题，共6题任选4题 | 2027募集要项 |

| 外国人留学生入试：専門科目試験（线上） | 检查博士前期课程学习所需的专业基础，题目日英并记；科目和范围由専攻通知 | 2027外国人留学生募集要项 |

- 一般選抜按 TOEFL/TOEIC 成绩、笔试（基礎·専門）和口頭試問综合评价，配点和总分官方没有公布。考试以「系」为单位：有機・高分子化学、応用物質化学、生命分子工学3専攻用同一套题，按成绩顺位决定合格和研究室配属。
- 各専攻约10名（约三分之一）名额先给笔试免除者，其余由一般選抜按成绩决定（専攻说明资料）。
- 变更点：2026年8月起「物理化学」「無機化学」合并为「無機・物理化学」，两部门都改为6题选4题（之前是基礎部門4科目选3科目、専門部門4科目8题选4题）。
- 变更点：専攻页公告笔试免除者面接以2026年7月为最后一次，2027年夏实施的2028年度入试起只有8月一般入试。
- 作答只能用黑色铅笔或自动铅笔；计算器、词典、智能手表等可穿戴设备除専攻另有指示外不能用。
- 题目倾向（体验记，非官方）：没有找到化学生命工学系考生的体验记。

### 口述試験 / 面接
- **官方形式**：笔试免除者选拔有面接（按専攻进行，考查专业基础学力与说明能力、升学意欲、将来展望），通过后仍须参加8月口頭試問；一般選抜笔试后有口頭試問，博士前期课程线上实施，具体时间和方法由専攻通知出願者，配点和时长未公布，用日语；外国人留学生入试为线上选考（含口頭試問）。
- **実際に聞かれた内容**：没有找到本専攻考生公开的口頭試問或面接体验记。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：8月入试（笔试免除者选拔＋一般選抜合计）34名，其中约10名给笔试免除者（化学生命工学系：有機・高分子化学34名、応用物質化学34名、生命分子工学28名）；外国人留学生入试若干名；出願资格(9)（大学3年级跳级）若干名。
- 8月入试：
  - 出願资格（10项之一）：大学毕业或2027年3月底前预计毕业；取得学士学位；在外国完成16年学校教育；在外国完成3年以上课程并取得相当于学士的学位；指定专修学校毕业；资格(9)大学在学3年以上且成绩优秀；资格(10)经个别审查认定、2027年3月底前满22岁等。资格(9)事前审查、资格(10)个别审查的材料须在 2026/5/18（周一）16:00 前寄到（已截止）。
  - 笔试免除者选拔的对象是学业成绩优秀、对志望専攻学习意欲高的人，没写具体 GPA 线；没获得免除的自动转入一般選抜，不用重新出願或缴费。资格(9)的人只能报一般選抜，且只能填第1志望専攻。
  - 志望専攻：入学志願票上要给系内3専攻全部排志望顺序。网上出願和出願书类里没有填志望研究室的地方；出願后専攻用邮件发研究室志望调查，把能接受的研究室按顺序全部填上，第1志望须在第1志望専攻内，第2志望以后可跨専攻。笔试免除者面接通过的人配属到希望的研究室，一般選抜按成绩顺位配属。
  - 出願书类：志願票、工学研究科博士前期課程入学志願票、志願票别纸履历（资格(3)–(10)）、写真票、学修希望調書（笔试免除用或一般選抜用，只能写在规定框内）、TOEFL/TOEIC スコアシート、长形3号和角形2号信封（海外居住者不用）、类型该当性自我申告书（所有出願者）、在留卡正反面复印件或住民票（外国籍，暂时没有可先交护照复印件）、国费留学生证明（该当者）；外国大学毕业者另交成绩证明书原件、毕业（预定）证明书及学位证明原件（非日英文附译文）。笔试免除者选拔还要交出身大学的毕业要件、进级要件、科目一览和 GPA 算法资料复印件。
- 外国人留学生入试：
  - 出願资格：非日本国籍（永住者除外）、持「留学」在留资格或入学手续前能取得，且满足：在外国完成16年学校教育；通过英语授课课程从日本的大学毕业；在外国完成3年以上课程取得相当于学士的学位；或经研究科认定的同等学力（须在 2026/9/11 前事前照会，已截止）。通过日语授课从日本的大学毕业的人要报8月一般入试；2026年8月入试的合格者不能报。
  - 出願书类：志願票及写真票、工学研究科博士前期課程入学志願票、志望理由书（所定用纸）、毕业（预定）证明书原件、学业成绩证明书原件（外国大学须由大学或公证处出具，非日英文附译文）、推荐书原件（出身大学教员所写，格式不限）、日语能力证明、在留卡复印件或住民票（海外在住者交护照复印件）、合否通知用和入学手续用信封（海外不用）、类型该当性自我申告书、国费留学生证明（该当者）、TOEFL/TOEIC スコアシート。用日文或英文填写。
- 出願方式：在网上出願系统（e-apply）登记并缴检定料后，把书类用简易书留速达从邮局寄到工学研究科教務課入学試験係（海外用 EMS、DHL 等可追踪方式）；8月入试不收窗口提交，外国人留学生入试可在窗口提交（9:00–16:00，12:00–13:00 除外）。出願用纸从工学研究科网站下载，A4 彩色单面打印。
