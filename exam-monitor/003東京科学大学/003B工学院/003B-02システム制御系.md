## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般入试（A日程、B日程都要）：
  - 不另设英语笔试，用 TOEIC L&R 或 TOEFL iBT（含 Home Edition）成绩评价，B日程配点 50 分。
  - 本系要求出願时必须提交在线版成绩单打印件，出願截止后一律不收，交后不能更换、不退还；截止前没交的没有受験资格。
  - 只认 2024/6/11 以后受检的成绩。TOEIC 须为带真伪确认 QR 码的数字公式认定证 PDF 打印件；TOEFL 须为 Test Taker Score Report PDF 打印件，并在 ETS 账户为该成绩设定 DI code G179。ETS 邮寄的纸质成绩单、TOEFL ITP、TOEIC IP 等团体考试不受理。
  - 要项附録3的换算基准：TOEFL iBT 先按对照表换成 PBT，再用（PBT－296）÷0.348＝TOEIC L&R，例如 iBT 80→PBT 550→TOEIC 约 730，iBT 100→PBT 600–603→TOEIC 约 874–882（TOEIC 300 分以下不适用）。
- IGP(C)：申请材料不要求英语成绩；面试和考试用英语进行。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 过去问（2025年8月）的数学试题为日文出题。
- IGP(C) 全英语授课，不要求日语。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 数学（150分） | 应用数学一般：微积分、线性代数、傅里叶/拉普拉斯变换、微分方程、概率统计等 | 9:30–11:30，120分钟 |
| 英语（50分） | 用外部成绩评价，见英語要件 | |

- A日程：系根据出願书类决定受験资格者（考生不能自选），凭出願书类和口述试验综合判定“合格内定”；内定者不再考 B日程，没内定的可接着考 B日程；出願资格(9)（飞级）只能考 B日程。
- B日程：先考筆答，按筆答结果决定口頭試問受験资格者，再综合出願书类、筆答和口頭試問判定合否；每位教员的指导学生数有上限。
- 筆答中止时，可能改为凭出願书类选拔口頭試問受験资格者。

### 口述試験 / 面接
- **官方形式**：A日程：口述試験线上进行，考查本科阶段学到的学力、研究能力和适性；B日程：口頭試問线上进行，考生用自己准备的资料发表现在做的毕业研究（或相当的内容），据此考查工学基础学力、研究能力和适性，发表要求的细节在系入学案内公布；两者都要事先交系指定的誓約書（保证独立作答、不录音录像、不外传试题等）；IGP(C)：系或志望导师安排的英语面试和/或考试，可能含口头提问或解题，原则线上。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：システム制御系受入可能予定人数 56 名（2026年9月和2027年4月入学合计，工学院合计 477 名）；IGP(C) 各系若干名。
- 出願资格：大学毕业（含 2027/3/31 前预计）或外国16年学校教育等，(9)(10)(11) 项须先做出願资格审查；只能报一个系，一个出願出结果前不能再报理工学系其他募集（含 IGP(C)）；外国籍考生选9月入学须出願时住在日本且在留资格有效到 2026/9/28，否则只能4月入学；网上出願登记的现住址限日本国内；网上出願的「系・課程指定入力項目」填第一志望コース（システム制御／エンジニアリングデザイン／人間医療科学技術）；志望指导教员最多填10位、出願后不能追加，在補足調査票里选择配不到所填教员时是否接受；IGP(C) 面向外国留学生，须先取得本系教员的指导同意。
- 要提前准备的书类：志望理由书（所定样式 A4 1张，1,000–1,500字，写毕业研究概要或所学专业、修士阶段的学修研究目的与计划、志望理由及与既往学习的关系、自身能力适性、修了后的希望）；TOEIC L&R 或 TOEFL iBT 成绩单（出願时必交）；受験资格者按系邮件指示另交誓約書和補足調査票（A日程用、B日程用，写毕业研究题目与概要）；日英以外语言的证明须附出身大学或使馆·公证处证明的译文；IGP(C) 另需导师同意书（扫描件须在出願截止前一周发给入試課）、研究计划（所定样式）、本科研究概要和推荐人直接提交的评价表兼推荐信。
- 出願：一般入试先在网上出願系统登记、上传照片、缴费，再把书类以速達書留寄到入試課（6/10 必达，不收窗口提交），检定料 30,000 日元＋手续费 990 日元，国费留学生等须 5/27 前办免缴手续；IGP(C) 全程网上提交，检定料 30,000 日元（信用卡）。
