## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 日程B（外国人等特別選考）：
  - 出願期间上传 TOEFL iBT（含 Home Edition）Score Report 或 IELTS Academic Test Report Form 的 PDF；不收 TOEIC。
  - 英语是第一次选拔：TOEFL iBT 72 以上（2026/1/20 及之前受检，120分制）、新制 overall 4.0 以上（2026/1/21 以后受检，1–6 band），或 IELTS overall 5.5 以上，才能参加口述。
  - 须为 2025/2/1 以后受检；TOEFL 只认 Test Date 成绩（不用 MyBest），向 ETS 送分（DI 代码 8001，Department 代码 99）并填 Appointment Number；IELTS 选电子送付并填 TRF 号码。
  - 出願时交不了的须在出願期间内告知専攻入试委员会，获准者 2027/1/7 前邮件补交。
  - 在美、英、澳、加、新西兰的大学当地就读毕业者可能免除，须出願前询问并在調査票申报。
- 日程A：一般選抜收 TOEFL iBT、IELTS Academic、TOEIC L&R（仅日本国内公开测试）之一，2024/9/1 以后受检，换算方法不公开；外国人等特別選考门槛同日程B（已结束）。
- 变更点：2027年度日程B 起也收 IELTS；一般選抜不再在考场统一实施 TOEFL ITP，改交外部成绩。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 日程B 口述用英语提问，可用英语或日语回答；日程A 一般選抜笔试题和口述提问为日语，可用日语或英语作答。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 日程A 一般選抜：専門基礎生命科学及び小論文 | 専門基礎生命科学：高中生物到大学通识水平的生命科学（生物学、生化学、遗传学等），原则上以《キャンベル生物学 原書11版》的知识可作答；小論文：不考生物学知识，看逻辑表达和独创性 | |
| 日程B 外国人等特別選考：无笔试 | 英语成绩（第一次选拔）＋口述，専門基礎生命科学的内容在口述中试问 | |

- 日程A 一般選抜：按笔试、英语成绩、口述综合判定；合否只看成绩，与志望分野无关。
- 日程B：英语达到门槛者参加口述，専攻判定后先发内定，经研究科审议发表最终合格。
- 题目倾向（体验记，非官方）：専門基礎为记述式，遗传相关计算和突变类型反复出现；过去问没有官方解答，考生多对照教科书自己整理答案（2022年8月，2人提到）。

### 口述試験 / 面接
- **官方形式**：日程A 一般選抜：柏校区面对面，先简要介绍毕业研究或实习（没有的话讲最近读过的论文）再问答，问志望理由、对专业领域的理解、沟通能力，日语提问、可用英语回答；外国人等特別選考（日程A·日程B）：柏校区面对面，问志望理由、对专业领域的理解、沟通能力、知识和独创性，另加専門基礎生命科学的试问，英语提问、可用英语或日语回答，须自带书写工具；各轮均禁止使用电脑、平板、手机、翻译机、耳机和智能眼镜等。
- **実際に聞かれた内容**：一般選抜要把本科研究内容讲到外行也能听懂；内定当天下午的线上面谈用来确定研究分野的配属（2022年8月，1人提到）。
- 变更点：2026年度日程B 的修士口述为 Zoom 线上，2027年度日程B 改为柏校区面对面；研究科入试信息页有应考用短期滞在签证的说明。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：54名（日程A 一般選抜）；日程A 外国人等特別選考若干名；日程B 一般選抜不募集、外国人等特別選考若干名。
- 出願资格：大学毕业（含 2027/3/31 前预计）或外国16年学校教育等；外国人等特別選考须在外国或用日语以外语言接受高中和大学教育；研究科内只能报1个専攻，同一日程不能并报两种选拔，日程A合格者不能报日程B；日程B 需新办在留资格的外国籍考生只能2027年10月入学，不需新办而想4月入学的须出願前联系専攻入试委员会。
- 要提前准备的书类：日程B 用「調査票（修士）」（选1个志望研究分野并写希望指导教员）、TOEFL iBT 或 IELTS 成绩、CERTIFICATE OF CONTACT（希望指导教员填写）；日程A 一般選抜交外部英语成绩和調査票。
- 出願：只能通过研究科网上出願系统上传 PDF；检定料 30,000 日元（文部科学省奖学金留学生免缴），出願后不退。
- 并愿限制：研究科内不能同时报两个以上専攻；日程A 合格者不能报日程B。
- 咨询：研究科层面只用入试信息页的问合せフォーム；専攻层面联系専攻入试委员会 admission@ib.k.u-tokyo.ac.jp（[専攻咨询页](https://www.ib.k.u-tokyo.ac.jp/admission/contact/)）。出願截止后只能就事务性问题联系入试委员会。
