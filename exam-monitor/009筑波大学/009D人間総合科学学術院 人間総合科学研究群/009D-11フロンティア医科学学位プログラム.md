## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 8月实施和1-2月实施都不设英语笔试：科目名「外国語」，配点 100 分，用外部英语成绩评分。
- 可用的考试：TOEIC Listening & Reading（TOEIC IP 不行）、TOEFL iBT 和 TOEFL iBT Home Edition（TOEFL ITP 不行）、IELTS Academic（IELTS General、IELTS Academic 在线版、One Skill Retake 不行）。
- 换算：达到 TOEIC L&R 850、TOEFL iBT 96、IELTS 6.5 的，外国語按满分 100 分计。低于这条线时怎么换算，要项和プログラム官网都没有写。
- 有效期：8月实施须为 2024年7月以后受检；1-2月实施须为 2025年1月以后受检。
- 提交方式（全学共通办法）：TOEIC 在 Web 出願系统里填デジタル公式認定証的 URL 并打印提交（在日本受检者必须用这种方式），或交公式認定証原件；TOEFL iBT 交 Test Taker Score Report 原件，或请 ETS 把 Official Score Report 直送大学并交 PDF 版成绩单的打印件（2026年1月起纸质成绩单已废止，没有纸质件的用后一种）；IELTS 要把 Additional TRF 的数据送到大学，并交 Test Report Form 的复印件。成绩单贴在 Web 出願系统下载的台纸上，与出願书类一起在书类截止日前必达。
- 没有在期限前交成绩的，按出願不受理或缺考处理，不列入选考对象；成绩单造假的不受理或取消合格。
- 出願书类表里「外部英語試験スコア票」的对象写的是全员。

### 日本語要件
- 要项没有要求提交 JLPT、EJU 等日语成绩，一般入试也没有针对外国人留学生另设区分。
- プログラム入学试验页写明考试语言可以按考生的希望选日语或英语。プログラム约一半的课程用英语授课。
- 小論文（出願时在 Web 表单里填写）要求约800字；用英文写时的词数要项没有写。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 外国語（100分；8月实施·1-2月实施相同） | 不考笔试，用 TOEIC L&R／TOEFL iBT／IELTS Academic 的成绩评分；达到 850／96／6.5 按满分计 | 2027募集要项 |
| 専門科目（100分，60分钟；一般入学試験，8月实施·1-2月实施相同） | 与医科学等有关的专门科目；当场从生化学·分子生物学、生理学、医学物理学 3题中选1题作答 | 2027募集要项 |
| 専門科目（100分，60分钟；社会人特別選抜） | 与医科学等有关的应用课题（小論文） | 2027募集要项 |
| 口述試験（200分；8月实施·1-2月实施相同） | 个别面接，问医科学领域的一般知识和志望动机 | 2027募集要项 |

- 一般入学試験的总分是 400 分：外国語 100＋専門科目 100＋口述試験 200。根据提交的书类和学力检查的结果综合判定，要项没有公布合格最低分。
- 社会人特別選抜：要项的配点表里，専門科目写的是应用课题（小論文）100 分，外国語和口述試験两格是空白（看排版像是与一般入学試験共用，但要项没有明写）；プログラム入学试验页写的是笔试（英语·小論文）＋口述（个别面接）。
- 可携带物品、题数以外的题型细节，要项没有写；考场和注意事项写在「受験者心得」里，考试1周前在入试站的通知栏掲載。
- 过去问的出题样子：大学过去问页上有2025年度实施的一般入试和社会人特別選抜试题 PDF。本次抓取这两份 PDF 被网站的 robots 设置拦下，内容没有读到，因此题型归纳只能写到要项的说明为止。
- 题目倾向（体验记，非官方）：没有找到本プログラム的考生体验记，暂无可写的内容。

### 口述試験 / 面接
- **官方形式**：个别面接，配点 200 分（占总分一半），问医科学领域的一般知识和志望动机。8月实施 2026/8/25 和1-2月实施 2027/1/27 都安排在専門科目当天的 13:00–18:00 之间。プログラム入学试验页说明口述考查逻辑分析能力、构思能力和学习意愿，可以按希望用日语或英语。每人的时长和具体时段的通知方式没有读到。
- **実際に聞かれた内容**：没有找到本プログラム的面接体验记，实际提问内容不明。
