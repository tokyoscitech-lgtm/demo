## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般入试：
  - 不另设英语笔试，用 TOEFL iBT（含 Home Edition）成绩评价，配点 100 分；本専攻只收 TOEFL，TOEIC、IELTS 不受理。
  - 换算：得分＝(TOEFL 总分－45)×2，低于0记0，上限100。例如 TOEFL 80＝70 分，95 以上＝100 分。
  - 有效成绩为 2024年9月–2026/7/14 受检的 Test Date Scores，不用 MyBest，ITP 等团体成绩不受理，英语母语者也要交。
  - 2026/8/1（周六）前完成三步（已截止）：ETS 送分（DI 代码 8596，Department 代码 99）、在 WEB 出願系统登记 Appointment Number 和受检日、上传 Test Taker Score Report；期限内可更换登记的那一次成绩。
- UBE-UPN/ENV：交英语标准化测验的成绩，或出身大学教务出具的本科英语授课证明；GRE 推荐但不是必须。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 一般入试：笔试原则上用日语作答；难以用日语作答的人，可在出願截止前把履历书（格式自由）发到専攻考试邮箱申请用英语作答，専攻回信批准才算受理。入学后只修英语授课科目也能修满学分。
- UBE-UPN/ENV：不要求日语，授课和指导用英语。

| 科目 | 范围·题型 | 时间 |
|---|---|---|

| 計画·設計·論文（200分） | 志望都市環境工学：C-1 計画·設計·論文；志望都市計画：C-2 計画·設計 和 C-3 論文 二选一 | 9:30–12:00，150分钟 |
| UBE-UPN/ENV：无笔试 | 书类初选 → 教员面谈 |  |

- 一般入试总分 800（TOEFL 100＋都市工学専門 500＋計画·設計·論文 200）加口述；不设书类选考和特別口述試験。
- 専攻分野（都市環境工学／都市計画）在受験申告票上勾选，决定都市工学専門的选科范围和計画·設計·論文考哪一种。
- 可带物品：受験票、黑色铅笔或自动铅笔、橡皮、削笔刀（台式不行）、只能计时的手表；計画·設計·論文另带有刻度的尺子，C-2、C-3 还要带彩色铅笔，可用水性笔，不可用制图墨水笔和颜料，三角尺、三角比例尺可用，模板和 T 字尺不可用；计算器由専攻发。

### 口述試験 / 面接
- **官方形式**：一般入试：线上（Zoom 等双向视频）口述，围绕所志望的専攻分野提问，接入时间和 URL 事后通知，须自备安静明亮的房间、稳定网络和带摄像头麦克风的电脑，出願时上传的受験申告票（含一页研究计划）是口述的参考；UBE-UPN/ENV：书类初选通过者与教员面谈（英语）。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：25名（都市環境工学、都市計画两个分野合计，2027年4月入学和2026年10月入学合计，含 UBE-UPN/ENV 等外国人留学生特別選考）。
- 出願资格：大学毕业（含 2027/3/31 前预计）或外国16年学校教育等，不限本科专业；个别入学资格审查 2026/4/21 截止（非独立出願）；不能同时报本研究科两个以上専攻；可选 2026年10月入学（需新办签证者要项建议4月入学）；UBE-UPN/ENV 只限出願期间住在日本以外的人，日本的大学毕业者不能报，不要求工学背景。
- 要提前准备的书类：受験申告票［修士］（専攻样式，写専攻分野、希望入学时期和一页研究计划）、TOEFL 成绩、安全保障輸出管理チェックシート（外国籍、双重国籍或入学前所属机构在海外者）；日英以外语言的证明须附出身大学盖章的英译；UBE-UPN/ENV 申请 ADB-JSP 奖学金的另交 ADB_UBE_Form。
- 出願：一般入试只能在 WEB 出願系统上传 PDF，检定料 30,000 日元，日本政府奖学金留学生免缴；UBE-UPN/ENV 经 T-cens 网上出願，初选通过者另寄纸质原件，检定料不能减免。
- 咨询：募集要项的问题用研究科网站的咨询表单（工学系研究科学務課大学院チーム）；専攻事務室 Tel 03-5841-6216；申请英语作答用 exam2027@ue.t.u-tokyo.ac.jp。合否不接受电话、邮件查询。
- 并愿：不能同时报本研究科两个以上専攻。
