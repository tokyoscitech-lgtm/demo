## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 8月入试：出願时必须提交 TOEFL、TOEIC Listening & Reading、TOEIC Speaking & Writing 三者之一的成绩单原件 1 份，不收复印件；书类里没有原件的按书类不全处理。
- 有效期：出願时起 2 年以内受检，即考试日在 2024/7/21 以后。
- TOEFL 可以交从 ETS 账户下载的 Test Taker Score Report（PDF），也可以让 ETS 直送 Official Score Report。
- TOEIC L&R 的 IP 成绩原则上不算公式成绩单；例外是慶應义塾内以团体特别受验制度实施的指定回次（2024/11/8–12 线上、2025/7/10–16 线上、2025/7/12 日吉对面、2025/11/7–11 线上、2026/7/9–15 线上），这些回次的成绩先上传到 Web エントリー，再打印出来随书类提交。
- 要项没有写最低分、换算方法和配点，也没有写英语成绩在合否判定里占多少。TOEFL 的 iBT Home Edition、ITP 是否受理，要项没有逐一写明（未核实）。
- 6月入试：不需要提交英语成绩。飛び級入试是否需要，未核实。
- 留学生入试（IGP）：以英语授课；Application Guide 里对英语成绩的具体要求未核实。

### 日本語要件
- 要项没有要求提交日语成绩（JLPT、EJU 等都没有提到）。
- 8月入试的記述試問和口述試問原则上用日语出题和进行；本専攻三个分野的出题说明里都没有提到用英语出题。
- 外国大学毕业者可以走留学生入试（IGP），该路线用英语授课，没有把日语作为入学条件；日语水平够的可以选修日语授课的科目。

- 只能报 1 个教育研究分野（有的教员同时属于多个分野，也只能选其一），記述試問按所报分野出题，内容是该分野的基础科目和与毕业研究有关的内容。
- 8月入试按記述試問、口述試問和入学志願者調書综合判定；各部分的配点和合格线官方都没有公布。
- 6月入试的书类审查会把考生分成三类：只凭书类就合格、再参加口述試問后判定、转到8月入试判定。被转到8月入试的人要重新办出願手续才能考，同一専攻不用再缴检定料，换専攻则算新出願、要缴。

### 口述試験 / 面接
- **官方形式**：8月入试的口述試問在 2026/8/28 分上午（9:30–12:00）和下午（13:00–16:00）进行，问記述試問的相关内容、志望分野的专门知识、适性和学习意欲，原则上用日语；配点和每人时长官方没有公布。6月入试的口述試問只对书类审查后被指定的人进行，考察志望分野的学力和学习意欲。飛び級入试以口述試問为主，可能要求事先提交课题或当场做发表。留学生入试（IGP）没有面试。
- **実際に聞かれた内容**：没有找到本専攻考生的体验记。辅导机构类账号的概述（非官方，1 处来源）只笼统地说会看研究计划是否具体、专门知识、研究意欲和表达沟通，没有给出具体问题。

## 📝 详细信息
### 出願資格 / 定員
- 本専攻修士課程的募集人员为 130 名。这是 6月入试、8月入试、飛び級入试等合在一起的数字，要项没有按入试区分或入学时期拆分。研究科四个専攻分别是：先端数物科学 100 名、化学・生命情報科学 130 名、総合デザイン工学 220 名、人間・社会システム情報科学 150 名。
- 出願资格（6月入试和8月入试相同）：大学毕业或 2027年3月前预计毕业；由学位授与机构取得学士学位；在外国完成 16 年学校教育（含 2027年3月前预计完成）；文部科学大臣指定者；在外国大学完成 3 年以上课程并取得相当于学士的学位；或经本研究科个别审查认定具有同等以上学力、入学时满 22 岁者。校内生、其他大学的在读生和毕业生、外国大学毕业生都可以报 6月入试和 8月入试。
- 入学时期：2027年4月入学对所有考生开放；2026年9月入学只限已经大学毕业或 2026年9月预计毕业的人。
- 教育研究分野：本専攻设 D）分子・生物化学、E）創発理化学、F）生命システム情報 三个教育研究分野，出願时选定 1 个分野和希望的指导教员。
- 出願书类：入学志願票、履历书（彩色打印，照片在 Web エントリー上传）、入学志願者調書（在 Web エントリー上填写后打印，须在和希望指导教员商量之后再写）、成绩证明书原件、毕业（预定）证明书原件、单位修得证明书（本校理工学部以外的考生）、检定料缴纳证明，8月入试另加英语成绩单原件。证明书类不收复印件。要项没有另外要求研究计划书或推荐信。
- 出願方式：先在 Web エントリー（web-entry.st.keio.ac.jp/master/）录入并打印一部分书类，再把全部书类用简易書留·速達邮寄，寄出才算出願完成；国内以截止日邮戳为准，国外须在截止日必达。没有窗口受理。
- 检定料 35,000 日元。可以在金融机构窗口用指定的汇款依赖书缴纳（不能用ゆうちょ银行和 ATM），或在便利店（ローソン、ミニストップ、ファミリーマート、セブン-イレブン）事先登记后缴纳，凭证贴在入学志願票上。留学生入试（IGP）的检定料是 10,000 日元。
- 并愿与再报：6月入试之后可以再报 8月入试；被书类审查转到 8月入试的人同専攻再出願免检定料。
- 个别出願资格审查（只适用于“同等以上学力”的第 6 类资格）：8月入试的申请期是 2026/6/22（周一）–6/25（周四），6月入试是 4/9–4/15，飛び級入试是 2026/11/25（周三）–11/27（周五）；提交认定申请书、申请用履历书（从初中毕业写起）、最终学历证明和申请理由书，约 2 周后用邮件通知结果。飛び級入试的认定结果在 2026年12月中旬通知。
- 外国人与出口管理：需要新办签证的人，出願前必须先联系 Admissions Office。研究科按外汇及外贸法做安全保障出口管理，可能因此不能接受希望的教育或研究，或被要求更改研究内容。
- 入学手续：8月入试合格者 2026年9月入学的手续期是 2026/9/3–9/6，2027年4月入学的是 2027/3/1（周一）–3/5（周五），邮寄办理、截止日邮戳有效。学费金额要项里没有写，以大学公布的「大学院修士課程学費」为准（本次没有读到具体金额）。
- 考场规则：受験票从 Web エントリー下载，用 A4 纸打印带去；考场在矢上キャンパス，具体教室当天看指引牌。迟于集合时刻原则上按缺席处理、不能应考。除书写用具外，笔袋、计算器、词典等一律不能带上桌；手机、电脑、平板、智能手表等电子通信设备不能使用。
- 飛び級入试（这不是一般考生的路线）：对象是到 2027/3/31 在大学就读满 3 年的学部3年生，要求 3 年级春学期结束时自然科学系科目成绩极为优秀、已修单位与毕业所需单位相差大致 30 以内，或在理工学的特定领域有特别突出的能力。以此入学者在学部按退学处理，拿不到学士学位。
- 留学生入试（IGP，这不是一般入试的要求）：面向外国大学毕业者（16 年教育并取得外国学士学位等），英语授课，只做书类选考。Period I 的入学时期在官方网页上写的是 2027年4月和9月都可以，Application Guide 的读取结果是 4月入学，两处不一致，未核实；Period II 只对应 2027年9月入学。
- 咨询：理工学研究科 Admissions Office（〒223-8522 横浜市港北区日吉3-14-1），ao_st_inquiry@info.keio.ac.jp，Tel 045-566-1800。合否结果和受验号码不接受查询。
- 成绩开示：要项没有成绩开示的规定。
