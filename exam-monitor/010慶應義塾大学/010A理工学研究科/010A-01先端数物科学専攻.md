## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 8月入试（飛び級入试相同）：
  - 出願时提交 TOEFL、TOEIC L&R、TOEIC S&W 之一的成绩单原件，没有原件按书类不全处理；不另设英语笔试，用外部成绩评价。
  - 有效期为出願时起2年以内（8月入试须为 2024/7/21 以后受验）。
  - TOEFL：交 ETS 账户下载的 Test Taker Score Report，或安排 Official Score Report 直送（Institution Code 0773，Department Code 无对应时填 99，截止日必达）并同封 Test Taker Score Report；TOEIC：交公式认定证或数字公式认定证的打印件。
  - TOEIC L&R IP 只认慶應义塾内团体特别受验的指定回次。成绩单不退还，不接受分数查询。
- 6月入试：不提交英语成绩。
- IGP：由 ETS／British Council 直送 TOEFL iBT 或 IELTS Academic 成绩（TOEFL 代码 0773），须为截止日前2年以内受验；在全英语授课大学取得学位并交授课语言证明的可免。另须 GRE General Test（ETS 直送，代码 3843），以 Quantitative Reasoning 为主，期望 160 分以上。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 6月入试、8月入试、飛び級入试：記述試問和口述試問原则上用日语。
- IGP：英语授课，申请书类用英文或日文。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| A）数理科学：記述試問 | 以微分积分、线性代数、集合与位相基础、代数学基础为中心，全部作答；2025年实施为5题 | 10:00–12:00，120分钟 |
| B）物理学：記述試問 | 物理学各领域，重点为力学·解析力学、电磁学、热力学·统计力学、量子力学，全部作答；2025年实施为3题 | 10:00–12:00，120分钟 |
| C）物理情報工学：記述試問 | 电气·电子回路、电磁学·量子力学、物理情报数学的论述题，考学力和逻辑思考力，全部作答；2025年实施为3大题，题内有选做 | 10:00–12:00，120分钟 |

- 8月入试按希望指导教员所属分野考该分野的記述試問，原则上用日语出题；合否由記述試問、口述試問和入学志願者調書等综合判定，各项权重按分野设定。
- 6月入试按书类审查，把考生分为只凭书类合格、加口述試問判定、转8月入试（再出願，同専攻免检定料）三类。

### 口述試験 / 面接
- **官方形式**：8月入试：有，问記述試問范围、志望专门分野、适性和意欲，原则上用日语，可能要求板书作答；6月入试：仅书类审查后被指定者参加，看志望分野的学力和意欲；飛び級入试：以口述試問为主，可能另加事先课题或口头发表（出願后个别通知）；IGP：无，只审书类。
