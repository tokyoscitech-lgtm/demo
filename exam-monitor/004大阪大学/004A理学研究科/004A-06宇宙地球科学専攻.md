## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 8月入试·第2次募集：不设英语笔试，出願时交 TOEFL iBT 或 TOEIC L&R 成绩，换算成100分计入；考过多次的只交1份。
- 换算（TOEIC 和 2026/1/20 以前的 TOEFL iBT，两点间线性插值、四舍五入）：TOEIC 225 以下＝0分、550＝50分、785 以上＝100分；TOEFL iBT 17 以下＝0分、42＝50分、72 以上＝100分。例如 TOEIC 700≈82分。
- 换算（2026/1/21 以后的 TOEFL iBT 新评分）：2 以下＝0分、2.5＝25分、3＝50分、3.5＝75分、4 以上＝100分。
- 有效期：8月入试为 2024/7/1 以后受检；第2次募集为 2024/10/1 以后受检。
- TOEFL：只认 iBT（含 Home Edition、Special Home Edition），只用 Test Date Scores；须在 ETS 账户向理学研究科电子送分（Institution Code G112，出願截止日前），并交 Test Taker Score Report 或 Examinee Score Record 的 PDF 打印件，只交 PDF 不受理。
- TOEIC：交数字公式认定证（L&R）的 A4 打印件（黑白可）；纸质认定证、邮件发送 PDF、TOEIC IP、Bridge、Speaking & Writing 都不受理。
- 出願时来不及取得成绩的可以出願，但英语按0分计；出願后不能换成新的成绩单。
- IPC：交 TOEFL iBT（含 Home Edition）、TOEIC 或 IELTS 成绩，没有最低分；TOEFL ITP（含 ITP Plus for China）、TOEIC IP、TOEIC Bridge、IELTS Indicator 不受理；英语母语者、在英语为唯一官方语言的国家或英语授课课程取得学位的人免交。

#### 日本語要件
- 要项没有要求提交日语成绩。IPC 全程英语授课，面试用英语。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 物理 | 与物理学専攻同一试卷，6个面接コース共通；不能带词典和计算器 | 9:00–12:30，210分钟 |
| IPC：物理笔试或 GRE Physics | 物理基础科目；也可交 2025年1月以后的 GRE Physics 成绩（机构代码 4260），交 GRE 的人也可能被要求加考 IPC 笔试 | 180分钟 |
| 第2次募集 | 无笔试 |  |

- 8月入试：按笔试和英语成绩分コース判定口头试问资格（可能只获其中一个コース的资格），最后综合笔试、英语、口头试问、学业成绩证明书和研究分野等希望調書判定合否，同时决定配属研究グループ。
- 第2次募集：综合口头试问、英语成绩、学业成绩证明书和研究分野等希望調書判定；面向天文学、地球物理、地质、岩石矿物、生物、工学等各种背景的考生，重视对研究对象的兴趣和热情。
- 题目倾向（体验记，非官方）：备考集中在力学、电磁学、量子力学、统计力学四个领域，统计力学常单独成一道大题（物理学専攻考生，同一试卷）。

### 口述試験 / 面接
- **官方形式**：8月入试：按面接コース分别进行，第1、第2希望コース各一次（可只考其中一个），内容包括志望动机和想做的研究、测试物理学等科学能力的提问、与其他大学或专攻的并愿情况、研究グループ志望顺序，不能带资料，原则口头回答，有时要用黑板；第2次募集：全体受験者口头试问，每人约30分钟，结合希望配属的研究グループ进行；IPC：笔试达标者接受 IPC 教员的英语面试（通常线上）；学部3年次特別選抜：笔试、口头试问和学业成绩综合判定，内容各専攻通知。
- **実際に聞かれた内容**：2024年8月（物理学専攻考生，同一考试），2人提到主要是志望理由、研究兴趣等固定问题，第2志望コース的面试也类似；同年1人提到被问到说明会预告范围内的一般物理问题。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：28名（8月入试，与物理学専攻68名合同考试）；第2次募集若干名；IPC 若干名（与物理学専攻共用）；学部3年次特別選抜若干名。
- 出願资格：大学毕业（含2027/3预计）或外国16年学校教育等，资格(9)(10)须事前审查（非独立出願，已过）；8月入试合格者不能报第2次募集；8月入试选第1、第2希望面接コース并在每コース内排研究グループ志望顺序（可含物理学専攻グループ）；第2次募集只能志望本専攻グループ（最多3个）；学部3年次特別選抜须先过事前审查（书类 2026/12/9 必达，非独立出願）。
- 要提前准备的书类：研究分野等希望調書（选コース理由、毕业研究题目和概要等）、TOEFL/TOEIC 成绩（TOEFL 须提前电子送分）；IPC 另需指导教员的 Letter of Conditional Acceptance、2页以内 Statement of Purpose 和2封以上推荐信。
- 出願：窗口提交或书留速达邮寄，没有网上出願；检定料 30,000 日元，经检定料纳入系统缴纳，国费留学生免缴；IPC 书类寄 IPC Office，免检定料。
- 咨询：理学研究科大学院係（A棟1階），〒560-0043 大阪府豊中市待兼山町1-1，Tel 06-6850-5289，ri-daigakuin@office.osaka-u.ac.jp（平日 8:30–11:30、12:30–17:00）；宇宙地球科学専攻秘書室 Tel 06-6850-5479，jimu@ess.sci.osaka-u.ac.jp。
