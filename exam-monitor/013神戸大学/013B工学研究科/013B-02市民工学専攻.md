## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各轮次都不另设英语笔试，用 TOEIC L&R 公开テスト或 TOEFL iBT 成绩评分，配点 100分（一般入試、外国人留学生特別入試相同）。
- TOEIC 只认在日本国内实施的公开テスト，须在出願期间内从 TOEIC 申込サイト「大学・企業等へのスコア提出」提交（申请代码 00010407），不收公式認定証；期间内没提交的不受理出願。TOEIC-IP、日本国外实施的 TOEIC 不受理。
- TOEFL 只认 iBT：交带照片的 Test Taker Score Report 原件和 A4 复印件（或 PDF 版打印件），并让 ETS 把 Official Score Report 送到神戸大学（DI 代码 B071）；TOEFL ITP、Home Edition 不受理。
- 有效期：8月入试为 2024/8/25 以后受验；第二期为 2025/1/21 以后受验。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 外国人留学生特別入試（第一期・第二期）可在調査シート上申请英文试题：本専攻申请者同时拿到日文和英文试题。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 専門科目(一) 数学（100分） | 线性代数、微积分、微分方程、概率·统计 | 8月 9:30–10:30；第二期 13:00–14:00；60分钟 |
| 専門科目(二) 水理学（100分） | 以学部课程「水工学の基礎（水理学I）」「管路・開水路の水理学（水理学II）」为主 | 8月 11:00–12:00，60分钟 |
| 専門科目(二) 構造力学（100分） | 以「構造力学I・II」为主 | 8月 13:00–14:00，60分钟 |
| 専門科目(二) 土質力学（100分） | 以「土質力学I・II」为主 | 8月 14:30–15:30，60分钟 |
| 専門科目(二) 土木計画学（100分） | 以「市民工学のための確率・統計学」「数理計画I・II」为主 | 8月 16:00–17:00，60分钟 |

- 一般入試：数学＋専門科目(二) 4科全考，加英语共 600分。
- 外国人留学生特別入試（第一期・第二期）：数学＋専門科目(二) 4选2（各100分），加英语共 400分；第二期専門2科在 10:00–12:05 连考。
- 笔试和口頭試問综合判定，缺考指定科目或口頭試問的不进入选考。可带尺，计算器由考场借给。

### 口述試験 / 面接
- **官方形式**：一般入試・外国人留学生特別入試（第一期・第二期）・社会人特別入試都有口頭試問，只判合否、不计分；推薦入試只考口頭試問，含土木工学一般、構造力学、水理学、土質力学、土木計画学的专业提问。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：42名（含推薦入試・外国人留学生特別入試・社会人特別入試各若干名）；外国人留学生特別入試第二期若干名。
- 出願资格：大学毕业（含2027/3/31前预计）、外国16年学校教育或外国3年以上课程取得学士相当学位等；外国人留学生特別入試限持有或2027年4月前取得「留学」在留资格的外国人；短大・高专・专修学校等毕业者须先过个别资格审查（第二期 2026/11/25–11/27 17:00 必达，12/7 前通知，非独立出願）；只能报一个専攻，出願后不能改内容；神戸大学工学部毕业生和在籍者不能报本専攻推薦入試。
- 要提前准备的书类：外国人留学生特別入試须上传指导预定教员出具的受入内諾書（所定样式或教员自拟）和本専攻用調査シート，非神戸大学工学部・工学研究科在籍者另交出身大学指导教授的推荐信（非英文附英译或日译）；外部英语成绩（见英語要件）；中国大学毕业者须申请 CHSI 英文学位认证电子邮件直接发到工学研究科（本人转发无效）；在日外国人上传住民票（30天内开具）。
- 出願：只能通过 Web 出願系统（e-apply.jp/ds/kobe-u）登录并缴费，再把纸质书类書留速達邮寄（截止日17:00必达）或窗口提交（平日 9:30–16:00）；检定料 30,000 日元，国费外国人留学生免缴。
- 咨询：工学研究科 学務課教務学生グループ（〒657-8501 神戸市灘区六甲台町1-1），eng-kyomugakusei@office.kobe-u.ac.jp，Tel 078-803-6350。
- 并愿：只能报一个専攻。
