## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 不另设英语笔试，用 TOEFL iBT（含 Home Edition）成绩评价。
- 须在 2024/8/1–2026/6/13 之间受检并向 ETS 申请把 Institutional (Official) Score Report 送到研究科（DI code 1113）；出願时在 WEB 出願系统填写 Appointment Number、受检日和分数，送过多次也只指定一次。
- TOEFL ITP 不受理，MyBest Scores 不采用。
- 变更点：2026年度还要上传 Test Taker Score Report，2027年度改为只填 Appointment Number、由 ETS 直送。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 専門科目的出题语言在出願时从日语和英语中选一种，出願后不能更改。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 専門科目（8科选2） | 木材物理学、木質材料学、製紙科学、森林化学、木材化学、高分子材料学、生物素材科学、環境材料設計学中选2科，必须包含第1志望分野的科目；每科出一道考该科目基础内容的大题；对面笔试 | 13:30–17:00，210分钟 |

- 按 TOEFL 成绩、専門科目和口述综合判定合否；本専攻不考一般教育科目。
- 2026年度出题（出题意图）：每科 3 问，第1问考相关基础学科（物理学·材料力学·界面化学·生物化学·有机化学·高分子化学·力学与数学·环境经济等），第2、3问考专业内容，如木材物性与干燥、木质材料强度与接合、纤维素结构与制浆造纸、木材腐朽与纤维素分解酶、木质素与蒸煮反应、生物降解高分子、木质建材市场与环境影响评价。

### 口述試験 / 面接
- **官方形式**：A日程 2026/8/7 或 8/8 的指定时间，在考场与审查委员当面进行。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：A日程（2026年10月入学＋2027年4月入学）17名；不实施 B日程。
- 出願资格：大学毕业（含 2027/3/31 前预计）或外国 16 年学校教育等 6 项之一；个别入学资格审查 2026/5/7 截止（非独立出願，已过）；2026年10月入学限 2026年9月以前毕业（含预计）者，出願时选定；同一日程只能报本研究科一个専攻；志望专门分野和教员最多填到第3志望。
- 要提前准备的书类：TOEFL 送分；本専攻没有另外指定的书类。
- 出願：只能通过 WEB 出願系统上传 PDF；检定料 30,000 日元（银行汇款、便利店、信用卡、Pay-easy），日本政府奖学金留学生免缴。
- 并愿：同一日程只能报研究科的一个専攻。
- 咨询：専攻的问题问 斎藤 幸恵 教授（Tel 03-5841-5251，aysaito@g.ecc.u-tokyo.ac.jp）；出願手续问农学生命科学研究科教務課学生支援チーム大学院学生担当（〒113-8657 東京都文京区弥生1-1-1，Tel 03-5841-5010，daigakuin.a@gs.mail.u-tokyo.ac.jp）。
