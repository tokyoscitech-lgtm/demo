## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 一般第1期·第2期：研究科自己出题的外国語（英語）笔试，60分钟，全専攻共通。配点官方未公布。
- TOEIC L&R 或 TOEIC L&R IP 的成绩可以在出願时提交，与本研究科英语考试的得分比较，取高者作为外国語成绩；这不是免考制度，提交了也要参加英语考试。换算方法按研究科规定，官方未公布换算式。
- 有效期：选考方法页写“从入学考试日起算3年以内受检”，第1期要项写“出願前3年以内”，以各期要项为准。数字公式认定证必须打印后提交，PDF 不受理。TOEFL、IELTS 等其他考试要项未列，不作比较对象。
- 一般第3期、社会人入试：没有英语笔试。
- 外国人留学生入试：选考方法页只列専門科目和口述，没有英语笔试的记载；全学留学生要项对理工学研究科没有要求外部英语成绩。

### 日本語要件
- 一般入试要项没有要求提交日语成绩。
- 外国人留学生入试：全学要项对理工学研究科不采用日本留学试验（EJU）；考过 JLPT、EJU 或 J.TEST 的，可作为日语能力参考资料提交（非必须）。
- 笔试和口述以日语进行，要项没有写其他作答语言。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 専門科目（配点官方未公布，120分钟） | 5个领域出题：①まちづくり工学相关时事（必答）；②力学（以结构力学为主，含地基力学·水理学）；③都市·建筑计划相关法令·事业制度·设计理论·历史；④景观·观光まちづくり学；⑤福祉·健康まちづくり学。②–⑤中选3个作答 | 2027募集要项／选考方法 |
| 外国語・英語（配点官方未公布，60分钟） | 研究科共通英语试题；可用 TOEIC 成绩比较取高 | 2027募集要项 |
| 一般第3期：无笔试 | 当天提交毕业研究说明资料（A4 2页）和研究计划书（A4 1页，格式自由）；10分钟发表毕业研究内容及与指导预定教员商定的修士研究计划并答辩；口头试问考力学、都市·建筑计划、都市·建筑法令制度基础、环境·防灾まちづくり学、景观·观光まちづくり学、健康·福祉まちづくり学的知识 | 选考方法 |
| 外国人留学生：専門科目（120分钟） | 科目细节官方页面未写 | 选考方法 |

- 一般第1期·第2期按英语、専門科目笔试和口述试验综合判定；官方没有公布配点和合否判定方法。
- 电卓：要项允许使用电卓的専攻名单里没有本専攻，按不能使用准备。
- 题目倾向（体验记，非官方）：没有找到本専攻的院试体验记。

### 口述試験 / 面接
- **官方形式**：一般第1期·第2期为“面接与试问”（时长和内容未公布）；一般第3期为10分钟研究发表＋质疑和专业知识口头试问；社会人入试只考口述，围绕业绩和研究计划进行面接与试问；外国人留学生为面接与试问。均以日语进行。
- **実際に聞かれた内容**：用日文和中文检索都没有找到本専攻的面试经验，没有可参考的先例。

## 📝 详细信息
### 出願資格 / 定員
- 博士前期课程入学定员为15名（全入试区分合计，官方未按期拆分）；社会人入试若干名。
- 出願资格：大学毕业或2027/3/31前预计毕业、取得学士学位、在外国完成16年学校教育等10项之一；以“预计”报考但到期未取得资格的不准入学。
- 个别出願资格认定：资格（10）须事先申请，第1期截止 2026/5/8（周五）邮戳有效、5/15 通知结果（已过）；资格（9）须事先向理工学部入試事務室咨询。第3期的截止日随第3期要项公布。
- 出願前须先联系志望専攻，确认希望条件和研究内容；外国人留学生须由指导预定教员签发「事前連絡確認書」（原件）。
- 出願方式：先在大学院入试Web出願系统登录志愿者信息，再把书类以简易书留邮寄（截止日邮戳有效）；只做 Web 登录或只寄书类都不算完成出願。准考证和考试案内在考试日前5天起从系统下载。
- 出願书类（一般）：入学志愿票（所定，贴照片）、毕业（预定）证明书、成绩证明书、TOEIC 成绩（任意）、出願确认票（所定）、外国学校出身者用出願资格确认票（资格3·4·6者）。社会人另交履历书。
- 检定料 35,000 日元，汇款到三菱UFJ银行神保町支店 普通 0049691「ニホンダイガクリコウガクブ」，汇款人名前加「22」；手续费自付，只有未提交书类或出願不受理时退还（第1期要项）。
- 外国人留学生：全学要项的入学资格审查截止 2026/9/30（已过），出願登录从 2026/7/17 起，出願截止 2026/10/30 16:00 前完成登录且书类必达；检定料 35,000 日元。
- 入学手续：一般第1期 7/29、第2期 9/30 截止（可选两段式，第2次截止 2027/1/29）；第3期 2027/3/11–3/25；办完手续后辞退须在 2027/3/31（周三）17:00 前电话告知。
- 初年度学费（令和8年度金额）：学外者 1,370,000 日元、本校出身者 1,170,000 日元（入学金 200,000 仅学外者；授業料 375,000、施設設備資金 150,000、実験実習料 40,000 为每学期额，另有后援会费·校友会费）。
- 考场：日本大学理工学部駿河台校舎（东京都千代田区神田駿河台1-8-14）。
- 本専攻其他路线：学内推薦（2026/7/11 实施，已结束）只限本校学生。
- 咨询：理工学部入試事務室 Tel 03-3259-0578，cst.nyushi@nihon-u.ac.jp；まちづくり工学専攻办公室 Tel 03-3259-0531，cst.machi.office@nihon-u.ac.jp。
