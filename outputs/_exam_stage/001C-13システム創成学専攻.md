## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 须提交 TOEFL iBT（含 Home Edition）的公式成绩，本専攻只收 TOEFL，不收 TOEIC、IELTS。
- 只用 Test Date 成绩，不用 MyBest 成绩；TOEFL ITP 等团体考试成绩不能用，考场也不举行 ITP。
- 本専攻的提交截止是 2026/8/6（周四）。要完成三件事：让 ETS 把公式成绩寄到 DI 代码 8596、Department 代码 99；在マイページ登记 Appointment Number 和考试日；上传 Test Taker Score Report 的 PDF。
- 有效期：考试日在 2024年9月以后的成绩有效。母语是英语的人也要交。
- 最低分和配点官方未记载。

### 日本語要件
- 募集要项和専攻入试案内都没有要求提交 JLPT 等日语成绩，也没有日语最低标准。
- 志望动机·希望研究内容书可以用日语或英语写；専門課題解答书按过去问的要求也是日语或英语二选一。
- 日语、英语以外的证明书要附日语或英语译文。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 一般教育科目（数学等） | 不考，不适用于本専攻 | 募集要项 専攻别试验科目表 |
| 书类选考 | 重点看志望动机·希望研究内容书，本科成绩作参考；结果在 2026/7/23（周四）前在専攻网站通知，没通过的直接不合格（检定料不退） | 専攻入试案内 |
| 専門課題解答书（代替専門科目笔试） | 2026/7/23 向书类选考合格者通知课题，2026/8/6（周四）15:00 前用専攻网站的样式提交；课题是第一志望教员所在领域的一篇学术论文 | 専攻入试案内／说明会资料 |

- 専門課题的形式（据公开的 2026年度过去问，其中一位教员的题）：读指定论文后回答 3 问，分别看对论文的理解和背景知识、发现和解决问题的能力、研究计划和逻辑思考；每问不超过 2 页（A4 或 US Letter），日语或英语，可以用图表和公式，引用要注明出处。其他教员的题页数和问数可能不同。
- 2026年度A日程公开了 36 位教员各 1 份课题，所以准备方向取决于第一志望教员的研究领域。
- 配点、合格标准官方未记载；要项只写按口述试验和提交书类等综合评价。

### 口述試験 / 面接
- **官方形式**：全部线上，分一般试验和専門试验两部分。一般试验就毕业论文研究（或预定做的、相当于毕业论文的研究）和修士阶段的研究构想提问，考查专业知识、入学准备情况和研究能力；専門试验就提交的専門課題解答书提问。要准备网络稳定、带摄像头和麦克风的电脑。具体考试时间和注意事项在 7/23 前由専攻网站通知，每人面试时长官方未记载。官方禁止把考试内容发到网上，也禁止考试中拍摄、录音。
- **実際に聞かれた内容**：没有找到可信的公开体验记（官方禁止公开考试内容，本次检索 note、博客、知乎都没有结果）。按官方说明，提问范围是自己的毕业研究、修士研究构想，以及解答书里对指定论文的理解和自己提出的方案。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员 45 名。
- 出願资格：日本的大学毕业或 2027/3/31 前预计毕业、在外国完成16年学校教育等（要项第1项 (1)–(6) 之一）。按 (6) 项个别入学资格审查出願的人，要在 2026/4/21（周二）前向工学系研究科学务课大学院チーム提交材料。
- 可以选 2026年10月入学（限符合条件者，资格里的 2027/3/31 换成 2026/9/30）。新申请在留资格的外国籍考生要等入学许可通知后才能办手续，通常要1个月以上，専攻建议也考虑4月入学。
- 检定料 30,000 日元（文部科学省奨学金留学生免缴），可用便利店、Pay-easy、信用卡、中国决济等支付；书类选考不合格也不退。
- 出願书类在 WEB 出願系统上传 PDF：成绩证明书、毕业证明书（已毕业者）、照片等，详见要项第6项。
- 本専攻另外要交的 4 样东西：志望指导教员申告票（マイページ填写）和志望动机·希望研究内容书（用専攻网站的样式），这两样在 2026/5/29–6/25（周四）15:00 提交；専門課題解答书在 2026/7/23–8/6（周四）15:00 提交；TOEFL 公式成绩 8/6 截止。
- 受験票在 2026/7/3（周五）15:00 左右通过マイページ交付。
- 入学料 282,000 日元、授业料年额 535,800 日元（前期 267,900 日元），都是预定额。
- 不能同时报工学系研究科的两个以上専攻。
- 咨询：専攻事务室（工学部3号館2楼225号室），电话 03-5841-6533，admission@sys.t.u-tokyo.ac.jp；要项本身的问题走研究科网站的问询表单。

### 研究室 / 指導教員
- 事前連絡要否：推荐。専攻入试案内写明修士考生出願前建议先和志望指导教员联系，但出願之后禁止再和志望教员联系入试的事，有问题只能问専攻事务室。
- 志望指导教员在申告票里填，修士最多可以填 5 名（说明会资料）；各教员的招收名额不公开。
- 専攻入试案内后面附有指导教员·研究领域一览（按五十音顺编号），领域包括系统设计与管理、金融情报学、数据市场、供应链与物流、材料与结构、海洋、能源资源、数值模拟、网络科学等。部分教员属于生産技術研究所、人工物工学研究センター等。
- 説明会后半是各研究室的介绍，只能到场参加。
