## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 不另设英语笔试，用 TOEFL 或 IELTS 成绩做外国语审查（研究科修士三専攻共通）；本専攻要求具备用英语上课、讨论所需的英语沟通能力。
- 受理：TOEFL iBT（含 Home Edition）、IELTS Academic Module。IELTS General Training 和 One Skill Retake 的成绩不受理。
- 有效期：2024/8/1 以后受检的成绩。考过多次的只能登记、上传 1 份。
- TOEFL：在 ETS 账户把 Official Score Report 送到研究科（DI Code 8426，Division：Graduate Organization，Department：42 Medicine），在 WEB 出願系统登记 Appointment Number 和受检日，并上传 Test Taker Score Report（PDF，考后约 8 天可下载）。
- IELTS：在 WEB 出願系统上传 Test Report Form，并向 IELTS 事务局申请把同一次考试的成绩单寄到研究科学務チーム大学院担当；出願前已申请寄送的，截止后寄到也受理。
- 官方成绩未送达、上传内容与官方成绩不一致、受检日早于有效期的，按没有参加外国语审查处理。
- 官方没有公布最低分、换算方法和配点。
- 免除：在澳大利亚、加拿大、爱尔兰、新西兰、英国、美国的大学取得学士学位（含预计），或在其他国家全英语授课的大学取得学士学位并有学校证明的，可申请免除；须先邮件联系研究科，2026/6/5（周五）前提交审查材料（已截止）。只看学士课程，英语母语者不申请也不能免除。
- ADB-JSP 路线：通过 Google 表单提交 TOEFL iBT 官方成绩或 IELTS（经 Result Verification System 核验）。

#### 日本語要件
- 不需要日语成绩：本専攻是从入学到毕业全部用英语授课、用英语取得学位的课程，官方写明不要求日语能力；要项里的日本語能力証明書不适用于本専攻。一般选拔和 ADB-JSP 路线都一样。
- 笔试题目全部用英语出，答案可以用英语或日语写。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：2027年度8月入试 21 名（成绩不够时可能不足额）；ADB-JSP 路线官方未单列名额；本年度没有其他轮次。
- 出願资格：日本的大学毕业或 2027/3/31 前预计毕业；在外国完成 16 年学校教育；在外国 3 年以上的课程取得相当于学士的学位；文部科学大臣指定的教育设施修了；由大学改革支援·学位授与機構取得学士学位；或经个别资格审查认定、入学时满 22 岁。
- 个别资格审查：先发邮件（主题「出願資格審査について」）联系大学院担当，联系截止 2026/5/29（周五），审查书类截止 2026/6/5（周五），结果约 6/12 邮件通知（均已截止）。
- 出願书类（全部在 WEB 出願系统上传）：入学願書、证件照（jpg，出願前 3 个月内）、检定料缴纳凭证、成绩证明书、毕业（预计）证明书（外国学位须为英文或附英译，写明学位名）、TOEFL/IELTS 成绩（免除者除外）、改姓名证明（有的话）。证明书原件在入学手续时提交。
- 本専攻另交：①志望理由书，英文 400–500 词，A4，格式自由；②研究计划书，A4 2 页，格式自由（两份左上角写书类名、姓名、页码，不装订）；③指导教员表示同意指导的邮件。
- 出願期限后一律不受理；证明书来不及开具的须事先邮件联系大学院担当。
- 检定料 30,000 日元（日本政府奖学金留学生免缴），可用银行汇款、便利店、Pay-easy、信用卡，手续费自付。
- 入学料 282,000 日元，授業料 前期 267,900 日元（年额 535,800 日元），均为 2027年度预定额；日本政府奖学金留学生免缴。
- 入学手续：手续要领 2027年2月下旬发到出願时登记的邮箱，3月上旬指定期间内缴入学料并交书类，逾期视为放弃；在职入学的交单位同意书；外国人须在手续前取得不妨碍入学的在留资格。
- 需要考试照顾的，2026/6/5（周五）前向事务部申请（已截止）。
- ADB-JSP 路线（亚洲开发银行·日本奖学金项目，2027年4月入学修士）：
  - 对象：所列 ADB 成员国国籍、学士毕业后有 2 年以上卫生·医学相关全职工作经验、2026/6/30 时未满 35 岁、学成后回国、目前住在本国等；优先女性和低收入者；有留学经历或读第二个修士的原则上不支持。
  - 同时报 ADB-JSP 和一般修士入试的，两边都无效。
- 咨询：医学系研究科学務チーム大学院担当（〒113-0033 東京都文京区本郷7-3-1），in.m@gs.mail.u-tokyo.ac.jp；研究科入试页另有咨询表单。
