## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 一般·社会人·外国人留学生入试都考语学试验（英语），A·B日程相同：90分钟，题型为英文和译、和文英译等；可带纸质词典，不能用电子词典和电脑；配点官方未公布。
- 满足以下任一条件可免考英语，出願时交成绩证明复印件：TOEFL iBT 60 分以上（2026/1/20 以前的考试）或 3.5 以上（2026/1/21 以后的新计分制）、TOEFL PBT／ITP 500 分以上、IELTS 5.5 以上、TOEIC 600 分以上，或曾通过本研究科的定期语学考试。成绩原则上须为 2021/1/1 以后的记录。
- 不满足免考条件的人如有语学检定成绩，也可以出願时提交，作为口述试验的参考资料。
- ヘルスコミュニケーション学位プログラム（医療通訳）要求的英语水平目安为 CEFR B2（IELTS 5.5–6.5、TOEFL iBT 72–94 或新制 4.0 以上、TOEIC 四技能合计约 1560–1840）。
- 变更点：2026年度要项可用 JLPT N2 以上免考英语，2027年度删除了这一项；TOEFL iBT 增加了新计分制的分数线；成绩起算日从 2020/1/1 改为 2021/1/1。

### 日本語要件
- 外国人留学生入试：须取得 JLPT N1，或 N2 且总分 112 分以上；日本语能力证明书复印件在出願书类中列为任意提交。
- 一般入试和社会人入试没有日语成绩要求。
- 春入学课程用日语授课，口述试验、授课和事务联络都只用日语；需要英语授课的须报考秋入学（另有要项）。
- 变更点：2026年度只在 FAQ 中写"N2 相当以上"，2027年度在要项中明确为 N1 或 N2（112分以上）。

## 📝 详细信息
### 出願資格 / 定員
- 医科学専攻入学定员60名（A·B日程合计，各日程及各入试区分的人数未公布）；其中臨床遺伝学（遺伝カウンセリング）学位プログラム约4名、ヘルスコミュニケーション学位プログラム约8名，A日程招满则B日程不募集；定员未满可能实施C日程追加募集。
- 学位プログラム：展開医科学（环境与人类系、人体生命机能系、人体再生·再建系，共70余研究分野）、臨床遺伝学（遺伝カウンセリング）、データサイエンス、公衆衛生学・グローバルヘルス、クリニカル・トランスレーショナルサイエンス、ヘルスコミュニケーション（医療通訳）。研究分野以 2026/5/1 时点为准，部分分野本年度不募集，以研究室一览为准；考后原则上不能更换学位プログラム。
- 出願资格：大学毕业或 2027年3月底前预计毕业、学位授与机构授予学士、外国16年课程修了或3年以上课程取得学士相当学位、文部科学大臣指定专修学校修了者等；外国学历和出願资格（3）（4）（6）须事先邮件确认。经个别审查认定、入学前满22岁者也可报考，个别审查申请截止 A日程 2026/8/6（周四）（已截止）、B日程 2026/11/5（周四），审查免费。
- 社会人入试：须提交工作单位所属长的承诺书（所定用纸）。外国人留学生入试：无日本永住权、入学后可取得"留学"在留资格者。
- 出願书类：入学願書（从 Web 出願系统下载，A4 原则彩色打印，须有指导教员签名·盖章；黑白打印时贴 4×3cm 照片）、志望理由书（所定用纸，用 Word 等打字，不可手写）、检定料缴纳证明、毕业（预计）证明书和成绩证明书（本校毕业预定者免交）；该当者另交语学成绩复印件、硕士修了证明、所属长承诺书、在留卡或在留资格证明、经费支办书等。证明书须为出願前6个月内开具。要项不要求研究计划书。
- 出願方式：先在 Web 出願系统登记并缴纳检定料，再打印书类，以角2信封装好用简易书留速达寄到医学部事務室 大学院医学研究科担当，或平日 9:30–16:30 窗口提交；书类和检定料确认后约一周发邮件通知，可下载受験票，A4 打印后考试当天带来。
- 检定料 20,000 日元，汇款至みずほ银行神田支店（汇款人名前加"ＭＲ９"），或在本郷・お茶の水校区センチュリータワー南栋13楼用券售机购买；缴纳后不退还。
- 学费：医科学各课程（含公衆衛生学等）入学金 200,000 日元、授业料 425,000 日元、设施设备费 150,000 日元，第一年合计 775,000 日元，第二年 575,000 日元；データサイエンス学位プログラム授业料 1,075,000 日元，第一年合计 1,425,000 日元。可最多分两期（入学金不能分期）；2027/3/31（周三）16:00 前提交辞退届可退还入学金以外的费用。
- 入学手续：A日程 2026/10/19（周一）–11/10（周二），B日程 2027/2/15（周一）–3/1（周一）。
- 考场：本郷・お茶の水校区（东京都文京区本郷2-1-1），详细地点邮件通知；带受験票和手表（智能手表不可）。
