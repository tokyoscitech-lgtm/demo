## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般入试：
  - 交 TOEFL iBT（含 Home Edition）或 TOEIC L&R 公开考试成绩二选一，出願时选定后不能改，不另设英语笔试；2024年9月以后受检有效，提交截止 2026/8/7（已截止）。
  - TOEFL：ETS 送分（DI 代码 8596，Department 代码 99）、在 WEB 出願系统登记 Appointment Number 和受检日、上传 Test Taker Score Report，采用 Test Date Scores；ITP 不受理。
  - TOEIC：在 WEB 出願系统登记数字公式认定证 URL；IP、Bridge、S&W 不受理；在不发行数字认定证的地区受检者须把扫描件发到専攻邮箱并邮寄原件（8/7 邮戳有效）。
  - 换算为得分率（区间内线性插值）：TOEFL 0＝0%、48＝45%、95＝90%、105 以上＝100%；TOEIC 10＝0%、650＝45%、990＝90%（TOEIC 最高 90%）。例：TOEFL 80 约 76%，TOEIC 820 约 68%。
- IME：交 TOEFL（优先）或 IELTS 成绩（书类截止前2年内），或出身大学的英语授课证明；GRE General 必交（5年内）。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 试题有日文和英文两种（専攻 FAQ）；IME 全英文授课。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 一般教育科目（数学／物理学／化学，出願时选1科） | 数学：微积分与微分方程、级数·傅里叶分析·积分变换、线性代数、曲线·曲面、复变函数、概率统计等，6题选3；物理学：力学、电磁学，2题全答；化学：物理化学、无机化学、有机化学，3题全答 | 数学 13:00–15:30，150分钟；化学 9:00–11:00，120分钟；物理学 13:00–15:00，120分钟 |
| マテリアル工学基礎 | ①热力学·速度论（材料プロセス）②组织学（化学·晶体学·微观组织）③材料物性学（固体物理·量子力学）④材料力学（弹性论·强度学），各1题共4题选2 | 10:00–12:00，120分钟 |

- 按英语成绩换算分、笔试、口述和提交书类综合评价；成绩不够时即使未满募集人员也可能不录取；所有考生科目相同。
- マテリアル工学基礎须自带直尺（不借），函数计算器用考场提供的，不能用自己的。
- IME：书类审查，必要时教员网上面试或考试。
- 题目倾向（体验记，非官方，仅1人提及）：传闻配点为英语 150、一般教育 150、専門 300；数学选前3题可行，物理2题能拿7–8成；考场计算器不顺手，容易耽误时间。

### 口述試験 / 面接
- **官方形式**：一般入试：2026/9/4 本郷口述，个人集合时间和地点在交付受験票时及考前邮件通知；IME：书类审查，必要时网上面试。
- **実際に聞かれた内容**：（体验记，非官方，仅1人提及）内部生约2分钟、外部生约4分钟，问的是笔试考得怎么样这类简单问题。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：45名（一般入试）；IME 另行选拔。
- 出願资格：大学毕业（含 2027/3/31 前预计）或外国16年学校教育等；个别入学资格审查 2026/4/21 截止（非独立出願）；不能同时报本研究科两个以上専攻；可申请 2026年10月入学（合格后换指导教员需重新做安全保障审查，可能推迟到4月入学）；志望教员在 WEB 出願系统填第1–3志望，可改到 2026/8/28 17:00；IME 只限非日本国籍、网上出願期间不住在日本的人，日本的大学毕业·在读者（含研究生）不能报。
- 要提前准备的书类：TOEFL 或 TOEIC L&R 公式成绩；安全保障輸出管理チェックシート（外国籍、双重国籍或入学前所属机构在海外者）；日英以外语言的证明须附出身大学盖章的英译；IME 须2封推荐信、学习计划书、毕业论文概要、GRE 成绩和指导教员接收函。
- 出願：一般入试只能在 WEB 出願系统上传 PDF，检定料 30,000 日元，日本政府奖学金留学生免缴；IME 用 T-cens 网上出願后邮寄纸质书类（9月募集 11/4、1月募集 2027/3/10 必达），检定料 10,000 日元。
