## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 自己推薦入试（夏季）、一般·社会人入试（秋季）都不要求提交 TOEFL、TOEIC、IELTS 等外部英语成绩，要项里没有最低分或换算规定。
- 一般·社会人入试（秋季）的英语在笔试“総合問題”里考，出题范围包含“英语的基础力”，没有单独的英语科目，配点官方未公布。
- 研究科的招生方针要求考生具备读懂学术论文所需的英语能力。FAQ 说明入学后授课原则上用日语，但轮读等课程要读英文原著。
- 笔试不能带词典。

### 日本語要件
- 要项没有要求提交日语成绩（JLPT、EJU 等都不需要），对外国人留学生也没有另设日语门槛。
- 但整个考试以日语进行：一般·社会人入试的笔试只能用日语作答；试题以日语为主，过去问里有用英文叙述的题目和英文论文读解题。エッセイ（约2,000字）必须用日语写。面接只用日语，FAQ 明确不能用英语。
- 自己推薦入试的志望理由書、活動報告書用日语写，面接用日语进行。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 一般·社会人入试（秋季）：総合問題（配点官方未公布，120分钟） | 考数学、统计学、逻辑思考、英语的基础力，以及解决未知问题的应用力。过去问为4–5道大题、全部必答、记述式，没有选答 | 2027前期課程入试要项／过去问 |
| 一般·社会人入试（秋季）：书类审查（配点官方未公布） | 审查エッセイ和成绩证明书等出願书类，与笔试一起决定面接对象者（第1次选考） | 2027前期課程入试要项 |
| 自己推薦入试（夏季）：书类选考（配点官方未公布） | 没有笔试。按志望理由書、活動報告書、成绩证明书做第1次选考 | 2027自己推薦入试要项 |

- 一般·社会人入试分两段：第1次选考用书类审查和笔试的结果决定面接对象者；最终按书类审查、笔试、面接三项成绩综合判定。各项配点和合格线官方都没有公布。
- 过去问的范围（官方公开题归纳）：2025年度（2024/8/31 实施）5道大题，涉及对数、最优化、相关系数、集合与逻辑、二进制、线性规划、二项系数、平均与假设检验、字符串规则与集合记号的读解，最后一题是英文学术文章的读解和日语说明。2024年度（2023/9/2 实施）4道大题，涉及微积分、三角函数、不等式、数论、向量、概率统计，以及用英文叙述的递归定义与数学归纳法。
- 题目倾向（体验记，非官方）：数学以高中数学 I·A、II·B 的水平为主，加上基础英语，不考算法、数据结构等专门科目，难度中等；有人用约两个月刷数学题集准备。仅1人提及。

### 口述試験 / 面接
- **官方形式**：一般·社会人入试（秋季）只有通过第1次选考的人参加面接，形式是按出願时提交的エッセイ做发表，发表10分钟、质疑10分钟，另有换场5分钟。发表资料用 PowerPoint 或 Keynote 制作后转成 PDF（嵌入字体，8MB 以内），须在 2026/9/8（周二）23:59（日本时间）前在出願系统的マイページ提交。面接日期和集合时刻由研究科指定并发邮件通知，不能改期，也没有补考日。全部在池袋キャンパス面对面进行，不能线上受验；语言只用日语。配点官方未公布。自己推薦入试（夏季）的面接也在校内面对面、用日语进行，逐人面接，时长官方未公布。
- **実際に聞かれた内容**：按エッセイ做10分钟发表后由教员提问，教员态度温和，没有刁钻的问题（1篇体验记，仅1人提及）。具体问了什么没有找到公开记录。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员为 63 名，是自己推薦、一般、社会人、指定企業推薦四种入试的合计；其中自己推薦和指定企業推薦各为若干名。本年度没有冬季或春季的修士募集。
- 出願资格：大学毕业或2027年3月底前预计毕业、在外国完成16年学校教育、在外国大学修完3年以上课程并取得学士相当学位等10项之一。按第10项（由本大学院个别认定，须在2027/4/1前满22岁）出願的人要先受事前审查：一般·社会人入试须在 2026/6/10（周三）前索取用纸，2026/6/23（周二）–6/25（周四）提交（已过）。
- 受验区分：一般区分只需满足出願资格；社会人区分还要求入学时有2年以上社会经验，在企业、行政机关、公益法人等有实务经验，并关心人工智能的社会应用。自己推薦入试要求对人工智能或数据科学有强烈兴趣、有数理和信息科学的素养，并且在学成绩或研究成果优秀，或有竞赛获奖、商用应用开发、学术论文发表等实绩。
- 不需要选择志望研究室或指导教员，出願时不填志望教员；研究内容在合格后与教员商量。
- 出願书类（一般·社会人入试）：成绩·单位证明书、毕业（预定）证明书（日文或英文；其他语言须附公证译文）、エッセイ（日语约2,000字，结合学历或职历写志望动机和毕业后的职业规划，用 Word 写好后转 PDF）。最终学历在中国的考生还要让 CSSD（学信网）把 Online Verification Report 直接发给大学。没有研究计划书。立教大学毕业生免交毕业证明书和成绩证明书。
- 出願书类（自己推薦入试）：成绩·单位证明书、毕业（预定）证明书、志望理由書（A4 2页以内，日语）、活動報告書（A4 2–4页，日语，写实绩内容），中国学历者同样需要 Online Verification Report。
- 出願方式：只能网上出願。在 WEB 出願系统登记信息、上传照片、缴费，再在マイページ上传 PDF 书类，不需要邮寄。
- 检定料 35,000 日元，另收事务手续费 1,500 日元，只能用信用卡支付。
- 并愿：要项没有写自己推薦入试不合格者能否再报秋季一般·社会人入试，需要向研究科确认。
- 外国人留学生：合格并办完入学手续后由大学代办“留学”在留资格认定证明书，约需2–3个月；中国等6国国籍者入境前须做结核筛查。研究内容可能受安全保障出口管理的限制。
- 学费：2027年度入学者的金额尚未确认到（要项称2026年10月前后公布）。参考2026年度入学者：入学金 225,000 日元，授業料 年 1,500,000 日元，其他 3,500 日元，初年度合计 1,728,500 日元，分两次缴纳。前期課程是専門実践教育訓練給付的指定讲座。
- 考场规则：须带打印好的受験票（不能用手机画面出示），开考15分钟前到场；不能用计算器和词典，手表只能是只有计时功能的，手机、智能手表等通信设备要收进包里放在椅子下。面接内容不得录音录像或对外发布。作弊者当年度所有入试无效。
- 需要受验照顾的人要事先申请：一般·社会人入试的申请期为 2026/6/25–7/1（已过）。
- 咨询：立教大学独立研究科事務室 人工知能科学研究科担当，ai-ad@rikkyo.ac.jp（周日、节假日、停课日不办公；2026/12/25–2027/1/6 闭室）。合格通知没收到时联系入学センター，Tel 03-3985-3293。
