## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 一般選抜：英语不设笔试，用 TOEFL iBT（含 Home Edition）或 TOEIC Listening & Reading 公开考试的成绩判定，成绩单贴在指定的「スコアシート提出用紙」上随出願书类一起寄出。
- TOEIC：只收公式认定证原件（Official Score Certificate）；数字版公式认定证打印件也按原件处理。一般選抜最晚可用 2026年5月实施的那一回（専攻资料写的是 2026/5/31 实施分）。
- TOEFL：需要两样——由 ETS 直送大学的 Institutional／Official Score Report（Institution Code D377，Department Code 69），以及 Test Taker Score Report 的复印件。直送成绩要在出願期间最后一天（一般選抜为 2026/7/3）之前到达大学，寄送要 6–8 周；两样缺一就按没有提交处理。只采用 Test Date Scores，不采用 MyBest。
- 有效期：只承认 2024/6/1 以后实施的考试成绩。不受理 TOEFL ITP 和 TOEIC IP（团体考试）。交上去的成绩单不退还。
- 没交成绩也可以参加考试，但英语不计分。
- 笔试免除者选拔：電気工学·電子工学·情報·通信工学 3専攻出願时不用交英语成绩。没有获得免除而转入一般選抜的人，要在 2026/7/29（周三）17:00 前补交成绩单（已截止）。
- 配点与换算：募集要项和専攻补充资料都没有写英语的配点和换算方法。
- 外国人留学生入试：同样用 TOEFL iBT 或 TOEIC L&R 判定，有效期同为 2024/6/1 以后；成绩单缺失或无效时英语按 0 分计，但仍可应考；已在8月入试交过有效原件的，这次交复印件即可。

### 日本語要件
- 8月入试（笔试免除者选拔、一般選抜）：募集要项没有要求提交日语成绩，没有 JLPT／EJU 门槛。笔试和口頭試問都用日语进行，要项写明不提供英语出题。
- 外国人留学生入试：専攻页写明，考过 JLPT N1 或 N2 的人可以把合格通知或成绩单复印件作为参考资料提交（要项没有要求必须提交，也不是门槛），实际日语能力在口頭試問中判定。2025年度的留学生募集要项原则上还要求提交日语教师等出具的「日本語能力証明書」；2027年度是否仍要求未核实。

- 募集人员：情報·通信工学専攻 33 名（電気工学 34 名、電子工学 47 名；工学研究科合计 603 名）。这 33 名是笔试免除者选拔和一般選抜的合计，其中一部分给笔试免除者，免除名额的具体人数没有公布。外国人留学生入试的募集人员为「若干名」。
- 出願资格（10 项之一）：大学毕业或 2027年3月底前预计毕业；取得学士学位；在外国完成 16 年学校教育；在外国大学完成 3 年以上课程并取得相当于学士的学位；指定专修学校专门课程毕业；资格(9) 在大学在学 3 年以上且成绩优秀（俗称跳级）；资格(10) 经个别入学资格审查认定、2027年3月底前满 22 岁等。
- 笔试免除者选拔的对象是「学业成绩优秀、对志望専攻的学习有高度意欲的人」，要项没有写具体的 GPA 或名次线；资格(9) 的人不能报免除，只能报一般選抜且只能填第1志望専攻。没有获得免除的人自动转入一般選抜，不用重新出願、重新缴费或重交书类。
- 志望専攻与研究室：出願书类和网上出願里都没有填志望研究室的地方。一般選抜考生把专攻页上的「配属研究室希望調書」（2026/7/1 公开）事先填好志望顺序，在笔试第一天开考前上交；笔试免除希望者在「学修希望調書（筆記試験免除希望者用）」里写第一志望専攻和希望的研究室。
- 研究室配属规则：优先按第1希望配属，超过研究室可接收人数时按入试成绩依次调到第2希望以后；校外考生中的成绩上位合格者单列一个名额，更容易进入所希望的研究室。最终配属在第二年1月确定，由教员联系本人。
- 出願书类（一般選抜）：志願票、工学研究科博士前期課程入学志願票、志願票别纸履历（资格(3)–(10) 的人）、写真票、学修希望調書（一般選抜試験用，只能写在规定的框内，不能扩框或写到背面）、TOEFL／TOEIC スコアシート、长形3号和角形2号信封（海外居住者不用）、类型该当性自我申告书、在留卡正反面复印件或住民票（外国籍）、国费留学生证明（该当者），以及成绩证明书、毕业（预定）证明书原件。笔试免除者选拔另加：能说明出身大学毕业要件和 GPA 算法的资料复印件、免除结果通知用信封。
- 出願书类不允许用生成式 AI 撰写；提交后不能改写也不退还，发现虚假申请会取消入学许可。
- 出願方式：先在网上出願系统（e-apply）登记并缴检定料，再把书类用简易挂号寄到工学研究科教務課入学試験係；国内以邮戳为准，海外须在截止日寄到。书类是否寄到不接受个别查询，用挂号追踪号自行确认。
- 检定料 30,000 日元，另付手续费（上一年度要项写的是最高 1,300 日元）；可用便利店、Pay-easy、网上银行、信用卡，海外居住者只能用信用卡；缴费期限为登记当天起 4 天内。国费外国人留学生免缴。
