## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 须提交 TOEFL iBT 成绩（含 Home Edition），不另设英语笔试；母语为英语的人也要交。
- 提交方式：通过 ETS 账户把 Official Score Report 直接送到研究科。Institution Name 为 University of Tokyo IS&T，Institution Code 8445，Department Code 99。送到其他代码的成绩无法被确认。
- 送达截止：夏入试为 2026/6/30（已截止）。送分后大约两周研究科才能收到，要留出时间。
- 有效期：夏入试要求受检日在 2024/9/1 之后、出願截止之前。出願时要填写该次考试的 Appointment Number 和受检日，只有对应的那一次成绩被采用；出願后原则上不能更换。
- 不受理 MyBest Scores 和 Test Taker Score Report；研究科也不实施 TOEFL ITP。
- 截止日前无法确认成绩的，外语不予评分，并失去笔试和口述的受験资格。
- 官方没有规定最低分，也没有公布换算方法和配点。

### 日本語要件
- 要项没有要求提交日语成绩。
- 専門科目「数理情報学」的试题有日文版和英文版；口述用日语或英语，在出願系统的専攻指定记入栏2里选择。书类选考课题可以用日文或英文写。
- 研究科公告：2026年4月以后大学院授课大部分用英语进行。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 书类选考课题（出願时提交，配点官方未公布） | 举出一个感兴趣的研究主题来说明志望动机，须包含主题的背景与近年进展、感兴趣的理由、想取得的成果、对社会价值的看法。使用専攻网页的 Word／LaTeX 模板，正文 2 页以内，参考文献可以放到第 3 页以后 | 2027専攻入试案内书 |
| 一般教育科目（数学）（150分钟，配点官方未公布） | 线性代数、解析（微积分、常微分方程等）、概率统计，共 3 题，3 题全答。只有书类选考合格者能考 | 2027修士募集要项 |
| 専門科目「数理情報学」（180分钟，配点官方未公布） | 代数、解析、几何、离散、概率、统计、算法等领域，5 题中选 3 题作答 | 2027専攻入试案内书 |
| 専門科目「システム情報学」（可代替上一行） | 出願时在数理情報学和システム情報学中二选一；选后者时，日期、范围按システム情報学専攻的入试案内书 | 研究科 2025/6/13 变更公告 |

- 选拔分阶段进行：书类选考（课题）→ 数学笔试 → 専門科目笔试和口述 → 最终合格发表。只有书类选考合格并考了数学的人才能参加専門科目和口述。官方没有公布各科配点和合否判定的计算方法。
- 缺考任何一场都视为弃权。
- 题目倾向（体验记，非官方）：専門科目里线性代数、解析、最优化、概率统计几乎每年都出，近几年 5 题中约 4 题来自这些范围，不少人放弃算法和几何；题目常与官方参考书目的内容对应（矩阵、概率模型等）。数学第 1 题常是带引导的知名结论，被认为需要完整答出。没有完全解出时把思路写在答卷上也很重要。
- 配点（体验记，非官方）：成绩开示显示数学和専門科目各为 300 分满分，有合格者为数学 205、専門 186。

### 口述試験 / 面接
- **官方形式**：夏入试有口述试验，原则上线上进行，具体方法在 8 月上旬通知，时间表在 8/12 正午前通知，不接受调整。用日语或英语（出願时选定）。配点和时长官方没有公布。
- **実際に聞かれた内容**：（体验记，非官方）每人约 5 分钟（通知上写约 8 分钟）。先做事务性确认，再陈述志望本専攻的动机，然后由有问题的教员逐个提问。提问围绕书类选考课题里写的技术内容、对该主题感兴趣的契机和理解程度、第二志望研究室的志望理由及该领域的基础问题；多由第一、第二志望的教员提问，不是很深的专业追问。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：夏入试 40 名。本専攻修士没有冬入试。
- 出願资格：大学毕业或 2027/3/31 前预计毕业；在外国完成 16 年学校教育；在外国取得 3 年以上课程的学士学位等。走个别入学资格审查的人须事先受审，夏入试的材料截止为 2026/5/13（已过）。
- 志望教员的填写：在出願系统的下拉菜单里选第一至第六志望；案内书写明这一选择不影响合否。还想列出的其他教员写在専攻指定记入栏1。
- 出願书类：入学願書（WEB 系统填写）、证件照（jpeg）、本科成绩证明书、毕业（预计毕业）证明书、TOEFL 成绩、检定料缴纳证明、安全保障出口管理检查表（外国籍、双重国籍或最终学历为外国机构者）、本専攻的书类选考课题解答。全部转成 PDF 上传；日文和英文以外的证明要附日文或英文译文。成绩证明书原件在入学手续时提交。
- 出願方式：只能通过 WEB 出願系统，没有邮寄和窗口受理。提交后不能修改，书类不全视为无效。
- 检定料 30,000 日元，可用便利店、Pay-easy、银行汇款或信用卡支付，手续费自付，缴纳后不退。国费（文部科学省奖学金）留学生免缴。
- 并愿限制：同一次入试不能同时报研究科内两个以上専攻或选拔类别。
- 受験票通过邮件发送；夏入试在 2026/7/17 17:00 前没收到的要联系入试担当。
- 外国籍者须在入学手续前取得可在大学院就学的在留资格。受安全保障出口管理的审查，即使考试合格也可能不被许可入学，或研究内容受到限制。
- 入学料 282,000 日元，授業料 半年 267,900 日元（年 535,800 日元），均为预定额。国费留学生免缴。
- 入学时期：夏入试合格者为 2027年4月。2027年4月入学者的入学许可通知约在 2026年10月下旬以邮件发出，入学手续截止为 2027/3/11（预定）。
- 考场规则：笔试在本郷キャンパス进行，开考 15 分钟前入室。只能用黑色铅笔或自动铅笔、橡皮、铅笔刀（桌上型不可）、只有计时功能的手表；手机关机且不能带在身上。考试中原则上不能中途离场，答卷只写受験番号不写姓名，答卷和试题册不能带走。
- 咨询窗口：出願手续问研究科入试担当（学務課大学院チーム），johoriko.t@gs.mail.u-tokyo.ac.jp，Tel 03-5841-7926（平日 9:00–17:00；出願相关问题只接受邮件）。専攻的考试内容问学務課専攻チーム（数理情報学専攻担当），office@office.keisu.t.u-tokyo.ac.jp，平日 9:00–17:00 回信，可能要几个工作日。
- 成绩开示：官方资料里没有查到说明。体验记称 10 月上旬起可以申请开示，结果邮寄送达（非官方）。
