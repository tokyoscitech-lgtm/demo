## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各期相同：不另设英语笔试，用外部英语成绩按研究科所定换算式计为“语学试验”得分；出願时须提交成绩（必交书类）。
- 推荐：TOEIC L&R 公式认定证原件（数字认定证可打印带二维码的PDF）；TOEFL iBT 须请 ETS 把 Official Score Report 直送本校（代码 0416），出願时附 Test Taker Score Report 打印件并写明直送申请日，专门试验日前未到按0分；受验超过2年无法直送的可交 Examinee Score Report 原件；本校实施的 TOEIC IP（マークシート版）Score Report 可交复印件。
- 其他可用：IELTS（Test Report Form 须在专门试验日前直送，出願时贴复印件或在线成绩页）、TOEFL ITP 和团体 TOEIC IP 的 Score Report 原件。
- 不受理：英検、TOEIC S&W、TOEIC Bridge、TOEIC IP オンライン（含本校实施的在线版）、TOEFL ITP デジタル版。
- 只认 2021/4/1 以后受验的成绩；可交多份，取换算后最高分；成绩不退还。

#### 日本語要件
- 外国人须提交能证明达到“日本語教育の参照枠”CEFR B2 相当以上日语能力的合格证书等复印件；证书没有 CEFR 参考标注的，由研究科按总分等判断；2009年以前受验的不认。
- 願書、志望理由书均为日语样式。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 専門試験 | 由志望的指导教员个别实施和评分，内容按各教室研究领域决定；考场在福浦キャンパス各研究室 | 13:00–14:30，90分钟 |

- 按专门试验、语学试验（外部英语成绩换算）和志望理由书等综合判定；成绩不足时合格者可能少于募集人员。第1–3期、一般选拔与社会人特别选拔的选拔方法相同。

### 口述試験 / 面接
- **官方形式**：各期不单独设面试或口头试问；专门试验由志望指导教员个别实施，形式由各教室决定。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：20名（第1期15名、第2期5名、第3期若干名，均含一般选拔和社会人特别选拔）；视第3期结果可能追加第4期。
- 出願资格：大学毕业（含2027/3/31前预计）或外国16年学校教育、外国3年以上课程取得学士相当学位等；资格“ク”（个别资格审查，满22岁）须先寄审查材料，第1期 2026/5/18–5/22、第2期 7/27–7/31、第3期 10/13–10/16（非独立出願，均已截止）。本课程面向医学以外领域出身者，修了不能获得医师国家考试资格；歯学科、6年制薬学科、獣医学科毕业者不在募集对象内。第3期报名的外国籍考生出願时须已持有日本在留资格（短期滞在除外），在留期限不到 2027/3/31 的须在合格后尽快更新。社会人特别选拔须入学时在同一单位任正规职员并有所属长推荐。
- 要提前准备的书类：外部英语成绩原件（TOEFL iBT·IELTS 须提前安排直送）、CEFR B2 相当以上的日语证明复印件（外国人）、志望理由书（本校样式）、他大学院在读者的受验许可书；中国大学毕业者可交 CHSI 英文学历·学位·成绩认证报告打印件；非日英文证明须附公证的日文或英文译文；海外大学的毕业证明须写明学位名；社会人另交所属长推荐书（厳封）、业绩报告书、业务报告书。
