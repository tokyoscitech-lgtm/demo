## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 日程A（已结束）：在考场统一参加 TOEFL-ITP，作为英语考试。
- 日程B：提交 TOEFL iBT（含 Home Edition）成绩。日程B不举行 TOEFL-ITP，也不接受 ITP 成绩；IELTS 成绩单不能提交（专攻入试页明写）。
- 日程B 只认 2025/2/1 以后受检的成绩。须向 ETS 申请送分，DI 代码 8001、Department 代码 99（用其他代码研究科无法确认）；另外从 My TOEFL HOME 下载 Test Taker Score Report PDF 上传到出願系统，上传时输入成绩单上的16位 Appointment Number。成绩单截止 2027/1/5（周二）。
- 最低分数线和配点均未公布。

### 日本語要件
- 没有要求提交日语成绩（JLPT 等）。
- 日程B 的小论文必须用日文写；口述和面接可用日语或英语。日程A 数学题只有日文（可用英文作答）。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 日程B：小论文（配点未公布，书类选考） | 就正在做或已完成的毕业研究（或同等水平项目）用日文写小论文，用专攻模板（ShortEssay_MasterB.docx），PDF 上传，2026/12/14 截止；字数不在PDF中注明 | 修士入试信息（日程B用） |
| 日程B：英语（配点未公布） | TOEFL iBT 成绩单，2027/1/5 截止 | 修士入试信息（日程B用） |
| 日程A：数学（参考，已结束，配点·时长未公布，2026/8/18 下午） | 线性代数、微积分、微分方程、傅里叶分析、概率统计、变分法、向量分析、复变函数等出3题；题目只有日文 | 修士入试信息（日程A用） |
| 日程A：英语（参考，已结束，2026/8/18 上午） | 考场 TOEFL-ITP | 修士入试信息（日程A用） |

- 日程B 判定：第一阶段按小论文和本科成绩（GPA集计表）做书类选考，通过者才参加英语评价·口述·面接。各项配点、总分和合格线官方都没有公布。

### 口述試験 / 面接
- **官方形式**：日程B口述＝通过书类选考者就小论文内容用日语或英语做口头发表，考查研究计划能力、研究执行能力和基础知识；面接＝就志望分野、研究意欲等提问。日程B 时间以专攻网站通知为准（现写 2027/1/23 柏校区当面），不接受个别调整时间。
- **実際に聞かれた内容**：未找到可靠的体验记（截至 2026-10-10）。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：日程A 一般选拔 38名、外国人等特别选考若干名；日程B 一般选拔若干名、外国人等特别选考若干名。日程B一般选拔在志望调查票所列全部分野都有接收名额。
- 出願资格（一般选拔）：日本大学毕业（含2027/3 预计）、外国16年学校教育修了、外国3年以上课程取得学士相当学位、文科大臣指定设施修了、学位授与机构学士，或经个别审查且 2027/3/31 时满22岁（在读大学生不适用个别审查）。
- 日程B 的个别入学资格审查：希望联系期限 2026/10/1，申请期 10/7–10/13（均已截止）；考试·修学特别照顾申请期限 2026/10/8（已过，之后仍会考虑但照顾有限）。
- 网上出願，检定料 30,000 日元（外国人等特别选考 10,000 日元）；日本政府（文部科学省）奖学金留学生免缴。
- 日程B 受験票 12月中旬发到登记邮箱，12/15（周二）前未收到须联系教務チーム。
- 研究科共通书类：证件照（jpeg）、本科成绩证明书（含教养课程）、毕业证明书（已毕业者，外国大学另附学位证明）；日英文以外文件须附译文，原件在入学手续时提交。
- 专攻书类（日程B一般选拔）：GPA集计表（专攻Excel模板，PDF）、志望调查票·检查表（9个分野按1–9全部排序）、日文小论文；在职就读者另交研究与工作兼顾计划（A4 自由格式）。
- 外国人等特别选考（日程B 同期实施）：只做书类选考，没有笔试和口述；需交毕业研究小论文（或替代物）、入学后研究计划、TOEFL iBT 成绩、出身大学2名教员推荐信（系统外提交），GRE 任意；追加材料截止 2027/1/5。出願前必须联系希望的指导教员并取得可以指导的承诺。不能与一般选拔同时报。
- 禁止事项：不能同时报研究科内两个以上专攻；日程A合格者不能再报日程B；同一日程不能重复报一般选拔和外国人等特别选考。
- 入学时期：日程B合格者原则 2027年4月入学（入学手续期限 2027/3/5）；需要新申请在留资格认定证明书（CoE）的外国籍考生，日程B合格后只能 2027年10月入学（9月上旬发通知、9月下旬办手续）。
- 入学料 282,000 日元，授業料年 535,800 日元（前期 267,900，令和9年度预定额）。
- 安全保障出口管理：东大对外国留学生在入学前和在学中实施审查，属于管制事项时可能不许入学或研究受限。
- 咨询：hees-admission@edu.k.u-tokyo.ac.jp（专攻）；研究科教務チーム（入试问合表单）。
