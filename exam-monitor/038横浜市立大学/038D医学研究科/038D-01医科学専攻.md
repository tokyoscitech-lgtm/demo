## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 各期相同：不设学内英语考试，以外部英语考试成绩换算成“语学试验”得分，出願时必须提交成绩原件（英语成绩是必交书类）。换算式是研究科内部规定，换算表、配点和最低分要项都没有公布。
- 推荐：TOEIC Listening & Reading Test——把公式认定证原件贴在“外部英語資格試験スコア貼付欄”；デジタル公式认定证可打印带二维码的PDF代替原件。
- TOEFL iBT：请 ETS 把 Official Score Report 直送本校（机构代码 0416），出願时贴从 My Home Page 下载的 Test Taker Score Report 并写明直送申请日；直送须在专门试验日前寄到，否则按0分处理。受检超过2年、无法直送的可交 Examinee Score Report 原件。
- 本校实施的 TOEIC IP（マークシート版）：贴 Score Report（可复印件）。2026年本校实施日为 6/13、8/8、11/7（均为周六），11/7 那次可赶上第3期出願。
- 其他可用：IELTS（Test Report Form 须在专门试验日前直送本校，出願时贴复印件或在线成绩页并写明申请日，未到按0分）、TOEFL ITP（Score Report 原件）、团体特别受验的 TOEIC IP（Score Report 原件）。
- 不受理：英検、TOEIC S&W、TOEIC Bridge、TOEIC IP オンライン（含本校实施的在线版）、TOEFL ITP デジタル版。
- 有效期：只承认 2021/4/1 以后受检的成绩。可以交多份，取换算后最高的一份；成绩原则上不退还。
- 变更点：自2026年度入试起，TOEIC IP 在线版（含本校实施的）一律不再受理，2027年度维持。

### 日本語要件
- 外国人须提交能证明达到“日本語教育の参照枠”CEFR B2 相当以上日语能力的合格证书等的复印件；没有 CEFR 参考标注的，由研究科根据总分等判断；2009年以前受检的合格证明不受理。要项没有点名 JLPT 等具体考试。
- 要项、願書、志望理由书均为日语样式；专门试验的语言由各指导教员决定，要项没有记载。
