## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 8月入试：英语须提交外部考试成绩（TOEFL／TOEIC），不设考场笔试，配点 100 分。可以提交的是 TOEFL iBT、TOEFL iBT Home Edition、TOEIC L&R 公开考试三者之一；TOEIC 只认在日本国内受检的成绩。
- 提交分两步，缺一不可：①通过考试机构把官方成绩送到本専攻（TOEFL 的 DI Code 为 8863，不需要 Department Code；TOEIC 的申请代码为 00027401）；②在研究科 WEB 出願系统里登记受检日和分数并上传文件（TOEFL 上传 Test Taker Score Report，TOEIC 上传デジタル公式認定証）。期限是出願截止（2026/6/23 15:00）。
- 有效期：2024/10/1 以后受检的成绩。2026/1/21 以前受检的 TOEFL 按 0–120 分登记，其后受检的按 1–6 分登记。
- 机构送分可以送多次，但 WEB 系统里只能登记 1 个成绩；TOEFL 的 MyBest Scores 不采用。考试当天带来的纸质成绩单不受理，逾期没有任何例外（専攻说明会资料）。
- 専攻案内只列出上面三种考试，没有提到团体考试（ITP、IP）和其他英语考试，即这些不在可提交之列。
- 说明会资料提到有把成绩换算成 100 分的换算表，但公开资料里没有给出表的内容；官方也没有设最低分数线。
- 研究科页告知的“天文学専攻、化学専攻改为提交外部成绩”的变更不适用于本専攻，本専攻此前已是提交制。

### 日本語要件
- 専攻案内和専攻入试告知都没有要求提交日语成绩（JLPT 等）。研究科要项 PDF 无法正常读取，其中是否另有规定未获取到。
- 笔试可以用日文或英文作答；口述試験可以用日语或英语进行。试题本身是否日英并记未获取到。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 専門科目（数学·物理学）（400分，240分钟） | 共4题，全部必答：数学1题（物理学研究所需的基础数学）＋物理学3题（主要范围是量子力学、统计力学、古典力学和电磁学） | 専攻入试信息（2027年度） |
| 外国語（英語）（100分，不在考场实施） | 以提交的 TOEFL／TOEIC 成绩换算 | 専攻入试信息（2027年度） |

- 总分 500（専門科目 400＋英语 100）。先按笔试结果决定口述試験对象者，再按サブコース进行口述；最终合否先看第1志望サブコース内的希望指导教员顺位，第1志望不合格时再按第2志望判定。各题配点和合格线官方未公布。
- 题目倾向（体验记，非官方）：近年固定为数学、量子力学、统计力学、电磁学或古典力学各1题，每题约可用 45–60 分钟，多人提到时间很紧、失分主要来自计算量和式变形而不是知识点；第3题在电磁学和古典力学之间变动，出现过电偶极子、镜像法和纯力学题；统计力学出过玻色–爱因斯坦凝聚这类与过去问接近的题。对难度的评价不一致，有人认为近年偏易、要靠稳定高分拉开差距，也有人认为难题变多、理论系合格线据传在8成左右。成绩开示显示四道题各按 100 分计（仅1人提及）。

### 口述試験 / 面接
- **官方形式**：只有笔试通过者参加，2026/9/1–9/2 在本郷キャンパス理学部1号館现场进行，按志望サブコース（A0–A8）分场，日语或英语均可。填了两个サブコース的人原则上分别受试，也可能只被安排其中一个。受付在理学部1号館2階207号室（受験生控室），须在各自开始时刻的15分钟前完成；时间割以15分钟为间隔排到个人。出願时可提交「口述試験日の配慮希望申請書」申请避开与他校考试冲突的日期，但不保证满足。配点和具体提问内容官方未公布。
- **実際に聞かれた内容**：体验记普遍说明被要求保密，没有人写出具体问题。能确认的只有方向：会问到个人经历、现在所在研究室的工作和入学后的研究兴趣；理论志望围绕学过的课程内容，实验志望围绕做过的实验或研究经历。A8 的考场面对约30位教员、气氛温和（仅1人提及）。
