## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般入试（A日程、B日程都要）：
  - 不另设英语笔试，用 TOEIC L&R 或 TOEFL iBT（含 Home Edition）成绩评价，B日程配点 100 分。
  - 本系要求出願时提交在线版成绩单打印件，出願截止后提交的不受理，交后不能更换、不退还；截止前没交的没有受験资格。
  - 只认 2024/6/11 以后受检的成绩。TOEIC 须为带真伪确认 QR 码的数字公式认定证 PDF 打印件；TOEFL 须为 Test Taker Score Report PDF 打印件，并在 ETS 账户为该成绩设定 DI code G179。ETS 邮寄的纸质成绩单、TOEFL ITP、TOEIC IP 等团体考试不受理。
  - 要项附録3的换算基准：TOEFL iBT 先按对照表换成 PBT，再用（PBT－296）÷0.348＝TOEIC L&R，例如 iBT 80→PBT 550→TOEIC 约 730（TOEIC 300 分以下不适用）。
- IGP(C)：申请材料不要求英语成绩；面试和考试用英语进行。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 过去问为日文出题；IGP(C) 全英语授课，不要求日语。

- B日程：筆答専門試験两限合计 400 分＋英语 100 分；先按筆答结果决定口頭試問受験资格者，再综合出願书类、筆答和口頭試問判定合否；教员人均合格者数可能受限。
- A日程：系根据出願书类决定受験资格者（考生不能自选，2026/7/2 マイページ通知），凭出願书类和口述試験决定“合格内定”；内定者不再考 B日程，没内定的可接着考 B日程；出願资格(9)（飞级）只能考 B日程。
- 计算器、尺、圆规不能用；考试和口頭試問不必穿西装、打领带。

### 口述試験 / 面接
- **官方形式**：A日程：口述試験线上进行，试问应用化学分野的专门内容（如学士论文研究、修士阶段想做的研究），评价 A–E 五级；B日程：口頭試問用 Zoom 线上进行，只有受験资格者参加，试问学士论文研究和修士阶段想做的研究等，评价 A–E 五级；IGP(C)：系或志望导师安排的英语面试和/或考试，原则线上。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：応用化学系受入可能予定人数 191 名（2026年9月和2027年4月入学合计）；IGP(C) 各系若干名。
- 出願资格：大学毕业（含 2027/3/31 前预计）或外国16年学校教育等，(9)–(11) 项须先审查出願资格；只能报一个系，结果出来前不能再报理工学系其他募集（含 IGP(C)）；外国籍选9月入学须出願时住在日本且在留资格有效到 2026/9/28；出願登记住址限日本国内；志望教员填到第5志望，第2志望以下可选不同分野；IGP(C) 须先取得本系教员的指导同意。
- 要提前准备的书类：志望理由书（所定样式，写对志望研究室·研究分野的志望理由，300字以内）；TOEIC L&R 或 TOEFL iBT 成绩单（出願时必交）；IGP(C) 另需导师同意书、研究计划和推荐人直接提交的评价表兼推荐信。

- 并愿限制：只能报一个系；结果出来前不能再报理工学系的其他募集，同一入学期不能报多个修士募集。本系考生可同时申请清華大学（中国）大学院合同项目。地球生命コース另有 ELSI 的入试说明。
- 咨询：系入试担当 chem.admin@mct.isct.ac.jp；出願手续问入試課大学院入試グループ inquiries.grad.se@adm.isct.ac.jp。
