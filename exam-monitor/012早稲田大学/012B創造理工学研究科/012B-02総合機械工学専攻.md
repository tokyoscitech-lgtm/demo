## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般入试、特別選考：
  - 不另设英语笔试，外部英语成绩是出願资格，须达到其一：TOEIC L&R 550、TOEFL iBT 57（或スコアバンド 3.5）、IELTS Academic 5.5；成绩不达标出願无效。
  - 有效期：出願开始日前2年以内受检。
  - TOEIC 交公式认定证（日本国内受检交数字认定证打印件，团体代码 00019702）；TOEFL iBT 由 ETS 直送（DI code 2874）并附 Test Taker Score Report；IELTS 电子送达研究科并附 Test Report Form。
  - 不受理：TOEIC IP・S&W・Bridge，TOEFL ITP・PBT・Home Edition・Paper Edition・My Best scores，IELTS General Training・Online・One Skill Retake。
- English-based AO：
  - 不设最低分，推荐 TOEIC L&R 800、TOEFL iBT 79（或スコアバンド 4.5）、IELTS Academic 6.5 以上，有效期同为2年；英语母语者、英语授课大学毕业者等可免交。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 一般入试和特別選考的笔试、面接原则上用日语进行；English-based AO 是英语授课的学位项目，申请书用英语填写。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 共通科目：小論文 | 与机械工学有关的题目1题，当场出题，必答 | 60分钟 |
| 選択科目 | 从下面4个科目共选2题作答（可出自同一科目），答3题以上不评分 | 90分钟 |
| 　熱と流れの工学 | 热力学第一·第二定律、热力循环、能量与㶲守恒、蒸气、传热基础；静止流体、完全流体、粘性流、旋涡、连续方程、动量守恒、流体损失、量纲分析、边界层、管内流动 | |
| 　材料の力学 | 应力、应变、材料力学性质、截面内力、拉伸·压缩·扭转·弯曲、组合应力、能量原理、屈曲 | |
| 　メカトロニクスとコントロール | 电路理论、古典控制理论、机械力学、拉普拉斯·傅里叶变换、建模、位置·速度·加速度·力传感器、电气执行器 | |
| 　材料工学の基礎 | 相平衡、状态图、材料组织、晶体塑性、强度与破坏 | |

- 笔试 10:00–13:00：先考小論文，休息30分钟后考選択科目；须自带计算器，带程序功能的不能用。
- 合否按书类审查、笔试、面接综合判定。
- 特別選考（社会人・奨学生）以面接为主，可能事先通知后加考笔试；English-based AO 以书类审查为主，不考笔试。

### 口述試験 / 面接
- **官方形式**：一般入试：笔试次日面接选考（含口述试验），原则上用日语；特別選考：面接，社会人另有针对出願书类的口述试验，原则在西早稲田校区（教员判断可改线上），缺席即不合格；English-based AO：视指导教员或専攻需要补充面试（电话、邮件、线上，日本居住者也可面对面）。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：100名（一般入试4月入学，含其他入试名额）；特別選考（社会人・奨学生）另设名额；English-based AO 9月・4月入学各若干名。
- 出願资格：大学毕业（含预计）或外国16年学校教育等，一般・特別選考还须满足英语成绩基准；只能报1个専攻，出願时填志望研究指导；特別選考社会人须毕业后2年以上实务经验且出願时在职，奨学生须已获研究科认可、相当于在学期间学费总额的奖学金；English-based AO 不接受中国大陆三年制专科学历（之后读完本科者可以）。
- 要提前准备的书类：志願票①（志望动机・研究计划，日语，A4 1页）；中国大陆毕业者须由 CSSD 直送学历·学位（在读者为学籍）Online Verification Report；特別選考另需所定样式推薦状（密封）、奨学生交奖学金受给证明原件；English-based AO 需英文 Application Form（2页以内）和推荐信2封（密封）。
- 出願：网上申请表＋检定料＋书类邮寄，三项在期限内完成，书类必达；检定料一般・特別選考 30,000 日元，English-based AO 日本国内居住 30,000 日元、海外居住 15,000 日元。
