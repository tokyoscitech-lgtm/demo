## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般選抜（不另设英语笔试，用外部考试成绩，按志望教员所属学府·専攻的方式提交）：
  - 経済学専攻区分：TOEFL iBT 或 TOEIC L&R，出願时提交，须为出願开始日前 2 年以内受检。TOEFL 要由 ETS 直送 Official Score Report（Institution Code 0410，Department Code 99），并另交 ETS 寄给本人的 Test Taker Score Report 复印件或网站打印件；TOEIC 须 550 分以上且只限日本国内受检，交 Official Score Certificate 原件或数字认定证打印件。成绩没送到原则上不受理出願。配点学環要项没写。
  - 経営学専攻区分：TOEFL iBT（含 Home Edition）或 TOEIC L&R，须为第2次選抜日前 2 年以内且出願开始日前受检。TOEFL 要由 ETS 直送 Official Score Report，出願开始前就要办好直送手续，并在出願时交 Test Taker Score Report 复印件或网站打印件，按 Test Date Scores 计；TOEIC 交 Official Score Certificate 原件（国内受检可用数字认定证，国外受检交 Official Score Report 原件）。成绩没送到原则上不受理出願。配点学環要项没写。
  - 環境情報学府区分：TOEIC L&R（公开考试）、TOEFL iBT（含 Home Edition）、IELTS 三选一，考试当天携带有照片的成绩单、按监考指示提交。原则上只收原件，复印件、下载的 PDF 不行；例外是国内受检的 TOEIC 可交带二维码的数字认定证打印件，2026年1月以后受检的 TOEFL iBT 和 IELTS Online 交下载打印的受験者用成绩单。须为考试日前 2 年以内受检，考过多次的交合计分最高的一次；没交不能合格。
  - 環境情報学府区分换算成 100 分：TOEIC 349 以下 0 分，350–500 为（分数−350）÷3，500–800 为（分数−500）÷6＋50，801 以上 100 分；TOEFL iBT 新分数 2 以下（旧 33 以下）0 分、2.5（34–43）40 分、3（44–57）70 分、3.5（58–71）90 分、4 以上（72 以上）100 分；IELTS 3 以下 0 分，3–4 为（分数−3）×50，4–7 为（分数−1）×50÷3，7 以上 100 分。例如 TOEIC 650＝75 分，IELTS 5.5＝75 分。
  - 各区分 TOEFL 都不用 MyBest Score；都不受理 TOEIC IP、TOEFL ITP 等团体考试和 TOEIC Bridge、TOEIC S&W。除経済学専攻区分的 TOEIC 550 分外，要项没有规定最低分。
- 特別選抜：本身不按外部成绩计分，口述试验中含英语提问；落选后转考一般選抜的人仍要按所属学府·専攻的方式交成绩。
- 社会人特別選抜：要项没有英语成绩要求。

#### 日本語要件
- 志望経済学専攻教员的外国人，须已通过日本語能力試験 N1 或 N2，出願时交日本国際教育支援協会出具的「日本語能力試験認定結果及び成績に関する証明書」原件（复印件不行）；按资格（1）出願、且在日本以日语授课的大学毕业（含预计）的人免交。一般選抜、特別選抜、社会人特別選抜都适用。
- 志望経営学専攻或環境情報学府教员的，要项没有要求提交日语成绩。
- 研究（希望）計画書必须用日语写（1,000 字以内），各选拔相同。経済学専攻区分笔试用日语出题，外国人可用英语作答，面试原则上用日语；経営学専攻区分论文必须用日语作答；環境情報学府区分的笔试和口述可以用英语作答。

- 出願书类（一般選抜·特別選抜）：出願書類送付内訳書；入学願書·受験票（4cm×3cm、3 个月内拍摄的照片 2 张，不能用 App 修图）；研究（希望）計画書（日语 1,000 字以内，写研究主题和具体内容，含如何实现文理融合·异分野融合、对 Society 5.0 构建与发展有何贡献的研究方法和意义；要项提醒须自己思考撰写，慎用生成式 AI）；卒業（見込）証明書（外国大学另附学位证明，非日英文附译文）；成績証明書；検定料缴纳证明；外部英语成绩（按所属学府·専攻方式）；外国人留学生另交在留卡（两面）或护照复印件、修学年数調書（按资格（1）出願的免交），志望経済学専攻教员的外国人交 JLPT 证明书；受験票回邮信封（长形3号，贴 410 日元邮票，注明速达，限日本国内地址）和地址标签。特別選抜另交出願資格証明書、推薦書、志望理由書（A4 1 页）、入学確約書。书式从学環网站下载，A4 白纸单面打印。
