## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 不另设英语笔试，用 TOEFL iBT（含 Home Edition）成绩评价。
- 送分：向 ETS 申请把 Institutional (Official) Score Report 送到研究科（DI code 1113）；出願时在 WEB 出願系统里填写 Appointment Number、受检日和分数，不必交 Test Taker Score Report。
- A日程只认 2024/8/1–2026/6/13 之间受检（并申请送分）的成绩。
- 送过多次的，出願时只填一次。TOEFL ITP 不受理，MyBest Scores 不采用。
- 官方没有公布最低分、换算方法和配点。

#### 日本語要件
- 要项和専攻案内都没有要求提交日语成绩（JLPT 等），外国人考生走一般选拔也不用交；研究科不设单独的外国人留学生特别选拔。
- 専門科目的出题语言在出願时从日语和英语中选一种，出願后不能更改。口述使用的语言官方没有写明。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：A日程（2026年10月入学或2027年4月入学）17名；本専攻不实施 B日程。
- 出願资格：日本的大学毕业或 2027/3/31 前预计毕业；在外国完成 16 年学校教育；在外国取得相当于学士的学位（3 年以上课程）；文部科学大臣指定者；学位授与機構授予学士学位；经个别入学资格审查认定且 2027/3/31 满 22 岁。个别入学资格审查和受验照顾申请截止 2026/5/7（已过）。
- 入学时期：A日程可选 2026年10月入学（限 2026年9月以前毕业或预计毕业者）或 2027年4月入学，在 WEB 出願系统里选择，出願后不能更改。
- 志望填写：在 WEB 出願系统里按「教員並びに専門分野一覧」填专门分野和教员，最多填到第3志望；第2、第3志望可以填同一分野的其他教员，没有可以不填。一览会因人事变动更新，出願前要看最新版。
- 出願书类：入学願書（WEB 填写，含照片）、出身大学成绩证明书（全部在学期间）、毕业（预定）证明书（写明学位名和授予日）、检定料缴纳证明、国费留学生证明书（仅该当者）、TOEFL 成绩；本専攻没有另外指定専攻独有书类。原件在入学手续时提交。
- 出願方式：只能通过 WEB 出願系统；书类不齐不受理，出願后原则上不能修改。受験票自己从系统打印，考试当天带上。
- 检定料 30,000 日元，银行汇款（邮储银行除外）、便利店、信用卡、Pay-easy 均可，A日程缴纳期间 2026/4/13–6/23（已过）；国费留学生免缴，缴后不退。
- 并愿：同一日程只能报研究科的一个専攻。
- 入学料 282,000 日元，授業料 年 535,800 日元（前期 267,900 日元），均为预定额；国费留学生免缴。
- 木造建築コース是另一条路线：只招有 2 年以上相关实务经验的社会人，用单独的募集要项（社会人特別選抜），専門科目从建築学、木材科学、木材利用システム学中选 2 科。这不是本専攻一般修士入试的要求。
- 咨询：専攻的问题问 斎藤 幸恵 教授（Tel 03-5841-5251，aysaito@g.ecc.u-tokyo.ac.jp）；出願手续问农学生命科学研究科教務課学生支援チーム大学院学生担当（〒113-8657 東京都文京区弥生1-1-1，Tel 03-5841-5010，daigakuin.a@gs.mail.u-tokyo.ac.jp）。
