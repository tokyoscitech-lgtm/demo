## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 须提交 TOEFL iBT（含 Home Edition）或 IELTS Academic 的成绩，専攻不另设英语笔试。
- TOEFL：在 ETS 账户里把 Official Score Report 送到研究科（机构代码 8426，Department 42 Medicine），在 WEB 出願系统登记 Appointment Number 和受检日，并上传 Test Taker Score Report 的 PDF。
- IELTS：在 WEB 出願系统上传 Test Report Form，并向 IELTS 事务局申请把同一次考试的成绩单寄到研究科学務チーム大学院担当；出願前申请即可，寄到时间晚于出願截止也受理。
- 有效期：只认 2024/8/1 以后受检的成绩。考过多次的只能上传 1 份，只采用与登记受检日一致的那一次。
- IELTS General Training 和 One Skill Retake 的成绩不受理；别纸没有列出其他考试种类。
- 最低分、换算方法、配点，官方都没有公布。成绩的具体提交期限别纸没有写日期，只说以 WEB 出願系统的通知为准。
- 免除：学士课程毕业于澳大利亚、加拿大、爱尔兰、新西兰、英国、美国的大学，或毕业大学出具全校英语授课证明的，可申请免交；须事先联系事务并在 2026/6/5（周五）前提交审查材料（已截止），逾期即使母语是英语也不免除。
- 官方送达的成绩未能确认、上传内容与官方成绩不一致、成绩早于有效期的，按无效处理。

### 日本語要件
- 外国人出願者须提交「日本語能力証明書」（研究科指定样式）。要项没有规定 JLPT 等级或分数。
- 作答语言（日文或英文）在要项和入学試験案内里没有明确记载。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员为 20 名（按成绩，合格人数可能不满 20 名）。
- 出願资格：大学毕业或 2027/3/31 前预计毕业；在外国完成 16 年学校教育；在外国大学 3 年以上课程取得相当于学士的学位；文部科学大臣指定者；由学位授与机构取得学士；经个别入学资格审查认定且入学时满 22 岁，以上之一（均含预定者）。
- 个别出願资格审查的申请截止为 2026/5/29（周五）（已截止），用邮件向研究科申请。
- 出願书类：入学願書、证件照（jpg，3 个月内）、检定料缴纳凭证、成绩证明书、毕业（预定）证明书、TOEFL 或 IELTS 成绩、志願理由書（A4 2 页，左上角写明“志願理由書”、姓名、页码，在 WEB 系统上传）、日本語能力証明書（仅外国人）、指導教員受入確認票（仅事先定好指导教员的人）、改姓证明（有需要者）。
- 只能通过 WEB 出願系统出願，不收邮寄；所有上传须在出願截止时刻前完成。
- 检定料 30,000 日元（国费留学生不用缴），可用银行汇款、便利店、Pay-easy、信用卡，手续费自付；要项没有另设缴纳期间，须在出願截止前缴清并上传凭证。
- 入学料 282,000 日元，授業料 年 535,800 日元（前期 267,900 日元），均为 2027年度预定额；国费留学生免缴入学料。
- 需要受验照顾的残障考生须在 2026/6/5（周五）前联系研究科（已截止）。
- 入学手续：2027 年 2 月下旬用邮件通知，3 月上旬在规定期限内缴费并交材料。
- 入学后前 3 个月上基础医学的讲义和实习，之后在指导教员处做研究并提交修士论文；修了后多数人直接升入医学博士课程。
- 咨询：医学系研究科学務チーム大学院担当（〒113-0033 東京都文京区本郷7-3-1），in.m@gs.mail.u-tokyo.ac.jp；要项没有写电话。另有网上咨询表单（见募集要项页）。

### 研究室 / 指導教員
- 事前連絡要否：要项没有要求所有人出願前联系教员（可以不定指导教员直接出願）；但想在出願时就确定指导教员的人，必须事先联系该教员、访问研究室，并取得「指導教員受入確認票」上的签名。
- 願書的「志望する研究室」一栏：已定好的选“有り”，填専攻分野和指导教员；没定的选“無し”。
- 没定指导教员的人，入学后在 7 月前后轮转各研究室，8 月底确定；因为有名额限制，可能进不了第一志愿的研究室。
- 每位教员每学年最多收 2 名（事先定好的和轮转后定的合计）。入学后原则上不能换指导教员，也不能委托校内外其他研究室指导。
- 协力研究所（医科学研究所、定量生命科学研究所）：出願阶段每所各 2 名；除本人希望的教员外，还要联系所里的联络教员并由其签名。联络教员：医科学研究所 岡田 尚巳 教授，定量生命科学研究所 岡崎 拓 教授。
