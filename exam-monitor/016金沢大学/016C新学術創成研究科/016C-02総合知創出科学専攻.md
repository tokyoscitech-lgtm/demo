## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各轮相同，必须提交 TOEIC L&R 或 TOEFL iBT（含 Home Edition）的成绩，不另设英语笔试；成绩计入综合评价，须是考试日前2年以内受检的。
- 不受理 TOEIC IP、TOEIC S&W、TOEIC Bridge、TOEFL ITP；TOEFL 只用 Test Date Score，不用 MyBest。
- TOEIC：上传数字公式认定证（二维码须能读取），或上传纸质认定证并在考试当天交原件。
- TOEFL：上传 Test Taker Score Report 的 PDF 时，必须同时请 ETS 向金沢大学送分（Institution Code G170），没办送分视为失格；上传邮寄版原件的，考试当天交原件。
- 出願期内来不及上传的，只要考试当天能交就可以出願；当天交不出则失格。

#### 日本語要件
- 要项没有要求提交日语成绩；外国人留学生特别选拔在要项里写明不问日语能力。小论文可用日文或英文写。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 小论文2篇（出願时提交） | 课题①至今学过的内容·做过的研究（毕业研究等）；课题②入学后想做的研究内容·研究计划（含综合知创出的观点）；每篇日文约1,000字或英文约600词，含图1页以内 |  |

- 各轮都不设笔试。合否按小论文、口头发表、口述试验并加上英语外部成绩综合评价，重视本科阶段的基础专门知识和创造综合知的意愿；一般选拔、社会人特别选拔、外国人留学生特别选拔按各自的基准判定，社会人另加实务经验。

### 口述試験 / 面接
- **官方形式**：夏入试·秋入试·冬入试相同：同一天进行口头发表（围绕出願时的小论文，10分钟以内，资料须在考试日2天前以 PDF 发到大学院係，另带打印件5份）和口述试验（就发表质疑，并口头出题考希望的研究指导教员所需的专门分野基础，社会人另问实务经验，20分钟以内，出题分野在受験票开放打印后通知）；海外在住、当天难以来日的可在出願时申请用 Zoom·Webex 线上应试。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：一般选拔32名（三轮合计；研究科入试信息页注明要项上的15名改为32名）；社会人特别选拔、外国人留学生特别选拔各若干名。
- 出願资格：大学毕业（含2027/3/31前预计）或外国16年学校教育等①–⑪项之一；以⑥⑨⑩⑪报考者须先通过出願资格认定（冬入试 2026/11/30–12/4 16:30 用邮件提交 PDF，非独立出願）；外国人留学生特别选拔限无日本国籍、且没有在日本取得学士学位者（日本大学毕业的外国人走一般选拔）；社会人特别选拔须在职或入学时有3年以上在职经验。
- 要提前准备的书类：志願者調書（様式1，写明希望的研究指导教员）、小论文2篇（様式2-①·2-②）、TOEIC L&R 或 TOEFL iBT 成绩；社会人另交社会经验概要；外国学校的证明书须是日文或英文；外国籍者交护照复印件，在日本的另交在留卡正反面复印件。
- 出願：只能 Web 出願，登记缴费后上传照片和全部书类，再把原件書留速達邮寄或窗口提交，最后一天必达（海外在住难以按期寄到的，缴费前先联系大学院係）；检定料 30,000 日元＋系统服务费 990 日元（国费留学生免缴）。
