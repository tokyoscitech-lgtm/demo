## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 各轮次、各受験系相同：考试当天不考英语，出願时提交 TOEFL iBT 或 TOEIC L&R 公開テスト的成绩，二选一。
- 成绩须为入学考试实施日之前 2 年以内受检。TOEFL iBT 只用 Test Date 成绩，不用 MyBest；TOEFL iBT Home Edition 可以。团体考试的 TOEFL ITP、TOEIC IP 不受理。
- 提交方式三选一：TOEIC 的デジタル公式認定証（带二维码）上传到 TAO；在日本国外考的 TOEIC 纸质公式認定証，上传复印件并把原件交到教務係；TOEFL 的 PDF 版 Test Taker Score Report 上传到 TAO。考试机构直接寄给大学的成绩单无效。
- 秋季募集的提交截止与书类相同（2026/7/23 16:00 窗口／当日必达）；只有 2026/6/28 日本国内 TOEIC 公開テスト的成绩可以在 7/23 16:00 前通过 TAO 的消息功能补交。出願后不能追加或替换。
- 没有提交的，英语按 0 分处理。换算方法官方只写“按一般方法换算成英语科目得分”，没有公布公式、配点和最低分。
- 以英语为母语或用英语接受高等教育的人，要事先向教務係询问并在指定日期前交材料（秋季募集为 2026/6/15）。

### 日本語要件
- 外国人留学生和在外国大学受过教育的人要提交“日本語能力証明書”：日本語能力試験的证明，或由教员等出具的证明；要项没有规定等级或分数。
- 外国人留学生等特別選抜的工学系（材料）在口頭試問里同时判定日语能力。
- 试题语言和可用的作答语言，本次没能从要项中读取到明确记载。
