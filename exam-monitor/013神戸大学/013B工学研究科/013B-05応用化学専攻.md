## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各轮次都不另设英语笔试，用外部成绩评分，配点 150分。
- 一般入試：只收在日本国内实施的 TOEIC L&R 公开テスト，2024/8/25 以后受验有效，须在出願期间内从 TOEIC 申込サイト「大学・企業等へのスコア提出」提交（申请代码 00010407），不收公式認定証；期间内没提交的不受理出願。TOEIC-IP 不受理。
- 外国人留学生特別入試：TOEIC L&R 公开テスト（日本国内外实施的都可以）或 TOEFL iBT。日本国内考的 TOEIC 从申込サイト提交；国外考的 TOEIC 交带照片的成绩单原件和 A4 复印件；TOEFL 交 Test Taker Score Report 原件和复印件（或 PDF 版打印件），并让 ETS 把 Official Score Report 送到神戸大学（DI 代码 B071）。TOEIC-IP、TOEFL ITP、Home Edition 不受理。有效期：第一期 2024/8/25 以后、第二期 2025/1/21 以后受验。
- 推薦入試：出願资格要求 TOEIC L&R 公开テスト 600分以上（2024/7/7 以后受验）。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 外国人留学生特別入試（第一期・第二期）可在調査シート上申请英文试题：本専攻申请者同时拿到日文和英文试题。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 専門科目(一) 物理化学（150分） | 物理化学 | 9:30–11:00，90分钟 |
| 専門科目(三) 化学工学（300分） | 化学反应工学、移动现象论、分离工学、生物化学工学 | 12:20–14:20，120分钟 |
| 専門科目(二) 物質化学（300分） | 无机化学、分析化学、有机化学、高分子化学 | 15:00–17:00，120分钟 |
| 外国人留学生特別入試 小論文（150分） | 不考上面的专门科目 | 10:00–11:30，90分钟 |

- 一般入試总分 900（专门科目 750＋英语 150）；各专门科目可能含相关数学、专业英语阅读或要求用简单英语作答的小题。可带尺和函数计算器。
- 外国人留学生特別入試（第一期・第二期）总分 400（小論文 150＋英语 150＋口頭試問 100）。
- 缺考指定科目或口頭試問的不进入选考。

### 口述試験 / 面接
- **官方形式**：一般入試先对全体考生做书面审查，结果好的免口頭試問（免除者 8/24 在考场张贴通知），其余考生 8/25 13:00 起口頭試問，书面审查和口頭試問只判合否；外国人留学生特別入試（第一期・第二期）口頭試問 100分计入总分；推薦入試以口頭試問为主，志願者多时先考小論文，可据此做第一次选拔。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：70名（含推薦入試约20名、外国人留学生特別入試・社会人特別入試若干名）；外国人留学生特別入試第二期若干名。
- 出願资格：大学毕业（含2027/3/31前预计）、外国16年学校教育或外国3年以上课程取得学士相当学位等；外国人留学生特別入試限持有或2027年4月前取得「留学」在留资格的外国人；短大・高专・专修学校等毕业者须先过个别资格审查（第二期 2026/11/25–11/27 17:00 必达，12/7 前通知，非独立出願）；只能报一个専攻，出願后不能改内容；推薦入試须 TOEIC L&R 600分以上。
- 要提前准备的书类：外国人留学生特別入試须上传指导预定教员出具的受入内諾書（所定样式或教员自拟）和本専攻用調査シート，非神戸大学工学部・工学研究科在籍者另交出身大学指导教授的推荐信（非英文附英译或日译）；外部英语成绩（见英語要件）；中国大学毕业者须申请 CHSI 英文学位认证电子邮件直接发到工学研究科（本人转发无效）；在日外国人上传住民票（30天内开具）。
- 出願：只能通过 Web 出願系统（e-apply.jp/ds/kobe-u）登录并缴费，再把纸质书类書留速達邮寄（截止日17:00必达）或窗口提交（平日 9:30–16:00）；检定料 30,000 日元，国费外国人留学生免缴。
- 咨询：神戸大学大学院工学研究科 学務課教務学生グループ（〒657-8501 神戸市灘区六甲台町1-1），eng-kyomugakusei@office.kobe-u.ac.jp，Tel 078-803-6350。
- 并愿：只能报一个専攻。
