## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般选拔（学力試験）：学内考外国語（英语）笔试（100分，90分钟），可以用成绩代替或免考：
  - 交 TOEIC L&R（公开或 IP，线上 IP 不可）、TOEFL iBT 或 IELTS 成绩原件的（第2次募集起 TOEFL iBT Home Edition 和 IELTS Online 不受理），按（TOEIC－220）÷6（舍去小数，0–100分）换算，与笔试分取高者；TOEFL、IELTS 先由研究科折成相当的 TOEIC 分。例如 TOEIC 700＝80分。换算以参加英语笔试为前提。
  - TOEIC 700、TOEFL iBT 72（2026/1/21 以后受检为 Overall Score 4）、IELTS 5.5 以上可申请免考，按80分计。
  - 成绩限出願截止前2年以内受检，出願期内交原件；TOEFL 须同时由 ETS 送分（DI Code G283）和邮寄打印的成绩单。
- 第1次募集口述試験选拔（只限第1回出願）：必须交 TOEIC L&R 成绩，按书类决定是否免笔试。
- 社会人特別選抜：不考外国語。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 外国人留学生特別選抜：外国語可选日语或英语（试题说明为日文）；考日语的，EJU「日本語」（不含记述）300分以上或上面的英语成绩可免考，按80分计；共通科目、専門科目可选日语或英语作答，口頭試問可能用日语进行。
- 社会人特別選抜的小論文可选日语或英语，口頭試問可能用日语进行。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 共通科目「食品流通安全管理学」 | 阅读与食品安全·安心有关的文章，分析问题所在并提出解决方案（论述） | 10:00–11:30，90分钟 |
| 専門科目 | 选择题；出願时从食品科学、品質安全マネジメント、食品流通・ロジスティクス 3 分野中选1个 | 13:00–14:30，90分钟 |
| 外国語（100分） | 一般选拔考英语；外国人留学生特別選抜选日语或英语 | 次日 10:00–11:30，90分钟 |
| 社会人特別選抜－A：小論文 | 与指导预定教员専門科目（食品流通安全管理）有关，可选日语或英语 | 10:00–11:30，90分钟 |

- 学力試験：在笔试和口頭試問都达到最低基准的人中，综合成绩、成绩证明书和入学定员判定。社会人特別選抜－B 不考小論文，只有口頭試問。
- 第1次募集另有口述試験选拔（只在第1回出願、交 TOEIC 成绩并承诺合格必入学者可以希望，入学资格审查对象除外）：书类判定通过的免笔试只考口述，没获免除或口述不合格的转入学力試験，不再交检定料。

### 口述試験 / 面接
- **官方形式**：第1次募集口述試験选拔：口述评价基础知识、专门知识、志望理由书（含研究计划）、表达力和学习意愿；学力試験和社会人特別選抜的口頭試問：问毕业论文研究内容或业务实绩、志望理由书（含研究计划）、表达力和学习意愿，围绕食品流通安全管理进行。
