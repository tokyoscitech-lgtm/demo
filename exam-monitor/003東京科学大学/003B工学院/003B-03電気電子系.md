## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般入试（A日程、B日程都要）：
  - 不另设英语笔试，用 TOEIC L&R 或 TOEFL iBT（含 Home Edition）成绩评价，B日程配点 150 分。
  - 本系要求出願时必须提交在线版成绩单打印件，出願时没交即无受験资格，之后一律不收。
  - 只认 2024/6/11 以后受检的成绩。TOEIC 须为带真伪确认 QR 码的数字公式认定证 PDF 打印件；TOEFL 须为 Test Taker Score Report PDF 打印件，并在 ETS 账户为该成绩设定 DI code G179。ETS 邮寄的纸质成绩单、TOEFL ITP、TOEIC IP 等团体考试不受理。
  - 要项附録3的换算基准：TOEFL iBT 先按对照表换成 PBT，再用（PBT－296）÷0.348＝TOEIC L&R，例如 iBT 80→PBT 550→TOEIC 约 730，iBT 100→PBT 600–603→TOEIC 约 874–882（TOEIC 300 分以下不适用）。
- IGP(C)：申请材料不要求英语成绩；面试和考试用英语进行。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 本系写明考试原则上用日语进行：A日程口述用日语线上进行，B日程口頭試問用日语对面进行，筆答试题为日文。
- IGP(C) 全英语授课，不要求日语。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 数学（300分） | 微分方程、复变函数、拉普拉斯变换、傅里叶变换、概率统计、向量分析等；必答 | 9:30–12:10（三科连考，共160分钟） |
| 電磁気学（300分） | 静电场、静磁场、电磁感应、电磁场定律等；必答 | 同上 |
| 选择专门科目：電気回路（200分） | 交流电路、分布参数电路、电路解析、电路定理、电子电路等；与下一行二选一 | 同上 |
| 选择专门科目：量子力学/物性基礎（200分） | 势与波函数、光的吸收与发射、电导、能带、晶体结构等；与上一行二选一 | 同上 |
| 英语（150分） | 用外部成绩评价，见英語要件 | |

- A日程：系根据出願书类决定受験资格者（考生不能自选），凭出願书类和口述试验决定“合格内定”；没有内定的照常考 B日程；出願资格(9)（飞级）只能考 B日程。
- B日程：总分 950，筆答受験者全员参加同日的口頭試問；按筆答和口頭試問成绩、志望研究分野和指导教员、适性判定，A日程的受験资格有无和口述成绩不计入；每位教员的指导学生数有上限。
- 2025年实施的出题（出題の意図归纳）：数学考二阶线性常微分方程、复变函数的奇点·级数展开·留数定理；電磁気学考平行导体板间静电场、线圈的自感互感与受力；電気回路考戴维南等效、含电感的过渡现象、运放电路的频率特性；量子力学/物性基礎考玻尔模型、本征半导体的载流子浓度与费米能级。
- 题目倾向（体验记，非官方）：2025年8月数学和電磁気学不算难，量子力学部分容易、物性部分范围广；160 分钟需自行分配（仅1人提及）。

### 口述試験 / 面接
- **官方形式**：A日程：口述試験，考查基础与专门学力及适性，用日语线上进行；B日程：口頭試問，与筆答同日，考查志望分野和适性，用日语对面进行，筆答受験者全员参加；IGP(C)：系或志望导师安排的英语面试和/或考试，原则线上。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：電気電子系受入可能予定人数 150 名（2026年9月和2027年4月入学合计，工学院合计 477 名）；IGP(C) 各系若干名。
- 出願资格：大学毕业（含预计）或外国16年学校教育等，(9)(10)(11) 项须先做资格审查；只能报一个系，出结果前不能再报理工学系其他募集（含 IGP(C)）；外国籍考生选9月入学须出願时住在日本且在留资格有效到 2026/9/28，否则只能4月入学；志望教员最多10位，另在「系・課程の指定する入力項目」填配不到时可接受的研究组顺序（不填可能被分到不相近的组）和想限定的コース。
- 要提前准备的书类：志望理由书（所定样式 A4 1张，志望研究室·分野的理由，1,000字以内）；TOEIC L&R 或 TOEFL iBT 成绩单（出願时必交）；IGP(C) 另需导师同意书（10/4 前交入試課）、研究计划和推荐人直接提交的推荐信。
- 出願：一般入试网上登记缴费后把书类以速達書留寄入試課（6/10 必达），检定料 30,000 日元＋手续费 990 日元；IGP(C) 全程网上提交，检定料 30,000 日元（信用卡）。
- 并愿限制：只能报一个系；同一入学期不能报理工学系修士的多个募集，一个出願结果出来之前不能再报理工学系其他募集。
- 咨询：出願手续问入試課大学院入試グループ（inquiries.grad.se@adm.isct.ac.jp）；本系入试内容问電気電子系入試担当（inquiry@ee.eng.isct.ac.jp）。
