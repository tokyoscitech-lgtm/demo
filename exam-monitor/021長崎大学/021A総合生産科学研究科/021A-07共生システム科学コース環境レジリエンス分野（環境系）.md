## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般入试（夏期·冬期）：
  - 不另设英语笔试，用外部成绩换算，英语配点150分，换算后以配点为上限；可用 TOEFL iBT（含 Home Edition，只认 Test Date 成绩）、TOEIC L&R 公开测试、IELTS，TOEIC L&R IP 和 TOEFL ITP 不受理。
  - 须为考试日前3年以内受检；出願时交成绩证明原件（之后返还）或数字版公式认定证打印件，赶不上或想换用新考的成绩须事先向大学院係申请。
- 外国人留学生入试：不交英语成绩；面接中也问英语等能力。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 外国人留学生入试：面接和口述在願書上选日语或英语进行；发表后的面接中也问日语能力。
- 日英以外语言的书类须附日文或英文译文。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 面接·口述試験（250分） | 不考专门科目笔试，内容见口述試験 / 面接 |  |

- 一般入试（夏期·冬期）总分400＝英语换算150＋面接·口述250；按系从总分高者录取，面接成绩极低可不合格。
- 外国人留学生入试：口述70＋面接30。
- 变更点：2027年度入学起改为只考面接·口述，不再考专门科目笔试（令和7年度夏期为科目群A·B）。

### 口述試験 / 面接
- **官方形式**：一般入试（夏期·冬期）：含口述的个人面试（250分），先用7分钟以内发表毕业研究和入学后的研究计划（研究计划须事先与指导予定教员协议，当天带PPT数据U盘和配付资料），之后试问基础知识以及研究的新颖性、独创性、预期成果和社会意义；外国人留学生入试：同样先做7分钟发表，就现在和合格后的研究试问基础学力和专门知识，口述70＋面接30，海外居住者经与指导予定教员商量可能网上考试；推荐入试：5分钟发表＋面接，面接100＋成绩证明100（已结束）。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：一般入试（夏期）11名；推荐入试11名；一般入试（冬期）1名；外国人留学生入试·社会人入试按環境レジリエンス分野若干名；推荐未招满的名额并入夏期。
- 出願资格：大学毕业（含2027/3前预计）或外国16年学校教育等；资格(9)(10)(11)须事先资格审查（夏期 2026/6/19、冬期和留学生入试 10/19 截止，已过，非独立出願）；外国人留学生入试只限无日本国籍（永住者除外）且在外国完成16年教育或取得相当学士学位者，在日本的大学毕业的外国人走一般入试；環境レジリエンス分野在出願时选工学系或環境系，按系分别考试和判定。
- 要提前准备的书类：与指导予定教员协议好的研究计划（面接发表用）；外部英语成绩（一般入试）；指导予定教员的受入内诺证明（外国人留学生入试，邮件复印件等）。
- 出願：书留速达邮寄或窗口（9:00–17:00）提交，期限内必达，另在研究科网站表单登记住所；检定料30,000日元，用 E-支払い 缴纳（英文版只能用信用卡），国费留学生免缴。
