## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 推薦入试、一般入试：不另设英语笔试，用外部 TOEIC 成绩评价，出願时随书类提交成绩复印件；社会人入试、外国人留学生入试不交；2026年10月入学一般入试同样要交。
  - 可用：TOEIC L&R 公开测试的公式认定证复印件（数字认定证 PDF 打印件也可）；对面实施的 TOEIC L&R IP 测试 score report 复印件。在线 IP 成绩不受理。
  - 只认 2024/4/1 以后受验的成绩；考过多次的交最高分一份，受理后不能更换；只收纸质复印件，不接受邮件或 URL 提交，误交原件不退还。
- 下一年度（2028年4月·2027年10月入学）：可用种类相同，只认 2025/4/1 以后受验的成绩；交不出成绩就不能出願。

#### 日本語要件
- 要项没有要求提交日语成绩。外国人留学生入试的面接及口头试问可用日语或英语；授课主要用日语进行。
- 日英以外语言的证明书须附日译或英译。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 建築・デザイン・マネジメント | 3分野各出1题、3题选1，必须选希望研究室所属分野的题：建築計画・デザイン＝建筑计划、城市计划、建筑史及意匠；建築構造＝构造力学、地震工学、建筑构造；マネジメント＝城市管理、社区管理 | 10:00–11:00，60分钟 |

- 一般入试（含10月入学）：外部英语（TOEIC）、笔试、面接及口头试问、成绩证明书综合判定。
- 推薦入试：面接及口头试问、TOEIC、成绩证明书、推荐书；社会人、外国人留学生入试：面接及口头试问＋书类审查。

### 口述試験 / 面接
- **官方形式**：推薦入试：面接及口头试问约20分钟，问毕业研究和入学后的研究计划，不能用电脑和资料（经许可可用黑板）；一般入试（含10月入学）：笔试当天下午面接及口头试问约10分钟，内容同上；社会人入试：约20分钟，问志望动机、研究与技术业绩、研究计划；外国人留学生入试：约20分钟，问志望动机、毕业研究、研究计划，日语或英语。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：12名（2027年4月入学：推薦6名、第1回一般6名，社会人·外国人留学生若干人；推薦缺额并入第1回一般）；2026年10月入学：一般入试3名、外国人留学生入试若干人；第2回一般入试本年度不实施。
- 出願资格：大学毕业（含2027年3月预计，10月入学为2026年9月预计）或外国16年学校教育等；资格⑨–⑫（外国人留学生入试为⑤–⑦）须先受入学资格审查（2026/6/16–6/19 必达，7/1 通知，非独立出願）；推薦入试面向2027年3月预计毕业、学长或学部长推荐并确约入学者，不限本校；外国人留学生入试限非日本国籍、日本的大学毕业（含预计）者不能报；社会人入试须2027/4/1时工作满1年。
- 要提前准备的书类：TOEIC 成绩复印件（推薦·一般）；推荐书（推薦，本校工学部在学生免）；研究计划书（外国人留学生入试，日语约4,000字或英语约1,200 words，格式自由）；研究（希望）计划书1,000字以内、职务经历书、希望指导教员的评价书（社会人）；外国学历的毕业·成绩证明须附日译或英译，复印件须经大使馆等原本证明。
- 出願：书类一并以书留邮寄（期限内必达）或持往山形大学工学部入試担当，窗口 9:00–16:30、周末除外；没有网上出願；检定料 30,000 日元（国費生免），信用卡或便利店缴纳，海外只能用信用卡。
- 并愿：2027年度共通募集要项没有关于跨专攻兼报的规定；推薦入试和社会人入试须确约合格后入学。
- 咨询：山形大学工学部（米沢キャンパス事務部学務課）入試担当，Tel 0238-26-3013，yu-kounyu@jm.kj.yamagata-u.ac.jp。
