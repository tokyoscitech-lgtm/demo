## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 第1期·第2期相同：不另设英语笔试，出願时提交外部英语成绩，按研究科所定换算式计为英语得分（100分）。
- 推荐：TOEIC L&R 公式认定证原件（不收复印件；数字认定证打印带二维码的PDF即可）；TOEFL iBT 须请 ETS 把 Official Score Report 直送本校（代码 0416），出願时附 Test Taker Score Report 打印件并写明直送申请日，考试日前未到按0分；受验超过2年无法直送的可交 Examinee Score Report 原件；本校实施的 TOEIC IP（マークシート版）Score Report 可交复印件。
- 其他可用：IELTS（Test Report Form 须在考试日前直送）、TOEFL ITP 原件、TOEIC IP マークシート版原件。
- 不受理：英検、TOEIC S&W、TOEIC Bridge、TOEFL iBT Home Edition、TOEIC IP オンライン版（含本校2020年实施的在线版）、TOEFL ITP デジタル版。
- 只认 2021/4/1 以后受验的成绩原件；可交多份，取换算后最高分；成绩不退还。

#### 日本語要件
- 外国人须在出願时（及资格审查时）提交日本語能力試験（JLPT）N2 以上（CEFR B2 以上）的合格证明书，限2010年以后受验。
- 专门科目为日语论述题（据サンプル問題）。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 英語（100分） | 用外部英语成绩换算，不另行考试 |  |
| 専門科目（100分） | 志望分野的看护学专门知识；サンプル問題每分野1–2题、均为日语论述 | 9:05–10:05，60分钟 |

- 英语100＋专门科目100＋面试100＝300分，结合出願书类综合判定；面试评价低于一定水准的可能不合格。第1期·第2期选拔方法相同。
- サンプル問題（2025年版）示例：看護生命科学考转化研究，がん看護学考癌痛与终末期居家支援，小児看護学考儿童权利与治疗决策支援，クリティカルケア・周麻酔期考手术室·ICU·病房协作，地域看護学考 Community as Partner 模型。

### 口述試験 / 面接
- **官方形式**：第1期·第2期：面试100分，专门科目之后 10:40（预定）开始，考查作为高度看护实践者和实践现场教育指导者的资质与适性；学内推薦（仅本校学生）：书类审查＋口述试验。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：25名（看護学分野〔周麻酔期·助产以外11分野合计〕17名、クリティカルケア・周麻酔期看護学 5名左右、助産学 3名）；第2期若干名（助产学分野不招生）；另有本校学生学内推薦若干名。
- 出願资格：大学毕业（含2027/3/31前预计）或外国16年学校教育等；资格“ク”（个别资格审查，满22岁，如看护系短大·专修学校毕业者）须先申请审查，第2期 2026/10/28（周三）–11/4（周三）必达（非独立出願，已截止），结果 12/4 前寄到；クリティカルケア・周麻酔期看護学须持看护师执照并满足修了后在神奈川县内或本校相关医院、或所属机构推荐回馈之一；助産学须持看护师执照（可预计）、能专心学业、限女性，可能追加合格；第2期外国籍考生须持在留期限到 2027/3/31 以后的日本在留资格（短期滞在除外）。
- 要提前准备的书类：外部英语成绩原件（TOEFL iBT·IELTS 须提前安排直送）、JLPT N2 以上合格证明书（外国人）、在留卡正反面复印件（外国人）、志望理由书（本校样式含研究课题，A4 1页）、看护师等执照复印件（持有者）、他大学院在读者的受验许可书；中国大学毕业者另交学位证书复印件，并安排 CHSI 英文学历·学位认证报告在出願期内邮件直送 ycugradkng@yokohama-cu.ac.jp；非日英文证明须附公证日语译文。
- 出願：只收邮寄，角2信封贴本校出願书类送付用标签，速达簡易書留寄到福浦キャンパス医学教育推進課 学務・教務担当（看護学専攻），邮戳有效；書類不全不能受验；检定料 30,000 日元在便利店终端缴纳。
- 并愿：学内推薦只限本校学生；2027年度要项没有说明第1期合格或不合格者能否再报第2期。
- 咨询：医学教育推進課 学務・教務担当（看護学専攻，〒236-0004 横浜市金沢区福浦3-9），Tel 045-787-2532（平日 9:00–17:00），ycugradkng@yokohama-cu.ac.jp。
