## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般選抜：
  - 出願时提交 TOEIC 公開テスト（仅 Listening & Reading）或 TOEFL-iBT（Home Edition 可）的成绩单原件，二选一；TOEIC 数字公式认定证的打印件视为原件，2026年春以后受检的 TOEFL 从 ETS 账户下载 PDF 打印提交。
  - 成绩限 2024年7月以后受检。TOEFL-ITP、TOEIC-IP、TOEIC Bridge 不受理（TOEFL-ITP 只有数学専攻可用，不适用于本専攻）。
  - 出願期间结束后不能追加或替换成绩单。
  - 在大学（院）接受过英语授课教育、能由大学出具证明的，可申请免交，须事先向大学院教育担当咨询。
  - 要项没有写英语的配点、换算方法和最低分；不另设英语笔试，用外部成绩评价。
- 外国人留学生特別選抜：提交日语或英语能力证明之一；难以取得时，可用能看出日语或英语成绩的出身学校成绩证明书代替。
- 冬期募集：要项未公布。参考上一年度冬期，同年度夏期·秋期已交过成绩单的人可以申请免交。

#### 日本語要件
- 一般選抜的要项没有要求提交日语成绩（JLPT、EJU 都没有规定）；专门科目试题和口头试问的语言要项没有写明。
- 外国人留学生特別選抜：日语或英语能力证明二选一即可，没有规定 JLPT 等级或分数。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 専門科目·午前（配点官方未公布，150分钟） | 物理学，要项只写科目名；与宇宙理学専攻共用试题（力学、电磁学） | 2027夏期募集要项 |
| 専門科目·午後（配点官方未公布，150分钟） | 物理学（量子力学、热·统计力学等），与宇宙理学専攻共用 | 2027夏期募集要项 |
| 外国人留学生特別選抜 | 没有笔试，只有口头试问 | 2027夏期募集要项 |
| 秋期·冬期募集（参考上一年度秋期） | 没有笔试，只有口头试问 | 2026年度秋期募集要项 |

- 合否判定：综合学科试验（笔试、口头试问）与成绩证明书等出願书类判定；各部分配点、总分、合格线官方都没有公布。
- 与宇宙理学専攻并愿的，笔试答“専門科目（物理学）”。
- 题目倾向（非官方解答网站对2023年度试题的整理，非官方）：共4个大题——解析力学、电磁学、量子力学、热·统计力学。

### 口述試験 / 面接
- **官方形式**：夏期募集一般選抜在笔试次日进行口头试问，集合时间按受験票通知，内容、时长、配点要项没有写；外国人留学生特別選抜只考口头试问，赴日前的考生可能用 Web 会议系统进行；冬期募集未公布（上一年度秋期募集本専攻只考口头试问，在札幌校区面对面进行）。
- **実際に聞かれた内容**：没有找到本専攻考生公开的体验记，实际问题不明。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：夏期募集一般選抜 2027年4月入学 24 名、2026年10月入学 若干名；夏期募集外国人留学生特別選抜 若干名；秋期募集本年度未实施（上一年度为若干名）；冬期募集未公布。
- 出願资格：大学毕业或 2027年3月前预计毕业、学士学位取得（见込）、在外国完成16年学校教育等（1）–（10）项之一；（9）（在学3年以上成绩优秀等）和（10）（个别审查，入学前满22岁）须先通过出願资格预备审查。
- 外国人留学生特別選抜的对象是没有日本国籍、也没有日本永住许可的人，须由接收教员推荐；不能与一般選抜并愿。
- 本専攻可与宇宙理学専攻并愿：入学願書的志望専攻栏写两个専攻，并分别提交两个専攻的志望研究室調査票。
- 一般選抜：
  - 出願书类：入学願書·履歴書·受験票·写真票（所定用纸，外国学校出身者加履歴書B）、学业成绩证明书、毕业（见込）或学位授予（见込）证明书、英语成绩单原件、志望研究室調査票、受験票寄送用信封（贴480日元邮票）、合否通知用地址贴纸；中国的大学出身者另交学信网的学历·学位认证报告（英文）。出身大学推荐书资格（9）必须交，其余资格可任意提交。
  - 志望研究室調査票：从要项的“指導教員及び研究内容一覧表”里最多填到第3志望，写到グループ名；要项没有要求研究计划书或志望理由书。出願后不能变更志望。
  - 出願方式：只收邮寄，速達書留，信封红字写“大学院入学願書在中”，受理期内必达。国内出願须用纸质要项所附用纸（理学部2号館1階大学院教育担当前免费领取，或用申请表单邮寄索取，不寄往国外）。
  - 检定料 30,000 日元，用要项所附汇款单在银行·邮局缴纳，受付证明书贴在願書上。
- 外国人留学生特別選抜：
  - 先取得接收教员的内诺并领取网上出願用密码；网上登录、缴检定料、邮寄书类都在期限内完成才算出願，登录后另把願書 PDF 发邮件到 r-gakuin@sci.hokudai.ac.jp。
  - 书类另含照片1张（4cm×3cm）、护照姓名页复印件和接收教员要求的材料；推荐书由接收教员直接交给大学院教育担当。
  - 检定料 30,000 日元，可用信用卡、Pay-easy、便利店、银联等支付，另付约500日元手续费。
- 国费外国人留学生、中国政府国家公派研究生免缴检定料。
- 外国人考生取得“留学”在留资格所需的在留资格认定证明书可能要3个月以上。
- 入学料 282,000 日元，授業料 年 535,800 日元（前期 267,900 日元），均为预定额。修士课程可申请长期履修（4年以内）。
- 考试当天必须带受験票；需要受验照顾的在出願前向大学院教育担当申请。
- 研究生（非正规生）是另一条路线，理学研究院每年约5月和11月公布研究生出願要项；这不是修士入试的要求。
- 咨询：北海道大学 理学·生命科学事務部事務課 大学院教育担当（〒060-0810 札幌市北区北10条西8丁目），Tel 011-706-3675，r-gakuin@sci.hokudai.ac.jp，平日 8:30–12:15、13:00–17:00；専攻事务 phys-office@phys.sci.hokudai.ac.jp。
