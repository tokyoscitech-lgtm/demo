## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 推薦入试、一般入试：不另设英语笔试，用外部 TOEIC 成绩评价，出願时随书类提交成绩复印件；社会人入试、外国人留学生入试、国費留学生推薦入试不交。
  - 可用：TOEIC L&R 公开测试的公式认定证复印件（数字认定证 PDF 打印件也可）；对面实施的 TOEIC L&R IP 测试 score report 复印件。在线 IP 成绩不受理。
  - 只认 2024/4/1 以后受验的成绩；考过多次的交最高分一份，受理后不能更换；只收纸质复印件，不接受邮件或 URL 提交，误交原件不退还。
- 下一年度（2028年4月·2027年10月入学）：可用种类相同，只认 2025/4/1 以后受验的成绩；交不出成绩就不能出願。

#### 日本語要件
- 要项没有要求提交日语成绩。外国人留学生入试的面接及口头试问可用日语或英语；授课主要用日语进行。
- 日英以外语言的证明书须附日译或英译。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 口述：化学工学及び物理化学 | 化学工学量论、移动现象、反应工学、化学热力学基础、气液固的性质结构与状态变化、反应速度论；3分野选2 | 13:30起，每人约20分钟 |
| 口述：無機化学及び有機化学 | 原子结构与元素周期性、酸碱与氧化还原、过渡金属配合物、无机固体基础、有机化合物命名、结构与物性、反应机理、合成反应；3分野选2 | 13:30起，每人约20分钟 |
| 口述：バイオ化学 | 细胞结构与功能、代谢与能量产生、细胞间相互作用、膜结构与功能、生物分子结构与功能；3分野选2 | 13:30起，每人约20分钟 |

- 第1回一般入试：外部英语（TOEIC）、专门科目口述试验、面接及口头试问、成绩证明书综合判定。
- 推薦入试：面接及口头试问、TOEIC、成绩证明书、推荐书综合判定；社会人、外国人留学生入试：面接及口头试问＋书类审查；国費留学生推薦入试：成绩证明书和推荐书等书类审查。
- 令和4–7年度的笔试过去问可用来把握三个分野的出题范围。

### 口述試験 / 面接
- **官方形式**：推薦入试：面接及口头试问约20分钟，问毕业研究和入学后的研究计划，不能用电脑和资料（经许可可用黑板）；第1回一般入试：专门科目口述约20分钟（3分野选2）＋次日面接及口头试问约10分钟（毕业研究、研究计划）；社会人入试：约20分钟，问志望动机、研究与技术业绩、研究计划；外国人留学生入试：约20分钟，问志望动机、毕业研究、研究计划，日语或英语。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：67名（2027年4月入学：推薦33名、第1回一般34名，社会人·外国人留学生若干人；推薦缺额并入第1回一般）；2026年10月入学：外国人留学生入试若干人、国費留学生推薦入试若干人；第2回一般入试本年度不实施。
- 出願资格：大学毕业（含2027年3月预计）或外国16年学校教育等；资格⑨–⑫（外国人留学生入试为⑤–⑦）须先受入学资格审查（第1回 2026/6/16–6/19 必达，7/1 通知，非独立出願）；推薦入试面向2027年3月预计毕业、学长或学部长推荐并确约入学者，不限本校；外国人留学生入试限非日本国籍、日本的大学毕业（含预计）者不能报；国費留学生推薦入试限已决定2026年10月起2年领取国費（大学推薦·特別枠）奖学金者；社会人入试须2027/4/1时工作满1年。
