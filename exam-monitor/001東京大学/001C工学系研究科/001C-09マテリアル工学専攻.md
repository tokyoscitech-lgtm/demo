## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 夏入试：须提交 TOEFL iBT（含 Home Edition）或 TOEIC L&R 公开考试的官方成绩，二选一。选哪一种在出願时决定，之后不能更改。専攻不另设英语笔试。
- 有效期：受检日在 2024年9月以后的成绩有效。
- 提交截止：2026/8/7（周五）（已截止）。
- TOEFL 的提交要同时完成三件事：通过 ETS 把官方成绩送到研究科（DI 代码 8596，Department 代码 99）；在 WEB 出願系统登记 Appointment Number 和受检日；上传 Test Taker Score Report 的 PDF。只采用 Test Date Scores，不采用 MyBest Scores；TOEFL ITP 等团体考试不受理。母语是英语的人也要提交。
- TOEIC 只收 L&R 公开考试；TOEIC IP、Bridge、S&W 不受理。在 WEB 出願系统登记数字官方认定证的 URL。所在国家或地区不发行数字认定证的，要把认定证扫描成 PDF 发到 exam@material.t.u-tokyo.ac.jp，并把原件（复印件不行）寄到専攻事务室，8/7 邮戳有效，信封上用红字写「大学院入試関係書類」。
- 换算：成绩按専攻入试案内的换算表折成得分率（两点之间线性插值，超出范围取端点）。TOEFL：0 分＝0%、48 分＝45%、95 分＝90%、105 分以上＝100%。TOEIC L&R：10 分＝0%、650 分＝45%、990 分＝90%（TOEIC 最高只能到 90%）。例如 TOEFL 80 分约 76%，TOEIC 820 分约 68%。
- 官方没有设最低分数线。
- 研究科共通表里其他専攻收的 IELTS 不适用于本専攻。

### 日本語要件
- 要项和専攻入试案内都没有要求提交日语成绩（JLPT 等）。
- 试题同时有日文和英文两种（専攻 FAQ）。作答语言官方资料里没有写明。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 一般教育科目（配点官方未公布；数学 150 分钟，物理学 120 分钟，化学 120 分钟） | 出願时从数学、物理学、化学里选 1 科。数学：微积分与微分方程、级数·傅里叶分析·积分变换、线性代数、曲线曲面、复变函数、概率统计等，6 题选 3 题。物理学：力学、电磁学，2 题全答。化学：物理化学、无机化学、有机化学，3 题全答 | 2027専攻入试案内／2027募集要项别纸 |
| マテリアル工学基礎（配点官方未公布，120 分钟） | 4 个领域各 1 题，共 4 题选 2 题：①热力学·速度论（材料プロセス）②组织学（化学·晶体学·微观组织）③材料物性学（固体物理·量子力学）④材料力学（弹性论·强度学） | 2027専攻入试案内 |

- 判定方法：按外国语（英语成绩换算）、笔试、口述和提交书类综合评价。各科配点、总分、合格最低分官方都没有公布。成绩达不到要求时，即使未满募集人员也可能不录取。
- 所有考生考同样的科目，没有按志望研究室区分的科目。博士后期课程的笔试用同一份マテリアル工学基礎试题。
- 过去问的变化：2020年度以前，専门科目是化学 3 题＋材料 5 题的旧形式；2021年度起改成现在的 4 领域 4 题。练习时以 2021年度以后的题为主。
- 题目倾向（体验记，非官方，仅1人提及）：配点传闻是英语 150、一般教育 150、専門 300，口述不明；作者估计笔试拿到 7–8 成比较稳。数学选前 3 题的做法可行；物理 2 题据说能拿 7–8 成。マテリアル工学基礎要用考场发的函数计算器，不顺手，容易耽误时间。

### 口述試験 / 面接
- **官方形式**：夏入试有口述考试，2026/9/4（周五）9:00–15:00 在本郷キャンパス进行。具体内容和个人的集合时间、地点在交付受験票时及考前用邮件通知（本年度为 8/28 通知）。配点、时长、使用语言官方没有公布。
- **実際に聞かれた内容**：体验记，非官方，仅1人提及（2024年8月受验的内部生）：内部生大约 2 分钟，外部生大约 4 分钟；作者被问的是笔试考得怎么样这类简单问题。外部生被问到的具体内容没有找到公开的体验记。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：修士课程 45 名（夏入试）。本年度没有冬入试。
- 出願资格：日本的大学毕业或 2027/3/31 前预计毕业；在外国完成 16 年学校教育；在外国取得相当于学士的学位（3 年以上课程，学校须受过该国政府或有关机构的评价）；文部科学大臣指定者；学位授与机构授予学士者；经个别入学资格审查认定且 2027/3/31 时满 22 岁者。希望 2026年10月入学的，上述日期换成 2026/9/30。
- 10月入学：本専攻可以申请 2026年10月入学，须在出願时申报（専攻 FAQ）。需要新申请在留资格的外国籍考生，研究科建议考虑 4月入学，因为办理要 2–3 个月。
- 个别入学资格审查（资格6）的书类提交截止：2026/4/21（周二）（已截止）。
- 志望教员：在 WEB 出願系统里选第1、第2、第3志望教员，可修改到 2026/8/28（周五）17:00（日本时间）。配属时优先看本人志望，同时参考考试成绩名次；各教员名额有限，志望不一定能满足。
- 研究室配属流程（本年度，均已结束）：第1次配属结果 2026/9/10 16:00 左右在専攻网站发表；没有配上的人参加 9/16（周三）16:00 起的线上第2次配属，不参加原则上视为放弃；第2次配属结果 9/18 17:00 左右发表。
- 出願书类：入学願書（WEB 出願系统填写）、证件照数据、检定料缴纳证明、毕业证明书（已毕业者）、成绩证明书、国费留学生证明（该当者）、安全保障輸出管理チェックシート（外国籍、双重国籍、入学前所属机构在海外的人）。全部转成 PDF 上传。日文、英文以外的证明要附原件和出身大学盖章的英译。本専攻修士没有另外要求志望理由书或研究计划书；英语成绩按上面的方法另行提交。
- 出願方式：只能通过 WEB 出願系统，没有邮寄或窗口出願。书类不齐不受理，出願后不能更改。
- 检定料：30,000 日元，可用便利店、Pay-easy、网银、中国结算或信用卡支付，手续费自付；国费留学生免缴。缴纳后不退。
- 并愿限制：不能同时报工学系研究科的两个以上専攻或课程。
- 受験票：2026/7/3（周五）15:00 左右通过 WEB 出願系统交付，自己打印带到考场。考场于 2026/8/28 前在研究科和専攻网站公布（一般教育科目在工学部4号館41–44講義室）。
- 安全保障出口管理：外国人留学生和一部分日本学生入学前必须受审查。属于外汇法管制事项的，即使最终合格也可能不能入学，或研究活动受限制。合格后换指导教员要重新审查，10月入学的人可能因此推迟到 2027年4月入学。
- 入学料 282,000 日元，授業料 年 535,800 日元（前期 267,900 日元），均为预定额；国费留学生免缴。入学手续：10月入学者 2026/9/18 前，4月入学者 2027/3/9 前（均为预定）。
- 考场规则：带受験票、黑色铅笔或自动铅笔、橡皮、卷笔刀（不能用桌上型）、只有计时功能的手表；不能用圆珠笔。マテリアル工学基礎还要自带尺子（考场不借）。函数计算器由考场提供，不能用自己的。开考前 20 分钟入场，开考后 30 分钟内可以入场；一般教育科目考试中途不能离场。答题纸和试题册不能带走。
- 在职社会人可以报考，入学手续时提交单位的同意书（格式自定）。
- 咨询：募集要项的问题通过研究科网站的咨询表单提交（工学系研究科学務課大学院チーム，〒113-8656 東京都文京区本郷7-3-1）。専攻的问题找マテリアル工学専攻事務室，Tel 03-5841-7091，exam@material.t.u-tokyo.ac.jp。合否不接受电话、邮件查询。
- 成绩开示：要项和専攻入试案内里没有记载。
