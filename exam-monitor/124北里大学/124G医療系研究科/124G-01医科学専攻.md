## 🎯 入試内容（考什么）

### 語学 / 英語要件

- 普通一般、社会人、外国人实施学内英語笔试，120分钟100点；可选择申请外部成绩免试，临床心理一般不可免试。一般考生不必提交外部成绩，具体类型与标准见下表。

| 路线／项目 | 类型与要求 | 范围及注意 |
|---|---|---|
| 普通一般・社会人・外国人 | 校内TOEIC L&R IP，120分钟100点；9:00集合、9:30–11:30，另书类100点 | 不是医学论文翻译考试；按规定申请外部成绩或母语条件免试者另行审核 |
| 可选外部英语免试 | TOEIC L&R850以上、TOEFL iBT80以上、英检准1级以上、IELTS6.0以上、Cambridge FCE以上 | 取得日至入试日不超过5年，申请时附结果复印件；不是所有申请者必须提交的材料 |
| 外部免试表口径 | 官方表列“现行／改正案”表头但分数仅一套 | 是否获准由研究科审核；免英语后仍审研究计划等 |
| 英语母语或同等水平外国人 | 可能申请英语免试，提前邮件i-gakusei@kitasato-u.ac.jp咨询 | 由研究科个别确认，不自行判定获准 |
| 临床心理一般 | 校内TOEIC L&R IP，120分钟100点 | 不适用外部成绩免试制度 |
| 普通推荐／临床心理推荐 | 没有英语笔试 | 临心推荐另考心理学，非免全部考试 |
| 2027变更预告：修士推荐 | 不实施面接，追加研究计划 | 2025/11/28官方预告，本年度最终以2027正式要项为准 |
| 2027变更预告：博士推荐 | 改交TOEIC L&R公开测试Official Score Certificate复印件，不收IP，当日不考英语 | 明确仅博士推荐，不能套给本修士一般／社会人／外国人 |
| 旧攻略与年度比较 | 旧网文“英语医学论文读解”与2027正式TOEIC规定不符；尚未另取2026一般要项逐项比对 | 不用于本年度准备，也不据此断言TOEIC IP开始年度 |

2027变更预告原文：[2025/11/28官方PDF](https://www.kitasato-u.ac.jp/jp/kugsms/news-all/mt_img/2026_entrance%20examination.pdf)。

### 日本語要件

- 2027外国人要项未要求提交JLPT/EJU成绩或指定等级；书类可日语或英语填写，成绩证明要求英文，非日英证明须认证译文。未据此推断可全英语修课或无需日语。

## 📝 详细信息

### 出願資格 / 定員

- 資格審査：资格(11)Ⅰ期7/21–31；Ⅱ期10/26–11/6必达；(9)(10)(12)须出願开始3周前联系。


- 普通一般50名（含医学物理士养成）；临心一般若干；社会人、外国人、两类推荐各若干。医科学是研究科唯一修士専攻；收容100是两年在籍规模，不是今年考试50的重复定员。
- 普通一般为大学毕业/预计2027年3月毕业、外国16年教育/认可3年以上学士课程等。个别审查(11)年满22并有相当学力，2年短大/专门毕业通常研究历3年、3年毕业通常2年；细节由入试係审查。资格(9)(10)(12)最迟出願开始3周前咨询。
- 外国人须无日本国籍且符合外国16年教育或认可3年以上学士学历等并获导师认可。社会人入学后须保有本务单位身份及所属长推荐。当前FAQ的北里大学病院职员额外研修手续明确写“医学専攻博士課程社会人枠”，不能据此直接要求医科学修士也走同一手续；修士在职者按本年度修士社会人要项核实所属长承诺。
- 推荐限北里四年制学部/学科2027年3月预计毕业或2026年3月毕业者，3年次前/在学成绩前50%，事前面接获推荐，专愿不得併愿。7/10是制度考试日，普通推荐仅书类与事前面接，不意味着当天所有人参加面试。
- 普通申请资料：导师签章愿书、履历、名票/费用票/受验票、健康自报、志望理由、与导师共同商定的研究计划、严封成绩、毕业证明、4×3cm照片2张、30,000检定料、成绩开示同意确认书、邮寄者回邮信封；社会人加单位受验承诺/推荐，外国人加英文成绩、经费支付银行/奖学金原件、在留/护照/签证等。推荐另学部导师严封推荐与自己推荐书。
- 费用银行汇款或校内券卖机证纸；简易书留速达寄送截止必达，或窗口递交。〒252-0373相模原市南区北里1-15-1 M5号馆4楼入试係，042-778-9557；平日9–11/13–16。
- 2027学费普通：入学金200,000+年授业745,000+设施100,000，首年1,045,000（前期622,500/后期422,500），次年845,000，两年1,890,000。临心首年1,210,000、次年1,010,000，两年2,220,000；北里毕业/预计毕业免入学金。长期履修可3年按2年学费，另定缴费规则。
- 个人成绩开示：仅不合格者本人或获同意的志望导师，英语/心理学按10分档；合格发表日至手续截止日17:00申请，窗口出示身份证，邮寄附身份复印及含特定记录邮费的回邮信封。
