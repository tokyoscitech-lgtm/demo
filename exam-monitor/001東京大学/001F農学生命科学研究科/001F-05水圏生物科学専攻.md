## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各日程相同：不另设英语笔试，用 TOEFL iBT（含 Home Edition）成绩评价；所属团体实施的 ITP 不受理，MyBest Scores 不采用。
- 在有效期间内受检，并在同期间内向 ETS 申请把 Institutional (Official) Score Report 送到研究科（DI code 1113，其他代码无效）；出願时在 WEB 系统填写 Appointment Number、受检日和分数，不必交 Test Taker Score Report。送过多份的只指定其中一次。
- 有效期间：A日程 2024/8/1–2026/6/13；B日程 2025/2/1–2026/11/15（均已过）。

#### 日本語要件
- 要项没有要求提交日语成绩。
- A日程専門科目用日语出题、日语作答；B日程用英语出题、英语作答。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|

### 口述試験 / 面接
- **官方形式**：A日程对面进行；B日程线上进行。
- **実際に聞かれた内容**：
  - 约15名教员面试，每人5–10分钟（2023年8月、2025年，各1人提到）。
  - 先说明本科研究和修士阶段想做的研究，再问答（2025年，1人提到）。
  - 问选择本専攻的理由、本科研究内容、为什么外部报考（2023年8月，1人提到）。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：30名（A日程，2027年4月入学）；B日程若干名（2027年4月入学）；本専攻不实施10月入学。
- 出願资格：大学毕业（含2027/3/31前预计）或外国16年学校教育等；个别入学资格审查 A日程 2026/5/7、B日程 2026/10/7 截止（非独立出願，已过）；同一日程只能报研究科一个専攻；本専攻同一年度只能考一次，受验过A日程的不能报B日程；志望最多填到第3志望，可填同一分野的其他教员；専門科目2科出願时选定。
- 要提前准备的书类：TOEFL iBT 送分；日英以外的证明书附日译或英译。
- 出願：只能通过 WEB 出願系统上传 PDF；检定料 30,000 日元（银行汇款〔邮储除外〕、便利店、信用卡、Pay-easy），日本政府奖学金留学生免缴。
- 并愿：同一日程只能报研究科的一个専攻；本専攻同一年度只能报一次，报了 A日程就不能再报 B日程。
- 咨询：専攻事务找第1志望教员或専攻主任濵﨑 恒二 教授（Tel 04-7136-6171，hamasaki@g.ecc.u-tokyo.ac.jp）；出願手续问农学生命科学研究科教務課学生支援チーム大学院学生担当（〒113-8657 東京都文京区弥生1-1-1，Tel 03-5841-5010，daigakuin.a@gs.mail.u-tokyo.ac.jp）。
