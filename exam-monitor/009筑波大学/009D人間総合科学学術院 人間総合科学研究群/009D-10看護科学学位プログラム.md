## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 7月实施和8月实施相同：「外国語」100分，不另设英语笔试，用出願时提交的外部成绩评价；英语成绩是全员必交书类，期限内没交齐的不受理出願或按缺考处理。
- 收 TOEIC L&R、TOEFL iBT（含 Home Edition）、IELTS Academic；不受理 TOEIC IP、TOEFL ITP、IELTS General、IELTS Academic 线上版、IELTS One Skill Retake。
- 受检时期：7月实施须2024年6月以后，8月实施须2024年7月以后，1-2月实施须2025年1月以后。
- 提交方式：TOEIC 在 Web 出願系统填デジタル公式認定証 URL 并打印随书类提交（在不发行数字证书的国家受检才交纸质原件）；TOEFL 交 Test Taker Score Report 原件，没有纸质版的让 ETS 直送 Official Score Report（DI 代码 9995，Department 代码 99）并交 PDF 打印件；IELTS 把 Additional TRF 数据直送筑波大学并交 Test Report Form 复印件。直送数据可能要几周。
- 要项没有写看護科学的换算方法和最低分（TOEIC 850／TOEFL 96／IELTS 6.5 按满分的规定只写在フロンティア医科学下，不适用于本プログラム）。
- 变更点：2026年度以前由プログラム自己出题考英语（100分），2027年度起改为评价外部成绩。

#### 日本語要件
- 要项没有要求提交 JLPT、EJU 等日语成绩，也没有外国人留学生的另设选拔；留学生与日本学生走同样的推薦、一般、社会人区分。
- 小論文、研究計画書只给了日文字数；口述試験的语言要项没有写。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 外国語（100分，不设考试时间） | 按提交的 TOEIC L&R／TOEFL iBT／IELTS Academic 成绩评分 | 2027募集要项 |
| 口述試験（200分） | 个别面接，就看護学的专门知识和本人志望等试问 | 2027募集要项 |
| 1-2月实施 | 科目和配点未公布，以11月要项为准 | 2027募集要项 |

- 7月实施和8月实施总分都是 300 分：外国語 100＋口述試験 200；推薦、一般、社会人三区分的科目配点相同，区别在出願条件和文书。综合书类和考试结果判定，没有公布合格最低分。
- 出願时在 Web 表单里写的文书作为面接材料：推薦入学試験和一般入学試験写「小論文」约1,200字；社会人特別選抜写「研究計画書」约800字（志望理由和入学后的研究计划）。
- 变更点：専門科目（看護学基础课题，100分）和社会人的小論文笔试本年度起废止。
- 题目倾向（体验记，非官方）：没有找到本プログラム的考生体验记，新制度也是第一年。

### 口述試験 / 面接
- **官方形式**：7月实施（推薦入学試験）2026/7/3、8月实施（一般入学試験·社会人特別選抜）2026/8/24，都是个别面接，200分（上一年度 100分），问看護学的专门知识和本人志望等，10:00–17:00 之间个别进行；时长、语言、是否要发表要项没有写；1-2月实施未公布。
- **実際に聞かれた内容**：没有找到本プログラム的面接体验记。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：7月实施（推薦入学試験）10名；8月实施 一般入学試験 5名、社会人特別選抜 若干名（说明会资料写明包含在5名内）；1-2月实施 是否实施及人数未公布。合计入学定员15名，2027年4月入学。
- 变更点：上一年度一般入学試験（含社会人）15名全部在8月实施；本年度拆为推薦10名＋一般5名。
- 出願资格（各区分共通）：日本的四年制大学毕业或预计毕业、大学改革支援·学位授与機構授予学士学位、在外国完成16年学校教育、在外国3年以上课程取得相当于学士的学位、经个别出願资格审查认定且满22岁等。要项没有要求看護師免許或看護系大学毕业。
- 推薦入学試験：已修学分中 A（優）以上占70%以上，或在看護科学特定领域特别优秀；保证合格后入学；交本人填写的「推薦要件確認書」（规定样式），不要求教员推荐信。
- 社会人特別選抜：到入学前一个月有2年以上社会经验（常勤、非常勤、家务劳动都算，学生身份的打工不算）；联系指导教员时要说明报社会人名额。
- 个别出願资格审查截止：7月实施 2026/5/20（已截止）；8月实施 2026/7/3（已截止）；1-2月实施 2026/11/24（周二）。要交出願者調書、学歴·研究歴·職歴調書、毕业证明书、成绩证明书等。
- 志望指导教员：Web 出願系统选第1志望，第2志望可不填；都要事先取得承诺。
- 出願书类：授予学士学位的大学出具的毕业（预计）证明书和成绩证明书原件、外国大学毕业者的学位取得证明书、外部英语成绩单（全员）、推薦要件確認書（仅推薦）、在学或在职者的受験·就学承認書、检定料收纳证明或信用卡支付画面打印件、国费留学生证明书（符合者）。
- 出願方式：Web 出願系统录入信息、上传证件照、选指导教员、填写みなし輸出确认事项、支付检定料后提交；打印受験票、收件人标签、英語スコア票貼付台紙、书类提出明细票，书类邮寄（必达）或送到医学医療エリア支援室。
- 检定料 30,000 日元（信用卡或便利店，缴纳后不退）。入学料 282,000 日元；授業料年额 535,800 日元，外国人留学生（「留学」在留资格）年额 608,800 日元。
- 在职者可申请長期履修（3年或4年），入学手续期间申请，须取得プログラムリーダー和指导教员同意。
- 咨询：出願手续找医学医療エリア支援室大学院教務（medgra-nyushi@un.tsukuba.ac.jp，Tel 029-853-3013／029-853-5668，平日 9:00–12:15、13:15–17:00）；プログラム内容和教员联系找看護科学事務室（kanngojimu@md.tsukuba.ac.jp，Tel·Fax 029-853-3403）。
