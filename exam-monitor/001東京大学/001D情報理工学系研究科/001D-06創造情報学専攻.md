## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各轮次相同：不另设英语笔试，用 TOEFL iBT 成绩评价；修士出願者全员提交，英语母语者也要交。
- 只收 TOEFL iBT（含 Home Edition）由 ETS 直送的 Official Score Report；MyBest scores 不采用，Test Taker Score Report 不受理，其他考试不能代替；夏入试交过的同一成绩报冬入试也要重新送分。
- 送分代码：University of Tokyo IS&T，Institution Code 8445，Division 选 Graduate Organization，Department Code 99；出願时填 Appointment Number 和受检日，出願后原则上不能更换；送分后约两周研究科才能收到。
- 有效期与到达期限：夏入试受检日 2024/9/1 以后、成绩 2026/6/30 前到达；冬入试受检日 2025/3/1 以后、成绩 2026/12/8 前到达。成绩无效的失去笔试和口述的受験资格。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 笔试有英文版试题，専攻另有英文版入试案内书；研究科自 2026年4月起大部分课程用英语授课。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 一般教育科目：プログラミング实技 | 自带笔记本电脑，按题目当场写程序，语言自选；可用电脑里已有的文档、源代码和软件，禁止联网和 LLM、Copilot 等基础模型；须能用 USB Type-A，可带鼠标，每人1个电源插座（无接地）；午后另有约5分钟针对实技的面接 | 10:00–12:30，150分钟 |
| 一般教育科目：数学（仅夏入试，与プログラミング二选一） | 线性代数、解析（微积分、常微分方程等）、概率·统计各1题；全研究科共通 | 13:00–15:30，150分钟 |
| 専門科目「創造情報学」 | 软件与算法、计算机硬件、信息系统等，共3题 | 13:00–15:30，150分钟 |

- 夏入试専門科目出願时从創造情報学／コンピュータ科学／数理情報学／システム情報学四选一，选其他専攻科目的按该専攻案内书；冬入试一般教育科目只有プログラミング，専門只能选「創造情報学」。缺考任一科目视为放弃受験。
- 选拔流程：书类选考 → 一般教育科目、専門科目与 TOEFL → 口述，综合判定。
- 变更点：2028年度入试（2027年夏实施）起，夏入试専門科目改为創造情報学／コンピュータ科学／数理情報学三选一，不能再选システム情報学（研究科 2026/7/16 予告）；2027年度已比上年少了「電子情報学」。
- 题目倾向（体验记，非官方）：「創造情報学」前两题为大题（逻辑电路、网络、数学等，领域每年变），第3题从8个术语中选4个解释（2025年1月、8月，2人提到）；プログラミング用U盘分发输入数据、提交计算结果和代码，题目分多个小问（2025年1月、8月，2人提到）。

### 口述試験 / 面接
- **官方形式**：夏入试 2026/8/27、冬入试 2027/2/1 都在工学部6号館（预定）现场口述，起止时刻按人数定、当天在网站公布，就笔试内容、现在的研究题目、入学后的研究题目等提问；各轮次另有约5分钟针对プログラミング实技答题的面接（夏入试选数学者没有）。
- 变更点：2026年度夏冬两轮口述都在线上进行，2027年度起改为本郷现场。
- **実際に聞かれた内容**（均为线上实施时的经历）：
  - 约10分钟，先用1–2张幻灯片或约2分钟介绍本科研究和修士研究计划，再细问研究计划的难点、与既有方法相比的优劣、应用场景（2025年8月，2人提到；1人写用日语、考官2人加主持）。
  - 冬入试不到8分钟：自我介绍后第一志望教员问毕业设计、为何选日本和该研究室、会不会编程（2025年1月，1人提到）。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：38名（夏入试，另可能从本研究科其他専攻合格者中转入若干名）。
- 出願资格：大学毕业或外国16年学校教育等，冬入试毕业基准日按 2027/9/30 顺延；个别入学资格审查截止 夏入试 2026/5/13、冬入试 2026/10/26（均已过，非独立出願）；同一期只能报研究科内一个専攻，夏入试合格不放弃入学就不能报冬入试；标准入学期 夏入试 2027年4月、冬入试 2027年10月，希望者可早期入学，需新办在留资格的外国籍考生官方强烈推荐标准时期；志望教员在出願系统最多填10名。
- 要提前准备的书类：研究计划书（合成1个PDF共2页：第1页志望分野、志望理由、入学后研究计划，第2页至今研究活动和课程演习中的实践活动，可附论文·公开软件清单，页数不限）、TOEFL iBT 成绩（ETS 直送）、安全保障輸出管理チェックシート（外国籍等）。
- 出願：只能通过 WEB 出願系统上传 PDF；检定料 30,000 日元（E-shiharai.net 缴纳），日本政府（文部科学省）奖学金留学生免缴。
- 并愿限制：同一期只能报一个専攻、课程或选拔区分；夏入试合格且不放弃入学的人不能报本年度冬入试；上一年度冬入试合格者不能报夏入试。
- 咨询：出願手续问情報理工学系研究科入试担当（〒113-8656 東京都文京区本郷7-3-1，johoriko.t@gs.mail.u-tokyo.ac.jp，Tel 03-5841-7926，平日 9:00–17:00，出願咨询原则上用邮件，回复可能要几个工作日）；専攻内容问創造情報学専攻事务室（office@ci.i.u-tokyo.ac.jp）。
