## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 不另设英语笔试，用 TOEFL iBT 成绩评价；修士出願者全员提交，英语母语者也要交。
- 只收 TOEFL iBT（含 Home Edition）由 ETS 直送的 Official Score Report；MyBest scores 不采用，Test Taker Score Report 不受理，其他考试不能代替。
- 送分代码：University of Tokyo IS&T，Institution Code 8445，Division 选 Graduate Organization，Department Code 99；出願时填 Appointment Number 和受检日，出願后原则上不能更换。
- 受检日须在 2024/9/1 至出願截止日之间，成绩须在 2026/6/30 前到达研究科；成绩无效的不能参加数学和口述。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 数学试题有日英两版；口述的发表必须用英语，之后的试问可用日语或英语回答；出願书类用日文或英文。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 一般教育科目（数学） | 线性代数、解析（微分积分、常微分方程等）、概率·统计各1题，3题全答；全研究科共通 | 13:00–15:30，150分钟 |

- 不设専門科目笔试，相当于専門科目的试问放在口述里（见口述小节）。
- 选拔流程：书类选考 → 数学 → TOEFL → 専門·口述，综合判定；只有通过书类选考、参加了数学且 TOEFL 有效的人才能参加口述。

### 口述試験 / 面接
- **官方形式**：夏入试 Zoom 线上：先用英语做7分钟发表（专业能力、志望领域、研究计划），事先准备幻灯片并共享屏幕，随后用日语或英语试问，可能问到机械系（机械力学、控制、メカトロニクス、ロボティクス等）和情报系（情報基礎、数字电路、计算机、软件等）的专业内容；须用 Windows 或 Mac 并外接摄像头，全程录像，房间里只能有本人，不能用虚拟背景、耳机、智能手表，考前要用摄像头展示桌面和整个房间，可准备 A4 以上笔记本或白板用来在镜头前作答；URL 在 8/21 前通知。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：56名（夏入试，含 2026年10月和 2027年4月入学）。
- 出願资格：大学毕业（含 2027/3/31 前预计）或外国16年学校教育等；个别入学资格审查 2026/5/13 截止（非独立出願）；同一期只能报研究科内一个専攻；希望者可 2026年10月入学，需新办在留资格的外国籍考生官方强烈推荐 2027年4月入学；在出願系统从可接收学生的教员中选第1至第10希望，排不进时可能分到其他有名额的教员。
- 要提前准备的书类：志望カード（専攻样式，1页，12pt 以上，写志望分野和研究计划）、専門能力調査カード（A4 2页，不能加页，写研究活动、课程演习中的自主制作、课外活动等）、TOEFL iBT 成绩（ETS 直送）、安全保障輸出管理チェックシート（外国籍等）。
- 出願：只能通过 WEB 出願系统上传 PDF（Word 样式填好后转 PDF）；检定料 30,000 日元，日本政府（文部科学省）奖学金留学生免缴。
- 并愿限制：同一期只能报一个専攻、课程或选拔区分。
- 咨询：出願手续问情報理工学系研究科入试担当（johoriko.t@gs.mail.u-tokyo.ac.jp，Tel 03-5841-7926，平日 9:00–17:00，原则上用邮件）；専攻内容问知能機械情報学専攻事务室（kyoumu@office.mech.t.u-tokyo.ac.jp，Tel 03-5841-6302）。
