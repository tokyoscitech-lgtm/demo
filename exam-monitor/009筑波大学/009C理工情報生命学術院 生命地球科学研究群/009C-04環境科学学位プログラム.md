## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 8月实施和1-2月实施的一般入学試験：不设英语笔试，必须提交外部英语检定成绩，作为「外国語」科目计 100 分。社会人特別選抜（两个轮次）不考外国語，也不用交英语成绩。
- 受理的考试：TOEIC Listening & Reading、TOEFL iBT（含 Home Edition）、IELTS Academic（本プログラム属于可以用 IELTS 的プログラム）。不受理：TOEIC IP、TOEFL ITP、IELTS General Training、IELTS 在线版、IELTS One Skill Retake。
- 提交方式：TOEIC 交デジタル公式認定証（在 Web 出願系统里填写 URL 并附打印件；只有在不发行数字认定证的国家受检的才交纸质原件）；TOEFL iBT 交 Test Taker Score Report，或让 ETS 直送 Official Score Report（机构代码 9995，部门代码 99）并附 PDF 打印件；IELTS 须让考试机构把 Additional TRF 数据直送筑波大学，并交成绩单复印件。直送数据可能要几周才到，要留出时间。
- 有效期：8月实施须为2024年8月以后受检，1-2月实施须为2025年1月以后受检。
- 换算：达到基准分的换算为满分 100 分——TOEIC L&R 860、TOEFL iBT 98、IELTS 7.0（基准分读自英语版要项）。低于基准分时怎样换算，要项没有公布公式；也没有设最低合格分。
- 没有在期限内提交有效成绩的，出願不受理或按缺考处理，不进入选考。
- 与上一年度相比有没有变更，没有读到相关说明。

### 日本語要件
- 要项没有要求提交 JLPT、EJU 等日语成绩，本プログラム也没有针对外国人留学生的另设区分，留学生与日本学生参加同一场口述试验。
- 研究计划可以用日文（约2000字）或英文（约1000词）写。面接使用的语言要项没有写明。
- 全部用英语修课并写论文的 SUSTEP 是另一条入试路线（见「出願資格 / 定員」），不走本要项。

### 口述試験 / 面接
- **官方形式**：一般入学試験（8月实施 2026/8/19、1-2月实施 2027/1/26，均为 13:30–17:00 之间）是个别面接，每人15分钟，配点 100 分，根据出願时提交的各种资料就专业领域、对环境问题的理解、志望动机、入学后的研究计划等进行试问。社会人特別選抜（同两天的 9:15–13:00 之间）配点 100 分，先由考生做10分钟发表（以往的研究、毕业后的工作或社会活动、从中得到的对环境的认识、志望动机、入学后的研究计划），再接受15分钟的综合面接；发表要自带笔记本电脑，考场提供有 HDMI 和 VGA 接口的投影仪。住在海外的考生可以申请线上（Zoom）口述试验，日期与现场相同，具体时间个别调整，须在出願期间内提交申告书和誓约书。面接使用的语言要项没有写。
- **実際に聞かれた内容**：没有找到本プログラム的面接体验记，实际提问内容不明。プログラム网站的 FAQ 提到，备考主要是和志望教员商量并整理好研究计划、准备面接，能否在与教员讨论的基础上写出研究计划本身就是判断学力的材料（这是官方说明，不是体验记）。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：8月实施 一般入学試験28名（含连携大学院方式和外国人留学生的名额）、社会人特別選抜2名；1-2月实施 一般入学試験23名、社会人特別選抜2名。7月实施（推薦）和10月入学本プログラム不举行。都是2027年4月入学。
- 出願资格：日本的四年制大学毕业或2027年3月底前预计毕业、由大学改革支援·学位授与機構授予学士学位、在外国完成16年学校教育、在外国3年以上的课程取得相当于学士的学位等。22岁以上、希望被认定为“与大学毕业同等以上学力”的人，要先申请个别出願资格审查。
- 社会人特別選抜的资格：除上述资格外，到入学前一个月为止要有1年以上的社会经验（专职或兼职工作，家务劳动也算）。
- 个别出願资格审查和出願资格咨询的截止日：8月实施 2026/7/3（周五）（已过）；1-2月实施 2026/11/24（周二）。资格咨询发给入試課（大学院入試）admission.grad@un.tsukuba.ac.jp，审查申请书类交给生命環境エリア支援室大学院教務；申请时要附研究计划书（样式不限，日文约2000字或英文约1000词）。
- 志望指导教员：在 Web 出願系统里选择志望的指导教员，出願前必须已经取得内诺（见下一小节）。外国人留学生还要从该教员处拿到安全保障出口管理（みなし輸出）确认用的リファレンス番号，在 Web 出願时填写。
- 研究计划：在 Web 出願系统里直接录入，日文约2000字或英文约1000词，本プログラム要求写清入学后的研究题目和研究方法；只有含数式等无法在网页录入时才改交所定样式的研究计划书。
- 出願书类：毕业（预计）证明书原件、成绩证明书原件、外国大学出身者的学位取得（预计）证明书、外部英语成绩（一般入学試験）、说明活动·研究业绩的资料（社会人特別選抜）、检定料收纳证明（便利店支付者）或查询结果画面的打印件（信用卡支付者）、在学或在职者的受験·就学承认书、国费留学生证明书（适用者）等。
- 出願方式：在 Web 出願系统注册并录入出願信息、选择志望指导教员、支付检定料后，把书类贴上系统打印的收件人标签，用書留（海外用 EMS 等）寄到生命環境エリア支援室，截止日必达。要项写明不接受到窗口当面递交。
- 检定料 30,000 日元，信用卡或便利店（仅限日本国内）支付，手续费由出願者负担，缴纳后不退。国费外国人留学生不收。
- 并愿：8月实施、1-2月实施和 SUSTEP 入试可以各自报考，プログラム网站说明只要其中一次合格就可以入学。
- 连携大学院方式：可以选国立環境研究所、国土技術政策総合研究所的连携教员作指导教员，名额含在8月实施一般入学試験的28名里。
- SUSTEP（Sustainability Science, Technology, and Policy，全英语修课）：单独的入试，书类只收纸质件，不走 Web 出願，合格者只能10月入学。2026年10月入学的一次是出願 2026/4/6–5/8、考试 6/2–6/3、发表 6/30（已结束）；面向2027年10月入学的要项没有读到（截至2026-10-10）。
