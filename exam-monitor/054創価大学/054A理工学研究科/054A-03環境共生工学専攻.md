## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 一般选抜Ⅰ·Ⅱ期：必须提交过去4年内最高分的 TOEIC 成绩原件（出願书类 C-7 英语能力证明书），代替英语笔试；要项没有最低分和换算方法。
- 变更点：2027年度入试起全専攻取消英语笔试，改为必须提交 TOEIC。
- 要项只写 TOEIC，没有列出 TOEFL 和 IELTS。
- 特别选抜（社会人）Ⅰ·Ⅱ期：考英语笔试（英文读解、英作文等，10:30–11:30）；TOEIC 成绩（过去4年内最高分）可任意提交，只交 TOEIC 可代替笔试，两者都有时取高分。
- 外国人学生入试：必须在日语能力考试合格证明书（C-6）和英语能力证明书（C-7）中至少提交一种；用英语授课的学历证明也可作为 C-7。要项没有写分数或级别基准。

### 日本語要件
- 一般选抜没有要求提交日语成绩，持有日语能力考试合格证明者可提交原件（C-6，任意）。
- 外国人学生入试：日语（C-6）或英语（C-7）证明二选一必交，只交英语证明也可以；要项没有规定 JLPT 级别。
- 外国人学生入试的书类须用日语或英语制作，其他语言的证明书须附日译或英译。要项没有写口述试验的语言。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 一般选抜Ⅰ期：専門（配点官方未公布，90分钟） | 物理化学、分析化学、微积分学、生态学、分子生物学、微生物学6科中，出願时选定2科作答（在 WEB 出願页填写専門试验科目届出票［J票］） | 2027募集要项 |
| 一般选抜Ⅰ·Ⅱ期：英语不考笔试 | 提交过去4年内最高分的 TOEIC 成绩 | 2027募集要项 |
| 一般选抜Ⅱ期：不考専門笔试 | 只有 TOEIC 提交＋口述试验 | 2027募集要项 |
| 特别选抜（社会人）Ⅰ·Ⅱ期：英语（配点官方未公布，60分钟，10:30–11:30） | 英文读解、英作文等；可用 TOEIC 代替，两者都有时取高分 | 2027社会人募集要项 |

- 一般选抜按笔试（含语言能力评价）、书类审查和口述试验综合判断，达到六成以上基准者合格；外国人学生入试按书类审查和口述试验，同样以六成为基准；学内选考按学业成绩、口述试验和出願书类综合判定。
- 考场一般只能带笔记用具；本専攻専門笔试可另带函数电卓1台（有通信功能的设备、PC、平板不行），计算用电卓也由考场出借。
- 本専攻不能用 EMaT 成绩代替専門笔试（EMaT 代替只适用于情報システム工学専攻）。
- 题目倾向：没有找到本専攻的体验记。

### 口述試験 / 面接
- **官方形式**：一般选抜Ⅰ·Ⅱ期的口述试验就研究课题和研究计划提问，时刻考前1周通过 TAO 通知；特别选抜（社会人）为英语笔试＋口述试验，与书类综合判定；外国人学生入试只有书类审查和口述试验，在创价大学校内实施，可选线下或线上，日期按时差决定、约考前2周通知。配点官方未公布。
- **実際に聞かれた内容**：没有找到本専攻的体验记。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：一般选抜 5名程度（Ⅰ·Ⅱ期合计）；学内选考 20名程度；特别选抜（社会人）若干名；外国人学生入试若干名。
- 本専攻特有规定：同一指导教员的升学希望者超过5人时，可能被分配到第2或第3志望的教员。
- 出願资格（一般）：大学毕业或 2027年3月底前预计毕业、学位授与机构授予学士、在外国完成16年学校教育等(1)–(3)；(4)–(9)（外国通信教育、专修学校、大学在学3年以上成绩优秀、个别资格审查22岁以上等）须先申请出願资格认定：Ⅰ期 2026/5/8–5/29（已截止），Ⅱ期 2026/10/2（周五）–10/23（周五）。
- 学内选考：本校理工学部 2026年度预计毕业生或本校理工学部毕业的研究生，须满足各専攻规定的 GPA（基准值在学内门户公布）；春季须专愿、合格必入学，秋季不要求专愿。
- 特别选抜（社会人）：2027年3月底时社会经验2年以上（推荐社会人须正式在职2年以上并获所属长推荐），且满足上述学历要件之一。
- 外国人学生入试：非日本国籍等，大学毕业或外国16年学校教育等；中国3年制大学的学位不被认可；只能报1个専攻。
- 出願书类（一般）：入学願書［A票］（贴照片转 PDF）、志望理由及入学后希望的研究［B票］、成绩证明书原件（校外出身者另需本校调查书［C票］）、毕业（预计）证明书、TOEIC 成绩原件（C-7）、JLPT 合格证（有者）、毕业研究概要［D票］（未做毕业研究者写明）、Ⅰ期须在 WEB 填写専門试验科目届出票［J票］、经费支办书［K票］（外国人）、合格通知送付地址［M票］；外国人学生入试另需指导教员签名的受入承诺书［F票］。B票和D票用 Word 写好后转 PDF 上传。
- 出願方式：在 WEB 出願系统（TAO）注册后上传书类并付款；需要原件的证明书邮寄或送理工学部事务室窗口。受験票在 TAO 上发行、自行打印；考试当天开考前15分钟到理工学部栋集合，教室在正面大厅公布。
- 检定料 33,000 日元，在 TAO 上支付；已交书类和检定料原则上不退。
- 外国人须证明1年的生活费和学费（约每月16万日元×12个月）；经费不足可能导致 COE 不交付而不能入学。
- 学费（2026年度参考额）：入学金 200,000 日元（本校学部毕业生等 100,000 日元），授业料 790,000 日元，实习费 110,000 日元，合计 1,100,000 日元，可分两期。一般选抜Ⅰ期合格者第1次手续 2026/10/1–10/22 交入学金，第2次 2027/2/16–2/26；Ⅱ期合格者 2027/2/16（周二）–2/26（周五）一次办理。
- 奖学金：理工学研究科特待生（学内选考春季各専攻成绩上位者，1年次30万＋2年次10万日元）；牧口奖学金（大学院生，20万日元一次）；牧口奖学金（留学生，年60万日元，最多2年，须在外国人学生入试出願时申请，最多9名）；各奖学金不能并给。
- 咨询：创价大学理工学部事务室大学院系（〒192-8577 东京都八王子市丹木町1-236），Tel 042-691-9400，eng-grad@soka.ac.jp。
