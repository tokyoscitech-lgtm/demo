## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各轮次相同：不另设英语笔试，出願时提交 TOEFL iBT、TOEIC L&R、IELTS（Academic）、TEAP（4技能）之一的成绩，须为出願开始日往前2年以内受检、出願截止日前已出结果；出願后不能更换。
- TOEFL：ETS 直送 Institutional Score Report（大学代码 0819），另附 Test Taker Score Report 复印件；只认 Test Date 成绩，iBT（含 Home Edition）可以，ITP 不受理。
- TOEIC：不认 IP；交公式认定证原件（或经出身学校·入学センター原本证明的复印件），或经スコア確認サービス直送（申请代码 00031501）并附デジタル公式認定証复印件。
- IELTS 由实施机构电子直送并附 Test Report Form 复印件；TEAP 交结果通知原件。

#### 日本語要件
- 外国人考生须提交日本语能力试验（JLPT）N2 以上合格的「認定結果及び成績に関する証明書」或「合否結果通知書」原件（或经出身学校·入学センター原本证明的复印件），须为出願开始日往前2年以内受检、截止前已出结果。
- 在日本的大学主要用日语授课取得（含预计）学位的人免交，在出願书类核对表上注明。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 数学基礎 | 线性代数、微分积分、集合·映射·逻辑，以及专门分野（代数学、几何学、解析学）的基础 | 9:30–12:00，150分钟 |

- 笔试是理工学専攻共通的「理工基礎（選択科目）」，出願时在 Web 出願系统从機械工学基礎、電気·電子工学基礎、化学基礎、数学基礎、物理学基礎、生物科学基礎、情報学基礎 7 科中选 1 科；9月入试与2月入试范围相同。
- 合否按出願书类、笔试、口述综合判定，全员都参加笔试和口述。

### 口述試験 / 面接
- **官方形式**：9月入试、2月入试都有口述试验，笔试次日 10:00 起（9:45 前集合），就专门研究内容和志望动机进行口头试问。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：理工学専攻博士前期課程200名（9月入试·2月入试、一般·社会人入试合计，不按領域分配）。
- 出願资格：大学毕业（含预计）或外国16年学校教育、外国3年以上课程取得学士相当学位等；中国3年制专科不认；需个别资格审查的人须在 Web 出願开始日2周前（2月入试约 2026/11/13）用邮件向入学センター索取申请表（非独立出願）；出願时选定領域，入学后不能变更；2月入试只受理出願时住在日本国内的人（短期滞在除外），海外居住者只能报9月入试；9月入试和2月入试可以并愿。
- 要提前准备的书类：外部英语成绩（直送须提前手配）、日本语能力试验 N2 以上证明（外国人）；中国大学出身者须安排 CHSI 把学位认证和成绩认证报告在出願截止前直送上智大学，并附复印件；2月入试的外国籍考生另交在留卡正面复印件。
- 出願：Web 出願系统登记并缴检定料 35,000 日元（另加支付手续费 1,100 日元），截止日 23:59 前付清；打印志願票后用簡易書留·速達邮寄书类到入学センター（海外寄出用 EMS 等，截止日必达），窗口不受理。
