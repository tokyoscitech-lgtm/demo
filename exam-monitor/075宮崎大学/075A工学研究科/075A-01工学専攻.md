## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 第1次募集（一般・社会人・外国人留学生）：不考英语笔试，改为提交外部考试成绩：TOEIC L&R 公开テスト（Official Score Certificate 原件，或 Digital Official Score Certificate 打印件）、TOEIC L&R IP テスト（Score Report 原件，线上 IP 不可）、TOEFL iBT（成绩原件）。
- 有效期：2023年4月以后实施的考试。
- 换算：折算成 100 分，TOEIC 695 以上或 TOEFL iBT 61 以上记满分 100。这是满分上限，不是出願最低分；要项没有写低于该线时的具体换算式。
- 期间内没寄到成绩的出願不受理。
- SP入试：接受 TOEIC L&R、TOEFL iBT（含 Home Edition）、IELTS，2023年4月以后受验；要项不设硬性分数线，但以 TOEFL iBT 61 相当作为基准水平。英语母语国出身者可申请免交（第1次募集外国人留学生入试的免除申请截止为 7/2，已过）。

### 日本語要件
- 一般・社会人选拔：要项没有要求提交 JLPT、EJU 等日语成绩；アドミッション・ポリシー只写“具备研究开发所需的日语和英语能力”，没有数值标准。
- 外国人留学生入试和 SP 入试：只要求“能用日语和/或英语沟通”，同样不要日语证书；SP 入试全英文授课，研究计划可用英文（约 300 词）。
- 面接·口述用什么语言，要项没有写明，建议事先向志望教员确认。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 专门科目笔试 | 不实施（第1次募集、SP入试都没有笔试） | 2027募集要项 |
| 英语（满分100分换算） | 外部成绩代替：TOEIC 695／TOEFL iBT 61 以上记满分 | 2027募集要项 |
| 面接（含口述试验） | 一般提问＋毕业研究约5分钟发表与答辩，可能问学部专门科目 | 2027募集要项 |

- 总分判定：面接（含口述）、书类审查、外部英语成绩三项综合判定；要项没有公布各项配点和总分。
- 面接评价专门知识技能、思考力、主体性、学术兴趣和意欲；书类评价知识技能；英语成绩评价语言能力。

### 口述試験 / 面接
- **官方形式**：先一般提问，再口述试验：就毕业研究（没有毕业研究的写课题研究或今后的研究计划）做约5分钟发表，随后答辩；自带电脑和发表文件，另带印刷资料 10 份；口述可能包含学部专门科目的内容。宮崎大学工学部出身者经书类审查可能免除口述。SP入试形式相同，海外居住者可向志望教员商量后申请线上考试。
- **実際に聞かれた内容**：未找到本専攻的受验体验记，暂无。

## 📝 详细信息
### 出願資格 / 定員
- 第1次募集的募集人员：工学専攻（先端情報、環境、電気・半導体、機械 4コース）合计 144 人，含社会人选拔和外国人留学生入试；要项不分コース公布人数。第2次募集“若干人”，可能不实施。SP入试各コース“若干人”。
- 一般选拔出願资格：大学毕业或 2027年3月前预计毕业、学位授与机构学士、外国 16 年学校教育、外国学士相当学位（3年以上课程）、大学在学3年以上成绩优秀者、22岁以上个别审查等 1–11 项之一；资格7、10、11 须事先审查（第1次募集截止 2026/6/26，已过）。
- 社会人选拔：在研究机关、学校、企业等在职，入学后保持身份，并有所属长的推荐。
- 外国人留学生入试和 SP 入试：非日本国籍，持有或将取得可就学的在留资格，并满足外国 16 年教育等 6 项之一；SP 入试资格(3)(6)者须在 2026/10/16 前提交资格审查材料。
- SP 入试（Special Program for International Students）全英文授课，不要求奖学金（奖学金证明可选）；没有留学签证的人不能享受学费减免、奖学金、tutor 等留学生待遇。
- 出願流程：先在 Web 系统登録（第1次募集 6/30 起，SP 10/26 起），缴检定料，再把志願票、履歴書等打印件和成绩证明、毕业（预定）证明、外部英语成绩原件、在留卡和护照复印件、志望理由书、研究计划书、研究业绩调书等邮寄到入试课；仅 Web 登録不算出願完成。
- 检定料 30,000 日元＋系统手续费（信用卡 600 日元，便利店/Pay-easy 300 日元）；国费留学生免缴。
- 入学料 282,000 日元（预定），授業料 年 535,800 日元（半期 267,900 日元，口座振替）。
- 资格7（3年级跳级）者为附条件合格，须在 2027/3/2 前提交含3年级的成绩证明。
- 出願书类寄送：宮崎大学学び・学生支援機構入試課（〒889-2192 宮崎市学園木花台西1丁目1番地，Tel 0985-58-7138），书留或速达，信封注明“大学院工学研究科一般選抜入学願書在中”。
- 受験票：第1次募集 7/15 起在 Web 系统打印；7月底仍看不到的打 0985-58-7979。
- 咨询：工学部教務・学生支援係 Tel 0985-58-7979，eng-m@miyazaki-u.ac.jp；Web 出願和手续问入试课 0985-58-7138。
- 残障考生的考试上的配慮：第1次募集须在 2026/6/26 前向入试课申请（已过）。
