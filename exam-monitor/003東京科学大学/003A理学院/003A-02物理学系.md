## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般入试：
  - 不另设英语笔试，用 TOEIC L&R 或 TOEFL iBT（含 Home Edition）成绩评价，配点 60 分。
  - 出願时不交，把在线版成绩单打印出来在筆答当天（2026/8/18）带到考场提交；筆答时没交的判为不合格，交后不能更换、不退还。
  - 只认 2024/6/11 以后受检的成绩。TOEIC 须为带真伪确认 QR 码的数字公式认定证 PDF 打印件；TOEFL 须为 Test Taker Score Report PDF 打印件，并在 ETS 账户为该成绩设定 DI code G179。ETS 邮寄的纸质成绩单、TOEFL ITP、TOEIC IP 等团体考试不受理。
  - 要项附録3的换算基准：TOEFL iBT 先按对照表换成 PBT，再用（PBT－296）÷0.348＝TOEIC L&R，例如 iBT 80→PBT 550→TOEIC 约 730，iBT 100→PBT 600–603→TOEIC 约 874–882（TOEIC 300 分以下不适用）。
- IGP(C)：申请材料不要求英语成绩；面试和考试用英语进行。

#### 日本語要件
- 要项没有要求提交日语成绩。
- IGP(C) 全英语授课，不要求日语。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 筆答専門試験（300分） | 力学、电磁学、物理数学、量子力学、统计力学、物理学实验的基础知识与理解；全部为共通题，没有选答题 | 9:30–11:30、13:30–15:30，各120分钟 |
| 英语（60分） | 用外部成绩评价，见英語要件 | |

- 一般入试只有 B日程：按筆答结果决定口頭試問受験资格者，再综合口頭試問和出願书类判定合否；每位教员的指导学生数有上限。
- 筆答试验中止时，改为 8/18 线上代替口述试验和 8/25 线上口頭試問，连同出願书类选拔。

### 口述試験 / 面接
- **官方形式**：一般入试 B日程：口頭試問考查物理学的知识与理解，只限筆答后公布的受験资格者参加，成绩提供时只给 A–E 评价；A日程（口述选拔）物理学系不实施；IGP(C)：系或志望导师安排的英语面试和/或考试，可能含口头提问或解题，原则线上，按居住地也可能面对面。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：物理学系受入可能予定人数 62 名（2026年9月和2027年4月入学合计，理学院合计 154 名）；IGP(C) 各系若干名。
- 出願资格：大学毕业（含 2027/3/31 前预计）或外国16年学校教育等，(9)(10)(11) 项须先做出願资格审查；只能报一个系，一个出願出结果前不能再报理工学系其他募集（含 IGP(C)）；外国籍考生选9月入学须出願时住在日本且在留资格有效到 2026/9/28，否则只能4月入学；网上出願登记的现住址限日本国内；IGP(C) 面向外国留学生，须先取得物理学系教员的指导同意。
- 要提前准备的书类：志望理由书（所定样式 A4 1张，写对志望研究室·研究领域的志望理由，约1,000字，可含特长）；TOEIC L&R 或 TOEFL iBT 在线成绩单；日英以外语言的证明须附出身大学或使馆·公证处证明的译文；IGP(C) 另需导师同意书（扫描件须在出願截止前一周发给入試課）、研究计划（所定样式）、本科研究概要和推荐人直接提交的评价表兼推荐信。
- 出願：一般入试先在网上出願系统登记、上传照片、缴费，再把书类以速達書留寄到入試課（6/10 必达，不收窗口提交），检定料 30,000 日元＋手续费 990 日元，国费留学生等须 5/27 前办免缴手续；IGP(C) 全程网上提交，检定料 30,000 日元（信用卡）。
