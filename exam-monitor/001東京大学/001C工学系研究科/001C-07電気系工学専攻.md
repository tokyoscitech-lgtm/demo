## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般入试：
  - 不另设英语笔试，用 TOEFL iBT（含 Home Edition）公式成绩评价；TOEIC、IELTS 不受理。
  - 2026/8/20（周四）前完成三步（已截止）：ETS 送分（DI 代码 8596，Department 代码 99）、在 WEB 出願系统登记 Appointment Number 和受检日、上传 Test Taker Score Report；没登记 Appointment Number 的可能仅因此不合格。
  - 只用 2024年9月以后受检的 Test Date Scores，不用 MyBest，TOEFL ITP 等团体成绩不受理，英语母语者也要交；截止前可更改登记。
  - 本研究科修士课程修了（预定）者不需要交 TOEFL；修士特別口述試験合格者也不需要交 TOEFL，并免専門科目笔试。
- IME：交 TOEFL（优先）或 IELTS 成绩（书类截止时2年内），或出身大学的英语授课证明；GRE General 必交（5年内）。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 一般入试的専門科目试题日英并记，可用日语或英语作答。IME 全英文授课。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 専門科目（電気電子工学·情報工学） | 6个范围各1题，选2题：①電磁気学（静电场、电介质、电流、磁场、磁性体、电磁感应、麦克斯韦方程、电磁波）；②電気回路（线性电路的直流·交流分析、过渡响应、拉普拉斯变换、频率响应、分布常数线路；小信号等效电路、放大器、振荡器、反馈）；③情報工学Ⅰ（信息理论、信号处理：傅里叶变换、采样定理、z变换、数字滤波器、调制）；④情報工学Ⅱ（逻辑电路、算法与编程：搜索、排序、数据结构）；⑤固体物性（量子力学基础、费米–狄拉克统计、能带、pn结、MOS结构）；⑥制御·電気エネルギー工学（传递函数、稳定性、反馈设计；交流电路、能量变换） | 9:00–11:30，150分钟 |
| IME：无笔试 | 书类审查＋教员接收函 |  |

- 一般入试不考一般教育科目（数学）；各范围的关键词只表示重点，不限定出题范围。
- 合否和配属按笔试、口述、提交书类和志望的指导教员综合决定，専門科目和口述缺一项即受験无效。
- 预备选拔：志願者多时按専攻調査票和成绩表做预备选拔，有无实施及结果在 2026/8/14（周五）前于専攻入试网页（受験者専用页）公布（已公布）。
- 笔试免除：本専攻、電気·電子工学専攻、新領域創成科学研究科基盤情報学専攻和先端エネルギー工学専攻、情報理工学系研究科電子情報学専攻的修士修了（预定）者只考口述。
- 题目倾向（体验记，非官方）：外部生有选電磁気学＋電気回路的，也有情报系出身选情報工学Ⅰ＋Ⅱ的（理由是電気回路计算量大）；基础题约占八成，重点是弄清东大本科讲到哪里（2023–2024年，2人提到）。

### 口述試験 / 面接
- **官方形式**：一般入试：线上口述（自备电脑、摄像头和宽带网络），问志望分野及理由、该分野的基础事项，并口头介绍毕业研究，指定时间不参加视为放弃；修士特別口述試験：线上，面向书类选考判定成绩优秀、以本専攻为第一志望的人，问志望分野及理由和该分野的基础知识，合格者仍须参加普通口述；IME：书类审查，必要时教员线上面试。
- **実際に聞かれた内容**：
  - 约25分钟，教员约5名轮流提问：为什么选东大、想做的研究、笔试自我评价、専攻調査票里写到的技术、本科研究与研究生阶段研究的不同（2023年8月，1人提到）。
  - 特別口述不合格后，走普通笔试＋口述合格（2024年，1人提到）。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：70名（一般入试，2027年4月入学和2026年10月入学合计）；IME 另行选拔。
- 出願资格：大学毕业（含 2027/3/31 前预计）或外国16年学校教育等；个别入学资格审查 2026/4/21 截止（非独立出願）；不能同时报本研究科两个以上専攻；可申报 2026年10月入学（需新办签证者建议4月入学）；出願时在线登记希望指导教员的优先顺序；IME 只限非日本国籍、网上出願期间不住在日本的人，日本的大学毕业·在读者（含研究生）不能报。
- 要提前准备的书类：専攻調査票（専攻样式，写修士阶段想做的研究、毕业研究题目、毕业后打算）和成绩集计表；TOEFL 公式成绩；安全保障輸出管理チェックシート（外国籍等）；外国大学的证明须写明学位（否则另交学位证明），日英以外语言须附出身大学盖章的英译；IME 须2封推荐信（推荐人网上提交）、学习计划书、GRE 成绩和教员接收函。
- 出願：一般入试只能在 WEB 出願系统上传 PDF，检定料 30,000 日元，日本政府奖学金留学生免缴；IME 用 T-cens 网上出願后邮寄纸质书类（9月募集 2026/11/4、1月募集 2027/3/10 必达），检定料 10,000 日元。
- 并愿限制：不能同时报工学系研究科的两个以上専攻或课程。
- 咨询：募集要项的问题用研究科网站的咨询表单（工学系研究科学務課大学院チーム）；専攻入试咨询 eeis-nyushi27-group@g.ecc.u-tokyo.ac.jp。
