## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 8月入试：不在考场考英语，改为提交 TOEFL iBT 或 TOEIC L&R 的成绩，两者只能选一种。官方说明外部考生必须提交。
- 提交要做两件事：①出願期间内在 WEB 出願系统登记考试日和分数，并上传成绩单（TOEFL 为 Test Taker Score Report，TOEIC 为デジタル公式認定証）；②在考试机构的网站上把成绩直送给本専攻，截止 2026/6/23（周二）（已截止）。TOEFL 的 DI code 为 2059，学科选“99 – any department not listed”；TOEIC 通过 IIBC 的公开考试成绩确认服务提交，申请代码 00027403。
- 有效期：考试日在 2024/10/1 及以后的成绩。TOEFL iBT Home Edition 不受理；TOEIC 只认在日本国内考的成绩；TOEFL 的 MyBest Scores 不采用。TOEFL ITP、TOEIC IP、IELTS 不在可提交的种类里。
- 换算：TOEIC 换成 TOEFL 分数来比较，TOEIC 250＝TOEFL 18，650＝55，970＝100，区间内按直线内插，超出范围取端点值。例如 TOEIC 800 约相当于 TOEFL 76。
- 官方没有公布最低分和英语的配点。専攻不回答“成绩是否已送达”的个别询问，并提醒成绩发布需要时间、要尽早考。
- 变更点：从 2025 年实施的入试（2026年度入学）起，由当天上午的英语考试改为提交成绩。

### 日本語要件
- 専攻页没有要求提交日语成绩（JLPT 等）。一般入试只用日语进行，专攻明确写了想用英语应试的人应报外国人特別選考。
- 小論文可以用日语（约 800 字）或英语（约 400 词）写。笔试题目的语言和作答语言専攻页没有另外说明。
- 研究科要项中对日语的规定未能核实（要项 PDF 无法读取）。

- 选拔分两个阶段：笔试（加英语成绩）决定口述对象者，再按笔试和口述的综合成绩，以研究グループ为单位判定合否。配点和合格倍率官方明确表示不公开。
- 受験要望科目：每位教员对自己将指导的合格者有希望的应试科目（必考、二选一、可选、不可选），不按要望科目应试的话可能无法由该教员指导。多数大气海洋、宇宙惑星、地震方向的教员要求数学＋物理学。
- 官方提示：生物学和地球科学的记述式题目在增加，参考过去问时要注意。
- 题目倾向（体验记，非官方）：没有找到可用的考生体验记。

### 口述試験 / 面接
- **官方形式**：对象是笔试通过者，2026/8/27（周四）公布名单和各人要去面试的研究グループ。Zoom 线上进行，分大気海洋科学、宇宙惑星科学、地球惑星システム科学、固体地球科学、地球生命圏科学 5 个グループ，可能要参加多个グループ的面试。考生事先提交的小論文（入学后想做的领域和研究内容，用指定 Word 模板，1 页以内，12pt，转成 PDF 在マイページ上传）和希望グループ调查（一般最多选 2 个，写明理由可选 3 个）用来决定面试グループ，也是合否判定的资料。时长和配点官方没有公布。可能合格多个グループ，但只能进入合格了的グループ。
- **実際に聞かれた内容**：没有找到可用的体验记。官方的说法只有：小論文不能请教员修改，但事先和教员讨论过的内容可以写进去。
