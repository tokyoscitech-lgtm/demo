## 🎯 入試内容（考什么）

### 英語要件
- 日程B：以提交的 TOEFL iBT 成绩作为英语考试（含 Home Edition、Paper Edition）。修士不能用 TOEIC（只有博士的社会人等特别选拔可选）。
- 成绩须在考试1周前上传 Test Taker Score Report，并完成对 ETS 的送分手续；过了出願期再交时用专攻指定的提交表单。
- 日程B 只认 2025/2/1 以后受检的成绩。TOEFL 须用 DI 代码 8001、Department 代码 99 请 ETS 送分，并另外上传 Test Taker Score Report（需填16位 Appointment Number）。

### 日本語要件
- 没有要求提交日语成绩。笔试题目日英双语，可用日文或英文作答。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 専門科目A | 考查对环境系统的知识、理解力、洞察力的题目（小论文形式） | 修士入试信息 |
| 専門科目B（日程B） | 理解环境系统所需的基础知识的题目 | 修士入试信息 |
| 専門科目B（日程A，参考） | 环境科学I 必答，再从环境科学II、数学、物理、化学4题中选1题 | 修士入试信息 |

- 配点比例（FAQ）：日程B 为 専門科目A：専門科目B：口述＝1：0.5：1.5；日程A 为 1：1：1.5。

### 口述試験 / 面接
- **官方形式**（日程B）：综合试问。用 PowerPoint 等做的幻灯片，在7分钟内说明毕业论文研究的概要和修士课程的研究计划（日程A为5分钟）。不做毕业论文的，说明在讨论课、项目、实验中感兴趣的对象。发表资料的提交方法随受験票通知。
- **実際に聞かれた内容**：未收集。

## 📝 详细信息
### 出願資格 / 定員
- 日程Aの募集人員は18名。日程B为一般选拔若干名。日程A·B都不实施外国人等特别选考，外国籍考生走一般选拔。
- 专攻的提交书类：募集要项所列书类、英语成绩单、志望调查票、学业·职务两立计划书（仅在职就读者）。
- 日程B可以选 2027年10月入学；出願后要改入学时期（10月或4月），须在口述试验前提出。
- 地圏環境システム学分野（德永 朋祥教授）的修士学生只招到 2027年4月入学为止，不收博士。
- 社会人学生每年约2名（FAQ）。
- 研究科共通（日程B）：网上出願，检定料 30,000 日元；受験票 12月中旬发到登记邮箱（12/15 前未收到须联系教務チーム）；合格发表 2027/2/18 10:00（基盤棟掲示板＋[发表页](https://go.k.u-tokyo.ac.jp/gsfs-exam)）；4月入学者的入学料缴纳·入学手续期限 2027/3/5。
- 入学时期：原则 2027年4月。需要由东大新申请在留资格认定证明书（CoE）的外国籍考生，日程B合格后只能 2027年10月入学（9月上旬发通知，9月下旬办手续）。
- 禁止事项：不能同时报研究科内两个以上专攻；日程A合格者不能再报日程B；一般选拔和外国人等特别选考不能重复报。
- 出願书类（研究科共通）：证件照（jpeg，3个月内，不得修图）、本科成绩证明书、毕业证明书（已毕业者；外国大学毕业者另附能确认学位的证明）、专攻要求的书类。日英文以外的文件须附日文或英文译文；上传文件的原件在入学手续时提交。
- 费用：入学料 282,000 日元，授業料 年 535,800 日元（前期 267,900）。日本政府（文部科学省）奖学金留学生免检定料和学费。
- 个别入学资格审查（仅资格⑥等）：联系期限 10/1 已过，申请期 10/7–10/13。考试·修学上的特别照顾须在 10/8 前申请。
- 安全保障出口管理：外国人留学生入学前必须接受审查，属于管制事项时即使最终合格也可能不许入学或研究受限。

### 研究室 / 指導教員
- 事前連絡要否：推荐（入试信息在特别口述部分写明“建议出願前联系希望的指导教员，商量希望的研究内容”；一般选拔没有写成必须）。说明会当天可与各教员面谈。
- 志望研究分野在志望调查票上填写；研究室见专攻「研究室一览」。
- 咨询：envsys_exam@edu.k.u-tokyo.ac.jp。
