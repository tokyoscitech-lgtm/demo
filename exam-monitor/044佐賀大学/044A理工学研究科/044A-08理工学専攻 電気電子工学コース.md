## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般入試：不另设英语笔试，用外部成绩评分（150分）。
  - 收 TOEIC L&R（公开测试或 IP 测试，IP 线上版不收）、TOEFL（含 ITP，iBT Home Edition 可）、IELTS（只限 Academic，纸笔或机考均可），可交多份。
  - 须为考试日前2年以内受检，出願时交成绩证明原件；TOEIC 公开测试的数字公式认定证可交打印件。
- 外国人留学生特別入試（本コース）、推薦入試、社会人特別入試：不要求英语成绩。
- AEPAT/IEPAD：要求能用英语开展学习研究，推荐信里须写明英语能力，有 TOEFL 等成绩可附上。

#### 日本語要件
- 要项没有要求提交日语成绩；AEPAT/IEPAD 全部授课和研究指导用英语。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 一般入試：専門科目−1 | 微分方程式、線形代数学 | 10:00–12:00，120分钟 |
| 一般入試：専門科目−2 | 電気回路、電磁気学 | 13:00–15:00，120分钟 |
| 外国人留学生特別入試：数学 |  | 10:00–11:00，60分钟 |
| 外国人留学生特別入試：専門科目 | 電磁気学、電気回路 | 13:00–15:00，120分钟 |

- 一般入試：外语（英语外部成绩）150＋専門科目 450＋面接 100，综合判定良/可/不可；专门科目不能带计算器。
- 外国人留学生特別入試：専門科目（含数学）300＋面接 100，综合判定。

### 口述試験 / 面接
- **官方形式**：一般入試：面接100分，评价志望动机和入学后的研究意欲，成绩证明作面接资料；外国人留学生特別入試：面接100分；推薦入試、社会人特別入試：就专门领域的口述试验100分＋面接100分（推荐书、研究业绩书等作面接资料）；AEPAT/IEPAD：就志望コース的专门科目进行口试（含面试），全程用英语。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：一般入試 15名（含社会人·外国人留学生特別入試）；推薦入試 14名；10月入学和 AEPAT/IEPAD 若干名。变更点：2026年度一般为 16名。
- 出願资格：大学毕业（含 2027年3月预计）或外国16年学校教育等；资格(9)–(13)须在 2026/6/26 前申请资格事前审查（已过，非独立出願）；外国人留学生特別入試限无日本国籍者；推薦入試限 2027年3月毕业预定者，须出身大学推荐、合格必入学；AEPAT/IEPAD 在日募集限住在日本的外国籍者，海外在住外国人报在外私费募集（书类审查＋导师面谈，AEPAT 定员4名、IEPAD 3名，均含10月入学）。
- 要提前准备的书类：英语外部成绩原件（一般入試）；推荐书（外国人留学生特別入試由学部长或指导教员填所定样式；推薦入試由出身大学校长等厳封）；AEPAT/IEPAD 的英文毕业论文摘要（A4 4页以内）和推荐信。
- 出願：银行窗口缴检定料 30,000 日元，J-Bridge System 网上登记后用速達簡易書留邮寄书类（截止日 17:00 必达）或窗口提交；AEPAT/IEPAD 用 Flywire 缴费、挂号邮寄必达。
