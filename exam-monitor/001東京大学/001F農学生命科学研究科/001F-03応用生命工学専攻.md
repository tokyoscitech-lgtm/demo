## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各日程相同：不另设英语笔试，用 TOEFL iBT（含 Home Edition）成绩评价；所属团体实施的 ITP 不受理，MyBest Scores 不采用。
- 在有效期间内受检，并在同期间内向 ETS 申请把 Institutional (Official) Score Report 送到研究科（DI code 1113，其他代码无效）；出願时在 WEB 系统填写 Appointment Number、受检日和分数，不必交 Test Taker Score Report。送过多份的只指定其中一次。
- 有效期间：A日程 2024/8/1–2026/6/13；B日程 2025/2/1–2026/11/15（均已过）。
- B日程综合型选考：在美国、英国、爱尔兰、加拿大、澳大利亚、新西兰的大学或研究机构取得（或预计取得）学士学位者免交。

#### 日本語要件
- 要项没有要求提交日语成绩。
- A日程笔试用日语出题，可用日语或英语作答；B日程笔试型用英语出题，可用英语或日语作答。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 基礎化学（必答） | 大学低年级程度的一般化学、基础生物化学、基础有机化学；参考书 McMurry 等《Fundamentals of General, Organic, and Biological Chemistry》 | A日程 16:10–17:05，55分钟 |
| 选择科目（7科选3科） | 分析化学、生物化学、有機化学·天然物化学、微生物学、分子生物学、植物生理学·植物栄養学·土壌学、食品科学；A日程考场当场选，B日程出願时选定 | A日程 13:00–15:45，165分钟 |
| 生命情報科学（只限只志望生物情報工学·生命情報解析者） | 编程基础（推荐 Python）、序列比对、基因组与转录组分析、蛋白质结构分析及相关算法和统计；可代替选择科目中的2科（即“1科＋生命情報科学”） |  |

- 两専攻用同一套试题，报哪个専攻由第1志望研究室所属决定，合否标准没有差别；按成绩顺序配属研究室，第1志望满员时配到第2志望（専攻 Q&A）。
- B日程笔试型科目同A日程，英语出题，对面实施。
- 题目倾向（体验记，非官方）：用研究科指定教科书做总结、刷约10年过去问（2022年，1人提到）；基礎化学出过热力学、金属络合物等超出预想范围的题（2022年，1人提到）。

### 口述試験 / 面接
- **官方形式**：A日程不实施口述；B日程笔试型不实施口述；B日程综合型选考：一次书类选考看学业成绩（含GPA）、获奖、奖学金、研究活动、论文和学会发表，通过者 2026年12月下旬线上口述，问研究活动与成果、化学基础及出願时所选3科（生物情報工学·生命情報解析志望者可为1科＋生命情報科学）的相关内容；书类或口述不合格者可转考笔试型。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：43名（A日程，2026年10月＋2027年4月入学）；B日程若干名（2027年4月＋10月入学）。
- 出願资格：大学毕业（含2027/3/31前预计）或外国16年学校教育等，国内外学士都可报B日程；个别入学资格审查 A日程 2026/5/7、B日程 2026/10/7 截止（非独立出願，已过）；同一日程只能报研究科一个専攻，A日程已合格两専攻之一者不能报B日程；A日程填第1、第2志望（不同分野；4月入学第1志望须在本専攻、第2志望可选応用生命化学専攻；10月入学须同一専攻），B日程只填第1志望；B日程笔试型和综合型选考二选一。
- 要提前准备的书类：志望教员（教授或准教授）签名的志望確認書（A日程第1、第2志望各1份，B日程1份）；B日程综合型选考另交记有 GPA 的成绩证明书、推荐书1份（推荐人熟悉本人研究、非志望教员，系统向其发上传链接）、自己アピール（英文约800–1,200词或日文约2,000字）。
- 出願：只能通过 WEB 出願系统上传 PDF；检定料 30,000 日元（银行汇款、便利店、信用卡、Pay-easy），日本政府奖学金留学生免缴。
- 并愿：同一日程只能报研究科的一个専攻；2027年度 A日程已合格本専攻或応用生命化学専攻的人，不能再报 B日程的这两个専攻。
- 咨询：出願手续问农学生命科学研究科教務課学生支援チーム大学院学生担当（〒113-8657 東京都文京区弥生1-1-1，Tel 03-5841-5010，daigakuin.a@gs.mail.u-tokyo.ac.jp）；専攻事务通过専攻网站咨询表单（选“大学院入試に関する問い合わせ”），由専攻長栁澤 修一 教授受理。
