## 🎯 入試内容（考什么）
### 語学 / 英語要件
- 一般入试（夏期募集）：学校不设英语笔试，用外部考试成绩换算。全部分野可用 TOEFL iBT（含 Home Edition，只用 Test Date 成绩）、TOEIC L&R 公开考试、IELTS；TOEIC L&R IP 只限水産生物資源分野和海洋未来科学コース水産系；TOEFL ITP 不受理。成绩须为考试日之前3年以内受检。
- 提交：出願时交成绩证明原件（之后归还）或数字版公式认定证的打印件（TOEFL iBT Test Taker Score Report、TOEIC L&R Official Score Certificate、IELTS Test Report Form 等）。出願时来不及交、或想换成之后新考的成绩的，要事先向大学院係提出。
- 配点：情報データ科学、化学·物質科学、環境レジリエンス工学系、スマートシティデザイン、電気·機械システム为 50 分，環境系 150 分，水産生物資源 180 分。换算后的得分以英语配点为上限；要项没有公布换算式和最低分。
- 一般入试（冬期募集）：收的考试种类、有效期、提交方式与夏期相同（TOEIC L&R IP 同样只限水産生物資源分野和海洋未来科学コース水産系）。
- 推荐入试：情報データ科学分野不用交英语成绩（只有水産生物資源、スマートシティデザイン等一部分分野要交）。
- 外国人留学生入试：不用交英语成绩。部分分野在口述试验里问英语，见下表。

### 日本語要件
- 一般入试（夏期募集·冬期募集）：要项没有要求提交日语成绩（JLPT、EJU 等都没有提到），也没有写明试题和作答使用的语言。
- 外国人留学生入试不要求 JLPT、EJU 等日语成绩，日语能力在口述试验里评价（情報データ科学分野、環境レジリエンス分野的口述说明里写明评价日语能力）。
- 願書上可以选面试和口述试验用日语还是英语。社会人入试的情報データ科学分野写明用日语提问。
- 日语和英语以外的书类要附日文或英文译文。

### 口述試験 / 面接
外国人留学生入试（2026/12/23、12/25 实施）的配点：水産生物資源分野为小论文 90＋面试 10；其余分野为口述试验 70＋面试 30。小论文可用日文或英文，可带语言词典（电子词典不行）。

| 分野 | 口述试验问什么（留学生入试） |
|---|---|
| 情報データ科学 | 就英语、数学、信息科学或数据科学提问，评价基础学力、专门知识和日语能力 |
| 化学·物質科学 | 说明毕业研究或相当的调查活动，考查对研究背景和定位的理解及基础·专门知识 |
| 環境レジリエンス（工学系） | 基础学力问数学和英语；专门知识问出願时选的1科（结构力学、地基力学、水理学、都市规划学）；也问日语能力 |
| 環境レジリエンス（環境系） | 面试时用7分钟说明毕业研究和入学后的研究计划（带 PPT 的 U 盘和资料），再就内容提问；也问日语·英语能力。研究计划要事先和指导予定教员商量 |
| スマートシティデザイン | 基础学力问数学和英语；专门知识问结构力学或材料力学 |
| 電気·機械システム | 说明毕业研究或相当的调查活动；对母语不是英语的考生另外评价技术英语的理解 |

- 面试为多名面试官的个人面试，参考出願书类评价志望动机、学习意欲、修学情况和社会性。面试成绩特别低的可能不合格。
- 住在日本国外的考生可能可以用网络考试，要事先和指导予定教员商量；水産生物資源分野不实施。
- **官方形式**：一般入试（夏期募集）機械系为书面面试（ペーパーインタビュー，2026/8/27 13:30–14:00，50分），以书面回答评价志望动机、学习意欲、对分野的适性、一般知识和社会性；情報データ科学分野的面试为多名面试官的个人面试，100 分，参考出願书类综合评价志望动机、学习意欲、对分野的适性、一般知识和社会性；外国人留学生入试为面试 30 分＋口述试验 70 分，内容见上表，语言在願書上选日语或英语。
