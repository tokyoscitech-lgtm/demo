## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 所有选拔区分都不考学校自己的外语笔试，用外部考试成绩换算成外语分数。一般選抜、社会人、学部3年次生、自己推薦型、推薦、高専専攻科只能用英语；外国人留学生特別選抜可选英语或日语。
- TOEIC L&R（公开考试或 IP 考试，含カレッジTOEIC）：须为 2024年4月以后的成绩（公开考试为第350回以后）。交公式认定证原件、数字认定证打印件或 IP「個人成績表」原件之一；在线 IP 没有成绩单，打印成绩 PDF 提交。原件受理后退还。TOEIC S&W、TOEIC Bridge 不受理。
- TOEFL iBT：须为 2024年4月以后的成绩。从 ETS 账户（My TOEFL Home）下载打印 Test Taker Score Report 同封，并在 ETS 账户选择 DI 代码 7976 在线送分；出願期间最后一天前大学在 ETS 系统里查不到成绩的，不受理出願。予告写明只看 Test Date 成绩、不认 MyBest，送达约需2个月。
- 换算表、配点、最低分：要项只写“将成绩换算”，没有公布换算方法、配点和最低分。
- 国费外国人留学生（研究留学生）、外国政府派遣留学生、JICA 留学生免考学力检查（外语和专门科目）。

### 日本語要件
- 只有外国人留学生特別選抜可以用日语成绩代替英语：日本语能力试验 N1 或 N2（2024年第1回以后，交认定结果及成绩证明书原件或合否结果通知书明信片，原件退还），或日本留学试验「日本語」（考试日前2年以内；第2期有效的是 2024年第2回、2025年第1回·第2回、2026年第1回）。
- 一般選抜等其他区分没有日语成绩要求。试题为日文；外国人留学生特別選抜考专门科目时可带日语·母语纸质词典（电子词典、翻译机不行），本プログラム适用。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：総合情報学専攻入学定员 61 名（2027年4月入学：一般選抜 37 名〔第1期与第2期合计，第1期招满后第2期仍招若干名〕、推薦特別選抜 24 名〔仅第1期，已结束〕，社会人·外国人留学生·学部3年次生·自己推薦型各若干名）。情報工学プログラム的标准定员约 36 名。2026年10月入学只在第1期招一般·社会人·留学生若干名。
- 一般選抜出願资格：大学毕业或2027年3月前预计毕业、学位授与机构授予学士、外国16年课程、文科省指定专修学校等①–⑦；⑧–⑩（大学3年以上在学、外国15年课程、个别审查且入学时满22岁等）须于 2026/10/19 前申请个别审查。
- 第2期可报的区分：一般、社会人、外国人留学生、学部3年次生、自己推薦型（自己推薦型只在本专攻3个プログラム实施）。第1期和第2期可以都报，每次分别出願、缴费。
- 社会人特別選抜：大学毕业后有1年以上（或义务教育后5年以上）社会经验（含家务）；交研究计划书（日文约2,000字或英文约1,000词）和社会人期间活动概要（日文1,200字以内或英文550词以内）。可申请夜间开课等教育方法特例、长期履修。
- 外国人留学生特別選抜：无日本国籍、外国16年课程等；在日本的大学或专修学校毕业（预计）者不能报，要走一般選抜。须交研究计划书（日文约1,000字或英文约500词）、经费支弁书和汇款证明或本人存折复印件、住民票（不在日本的先咨询）。中国「高等教育自学考试」学士须在 10/19 前咨询入试课。
- 学部3年次生特別選抜：2027年3月底在学满3年、修完3年级必修并修得毕业学分4/5以上且其中4/5以上为优（80分以上），须学部长等推荐；入学后按学部退学处理。须在 10/19 前申请资格认定。
- 自己推薦型特別選抜：资格同一般選抜；交自己推荐书（日文约1,000字或英文约500词），不考专门科目。
- 出願书类（一般選抜）：入学志願票（A4 双面彩印）、毕业（预计）证明书、成绩证明书（密封）、TOEIC/TOEFL 成绩材料；外国籍者交住民票。本プログラム的一般選抜不需要研究计划书。证书非日英文的可能要求译文。
- 出願方式：只能网上出願（e-apply），登录·缴费后打印书类，用角2信封以書留·速達寄到 学務部入試課（〒321-8505 宇都宮市峰町350），截止日 16:00 必达；赶不上可在受理期间工作日 9:00–16:00 送到窗口。受験票出願受理后在网上打印。
- 检定料 30,000 日元（便利店、ATM/Pay-easy、网银、信用卡），受理后不退；受灾者和延长奖学金的国费留学生可申请免除。
- 入学料 282,000 日元，授業料 年 535,800 日元（每半期 267,900 日元，均为预定额），保险 2,430 日元（2年）。第2期合格者的入学辞退截止 2027/1/29 必达，入学手续 2027年3月中旬。
- 安全保障出口管理：外国人留学生出願前要通过希望指导教员做事前确认，审查可能耗时较长，结果可能限制研究内容。
