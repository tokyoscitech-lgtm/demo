## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 出願资格要求英语能力充分，提交 TOEFL、IELTS、TOEIC 等能客观证明英语能力的成绩，不另设英语笔试。
- 提交方式：TOEFL iBT（含 Home Edition）打印网上 PDF 成绩单并在 ETS 设定 DI code 8195；TOEIC L&R 打印数字公式认定证；IELTS Academic 交寄给本人的原件；考试机构直送大学的不受理。

#### 日本語要件
- 要项没有要求提交日语成绩；教育研究用英语进行，要项希望入学者渡日前做一定日语准备。
- 提交书类用日文或英文。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：若干名（上一轮为修士本専攻与博士生命理工医療科学専攻合计）。
- 出願资格：日本以外国籍的私费外国人留学生，志望在生命理工医療科学専攻的分野连续修读修士和博士；取得学士学位或入学当年 9/27 前预计毕业，或经个别审查认定同等学力且入学时满22岁（须先受出願资格审查）；须在 9/27 前渡日；修士授予修士（理学）或修士（工学）。
- 要提前准备的书类：指导教员的邮件出願许可；指导计划书（様式 B-3，由指导教员填写并直接交入試課）；专攻分野及研究计划（様式 C-4）；推荐书（在学者由所属大学研究科长级以上、在职者由机构负责人出具，亲笔签名）；英文学位论文（没有的交主要论文、学会摘要等代替）；英语成绩；外国学历者的履歴書（様式 C-2）。
- 出願：把书类 PDF 发到 nyu-grad-02.adm@tmd.ac.jp，同时把原件用書留速達寄到入試課，两者都须在截止前到达；检定料 36,000 日元汇款到三菱UFJ銀行本店（普通 7897115，国立大学法人東京科学大学），汇款和兑换手续费自付。
- 咨询：東京科学大学 教育推進部 入試課 湯島大学院入試グループ（〒113-8510 東京都文京区湯島1-5-45），Tel +81-3-5803-4924，Fax +81-3-5803-0106，nyu-grad-02.adm@tmd.ac.jp（原则上用邮件）；教务 grad02@ml.tmd.ac.jp；入学料·授業料 suitou.adm@tmd.ac.jp。合否不接受电话询问。
- 并愿：尚未核实是否可同时报考其他专攻或选拔类别。请以本年度募集要项或招生窗口答复为准。
