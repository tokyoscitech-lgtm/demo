## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 推薦入试和一般入试（含2026年10月入学一般入试）：英语一律以外部 TOEIC 成绩评价，出願时随书类提交成绩复印件；学内没有英语笔试。社会人入试和外国人留学生入试的要项没有要求提交 TOEIC。
- 可用的成绩：TOEIC Listening & Reading 公开测试（公式认定证复印件，打印的数字认定证 PDF 也可）；TOEIC L&R IP 测试的对面实施版（score report 复印件）。在线实施的 IP 测试不受理；要项只认 TOEIC，TOEFL 和 IELTS 不在可用之列。
- 有效期：2024/4/1 以后受检的成绩。考过多次的交最高分的一份；受理后不能更换。
- 只收纸质复印件，不接受邮件或 URL 等电子提交；误交原件不退还。
- 要项没有写 TOEIC 的最低分、换算方法和配点。

### 日本語要件
- 要项没有要求提交日语成绩（JLPT 等）。外国人留学生入试的面接及口头试问可用日语或英语；要项注明授课主要用日语进行。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 建築・デザイン・マネジメント（配点官方未公布，60分钟） | 3分野各出1题、3题选1，须选希望研究室所属的分野：建築計画・デザイン＝建筑计划、城市计划、建筑史与意匠；建築構造＝构造力学、地震工学、建筑构造；マネジメント＝城市管理、社区管理 | 2027募集要项 |

- 一般入试按外部英语考试成绩、笔试、面接及口头试问、成绩证明书等综合判定；要项没有公布各项配点和合格基准。
- 题目倾向：官方公开了令和8年度试题的解答例和出题意图，可据此把握各分野的出题范围；没有找到体验记。

### 口述試験 / 面接
- **官方形式**：推薦入试为面接及口头试问（约20分钟），问毕业研究和入学后的研究计划。第1回一般入试（含10月入学）为面接及口头试问（约10分钟），问毕业研究和大学院研究计划，不能用电脑和资料（经许可可用黑板）。社会人入试（约20分钟）问志望动机、研究与技术业绩、研究计划；外国人留学生入试（约20分钟）问志望动机、毕业研究和研究计划，可用日语或英语。
- **実際に聞かれた内容**：没有找到本専攻的体验记。

## 📝 详细信息
### 出願資格 / 定員
- 2027年4月入学的入学定员为12名：推薦入试6名、第1回一般入试6名、社会人·外国人留学生入试若干人；另设2026年10月入学一般入试3名、外国人留学生若干人。第2回一般入试本年度不实施。
- 出願资格（一般）：大学毕业或2027年3月前预计毕业、学位授与机构授予学士、在外国完成16年学校教育等；大学在学3年以上成绩优秀、个别资格审查（22岁以上）等须先受入学资格审查（第1回：6/16–6/19 提交，7/1 通知）。
- 推薦入试：2027年3月预计毕业、成绩优秀、学长或学部长可推荐并承诺合格后入学者。
- 社会人入试：2027/4/1 时在研究机构、教育机构或企业等工作满1年以上的研究者、教育者、技术者；须交入学确约书、研究（希望）计划书和职务经历书（附业绩资料）。
- 外国人留学生入试：非日本国籍，日本的大学毕业者（含预计）不能报。
- 出願书类（共通）：入学願書、写真票（4×3cm）、受験票、受験票回信信封（长3，贴110日元邮票，海外寄送免）、标签票、检定料收纳证明书；一般入试另交毕业（预计）证明书、成绩证明书、TOEIC 成绩复印件。用纸从"大学院受験生の方"页下载，不印纸质要项。
- 出願方式：书类一并以书留邮寄（必达）或持往山形大学工学部入試担当（〒992-8510 山形县米沢市城南4-3-16）。没有网上出願。
- 检定料 30,000 日元（国费外国人留学生免），信用卡或便利店支付，手续费自负。
- 入学料 282,000 日元，授業料 年额 535,800 日元（预定额）。
- 本専攻是雇用保险"教育训练给付制度"的厚生劳动大臣指定讲座（面向社会人的管理教育），符合条件者修了后可向 Hello Work 申请，最多10万日元；咨询工学部教育支援担当 0238-26-3015。
- 考场：山形大学工学部（米沢市）。考试开始30分钟前到场，开始后20分钟不能入场，中途不能退场；手机须关机收进包里；考试当天禁止开车进校。
- 外国政府或法人影响较强者可能被要求提交安全保障出口管理申告书。
- 咨询：山形大学工学部入試担当，Tel 0238-26-3013，yu-kounyu@jm.kj.yamagata-u.ac.jp。
