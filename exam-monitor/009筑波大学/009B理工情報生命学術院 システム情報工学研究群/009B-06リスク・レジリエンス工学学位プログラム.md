## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 8月实施、1-2月实施的一般入试相同：出願时提交外部英语检定成绩单，作为外国語评分，配点 200 分。
- 可用 TOEIC Listening & Reading（公开考试）、TOEFL iBT（Home Edition 也可）、IELTS Academic（纸笔版或机考版）。成绩须为 2024年7月以后受检，成绩单上要印有本人照片。
- 只收原件（或由考试机构直送的成绩）；TOEIC L&R 的数字版公式认定证可以，其他成绩的复印件不收。成绩单不退还。
- 出願时没有交出符合条件的成绩单的，不论理由，外国語按缺考处理，不进入选考。在海外大学毕业的考生同样要交。
- 本プログラム不适用英语成绩免除（免除只适用于研究群内另外两个プログラム）。
- 要项没有公布成绩到 200 分的换算公式，也没有规定最低分。
- 7月实施（推薦）和社会人特別選抜不需要英语成绩。

### 日本語要件
- 要项没有要求提交 JLPT 等日语成绩，也没有写明口述试验使用的语言。
- Web 出願时填写的研究计划可用日文（约1000字）或英文（约500词）。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 专门科目笔试 | 不实施。7月实施（推薦）、8月实施、1-2月实施都没有笔试 | 2027募集要项 |
| 外国語（200分） | 8月实施、1-2月实施的一般入试：外部英语考试成绩换算，不另设考试 | 2027募集要项 |

- 8月实施和1-2月实施的一般入试总分 500（外国語 200＋口述试验 300）。7月实施（推薦）只有口述试验 200 分。社会人特別選抜（8月实施、1-2月实施）只有口述试验 300 分。
- 合格最低分官方没有公布。
- 题目倾向（体验记，非官方）：没有找到本プログラム考生写的体验记。

### 口述試験 / 面接
- **官方形式**：7月实施（推薦）、8月实施、1-2月实施都是对面的个别面接，就专门分野和本人的志望等进行试问；一般入试配点 300 分，推薦入试 200 分。要项没有写明面接的分钟数、是否要做口头发表或使用幻灯片。集合时间不能个别调整。
- **実際に聞かれた内容**：没有找到本プログラム的体验记，暂无可归纳的内容。因为专门知识只在口述试验里考，建议向志望教员确认需要准备的范围。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：推薦入试（7月实施）13名、一般入试（8月实施）14名、一般入试（1-2月实施）1名、社会人特別選抜（8月实施）3名、社会人特別選抜（1-2月实施）1名。
- 入学时期：7月实施和8月实施为 2027年4月入学；1-2月实施可选 2027年4月或10月入学。
- 出願资格：日本4年制大学毕业或入学前预计毕业、在外国完成16年学校教育、在外国大学取得相当于学士的学位（修业3年以上课程）、或通过本校个别出願资格审查者等。
- 个别出願资格审查的申请截止日：7月期 2026/5/20（已过），8月期 2026/7/3（已过），1-2月期 2026/11/24（周二）；用邮件向システム情報エリア支援室大学院教務提出。
- 推薦入试的出願要件（7月实施，已结束）：学士课程取得学分中 A（优）约占七成以上，或在特定研究领域有优秀成绩并能提交依据资料；需要所属大学的推薦书或自己推薦书，并确约合格后入学。
- 社会人特別選抜的要件：入学前一个月时点有1年以上社会经验（常勤、非常勤均可，学生打工不算）；出願时要告知志望教员是以社会人名额出願。
- 所有出願者都必须事先取得志望指导教员的内诺；填写第2志望教员的，也要取得该教员的内诺。合格后没有特别联系时，配属到第1志望教员的研究室。
- 「リファレンス番号」：外国籍者（永住者、特别永住者除外）、外国的大学·企业·政府机构出身者、属于特定类型者，要在取得内诺后由教员告知编号，并在 Web 出願系统里输入。本プログラム需要。
- 出願书类：Web 入力（含研究计划，日文约1000字或英文约500词）、毕业（预定）证明书、成绩证明书、证件照（JPEG）、外部英语考试成绩单（一般入试）；外国大学毕业者另交学位取得（预定）证明书，在职者或他校在学者交受験·就学承认书。要项没有要求另交志望理由书。
- 出願方式：先在 Web 出願系统入力并缴检定料，再把书类邮寄到システム情報エリア支援室，截止日必达。
- 检定料 30,000 日元，信用卡或便利店支付，缴后不退。
- 入学料 282,000 日元；授業料 年 535,800 日元，外国人留学生为年 608,800 日元。
- 所有出願者要在 Web 出願时回答安全保障出口管理（みなし輸出）的特定类型确认。
- 同一个月可以报考多个プログラム，但口述试验时间不会因此调整，时间冲突就无法都参加。
- 成绩开示：只对不合格者本人开示总分，申请期间 2027/5/1–5/31，邮寄申请。
- 修了后授予修士（工学）。
- 另有面向 2026年10月入学的7月实施一般入试·社会人特別選抜，属于上一年度（2026年度）的募集，不在本页范围内。
- 咨询：入试相关 entexam@risk.tsukuba.ac.jp；出願资格相关 admission.grad@un.tsukuba.ac.jp。
