## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各日程相同：不另设英语笔试，用 TOEFL iBT（含 Home Edition）成绩评价。
- 送分：向 ETS 申请把 Institutional (Official) Score Report 送到研究科（DI code 1113），其他代码无效；出願时在 WEB 出願系统里填写 Appointment Number、受检日和分数，不必交 Test Taker Score Report。
- 有效受检期间（向 ETS 申请送分也须在此期间内完成）：A日程 2024/8/1–2026/6/13（已过）；B日程 2025/2/1–2026/11/15。
- 送过多次的，出願时只指定一次。TOEFL ITP 不受理，MyBest Scores 不采用。
- 要项和専攻案内都没有规定最低分、换算方法和配点。

#### 日本語要件
- 要项和専攻案内都没有要求提交日语成绩（JLPT 等），外国人考生走一般选拔也不用交；研究科不设单独的外国人留学生特别选拔。
- A日程専門科目用日语出题，B日程日英并记出题；两个日程都可以用日语或英语作答。口述使用的语言官方没有写明。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：A日程（2027年4月入学）17名，B日程（2027年4月入学，仅外国学历者）若干名；本専攻不实施 10月入学。
- 出願资格（A日程）：日本的大学毕业或 2027/3/31 前预计毕业；在外国完成 16 年学校教育；在外国取得相当于学士的学位（3 年以上课程）；文部科学大臣指定者；学位授与機構授予学士学位；经个别入学资格审查认定且 2027/3/31 满 22 岁。
- B日程：
  - 出願资格只限上面的“在外国完成 16 年学校教育”和“在外国取得相当于学士的学位”两项。
  - 日本的大学毕业（预定）者中，从初等、中等教育起都在日语以外的语言环境中受教育的，须在 2026/10/7 前申请出願对象审查，获准后才能报（已截止）。
  - 个别入学资格审查和受验照顾的申请截止 2026/10/7（已过）。
- 志望填写：在 WEB 出願系统里按「教員並びに専門分野一覧」选专门分野和指导教员，最多填到第3志望；第2、第3志望可以选同一分野的其他教员，没有可以不填。一览会因人事变动更新，出願前要看最新版。
- 出願书类（都在 WEB 出願系统里填写或上传 PDF）：入学願書（含 3 个月内的证件照）、出身大学成绩证明书、毕业（预定）证明书（写明学位名和授予日）、检定料缴纳证明、国费留学生证明书（仅该当者）、TOEFL 成绩。本専攻没有另外指定研究计划书等専攻独有书类。证明书不是日文或英文的要附译文，原件在入学手续时提交。
- 出願方式：只能通过 WEB 出願系统，没有邮寄或窗口受理；书类不齐不受理，出願期间结束后不能修改。受験票自己用 A4 纸打印，考试当天带上；B日程受験者心得到 2027/1/13（周三）还没收到的要联系教務課。
- 检定料 30,000 日元，银行汇款（邮储银行除外）、便利店、信用卡、Pay-easy 均可；缴纳期间 A日程 2026/4/13–6/23（已过），B日程 2026/10/5–11/25。国费留学生免缴；缴后不退。
- 并愿：同一日程只能报研究科的一个専攻。
- 入学料 282,000 日元，授業料 年 535,800 日元（前期 267,900 日元），均为预定额；国费留学生免缴。B日程合格者 2027年2月下旬收到入学手续通知，3月上旬办理；住在国外的要注意合格到入学的时间短，在留资格可能来不及。
- 咨询：専攻的问题问専攻主任 松田 怜 教授（Tel 03-5841-5355，bee.shunin@mail.en.a.u-tokyo.ac.jp）；出願手续问农学生命科学研究科教務課学生支援チーム大学院学生担当（〒113-8657 東京都文京区弥生1-1-1，Tel 03-5841-5010，daigakuin.a@gs.mail.u-tokyo.ac.jp）。
