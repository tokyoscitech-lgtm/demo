## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 8月入试（一般·社会人·外国人学生）：不另设英语笔试，用外部成绩评价——提交 2023/4/1 以后受验的 TOEIC 公式认定证原件（数字公式认定证可）或 TOEIC IP 的 Score Report（限线下实施），结果计入综合判定。
- 推荐选拔（一般学生、外国人编入学生）不看 TOEIC。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 外国人学生和一般学生考同一套专门科目和小论文，试题为日文。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 電気電子工学1 | 电磁学（静电场、电流与磁场、电磁感应）、电气电子电路（交流电路的复数计算、电路解析、晶体管等效电路、放大·振荡电路） | 10:00–11:20，80分钟 |
| 電気電子工学2 | 数学：线性代数、线性微分方程、复变函数、向量分析、傅里叶级数·傅里叶变换、拉普拉斯变换、微积分 | 13:00–14:20，80分钟 |
| 小论文 | 各科目群共通 | 14:50–15:50，60分钟 |
| 推荐选拔（一般学生）：小论文 | | 10:30–11:30，60分钟 |

- 8月入试出願时从科目群 A–F 中选1组，与本分野对口的是科目群A（電気電子工学1·2）；外国人学生与一般学生考同样的科目。
- 8月入试：学力试验、TOEIC 成绩、面接和成绩证明书综合判定；社会人以口述试验代替学力试验，另看所属机构推荐书。
- 推荐选拔（一般学生）：小论文、面接、成绩证明书和推荐书综合判定。
- 题目倾向（2026年度入学过去问）：電気電子工学1 为4道大题（交流电路复数阻抗与相位、运放电路传递函数与频率特性、同心球电容器的电容与电场、直线电流磁场与互感）；電気電子工学2 为3道大题（矩阵的秩·行列式·特征值、留数与复积分、傅里叶级数），与知能情報2 同一套数学题；小论文用日语写约600字，谈将来想成为怎样的研究者·技术者并联系 DX·GX·LX·MX 之一。

### 口述試験 / 面接
- **官方形式**：8月入试（一般·外国人学生）：学力试验次日面接；社会人：口述试验（主要针对研究计划书）＋面接；推荐选拔（一般学生）：小论文后面接；推荐选拔·外国人编入学生：面接＋口述试验（专门科目），结合成绩证明书和推荐书判定，考试和发表都在姫路工学キャンパス。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：电气电子工学·知能情报分野合计约40名（一般·社会人·外国人学生，分野名额为目安；工学専攻合计120名）；推荐选拔（一般学生）两分野合计约10名（工学専攻合计30名）；推荐选拔·外国人编入学生各分野若干名；2026年10月入学各分野若干名（与8月入试同一场考试）。变更点：工学専攻合计从2026年度的150名减为120名，两分野合计从50名减为约40名。
- 出願资格：一般学生为大学毕业（含 2027/3 预定）、外国16年课程修了等；外国人学生限以在大学院接受教育研究为目的入境的外国人，日本大学毕业或预定毕业者不属于此区分（报一般学生）；外国15年课程修了等须先办出願资格事前审查，书类先交希望的研究指导教员协议，2026/7/6 前提交学務課（非独立出願）；推荐选拔·外国人编入学生限从海外编入日本大学、持「留学」在留资格、2027/3/31 前毕业预定者；公费（国费·县费等）留学生可能在2月另行选考。
- 要提前准备的书类：TOEIC 公式认定证或 IP Score Report；社会人交所属机构推荐书、承诺书和研究计划书；推荐选拔（一般学生）交学科长或指导教员的推荐书；推荐选拔·外国人编入学生交在籍大学学科长或指导教员的推荐书和兵庫県立大学指导预定教员的推荐书。
