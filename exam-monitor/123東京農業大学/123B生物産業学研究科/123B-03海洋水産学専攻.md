## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 一般入试（10月入学·1期·2期）：在校内笔试中考外国语，科目为英語（本専攻共通）。配点与考试时长要项没有公布。
- 生物産業学研究科不要求提交 TOEIC·TOEFL 等外部英语成绩；要项中「英语成绩证明」只针对世田谷·厚木的部分専攻，不适用于本専攻。
- 社会人特別選抜：笔试考外国语（英語）和小論文，另加书类选考与口述。

### 日本語要件
- 要项没有规定 JLPT·EJU 等日语成绩的最低要求。外国人志願者可以任意提交日语能力证明（JLPT 认定书、日语学校的证明等）的复印件，不提交也可以出願。
- 考试和口述用日语进行。要项总则写有「只有外国人留学生可以用日语作为外国语科目受验」，但生物産業学研究科的外国语科目表只列英语，是否适用于本研究科要项没有明说。

### 口述試験 / 面接
- **官方形式**：一般入试1期·2期在笔试同日实施口述，配点·时长未公布；社会人特別選抜的口述包括研究计划的发表和专门知识问答；本専攻不实施学内推薦。口述用日语进行。
- **実際に聞かれた内容**：没有找到公开的考生体验记，实际问题不明。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：入学定员5名；一般入试1期 4名（已结束），2期 1名；本専攻不设学内推薦；社会人特別選抜 若干名；2026年10月入学一般入试：要项募集人员表中本专攻一栏未能确认设有名额（已结束）。
- 专攻名称：「海洋水産学専攻」并不是2026/2027年新设的名称，大学院入学者数统计中令和2年度（2020年度）起就以此名称列出，2027年度照常招生。
- 一般入试出願资格：大学毕业或2027年3月（10月入学为2026年9月）前预计取得学士学位，或在外国完成16年学校教育等；资格(9)–(11)须事先接受出願资格认定。
- 社会人特別選抜资格：满足一般出願资格，原则上在企业等工作1年以上，并在志望専攻的专门领域有实务经验。
- 出願书类：志願者確認票（从大学出願ネット打印）、入学志願者調書 Form1（须有希望指导教授的确认印，海外居住者可用受入许可邮件打印件代替）、毕业（预计）证明书和成绩证明书（发行后3个月以内的原件）；学内推薦和社会人另交研究计划书 Form2，学内推薦另交推荐书 Form4，社会人和外国人（本学毕业预定者除外）交履历书 Form5，外国人交护照复印件贴付书 Form6。中国的学校毕业者须交学历认证报告书；英语·日语以外的证明书须附翻译和公的证明，网上取得的证明书和彩色复印件原则上不收。
- 出願方式：在「大学出願ネット」完成 WEB 登録并缴费，同时把书类装入角形2号信封，以简易书留·速达邮寄或送到窗口，出願期间最终日必达；信封上写研究科名·専攻名·课程·姓名。
- 检定料 30,000 日元，另需手续费（信用卡 700 日元、便利店 350 日元、Pay-easy 500 日元）；书类里夹现金等不受理，检定料不退还。
- 受验票从 WEB 出願系统的确认邮件打印后带到考场。考试开始后30分钟内未入场的原则上不能参加之后的考试；有不正行为者当年度全部入试成绩作废。
- 学费（博士前期首年）：入学金 270,000 日元、授業料 660,000 日元、実験実習演習費 300,000 日元、整備拡充費 210,000 日元、学生厚生費 20,600 日元、其他诸会费 20,000 日元，首年合计 1,480,600 日元；2年级以后授業料等会增加。4月入学者在 2027/2/16（周二）–3/3（周三）缴纳，入学手续 2027/2/22（周一）–3/3（周三）最终日必达。
- 奖学金：第一种奖学生减免授業料和整備拡充費各一半；本学学部毕业生免入学金（第二种）；私费外国人留学生中成绩优秀且经济困难者可申请第三种（入学金·授業料·整備拡充費全额减免，名额在定员一半以内）。
- 长期履修制度：在职者可申请最长4年的博士前期课程，须事先与指导教员商量并在出願时提交相关书类，只限4月入学。
- 咨询：生物産業学研究科 学生教務課（北海道オホーツクキャンパス，〒099-2493 北海道網走市八坂196），Tel 0152-48-3813，邮箱 o-kyomu@nodai.ac.jp（平日 8:30–17:00）；WEB 出願系统的问题发邮件给世田谷キャンパス学務課 innogaku@nodai.ac.jp。
