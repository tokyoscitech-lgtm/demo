## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般选拔不另设英语笔试，出願时必须提交 TOEIC L&R 公开测试、TOEFL iBT 或 IELTS 的成绩原件，作为合否判定的参考资料。
- 有效期：口头试问日前2年以内受检（以受检日为准）。
- 提交：TOEIC 交公式认定证（2023年4月以后国内受检的交数字认定证打印件，背面写 URL；韩国 TOEIC 网页成绩不受理）；TOEFL iBT 须在出願期内经 ETS 电子送分到 DI code B212，并附 Test Taker Score Report 的 A4 打印件；IELTS 交 Test Report Form 原件。
- 推荐型选拔：英语成绩任意提交，但母语不是日语的人英语成绩和 JLPT 成绩至少交一种。

#### 日本語要件
- 一般选拔不需要提交日语成绩，母语不是日语的考生可以任意附交 JLPT 成绩证明书原件，作为选考参考。
- 研究科授课基本用日语，入学后需要一定的日语能力；出願书类可以用日文或英文填写。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 各回：不设笔试 | 口头试问和出願书类综合评价数据科学的基础知识与技术、研究意愿、英语能力和交流能力 |  |

- 志願理由書和研究计划书在口头试问中被参照，也是合否判定的参考资料。
- 变更点：2027年4月起修士课程改为博士前期课程，入学定员由15名增至30名，同时设博士后期课程。

### 口述試験 / 面接
- **官方形式**：各回相同：口头试问（面接），在滝子（山の畑）キャンパス，周六或周日中由研究科指定时间，参照志願理由書和研究计划书。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：30名（推荐型选拔和一般选拔、第1–3回合计）；第2回只在第1回手续者不满定员时、第3回只在第1·2回合计不满30名时实施。
- 出願资格：日本国内大学毕业（含2027年3月预计）或外国16年学校教育等（ア）–（ク）；大学3年在学或外国15年课程（ケ）、个别审查（コ）须先过资格审查（第3回 2026/11/13–11/20 必达，非独立出願）；前一回不合格或上一年度考过的也可以再报，但须重新事前面谈；国外出願须由日本国内的代理人办理。
- 要提前准备的书类：英语外部成绩原件；志願理由書（所定用纸，A4 约1页）；研究计划书（所定用纸，A4 1–2页，双面印刷，有研究实绩的写上）；有工作经历者的职务经历书；外国籍者交住民票（无个人番号），国外在住者交护照复印件。
- 出願：角形2号信封速达挂号邮寄到学生課（入試）データサイエンス研究科担当，期限内必达，不设窗口；检定料 30,410 日元（含速达邮费410日元），在银行窗口用所定振込依頼書汇款，ATM 和ゆうちょ銀行不可。
