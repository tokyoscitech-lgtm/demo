## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 不另设英语笔试，用出願时提交的 TOEFL iBT 成绩判定外国语（含 TOEFL iBT Home Edition）；IELTS 等其他考试不受理，MyBest Scores 能否使用官方没有写明。
- 提交三步缺一不可：①在 ETS 账户把 Official Score Report 送到研究科（DI Code 8426，Department 42 Medicine）；②在 WEB 出願系统登记 Appointment Number 和受检日；③上传同一次考试的 Test Taker Score Report（PDF，考后约 8 天可下载）。
- 有效期：2024/8/1 以后受检的成绩；考过多次的只能上传 1 份。
- 官方成绩未确认、上传成绩与官方成绩不一致、受检日早于有效期的，按没有参加外国语审查处理；研究科不告知成绩是否送达。
- 官方没有公布最低分、换算方法和配点。
- 变更点：2026年度及以前由専攻自己出英语题，2027年度起改为提交 TOEFL iBT 成绩。

#### 日本語要件
- 外国人（日本的大学毕业或预计毕业者除外）须提交日本語能力証明書（由指导教员等出具，或日语学校证明、日本語能力試験合格证复印件）；官方没有规定 JLPT 等级或分数。
- 笔试和口述的使用语言、可否用英文作答，要项和入学試験案内没有写明。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：2027年度8月入试合计 30 名（2年コース约 20 名，1年コース约 10 名），成绩不够时可能不足额；本年度没有其他轮次。
- 出願资格：日本的大学毕业或 2027/3/31 前预计毕业；在外国完成 16 年学校教育；在外国取得相当于学士的学位；文部科学大臣指定的教育设施修了；由大学改革支援·学位授与機構取得学士学位；或经个别资格审查认定、入学时满 22 岁。个别资格审查须先联系事务部，书类 2026/6/5（周五）截止（已截止）。
- 1年コース另需保健医疗相关实务经验：4年制大学毕业者 3 年以上，6年制（医·齿·兽医·药学）毕业者或修士修了者 2 年以上，医师等的临床研修也算；希望事先确认资格的，2026/6/5（周五）必达提交履历书和全部任职单位的在职期间证明书（已截止），结果在出願期间前通知。
- 出願书类（全部在 WEB 出願系统上传）：入学願書、证件照（jpg，3 个月内、未修图）、检定料缴纳凭证、成绩证明书、毕业（预计）证明书、TOEFL 成绩；1年コース加在职期间证明书；在职入学者加学习计划书（A4 2 页）；外国人加日本語能力証明書；改姓名的加证明。证明书原件在合格后提交。
- 要项没有要求提交研究计划书，也没有填写志望研究室或分野的规定。
- 检定料 30,000 日元（日本政府奖学金留学生免缴），可用银行汇款、便利店、Pay-easy、信用卡，手续费自付。
- 入学料 282,000 日元，授業料 前期 267,900 日元（年额 535,800 日元），均为 2027年度预定额；日本政府奖学金留学生免缴。
- 入学手续：2027年2月下旬邮件通知手续办法，3月上旬缴入学料并交书类，逾期视为放弃；在职入学的交单位承诺书；外国人须在手续前取得可以入学的在留资格。
- 需要考试照顾的，2026/6/5（周五）前向事务部申请（已截止）。
- 咨询：医学系研究科学務チーム大学院担当（〒113-0033 東京都文京区本郷7-3-1），in.m@gs.mail.u-tokyo.ac.jp；研究科入试页另有咨询表单。
