## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般選抜·私費外国人留学生選抜（两者相同）：
  - 不另设英语笔试，用 TOEFL-iBT 或 TOEIC L&R 成绩换算为英语得分（100分）；两种都交时取换算后较高的一个。
  - 按要项换算表换算（TOEIC 990＝TOEFL-iBT 120＝100分，TOEIC 10＝TOEFL-iBT 0＝0分）；2026年1月起的 TOEFL-iBT 新分数（1–6）仍按旧的 0–120 分制换算，不用 MyBest scores。
  - TOEFL-iBT 由 ETS 直接送分（DI code 8549，考试前一天前申请免费）；TOEIC L&R 交公式認定証原件（数字认定证打印件也可），TOEIC S&W 不认。成绩须在出願书类受理期内（2026/7/17 16:00 前）到达，未到按书类不备处理。
  - 有效期为出願期间前2年以内；TOEFL-ITP、TOEIC-IP 等团体受验成绩不受理。
  - 选择社会人口述試験的社会人不交成绩，英语在口述中考查。
- 推薦選抜：不收英语成绩。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 一般選抜的専門試験用日语出题，可用日语或英语作答（英文版要项）；私費外国人留学生選抜的试题日英并记，可用日语或英语作答。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 量子物性（問題10） | 量子力学、固体物理、磁性材料·电子材料的量子论；必答 | 9:00–12:00，180分钟（3题合计） |
| 材料物理化学（問題11） | 热力学、材料平衡论、迁移速度论、反应速度论（合成·表面处理）；必答 | 同上 |
| 金属材料学（問題12） | 材料物理学、材料组织学、衍射晶体学、力学物性论、材料强度学；必答 | 同上 |
| 私費外国人留学生選抜：専門試験（300分） | 問題5（金属材料学）和問題6（量子物性・材料化学：固体物理、量子力学、磁性材料、热力学、反应速度论）2题都必答；日英并记 | 10:00–12:00，120分钟 |

- 一般選抜：問題10–12 三题全部必答，専門試験合计300分。
- 一般選抜·私費外国人留学生選抜：専門試験 300＋英语 100，结合面接（5级）和成绩证明书综合判定，按 A·B·C 三级评定，A 为合格；缺考任何一项不能合格。推薦選抜不设笔试，按口述試験、推荐书、成绩证明书和志望理由书综合判定。

### 口述試験 / 面接
- **官方形式**：一般選抜：个人面接，考查研究意欲、适性、人物等，按5级评价，不计分；社会人（不在大学就读者）可事先申请以社会人口述試験（8/20，专门科目、业绩报告书和英语）代替専門試験和英语成绩；私費外国人留学生選抜：个人面接，内容和评价方法与一般選抜相同；推薦選抜：口述試験，先用5分钟以内发表毕业研究进展（可用投影仪），再问发表内容和专业基础知识并面接，按5级评价。

### 出願資格 / 定員
- 募集人员：一般選抜：本プログラム受入目安22名程度（工学専攻合计386名）；推薦選抜：14名程度（工学専攻合计220名）；私費外国人留学生選抜：若干名。
- 出願资格：大学毕业（含2027/3预计）或外国16年学校教育等；资格(13)个别审查须在2026/5/11 16:00前申请（非独立出願，已过）；私費外国人留学生選抜限没有日本国籍（永住者除外）、持有或可取得「留学」资格、且不是日本的大学毕业（含预计）的人；推薦選抜须2027/3毕业预计、成绩优秀、取得学长·学部长·学科长等役職者推荐并确约入学；社会人想用社会人口述試験须在2026/6/19 16:00前申请审查。
- 要提前准备的书类：志望理由书（所定样式）；TOEFL-iBT 送分或 TOEIC L&R 原件；類型該当性の自己申告書（安全保障，全员提交）；外国人须事先把所定履歴書交给希望的指导教员（一般·私費 2026/6/12、推薦 4/13 前）；中国的学校出身者的成绩和学历须由 CHSI 直接把英文认证报告发到入試課（nit.nyushi@adm.nitech.ac.jp），官方建议提前2个月以上申请；推薦選抜另需役職者推荐书（所定样式）。

- 并愿：每次出願只选一个プログラム；推薦選抜不合格者可以按一般選抜要项另行出願；在日本的大学毕业（含预计）的外国人不能报私費外国人留学生選抜，只能报一般選抜；一般選抜与私費外国人留学生選抜同日考试，2027年度两份要项均未说明能否同时出願。指导教员按希望顺序填写（推薦·私費可填到第3希望，推薦限同一プログラム、私費限同一研究分野），面接时再确认，不一定分到第1希望。
