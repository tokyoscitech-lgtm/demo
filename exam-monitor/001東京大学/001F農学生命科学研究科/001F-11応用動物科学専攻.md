## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各日程相同：不另设英语笔试，用 TOEFL iBT（含 Home Edition）成绩评价。
- 送分：向 ETS 申请把 Institutional (Official) Score Report 送到研究科（DI code 1113），其他代码无效；出願时在 WEB 出願系统里填写 Appointment Number、受检日和分数，不必交 Test Taker Score Report。
- 有效受检期间（向 ETS 申请送分也须在此期间内完成）：A日程 2024/8/1–2026/6/13（已过）；B日程 2025/2/1–2026/11/15。
- 送过多次的只指定一次。TOEFL ITP 不受理，MyBest Scores 不采用。官方没有公布最低分和换算方法。
- 变更点：2026年度入试的 A日程是在研究科内考 TOEFL ITP，2027年度起 A、B 两日程都改为提交 TOEFL iBT 成绩。

#### 日本語要件
- 要项和専攻案内都没有要求提交日语成绩（JLPT 等），外国人考生走一般选拔也不用交；研究科不设单独的外国人留学生特别选拔。
- A日程専門科目日英并记出题，B日程全英文出题；两个日程都可以用日语或英语作答。口述使用的语言官方没有写明。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：A日程 19名，B日程若干名；符合资格者 A日程可选 2026年10月入学、B日程可选 2027年10月入学，其余为 2027年4月入学。
- 出願资格：日本的大学毕业或 2027/3/31 前预计毕业；在外国完成 16 年学校教育；在外国取得相当于学士的学位（3 年以上课程）；文部科学大臣指定者；学位授与機構授予学士学位；经个别入学资格审查认定且 2027/3/31 满 22 岁。个别入学资格审查和受验照顾申请截止：A日程 2026/5/7、B日程 2026/10/7（均已过）。
- 入学时期在 WEB 出願系统里选择，出願后不能更改。
- 志望填写：在 WEB 出願系统里按「教員並びに専門分野一覧」填专门分野和教员，最多填到第3志望；第2、第3志望可以填同一分野的其他教员，没有可以不填。専攻教员一览的专门领域名与願書用的不同，填写时以「教員並びに専門分野一覧」为准。
- 出願书类：入学願書（WEB 填写，含 3 个月内照片）、出身大学全部在学期间的成绩证明书、毕业（预定）证明书（写明学位名和授予日）、检定料缴纳证明、TOEFL 成绩、国费留学生证明书（仅该当者）；原件在入学手续时提交。
- 専攻指定书类：推荐书至少 1 份，请了解本人研究生活和研究内容的人撰写；在 WEB 出願系统“その他”栏填推荐人姓名和邮箱，系统把上传链接发给推荐人，由推荐人自己上传 PDF。
- 出願方式：只能通过 WEB 出願系统；书类不齐不受理。受験票自己用 A4 纸打印，考试当天带上；B日程受験者心得到 2027/1/13（周三）还没收到的要联系教務課。
- 检定料 30,000 日元，银行汇款（邮储银行除外）、便利店、信用卡、Pay-easy 均可；缴纳期间 A日程 2026/4/13–6/23（已过），B日程 2026/10/5–11/25。国费留学生免缴；缴后不退。
- 并愿：同一日程只能报研究科的一个専攻。
- 入学料 282,000 日元，授業料 年 535,800 日元（前期 267,900 日元），均为预定额；国费留学生免缴。
- 咨询：専攻的问题问専攻主任·入试担当 田中 智 教授（Tel 03-5841-5472）或入试担当 片岡 直行 准教授（Tel 03-5841-5372）；出願手续问农学生命科学研究科教務課学生支援チーム大学院学生担当（〒113-8657 東京都文京区弥生1-1-1，Tel 03-5841-5010，daigakuin.a@gs.mail.u-tokyo.ac.jp）。
