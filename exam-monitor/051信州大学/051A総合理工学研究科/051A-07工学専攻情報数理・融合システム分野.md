## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般選抜（A日程·B日程第2次）：
  - 不另设英语笔试，用外部成绩评价，配点 20（满分100）；可交 TOEIC L&R 公开测验、TOEIC L&R IP（限信州大学实施，在线版不可）、TOEFL iBT（含 Home Edition），须为 2023年4月以后受检；TOEFL ITP、TOEIC Bridge 不受理。
  - 换算：TOEIC 730 分以上给满分，不足按 20×分数/730；TOEFL iBT 先按对照表换成 PBT，再按 (PBT－296)×2.874 折成 TOEIC。例：TOEIC 600＝16.4分；iBT 80（PBT 550）＝满分。
  - 没交成绩的英语按 0 分。
  - 提交：TOEIC 纸质认定证带原件和复印件，数字版用申请代码 00030518 提交并打印；TOEFL 纸质带原件和复印件，PDF 版用机构代码 G068 送分并打印。
- 推薦特別選抜（A日程）、外国人留学生·社会人·学部3年次特別選抜（B日程）：须交上述英语成绩，计入书类审查；不交则降低评价。

#### 日本語要件
- 要项没有要求提交日语成绩；外国人的面接含用日语提问的部分。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 一般選抜：面接（口头试问）·书类审查（80分）＋英语（20分） | 不考笔试；英语用外部成绩换算 |  |
| 推薦·外国人留学生·社会人·学部3年次特別選抜：面接（口头试问）·书类审查（100分） | 不考笔试；书类审查含英语成绩 |  |

- 按口头试问和书类审查综合评价一般教养、专门基础学力、英语能力和研究意欲。
- 同一日程内不能并报；A日程已合格者不能报B日程一般選抜。

### 口述試験 / 面接
- **官方形式**：个别口头试问＋书类审查，外国人含日语提问；A日程一般選抜：考数学专门基础——微积分（极限、一元和多元函数微积分）、线性代数（联立一次方程、秩、逆矩阵、行列式、对角化），在白板上板书解答并口头说明，另问研究计划；A日程推薦特別選抜：所学内容、毕业研究和研究计划；B日程一般選抜（第2次）：研究领域相关科目的基础学力和研究计划；B日程外国人留学生·学部3年次特別選抜：研究领域相关科目的基础学力、英语能力和研究计划；社会人特別選抜：研究领域相关科目的基础学力、外语能力和研究计划。

### 出願資格 / 定員
- 募集人员：80名（工学専攻280名中本分野单独定员，A日程推薦·一般合计）；B日程各区分均为若干人。
- 出願资格：一般選抜为大学毕业（含2027年3月预计）或外国16年学校教育等(1)–(11)，(10)(11)须先受入学资格审查（B日程 2026/10/19–10/22 已截止，非独立出願）；外国人留学生特別選抜（B日程）限无日本国籍、有不妨碍入学的在留资格（或入学后可取得）者，另可用外国15年课程优秀修了的资格(13)–(15)（须事前审查）；A日程另有2026年10月入学的一般·外国人留学生·社会人特別選抜（已结束）；外国人也可报一般選抜；A日程推薦特別選抜限日本的本科或高专专攻科应届推荐生。
- 要提前准备的书类：志望理由书（様式①，毕业研究概要、进学理由和研究计划，日文1,000字以内或英文300词以内）、TOEIC/TOEFL 成绩；外国籍者交护照复印件和在留资格证明；外文证明须附经认证的英译或日译。
- 出願：先在网上出願网站登录并缴检定料 30,000 日元＋系统使用费 900 日元，再把书类用简易書留速達寄出（B日程也可平日 8:30–17:00 送到入试事务室），期限内必达。
