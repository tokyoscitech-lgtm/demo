## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 夏入试：英语不单独考试，用 TOEFL 成绩评价。修士課程的出願者全员都要提交。
- 只受理 TOEFL iBT 和 TOEFL iBT Home Edition 的成绩。不采用 MyBest scores；考生手里的 Test Taker Score Report 不受理。TOEFL 成绩提出要项里没有列出 TOEIC、IELTS、TOEFL ITP 作为可提交的考试。
- 提交方式：从 ETS 账户申请把官方成绩直送研究科。机构代码 8445，Division 选 Graduate Organization，Department Code 选 99（For any other department not listed）。
- 有效范围（夏入试）：受检日在 2024/9/1 以后、出願截止日以前；成绩须在 2026/6/30 前送达研究科。
- TOEFL 成绩提交被判为无效的，失去数学、専門科目和口述試験的受験资格。
- 最低分：研究科 FAQ 写明研究科没有设最低分，个别専攻有规定的写在各自的入试案内書里；本専攻的入试案内書里没有读到最低分的规定。配点和换算方法官方没有公布。
- 配点（体验记，非官方）：2025年8月受验的内部生写 TOEFL 按 120 分计入。同年合格者自述的成绩有 76、80、82 分。

### 日本語要件
- 要项没有要求提交日语成绩（JLPT 等）。
- 研究计划书可用日文或英文写。数学的过去问是日英对照的；専門科目的出题与作答语言在这次读到的资料里没有明确写出。
- 研究科 FAQ 写明只靠英语授课的科目就能修满毕业所需学分，研究指导也可以用英语进行；研究科预告2026年4月以后大部分课程用英语授课。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 一般教育科目（数学）（配点官方未公布，13:00–15:30 共150分钟） | 线性代数、解析（微分积分、常微分方程等）、概率·统计三个领域各出1题，3题全答。全研究科共通 | 2027修士課程募集要项 |
| 専門科目「コンピュータ科学」（配点官方未公布，180分钟） | 从情報数学、数値計算、離散数学、アルゴリズムと計算量、形式言語、論理学、プログラミング言語論、コンピュータアーキテクチャ、オペレーティングシステム、デジタル回路、機械学習中出4题左右，全部作答。题目里可能用到 C 或 Java 语言 | 2027専攻入试案内書 |

- 选拔流程：先按出願书类做书类选考；合格者参加笔试；再“视需要”进行口述試験。募集要项和専攻入试案内書都没有公布各科配点、合格最低分和判定公式。
- 配点（体验记，非官方）：2025年8月受验的三篇体验记一致写数学 300 分、専門科目 800 分（4题各 200 分）。这不是官方公布的数字。
- 题目倾向（体验记，非官方）：2025年8月的専門科目出了4题，涉及形式语言、OS、硬件/电路、算法等（两位考生对领域的叫法略有不同）；数学当年被评价为偏难，微分方程题让不少人失分。2021年8月的考试是线上实施，与现在的对面笔试不同。
- 得分水平（体验记，非官方）：2025年8月合格的两名内部生，一人成绩开示为数学 155/300、専門 356/800，另一人自估数学约 150/300、専門约 610/800；一名外部合格者估计两科各六成左右可以合格，并指出合格线因志望研究室而差别很大。

### 口述試験 / 面接
- **官方形式**：夏入试 2026/8/27（周四）10:00–17:00 线上进行，考查内容写的是“専門科目”。募集要项的说法是笔试之后“视需要”进行口述試験。使用的会议软件、每人的时长和使用语言，入试案内書没有写，细节在 7 月下旬通知书类选考合格者。
- **実際に聞かれた内容**：（体验记，非官方）2025年8月两名内部生都写是 Zoom、3–5 分钟：一人被要求用1分钟说志望理由，再问研究上的抱负和修士毕业后的出路；另一人被问自己研究的独特之处。2022年8月的外部生写几乎没被问什么。2021年8月的外部生（文科出身）被问了1分钟以内的志望理由、休学期间和本科活动、实习经历，以及确认算法知识的问题，研究计划书的内容没有被问到。2019年的体验记是对面形式，写大多数人不到1分钟就结束，少数人被留下接受教员追问。

## 📝 详细信息
### 出願資格 / 定員
- 夏入试的募集人员为44名（修士課程，コンピュータ科学専攻）。本専攻修士没有冬入试，所以全年就是这 44 名。
- 出願资格（满足一项）：日本的大学毕业或 2027/3/31 前预计毕业；在外国完成16年学校教育；在外国大学等修完3年以上课程并取得相当于学士的学位；文部科学大臣指定者；由大学改革支援·学位授与機構授予学士学位者；经研究科个别入学资格审查认定具有同等以上学力、且 2027/3/31 时满 22 岁者。
- 同一期（夏入试或冬入试）里不能同时报研究科内两个以上的専攻、课程或选拔区分。
- 志望研究室：对照《各教員研究室紹介》，在出願系统上最多填到第6希望。
- 出願书类：入学願書（在 WEB 出願系统上生成，上传脸部照片数据：上半身、脱帽、正面、无背景、3个月内单人拍摄）、出身大学的成绩证明书、毕业证明书或预计毕业证明书、TOEFL 成绩（ETS 直送）、安全保障出口管理チェックシート（外国籍者等）、専攻要求的研究计划书。修士課程不要求推荐信。
- 研究计划书：A4 2页（参考文献不计入），日文或英文，写进入大学院后想做的研究内容；严禁剽窃。体验记（非官方）提到有人因研究计划书在书类选考阶段落选。
- 日语或英语以外的证明书要附日文或英文译文。
- 出願方式：全部在 WEB 出願系统完成，所有书类转成 PDF 上传，不需要邮寄。受験票通过邮件发给本人。
- 检定料 30,000 日元（日本政府奖学金留学生不用缴）。可用银行汇款、便利店、Pay-easy（ATM／网银）或信用卡支付；今年 e-shiharai.net 的可用期间为 2026/5/21–6/4。
- 入学时期：2027年4月入学；夏入试合格者中在出願时提出希望的人可以2026年10月入学。入学手续期限（预定）：2027年4月入学者为 2027/3/11（周四），2026年10月入学者为 2026/9/24（周四）。
- 外国人须在入学手续前取得不妨碍大学院在学的在留资格。按外为法属于管制对象的，即使最终合格也可能不被许可入学。
- 个别入学资格审查：夏入试的书类提交截止为 2026/5/13（周三）（已过）。
- 入学料 282,000 日元；授業料半年 267,900 日元（年额 535,800 日元）。
- 考场规则：考试开始 30 分钟前进入指定试验室；迟到要向监考人员申报并听从指示；受験票一直放在桌上；手机关机，不得使用。必须带黑色的铅笔、自动铅笔、钢笔或圆珠笔，以及橡皮、卷笔刀（桌上式不可）、仅有计时功能的手表。
- 咨询：研究科方面为情報理工学系研究科学務課大学院チーム入試担当，〒113-8656 東京都文京区本郷7-3-1，Tel 03-5841-7926／7428，johoriko.t@gs.mail.u-tokyo.ac.jp，平日 9:00–17:00。専攻方面为 admissions@is.s.u-tokyo.ac.jp，Tel 03-5841-4111。
- 成绩开示：受験者本人可以申请，手续因専攻而异，多数専攻是把申请书、受験票、身份证明复印件用挂号信寄到専攻事务室；受理期间为合格发表后2年以内，9月发表的那次从 10/7 起受理。
