## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 一般選抜：英语不设笔试，用 TOEFL iBT（含 Home Edition）或 TOEIC Listening & Reading 公开考试的成绩评分，成绩单贴在指定的「スコアシート提出用紙」上随出願书类一起寄出。
- TOEIC：只考 Listening & Reading 即可；只收公式认定证原件，数字版公式认定证自行打印后按原件处理。
- TOEFL：需要两样——由 ETS 直送大学的 Institutional／Official Score Report（Institution Code D377，Department Code 69），以及 Test Taker Score Report 的复印件。直送成绩要在出願期间最后一天之前到达大学，寄送要 6–8 周；提前寄到没有问题。只采用 Test Date Scores，不采用 MyBest。
- 有效期：只承认 2024/6/1 以后实施的考试成绩。不受理 TOEFL ITP 和 TOEIC IP（团体考试）。交上去的成绩单不退还。
- 没交成绩也可以出願和参加考试，但英语不评分。
- 笔试免除者选拔：本専攻在出願时（2026/6/4 前）就要交英语成绩（只有電気電子情報工学系 3専攻免交）；没有获得免除而转入一般選抜的人，可以按要项 A-10 在 2026/7/29（周三）17:00 前重新提交成绩单（已截止）。
- 配点与换算：募集要项和専攻注意事项都没有写英语的配点、最低分和换算方法。
- 外国人留学生入试：2027年度的英语要求未获取到。上一次的做法见下文「出願資格 / 定員」里的参考规定。

### 日本語要件
- 8月入试（笔试免除者选拔、一般選抜）：募集要项没有要求提交日语成绩。笔试和口頭試問都用日语进行。
- 外国人留学生入试：2027年度留学生募集要项的正文没能读到，本専攻的日语条件未核实。参考 2025年度留学生要项：要交日语能力的证明材料（指导教员等出具的证明书原件，或日语考试成绩单复印件），在日本的大学以日语课程毕业的人可免交；専門科目试题为日英并记。以新要项为准。
