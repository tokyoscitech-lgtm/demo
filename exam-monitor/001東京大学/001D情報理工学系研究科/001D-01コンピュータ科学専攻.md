## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 不另设英语笔试，用 TOEFL iBT 成绩评价；修士出願者全员提交，英语母语者也要交。
- 只收 TOEFL iBT（含 Home Edition）由 ETS 直送的 Official Score Report；MyBest scores 不采用，Test Taker Score Report 不受理，其他考试不能代替。
- 送分代码：University of Tokyo IS&T，Institution Code 8445，Division 选 Graduate Organization，Department Code 99；出願时填 Appointment Number 和受检日，只采用这一次成绩，出願后原则上不能更换。
- 受检日须在 2024/9/1 至出願截止日之间，成绩须在 2026/6/30 前到达研究科；未按期到达或不符合要求的，失去笔试和口述的受験资格。
- 配点（体验记，非官方）：2025年8月受验的内部生写 TOEFL 按 120 分计入；同年合格者自述成绩有 76、80、82 分。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 数学试题日英对照，専門科目试题有日文版和英文版；研究计划书可用日文或英文写。研究科自 2026年4月起大部分课程用英语授课。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 一般教育科目（数学） | 线性代数、解析（微分积分、常微分方程等）、概率·统计各1题，3题全答；全研究科共通 | 13:00–15:30，150分钟 |
| 専門科目（コンピュータ科学） | 从情報数学、数値計算、離散数学、アルゴリズムと計算量、形式言語、論理学、プログラミング言語論、コンピュータアーキテクチャ、オペレーティングシステム、デジタル回路、機械学習中出4题左右，全部作答；可能用到 C 或 Java；専攻网站有参考书目 | 13:00–16:00，含收卷约180分钟 |

- 选拔流程：书类选考 → 数学＋専門科目笔试与 TOEFL → 口述，综合判定；书类选考不合格者不能参加笔试。
- 配点（体验记，非官方）：2025年8月三篇体验记一致写数学 300 分、専門科目 800 分（4题各 200 分）；成绩开示一例为数学 155/300、専門 356/800（合格）。
- 题目倾向（体验记，非官方）：2025年8月専門4题涉及形式语言、OS、硬件/电路、算法；数学当年微分方程题失分者多；外部合格者称两科各六成左右可合格，合格线因志望研究室差别很大。

### 口述試験 / 面接
- **官方形式**：夏入试 2026/8/27 线上口述，考查専門科目，集合时间等细节在考试日前通知书类选考合格者。
- **実際に聞かれた内容**：
  - Zoom，3–5 分钟；先用1分钟说志望理由，再问研究抱负和毕业后出路，或问自己研究的独特之处（2025年8月，2人提到）。
  - 几乎没被提问（2022年8月，1人提到）。
  - 志望理由、本科和实习经历、确认算法知识的问题，研究计划书没被问到（2021年8月，1人提到）。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：44名（夏入试，含 2026年10月和 2027年4月入学）。
- 出願资格：大学毕业（含 2027/3/31 前预计）或外国16年学校教育等；个别入学资格审查 2026/5/13 截止（非独立出願）；同一期只能报研究科内一个専攻，夏入试合格不放弃入学就不能报冬入试；希望者可 2026年10月入学，需新办在留资格的外国籍考生官方强烈推荐 2027年4月入学。
- 要提前准备的书类：研究计划书（A4 2页，参考文献除外，日文或英文，写入学后想做的研究，严禁剽窃）、TOEFL iBT 成绩（ETS 直送）、安全保障輸出管理チェックシート（外国籍等，系统内填写）；志望研究室最多填到第6希望。
- 出願：只能通过 WEB 出願系统上传 PDF，不需邮寄；检定料 30,000 日元，日本政府（文部科学省）奖学金留学生免缴。
- 并愿限制：同一期只能报研究科内一个専攻、课程或选拔区分；夏入试合格且不放弃入学的人不能报同年度冬入试。
- 咨询：出願手续问情報理工学系研究科入试担当（〒113-8656 東京都文京区本郷7-3-1，johoriko.t@gs.mail.u-tokyo.ac.jp，Tel 03-5841-7926，平日 9:00–17:00，出願咨询原则上用邮件）；専攻内容问 admissions@is.s.u-tokyo.ac.jp。
