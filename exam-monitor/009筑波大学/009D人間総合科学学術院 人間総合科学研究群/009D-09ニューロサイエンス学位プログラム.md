## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 8月实施和1-2月实施都由プログラム自己出英语笔试：科目名「外国語」，配点 100 分，90 分钟，内容是与行动科学·神经科学有关的英语题目。
- 不需要提交 TOEIC、TOEFL、IELTS 等外部英语成绩；全学共通的「外部英语成绩的处理办法」里没有本プログラム的规定，因此也没有有效期、最低分一类的门槛。
- 外国語考试能否带词典、题目的具体题型（英文和译、摘要等），要项没有写。

### 日本語要件
- 要项没有要求提交 JLPT、EJU 等日语成绩，也没有针对外国人留学生另设区分，留学生与日本学生参加同一场考试。
- 研究计划可以用日文（约2,000字）或英文（约800词）写。笔试的出题和作答语言要项没有写明。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 外国語（100分，90分钟；8月实施·1-2月实施相同） | 与行动科学·神经科学有关的英语题目；题数没有读到 | 2027募集要项 |
| 専門科目（100分，90分钟；8月实施·1-2月实施相同） | 与行动科学·神经科学有关的题目，不论志望领域，从所出题目中选2题作答；出题总数要项没有写 | 2027募集要项 |
| 口述試験（50分；8月实施·1-2月实施相同） | 个别面接，就研究领域的专业知识和研究计划进行试问 | 2027募集要项 |

- 两轮的总分都是 250 分：外国語 100＋専門科目 100＋口述試験 50。根据提交的书类和学力检查的结果综合判定，要项没有公布合格最低分。
- 没有社会人特別選抜，也没有推薦入试，所有人考同一套科目。
- 题目倾向（体验记，非官方）：没有找到本プログラム的考生体验记，暂无可写的内容；出题样子可以看大学过去问页上2025年度实施的试题。

### 口述試験 / 面接
- **官方形式**：个别面接，配点 50 分，问研究领域的专业知识和研究计划。8月实施 2026/8/26 和1-2月实施 2027/1/29 都安排在笔试次日 10:00–17:00 之间，每人的具体时段另行通知。プログラム官网写的是每人大约10分钟，并注明形式和时间可能变更。面接使用的语言没有写。
- **実際に聞かれた内容**：没有找到本プログラム的面接体验记，实际提问内容不明。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：8月实施（一般入学試験）8名；1-2月实施（一般入学試験）2名。两个数字都包含连携大学院（産業技術総合研究所）的名额。
- 出願资格：日本的四年制大学毕业或入学前一个月底前预计毕业；由大学改革支援·学位授与機構授予学士学位；在外国完成16年学校教育；在外国3年以上的课程取得相当于学士的学位（出願前要先确认资格）；经本大学院个别审查认定与大学毕业同等以上学力、且满22岁的人（要先申请个别出願资格审查）。
- 个别出願资格审查和出願资格咨询的截止日：8月实施 2026/7/3（周五）（已过）；1-2月实施 2026/11/24（周二）。以「出願資格審査希望」为邮件标题，写明住址、姓名、电话、邮箱、志望プログラム、最终学历和有关情况，发给体育芸術エリア支援室大学院教務；收到样式后在截止日前把原件和证明书交齐。以前通过审查的人每次仍要重新申请。
- 志望指导教员：在 Web 出願系统里选第1志望的指导教员，第2志望可以不填；填了的教员都必须事先联系并取得承诺。
- 出願书类：毕业（预计）证明书（已有硕士、博士学位的人也要交取得学士的大学的证明）、外国大学毕业者的学位取得证明书、成绩证明书（读过大学院的还要交大学院的）、检定料收纳证明（便利店支付者）或信用卡支付结果画面的复印件、在学或在职者的受験·就学承认书（样式不限）、国费留学生证明书（符合者）。改过姓名的人要附户籍抄本等。
- 研究计划：原则上直接在 Web 出願表单里填写（日文约2,000字或英文约800词）；需要图表时才用规定样式另交研究计划书。
- 出願方式：在 Web 出願系统注册邮箱 → 录入出願信息并上传证件照（JPEG，3个月以内）→ 选择志望指导教员 → 填写安全保障出口管理（みなし輸出）的确认事项 → 支付检定料 → 点击「出願」（之后不能再改）→ 在出願期间内保存并打印受験票和收件人标签。书类装进角形2号信封、贴上标签，用書留寄到体育芸術エリア支援室，截止日必达。一个账号只能报一个学位プログラム，建议用电脑操作。
- 检定料 30,000 日元，信用卡或便利店支付，手续费由出願者负担，缴纳后不退。国费外国人留学生不收。
- 入学料 282,000 日元（缴纳后不退）。授業料每学期 267,900 日元（年额 535,800 日元）；在留资格为「留学」的外国人留学生每学期 304,400 日元（年额 608,800 日元）。入学手续的说明在合格发表当天发到出願时登记的邮箱，合格通知书在线发放；入学手续的具体期限没有读到。
- 试场：筑波大学筑波キャンパス（茨城県つくば市天王台1-1-1）。具体建筑、可携带物品等写在「受験者心得」里，考试1周前在入试站的通知栏掲載。
- 需要受験上配虑（残疾等）的人要事先向教育推進部入試課提交申请书和诊断书等；本年度的申请期限没有读到。
- 成绩开示：只对不合格的本人开放总得点，用邮寄方式申请；缺考1科以上的人不在对象内。受理期间没有读到。
- 咨询：出願手续和资格审查找体育芸術エリア支援室大学院教務，邮箱 taigeiin.admission@un.tsukuba.ac.jp；外国学历等出願资格的事先确认找入試課大学院入試，邮箱 admission.grad@un.tsukuba.ac.jp；プログラム内容通过官网的咨询表单联系。电话号码没有读到。
