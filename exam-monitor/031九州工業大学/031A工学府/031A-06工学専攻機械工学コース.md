## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 第1回推薦型·一般型、第2回一般選抜、外国人留学生特別選抜：
  - 不另设英语笔试，用外部成绩评价：出願时提交 TOEIC L&R 公开测试的デジタル公式認定証打印件或 TOEFL iBT 成绩，换算后计入書類審査（本コース一般型200分，推薦型和外国人留学生特別選抜600分，与学业成绩合计）；两种都交的取换算分高的一方。
  - TOEIC：邮寄的纸质公式認定証不受理（在日本国外受验的可交寄给本人的纸质原件，不收复印件）。TOEFL iBT：既要交从个人账户下载的 Test Taker Score Report 打印件，又要在出願截止前让 ETS 用 DI コード 8000 把 Official Score Report 送到大学。
  - 成绩须为考试日前2年以内受验、带照片；TOEIC L&R IP、カレッジ TOEIC、TOEFL ITP 等团体成绩不受理（能证明是所在大学英语课程一环的 TOEIC L&R IP 除外，IP 线上版一律不收）。
  - 出願时交不出成绩的，英语按本分野规定的最低分评价；外国人留学生特別選抜考生住在海外交不出成绩的，出願前与希望的指导教员商量。
- 社会人特別選抜：不要求英语成绩，面接中有英语口头试问。

#### 日本語要件
- 要项没有要求提交日语成绩。

- 第1回一般型和第2回一般選抜（仅飛び入学者）：总分1000＝笔试500＋面接300＋書類審査200（学业成绩和英语），按总分从高到低判定，同分同名次。
- 第1回推薦型、外国人留学生特別選抜（第1·2回）：无笔试，面接400＋書類審査600；社会人特別選抜：面接1000。

### 口述試験 / 面接
- **官方形式**：第1回一般型·第2回一般選抜：个人面接300分，考专门学力（含机械工学口头试问）并围绕出願书类提问，多名面接员按“基础学力·专门性”“问题解决能力”两个观点各5级评价；推薦型和外国人留学生特別選抜：内容相同，400分；第2回外国人留学生特別選抜：校内，每人30分钟（含问答），自带电脑用PPT发表以往研究（毕业研究）和入学后研究计划，并问机械工学基础、数学等，发表资料须事先提交；社会人特別選抜：面接1000分，含专门科目和英语口头试问；要项写明面接可能改为线上。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：本コース接收人数目安40名（工学専攻第1回一般選抜合计278名）；2026年10月入学若干名（仅第1回一般型）；第2回一般選抜仅招飛び入学者，若干名；社会人特別選抜、外国人留学生特別選抜各若干名。
- 出願资格：大学毕业（含2027年3月预计，10月入学为2026年9月预计）或在外国完成16年学校教育等11项之一；飛び入学（资格8）和资格9–11须先通过事前审查·入学资格个别审查（第1回 2026/4/20–4/27，第2回 2026/9/16–9/25，均已截止，非独立出願）；本コース第2回一般選抜只招飛び入学者（资格8，限大学3年级在学、通过事前审查者）；外国人留学生特別選抜只限没有日本国籍、在外国完成（含预计）16年学校教育、持有或入学时取得“留学”在留资格的人，日本的大学毕业（含预计）的外国人报一般選抜；推薦型须由出身大学学部長等推荐并保证合格后入学；所选试验分野有时做不了志望领域的研究，想限定研究领域的在网上登记前向大学院係确认。
- 要提前准备的书类：外部英语成绩（见語学）；推薦型的推薦書（所定样式，由学部長·学科長·指导教员之一填写并密封）；外国人的学歴確認シート（所定样式）；中国的大学毕业者交 CHSI 英文学历认证和英文成绩认证报告，并申请让 CHSI 在出願截止前把电子认证报告直接发到大学院係邮箱（本人转发无效，送达时有效期须剩30天以上）；社会人特別選抜另交志望理由書和研究（希望）計画書（日文约1000字或英文约500词）。
- 出願：先在网上出願登记网站登记并缴检定料 30,000 日元（另收系统利用费，可用信用卡·便利店·Pay-easy），再在书类提交期间内用速達簡易書留（角形2号信封）寄送或送到窗口（9:00–16:00），必达；只做网上登记不算完成出願；外国人留学生特別選抜考生和国费留学生须先发邮件向大学院係索取登记用密码。
- 并愿：推薦型与一般型只在第1回实施，出願时二选一，推薦型不合格者不用重新出願即可参加同一コース的一般型；10月入学和飛び入学只能报一般型；第2回一般選抜不分推薦型·一般型；只有第1回一般型考生可把生命体工学研究科生命体工学専攻填为第2志望（2026/8/29–8/30 考试，9/7 发表，已结束），不能把工学府其他コース填为第2志望。
- 咨询：九州工業大学 大学院工学研究院事務課大学院係（〒804-8550 北九州市戸畑区仙水町1-1），koh-daigakuin@jimu.kyutech.ac.jp，Tel 093-884-3057（窗口 9:00–16:00，周六日和节假日除外）；外国人留学生特別選抜的登记密码、研究领域限定等也向该係询问。
