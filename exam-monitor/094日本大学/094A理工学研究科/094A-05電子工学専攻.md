## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般第1期・第2期：
  - 研究科共通的外国語（英語）笔试，60分钟；配点官方未公布。
  - 出願时可任意提交 TOEIC L&R 或 TOEIC L&R-IP 成绩单（原件或复印件），与研究科英语笔试得分比较，取高者作为外国語成绩；换算按研究科规定，换算式未公布。这不是免考制度，提交了也要参加英语笔试。
  - 成绩须为从入学考试日起算3年以内受检；数字公式认定证须打印后提交，PDF 不受理。TOEFL、IELTS 不在比较对象之列。
- 一般第3期、社会人入试、外国人留学生入试：不考英语，也不要求提交外部英语成绩。

#### 日本語要件
- 一般入试要项没有要求提交日语成绩。
- 外国人留学生入试：全学要项对理工学研究科只实施学内独自考试，不采用日本留学试验，也没有要求提交 JLPT 等日语成绩。
- 笔试和口述以日语进行，要项没有写其他作答语言。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 専門科目（配点官方未公布，120分钟） | 从「電磁気学」「電気電子回路」出题；可用电卓（带编程・通信功能的除外，含手机、穿戴设备） | 2027募集要项（一般第2期）／选考方法 |
| 外国語・英語（配点官方未公布，60分钟） | 研究科共通英语试题；可用 TOEIC 成绩比较取高 | 2027募集要项 |
| 外国人留学生：専門科目（120分钟） | 与一般第1・2期专攻科目相同的区分出题；可用电卓（限制同上） | 外国人留学生要项／选考方法 |
| 一般第3期：无笔试 | 出願时提交卒业研究概要和大学院研究计划书（事前课题），当天做专业口头试问 | 选考方法 |

- 一般第1期・第2期按英语、専門科目和口述综合判定，官方没有公布配点和合格基准。
- 社会人入试只考口述（见口述小节）。

### 口述試験 / 面接
- **官方形式**：一般第1期・第2期为面接与试问；一般第3期为以出願时提交的卒业研究概要和研究计划书为基础的专业口头试问；外国人留学生为面接与试问；社会人入试为围绕业绩和研究计划等的面接与试问，本専攻可在 Web 登录时选择到校面试或 Zoom 线上面试（登录后不能更改）。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：博士前期课程入学定员35名（一般第1〜3期・学内推薦・外国人留学生等全入试合计，官方不按期拆分）；社会人入试各専攻若干名。
- 出願资格：大学毕业或2027/3/31前预计毕业、取得学士学位、在外国完成16年学校教育等10项之一；资格（10）须事先接受个别资格审查（第2期截止 2026/6/15 已过，第3期截止随第3期要项公布），资格（9）须先向理工学部入試事務室咨询。
- 出願方式（一般・社会人）：先在大学院Web出願系统登录，再把书类以简易书留邮寄，截止日邮戳有效；只做其中一项不算出願完成。准考证和考试案内从考试日5天前起在系统下载。
- 出願书类（一般）：入学志愿票（所定，贴照片）、毕业（预定）证明书、成绩证明书、TOEIC 成绩（任意）、出願确认票（所定）；外国人加交指导预定教员签发的事前連絡確認書（原件）；外国学校出身者按资格加交出願资格确认票。社会人另交履历书等。
- 检定料 35,000 日元，汇款到要项指定账户，手续费自付；只有未寄书类或出願不受理时退还。
- 外国人留学生入试：通过日本大学本部的出願系统登录（My Page），书类寄本部入学課；检定料 35,000 日元；入学资格审查截止 2026/9/30（已过）；入学手续截止 2027/1/7（周四）。
- 入学手续：一般第3期 2027/3/11（周四）–3/25（周四）；一般第1・2期可分两段缴费，第2段截止 2027/1/29。
- 初年度纳入金（令和8年度金额）：学外者 1,370,000 日元（含入学金 200,000 日元），本校出身者免入学金；自费外国人留学生可按经济情况和学业申请减免授業料 20%。
- 考场：日本大学理工学部駿河台校舎（东京都千代田区神田駿河台1-8-14）；本専攻的研究教育在船橋校舎（千叶县船橋市習志野台7-24-1）。
- 本専攻其他路线：学内推薦只限日本大学理工学部学生，已于 2026/7/11 实施。
- 咨询：理工学部入試事務室 Tel 03-3259-0578，cst.nyushi@nihon-u.ac.jp；電子工学専攻 Tel 047-469-5453，cst.ene.office@nihon-u.ac.jp。
