## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各轮次都不另设英语笔试，用外部成绩评价：出願时上传 TOEIC L&R 公式認定証原件（原则上带本人照片）、TOEIC L&R デジタル公式認定証（QR码须可读）、TOEFL iBT Test Taker Score Report 原件三者之一的 PDF；TOEIC-IP、TOEIC Speaking & Writing、TOEFL ITP 不受理。
- 受验日：一般選抜须在 2024/7/4 以后；第2次募集、国際コース4月入学须在 2024/12/5 以后。
- 出願时成绩还没出的，先交能看出姓名和受验日的报名证明（受験票复印件或マイページ截图），考试当天带原件（数字版带打印件）；考试当天还确认不了公式成绩的可能不能受験。
- 国際コース：英、美、加、澳、新西兰、爱尔兰等英语国家出身者免交（其他英语官方语言国家须先问教務課）；在外国大学用英语受课的，可用校长或研究科长出具的 CEFR B2 以上证明信代替。

#### 日本語要件
- 要项没有要求提交日语成绩。一般選抜和第2次募集全部用日语进行，笔答只能用日语作答，面接和口头试问也用日语；要项建议日语不熟练、在留资格为「留学」的考生改报国際コース。
- 国際コースの笔试、面接、口述全部用英语进行。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 一般選抜·筆答試験：数学Ⅰ（必答） | 线性代数（矩阵、联立一次方程与逆矩阵、向量空间、行列式、线性映射、特征值与特征向量）和（联立）常微分方程，1题；三類共通试题 |  |
| 一般選抜·筆答試験：选答2题 | 数学Ⅱ和力学、熱力学、流体力学、電磁気学各1题，共5题选2题 |  |
| 第2次募集、国際コース4月入学：数学 | 线性代数、微分方程各1题，2题全答；国際コース用英语出题、作答 |  |

- 一般選抜出题范围：数学Ⅱ（Ⅱ・Ⅲ類共通）为级数·极限·多变量微积分、向量分析（梯度·散度·旋度、高斯与斯托克斯定理、线面体积分）、复变函数（柯西–黎曼方程、柯西定理、泰勒·洛朗展开、留数定理）；力学为质点·质点系·刚体；熱力学为第一·第二定律、理想气体与实际气体、气液相变、热力学循环；流体力学为静水力学、伯努利定理·连续方程·动量守恒、管内流动与损失、粘性流体（层流）、完全流体、量纲分析与相似律（不考可压缩流体）；電磁気学为静电场、恒定电流、静磁场、电磁感应。
- 一般選抜跨類限制：志望里含Ⅰ類或Ⅱ類研究室时，选答的2题中至少1题须是共通専門科目（Ⅰ・Ⅲ類共通：力学、電磁気学；Ⅱ・Ⅲ類共通：力学、熱力学、流体力学、電磁気学），不满足条件的類的研究室不论志望顺位都不分配。
- 合否判定：筆答試験、第2次募集、国際コース按出願书类和学力检查（笔试＋面接）综合判定；口述試験按出願书类（含志望动机·研究计划书）和口头试问综合判定。

### 口述試験 / 面接
- **官方形式**：一般選抜·口述試験：不考笔试，口头试问専門科目、毕业研究、志望动机和入学后研究计划（日语），对象由専攻按出願书类决定、6月下旬在マイページ通知，前提是第1志望研究室属于Ⅲ類且出願前与该教员面谈过（可线上），不合格的可再考筆答試験但不能改志望研究室；一般選抜·筆答試験：面接含学问领域的提问（日语）；第2次募集：笔试日有面接（日语）；国際コース4月入学：Ⅲ類设口述試験（英语，内容同一般選抜口述，只对専攻判定学力足够的出願者实施，未通过的可再考 12/5 笔试），12/5 笔试日有面接（英语）。

- 募集人员：一般選抜为総合理工学専攻全体 172 名（Ⅰ・Ⅱ・Ⅲ類合计，不按類分配）；第2次募集若干名；国際コース4月入学若干名。
- 出願资格：大学毕业（含 2027/3/31 前预计）或外国16年学校教育等；按资格(9)–(11)（含外国15年课程）出願的须先过出願资格事前审查（一般選抜 2026/4/20、第2次募集和国際コース 9/28 截止，已过，非独立出願）。出願时以Ⅲ類为受験類，按研究室番号填最多第5志望，筆答可以跨類填（科目限制见筆記試験），口述試験的第1志望须属于Ⅲ類；第2次募集和国際コース只能从各自的招生研究室一览中选；入学后多选機械・システム理工学メジャー或地球環境理工学メジャー。
