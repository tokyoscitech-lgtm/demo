## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 一般选拔不考英语笔试，英语按外部成绩换算为100分：
  - TOEIC L&R（公开考试）：（分数−200）÷790×100。例如 TOEIC 700 → 63分。
  - TOEFL iBT：（分数−23）÷87×100。例如 TOEFL 80 → 66分。
  - TOEIC L&R-IP 和 TOEFL ITP：只限本校在校生参加本校组织的考试，ITP 用（分数−363）÷277×100。
  - 四舍五入取整；换算公式下一年度可能调整。
- 有效期：2024/9/2 以后受检、且在考试日前2年以内的成绩。线上考试不受理（本校组织的 TOEFL ITP Digital 除外）；TOEFL iBT Home Edition 不受理，MyBest score 不采用。
- 提交方式：TOEIC 交 Official Score Certificate 原件（无原件时可交数字认定证打印件），并在 TOEIC 网站登录本校团体代码 00018701；TOEFL iBT 指定 DI Code 8276 送分，并交 Test Taker Score Report 打印件；IP/ITP 只在志願書上填写日期和分数。
- 缺交、与记录不符、超出有效期或有不正行为的，英语按0分处理。
- 变更点：2026年度起取消英语笔试，改用外部成绩。

### 日本語要件
- 要项没有要求提交 JLPT 等日语成绩，但写明授课以日语为主，建议具备 JLPT N1 程度的日语能力。事前课题必须用日语写，考试和面接用日语进行。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 数学（100分，90分钟） | 微积分、常微分方程、线性代数、向量分析；全部必答 | 2027募集要项 |
| 物理·化学·情報（100分，90分钟） | 共7题（物理3题：质点·质点系力学、电磁学、热力学；化学3题：物理化学、无机化学、有机化学；情報1题：算法与数据结构），任选3题，可以只选物理或只选化学；每题配点未公布 | 2027募集要项 |
| 英语（100分） | 不考笔试，按 TOEIC/TOEFL 成绩换算 | 2027募集要项 |
| 面接（50分） | 见下节 | 2027募集要项 |

- 按笔试、英语、面接成绩和出願书类综合判定；任一项低于基准分都可能不合格。迟到20分钟以上不能参加笔试，缺考任一科目即不合格。
- 研究室分配按考试成绩排名决定，不按志愿顺序；没有填写的研究室不会被分配。
- 题目倾向（体验记，非官方）：没有找到考生的体验记。

### 口述試験 / 面接
- **官方形式**：个别面接约20分钟、50分。考生就事前课题的两个问题各用约1分钟发表（不能带资料），并考察专门基础知识、研究经历与热情、工学科目的学习情况。等候时手机和穿戴设备须关机，可看书和笔记。
- **実際に聞かれた内容**：没有找到考生的体验记。

## 📝 详细信息
### 出願資格 / 定員
- 一般选拔的募集人员为50名（机械システム、电子情报、物质工学3个分野合计，含特別选拔和双学位交换生）；社会人特別选拔和早期卒業予定者対象特別选拔为「若干名」。
- 出願资格：日本国籍，或持有（入学时能取得）「留学」在留资格的外国人；大学毕业或2027/3/31 前预计毕业、按学校教育法施行规则第155条认定具有同等学力、或经个别审查认定且到2027/3/31满22岁。
- 个别资格审查：外国大学毕业者和第2、3项资格者须在 2026/5/29（周五）17:00 前联系入学試験事務室（已截止）。
- 研究室志愿最多填8个；出願前必须与志望研究室的指導教員面谈，前3志愿的面谈是必须的，面谈的研究室名、教员名和日期须写在志願書上。
- 出願书类：入学志願書和受験票·写真票（网上表格，3个月内照片）、卒业（见込）证明书和成绩证明书（2026/5/1 以后开具，本校工学部在校生免交）、事前课题、检定料汇款证明、英语成绩证明、类型该当性自我申告书（安全保障出口管理）；中国大陆院校出身者另须由学信网（CHSI）直接发送学历、成绩和学位认证报告到 nyushi@toyota-ti.ac.jp。
- 事前课题：用日语各写约500字的两篇——「至今的研究」和「升学动机与目标」，各可附1张图，填多个志愿时以第1志愿研究室为准，须用本校指定様式。
- 出願方式：用 A4 角形2号信封（红字注明「修士課程一般選抜 入学願書在中」）以简易书留速达邮寄，邮戳有效；或在平日窗口持参。书类不全不受理。
- 检定料 24,000日元，2026/7/10–7/24 期间汇款，7/24 15:00 前到账；海外汇款须自行承担境内外手续费。
- 入学金 260,000日元；授業料每学期 350,000日元＋教育充实·环境整备费每学期 50,000日元；入学时合计约 661,200日元（含保险），以后每学期 400,000日元（2026年度金额）。2027/3/31 前辞退的，入学金以外的费用退还。
- 需要考试或修学照顾的须在 2026/6/26（周五）17:00 前申请。
- 本校遵守外汇及外国贸易法的安全保障出口管理，研究内容可能受限或需调整。
- 考场为豊田工業大学（名古屋市天白区久方2-12-1），只能使用公共交通。患流感、新冠等传染病者可能被要求不参加考试，不设补考也不退检定料。
- 其他：有男女宿舍（超额抽签）、トヨタ奨学基金无息贷与（月2万–10万日元）、修士1年级的 TA 制度（有报酬）。
- 咨询：入学試験事務室 Tel 052-809-1716，nyushi@toyota-ti.ac.jp（总机 052-802-1111，Fax 052-809-1721）。
