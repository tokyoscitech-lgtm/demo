## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 须提交 TOEFL iBT 成绩（含 Home Edition），由 ETS 把 Official Score Report（Institutional Score Report）直送研究科；本専攻的外国语考试就是用这份成绩评定，没有另外的英语笔试。
- 送分方式：在 ETS 账户里指定 University of Tokyo IS&T，Institution Code 8445，Department Code 99（Graduate Organization）。送到别的代码研究科查不到。出願时在系统里填写 Appointment Number 和受检日。
- 有效期与截止：夏入试只认 2024/9/1 以后、出願截止（2026/6/4）以前受检的成绩，成绩数据须在 2026/6/30 前到达研究科（已截止）。
- MyBest scores 不采用，考生自己手里的 Test Taker Score Report 不受理；其他英语考试不能代替。
- 官方没有规定最低分，也没有公布换算方法和配点。
- 成绩没有按期到达或不符合要求的，视为无效，并失去笔试和口述试验的受験资格。英语母语者也要提交。考过多次的只认出願时填写的那一次，出願后原则上不能更换。

### 日本語要件
- 要项和専攻入试案内书都没有要求提交日语成绩。
- 数学试题为日英两版。口述试验的发表必须用英语，之后的试问可以用日语或英语回答。
- 出願书类只收日文或英文，其他语言的要附日文或英文译文。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 一般教育科目（数学）（配点官方未公布，150分钟） | 研究科各専攻共通试题，共 3 道大题；具体领域要项没有列出，以过去问为准 | 2027修士募集要项／过去问アーカイブ |
| 専門科目（没有笔试） | 相当于専門科目笔试的考查放在口述试验里进行，范围见下一节 | 2027修士募集要项／専攻入试案内书 |

- 选拔流程：书类选考 → 一般教育科目（数学）笔试 → 外国语（TOEFL 成绩）→ 専門·口述试验。只有通过书类选考、参加了数学考试、TOEFL 成绩有效的人才能参加口述试验。
- 各项的配点和合否判定的计算方法官方都没有公布。
- 变更点：専攻入试案内页挂的専門科目笔试旧题只到 2020 年度，此后专业考查改为口述形式，备考时不要按旧的笔试形式准备。
- 题目倾向（体验记，非官方）：本次没有找到针对本専攻的考生体验记，数学部分只能参照研究科共通过去问。

### 口述試験 / 面接
- **官方形式**：Zoom 线上进行，须用 Windows 或 Mac 电脑并外接摄像头。先用英语做 7 分钟发表，内容是自己的专业能力、志望领域和研究计划，幻灯片事先做好并共享屏幕；随后试问，可用日语或英语回答，会问到机械系（机械力学、控制、メカトロニクス、ロボティクス等）和情报系（情報基礎、数字电路、计算机、软件等）的专业知识。每人的总时长和配点官方没有写。考试全程录像，房间里只能有本人，不能用虚拟背景、耳机、帽子、智能手表等穿戴设备，考前和考中要向监考展示房间全景，桌上只能放受験票、电脑及外设、A4 以上的笔记本或白板和笔。
- **実際に聞かれた内容**：本次没有找到本専攻口述试验的考生体验记（日文、中文各检索过），实际提问内容未获取到。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：夏入试 56 名；本専攻修士没有冬入试，所以全部名额都在夏入试。
- 出願资格：大学毕业或 2027/3/31 前预计毕业；在外国完成 16 年学校教育；在外国取得相当于学士的学位（修业年限 3 年以上）等。走个别资格审查的人须事先交材料，夏入试的截止日是 2026/5/13（周三）（已截止）。
- 志望研究室：在 WEB 出願系统的“志望研究室”栏用下拉菜单选第 1 至第 10 志望，最多 10 位教员，只能选案内书一览里本年度可接收学生的教员。所选教员都排不进时，可能被分到其他有名额的教员。
- 専攻独有的提交物（与願書一起提交，用専攻的样式在电脑上填写后转成 PDF）：志望カード（1 页以内，12pt 以上）；専門能力調査カード（A4 2 页，不能加页，12pt 以上，可用图表，写研究活动、课程和演习里的自主制作、课外活动等能说明专业能力的内容）。
- 研究科共通书类：WEB 出願系统填写的願書和照片（jpeg）、成绩证明书、毕业（预计）证明书（均上传 PDF，入学手续时交原件）、TOEFL 成绩（ETS 直送）、检定料缴纳证明、安全保障出口管理检查表（外国籍等）。
- 出願方式：只能通过 WEB 出願系统，没有邮寄或窗口受理。
- 检定料 30,000 日元，用银行转账、便利店、Pay-easy 或信用卡支付，手续费自付；日本政府（文部科学省）奖学金留学生免缴，须上传证明。
- 并愿限制：同一次入试只能报一个専攻。夏入试合格且没有放弃入学的人不能再报冬入试。
- 受験票用邮件发送，夏入试到 2026/7/17（周五）17:00 还没收到的要联系入试担当。
- 外国籍者须在入学手续前取得可在大学院就读的在留资格；在职者入学须提交所属单位负责人的同意书。
- 入学料 282,000 日元，授業料 半年 267,900 日元（年额 535,800 日元），均为预定额；文部科学省奖学金留学生免缴。入学料缴纳后不退。
- 入学手续截止（预定）：2027年4月入学为 2027/3/11（周四）。
- 大学院外国人研究生是另一条路线，这不是修士入试的要求。
- 咨询：出願手续问情報理工学系研究科入试担当（东京都文京区本郷 7-3-1，johoriko.t@gs.mail.u-tokyo.ac.jp，Tel 03-5841-7926，平日 9:00–17:00，优先用邮件）；専攻内容问知能機械情報学専攻事务室（kyoumu@office.mech.t.u-tokyo.ac.jp，Tel 03-5841-6302）。
