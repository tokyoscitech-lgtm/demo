## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 非英语母语者提交 TOEFL iBT 或 IELTS Academic 官方成绩，不另设英语笔试；英语为第一语言或到高中为止主要用英语受教育的人免交，不完全符合而申请免交的须在 Personal Statement 栏说明理由。
- TOEFL iBT：由 ETS 电子直送（Institution Code D175，Department Code 99），2年以内受检；MyBest 可以，新旧计分形式都收；Test Taker Score Report 和本人成绩记录不收；出願表填 Appointment Number，但不能代替送分。
- IELTS Academic：通过 IELTS Results Service 电子直送 ITASIA，2年以内受检；纸质 TRF、eTRF 复印件和 One Skill Retake 不收；出願表填 TRF Number。
- 居家考试（TOEFL iBT Home Edition、IELTS Online 等）可以，前提是考试机构能直送官方成绩（FAQ）。
- 没有最低分数线，综合审查。

#### 日本語要件
- 要项没有要求提交日语成绩；日语考试成绩可自愿附上扫描件作参考。
- 必修课全部用英语授课，不能用日语课代替；日语开设的选修课可以选，学分计入毕业要求。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 书类选考（无笔试） | 网上出願表（英文，含 Personal Statement、Research Proposal 等文字栏）、2份评价、学位证明与成绩单、英文写作样本、GRE、英语成绩，综合审查 |  |

- 修士只看书类，必要时会要求补充信息。
- GRE General Test 全员必交：由 ETS 电子直送（Institution Code 3560，Department Code 0000），5年以内受检，出願表填 Registration Number；没有官方成绩的申请不予审查。只有 ITASIA 在读生、修士毕业2年内报 ITASIA 博士的人免交。GRE 平均分不公开。
- 英文写作样本：毕业论文、研究论文或学期论文，论文未完成的可交中期报告或草稿；须本人用英语写成，不收译文；须为可检索文字的 PDF，不能是扫描件。

### 口述試験 / 面接
- **官方形式**：2027年10月入学募集：修士不实施面试（面试只在需要时针对博士出願者）。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：2027年10月入学修士13名（学際情報学専攻全体100名中包含这13名）。
- 出願资格：持学士学位或同等学力（含 2027/9/30 前预计毕业，须交毕业预定证明）；不符合者可申请个别资格审查（2027/9/30 满22岁，2026/10/16 16:00 前联系 Admissions Office 并提交 CV、成绩单和学校概要，已截止）；须具备用英语上研究生课程、接受指导的能力。
- 要提前准备的书类：GRE（全员）和 TOEFL/IELTS（非母语者）官方直送成绩；2份网上评价（评价人须有机构邮箱和机构网页，至少1人来自学府以外，可用英文或日文，应事先确认对方愿意）；英文写作样本；护照身份页扫描件。
- 出願：只能网上填写和上传，不接受窗口提交，所有书类和评价须在截止前到达；检定料 10,000 日元（信用卡或银行汇款，截止前缴纳；日本政府（MEXT）奖学金留学生免缴）。
- 咨询：ITASIA Admissions Office，itasiaao2027@iii.u-tokyo.ac.jp（只受理咨询，不收书类；官方要求先看 FAQ）。
- 并愿：尚未核实是否可同时报考其他专攻或选拔类别。请以本年度募集要项或招生窗口答复为准。
