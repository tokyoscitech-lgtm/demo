## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 各轮都没有英语笔试，改为出願时提交外部英语考试成绩（自2024年度入试起实行）。
- 受理的种类：TOEFL iBT（含 Home Edition）、TOEIC Listening & Reading、IELTS Academic。不受理：TOEFL ITP、TOEIC IP、TOEIC Speaking & Writing、TOEIC Speaking、TOEIC Bridge、IELTS General Training。
- 成绩须为笔试日之前2年以内受检。只能交1份成绩，交多份的可能全部无效。
- 提交方法：TOEFL 要向 ETS 申请把 Official Score Report 直送北海道大学大学院环境科学院（DI code 8744），同时附 Test Taker Score Report 复印件；TOEIC 交 Digital Official Score Certificate 的打印件或公式认定证原件（原件考试当天归还）；IELTS 交 Test Report Form 复印件。
- 要项没有写最低分数线，也没有公布换算方法和配点；成绩作为书类审查的一部分用于综合判定。
- 秋季特别入试（11月）注明招收“英语能力优秀、学习意愿高”的人，但要项没有给出具体的分数门槛。

### 日本語要件
- 要项没有要求提交日语成绩。出願书类用日文或英文书写。
- 秋季入试的专门科目试题有日文版和英文版（2024、2025年实施分两种版本都公开过）；要项没有对本専攻的作答语言作出规定。
- 学院的留学生说明页写明：修士课程可以只用英语完成学位；选修日语授课的科目需要 JLPT N2 以上，野外调查可能需要日常会话程度的日语，具体要求向志望教员确认。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 秋季入试·10月入学：专门科目（120分钟，配点未公布） | 3个科目群共12题，任选3题作答，可以跨科目群。フィールド科学4题（生态学、农学、林学）；生命科学4题（分子生物学、生物化学、细胞生物学、细胞生理学）；水圏·海洋科学4题（水圏生物学、海洋学、水产学）。官方列出的参考书：《Instant Notes in Ecology》《Campbell Biology》《Molecular Biology of the Cell》《水産学ハンドブック》第3版、Pinet《Invitation to Oceanography》 | 2027募集要项 |
| 秋季特别入试：专门科目（小论文，90分钟，配点未公布） | 就环境与生物学的一般性话题写小论文 | 2027募集要项 |
| 春季入试 | 没有笔试。专门科目的内容在口述试验的问答里考 | 2027募集要项 |
| 特别推荐入试 | 没有笔试，只有口述试验 | 2027募集要项 |

- 要项没有公布各科配点、总分和合格线；按笔试、口述、成绩证明书、英语成绩等书类综合判定。
- 2026年8月实施的秋季入试试题构成（据官方公开的过去问归纳）：每题一张答题纸；フィールド科学出了林下植物的叶物候与碳收支、畜产与人畜共通传染病·耐药性·排放、生物多样性丧失与自然选择的证据、生态学基本概念（营养级调控、生活史权衡、干扰与多样性、关键种）；生命科学出了真核基因表达与表观遗传、自由能与糖酵解·酶催化（含 ΔG 计算）、肽类激素与信号通路、生物膜与物质运输；水圏·海洋科学出了鞭毛与趋性·海带生活史、鱼类生殖与内分泌调控、个体群增长模型、微生物环与初级生产·赤潮。题型以 50–400 字的论述为主，夹有填空、选择、计算和读图题。

### 口述試験 / 面接
- **官方形式**：秋季入试·10月入学：每人约15分钟，考察志望动机和志望领域的基础知识，日程在笔试前通知。秋季特别入试：小论文之后每人约15分钟，内容同样是动机和基础知识。春季入试：就毕业研究（或相当的研究）和/或研究计划发表15分钟，然后就发表内容和专门科目问答；会场备有投影仪和 Windows 电脑，发表文件用 U 盘带去。特别推荐入试：就提交的自我推荐书进行问答，时间和地点随受験票通知。
- **実際に聞かれた内容**：没有找到本専攻的公开体验记，实际问答内容不明。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：専攻入学定员 52 名。各轮人数（按要项募集人员表的栏位顺序读取）：秋季入试约50名；特别推荐入试（高专专攻科在学生）约5名；10月入学、秋季特别入试、春季入试各为若干名（要项注明“若干名”指数名至10名左右）。
- 専攻下设8个コース：植物生態·多様性生物学、生態遺伝学、分子生物学、動物生態学、海洋生物生産学、水圏生物学、森林圏フィールド科学、耕地圏科学。要项没有写哪个コース在某一轮不招生，是否接收取决于各教员，出願前联系时一并确认。
- 出願资格：日本的大学毕业或入学前一个月底前预计毕业；取得学位授与机构的学士学位；在外国完成16年学校教育；在外国取得相当于学士的学位（3年以上课程）；专修学校专门课程（4年以上）修了；大学在学3年以上的跳级者、满22岁经个别入学资格审查认定者等。后两类须事先接受资格审查，受理期间为 2026/5/8–5/14（特别推荐、秋季入试用，已过）、2026/9/3–9/9（秋季特别入试用，已过）、2026/11/6–11/12（春季入试用）。
- 特别推荐入试只面向日本的高等专门学校专攻科在学生；秋季特别入试面向英语能力优秀、学习意愿高的人。
- 共通出願书类：规定样式的入学願書；照片2张（4×3 cm，3个月内）；成绩证明书原件；毕业（预定）证明书原件；TOEFL／TOEIC／IELTS 成绩；规定的回信信封（贴 410 日元邮票）和收件地址标签；检定料汇款凭证；在留卡复印件（在日者）或护照复印件；中国的大学毕业者要交学信网的学历认证报告（在读者交学籍在线验证报告）；居住在 EEA 的人另交个人信息处理同意书。
- 本専攻追加书类：特别推荐入试要交自我推荐书（A4 4页以内，写至今的研究或学习经过、志望理由、想做的研究课题，可以放图表，要标页码）和校长或学科长的推荐信（A4 1页左右，涉及英语和生物学的学力）；春季入试要交小论文（日文约1,600字，写至今学了什么，含毕业研究内容、志望理由、今后的目标），口述时作为参考。
- 出願方式：到环境科学院教务担当窗口提交，或用简易書留邮寄（出願期间内必达，邮戳无效），信封上用红字写明是大学院出願书类。没有网上出願。书类不齐的不受理。
- 检定料 30,000 日元，用规定的汇款单缴纳，不退还。国费留学生、北海道大学特别助成项目的留学生、CSC 项目生免缴。需要事先资格审查的人，等审查结果出来后在出願期间内再缴。
- 入学料 282,000 日元，授業料半年 267,900 日元（全年 535,800 日元），均为预定额。入学手续：10月入学者在9月上旬前办完；4月入学者的入学手续材料于2月中旬寄出，3月上旬前办完。
- 考场在札幌校区环境科学院（札幌市北区北10条西5丁目）。要项列有东京会场（北海道大学东京办公室），但没有写明本専攻可以在东京受验。
- 另有“海外在住外国人留学生特别选拔”（在本国在线受验；4月入学的在前一年11月考、10月入学的在6月考），只限指定的専攻·コース，本専攻是否在列要向志望教员确认，要项每年2月下旬公布。
- 咨询：环境科学院教务担当，Tel 011-706-2204／2205，kyomu@ees.hokudai.ac.jp；専攻长联系邮箱 envsci@ees.hokudai.ac.jp。
