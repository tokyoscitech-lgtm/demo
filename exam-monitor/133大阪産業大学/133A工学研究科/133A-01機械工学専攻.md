## 🎯 入試内容（考什么）

### 語学 / 英語要件

- 本专攻10月、3月普通一般不考英语，也不需要提交外部英语成绩；飞び级科目为小论文与面接，未另列英语。

| 对象／条件 | 官方规定与适用范围 |
|---|---|
| 本专攻普通一般 | 科目表没有英语，书类表也没有本专攻TOEIC／TOEFL成绩提交；没有本专攻英语最低分、成绩换算或有效期条款 |
| 同册环境设计专攻（其他专攻） | TOEIC（含IP）或TOEFL（含自宅受验），成绩为出願最后日起前2年以内；英语公用／母语留学生以JLPT N1替代，均不能移植本专攻 |
| 博士后期（其他课程） | 另有英语能力证明书类，不能套给本修士 |
| 独立英语学位路线 | 当前英文课程介绍不构成2027英授专用招生要项；未取得本专攻独立英授日程或条件，不据英文网页推定英语应试 |

### 日本語要件

- 普通一般的出願材料与入学后在留手续分开判断：需要取得或更新“留学”在留资格者必须提供日语能力证明，接受下表任一证明；并非所有考生同时提交各项成绩。

| 适用对象／事项 | 官方要求 |
|---|---|
| 普通一般统一出願书类 | 本专攻没有统一列JLPT或EJU成绩为必交材料 |
| 入学后取得／更新“留学”资格 | JLPT N2以上；或EJU日语阅读、听力、听读合计200以上；或BJT400以上；或JPT525以上；或日语学习600小时以上 |
| 证明不足后果 | 不能证明所需日语能力，可能取消入学许可 |
| 面接／试验使用语言 | 要项未承诺英文作答或英语面接；须在事前咨询中向导师确认，不能据英文课程介绍推定英授招生 |

### 筆記試験（专门科目）

| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 普通一般选拔：无独立笔试 | 10月、3月均以研究计划书及演示问答进行选考。 | 2027募集要项第5页 |
| 飛び級：小論文（配点未公布，60分钟） | 仅本校指定年级及成绩优秀者路线，3月5日10:00–11:00；普通外校本科毕业生不能据此替代一般选拔。 | 2027募集要项第3、5页 |

- 选考综合笔试、面接等对应専攻的审查结果；要项没有公布科目分值、总分线或面接最低分。人数不满定员也可能不合格。
- 题目倾向（体验记，非官方）：尚未找到可核验、明确对应本専攻该选拔的考生题型记述。

### 口述試験 / 面接

- **官方形式**：普通一般10月、3月均为10:00开始的研究计划演示与问答，单人时长、配点及具体提问清单未公布；飛び級为小论文后的11:20开始面接。普通一般当天9:30集合。地点均为东校区4号馆2楼工学研究科事务室前。
- **実際に聞かれた内容**：尚未获取可确认属于本専攻的考生面接经历，不把学部推荐、小论文或大学职员招聘面试经验当作院试依据。

## 📝 详细信息

### 出願資格 / 定員

- 本専攻博士前期募集定员10名，为全部考试区分合计，不是10月与3月各10名。
- 基本资格为大学毕业或2027年3月预计毕业，外国学历通常为16年教育修了或2027/3/31前预计修了；另有学位授予、指定资格及个别认定路线。
- 外国15年教育等个别资格认定及年龄22岁以上的同等学力路线，需要在出願截止至少一个月前联系研究科接受资格咨询；不能直接按普通毕业资格交件。
- 飛び級仅面向本校设计工学部、工学部在学3年以上并以优异成绩修得规定学分者，且仅3月实施。
- 出願前必须向希望教员咨询；提交教员签名盖章的「指導予定教員承諾書」，出願后不能更改研究科或専攻。
- 基本材料包括入学愿书附最近3个月照片、履历书1与2、指导教员承诺书、成绩证明原件、毕业或预计毕业证明原件。外国证明非日文时附日文或官方英文译文；留学生另交载有英文姓名的在留卡或护照复印件。
- 研究计划书须与希望教员商议后制作，A4横写、下方标页码，页数不限并附指定封面；图表照片只能使用自己研究制作的内容，不能引用他人或互联网资料。在职者须另附雇主承诺书；姓名变化者附改名证据。
- 原则邮寄，窗口也受理，窗口为工作日9:00–17:00；邮寄至〒574-8530大阪府大東市中垣内3-1-1，大阪産業大学入試センター。受理后书类及检定料不退还。
- 检定料20,000日元，通过EX决済系统缴费，另加1,000日元支付手续费；注意保留入学愿书的整理番号用于缴费及UCARO出願联动。
- UCARO账户及出願联动用于打印受验票、查询结果，不替代纸质出願。3月受验票可在2027/3/3（周三）15:00–3/20（周六）23:59下载，须A4打印，彩色黑白均可；截图不能替代。
- 10月合格者入学金和手续书类期限2026/10/13（周二）–10/23（周五），书类邮戳有效；春学期其他费用至12/17（周四）。3月合格者2027/3/12（周五）–3/17（周三）一次办理缴费、邮寄书类，书类邮戳有效。
- 入学金250,000日元，本校毕业或预计毕业者100,000日元；年授业料754,000日元、教育环境充实费194,000日元。入学时含第一学期及初次会费合计734,450日元，首年秋学期另483,950日元；第二年费用可能随物价调整。
- 「留学」在留资格私费生可申请授业料30%减免，从秋学期扣除，入学时仍全额缴纳；平均每月汇款超过90,000日元（不含学费等）或日本扶养者年收入500万日元以上者不适用。留学经费支付能力须每月18万日元以上。
- 考试须按集合时间到场；开考超过30分钟不得受验。数学禁止计算器，电气电子・信息允许；携带纸质受验票及不具通信功能的计时工具。
- 外国人留学生在入学手续及入学时分别提交安全保障出口管理的特定类型申告、誓约；限制可能影响研究内容。国费及外国政府派遣生另行选考。
- 咨询：研究科事前咨询与资格问题 kougaku-nc@cnt.osaka-sandai.ac.jp；入试中心 nyushi@cnt.osaka-sandai.ac.jp、072-875-3001（代表），工作日9:00–17:00。

### 学费减免、给付及贷款

- 2027一般要项明确：本校学部毕业者可由各专攻推荐“入学前予約給付”，前期每专攻1名、标准修业年限内授业料等全额给付，约5月决定、不公开招募。普通一般给付为授业料等半期额、1年，前期各专攻在籍人数的2成以内，例年10月招募、12月决定；不是所有新生自动减免。
