## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 须提交外部英语成绩，不另设英语笔试，用外部成绩评价；在 TOEFL iBT（含 Home Edition）、TOEIC L&R、IELTS Academic（含机考）三种里选一种，在入学願書上勾选。
- 不受理：TOEFL ITP、TOEFL 的 Test Taker Score Report、TOEIC IP 的个人成绩表和 S&W、Speaking、Writing、Bridge、IELTS General Training。
- 有效期：2024/9/1 以后到出願期间结束（2026/7/10）为止受检的成绩。
- TOEFL：由 ETS 把 Institutional Score Report 直送学府（Institution Code 0440，Department Code 99），原则上 2026/7/24（周五）前到达；願書上填 Appointment Number；以前寄过的也要重新申请送分。
- TOEIC：出願时上传 Official Score Certificate（数字版或扫描 PDF）。IELTS：出願时上传 Test Report Form 扫描件，或由英检协会管辖办公室直接寄到学府（2026/7/24 必达）。来不及在出願期间提交的，须事先联系学府，并在 2026/7/24（周五）正午前用邮件提交。
- 配点、最低分和换算方法，入学試験案内没有记载。

#### 日本語要件
- 要项没有规定 JLPT 等的最低分数。外国人（日本的大学毕业或预计毕业者除外）须提交「日本語学力証明書」，原则上用所附样式，由日语教员或相当的人就说、听、写、读四项评价；用其他样式时须写明四项评价及评价方法。
- 笔试必须用日语作答，口述的质疑应答也用日语进行，实际上需要能用日语答题和答辩的水平。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 専門科目（配点、时长官方未公布） | 大学本科水平的统计学，加上医学·齿学·药学领域的统计学基础知识和应用思考力；范围依据統計関連学会連合「統計学の各分野における教育課程編成上の参照基準」（2014年8月）。共3题，第1题选择题，第2、3题记述题，全部必答，用日语作答 | 2027年度コース入学試験案内 |

- 一次选考按笔试、英语成绩证明和提交书类综合判定；二次选考的口述结果再与一次选考合在一起做最终判定。总分构成和合格最低分官方未公布。
- 考试时间、可带物品写在受験者心得里，要项没有记载。
- 特別選考枠（若干名）与一般枠考试科目相同，在願書上勾选区分（对象见出願資格）。

### 口述試験 / 面接
- **官方形式**：夏季：线上视频会议，只有一次选考合格者参加，需要自备带摄像头且能联网的电脑；就受験者心得里给出的课题做发表并接受提问，质疑应答用日语；综合评价基础与专门学力、研究能力和研究计划、提交书类，以及作为生物统计专家的素养和将来规划，也可能问到笔试出题范围内的内容。
- **実際に聞かれた内容**：没有找到本コース的可核实体验记。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：夏季10名（含特別選考枠若干名）；冬季不募集。学際情報学専攻全体100名，各コース人数是目安，可能按出願和考试情况增减。
- 特別選考枠的对象：现在在国内的大学或研究机构从事临床试验、临床研究、流行病学研究实务的人，或修了后预定在这类机构从事临床试验相关工作的人。
- 出願资格：日本的大学毕业或 2027/3/31 前毕业预定、在外国完成16年学校教育、在外国取得相当于学士的学位（3年以上课程）等(1)–(6)之一。按(6)个别入学资格审查出願的，须在 2026/6/1（周一）前用书留邮寄审查书类（当日邮戳有效，已截止），结果在 2026/6/29 前通知。
- 出願书类：网上入学願書·履历事项；学部4年（含教养课程）的成绩证明书（大学院修了者也交学部的；编入学者加交编入前的）；毕业（预定）证明书；检定料缴纳证明；研究計画書（所定样式）；自己推薦書（所定样式，自评基础学力和专门能力，可写生物统计、临床试验、流行病学方面的实绩和成果 URL，有統計検定合格证等证明的须一并提交）；推薦書（所定样式，由了解本人研究或实务能力的上司、毕业论文指导教员等直接上传到指定网站）；英语成绩证明；日本語学力証明書（对象者）。
- 本コース不用提交指導教員希望調査書（其他コース要交），也不用提交研究成果物。
- 出願全部通过指定网站入力和上传，只能选一个コース；同一时期不能同时报修士和博士。证书原件自己保管，书类原则上用日文或英文。
- 检定料 30,000 日元（银行转账、便利店、Pay-easy、信用卡，手续费自付；日本政府奖学金留学生免缴）。
- 入学料 282,000 日元，授業料前期 267,900 日元（年额 535,800 日元），均为预定额；日本政府奖学金留学生不征收。
- 需要考试上的照顾的，须在 2026/6/8（周一）前申请（已截止）；受験票和受験者心得在 2026/7/24（周五）前没收到的，要联系学務チーム。
- 咨询：学際情報学府 事務部学務チーム（〒113-0033 東京都文京区本郷7-3-1），Tel 03-5841-8769／8768，gakumu@iii.u-tokyo.ac.jp。合否不接受电话和邮件查询。
