## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般入试（夏季·春季）：不另设英语笔试，用外部成绩评价（外国語100分）。
  - 可交：TOEFL（PBT·iBT）的 Examinee Score Report 或 Test Taker Score Report、TOEIC L&R 公式认定证（2023年度以后的考试也可交数字公式认定证的打印件）、中央大学校内对面实施的 TOEIC-IP 成绩单。
  - TOEFL iBT Home Edition、Special Home Edition 不受理。
  - 须为考试日前5年以内受检的成绩原件，出願期间内随书类提交；考过两种以上的全部提交。换算式由専攻自定，不公布。
  - 参考：雅思成绩只限都市人間環境学、電気電子情報通信工学、応用化学専攻使用，本専攻不收。
- 社会人特別入学試験：同样用成绩评价；希望者可改为当场作答英文试卷（可带英和、和英词典各1本），选这一方式的不交成绩。
- 外国人留学生入学試験、自己推薦入学試験：不考英语，也不收英语成绩。

#### 日本語要件
- 一般入试、自己推薦、社会人特別：要项没有要求提交日语成绩。
- 外国人留学生入学試験：须交 JLPT N2（或旧2级）以上合格证明，或 EJU「日本語」合计200分以上（2年以内、最近4次）的成绩原件；日本的大学·大学院毕业者可不交。専門科目用日语作答；论文用英文写的须另附日文论文概略（A4 1页）。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 一般：専門 数学、情報（100分） | 6题选4题。2026年度夏季：线性代数、微积分、概率、统计学、二项分布与 Python 编程、关系数据库 SQL；春季结构相同（Python 数值计算、SQL 等） | 11:00–13:00，120分钟 |
| 外国人留学生：専門 数学、情報（100分） | 6题选4题，用日语作答 | 11:00–13:00，120分钟 |
| 社会人特別：専門 数学、情報（100分） | 6题选4题；按提交书类可能免笔试（事前通知） | 11:00–13:00，120分钟 |

- 一般入试：外国語（成绩）100＋専門100＋口述100，结合出願书类综合判定。
- 外国人留学生：书类·论文审查＋专门笔试＋口述综合判定。
- 自己推薦：不考笔试，书类（小论文）审查＋研究发表·面接。

### 口述試験 / 面接
- **官方形式**：一般·社会人特別·外国人留学生：口述100分，笔试结束后当天对全体考生实施，会场和时间当天公布；自己推薦：就自己正在做的毕业研究或研讨课研究发表10分钟以内（可用电脑和配布资料，学校备 Windows＋Office 电脑，数据存外部媒体带去并附打印稿1份），之后就发表内容和基础知识提问，并面接人物、研究意欲、适性。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：博士前期入学定员30名；一般入试20名（夏季·春季合计）；外国人留学生、社会人特別、自己推薦各若干名。
- 出願资格：大学毕业（含2027年3月预计）或外国16年学校教育并取得学士学位等；中国大学专科（3年制）毕业者须先通过个别入学资格审查（春季 2026/11/30 必达，非独立出願）。夏季合格者可选2027年4月或2026年9月入学，春季和留学生入试只能2027年4月入学。外国人留学生入试限外国籍，在日本读完普通高中者除外。自己推薦须 GPA 3.00以上，外国籍者限日本的大学毕业或在读。社会人特別须大学毕业满2年。
- 要提前准备的书类：一般入试为 TOEFL/TOEIC 成绩原件；中国学历可由 CHSI 直送学历·学位·成绩认证报告（并附打印件）；外国人留学生入试另需论文（题目自由，A4 5页以内，日文或英文）、研究计划书（A4 1页）、经费支付能力证明、日语能力证明，并在志願票取得希望指导教员的签名·盖章（可用承认邮件的复印件代替）；自己推薦另需履历书和小论文（想学的内容、研究计划、将来想从事的工作，约2,000字，所定用纸4份）；社会人特別另需研究计划书（A4 约5页，含图表）。
- 出願：先缴检定料35,000日元（便利店或信用卡），再把书类装角2信封以简易书留邮寄（截止日邮戳有效）或窗口提交；海外出願须由在日代理人邮寄；没有网上出願。
- 并愿：各要项没有说明不同入试或夏季·春季之间能否兼报；出願后不能更改専攻、课程和受验科目；指导教员只能填本専攻专任教员（不能填其他専攻、兼任和2027年度休讲的教员）。
- 咨询：理工三学部事務室 大学院担当（後楽園キャンパス，东京都文京区春日1-13-27），Tel 03-3817-1740，gsse-all-grp@g.chuo-u.ac.jp，或[问询表单](https://www.chuo-u.ac.jp/inquiry/form/?id=20)；出願资格有疑问要在缴检定料前问；不回答合否和成绩问题。
