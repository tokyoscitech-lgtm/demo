## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 出願日程A（夏入试）：英语不另设笔试，以 TOEFL 成绩代替。只收 TOEFL iBT 和 TOEFL iBT Home Edition。
- 提交方式有三步：①通过 ETS 把官方成绩寄送到东京大学工学系研究科（DI コード 8596，Department コード 99）；②在 WEB 出願系统的マイページ登记 Appointment Number 和受検日；③把 Test Taker Score Report 上传到マイページ。
- 本専攻的 TOEFL 提交截止为 2026/8/20（周四）（已截止）；截止前登记的 Appointment Number、受検日和 Score Report 可以反复更改。専攻入试案内写明：没有提交 Appointment Number 的，可能仅因此不合格。
- 有效期：修士课程收受検日（Test Date）在 2024年9月以后的成绩。
- 只采用 Test Date Scores，不采用 MyBest Scores；TOEFL ITP 等团体受検的成绩不能用。要项没有把 TOEIC、IELTS 列为可提交的考试。
- 母语是英语的人也必须提交 TOEFL 成绩。
- 要项和専攻入试案内都没有写 TOEFL 的配点、换算方法和最低分。
- 免除：东京大学大学院工学系研究科修士课程的修了（预定）者不需要考英语。
- 修士特別口述試験合格者的英语和専門科目笔试免除（普通的口述試験仍要参加）。

### 日本語要件
- 要项和専攻入试案内都没有要求提交 JLPT、EJU 等日语成绩。
- 専門科目的试题以日语和英语并记出题，可用日语或英语作答。口述試験用什么语言，専攻入试案内没有写。
- 日语、英语以外语言的证明书等，要附上原件和出身大学开具的盖章英译。

| 一般教育科目（数学） | 本年度不举行笔试 | 2027専攻入试案内 |

- 専攻试验科目页注明：各范围列出的关键词只表示重点，并不限定出题范围。
- 配点：専攻入试案内和募集要项都没有公布各科目的配点和总分。注意“150”是 2 题合计的作答时间（150分钟），不是分数。
- 合否判定和配属：按笔试和口述試験的成绩、提交书类的内容、志望的指导教员等综合决定。専門科目笔试和口述試験必须两项都参加，否则受験无效。
- 预备选拔：志願者多的时候，按専攻調査票的内容和成绩表进行预备选拔；有没有实施及其结果在 2026/8/14（周五）前掲載在専攻入试网页，审查标准不接受询问。本年度实际有没有实施，这次没有查到。
- 笔试免除：本専攻、電気·電子工学専攻、新領域創成科学研究科基盤情報学専攻和先端エネルギー工学専攻、情報理工学系研究科電子情報学専攻的修士课程修了（预定）者，不需要考英语和専門科目，只参加口述試験。
- 背景：専攻入试案内说明，为了让电气系以外出身的人也能报考，从2020年度实施的入试起调整了専門科目的构成、减少了题数。
- 题目倾向（体验记，非官方）：外部生的两类选法都有——有人选電磁気学＋電気回路，也有情报系出身的人选情報工学Ⅰ＋情報工学Ⅱ（理由是電気回路计算量大）。一位2023年受験者认为基础题约占八成，重点在于弄清东大本科讲到哪里；他是通过研究室访问和发邮件请教在读研究生，才知道该用哪些教科书的。専攻Q&A 也提到内部升学者多数准备一个月左右。

### 口述試験 / 面接
- **官方形式**：出願日程A（夏入试）的口述試験在 2026/8/31–9/3 线上进行，考生自备电脑、能拍到本人的摄像头和宽带网络。问志望分野及理由、该分野的基础事项，并让考生口头介绍毕业研究的内容。在指定的时间不参加的，视为放弃受験。配点、时长和使用语言，専攻入试案内没有写。修士特別口述試験（2026/7/18，线上）面向书类选考判定为成绩优秀、且以本専攻为第一志望的人，问志望分野及理由和该分野的基础知识。
- **実際に聞かれた内容**：（体验记，非官方）一位2023年8月受験的外部生写的是：约25分钟，约5名教员轮流提问；问了为什么选东大、想做的研究、笔试的自我评价、専攻調査票里写到的技术、本科的研究和研究生阶段想做的研究有什么不同，提前问完后闲聊了兴趣爱好（仅1人提及）。修士特別口述試験的具体提问内容只在收费文章里，这次没有读到；一位2024年受験的外部生写到自己特別口述不合格，之后改走普通的笔试＋口述并合格。

## 📝 详细信息
### 出願資格 / 定員
- 出願日程A（夏入试）的募集人员为70名（電気系工学専攻修士课程）。本専攻修士课程本年度不实施出願日程B（冬入试）。
- 出願资格：日本的大学毕业或 2027/3/31 前预计毕业；在外国完成16年学校教育（含预计）；取得相当于学士的学位（含预计）；文部科学大臣指定的教育设施修了；由学位授与机构授予学士学位；或通过个别入学资格审查且到 2027/3/31 满22岁，共6项之一。
- 入学时期：2027年4月入学。本専攻对满足研究科要件的合格者也认可2026年10月入学，须在出願时申报，与合否无关。新申请在留资格通常要在入学许可书发出后约3个月，専攻建议需要新办在留资格的人选4月入学。
- 指导教员的填写：出願时在线上登记希望指导的教员的优先顺序；専攻Q&A 说明在变更期间内可以从 WEB 出願系统的マイページ修改。可以填几名，専攻入试案内没有写。
- 出願书类：入学願書（线上填写）、证件照数据、检定料、出身大学的毕业证明书（已毕业者）、成绩证明书、安全保障出口管理检查表（外国籍者等）、専攻調査票和成绩集计表。本専攻对东京大学工学部毕业（预定）者也要求交成绩证明书。
- 専攻調査票：下载専攻指定的表格填写，写修士课程希望做的研究内容、毕业研究的题目、毕业后的打算；它是预备选拔和口述試験的资料。成绩证明书的内容要汇总到成绩集计表里，按各区分的取得学分数填写（教养科目也算；高専编入者把高専4、5年级的成绩全部算入）。两者与願書一起从 WEB 出願网站提交。页数限制，専攻入试案内没有写。
- 外国大学毕业者：证明书上要写明学位，没有写明的另交学位取得证明书；多份文件合成一个 PDF。
- 出願方式：只有 WEB 出願，没有邮寄和窗口。受験票于 2026/7/3（周五）15:00 左右在マイページ发放，自己打印后考试当天带去。
- 检定料 30,000 日元，可用便利店、Pay-easy（ATM·网银）、网络银行、中国决济或信用卡支付；日本政府（文部科学省）奖学金留学生免缴。已缴的检定料不论什么原因都不退，书类选考不合格也不退。
- 并愿限制：不能同时报工学系研究科的两个以上専攻或课程；也不能与其他大学或东京大学其他研究科重复入学。
- 安全保障出口管理：东京大学依据外为法在接收前和在学期间进行审查。属于规制事项的，即使最终合格也可能不被许可入学，或者入学后的研究活动受限；希望的指导教员的配属也可能因此受限。
- 入学料 282,000 日元，授業料 年 535,800 日元（前期 267,900 日元），均为预定额；日本政府奖学金留学生不征收。入学手续：10月入学者 2026/9/18（周五）前，4月入学者 2027/3/9（周二）前（均为预定）。
- 考场规则：带受験票、黑色铅笔或自动铅笔、橡皮、卷笔刀、尺、只有计时功能的手表；不能带圆珠笔，不能用手机、可穿戴设备等电子设备、计算器和词典。开考后即使答完或弃考也不能离场。専攻Q&A 说明笔试缺考原则上视为弃权。
- 有障碍等需要考试照顾的人，要在出願截止前向学務課大学院チーム申请。
- 成绩开示：募集要项没有写成绩开示的规定。
- 咨询：研究科方面为东京大学大学院工学系研究科学務課大学院チーム（〒113-8656 東京都文京区本郷7-3-1），关于募集要项的问题用研究科网站的咨询表单（https://www.t.u-tokyo.ac.jp/about/info/contact/examination-graduate-school ）。専攻方面的入试咨询邮箱为 eeis-nyushi27-group@g.ecc.u-tokyo.ac.jp。要项没有写受理咨询的电话号码。
