## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般8月、一般1-2月：
  - 出願时提交外部英语成绩单，作为「外国語」评分，配点 100 分；不另设英语笔试。
  - 可用 TOEIC Listening & Reading（公开）、TOEFL iBT（含 Home Edition）、IELTS Academic（纸笔或机考）；须为 2024年7月以后受检、成绩单印有本人照片。在日本以外受检的 TOEIC 公式认定证贴在 Web 出願系统下载的台纸上。
  - 不受理 TOEIC IP、TOEFL ITP、IELTS General Training、IELTS Academic 在线版；成绩单不退还。
  - 出願时没有交齐符合条件的成绩单，外国語按缺考处理，不进入选考。本プログラム没有英语成绩免除，海外大学毕业者也要交。
  - 要项没有公布换算方法，也没有最低分。
- 推薦（7月）和社会人特别选拔：不考外国語，不用交英语成绩。

#### 日本語要件
- 要项没有要求提交日语成绩。
- プログラム FAQ 写明口述可用日语或英语作答；研究计划可用日文（约1000字）或英文（约500词）。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 没有专门科目笔试（一般8月、一般1-2月） | 基础学力改在口述中口头试问（口述400分的一部分） | 2027募集要项 |
| 口述中的数学（必答） | 解析：微分法、泰勒定理、积分、级数、偏微分、重积分、微分方程等；线性代数：矩阵、行列式、向量空间、线性映射、特征值与特征向量等 | 口述试验的内容（2026年7月版） |
| 口述中的物理（出願时 3 选 1） | 力学：质点与质点系的运动、功与能量、刚体力学等；熱力学：第一·第二定律、状态方程、熵、自由能与一般关系式等；電磁気学：电荷、库仑定律、电场、高斯定律、安培定律、磁场、电路、电磁感应等 | 口述试验的内容（2026年7月版） |
| 外国語（100分） | 外部英语成绩换算 | 2027募集要项 |

- 一般入试总分 500（外国語 100＋口述 400）；推薦和社会人特别选拔只有口述 200 分。合格最低分没有公布。
- 官方列出的参考教科书（本校工学システム学類使用的例子）：『入門講義 微分積分』（裳華房）、『明解線形代数 改訂版』（日本評論社）、『基礎物理学 力学』『基礎物理学 電磁気学』（培風館）、『熱力学』（共立出版）。プログラム FAQ 说明考的是本科基础，重点看是否理解并讲得清楚。
- 题目倾向（体验记，非官方）：没有找到本プログラム考生写的体验记。

### 口述試験 / 面接
- **官方形式**：一般8月、一般1-2月：对面个别面接，400分，约25分钟，先问姓名、现所属、志望研究室和志望理由，再做基础学力试问（数学必答＋出願时选定的物理1科），进考场前约20分钟可先看题，作答时口头说明，可在发的纸上边算边画，不用白板，可用日语或英语，候考期间不能用可联网的电子设备，不能线上受验；推薦（7月）：对面，200分，就专门领域和志望提问（已结束）；社会人特别选拔：200分，约15分钟研究内容与研究计划发表（自带笔记本电脑）后提问。
- **実際に聞かれた内容**：没有找到本プログラム的体验记。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：推薦（7月）34名；一般8月 29名、社会人特别选拔8月 2名；一般1-2月 1名、社会人特别选拔1-2月 2名。
- 入学时期：推薦和一般8月为 2027年4月；一般1-2月可选 2027年4月或10月。
- 出願资格：日本4年制大学毕业（含预计）、在外国完成16年学校教育、在外国取得相当于学士的学位（3年以上课程，须事前确认）、或年满22岁并通过个别资格审查者等。个别资格审查的截止：1-2月期 2026/11/24（周二），向システム情報エリア支援室大学院教務邮件申请。
- 所有出願者都要事先取得志望指导教员的内诺；第2志望可填可不填，填了也要取得其内诺。合格后没有另行通知就配属第1志望教员的研究室。只能任副指导的连携教员须与主指导配对并取得两人的内诺，两人须在研究群教員検索システム里属于同一研究领域。
- 外国籍考生（永住者等除外）须由志望教员告知「リファレンス番号」并在 Web 出願时输入；全员都要在 Web 出願时回答みなし輸出的特定类型确认。
- 出願书类：Web 入力（证件照 JPEG、志望教员、研究计划——日文约1000字或英文约500词，不能含图表；有公式等无法输入的另交所定样式研究计划书；口述物理科目在出願时选定）、毕业（预定）证明书和成绩证明书原件（日文或英文）、外部英语成绩单（一般入试）、检定料收纳证明；在学或在职者交受験·就学承认书；中国大学毕业者交学信网（CHSI）英文学历认证报告。
- 出願方式：先在 Web 出願系统入力，再把书类装角形2号信封贴宛名シート，書留邮寄或送窗口（最后一天 17:00 前）至システム情報エリア支援室，截止日必达。一个账号只能报一个学位プログラム；日程不冲突可分别报其他プログラム，但口述时间不调整。
- 检定料 30,000 日元（信用卡或便利店，手续费自付，缴后不退）；国费外国人留学生免缴。
- 入学料 282,000 日元；授業料 年 535,800 日元，外国人留学生（留学签证）年 608,800 日元。
- 受験者心得在考试一周前登在入试网站「お知らせ」栏；必须在指定集合时间前到场。1-2月入试可能有追加合格，4月入学者在 2027年3月中旬前后电话等联系。
- 外国人研究生是另一条路线（大学的研究生制度）。这不是修士入试的要求。
- 咨询：入试 infoexam@kz.tsukuba.ac.jp（プログラム负责人 金久保 利之 教授）；事务室 工学系F棟3階 F300，Tel 029-853-5059／5203；出願资格事前确认 admission.grad@un.tsukuba.ac.jp。
