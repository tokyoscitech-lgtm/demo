## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 8月入试、2月入试相同：不另设英语笔试，用外部成绩评价。
  - 收 TOEIC L&R 公开测验、TOEFL iBT（含 Home Edition）、IELTS、Duolingo English Test 之一，须为 2024/4/1 以后受检；TOEIC IP、TOEFL ITP 不受理。
  - 按换算表折成100分制（TOEIC／TOEFL iBT／IELTS／Duolingo → 换算分）：580／61／5.0／80 → 59；729／79／6.0／105 → 74；867／100／7.0／130 → 88；986／111／8.0以上／150 → 100。
  - 可随出願书类提交，也可后交（简易書留）：8月入试 2026/7/21（周二）16:00 必达（已截止）；2月入试 2027/1/18（周一）16:00 必达。截止前没交的，英语按缺考处理；交后不能退回或更换。
- 国費留学生优先配置：须满足 CEFR B2（TOEFL iBT 79 或 IELTS 6.0 以上，四技能各 B2 以上）、用英语授课取得学士学位、或有同等英语能力证明之一。

#### 日本語要件
- 8月入试、2月入试：要项没有要求提交日语成绩；考过日本语能力试验的外国人留学生可附合格证或成绩通知书复印件。出願书类可用英文填写；8月入试专门笔试外国人考生可用英语作答；口头试问和2月口述试验用日语进行，可用英语回答。
- 国費留学生优先配置：须满足 JLPT N2 以上、用日语授课取得学士学位、或有同等日语能力证明之一。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 8月入试：专门科目 | 解析·线性代数、概率·统计、程序设计（以 Python 3 为准）3个科目，全部作答 | 12:30–15:30，180分钟 |
| 2月入试：专门口述试验 | 无笔试；解析·线性代数、概率·统计2个科目口头作答，不考程序设计 | 每人约30分钟（含口头试问） |
| 国費留学生优先配置 | 无笔试，书类审查＋网上面试 | |

- 8月入试按笔试、口头试问和出願书类综合判定，笔试后被判断为不需要口头试问的按笔试和书类判定；2月入试按口述试验·口头试问成绩和出願书类综合判定。
- 题目倾向（2025年8月过去问）：解析·线性代数3大题（二阶常微分方程、二次型的特征值与极值、换元积分与复积分），概率·统计2大题（组合概率与条件概率、期望·方差与最大值分布），程序设计1题（读二维数组连通区域标记的 Python 程序，填空并写运行结果）；都是要写过程的计算题。
- 题目倾向（体验记，非官方）：程序设计被认为最难——2025年8月考连通区域标记·Union-Find 的程序填空，2021年8月（当时为C语言）考读程序并分析 bug 原因（各1人提到）；复积分、带参数二次型、微分方程是反复出现的题型（2021年8月、2025年8月，2人提到）。

### 口述試験 / 面接
- **官方形式**：8月入试口头试问 2026/8/6 13:00 起对面进行，只叫笔试后被判定需要的人（对象者当天10:00左右在研究科网站公布，没被列入不等于不合格），笔试结束后发「课题」，口头试问时就课题做逻辑说明，说明资料只能是1张 A4 单面手写稿、用实物投影仪投影；2月入试 2027/2/9 对面进行，每人约30分钟，先口述作答解析·线性代数和概率·统计，再就毕业研究等一般事项口头试问（没做毕业研究的可用学部研讨课内容或在本研究科想做的研究代替），须准备以往研究内容概要（A4 一页左右）；两轮都用日语进行、可用英语回答；国費留学生优先配置为书类审查后网上面试，可能追加邮件或视频面谈。
- **実際に聞かれた内容**：
  - 课题说明约3分钟，资料是手写图示：2021年8月的课题是机器学习中偏差-方差权衡及其对策（2021年8月、2025年8月，2人提到）。
  - 志望动机、入学后想做的具体研究（2021年8月、2025年8月，2人提到）。
  - 还报了哪些学校、都合格时怎么选（2021年8月、2025年8月，2人提到）。
  - 分不到第1志望研究室时是否仍入学（2021年8月、2025年8月，2人提到）。
  - 自我介绍、有无读博意向（2021年8月、2025年8月，各1人提到）。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：本専攻定员40名，8月入试40名；2月入试若干名；国費留学生优先配置项目研究科全体4名（2027年10月入学，未限定専攻）。
- 出願资格：大学毕业（含预计）或外国16年学校教育等；资格(8)(9)（在学3年以上成绩优秀、个别资格审查，后者须 2027/3/31 前满22岁）须事先审查（非独立出願）：8月入试 2026/6/5 截止（已截止），2月入试 2026/12/1（周二）16:00 必达、12/15 前通知；志願理由書不写教员名，而在第1–10志望栏全部填研究小组代码（6A–6L），可能被分到志望以外的小组。
