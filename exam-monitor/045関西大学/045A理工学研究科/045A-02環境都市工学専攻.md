## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各分野做法不同：
  - 建築学分野：不另设英语笔试，外语不计分；一般、外国人留学生、社会人入学試験出願时都要交 TOEIC 或 TOEFL 成绩。
  - 都市システム工学分野：不另设英语笔试，一般、外国人留学生入学試験把出願时交的 TOEIC 或 TOEFL 成绩换算为 100 分；社会人入学試験也要交成绩。
  - エネルギー環境・化学工学分野：一般和外国人留学生都考学内英语笔试 100 分（13:30–15:00，90分钟），不交成绩。
- 成绩种类：TOEIC L&R 公开考试（日本国内受验交「デジタル公式認定証」A4 打印件，海外受验交 Official Score Certificate 原件）；TOEFL iBT（须向 ETS 办直送，机构代码 G128，并交 Test Taker Score Report 打印件和直送完成画面打印件）。
- 只认各轮出願开始日往前2年以内的成绩；TOEIC IP 等团体考试、TOEFL ITP、TOEFL iBT Home Edition 不受理，MyBest Scores 不采用。
- 特別選抜入学試験（建築学、エネルギー環境・化学工学分野）不交英语成绩、不考外语。
- 变更点：2027年度起社会人入学試験的建築学、都市システム工学分野新增 TOEIC/TOEFL 成绩提交。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 建築学分野外国人留学生的专门科目是用日语作答的专业小论文；エネルギー環境・化学工学分野留学生的综合问题可用日语或英语作答；外国人留学生的志望理由書、研究計画書可用日文或英文写。

- 总分：一般 450（建築学 専門300＋口頭試問150；都市システム工学 専門250＋英语换算100＋口頭試問100；エネルギー環境・化学工学 専門250＋英语100＋口頭試問100）；外国人留学生 400（建築学 小論文250＋口頭試問150；其余两分野 専門200＋英语100＋口頭試問100）。
- 一般·外国人留学生按笔试和口頭試問总分从高到低决定合格，任一项低于基准分可判不合格，合格者可能少于定员；社会人·特別選抜按口頭試問得分决定。
- 官方「出題意図・解答のポイント」：重视原理理解，要求准确写出定义、定律、公式及前提和单位，按步骤写推导，必要时配图和式子。

### 口述試験 / 面接
- **官方形式**：一般（8月募集）·外国人留学生（10月·2月·7月募集）：笔试当天笔试后进行口頭試問，建築学分野 150 分、都市システム工学和エネルギー環境・化学工学分野各 100 分，开始时间当天通知；社会人（10月·2月募集）·特別選抜（2月募集）：无笔试，口頭試問（含口答·笔答）问出願书类、志望分野基础科目，并做 5–10 分钟的自我推荐或课题发表（有2年以上实务经验者讲所在机关业务和入学后研究计划），准备资料先向志望教员确认。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：86名（専攻入学定员，不按入学学期、入试种别和分野分设名额）；特別選抜若干名（建築学、エネルギー環境・化学工学分野招，都市システム工学分野不招）。
- 出願资格：一般为大学毕业（含预计）或外国16年学校教育等，资格(9)(10)须先通过个别入学资格审查（书类＋口头试问，申请必达：8月募集 6/4、10月募集 6/25、2月募集 11/19、秋学期7月募集 2027/4/15，均为非独立出願），外国学历不足16年但有学士学位的尽早咨询；外国人留学生入学試験限外国16年教育、在日以留学生身份大学毕业等，在日本小中高在籍合计4年以内视同外国学历；社会人须在同一机关工作2年以上且入学时满25岁；特別選抜不收本校システム理工·環境都市工·化学生命工·工学部应届毕业生，2028年度起建築学分野不再实施特別選抜。
- 要提前准备的书类：志望理由書（所定用纸，本人手写，填写联系教员的日期和教员姓名）；TOEIC/TOEFL 成绩（建築学、都市システム工学分野）；外国人留学生和社会人另交研究計画書（约1,000字，A4 横写 40字×40行，原件1份＋复印3份）；社会人加交業績報告書；特別選抜加交推薦書（所定格式，密封，原则上由第三者写）。
- 出願：先在 Web 出願门户登记并缴检定料 35,000 日元（另加系统手续费），再用簡易書留速達邮寄书类（截止日邮戳有效）或在窗口提交；海外用国际快递截止日必达并邮件告知追踪号；只做网上登记不算出願。
- 并愿：一般入学試験只在8月募集实施，外国人留学生可报10月、2月和秋学期7月募集（外国人留学生报2月募集须走外国人留学生入学試験，不能报特別選抜）；个别资格审查一次认定后，同年度同研究科其他日程不必再审；出願后不能更改研究领域和受验科目。
