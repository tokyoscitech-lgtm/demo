## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 三个分野的做法不同（8月募集一般入学試験和10月·2月募集外国人留学生入学試験相同）：
  - 建築学分野：不考英语笔试，外国語没有配点；但一般、外国人留学生、社会人三种入试都要求出願时提交 TOEIC 或 TOEFL 成绩。要项没有写这份成绩怎样计入评价，也没有最低分。
  - 都市システム工学分野：不考英语笔试，把出願时提交的 TOEIC 或 TOEFL 成绩换算成 100 分（一般、外国人留学生）。社会人入学試験也要交成绩。
  - エネルギー環境・化学工学分野：考场笔试「外国語（英語）」100 分，13:30–15:00（90分钟），一般和外国人留学生都考；不用交 TOEIC/TOEFL。
- 可用的成绩：TOEIC L&R 公开考试（在日本国内考的交「デジタル公式認定証」的打印件，在国外考的交 Official Score Certificate 原件）；TOEFL iBT（向 ETS 办理成绩直送，机构代码 G128）。
- 不受理：TOEIC IP 等团体特别受验制度的成绩、TOEFL iBT Home Edition、TOEFL iBT 的 MyBest Scores。
- 有效期：各轮出願开始日往前2年以内受检的成绩（2月募集即 2024/12/18 以后）。
- 要项没有写换算公式或换算表，也没有写最低分。
- 特別選抜入学試験（2月募集）：建築学、エネルギー環境・化学工学分野都不用交英语成绩，也不考外国语。
- 英语笔试的出题意图（官方「出題意図・解答のポイント」）：以阅读专业、学术英文为主，考查结合上下文理解专业术语和句子结构、把握多段落的主张与因果关系、词汇语法，要求自由作答时写简洁合乎逻辑的英文。

### 日本語要件
- 要项没有要求提交 JLPT、日本留学試験等日语成绩，外国人留学生入学試験的出願资格里也没有日语等级条件。
- 但建築学分野外国人留学生入学試験的专门科目是用日语写的「専門に関する小論文」，实际需要日语写作能力；エネルギー環境・化学工学分野留学生的综合问题可以用日语或英语作答。外国人留学生的志望理由書和研究計画書可以用日文或英文写。口頭試問用什么语言，要项没有写明。

- 一般入学試験（8月募集）总分各分野都是 450：建築学为 専門 300＋口頭試問 150；都市システム工学为 専門 250＋英语（TOEIC/TOEFL 换算）100＋口頭試問 100；エネルギー環境・化学工学为 専門 250＋英语笔试 100＋口頭試問 100。
- 外国人留学生入学試験（10月·2月募集）总分各分野都是 400：建築学为 小論文 250＋口頭試問 150；都市システム工学为 専門 200＋英语换算 100＋口頭試問 100；エネルギー環境・化学工学为 専門 200＋英语笔试 100＋口頭試問 100。
- 判定方法：一般入学試験和外国人留学生入学試験综合书类选考、笔试、口頭試問的结果判定；社会人入学試験和特別選抜入学試験按口頭試問得分从高到低决定合格者。
- エネルギー環境・化学工学分野的专门科目由考场借给函数计算器和尺子；其他场合计算器、尺子、词典都不能带。
- 官方「出題意図・解答のポイント」（理工学研究科共通）：重视对原理的理解而不是死记，答题时要准确写出定义、定律、公式及其前提和单位，按顺序简洁写出推导，必要时用图和式子。
- 题目倾向（体验记，非官方）：没有找到本専攻的考生体验记。

### 口述試験 / 面接
- **官方形式**：各轮都在笔试当天、笔试结束后进行口頭試問。
  - 一般入学試験（8月募集）和外国人留学生入学試験（10月·2月募集）：建築学分野 150 分，都市システム工学分野和エネルギー環境・化学工学分野各 100 分；要项没有写时长和具体问题。
  - 社会人入学試験（10月·2月募集）和特別選抜入学試験（2月募集）：问①出願书类的内容，②志望分野和研究領域的基础科目，③自我推荐或发表。入学时在企业、教育·研究机关等连续有2年以上实务经验的人，要做 5–10 分钟的发表，讲所在机关的业务内容和入学后的研究计划；其他人做关于大学院学习研究的自我推荐，或就指定课题做发表。说明资料或作品要事先准备，准备什么要先向志望研究領域的教员确认。要项没有写配点。
- **実際に聞かれた内容**：没有找到本専攻口頭試問的体验记。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：環境都市工学専攻（博士課程前期課程）的入学定员是 86 名；要项写明不按入学学期和入试种别分别设定募集人员，所以8月募集、10月募集、2月募集各招多少、各分野各招多少都没有数字。特別選抜入学試験为若干名。
- 各入试种别实施的轮次：一般入学試験只有8月募集；外国人留学生入学試験有10月募集、2月募集（2027年4月入学）和7月募集（2027年秋学期入学，本専攻只有エネルギー環境・化学工学分野招，建築学和都市システム工学分野不招）；社会人入学試験有10月募集、2月募集；特別選抜入学試験只有2月募集；学内進学試験（6月、2月）只面向本校在读生。
- 一般入学試験的出願资格共10项：大学毕业或预计毕业、取得学士学位、在外国完成16年学校教育、在外国取得相当于学士的学位（3年以上课程）等；第(9)(10)项（飞跃入学、个别审查认定同等学力且入学时满22岁）要先通过个别入学资格审查。
- 外国人留学生入学試験的出願资格共5项：在外国完成16年学校教育；以外国人留学生身份在日本的大学毕业；在外国大学完成3年以上课程并取得相当于学士的学位；以外国人留学生身份完成日本指定专修学校专门课程；经个别入学资格审查认定。在日本的小学、初中、高中等在籍合计4年以内的人，按第(1)项同样处理。
- 社会人入学試験：学历条件和职历条件都要满足——入学时在同一机关工作满2年以上（或预计满），且入学时满25岁（现职教员或有教员经验者为22岁）；部分资格要先经个别审查。
- 特別選抜入学試験（2月募集）：出願资格与一般入学試験相同，外国人留学生要报同一天的外国人留学生入学試験；建築学、エネルギー環境・化学工学分野招，都市システム工学分野不招；本校システム理工学部·環境都市工学部·化学生命工学部·工学部的应届毕业预定者不能报（该格为×，以要项第18页原表为准）；要另交推薦書（本校所定格式、密封，原则上由第三者写），有社会人经验的加交业务·研究经历与研究计划、学术业绩（各4部）。
- 出願书类（一般入学試験）：出願確認票（Web 登记、缴费后打印，建议彩印）、志望理由書（本校所定用纸，本人手写，贴3个月内照片，写明联系教员的日期和教员姓名）、出身大学的成绩证明书原件、毕业（预计）证明书原件（成绩证明书上有记载的可省）、出願书类一览（检查表）、TOEIC/TOEFL 成绩（仅建築学和都市システム工学分野）、在留卡或护照复印件（外国籍，特别永住者除外）。成绩证明书多页的每页要有校印或签名，有留学或空白期的要附理由书，编入学的还要交之前大学的成绩证明书。
