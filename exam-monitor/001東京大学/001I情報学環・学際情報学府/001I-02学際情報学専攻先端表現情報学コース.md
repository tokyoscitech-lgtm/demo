## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 不另设英语笔试，用外部成绩评价；TOEFL iBT（含 Home Edition）、TOEIC L&R、IELTS Academic（含 Computer Delivered）三选一，願書上只能勾选一种。
- 有效期：2024/9/1 以后到出願受付结束（2026/7/10）之间受检。
- TOEFL iBT：由 ETS 直送官方成绩（Institution Code 0440，Department Code 99），原则上 2026/7/24（周五）前到达；願書填 Appointment Number，以前寄过的也要重新申请送分。
- TOEIC L&R：上传 Official Score Certificate（数字版或扫描 PDF）。IELTS：上传 Test Report Form 扫描件，或由英检协会管辖办公室直送（7/24 必达）。来不及随出願提交的，事先联系学府，2026/7/24（周五）正午前用邮件提交。
- 不受理：TOEFL ITP、TOEFL Test Taker Score Report、TOEIC S&W／Speaking／Writing／Bridge／IP、IELTS General Training。

#### 日本語要件
- 外国人（日本的大学毕业或预计毕业者除外）须提交「日本語学力証明書」，原则上用コース入试案内所附样式，由日语教员或相当的人就说、听、写、读四项评价；用其他样式时须写明四项评价及评价方法。
- 出願书类原则上用日文或英文，其他语言须附日译或英译。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 一次选考：书类选考（无笔试） | 英语成绩＋研究計画書、自己推薦書、推薦書、成绩证明书、指導教員希望調査書；特別選考枠另交ポートフォリオ |  |
| 専門科目范围（口述时可能试问） | 一般选考：数学共通（线性代数、微积分、微分方程）＋情报相关选择领域（電子情報学／機械情報学／都市工学／社会基盤学，或人間・環境／歴史・文化／メディア・コミュニケーション）的基础学力；特別選考枠只涉及选择领域 |  |

- 共通要项写明只有社会情報学、総合分析情報学、生物統計情報学三个コース考笔试；本コース一次选考按英语成绩和书类判定，案内列出的専門科目是口述时可能试问的范围。
- 一次选考合格者进入二次选考（口述），最终结果与一次选考合并综合判定。
- 特別選考枠：面向在媒体技术相关的设计、艺术表现领域有显著作品制作或发表实绩的人（媒体艺术、媒体设计、产品设计、信息设计、娱乐内容、都市·防灾设计、教育内容等），名额占募集人员三分之一左右以内。

### 口述試験 / 面接
- **官方形式**：夏季：只有一次选考合格者参加，用线上会议系统远程进行（需带摄像头、能联网的电脑），用画面共享发表修士研究计划和以往研究实绩（特別選考枠加讲ポートフォリオ），本人说明10分钟以内，之后可能试问基础与专门学力（含案内専門科目范围）（已结束）。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：28名（只在夏季募集，其中特別選考枠三分之一左右以内），学際情報学専攻全体100名（含アジア情報社会コース13名），合格人数可能不足募集人员。
- 出願资格：大学毕业（含 2027/3/31 前预计）或外国16年学校教育等；资格(6)个别审查书类 2026/6/1（周一）前书留邮寄（邮戳有效，已截止，非独立出願）；同一时期只能报学府一个コース，也不能同时报修士和博士。
- 要提前准备的书类：研究計画書（所定样式）；自己推薦書（所定样式，有信息学相关实绩的写上网址）；推薦書（上司或毕业论文指导教员等撰写，本人取得受付番号后委托其直接上传）；英语成绩；日本語学力証明書（外国人）；特別選考枠另交ポートフォリオ（PDF，书式自由，合作作品写明本人贡献，视频·网页链接只作参考，须保持可访问到二次选考合格发表）。
- 出願：只能在指定网站填写和上传，7/10 12:00 前上传完成；检定料 30,000 日元（日本政府奖学金留学生免缴）。
- 咨询：学際情報学府 事務部学務チーム（東京都文京区本郷7-3-1），电话 03-5841-8769／8768，gakumu@iii.u-tokyo.ac.jp。合否不接受电话和邮件查询。
