## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 夏季入试：
  - 専攻不另设英语笔试，用外部成绩评价：提交 TOEFL iBT（含 Home Edition）或 TOEIC Listening & Reading 公開テスト的官方成绩，二选一，配点 120 分；其他考试不能代替。
  - 换算（得分率，区间内线性插值，超出按端点计）：TOEFL 0分＝0%、48分＝45%、95分＝90%、105分以上＝100%；TOEIC 10分＝0%、650分＝45%、990分＝90%。例如 TOEFL 95＝108分，TOEIC 990＝108分（TOEIC 最多只能拿到90%）。
  - 提交截止 2026/8/5（周三）（已截止）；受检日在 2024年9月以后有效；没有最低分。
  - TOEFL：通过 ETS 向 DI 代码 8596、Department 代码 99 送分，在マイページ登记 Appointment Number 和受检日并上传 Test Taker Score Report；只采用 Test Date Scores，不采用 MyBest Scores；TOEFL ITP 等团体受检成绩不受理；母语是英语的人也要交。
  - TOEIC：在 WEB 出願系统登记数字公式认定证的 URL，或上传纸质认定证扫描件并把原件寄到化学·生命系事務室。
  - 变更点：本年度起新增 TOEIC L&R（上年度只收 TOEFL）。
- IME 国际项目：TOEFL 优先，也收 IELTS；成绩在书类截止时须在2年以内；另要 GRE General（5年以内，DI 代码 8596）。用英语授课的大学出具的证明或英语母语者的国籍证明可以代替英语成绩。

#### 日本語要件
- 一般选拔和 IME 国际项目都没有要求提交日语成绩（JLPT 等）。
- 夏季入试的笔试题册默认为日文，希望用英文题册的在 WEB 出願系统指定栏申请；口述使用的语言専攻入试案内没有写明。IME 国际项目的授课和研究指导用英语。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 専門科目「化学及び化学工学」（450分，150分钟） | 5题选3题：物理化学2题（热力学、化学反应论、量子化学等）、无机化学1题、化学工学2题（移动现象、反应工学、单元操作、过程系统工学等） | 2027専攻入试案内 |
| 一般教育科目 | 不考 | 2027修士募集要项 |
| IME 国际项目：书类审查＋笔试·口述 | 研究科国际项目共通要项写明综合书类、笔试和口述评价，看学业成绩和外语能力；具体科目官方没有公布 | 国际项目共通要项 |

- 夏季入试先做书类选考（看基础学力和与本専攻的适合度，重点是「志望動機およびキャリアプラン」），结果在 7 月上旬交付受験票时邮件通知；通过者参加笔试和口述。
- 夏季入试按英语（120分）、笔试（450分）、口述三项综合判定，三项都必须参加，缺一项即不合格；口述配点官方未公布。
- 题目倾向（体验记，非官方）：没有找到本専攻的考生体验记。

### 口述試験 / 面接
- **官方形式**：夏季入试有口述，每人约10分钟，问志望动机与职业规划、修士阶段想做的研究、化学システム工学相关的基础学力，配点未公布，形式和语言详细随受験票通知，迟到不能受验；IME 国际项目有口述（面试），日程和形式个别通知。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：夏季入试 28 名（含 2026年10月入学者和外国人特別選考，每个研究室大约1–5名）；IME 国际项目名额未公布（“若干名”）；本年度修士没有冬季一般选拔。
- 出願资格：日本的大学毕业或 2027/3/31 前预计毕业、在外国完成16年学校教育、在外国取得相当于学士的学位（3年以上课程）、学位授与機構授予学士等6项之一；10月入学的期限换成 2026/9/30。个别入学资格审查（资格6）的书类截止 2026/4/21（周二）（已截止）。
- 外国人特別選考（夏季入试内）：对象是外国的大学毕业或预计毕业的外国人，必须事先联系志望教员并取得受验许可；考试科目与一般选考相同，没有单独的名额和日程；合格后配属到该教员的研究室。
- 研究室志望：从専攻入试案内的研究室一览选；志望不影响合否，配属在合格发表后通知，合格者要主动联系配属教员。
- 出願书类：入学願書（WEB 输入）、证件照数据、检定料缴纳证明、毕业证明书（已毕业者）、成绩证明书、出口管制检查表（外国籍、双重国籍、入学前所属为海外机构者）、国费留学生证明（该当者），以及本専攻指定的「志望動機およびキャリアプラン」（从専攻入试信息页下载样式）。全部做成 PDF 上传；日语·英语以外的证明附出身大学盖章的英译。
- 出願方式：只能通过 WEB 出願系统，没有邮寄和窗口受理；受験票 2026/7/3（周五）15:00 前后在マイページ交付。
- 检定料 30,000 日元，便利店、Pay-easy、网银、中国决济或信用卡支付，缴纳后不退；国费留学生免缴。
- 并愿限制：不能同时报工学系研究科两个以上専攻或课程。
- IME 国际项目：只收不具日本国籍、申请期间不在日本居住的人；日本的大学在读或毕业者、日本永住者等原则上不能报；只能报一个国际项目；检定料 10,000 日元；9月轮自动参加奖学金评选，1月轮没有 IME 奖学金。
- 入学时期：4月入学，也接受 2026年10月入学；新申请在留资格的外国籍考生研究科建议考虑4月入学。入学料 282,000 日元，授業料 年 535,800 日元（前期 267,900 日元），均为预定额；4月入学者入学手续截止预定 2027/3/9（周二）。
- 考场规则：必带受験票、黑色铅笔或自动铅笔、橡皮；可带能算指数·对数的计算器、只有计时功能的手表、小型卷笔刀；手机不能当计算器或手表用。笔试和口述都要在开始前30分钟入场；笔试迟到30分钟以内可入场。
- 咨询：専攻入试找常務委員 小倉 賢 教授（admission@chemsys.t.u-tokyo.ac.jp，Tel 03-5452-6321）；募集要项的问题用研究科网站的问询表单（工学系研究科学務課大学院チーム）；不接受合否查询。
