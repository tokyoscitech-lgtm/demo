## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各轮次都不另设英语笔试，用外部成绩评价：只收 TOEFL iBT 的 Test Taker Score Report 或 TOEIC L&R 公式认定证，配点 100 分。
- 换算：TOEFL＝1.0×分数；TOEIC＝0.134×分数－32.66；小数点以下进位，上限 100 分。例如 TOEFL 90＝90 分，TOEIC 860＝83 分。
- 成绩须为出願截止日前2年以内受检；Home Edition 可以，TOEFL Essentials、ITP、TOEIC IP 和 IELTS 不受理；考过多次的只交1份。2027年度实施的入试为止 TOEFL 用 0–120 分计算。
- 出願时没交的英语按 0 分，不接受考试当天补交。8月入试为复印件邮寄，第2次募集上传到 WEB 出願系统。
- 变更点：2026年2月的第2次募集还收 IELTS、可当天补交；2026年8月入试起只认 TOEFL/TOEIC、须出願时提交。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 笔试只用日语出题，可用日语或英语作答；口头试问和发表用日语或英语。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 8月入试：基礎科目（100分） | 微积分、线性代数，共2题全答，每题50分 | 9:30–11:30，120分钟 |
| 8月入试：専門科目（200分） | 复变函数／傅里叶分析、图论、凸优化（含线性规划、KKT条件、对偶定理）、控制理论、统计力学、常微分方程6个领域各1题，选2题，每题100分 | 12:30–14:30，120分钟 |
| 第2次募集：基礎科目（100分） | 数学基礎（微积分·线性代数）、数理工学基礎（最优化），全部作答；専門科目不实施 | 10:00–12:00，120分钟 |

- 8月入试：基礎 100＋専門 200＋英语 100；口头试问只判可否；按笔试成绩、口头试问结果和各志望区分可接收人数决定合格者。
- 第2次募集：志願者多时先按出願书类做一次选拔；通过者按出願书类、笔试和口头试问综合判定。
- 变更点：2026年2月的第2次募集与8月入试一样考基礎＋専門；2027年2月起取消専門科目，基礎科目加入最优化。
- 题目倾向（体验记，非官方）：2024年8月基礎科目计算量比往年多、加了证明题；専門选凸优化和图论（1人）。

### 口述試験 / 面接
- **官方形式**：8月入试：笔试第二天口头试问，问志望动机、本科所学、希望的专门领域、毕业去向等，日语或英语，只判可否（コース FAQ：面试官为本コース教授、准教授、講師，常问两三个笔试相关问题）；第2次募集：先用幻灯片做约5分钟发表（志望动机、本科所学或研究经过、希望领域、研究抱负）再提问，日语或英语，发表资料做成 PDF 当天提交并带1份纸质打印件。
- **実際に聞かれた内容**：
  - 每人约1–3分钟，教员8–10名（2024年8月，1人提到）。
  - 志望动机、并愿学校、非情报系出身怎么补专业知识、学习计划、是否读博（2024年8月，1人提到）。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：25名（8月入试）；第2次募集若干名；2027年10月入学若干名。
- 出願资格：大学毕业（含预计）或外国16年学校教育等；资格10须事先审查（第2次募集 2026/12/7 17:00 必达，非独立出願）；外国大学毕业（含预计）者须在出願截止前完成 AAO 学历验证申请；只能报一个コース，第2次募集不能与10月入学并愿，8月入试合格者不能再报；志望区分按顺序填写、数量不限，没填的不分配。
- 要提前准备的书类：志望说明书（A4 2页以内，写学修研究经过、志望动机、研究抱负，做过毕业研究的写题目和内容）、TOEFL/TOEIC 成绩单；书类须为日语或英语，其他语言附译文。
- 出願：第2次募集只能通过 WEB 出願系统上传书类，纸质成绩证明须原件连同打印的入学願書以書留速達等寄送、期限内必达（8月入试为纸质邮寄或窗口提交）；检定料 30,000 日元＋决济手续费。
- 咨询：情報学研究科教務掛（総合研究8号館1階），jyoho-kyomu@mail2.adm.kyoto-u.ac.jp，Tel 075-753-4894／5500（平日 9:00–17:00，12:00–13:00 除外）；コース方面的邮箱为 amp-course@amp.i.kyoto-u.ac.jp，各分野窗口教员的邮箱登在コース入试信息页。
- 并愿：只能报一个コース，第2次募集不能与10月入学并愿，8月入试合格者不能再报。
