#### 英語要件
- 不考英语，也不收英语成绩；只用面试和出願书类选拔。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 授课用日语进行，原则上周一至周五晚间 18:00–21:10，以同步远程或线上线下混合方式为主。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：15名（医療管理学コース5名、医療政策学コース10名）。
- 出願资格：大学毕业（含2027年3月预计）或外国16年学校教育等，资格⑼–⒁须事先受出願资格审查（2026/8/13–8/17 必达，已截止）；外国学历者事先向入試課确认；医療管理学コース（1年）面向医院院长·管理运营核心人员和教育研究者，要求已有研究课题和研究现场、能在1年内完成研究；医療政策学コース（2年）面向医疗行政、医疗相关团体·企业从业者和教育研究者。
- 要提前准备的书类：所选コース担当教员的邮件出願许可（日期填进 Web 出願系统）；経歴調書（様式 M-2）；志願理由書（様式 M-3，400字以内）；资格·执照证明；外国学历者的履歴書（様式 C-2）。
- 出願：先在 Web 出願系统登记、上传并缴检定料 36,000 日元（另收手续费），再把入学願書和毕业（修了）证明原件用書留速達寄到入試課，期限内必达；海外寄送须用可追踪方式。
- 咨询：入试相关 東京科学大学 教育推進部 入試課 湯島大学院入試グループ（〒113-8510 東京都文京区湯島1-5-45），Tel 03-5803-4924，nyu-grad-02.adm@tmd.ac.jp（原则上本人用邮件联系），合否不接受电话询问；授業料 suitou.adm@tmd.ac.jp。
- 并愿：尚未核实是否可同时报考其他专攻或选拔类别。请以本年度募集要项或招生窗口答复为准。

### 研究室 / 指導教員
- 事前連絡要否：必须。要项规定出願前须与所选コース的担当教员面谈商量，并通过邮件取得出願许可，未经许可出願的可能被取消；原则上每年度、每次募集都要重新取得。
- 担当教员（按コース）：
  - 医療管理学コース（分野代码2010）：[新城 大輔](https://researchmap.jp/D_shinjo) 准教授｜DPC与NDB医疗大数据、医疗质量评价、卫生服务研究、医疗提供体制｜[教员介绍](https://www.tmd.ac.jp/cmn/mma/members.html)
  - 医療政策学コース（分野代码2020）：岡田 就将 教授｜卫生政策、医疗政策制定、医疗效率与质量｜[研究室](https://www.med.tmd.ac.jp/medicine/departments/hc_management.html)
