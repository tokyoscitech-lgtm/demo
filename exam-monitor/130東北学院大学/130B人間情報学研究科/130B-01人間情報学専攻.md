## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 一般選考（秋季·春季）：当天进行外国語笔试，从英语、德语、法语中选1科目（9:00–10:30，90分钟）；可以带多本纸质词典，电子词典不可；配点官方未公布。
- 不需要提交 TOEFL、TOEIC、IELTS 等外部成绩，要项里也没有用外部成绩代替笔试的规定。
- 社会人特別選考和推薦選考没有外语笔试。

### 日本語要件
- 外国人出願者须提交 日本語能力試験（JLPT）的成绩证明书，人間情報学研究科要求 N1 相当；另需在留卡复印件和外国人出願申请书。
- 试题与面接用日语进行；研究计划书须用日语书写。官方没有设外国人留学生特别选拔。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 外国語（90分钟 9:00–10:30；配点官方未公布） | 英语、德语、法语中选1科目；可带多本纸质词典 | 2027募集要项 |
| 専門科目（90分钟 11:00–12:30；配点官方未公布） | 从 社会学、心理学、教育学、言語学、人類学、物理学、生物学、コンピュータ科学、数学、スポーツ科学、地理学、環境化学、日本語教育学 共13科目中选1科目 | 2027募集要项 |
| 社会人特別選考 | 没有笔试，凭出願书类（论文、研究计划书等）面接・口述 | 2027募集要项 |
| 推薦選考（A/B日程） | 没有笔试，综合评价学业成绩、研究计划书、推荐书和面接（含口述） | 2027推薦選考要项 |

- 一般選考由外国语、専門科目、面接・口述三部分综合判定，并参考研究计划书；各科配点和合格基准官方未公布。
- 公認心理師コース也走一般選考，考试科目与其他考生相同，另需提交公認心理師カリキュラム履修希望书。
- 题目倾向（体验记，非官方）：没有找到本専攻的合格体验记；过去问只能到窗口阅览。

### 口述試験 / 面接
- **官方形式**：一般選考在笔试当天 13:30 起进行面接・口述，内容围绕提交的出願书类（研究计划书等）；社会人特別選考 9:30 起，以出願书类为基础考查专门领域的基础学力；推薦選考为面接（含口述）。时长和配点官方未公布，用日语进行。
- **実際に聞かれた内容**：没有找到本専攻的面接体验记。

## 📝 详细信息
### 出願資格 / 定員
- 一般選考的募集人员为12名（2027年度募集起适用，秋季·春季合计，要项没有分开写）；社会人特別選考、推薦選考均为若干名；公認心理師コース春季为若干名，满员即停止；本校生的特別選考人数未公布。
- 一般選考出願资格：大学毕业或2027年3月预计毕业、由大学改革支援・学位授与機構授予学士、在外国完成16年学校教育、经个别入学资格审查认定且到2027年3月底满22岁等，共9项之一。
- 社会人特別選考：满足一般選考资格之一，并且是可在职入学的正式职员，或大学毕业后有3年以上社会经验（含家庭主妇/主夫）的人。
- 推薦選考（A日程秋季、B日程春季）：2027年3月大学毕业预定或高专专攻科修了预定；须所属学部长或高专校长推荐、合格后必定入学；大学生须到3年级为止全科目平均85分以上且累计 GPA 3.0 以上，高专生须4–5年级及专攻科1年级全科目平均85分以上。
- 特別選考（A/B/C日程）只面向满足成绩基准的东北学院大学毕业预定者，要项只在学内网站公开，这不是一般考生的路线。
- 出願书类（一般選考）：入学志愿书、研究计划书、成绩证明书、毕业（预定）证明书、最终学历为大学院者的修了证明书、在职者的通学证明书、希望公認心理師コース者的履修希望书；外国人另交在留卡复印件、外国人出願申请书、JLPT 成绩证明书。证明书须为发行后3个月以内。
- 研究计划书：本専攻要求 4,000–12,000 字左右（每行40字、每页36行），用文字处理软件制作，A4 横排单面，不得订书钉装订，标页码，使用本校规定封面并注明字数（不含标题、姓名、参考文献），用日语写研究课题（问题意识尽量详细）、研究方法及相关业绩。
- 公認心理師コース：入学后不能变更コース；入学志愿书里填写的希望指导教员不保证入学后由其指导，实践教育由多名教员集体负责；强烈建议事先联系希望的指导教员。该课程从2022年度入学者起开设。
- 出願方式：先在 WEB 出願系统登记并缴费，再把书类用角2信封以邮局窗口“简易书留速达”寄送（期限内必达），或在平日 9:00–17:00（最后一天到 15:00）送到入試部アドミッションズ・オフィス。只做 WEB 登记不算出願完成。受験票不邮寄，考试日7天前起在 My Page 自行打印。
- 检定料 33,000 日元（另加支付手续费），通过 WEB 出願系统支付，任何理由都不退还。
- 没有大学毕业资格的人须先接受出願資格事前審査（免费）：春季 WEB 2026/11/24（周二）–12/2（周三）22:59，书类 2026/12/4（周五）15:00 截止（秋季已截止）。
- 入学手续：秋季合格者 2026/12/11（周五）15:00 截止，春季合格者 2027/3/12（周五）15:00 截止。博士前期可申请日本学生支援机构贷与奖学金相关的授業料后付制度。
- 学费：本次能查到的官方页面只列出文系四研究科2027年度的参考额，人間情報学研究科的入学金和授業料没有在公开页面列出，以入学手续要项为准。
