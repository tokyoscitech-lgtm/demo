## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各区分相同：出願时提交 TOEIC L&R 公開テスト、TOEIC-IP、TOEFL-PBT、TOEFL-iBT 之一的成绩证明复印件，按成绩单换算计 50 分；只认 2023/4/1 以后受检的成绩。
- 不另设英语笔试；拿不出上述成绩的，可用所在大学外国語教育センター等出具的成绩证明代替。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 社会人·私費外国人留学生的口頭試問·面接用日语进行，私費外国人留学生同时确认日语能力。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 推薦：无笔试 | 书类（成绩证明书中的专门基础知识）100＋面接 100＋英语 50＝250 分 |  |
| 一般：无笔试 | 书类 100＋口頭試問·面接 100＋英语 50＝250 分 |  |
| 社会人·私費外国人留学生：无笔试 | 口頭試問·面接 150＋英语 50＝200 分，不计书类分 |  |

- 推薦：总分从高到低依次合格，同分同序，不足6成（150分）者不合格。
- 一般、社会人·私費外国人留学生：总分从高到低依次合格，同分同序，口頭試問·面接不足4成者不合格。

### 口述試験 / 面接
- **官方形式**：推薦：数名面接委员每人约10分钟面接，看逻辑思考、表现力和对研究与社会实装的意欲，参考志望理由書；一般：口頭試問约10分钟（开头约5分钟不用幻灯片和资料口头介绍现在的研究和入学后的研究计划，之后就毕业研究和材料·化学·信息相关内容质疑）＋面接约10分钟；社会人·私費外国人留学生：口頭試問约10分钟（同样先口头发表约5分钟，确认材料·化学·信息基础学力）＋面接约10分钟，用日语，原则对面，不能来校的事先商量后可在线受考。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：52名（推薦20、一般32，社会人与私費外国人留学生合计若干名）；只有一次募集。
- 出願资格：一般为大学毕业（含预计）或外国16年学校教育等(1)–(10)之一，资格(9)(10)须在 2026/8/21 前照会（已过）；推薦限2027/3/31前毕业、确约入学者，本校材料エネルギー学部生须GPA学部内前35名，他学部·他大学·高专专攻科须GPA 2.5以上或「優」以上比率50%以上；社会人须有2年以上技术者·研究者等工作经验；私費外国人留学生限外国人留学生或在外国大学受教育者，日本大学毕业的留学生也可以报。
- 要提前准备的书类：志望理由書（所定样式）、英语成绩证明复印件；推薦另交学部长等写的推荐书（厳封）；社会人·私費外国人留学生另交研究计划书和受入预定教员写的確認書。
- 出願：先在网上出願系统登录、上传照片并缴检定料 30,000 日元（便利店、Pay-easy、网上银行、信用卡），再把书类持参或以特定记录·速达邮寄，海外居住者用相当方式寄送；受験票 10/13 起在系统下载。
- 并愿：只能报一个区分，出願时填写志望研究室——推薦·社会人·私費外国人留学生第1志望必填、第2·3志望任意，一般入试第1–5志望都必填；各教员接收人数有上限。
- 咨询：松江地区学部等事務部 材料エネルギー研究科担当，〒690-8504 松江市西川津町1060，Tel 0852-32-6661；学部另列 Tel 0852-32-6663、gad-mfe@office.shimane-u.ac.jp；入试咨询（学生センター）Tel 0852-32-6256。
