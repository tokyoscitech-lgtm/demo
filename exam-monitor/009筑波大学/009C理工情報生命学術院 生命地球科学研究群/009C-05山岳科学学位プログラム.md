## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般入学試験（8月、1-2月实施相同）：不另设英语笔试，用出願时提交的外部成绩评价，「外国語」计100分。社会人特別選抜不需要英语成绩。
- 受理 TOEIC Listening & Reading（公式認定証原件或デジタル公式認定証）、TOEFL iBT（含 Home Edition，受験者用スコア票）、IELTS Academic（Additional TRF）；不受理 TOEIC IP、TOEFL ITP 等团体考试、IELTS Online 和复印件。
- 换算：TOEIC L&R 860、TOEFL iBT 95、IELTS 7.0 以上记满分100分，低于基准分按比例换算，公式没有公布。
- 有效期：8月实施须为2024年8月以后受检，1-2月实施须为2025年1月以后受检；プログラム入试页提醒须在出願前考完并拿到正式成绩。

#### 日本語要件
- 要项没有要求提交 JLPT、EJU 等日语成绩，也没有给外国人留学生另设区分（募集人员含外国人留学生）。
- 口述可以用日语或英语进行；専門科目试题的出题语言要项没有写明。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 8月实施·1-2月实施 一般入学試験：専門科目（100分，60分钟） | 从地球科学、生物学、農学（生物资源）、环境科学各领域的题目里选1题作答；每次只出当次考生志望领域的科目。2026年8月出题科目：林政学、地形学、生物集団動態学、生態系生態学、森林生態学、草原生態学、菌類学、動物生態学、保全生態学、生物多様性学 | 2027募集要项英语版／プログラム入试页 |
| 社会人特別選抜（8月、1-2月） | 无専門科目，只有口述 | 2027募集要项英语版 |

- 一般入学試験总分300分（外国語100＋専門科目100＋口述100），社会人特別選抜只有口述100分；合格最低分和判定方法没有公布。
- 历年出过的科目还有観光学、森林遺伝学·分子生態学、土壌学、大気科学、水生植物学等；过去的1月期通常只出2–4科（プログラム入试页）。
- 题目倾向（体验记，非官方）：没有找到本プログラム的考生体验记。

### 口述試験 / 面接
- **官方形式**：8月实施一般入学試験：先发表研究计划3分钟，再就专业、基础知识和将来打算提问（100分）；1-2月实施一般入学試験：发表至今的研究和研究计划5分钟，再同样提问（100分）；一般都可用日语或英语，可用白板或黑板，不能带资料和电脑；社会人特別選抜（8月、1-2月相同）：每人约20分钟＝发表社会经验、研究经历和研究计划8分钟＋问答12分钟（100分），用自带笔记本电脑投影（HDMI 或 Mini D-Sub 15针），12:50–13:10 试机，并用 U 盘带 PDF 备份，可用日语或英语。
- **実際に聞かれた内容**：没有找到本プログラム的面接体验记。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：8月实施 一般入学試験9名、社会人特別選抜1名（已结束）；1-2月实施 一般入学試験4名、社会人特別選抜1名；各项含连携大学院方式和外国人留学生，都是2027年4月入学。7月实施（推薦）本プログラム不举行。
- 变更点：因2027年度预定新设学際創成学術院，8月实施一般入学試験的募集人员由14名改为9名。
- 出願资格：大学毕业或2027年3月底前预计毕业、由学位授与機構授予学士学位、在外国完成16年学校教育等全学共通各项之一；属于资格(6)的须事先确认；个别出願资格审查（资格(9)）1-2月实施截止 2026/11/24（周二）。
- 社会人特別選抜另外要求：到入学前一个月有1年以上社会经验（企业、官厅、教育机构工作，家务等也算），报社会人枠要事先告诉志望指导教员。
- 出願书类：毕业（预计）证明书、成绩证明书原件、外国大学毕业者的学位取得证明书、外部英语成绩（一般入学試験）、检定料缴纳证明、在学或在职者的受験·就学承認書、国费留学生证明书（符合者）。研究计划在 Web 出願时录入（一般和社会人都要）；有公式图表录不进去时另交格式自由的研究計画書，开头写志望学位プログラム名、姓名、志望指导教员名，日文约2000字或英文约1000词。社会人还要交活动·研究业绩目录及证明材料。
- 书类装角形2号信封、贴 Web 出願后下载的宛名シート，用書留寄出；受験票在 Web 出願期间内自己下载打印，考试当天带去。
- 检定料 30,000 日元，信用卡或便利店支付，手续费自付，缴纳后不退；国费外国人留学生免缴。
- 受験者心得在考试约一周前掲載于募集要项站「お知らせ」栏。
- 本プログラム是筑波大学与信州大学、静岡大学、山梨大学合作的博士前期課程，学位为修士（山岳科学）；筑波大学的入试只按上述筑波要项进行。
- 咨询：山岳科学学位プログラム入试担当 sangaku-admissions@ml.cc.tsukuba.ac.jp，プログラム事务室 Tel 029-853-5812；出願资格问入試課大学院入試 admission.grad@un.tsukuba.ac.jp。
