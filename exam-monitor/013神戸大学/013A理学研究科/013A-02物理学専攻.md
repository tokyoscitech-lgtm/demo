## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 夏季入试：必须提交 TOEIC Listening & Reading 公開テスト的成绩，用它评价英语。専攻自己没有另外的英语笔试。本専攻的评价权重是 Listening：Reading＝1：3。最低分、满分换算方法和英语在总分里的配点，官方都没有公布。
- 提交方法（在日本国内受験 TOEIC 的人）：出願时交纸质的「TOEIC L&R 公開テスト受験情報確認票」（研究科所定样式），再在 TOEIC 申込网站上输入申请代码 00010402，把成绩直接提交给研究科，截止 2026/8/3（周一）（已截止）。考试日的17天后才能在网站上提交成绩。国内受験者不能用纸质的公式认定证代替。
- 在海外受験 TOEIC 的人：交受験情報確認票和公式认定证的原件；出願时来不及的，原件最迟 2026/8/3（周一）交到。
- 成绩须为笔试实施日之前2年以内受験的公開テスト。团体特别受験（IP テスト）的成绩不受理，TOEFL 不受理；成绩只能交1次，不能交多份。
- 冬期追加募集：未公布（截至 2026-10-11）。
- 变更点：2028年度入试起，TOEIC 成绩的提交期限改为出願期间的最后一天（研究科入试页的预告）。

### 日本語要件
- 一般選抜：要项没有要求提交日语成绩。
- 外国人留学生特別選抜：必须提交「日语水平足以不妨碍修学」的证明书，要项举的例子是日本語能力試験的成绩证明书；没有规定具体等级或分数。
- 试题语言和可用的作答语言，要项对本専攻没有写明（“原则上用日语出题”的注只写在生物学専攻下）。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 物理Ⅰ（120分钟，配点官方未公布） | 要项只写科目名，没有写出题范围和题数 | 2027募集要项 |
| 物理Ⅱ（120分钟，配点官方未公布） | 要项只写科目名，没有写出题范围和题数 | 2027募集要项 |
| 英語（TOEIC L&R 成绩，配点官方未公布） | 不设笔试，按 Listening：Reading＝1：3 的权重评价 | 2027募集要项 |
| 冬期追加募集 | 是否实施及科目均未公布（截至 2026-10-11） | 研究科入试信息 |

- 选拔方法：综合学力检查（笔试、口头试问）和成绩证明书决定合格者，本専攻还会考虑考生希望的教育研究分野。选考分两步：第一次选考为笔试（物理Ⅰ·物理Ⅱ）；第二次选考为面接，只有第一次选考合格者能参加。总分和合格线官方没有公布。
- 外国人留学生特別選抜的科目和时间与一般選抜相同（物理Ⅰ、物理Ⅱ＋TOEIC＋面接）。
- 题目倾向（第三方解答网站的归纳，非官方，仅1处来源）：物理Ⅰ、物理Ⅱ各为3道大题（问Ⅰ～Ⅲ）；各大题对应的领域该网站没有列出，这里不作推测。

### 口述試験 / 面接
- **官方形式**：夏季入试在笔试次日（2026/8/19 9:30 起）进行第二次选考的面接，对象仅限第一次选考合格者（当天 9:00 发表）。面接的内容、时长、配点和使用语言要项都没有写明；出願时提交的入学理由书（A4 1页）和希望的教育研究分野是参考材料。冬期追加募集未公布。
- **実際に聞かれた内容**：没有找到物理学専攻大学院入试的考生体验记，实际提问内容不明。

### 出願資格 / 定員
- 募集人员：夏季入试的一般選抜为24名，外国人留学生特別選抜为若干名。冬期追加募集的人数未公布（是否实施也未公布，截至 2026-10-11）。
- 一般選抜的出願资格共11项，满足其一即可：大学毕业或2027年3月31日前预计毕业、被授予学士学位、在外国完成16年学校教育、在外国取得相当于学士的学位（3年以上课程）、専修学校専門課程修了、文部科学大臣指定者、经本研究科个别审查认定具有大学毕业同等以上学力且2027年3月31日前满22岁、大学在学3年以上且成绩优秀（跳级）等。
- 外国人留学生特別選抜的资格：持有在留资格「留学」的外国人（含预计2027年4月取得者），并满足大学毕业（含预计）、在外国完成16年课程、外国3年以上课程的学士相当学位、个别审查认定等之一。
- 需要个别出願资格审查的人，夏季入试的申请截止日是 2026/6/5（周五）（已过）；跳级资格的事前审查受理期间是 2026/6/3–6/5，结果 6/17 寄出。
- 志望的填写：本専攻在 Web 出願时不需要填写志望指导教员的姓名；选拔时会考虑考生希望的教育研究分野（理論物理学、粒子物理学、物性物理学）。
- 出願方式：只能先在 Web 出願网站登记、上传证件照数据（3个月内拍摄，2MB 以内）并缴纳检定料，再把纸质书类在书类提交期间内送达理学研究科教務学生係。邮寄用レターパックプラス或書留速達；窗口受理时间为 9:00–12:00、13:00–17:00。
- 出願书类（一般選抜）：入学願書·履历书（从 Web 出願网站打印）、成绩证明书、毕业（预计）证明书、TOEIC L&R 公開テスト受験情報確認票、入学理由书（只有物理学専攻要交：把想入学的理由写在 A4 1页上，字数和格式不限）；住在日本的外国人另交住民票的复印件（30日以内出具）或在留卡复印件。
- 外国人留学生特別選抜另需：日语能力证明书、出身大学指导教员的推薦状（研究科所定样式；以本研究科研究生等身份在籍并继续出願的可免）、国费外国人留学生证明书（仅该当者）。
- 外国学历的注意事项：中国的大学毕业者须办理中国高等教育学生信息网（CHSI）的认证，提交认证过的英文报告。日文、英文以外的证明书必须附上由日本或外国政府驻外机构等公的机关出具翻译证明的日文译文。
- 检定料 30,000 日元，在 Web 出願网站上支付，手续费由考生负担。出願后不能更改填写内容，已交的书类和检定料原则上不退还。
- 并愿限制：不能与同一天实施的理学研究科博士課程前期課程其他入试（10月入学的一般選抜·外国人留学生特別選抜等）同时报考。
- 10月入学：2026年度10月入学的募集要项里本専攻的一般選抜和外国人留学生特別選抜各募集若干名，出願期间、考试日、科目与4月入学相同（已结束）。2027年度10月入学的要项未公布（截至 2026-10-11）。
- 受験票从 Web 出願网站的个人页面下载打印，考试当天带来。考场在神戸大学理学部学舎（神戸市灘区六甲台町1-1），考场和面接室当天贴在理学部Y棟1階的掲示板上。手表只能用仅有计时功能的；大学不介绍住宿。迟到的处理要项没有写。身体有障碍需要特别照顾的，要在出願2周前提出。
- 入学手续预定在2027年3月中旬，详情一般選抜在2027年2月中旬左右、外国人留学生特別選抜在3月上旬通知。入学料 282,000 日元，授業料 年 535,800 日元（前期 267,900 日元；为2026年度的金额，学费改定时适用新金额）。
