## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 第1次募集（8月入试）和第2次募集（2月入试）都不在考场考英语，而是在出願时提交外部考试成绩：TOEIC L&R、TOEFL iBT、IELTS（Academic Module）三选一，须为 2024年4月以后受检的成绩。
- 提交形式：TOEIC 交公式认定证的纸质原件，或把数字公式认定证 PDF 打印出来；TOEFL iBT 交 Test Taker Score Report 的 PDF 打印件（只认 0–120 分制的成绩）；IELTS 交 Test Report Form 原件，网页打印的不行。
- 出願时正式成绩单还没到手的，可以先交网上成绩画面的打印件作为“仮提出”，正式成绩单的补交期限：第1次募集为 2026/7/3（周五）上午（已截止）；第2次募集为 2027/1/29（周五）上午。
- 没有提交有效成绩证明的，英语按 0 分处理。要项没有写最低分数线，也没有公布换算公式和配点。
- 不受理的成绩：参考 2025年度要项，TOEIC IP 等团体考试、机构直送的成绩不受理；2027年度要项只读到上面的形式要求，这一条未核实。
- 变更点：成绩有效期的起点逐年后移（2025年度要项为“2022年4月以后”，2027年度为“2024年4月以后”）。

### 日本語要件
- 一般選抜的要项没有要求提交日语成绩。
- 要项写明出願时要选择出题语言（日语或英语）。要项没有写作答语言的规定。
- 外国人留学生特別選抜（另一条路线）：只考口头试问，出願时选日语或英语作为考试语言，同样要交 TOEIC／TOEFL／IELTS 成绩，要项没有日语成绩要求。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 専門科目《基幹情報学基礎》（配点官方未公布，150分钟） | 算法、软件、逻辑电路、计算机体系结构。要项只列出这4个领域，没有写题数和选答规则 | 2027一般選抜募集要项 |
| 基礎科目《数学》（配点官方未公布，90分钟） | 线性代数、微积分（含微分方程）、概率·统计。题数没有写 | 2027一般選抜募集要项 |
| 第2次募集（2027年2月）：科目与第1次募集相同 | 2027/2/9 同样的两场笔试，次日口头试问；另须提交毕业论文或代替论文 | 2027一般選抜募集要项 |

- 合否判定：按笔试（含英语外部考试成绩）、口头试问、出願书类综合判定。各科配点和总分官方都没有公布。
- 变更点：2025年度要项的専門科目是“算法、软件、逻辑电路3个必答，再从计算机体系结构、信息·通信网络里选1个”；2027年度要项里没有信息·通信网络，也没有必答/选答的区分。从哪一年度开始变更没有核实。
- 题目倾向（体验记，非官方）：没有找到体验记，过去问也没能看到，无法归纳。
- 第2次募集的笔试预备日为 2027年2月12日、2月13日。

### 口述試験 / 面接
- **官方形式**：第1次募集和第2次募集都有口头试问，在笔试的第二天 9:30 开始，围绕研究计划书等（包括研究内容）提问。配点、每人时长、是否要做发表，要项都没有写。住在日本国外的人可能改用远程中继方式考口头试问。口头试问（笔试免除）只对大阪公立大学、大阪府立大学、大阪市立大学、大阪公立大学工業高等専門学校専攻科的在籍者和学术交流协定校的在籍者开放（需要个别资格认定的人里也可能有获准者），由出願书类综合判断谁可以免笔试，名单在 2026/6/26 公布；普通外校考生走不了这条路。
- **実際に聞かれた内容**：没有找到体验记，实际被问到的内容不明。
