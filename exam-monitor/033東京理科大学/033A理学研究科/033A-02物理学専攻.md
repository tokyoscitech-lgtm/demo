## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 一般入试：用 TOEIC 或 TOEFL 的成绩评价英语能力。要项没有写最低分，也没有写换算方法和配点。
- 一般入试可用的成绩：TOEIC L&R 公開テスト和 IP テスト都可以，TOEIC Bridge 不可以；TOEFL iBT 和 TOEFL ITP 都可以，TOEFL iBT Home Edition 不可以。
- 一般入试的提交方式：出願时提交成绩单原件；TOEFL iBT 须由 ETS 直接寄送到大学，Institution Code 是 G277。成绩须是出願截止日前2年以内考的，只能交一种，交过之后不退还、也不能换成别的成绩。
- 外国人留学生入试：同样用 TOEIC 或 TOEFL 的成绩评价，但只受理 TOEFL iBT（会场受験，Home Edition 和 ITP 不可）和 TOEIC L&R 公開テスト（IP 不可）；成绩须是第二次選考出願截止日前2年以内考的。该要项给出的 Institution Code 是 0438，与一般入试要项的 G277 不同，寄送前请向理学事務課确认。
- 变更点：外国人留学生入试从2027年度起不再受理 TOEFL ITP 和 TOEIC IP（2026/4/6 通知）。

### 日本語要件
- 一般入试：要项没有要求提交日语成绩（JLPT、日本留学試験都没有提到）；出願书类用大学的日文所定用纸，试题按日文出题。
- 外国人留学生入试：修士課程的志愿者必须提交大学所定用纸的「日本語能力認定書」，请日语教师、日本驻外使领馆人员或日语熟练的人填写，不需要、也不能用 JLPT 证书代替；要项没有规定 JLPT 等级或分数。
- 外国人留学生入试的物理学専攻専門科目只用日语出题（数学専攻等可选英语，本専攻不可）；面接用日语或英语进行。

- 一般入试由笔试两场、TOEIC/TOEFL 成绩、出願书类（含指導教員的推薦書和面谈记录）和面接构成。要项没有公布各项配点、总分和合否判定方法。面接只对笔试当天公布的对象者进行，相当于笔试后的一次筛选。
- 题目倾向（体验记，非官方）：没有找到本専攻的受験体验记，无法归纳。

### 口述試験 / 面接
- **官方形式**：一般入试没有口頭試問；面接在 2026/8/1 14:00 起进行，对象者在笔试当天公布，配点、时长和提问范围要项没有写。外国人留学生入试第二次選考有面接，用日语或英语进行。
- **実際に聞かれた内容**：没有找到本専攻的体验记（日文和中文来源都查过），暂无可归纳的内容。

## 📝 详细信息
### 出願資格 / 定員
- 一般入试的要项写的物理学専攻入学定員为50名（神楽坂キャンパス），其中包含学内選考的名额，一般入试单独招多少人没有公布。外国人留学生入试的募集人员为理学研究科数学·物理学·化学·応用数学4専攻合计若干名。
- 一般入试的出願资格：大学毕业或2027年3月前预计毕业（取得学士学位）、在外国完成16年学校教育、修完4年以上的専修学校専門課程、文部科学大臣指定者、经个别审查认定有同等以上学力且2027/3/31前满22岁者，符合其中一项即可。
- 大学3年级在籍者的特别选拔（出願资格⑸，俗称飞跃入学）本年度在物理学専攻实施，按另行发布的特別選抜出願要项办理；该要项这次没有找到，日程和条件未核实，有意者向理学事務課询问。
- 外国人留学生入试的出願资格须同时满足四条：外国籍；在外国完成16年课程，或满22岁并有研究经历等；没有在日本受过4年的大学本科教育；入学时能取得「留学」在留资格。
- 一般入试的出願书类：入学願書（所定用纸，贴3个月内拍的 4cm×3cm 彩色照片）、成绩证明书原件、毕业（预定）证明书原件（都要3个月内开具的）、履历书（所定用纸）、志望理由書（所定用纸）、TOEIC/TOEFL 成绩单原件、本専攻专用的「指導教員の推薦書および受入教員との面談記録（物理学専攻用）」、寄受験票用的明信片1张（贴速达邮资）；住在日本国外的人另交「国外居住者用事前相談シート」。
- 外国人留学生入试的出願书类：入学願書、日本語能力認定書、最终学校的毕业证明书、成绩证明书、推荐信、护照复印件、参考资料、检定料缴纳票、チェックシート；住在国外的另交事前相談シート。本専攻不需要交選択科目届。
- 出願方式：邮寄到理学事務課，要项里没有网上出願。一般入试邮戳有效（国外寄出须最后一天必达），外国人留学生入试两次選考都要求必达。
- 检定料：一般入试 35,000 日元，通过银行窗口（電信扱）或便利店缴纳，ATM 和网银不可，缴后不退。外国人留学生入试分两次缴：第一次選考 18,000 日元，第二次選考 17,000 日元（银行窗口 2026/11/30–12/2，便利店 2026/11/25–12/2）。
- 并愿：笔试日期不同的専攻之间可以并愿；理学研究科各専攻一般入试的笔试都在 2026/8/1，本専攻与同日笔试的専攻不能并愿。
- 学费（2027年度入学，修士）：入学金 200,000 日元，授業料 年 880,000 日元，教育充実費 年 200,000 日元，学生傷害共済補償費 2,740 日元，第一年合计 1,282,740 日元，第二年 1,082,740 日元。东京理科大学本科毕业生入学金和教育充実費减半。
- 考场规则：笔试开始后（面接是集合时间后）30分钟内没有进入指定会场的，不能参加该场考试。具体会场在考试前一天公布。
- 咨询窗口：理学事務課，〒162-8601 東京都新宿区神楽坂1-3，Tel 03-5228-8120，窗口时间 9:00–12:00、14:00–16:00（周六日和节假日除外）。
- 成绩开示：要项已读到的部分没有记载。
