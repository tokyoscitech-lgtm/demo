## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各轮次相同（一般、外国人留学生入试）：不在考场考英语，必须提交 TOEIC L&R 或 TOEFL iBT 成绩，由専攻换算成入试分数计入合否判定；换算基准 TOEIC 730＝满分、230＝0分，TOEFL iBT（0–120分制）80＝满分、25＝0分，TOEFL iBT（1–6分制）4.5＝满分、2＝0分。
- 成绩须为考试日前2年以内受检；有多份成绩时只交最有利的1份。
- TOEIC L&R：交 Official Score Certificate 原件和复印件（原件考试当天归还），或日本国内受检带 QR 码的数字认定证 PDF 打印件；TOEIC IP 不受理。
- TOEFL iBT：由 ETS 直送 Institutional Score Report（Institution Code 5132、Department Code 72，官方建议提交期限 6 周前申请），另把 Test Taker Score Report 的 PDF 打印件随出願书类寄出；Home Edition、MyBest 不受理。
- 英语成绩另设提交期限：Ⅰ期 2026/6/26（已过）、Ⅱ期 2027/1/15（周五），出願时还没有的在チェックリスト写受检日；期限后送到的一律不认。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 外国人留学生入试的考生，笔试（専門科目）可以用英语作答；研究计划书用日文或英文写。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 専門科目 | 数学、情報、プログラミング各1题，3题选2题作答 | 9:30–11:00，90分钟 |

- 按専門科目、プレゼンテーション·面接試問、英语成绩换算分综合判定。
- 2026年度试题（官方公开）：数学考线性代数和微积分的基本计算，情報考计算机与网络基础（位运算、流水线、CSMA/CD、逻辑电路、软件生命周期、分组网络延迟等），プログラミング考读程序和算法（循环、递归、数组、计算量），不指定编程语言。
- 题目倾向（体验记，非官方）：1名2022年夏季合格的外部考生选了情報和プログラミング，情報用基本情報技術者试验的教材准备（仅1人提及）。

### 口述試験 / 面接
- **官方形式**：各轮次都在笔试结束后进行プレゼンテーション及面接試問：就至今的研究成果和今后的研究课题做5分钟发表（可演示），有投影仪（VGA、HDMI）和电源，电脑和转接头自备，不提供网络；详细安排在笔试时通知。
- **実際に聞かれた内容**：（体验记，仅1人提及）2022年夏季是发表5分钟＋质疑约10分钟、考官3名，约八成追问研究内容、两成是技术性问题。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：45名（学内選考、Ⅰ期、Ⅱ期，一般和外国人留学生合计）。
- 出願资格：大学毕业（含2027年3月预计）或外国16年学校教育等；外国人留学生入试要求非日本国籍、初中等教育全部在外国修完；没有学士学位等需个别资格审查的人须先申请（Ⅰ期 5/29、Ⅱ期 2026/11/13 必达，非独立出願）。
- 要提前准备的书类：研究计划书（本専攻所定用纸，A4 2页以内即双面1张，研究计划书上希望指导教员只写第1希望）、TOEIC/TOEFL 成绩；外国籍者另交経費支弁方法計画書、护照和在留卡复印件；中国的大学毕业者须由 CHSI 把英文成绩认证报告和学位认证报告直送研究科邮箱（ams@mics.meiji.ac.jp）。
- 出願：只收邮寄（速達·簡易書留，国内邮戳有效；海外用 EMS、DHL 等，最后一天必达），不收窗口和网上出願；检定料 35,000 日元（Ⅱ期缴纳期间：一般 11/20–12/4，外国人留学生 11/17–12/4）。
