## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 一般入試·外国人留学生特別入試：考试当天不考英语，用出願时上传的成绩评分，配点 100 分。受理 TOEIC Listening & Reading Test（公開テスト）的デジタル公式認定証或纸质 Official Score Certificate，以及 TOEFL iBT 的 Test Taker Score Report。
- 有效期：入试日（2026/7/11）之前 2 年以内受检的成绩有效。
- 不受理：TOEIC-IP 等团体考试、TOEIC Speaking & Writing、TOEIC Speaking、TOEIC Bridge、TOEFL ITP。官方资料没有提到 IELTS，也没有说明 TOEFL iBT Home Edition 是否可以。
- 提交方式：以 PDF 上传到 Web 出願系统；只有纸质成绩单的要扫描成清晰的 PDF，合格发表后提交原件。官方提示 TOEIC 最晚参加 2026/6/13（周六）的公开考试，才大致赶得上出願，デジタル認定証发行晚了可能来不及。
- 官方没有公布分数换算成 100 分的方法，也没有设最低分。
- 推薦入試：2027年度不要求提交英语成绩，英语能力在口头试问中一并考察。研究科已通知 2028年度的推薦入試将利用英语外部考试成绩。
- 变更点：2027年度起成绩单改为 PDF 上传（随 Web 出願导入）。

### 日本語要件
- 一般入試：要项没有要求提交日语成绩，也没有写试题语言和作答语言。
- 外国人留学生特別入試：必须提交「日本語修得証明書」，证明日语水平不妨碍修学；格式自由，现所属机构或指导教员出具的证明也可以。要项没有指定 JLPT 等级或分数，也没有写 JLPT 证书能否代替。
- 外国人留学生特別入試的小論文原则上用日语作答，也可以用英语作答。口头试问使用什么语言，要项没有写。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 小論文·共通問題（50分；与选择问题合计 90 分钟） | 全员必答。从研究科事先指定的课题资料出题；2027年度的课题资料由 3 份构成：关于アントレプレナーシップ的论文、关于シード·アクセラレーター作用的论文（均出自《季刊ビジネス·インサイト》）、神戸大学研讨会小册子中的イノベーション理论学习资料。资料须通过申请表申请阅览，考试当天不能带入 | 2027一般入試募集要项／课题资料构成 |
| 小論文·选择问题（50分） | 按入学願書第1志望的指導教員群所属的教育研究分野，从バイオプロダクション、先端膜工学、先端IT、先端医療·製薬学中答对应分野的题。各分野的具体出题范围和题数官方没有公布 | 2027一般入試募集要项 |
| 英語（100分，不设当天考试） | 用 TOEIC L&R 公開テスト或 TOEFL iBT 的成绩评分 | 2027一般入試募集要项／英語的处理方法 |
| 推薦入試 | 没有笔试，只有口头试问 | 2027推薦入試募集要项 |

- 一般入試与外国人留学生特別入試的科目和配点相同：小論文 100＋口头试问 100＋英語 100，合计 300 分。合否根据这三科的成绩加上成绩证明书和研究计划书综合判定；官方没有公布合格线。
- 考试中不能使用词典和专业书，只能用仅有计时功能的手表，须携带受験票。
- 过去问的 PDF 是扫描图像，本次没能读取文字内容，题型和题数未核实。
- 题目倾向（体验记，非官方）：没有找到本専攻的考生体验记。

### 口述試験 / 面接
- **官方形式**：一般入試·外国人留学生特別入試有口头试问（100分），内容是志望动机、研究计划概要等，2026/7/11 13:30 起，面试室当天公布，时长和使用语言官方没有写。推薦入試只考口头试问（含英语能力的考察），与研究计划书、成绩证明书综合判定，配点官方未公布。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：科学技術イノベーション専攻 40 人。推薦入試（10 人程度）和外国人留学生特別入試（若干人）都在这 40 人的名额之内。2次募集本年度不实施（上次实施的 2024年度 2次募集为 5 人程度）。
- 一般入試的出願资格共 11 项：大学毕业或 2027/3/31 前预计毕业；取得学士学位（大学改革支援·学位授与機構）；在外国完成 16 年学校教育；在外国大学完成 3 年以上课程并取得相当于学士的学位；指定専修学校専門課程毕业；文部科学大臣指定者；经个别审查认定具有与大学毕业同等以上学力且入学时满 22 岁；大学在学 3 年以上或在外国完成 15 年课程、成绩优秀者（所谓飞び入学）等。
- 外国人留学生特別入試的对象是已取得在留资格「留学」（含 2027年4月预计取得）的外国人，并符合大学毕业（见込）、在外国完成 16 年课程、3 年以上课程的学士相当学位、个别审查等 5 项之一。要项没有写能否与一般入試并愿。
- 推薦入試面向在志望分野受过教育、学业和人品优秀并能保证合格后入学的人（专愿）；推薦書为任意提交，神戸大学的学部生不需要。
- 个别出願资格审查（一般入試的资格 9·10·11，留学生入试的资格 5）：受理期间 2026/6/1（周一）–6/3（周三）9:00–16:00（12:00–13:00 除外），邮寄须用書留并在期间内必达，结果在 6/26（周五）前通知（已过）。
- 出願书类（一般入試）：证件照数据（3 个月内拍摄）、成绩证明书、毕业（见込）证明书、研究计划书（研究科规定格式，事前相談时交给教员；要项没有写页数或字数限制）、受入内諾書（研究科规定格式，由希望指导教员出具，没有就不能出願）、TOEIC 或 TOEFL 成绩单；该当者另交学位授与证明书、住民票的写し（30 日内开具）或在留卡正反面复印件（在日外国人）。外国人留学生特別入試另加日本語修得証明書。
- 中国的教育机构出身者不交学校出具的成绩·毕业证明书，改交 CHSI（学信网）的英文 Online Verification Report 等认证文件，出願时 Web 认证的有效期须剩 1 个月以上，过期视为书类不齐。英语以外的证明书要附英文或日文译文。
- 出願方式：只能通过 Web 出願系统（e-apply），全部书类转成 PDF 上传，每个项目只能传 1 个 PDF（多页先合并）。上传书类的原件要在合格后尽快提交，不交可能不被准许入学。出願登记完成后不能修改填写内容。
- 检定料 30,000 日元，在 Web 出願系统选择信用卡、网银、便利店或 Pay-easy 对应的银行 ATM 支付，手续费自付；除出願未被受理外不退还。
- 指导教员群的填写：入学願書里指定第1志望的指導教員群，小論文的选择问题按它所属的分野作答。
- 外国人留学生等的教育研究内容受安全保障出口管理限制，属于管制事项时可能无法接受希望的教育或研究活动受限。
- 入学手续在 2027年3月中旬（预定），详情 2月下旬邮寄通知。入学料 282,000 日元，授業料年额 535,800 日元（前期 267,900 日元），均为 2026年度的金额。全体新生须在新生体检时提交麻疹·风疹疫苗接种或抗体检查的证明。

- 研究生、科目等履修生是另一条路线，另有出願要项（2027年度4月·10月入学的研究生要项预定 2026/7/13 公开）。这不是修士入试的要求。
