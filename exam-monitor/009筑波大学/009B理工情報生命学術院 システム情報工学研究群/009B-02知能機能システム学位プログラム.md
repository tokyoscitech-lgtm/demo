## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 8月入试、1-2月入试相同：出願时提交外部英语检定成绩单，配点 100 分。本プログラム所有轮次、所有选拔区分（含推薦、社会人）都必须提交。
- 可用 TOEIC Listening & Reading（公开考试）、TOEFL iBT（Home Edition 也可）、IELTS Academic（纸笔版或机考版）。成绩须为 2024年7月以后受检，成绩单上要印有本人照片。
- 不受理：TOEIC IP、TOEFL ITP、IELTS General Training、IELTS Academic 在线版。
- 出願时没有交出符合条件的成绩单的，不论理由，外国语按缺考处理，不进入选考。
- 要项没有公布成绩到 100 分的换算公式；一般入试没有最低分。推薦入试（已结束）另有门槛：最低 TOEIC 470、TOEFL iBT 42 或 IELTS 4.0。

### 日本語要件
- 要项没有要求提交 JLPT 等日语成绩。
- Web 出願时填写的研究计划可用日文（约1000字）或英文（约500词）。口述试验的发表语言，要项和当日注意都没有规定。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 没有专门科目笔试（8月入试、1-2月入试） | 数学的基础学力并入口述试验1；出题范围和题数官方没有公布 | 2027募集要项／8月入试当日注意 |
| 外国語（100分） | 外部英语考试成绩换算，不另设考试 | 2027募集要项 |

- 总分 400（外国语 100＋口述试验 300）。口述试验1和口述试验2各占多少分官方没有公布，合格最低分也没有公布。
- 题目倾向（体验记，非官方）：本次没有找到本プログラム考生写的体验记。

### 口述試験 / 面接
- **官方形式**：配点 300 分，分两部分。口述试验1：数学的基础学力试问，要求自带铅笔和橡皮等文具。口述试验2：就现在的研究内容（毕业研究）、志望理由和研究计划做 5 分钟发表（4 分钟响铃一次、5 分钟响铃两次），之后就相关事项提问；发表资料打印在 A4 纸上，用实物投影仪（书画カメラ）投影，张数不限，不能使用电脑，彩色打印会按彩色投影。2026年8月的一般入试在筑波校区3L棟对面实施，开场前30分钟可入场，集合时刻不到可能失去资格。
- 实施方式的补充：要项写明本プログラム的社会人特别选拔（8月、1-2月）在线实施。一般入试1-2月期是否也对面实施，本次两次读取要项结果不一致，未核实，以1-2月入试的当日注意为准。
- **実際に聞かれた内容**：没有找到本プログラム的体验记，暂无可归纳的内容。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：推薦入试（7月）60名、一般入试（8月）57名、一般入试（1-2月）12名。社会人特别选拔与一般入试同时实施。
- 出願资格：日本4年制大学毕业或入学前一个月前预计毕业、在外国完成16年学校教育、在外国大学取得相当于学士的学位（修业3年以上课程）、或年满22岁并通过本校个别出願资格审查者等。
- 个别出願资格审查的截止日：8月期 2026/7/3（已过），1-2月期 2026/11/24。
- 研究群的1-2月入试设有 2027年4月／10月入学的区分；本プログラム是否可选10月入学本次没有单独核实。
- 所有出願者都必须事先取得志望指导教员的内诺；填写第2志望教员的，也要取得该教员的内诺。
- 外国籍者（永住者·特别永住者除外）、外国大学·企业·政府机关出身者等须从志望教员处取得「リファレンス番号」（出口管理用的编号，不是受験番号）并在 Web 出願时输入。本プログラム不在免除范围内。
- 出願书类：Web 入力（含研究计划，日文约1000字或英文约500词，不能含图表）、毕业（预定）证明书原件、成绩证明书原件、外部英语考试成绩单。
- 出願方式：先在 Web 出願系统入力，再把书类邮寄到システム情報エリア支援室（〒305-8577 茨城県つくば市天王台1-1-1），截止日必达。
- 检定料 30,000 日元，信用卡或便利店支付；国费外国人留学生免缴。
- 一个账号不能报多个学位プログラム，一个邮箱也不能注册多个账号。
- 出願者全员要在 Web 出願时回答安全保障出口管理（みなし輸出）的特定类型确认。
- 入学料 282,000 日元；授業料 年 535,800 日元，外国人留学生为年 608,800 日元。
- 受験票自行打印，考试当天携带；在线受験的要准备受験票和护照等带照片的身份证件。
- 研究生（Research student）是另一条路线，按大学层面的规定办理。这不是修士入试的要求。
- 咨询：大学层面为教育推進部入試課 admission.grad@un.tsukuba.ac.jp；プログラム的问题通过官网的咨询渠道或志望教员联系。
- 成绩开示：不合格者可在 2027/5/1–5/31 申请。
