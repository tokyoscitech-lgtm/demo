## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 一般入試、外国人留学生特別入試、社会人特別入試都不设英语笔试，改用 TOEIC 或 TOEFL 的成绩评分。收 TOEIC Listening & Reading 公开考试（只认在日本国内实施的）和 TOEFL iBT 两种。
- 成绩有效期：夏季入试只认 2024/8/25 以后受检的成绩（考试日前2年以内）。第二期未公布，上次是考试日前2年以内（2024/1/22 以后）。
- TOEIC 的提交方式：在出願期间内通过 TOEIC 报名网站的“大学・企業等へのスコア提出”功能提交，申请代码 00010407；不收纸质的公式认定证。出願期间内没提交的，按书类不全处理，不受理出願。
- TOEFL 的提交方式：交 Test Taker Score Report（带照片的原件加 A4 复印件，或 PDF 版的 A4 打印件），并且让 ETS 把 Institutional Score Report 寄到神戸大学（DI 代码 B071）。
- 不受理的种类：TOEIC-IP、日本以外实施的 TOEIC、TOEIC S&W、TOEIC Bridge、TOEFL ITP、TOEFL iBT Home Edition。IELTS 不在收取范围内。
- 配点：一般入試 100 分（总分 400 分中）。外国人留学生特別入試的英语配点在要项表格里读作 50 分（总分 250 分），建议对照要项原件确认。
- 换算：専攻按自己的基准把分数换算成满分，换算方法不公开，也不回答相关咨询；TOEIC 和 TOEFL 都交的，取换算后较高的一个。
- 専攻的注意事项文件里写的是交 TOEIC 公式认定证原件，这是 Web 出願导入之前的写法；2027年度要项规定只能通过 TOEIC 报名网站提交，以要项为准。
- 推薦入試不要求英语成绩（TOEIC 600 分以上的条件只适用于電気電子工学専攻和応用化学専攻，不适用于本専攻）。

### 日本語要件
- 要项没有要求提交日语成绩（JLPT、EJU 等都没有提到）。
- 外国人留学生特別入試可以申请英文版试题：在调查表（調査シート）里填写是否需要，填“需要”的人会同时拿到日文版和英文版试题。英文要项写明该入试的口头试问用英语进行。
- 一般入試的试题和口头试问以日语进行，要项没有提供英文版试题的安排。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：建築学専攻 64 名，这个数字包含推薦入試（约10名）、外国人留学生特別入試（若干名）、社会人特別入試的名额。第二期（仅外国人留学生特別入試）的人数未公布，上次为若干名。
- 出願资格（一般入試）：大学毕业或2027年3月底前预计毕业；在外国完成16年学校教育；在外国取得相当于学士的学位（3年以上课程）等共11项之一。其中资格(9)(10)(11)须事先接受出願资格审查。
- 出願资格（外国人留学生特別入試）：持有或2027年4月预计取得在留资格“留学”的外国人，并符合大学毕业、外国16年课程修了、外国3年以上课程取得学士相当学位、个别资格审查合格（2027年3月底前满22岁）等5项之一。
- 出願方式：只能通过 Web 出願系统登录并缴费，再把需要纸质提交的书类邮寄（書留速達，截止日17:00必达）或送到窗口（9:30–16:00，周末节假日和12:00–13:00除外）。照片、调查表、确认表等以 PDF 或图片上传。
- 检定料 30,000 日元，在 Web 出願系统支付，手续费自付。出願时和入学后都是国费外国人留学生的人免缴。
- 一次只能报一个専攻。出願手续完成后不能更改内容，检定料原则上不退。
- 证明书类原则上交原件，不收复印件，也不退还。中国的大学毕业者要另外办理 CHSI（中国高等教育学生信息网）的英文学位证明电子认证，并让认证邮件直接发到工学研究科；预计毕业者毕业后尽快办理，入学前认证没到可能取消合格。
- 在日本居住的外国人要上传住民票（提交日前30天内开具）；大学院在读或在职者要交受験許可書。
- 安全保障出口管理：神戸大学按外汇及外贸法审查留学生的接收，属于管制事项时，即使合格也可能不被允许入学，或研究内容受限制。
- 个别出願资格审查的申请截止：夏季入试为 2026/6/11（周四）17:00 必达（已截止）；推薦入試为 2026/5/11 必达（已截止）；第二期未公布（上次为 11/21）。
- 入学手续预定在 2027年3月中旬，详情 2027年2月下旬邮寄通知。入学料 282,000 日元，授業料 年 535,800 日元（前期 267,900 日元），均为2026年度金额。
- 考场规则：只能用黑铅笔、黑芯自动铅笔、塑料橡皮、铅笔帽、小型卷笔刀；手表只能是仅有计时功能的；计算器由考场借给。受験票从 Web 出願系统的マイページ下载后彩色打印带到考场。要项没有写迟到的处理办法。
- 入学后各専攻有若干名可以选修跨研究科的デジタル医工創成学コース。
- 研究生（非正规生）和科目等履修生·聴講生是另外的路线，各有单独的要项。这不是修士入试的要求。
