## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各轮次相同。一般入试考学内英语笔试「外国語（英語）」，100分，与専門科目同在 10:00–12:00 时段实施；可以带纸质辞典，电子辞典不可。
- 要项没有规定用 TOEIC、TOEFL、IELTS 等外部成绩代替，也没有最低分要求，出願时不交外部成绩。
- 社会人入试和推薦入试不考外语。

#### 日本語要件
- 要项没有要求提交 JLPT、EJU 等日语成绩。
- 「留学生可选日语作为外语科目」只设在文学·経済学·情報通信学等研究科的部分専攻，工学研究科的外语只能考英语。
- 英文版 Application Guide 覆盖本専攻，日程和考试科目与日文要项相同；两者都没有写明专门科目和面试的出题语言及能否用英语作答。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 外国語：英語（100分，10:00–12:00 时段） | 学内英语笔试；可带纸质辞典，不可用电子辞典 | 2026秋・2027春 一般・社会人要项 |
| 専門：建築学（200分，10:00–12:00 时段，与土木工学二选一） | 建筑计划·意匠、城市规划、建筑史、建筑结构力学、建筑材料·施工、建筑环境·设备中选 2 题作答；只能带函数计算器（不可用编程功能） | 同上 |

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：本専攻入学定员 35 名（2026年10月入学与2027年4月入学、一般・社会人・推薦各区分、一期·二期合计），各轮次没有分开的名额。
- 一般入试出願资格：大学毕业或预计在2026年9月（秋学期入学）／2027年3月（春学期入学）前毕业；在外国完成16年学校教育（含预计）；在外国3年以上课程取得相当于学士的学位（含预计）；大学在读3年以上并以优秀成绩取得规定学分（飞级）；经个别出願资格审查认定、年满22岁（春学期入学须 2005/4/1 以前出生）等。
- 出願资格审查：凭外国学历报考的人必须在出願前受审，二期截止 2026/12/11（周五）（一期 5/22 已过）。先向希望指导教员咨询，再用大学的书类提交表单上传履历书（大学规定格式，有留学生用）、毕业（预计）证明书、成绩证明书（均为3个月内开具，非日英文的附译文）；资格中含研究生期间的另交推荐书。中国大陆学历须由 CHSI 把英文学历认证和成绩认证直接发到大学指定的邮箱（本人转发无效），办理约需1个月。审查中可能被要求面谈。
- 社会人入试出願资格：大学毕业等，且毕业后有2年以上的社会经验。
- 推薦入试（只审书类，推荐人选定后才发给 WEB 出願用的认证ID）：本専攻的推薦基準包括本校同系列学科预计毕业生（成绩前50%以内，或2022年度以后入学者通算 GPA 3.5 以上、2021年以前入学者 2.8 以上，学科长强烈推荐；建筑领域另交志望理由书并面试）、本校其他学科预计毕业生（同样的成绩条件，由所属学部·学科和受入研究科·専攻·指导教员协商）、本校同系列学科毕业5年以内者（通算 GPA 2.8 以上）、日本国内大学毕业生和预计毕业生（通算 GPA 2.8 以上，选拔推荐人选时要面试）。推薦基準没有日本国外大学毕业生的类别。申请推薦前须先取得希望指导教员的同意。
- 出願书类：WEB 登录并缴费后打印的志願登録票（大学提出用2种）、最终学历的毕业（预计）证明书和成绩证明书（3个月以内开具；非日英文的附公的机构·日语学校·翻译公司证明的日文或英文译文）。一般入试和社会人入试另需事先提交入学后的研究计划书（格式和页数不限），寄到湘南校舍サイエンス・エンジニアリングカレッジオフィス，期限与出願书类相同。
- 出願方式：先在大学院 WEB 出願网站（sak-sak.net/app/tokaigs）登录个人信息和照片并缴费，再打印志願登録票·宛名ラベル，把书类用简易书留寄到サイエンス・エンジニアリングカレッジオフィス。缴费后不能修改输入内容；书类不齐不受理，出願后不能变更。受験票二期 2027/1/29（周五）起在网站打印。
- 检定料 32,000 日元，在 WEB 出願网站支付。
- 学费（2027年4月入学）：入学金 200,000 日元，春学期授業料 406,000 日元，入学手续时一次缴 606,000 日元；秋学期授業料 406,000 日元；另缴学研灾害伤害保险 2,430 日元、同窓会费 12,000 日元。本校毕业者免入学金（及同窓会费），九州東海大学·北海道東海大学毕业者入学金半额。2027/3/31（周三）17:00 前办完入学辞退的，退还入学金以外的费用。
- 考场为湘南校舍（神奈川县平塚市北金目4-1-1），具体教室见受験票。考试开始前20分钟入座，开始后20分钟仍未受付的不能应考；没考完全部科目的不进入合否判定。桌上只能放 HB 黑铅笔·自动铅笔、塑料橡皮、无计算和通信功能的手表等，専門科目另可带函数计算器；午饭自带。
- 考试需要特别照顾的，二期 2026/12/4（周五）前向入试担当申请（0463-63-4660，nyushi@tokai.ac.jp）。
- 咨询：サイエンス・エンジニアリングカレッジオフィス（〒259-1292 神奈川県平塚市北金目4-1-1），Tel 0463-63-4210；出願·入学手续帮助台 03-6625-0819（平日 10:00–18:00）。
