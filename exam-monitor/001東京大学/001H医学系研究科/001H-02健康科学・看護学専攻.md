## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 不另设英语笔试，用 TOEFL iBT（含 Home Edition）或 IELTS Academic 成绩做外国语审查；只认 2024/8/1 以后受检的成绩。IELTS General Training 和 One Skill Retake 成绩不受理。
- TOEFL：①在 ETS 账户把 Official Score Report 送到研究科（DI Code 8426 University of Tokyo Faculty MED，Division: Graduate Organization，Department 42 Medicine）；②在 WEB 出願系统登记 Appointment Number 和受检日；③上传同一次的 Test Taker Score Report PDF。三步缺一或上传件与官方成绩不一致都按无效处理；以前已用同一代码送过有效成绩的不必再送。
- IELTS：在 WEB 出願系统上传 Test Report Form，并在出願前向 IELTS 事务局申请把同一次的成绩单寄到研究科学務チーム大学院担当（寄到晚于出願截止也受理）。
- 考过多次也只能上传 1 份。
- 免交：学士毕业于澳大利亚、加拿大、爱尔兰、新西兰、英国、美国的大学，或毕业大学出具全校英语授课证明的，须事先联系研究科并在 2026/6/5 前提交审查材料（已截止）；逾期即使母语是英语也不免除。

#### 日本語要件
- 外国人（日本的大学毕业或预计毕业者除外）须提交「日本語能力証明書」：指导教员或相当的人出具的证明，也可用日语学校等的证明或日语考试合格证明的复印件代替。
- 小論文可用日文或英文写。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 保健学 | 线上笔试 |  |
| 専門分野 | 线上笔试，针对志望的専攻分野 |  |
| 小論文（出願时提交） | 所定样式，写志望理由和保健学·看护学知识技能的自我推荐（可写资格、活动成绩等），日文合计1,600字以内或英文700词以内（不含参考文献）；做抄袭检测，引用（含自己已发表的论文）须注明出处 |  |

- 一次考试按外国语审查、小論文、笔试综合评价，合格者参加二次口述；最终按出身学校成绩、提交书类、笔试和口述综合判定，成绩不足时合格者可能少于募集人员。
- 考试时间在出願后经 WEB 出願系统マイページ发放的「受験者心得」里通知。

### 口述試験 / 面接
- **官方形式**：二次考试为线上口头试问，只对笔试合格者进行；报保健師或助産師教育コース的人，教育コース的另行选拔口述与此一并进行，按入试成绩和「教育コース履修希望書」判定。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：25名（保健師教育コース上限约10名、助産師教育コース约5名）；只有 8 月一次募集。
- 出願资格：大学毕业（含 2027/3/31 前预计）或外国 16 年学校教育等；个别入学资格审查须先邮件联系研究科，2026/6/5 前提交材料（非独立出願，已截止）；保健師、助産師教育コース只面向持有或预计取得日本看護師执照的人，两者只能选一，任何专攻分野都可兼报。
- 要提前准备的书类：小論文（所定样式）、誓約書（所定样式，签名）、TOEFL 或 IELTS 成绩、日本語能力証明書（外国人）、教育コース履修希望書（仅报教育コース者，A4 1页，写志望指导教员、希望コース及其与研究内容的关系）；海外大学的毕业证明须为英文或附公证英译，并写明学位名。
- 出願：只能通过 WEB 出願系统上传；检定料 30,000 日元（银行汇款、便利店、Pay-easy 或信用卡，手续费自付；日本政府奖学金留学生免缴）。
- 咨询：医学系研究科学務チーム大学院担当（〒113-0033 東京都文京区本郷7-3-1），in.m@gs.mail.u-tokyo.ac.jp；研究科入试页另有咨询表单。
- 并愿：保健師、助産師教育コース只面向持有或预计取得日本看護師执照的人，两者只能选一，任何专攻分野都可兼报。
