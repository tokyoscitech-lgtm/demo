## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 8月入试（笔试免除者选拔、一般選抜）：
  - 不另设英语笔试，用 TOEFL iBT（含 Home Edition）或 TOEIC Listening & Reading 公开考试的成绩评价，配点 200 分（専攻入试案内）；换算方法官方没有公布。成绩贴在「スコアシート提出用紙」上随书类寄出，两种可以只交一种，也可以都交；笔试免除者选拔出願时必须交。
  - TOEIC 只收 Official Score Certificate 原件（不发行该证书的国家交 Official Score Report 和 Certificate of Achievement）；TOEFL 须 ETS 直送大学的 Institutional／Official Score Report（Institution Code D377，Department Code 69）加 Test Taker Score Report 复印件，两样都要在出願期间最后一天前到达。
  - 只认 2024/6/1 以后实施的成绩，TOEIC 限 2026/5/17 以前实施的场次（成绩单寄到约要一个月）；TOEFL ITP、TOEIC IP 不受理。没交成绩可以应考，但英语不计分。
- 外国人留学生入试：
  - 本専攻实施学内的语学考试（英语），不使用 TOEFL/TOEIC 成绩（只有化学生命、マテリアル、電気電子情報系用外部成绩）；题型和配点官方未公布，由専攻另行通知。
- G30（2027年10月入学）：
  - 须交以下之一的正式成绩（由考试机构直送）：IELTS Academic 总分 6.0、TOEFL iBT 80（2026年1月起的新计分为 4.0）、Duolingo English Test 110、CEFR C1；TOEIC 和 TOEFL ITP 不受理。大学课程以英语授课的，可交学校出具的授课语言证明代替。英语能力还在口试中评价。

#### 日本語要件
- 8月入试：要项没有要求提交日语成绩，没有 JLPT／EJU 门槛；笔试和口頭試問用日语进行。
- 外国人留学生入试：
  - 出願时须交「日本語能力を証明するもの」：日语担当教员等出具的证明书原件，或 JLPT／JPT 成绩复印件；要项没有规定最低等级。
  - 专门科目试题日英并记；要项写明可能在语学考试、口頭試問中检定日语能力。
- G30（2027年10月入学）：要项没有日语要求，课程和选拔都用英语。
