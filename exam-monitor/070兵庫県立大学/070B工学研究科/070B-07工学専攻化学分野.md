## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 8月入试（一般·社会人·外国人学生）：不另设英语笔试，用外部成绩评价——提交 2023/4/1 以后受验的 TOEIC 公式认定证原件（数字公式认定证可）或 TOEIC IP 的 Score Report（限线下实施），结果计入综合判定。
- 推荐选拔（一般学生、外国人编入学生）不看 TOEIC。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 外国人学生和一般学生考同一套专门科目和小论文，试题为日文。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 科目群E：化学1 | 有机化学、生物化学、高分子化学 | 10:00–11:20，80分钟 |
| 科目群E：化学3 | 物理化学、无机·分析化学 | 13:00–14:20，80分钟 |
| 科目群F：化学2 | 化学工学基础（物料衡算、蒸馏、气体吸收、萃取、吸附、干燥、扩散、传热）、金属学、有机化学 | 10:00–11:20，80分钟 |
| 科目群F：化学4 | 物理化学、无机化学、反应工学、电气化学 | 13:00–14:20，80分钟 |
| 小论文 | 各科目群共通 | 14:50–15:50，60分钟 |
| 推荐选拔（一般学生）：小论文 | | 10:30–11:30，60分钟 |

- 8月入试出願时从科目群 A–F 中选1组，与本分野对口的是科目群E（化学1·3，偏有机·生化·高分子与物化·无机分析）或科目群F（化学2·4，偏化学工学·金属学与反应工学·电化学）；外国人学生与一般学生考同样的科目。
- 8月入试：学力试验、TOEIC 成绩、面接和成绩证明书综合判定；社会人以口述试验代替学力试验，另看所属机构推荐书。
- 推荐选拔（一般学生）：小论文、面接、成绩证明书和推荐书综合判定。
- 题目倾向（2026年度入学过去问）：化学1 为有机2题、生化1题、高分子1题；化学3 为偏摩尔量与活度、原子轨道与分子构型、反应速率与活化能、溶度积与螯合平衡；化学2 为吸附、燃烧物料衡算·干燥、二元相图、有机命名与反应；化学4 的溶液热力学、无机题与化学3 相同或相近，另有反应器设计和电极电位。
- 小论文用日语写约600字，谈将来想成为怎样的研究者·技术者并联系 DX·GX·LX·MX 之一。

### 口述試験 / 面接
- **官方形式**：8月入试（一般·外国人学生）：学力试验次日面接；社会人：口述试验（主要针对研究计划书）＋面接；推荐选拔（一般学生）：小论文后面接；推荐选拔·外国人编入学生：面接＋口述试验（专门科目），结合成绩证明书和推荐书判定，考试和发表都在姫路工学キャンパス。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：化学分野约40名（一般·社会人·外国人学生，分野名额为目安；工学専攻合计120名）；推荐选拔（一般学生）约10名（工学専攻合计30名）；推荐选拔·外国人编入学生各分野若干名；2026年10月入学各分野若干名（与8月入试同一场考试）。变更点：工学専攻合计从2026年度的150名减为120名，本分野从50名减为约40名。
- 出願资格：一般学生为大学毕业（含 2027/3 预定）、外国16年课程修了等；外国人学生限以在大学院接受教育研究为目的入境的外国人，日本大学毕业或预定毕业者不属于此区分（报一般学生）；外国15年课程修了等须先办出願资格事前审查，书类先交希望的研究指导教员协议，2026/7/6 前提交学務課（非独立出願）；推荐选拔·外国人编入学生限从海外编入日本大学、持「留学」在留资格、2027/3/31 前毕业预定者；公费（国费·县费等）留学生可能在2月另行选考。
