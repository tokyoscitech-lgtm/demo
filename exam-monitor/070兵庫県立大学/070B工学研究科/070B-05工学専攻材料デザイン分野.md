## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 8月入试（一般·社会人·外国人学生）：不另设英语笔试，用外部成绩评价——提交 2023/4/1 以后受验的 TOEIC 公式认定证原件（数字公式认定证可）或 TOEIC IP 的 Score Report（限线下实施），结果计入综合判定。
- 推荐选拔（一般学生、外国人编入学生）不看 TOEIC。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 外国人学生和一般学生考同一套专门科目和小论文，试题为日文。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 材料デザイン1 | 材料科学：晶体结构与X射线衍射、固体中的缺陷、合金状态图、焓·熵·吉布斯能变化、反应速度论、平衡、化学势、金属的力学性质、弹塑性变形、位错与强化机制 | 10:00–11:20，80分钟 |
| 材料デザイン2 | 物性物理：原子结合与晶体结构、光和电子的波粒二象性、自由电子论、晶格比热、晶格振动与色散关系，以及运动方程、功与能、动量与冲量·碰撞 | 13:00–14:20，80分钟 |
| 小论文 | 各科目群共通 | 14:50–15:50，60分钟 |
| 推荐选拔（一般学生）：小论文 | | 10:30–11:30，60分钟 |

- 8月入试出願时从科目群 A–F 中选1组，与本分野对口的是科目群D（材料デザイン1·2）；外国人学生与一般学生考同样的科目。
- 8月入试：学力试验、TOEIC 成绩、面接和成绩证明书综合判定；社会人以口述试验代替学力试验，另看所属机构推荐书。
- 推荐选拔（一般学生）：小论文、面接、成绩证明书和推荐书综合判定。
- 题目倾向（2026年度入学过去问）：材料デザイン1 为5道大题（平衡空位浓度与滑移系、形核临界半径与二元相图、弹性常数、Hollomon 式拉伸特性、吉布斯能与反应自发性）；材料デザイン2 为5道大题（弹簧–质量–阻尼系、金属键与自由电子论述、金刚石结构填充率、一维双原子链色散关系、自由电子态密度）；小论文用日语写约600字，谈将来想成为怎样的研究者·技术者并联系 DX·GX·LX·MX 之一。

### 口述試験 / 面接
- **官方形式**：8月入试（一般·外国人学生）：学力试验次日面接；社会人：口述试验（主要针对研究计划书）＋面接；推荐选拔（一般学生）：小论文后面接；推荐选拔·外国人编入学生：面接＋口述试验（专门科目），结合成绩证明书和推荐书判定，考试和发表都在姫路工学キャンパス。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：材料设计·放射光工学分野合计约20名（一般·社会人·外国人学生，分野名额为目安；工学専攻合计120名）；推荐选拔（一般学生）两分野合计约5名（工学専攻合计30名）；推荐选拔·外国人编入学生各分野若干名；2026年10月入学各分野若干名（与8月入试同一场考试）。变更点：工学専攻合计从2026年度的150名减为120名，两分野合计从25名减为约20名。
- 出願资格：一般学生为大学毕业（含 2027/3 预定）、外国16年课程修了等；外国人学生限以在大学院接受教育研究为目的入境的外国人，日本大学毕业或预定毕业者不属于此区分（报一般学生）；外国15年课程修了等须先办出願资格事前审查，书类先交希望的研究指导教员协议，2026/7/6 前提交学務課（非独立出願）；推荐选拔·外国人编入学生限从海外编入日本大学、持「留学」在留资格、2027/3/31 前毕业预定者；公费（国费·县费等）留学生可能在2月另行选考。
- 要提前准备的书类：TOEIC 公式认定证或 IP Score Report；社会人交所属机构推荐书、承诺书和研究计划书；推荐选拔（一般学生）交学科长或指导教员的推荐书；推荐选拔·外国人编入学生交在籍大学学科长或指导教员的推荐书和兵庫県立大学指导预定教员的推荐书。
- 出願：书类持参或用本学所定信封邮寄，期限内必达，没有网上出願；检定料 30,000 日元（银行汇款）；纸质要项（含愿书）须寄贴 320 日元邮票的角形2号返信信封向姫路工学キャンパス学務課索取。
- 并愿：推荐选拔（一般学生、外国人编入学生）都要求合格后确约入学；外国人编入学生须在出願截止前没有考过日本任何大学院的博士前期入试；8月入试只能选1个科目群。
- 咨询：姫路工学キャンパス経営部学務課（〒671-2280 兵庫県姫路市書写2167，电话 079-267-4109）；合否不接受电话查询。
