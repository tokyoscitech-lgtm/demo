## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各日程相同：不另设英语笔试，用 TOEFL iBT（含 Home Edition）成绩评价；所属团体实施的 ITP 不受理，MyBest Scores 不采用。
- 在有效期间内受检，并在同期间内向 ETS 申请把 Institutional (Official) Score Report 送到研究科（DI code 1113，其他代码无效）；出願时在 WEB 系统填写 Appointment Number、受检日和分数，不必交 Test Taker Score Report。送过多份的只指定其中一次。
- 有效期间：A日程 2024/8/1–2026/6/13；B日程 2025/2/1–2026/11/15（均已过）。

#### 日本語要件
- 要项没有要求提交日语成绩。
- A日程専門科目日英并记出题，可用日语或英语作答。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| A日程：専門科目 2科 | 从栽培学、植物分子遺伝学、育種学、植物病理学、応用昆虫学、作物学、園芸学、昆虫遺伝・病理学、生物測定学 9科中选2科；出願时选定，考试当天可以改选 |  |
| B日程：书类选考 | 看出身大学成绩证明书和 TOEFL 成绩，合格者进入口述；不合格检定料不退 |  |

- 2026年度A日程每科3问：前2问是该领域论述题，第3问是术语·基本概念题（育種学为短文说明，応用昆虫学为选择题）。
- 2026年度A日程各科考查内容（出题意图）：栽培学为农业技术体系与温室气体排放；植物分子遺伝学为水稻正向遗传学与基因组编辑；育種学为转基因与基因组编辑的规制、F1育种；植物病理学为产毒病原菌生活史、植物病毒基因功能；応用昆虫学为昆虫分类与杀虫剂作用机制；作物学为水稻与大豆形态生理、同化产物运输；園芸学为顶端优势与芸薹属遗传；昆虫遺伝・病理学为家蚕突变体与杆状病毒·Bt利用；生物測定学为方差分析、连锁不平衡与基因组选择·GWAS。
- 成绩不足时可能录不满。
- 变更点：2026年度B日程考过専門科目笔试，2027年度B日程改为书类选考＋线上口述。

### 口述試験 / 面接
- **官方形式**：A日程线上进行；B日程只限书类选考合格者，线上进行，先口头发表志望动机、毕业论文（或相当研究）内容和入学后的研究计划，再就论文要旨和出願资料问答，并口头试问本専攻专门知识和农学生命科学综合知识。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：28名（A日程，2026年10月＋2027年4月入学）；B日程若干名（2027年4月＋2027年10月入学）。
- 出願资格：大学毕业（含2027/3/31前预计）或外国16年学校教育等；个别入学资格审查 A日程 2026/5/7、B日程 2026/10/7 截止（非独立出願，已过）；同一日程只能报研究科一个専攻；入学时期出願时选定、之后不能改；志望最多填到第3志望，须为不同专门分野的教员；海外居住者报B日程4月入学，发表到入学时间短，可能来不及入境。
- 要提前准备的书类：TOEFL iBT 送分；B日程另交毕业论文（或相当研究）要旨（格式自由，A4 1页以内），2027年1月底前邮件发到 aeb-chief@ab.a.u-tokyo.ac.jp；日英以外的证明书附日译或英译。
- 出願：只能通过 WEB 出願系统上传 PDF；检定料 30,000 日元（银行汇款〔邮储除外〕、便利店、信用卡、Pay-easy），日本政府奖学金留学生免缴。
- 并愿：同一日程只能报研究科的一个専攻。要项允许有资格的人 A、B 两个日程都报，本専攻案内没有另设限制。
- 咨询：出願手续问农学生命科学研究科教務課学生支援チーム大学院学生担当（〒113-8657 東京都文京区弥生1-1-1，Tel 03-5841-5010，daigakuin.a@gs.mail.u-tokyo.ac.jp）；専攻内容问井澤 毅 教授（Tel 03-5841-5063，takeshizawa@g.ecc.u-tokyo.ac.jp）或専攻主任邮箱 aeb-chief@ab.a.u-tokyo.ac.jp。
