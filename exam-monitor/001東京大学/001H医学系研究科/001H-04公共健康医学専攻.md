## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 须提交 TOEFL iBT 成绩（含 TOEFL iBT Home Edition），不再有英语笔试；其他英语考试不受理，TOEFL ITP 和 MyBest Scores 是否可用，别纸没有写。
- 提交要做完三步，缺一步就不受理：①在 ETS 账户里把 Official Score Report 寄送到研究科，机构代码 DI Code 8426（University of Tokyo, Faculty of Medicine），Department 代码 42（Medicine）；②在 WEB 出願系统里登记 Appointment Number 和受检日；③在 WEB 出願系统上传同一次考试的 Test Taker Score Report（PDF，考后约 8 天可从 ETS 下载）。
- 有效期：只收 2024/8/1 以后受检的成绩。考过多次的只能上传一份。
- 截止：别纸只写“规定的提交期限”，没有单独的日期，实际上要随 WEB 出願（2026/6/29 截止）一起上传。
- 官方成绩没有确认到、上传的成绩单与官方成绩不一致、成绩过期的，都按没有参加外语审查处理；研究科不告知成绩是否送达。
- 最低分和换算方法官方没有公布。
- 变更点：2026年度及以前是専攻自己出题的英语笔试，2027年度起改为 TOEFL。

### 日本語要件
- 外国人须提交「日本語能力証明書」（研究科指定样式，由指导教员等出具；也可用日语学校的证明或日语检定合格证的复印件代替）。日本的大学毕业或预定毕业者不用交。
- 要项没有规定日语检定的级别或分数。笔试是否可以用英文作答，要项和入试案内没有记载。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员合计 30 名：2年コース约 20 名，1年コース约 10 名；成绩不够时可能招不满。
- 出願资格：大学毕业或 2027/3/31 前预计毕业；在外国完成 16 年学校教育；在外国取得相当于学士的学位；文部科学大臣指定的教育机构毕业；由学位授与机构取得学士学位；经个别入学资格审查认定且入学时满 22 岁，以上之一。
- 1年コース另需保健医疗相关的实务经验 3 年以上，须事先确认：2026/6/5（周五）前提交履历书和各任职单位的在职证明，结果在出願开始前通知（已截止）。
- 出願书类（全部在 WEB 出願系统上传）：入学願書、照片（jpg，3 个月内）、检定料缴纳证明、成绩证明书、毕业（预定）证明书（海外学位需英文证明）、TOEFL 成绩；1年コース加在职期间证明书；在职者加学习计划书（A4 2 页）；外国人加日本語能力証明書。成绩证明等合格后要补交纸质原件。
- 要项没有要求提交研究计划书，也没有让考生填写志望研究室或志望分野的规定。
- 检定料 30,000 日元，可用银行汇款、便利店、Pay-easy、信用卡支付，手续费自付；国费留学生免缴。要项没有另写缴纳截止日，须在出願期间内完成。
- 入学料 282,000 日元，授業料年额 535,800 日元（前期 267,900 日元），均为 2027年度预定额；国费留学生免缴。
- 入学手续：2026年9月上旬在 WEB 出願系统领取入学许可通知；2027年2月下旬邮件通知手续办法，3月上旬缴入学料并交手续书类。在职入学的要交单位的承诺书；外国人要在办手续前取得可以入学的在留资格。
- 咨询：医学系研究科学務チーム大学院担当，in.m@gs.mail.u-tokyo.ac.jp，〒113-0033 東京都文京区本郷7-3-1；研究科入试页另有咨询表单。
