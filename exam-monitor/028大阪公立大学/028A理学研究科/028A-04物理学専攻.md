## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 一般選抜（第1次·第2次）：英语不另考，用外部考试成绩换算为英语分，配点 50 分。可交 TOEIC L&R 公式认定证（纸本或带 URL 的数字版）、TOEFL iBT Test Taker Score Report、TOEIC IP 成绩单之一，原件。TOEFL iBT Home Edition 不受理。
- 换算上限：TOEIC 785 分、TOEFL 72 分即满分（TOEFL 只用 Test Date Score）。
- 有效期：第1次募集为 2024/7/1–2026/6/30 受检；第2次募集为 2025/1/1–2026/12/31 受检。
- 出願时尚未拿到成绩的，必须随出願书类附「スコア未提出申出書」，再在补交期限前寄到（第1次 2026/8/4 必着，第2次 2027/1/26 必着）；没附申出书的不接受事后补交。
- 外国人留学生特別選抜：同样外部成绩换算 50 分，物理学専攻收 TOEIC L&R、TOEFL iBT、TOEIC IP 三种（IELTS 不在物理的可选范围内）。有效期为 2024/10/1–2026/9/30 受检，补交期限 2026/11/10（周二）必着。

### 日本語要件
- 一般選抜：要项没有要求提交日语成绩。
- 外国人留学生特別選抜：物理学専攻明确不需要提交日本語能力证明书（其他専攻需要）。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 筆記試験（300分，150分钟；一般選抜第1次募集） | 物理学全般（专门科目） | 2027募集要项 |
| 英語（50分；一般選抜第1次·第2次） | 不考试，外部成绩换算 | 2027募集要项 |
| 第2次募集 | 不设笔试，物理学全般在口述中考查 | 2027募集要项 |
| 外国人留学生特別選抜（2026/11/21） | 科目明细在 PDF 中未能读出（文本提取不完整） | — |

- 一般選抜第1次募集总分 500（笔试 300＋口述 150＋英语 50）；第2次募集总分 500（口述 450＋英语 50）。
- 判定：按志望专门分野，结合各分野的志愿情况综合判断，所以不一定按总分名次录取。要项没有写最低分或足切り。

### 口述試験 / 面接
- **官方形式**：第1次募集口述 150 分，考专门科目；第2次募集口述 450 分，内容为物理学全般、入学后的研究计划、毕业研究内容。

## 📝 详细信息
### 出願資格 / 定員
- 入学定員 55 名（募集人员 55 名，含推薦入学特別選抜、一般選抜、外国人留学生特別選抜，未分开写；物理学専攻的外国人留学生特別選抜只有第1次）。
- 出願资格：大学毕业或 2027年3月底前预计毕业等〔11〕(1)–(11)；(9)–(11) 须事先个别资格审查，(10) 为飞级出願。
- 资格审查申请（一般選抜）：物理学専攻只在第2次募集时受理，期间 2026/10/28–11/4 必着（已过）。外国人留学生特別選抜（数学·物理）的资格审查为 2026/9/9–9/16 必着（已过）。
- 出願书类（一般選抜）：出願确认票、毕业（预定）证明书、成绩证明书（原件）、志望理由书（500字以内）、英语外部成绩原件、写真票·照片、宛名标签。
- 出願书类（外国人留学生特別選抜）：另需履歴書（指定格式）、厳封推薦书、在留卡或护照复印件；志望理由书 500字（英文 250 words）；不需要日语证明。
- 出願方式：网上登录（故障期间用 sak-sak.net 入口）＋书类邮寄，消印有效。
- 网上出願时按志望顺序输入志望专门分野 1–3。
- 入学检定料 30,000 日元＋手续费 990 日元。
- 事前相談过的教员姓名要填在出願信息里（可填多名）。
- 入学料 282,000 日元（大阪府民及其子女）／382,000 日元（其他），授業料 年 535,800 日元。外国人留学生不适用大阪公立大学等授業料支援制度。须自备笔记本电脑。
- 考场：杉本キャンパス（JR阪和線 杉本町駅），受験票自行打印携带。
- 仮合格者（如3年级在学飞级）须在 2027/3/2 前补交成绩接受二次审查，正式合格者编号 2027/3/9 10:00 网上公布。
- 个人成绩开示：第1次（物理）及外国人留学生特別選抜等按要项期间在门户网站查看（外国人留学生特別選抜为 2027/5/7–6/4）。
- 长期履修制度可申请。
- 咨询：杉本キャンパス入試課 理学研究科担当，〒558-8585 大阪市住吉区杉本3-3-138，Tel 06-6605-2141，gr-nyu-gss@omu.ac.jp；International Course 另有 omu.admission.sci@gmail.com（故障期间）。
