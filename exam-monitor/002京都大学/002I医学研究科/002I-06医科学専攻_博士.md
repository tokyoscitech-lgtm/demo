## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 接受 TOEFL iBT 或 TOEIC L&R 公开考试，成绩须为出願截止日前两年以内受检；不接受 TOEFL Home Edition、ITP、MyBest Scores 和 TOEIC IP。无现场英语笔试。
- TOEFL：ETS直送（DI 9501）并交 Test Taker Score Report 复印件，或提交要项认可的 Test Taker Score Report 原件；不能把网上PDF自行打印件当作原件。TOEIC交数字官方认定证的打印件；海外考试没有数字认定证时须官方直送或事先咨询教务。
- 有效受检日为2024/12/24以后。要项未规定最低分与换算公式；须按规定提交有效成绩，不能视为英语任意提交。

#### 日本語要件
- 本路线2027要项未要求JLPT或EJU等日语成绩证明；语言能力、研究指导与发表语言须与拟接收导师确认，不据此保证所有研究室均可全英语完成。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：若干名，未公布精确人数；入学2027年4月，旧制博士后期通常3年。
- 出願资格：修士／专业职学位、外国相当学位等要项各项之一；需个别审查的资格6–8于2026/11/27 17:00前提交（日本国内11/23以前消印可适用例外）；外国学历可按需要于11/18 17:00前申请资格确认，AAO及导师同意须先办。
- 要提前准备的书类：学位和成绩证明、英语证明、约1500日文字符的研究内容概述、规定志望理由及身份材料；资格6–8按要求交研究经过报告。现京大医科学修士预计毕业者另走内部进学程序，经所属研究室办理。
- 出願：WEB登记、缴费与纸质材料都要完成；检定料30,000日元（适用免除者除外）。纸件书留速达或窗口必达；常勤工作者须于2027/3/31前辞职，不得把本条目当社会人保留常勤工作的路线。
