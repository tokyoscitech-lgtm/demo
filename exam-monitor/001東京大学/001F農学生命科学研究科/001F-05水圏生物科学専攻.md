## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各日程相同：不另设英语笔试，用 TOEFL iBT（含 Home Edition）成绩评价。
- 送分：向 ETS 申请把 Institutional (Official) Score Report 送到研究科（DI code 1113），其他代码无效；出願时在 WEB 出願系统里填写 Appointment Number、受检日和分数，不必交 Test Taker Score Report。
- 有效受检期间（向 ETS 申请送分也须在此期间内完成）：A日程 2024/8/1–2026/6/13（已过）；B日程 2025/2/1–2026/11/15。
- 送过多次的，出願时只指定一次。TOEFL ITP 不受理，MyBest Scores 不采用，其他英语成绩不能代替。
- 要项和専攻案内都没有写最低分、换算方法和配点。

#### 日本語要件
- 要项和専攻案内都没有要求提交日语成绩（JLPT 等），外国人考生走一般选拔也不用交；研究科不设单独的外国人留学生特别选拔。
- A日程：专门科目用日语出题、日语作答，口述对面进行，实际需要能用日语答题。
- B日程：专门科目用英语出题、英语作答，口述线上进行（语言官方未写明）。
- 从初等、中等教育起都在日语以外的语言环境中受教育的课程毕业（预定）者，出願前须接受出願对象审查：B日程截止 2026/10/7（已过）。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：A日程（2027年4月入学）30名，B日程（2027年4月入学）若干名；本専攻不实施 10月入学。
- 出願资格：日本的大学毕业或 2027/3/31 前预计毕业、在外国完成 16 年学校教育、在外国大学修完 3 年以上课程并取得相当于学士的学位、经个别入学资格审查认定且 2027/3/31 满 22 岁等 6 项之一。个别入学资格审查申请截止：A日程 2026/5/7、B日程 2026/10/7（均已过）。
- 志望填写：在 WEB 出願系统里按「教員並びに専門分野一覧」选志望专门分野和指导教员，最多填到第3志望；第2、第3志望可以选同一分野的其他教员，没有可以不填。专门科目 2 科也在出願时选定，出願期结束后原则上不能修改。
- 出願书类：入学願書（含 3 个月内照片）、出身大学成绩证明书、毕业（预定）证明书（写明学位名和授予日）、检定料缴纳证明、国费留学生证明书（仅国费生）、TOEFL 成绩；本専攻没有追加専攻指定书类。日语、英语以外的证明书附译文，PDF 上传，合格后提交原件。
- 出願方式：只能通过 WEB 出願系统，没有邮寄或窗口出願；受験票考前自行打印（A4），考试当天带上。B日程受験者心得到 2027/1/13 还没收到的要联系教務課。
- 检定料 30,000 日元，银行汇款（邮储银行除外）、便利店、信用卡、Pay-easy 均可；缴纳期间 A日程 2026/4/13–6/23（已过），B日程 2026/10/5–11/25。国费留学生免缴；缴后不退。
- 并愿：同一日程只能报研究科的一个専攻；本専攻同一年度只能报一次，报了 A日程就不能再报 B日程。
- 外国人须在入学前取得可以就读的在留资格；B日程合格后 4月入学的，注意入境时间。
- 入学料 282,000 日元，授業料 年 535,800 日元（前期 267,900 日元），均为预定额；国费留学生免缴。入学许可通知 2027年2月下旬，3月上旬办手续。
- 研究生（外国人留学生等）另有单独的出願要项，这不是修士入试的要求。
- 咨询：専攻事务找第1志望教员或専攻主任濵﨑 恒二 教授（Tel 04-7136-6171，hamasaki@g.ecc.u-tokyo.ac.jp）；出願手续问农学生命科学研究科教務課学生支援チーム大学院学生担当（〒113-8657 東京都文京区弥生1-1-1，Tel 03-5841-5010，daigakuin.a@gs.mail.u-tokyo.ac.jp）。
