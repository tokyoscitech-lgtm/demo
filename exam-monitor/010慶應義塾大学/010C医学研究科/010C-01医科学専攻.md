## 🎯 入試内容（考什么）

### 語学 / 英語要件
- Ⅰ期募集、Ⅱ期募集相同：不设英语笔试，用外部英语考试成绩代替。出願时提交 TOEFL iBT 或 IELTS（Academic Module）的成绩证明，可以交复印件，同时在 Web 出願登録画面里录入分数。
- 有效期：从出願截止日往前 2 年以内受检，并且能在出願期间内提交。Ⅱ期募集的出願截止日是 2026/11/20，即 2024/11/20 以后的成绩。
- 不受理：TOEFL 的 MyBest Scores 和 IELTS 的 One Skill Retake 成绩。要项只列了 TOEFL iBT 和 IELTS 两种，TOEIC 不在其中。TOEFL iBT Home Edition、IELTS Online 能不能用，要项没有提到。
- 要项没有规定最低分，也没有写配点和换算方法。
- 没有符合条件的英语成绩就没有出願资格，不能事后补交。

### 日本語要件
- 要项没有要求提交日语成绩（JLPT、EJU 等都没有提到）。
- 小論文的试题日文、英文并记，可以用日文或英文作答。本课程以日语授课（英文页注明 taught in Japanese）。
- 出願书类用日文或英文书写；其他语言的证明书要附日文或英文译文，并经大使馆或公证处证明。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| Ⅰ期募集·Ⅱ期募集共通：小論文（配点官方未公布，90分钟） | 论述题，没有专门科目的笔试。要项注明作答有时需要大学 1 年级程度的生物学知识。公开的过去问每期 1–2 题、全部必答，主题是医学·医疗与社会的关系和研究者的素养（医疗技术进步带来的伦理问题、先进医疗的公平负担、AI 进入医疗现场的影响与误诊责任、研究不正、团队研究中的第一作者问题、研究的独创性）；2025年度実施的题目每题要求日文约 200 字或英文约 100 words | 入学試験要项／过去问页 |
| 国外居住者（Ⅰ期·Ⅱ期） | 不到场考小論文，改为提交研究科指定的事先课题；具体做法在受験票公开后由学生課用邮件通知 | 入学試験要项 |

- 合否按筆記試験（小論文）、面接和志望理由书等书类综合判定，各项的比重按専攻的特点设定；配点和合格线官方都没有公布。
- 「出題の意図」说明小論文看的是：能否从伦理、经济、法律、社会制度等多个角度理解医疗和研究上的问题，并把自己的看法有条理地写出来；不考细的专门知识。
- 题目倾向（体验记，非官方）：没有找到考生本人写的体验记，暂时没有官方资料以外可归纳的倾向。

### 口述試験 / 面接
- **官方形式**：Ⅰ期募集、Ⅱ期募集都有面接（Ⅰ期 2026/7/3，Ⅱ期 2027/1/15），和志望动机等书类一起评价；配点、每人时长、面试官人数和使用语言要项都没有写。集合时刻和地点按受験票上的网址通知，过了集合时刻就不能应考。国外居住者改为线上面接。
- **実際に聞かれた内容**：没有找到本専攻考生写的体验记（日文、英文、中文都检索过），实际问了什么没有可靠来源。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：医科学専攻修士課程 20 名（2027年4月入学）。这是Ⅰ期募集和Ⅱ期募集合在一起的数字，要项没有按期拆分。
- 出願资格（Ⅰ期、Ⅱ期相同）：①大学毕业或 2027/3/31 前预计毕业；②由大学改革支援·学位授与机构取得学士学位；③在外国完成 16 年学校教育；④修完文部科学大臣指定的 4 年以上専修学校専門課程；⑤文部科学大臣指定者；⑥在大学就读 3 年以上、以优秀成绩修得规定单位者（到 2027年3月底在学满 3 年，预计取得 90 单位以上，其中 60 单位以上已取得最高评语）；⑦在外国大学完成 3 年以上课程并取得相当于学士的学位；⑧经认定具有与大学毕业同等以上学力、入学时满 22 岁者。专攻介绍页写明招收对象是齿学、兽医学以外的自然科学系以及人文·社会科学系的学部毕业生。
- 出願資格認定：资格⑥和⑧必须先申请认定。Ⅰ期 2026/4/13（周一）–4/17（周五）（已截止），Ⅱ期 2026/10/26（周一）–10/30（周五）；把认定申请书、履历书（学历从小学写起）、最终学历证明、申请理由书、最终学历学校的课程资料做成 PDF 用邮件发给大学院入試担当，不收费，约 2 周后用邮件通知结果。
- 希望指导教员：只能从 Web 出願登録画面列出的教员里选，出願前必须得到希望指导教授的许可，没有许可不能出願；多位教员共同指导时写主指导教授。
- 出願书类（Ⅰ期、Ⅱ期各自都要交全套）：出願书类チェックリスト、入学志願者調書（Web 登録后打印）、入学志願者調書B、入学志願者履歴書、志望動機（所定用纸，可手写或在 Word 里输入后打印，本人亲笔签名；要项没有规定字数和页数）、出願確認書（希望分野的研究科委員亲笔签名，可以用 PDF 往来后打印的复印件）、成绩证明书、毕业（预定）证明书、志願者に関する報告書（由学部指导教员等填写并密封）、英语成绩复印件；外国大学毕业而毕业证明上没写学位的另交学位取得证明，资格⑥的另交在学证明。中国大陆的大学毕业者还要交「教育部学历证书电子注册备案表」英文版。
- 书类的规定：证明书只收原件或经官方证明与原件相同的副本，不收普通复印件；A4 单面；除出願確認書上教员的签名外，本人签名必须手写，不能用电子签名。
- 出願方式：Web 出願登録 → 缴检定料 → 邮寄书类，三步都完成才算出願。书类装进自备信封，贴上 Web 画面打印的地址标签，用速達書留（或速達簡易書留）寄到信濃町学生課大学院入試担当；国外用 EMS、FedEx、DHL 等可追踪的方式。不收窗口递交和校内信件，过了截止日一律不收，也不接受是否送达的查询。
- 检定料 35,000 日元，另付手续费，按 Web 出願时指定的支付页面办理。只有没有出願或重复缴纳时才退，须在出願期间最后一天起 1 周内申请。
- 再报：Ⅰ期募集不合格的人可以再报Ⅱ期募集，但全部书类要重新提交。Ⅰ期合格者能否再报、是否限制与其他研究科并愿，要项没有写。
- 外国人与出口管理：研究科按安全保障出口管理的规定审查对外国人留学生的教育研究内容，可能受限，出願前要和准备接收的指导教员商量。从国外来考、办签证需要「受験許可証」的，可以用邮件向大学院入試担当申请。
- 入学手续（Ⅰ期、Ⅱ期合格者共通）：网上手续 2027/1/22（周五）10:00–2/12（周五）23:59，书类邮寄 2027/2/5（周五）–2/12（周五），国内邮戳有效、国外必达；缴入学费用、录入必要事项、邮寄书类三项全部完成才有效，逾期丧失入学资格。
- 学费：2027年度入学者的金额未定；参考 2026年度：在籍基本料 70,000 日元、授業料 1,510,000 日元、其他费用 2,600 日元，初年度合计 1,582,600 日元，可分春、秋两学期缴纳。没有另列入学金。

- 考场规则：受験票不邮寄，自己用白色 A4 纸竖向打印带去。桌上只能放受験票、黑色铅笔或自动铅笔、黑或蓝色笔、橡皮、卷笔刀、没有附加功能的手表、眼镜、口罩；手机等电子设备关机收进包里，不能用耳塞。筆記試験开考后 30 分钟内可以入场，不延长时间；面接迟到不能应考。
