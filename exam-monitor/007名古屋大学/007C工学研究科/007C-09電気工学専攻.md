## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 一般選抜：英语不设笔试，用 TOEFL iBT（含 Home Edition）或 TOEIC Listening & Reading 公开考试的成绩判定，成绩单贴在指定的「スコアシート提出用紙」上随出願书类一起寄出。
- TOEIC：只收公式认定证原件（Official Score Certificate）；数字版公式认定证自行打印后按原件处理。
- TOEFL：需要两样——由 ETS 直送大学的 Institutional／Official Score Report（Institution Code D377，Department Code 69「Engineering, other」），以及 Test Taker Score Report 的复印件。直送成绩要在出願期间最后一天（一般選抜为 2026/7/3）之前到达大学，寄送要 6–8 周。只采用 Test Date Scores，不采用 MyBest。
- 有效期：只承认 2024/6/1 以后实施的考试成绩。不受理 TOEFL ITP 和 TOEIC IP（团体考试）。交上去的成绩单不退还。
- 没交成绩也可以出願和参加考试，但英语不计分。
- 笔试免除者选拔：電気工学·電子工学·情報·通信工学 3専攻出願时不用交英语成绩。没有获得免除而转入一般選抜的人，要在 2026/7/29（周三）17:00 前补交成绩单（TOEIC 限 2026/5/31 以前实施的那几回；TOEFL 要 2026/7/3 以前发行的 Test Taker Score Report，直送成绩 7/29 17:00 前到达）（已截止）。
- 配点与换算：募集要项和専攻补充资料都没有写英语的配点、最低分和换算方法。
- 外国人留学生入试：同样用 TOEFL iBT 或 TOEIC L&R 判定，有效期同为 2024/6/1 以后；成绩单缺失或无效时英语按 0 分计，但仍可应考。

### 日本語要件
- 8月入试（笔试免除者选拔、一般選抜）：募集要项没有要求提交日语成绩，没有 JLPT／EJU 门槛。笔试和口頭試問都用日语进行。
- 外国人留学生入试：専攻页没有要求必须提交日语成绩，考过日语能力考试的人可以把合格通知或成绩单复印件作为参考资料附上（不是门槛），实际日语能力在口頭試問中判定。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：電気工学専攻 34 名（電気工学 34 名、電子工学 47 名、情報·通信工学 33 名；工学研究科合计 603 名）。这是笔试免除者选拔和一般選抜的合计，免除名额的具体人数没有公布。外国人留学生入试的募集人员为「若干名」。

- 笔试免除者选拔的对象是学业成绩优秀、对志望専攻的学习有高度意欲的人，要项没有写具体的 GPA 或名次线。没有获得免除的人自动转入一般選抜，不用重新出願或重新缴费。
- 志望専攻与研究室：出願书类和网上出願里都没有填志望研究室的地方。一般選抜考生把専攻页上的「配属研究室希望調書」（2026/7/1 公开）事先填好志望顺序，在笔试第一天开考前上交；笔试免除希望者在「学修希望調書（筆記試験免除希望者用）」里写第一志望専攻和希望的研究室。
- 研究室配属规则：合格的同时决定配属。优先按第1希望配属，超过研究室可接收人数时按入试成绩依次调到第2希望以后；校外考生中的成绩上位合格者另行处理，尽量配到所希望的研究室。
- 出願书类（一般選抜）：志願票、工学研究科博士前期課程入学志願票、写真票、学修希望調書、TOEFL／TOEIC スコアシート、回信用信封、类型该当性自我申告书、在留卡复印件或住民票（外国籍）、成绩证明书、毕业（预定）证明书等。笔试免除者选拔另加能说明出身大学毕业要件和 GPA 算法的资料。
- 出願方式：先在网上出願系统（e-apply）登记并缴检定料，再把书类用挂号寄到工学研究科教務課入学試験係；国内以邮戳为准，海外须在截止日寄到。

- 入学料 282,000 日元，授業料全年 535,800 日元（均为预定额）。
- 外国人留学生入试的规定：出願前必须先联系志望的指导教员；部分研究室不接收留学生，専攻页要求留出充足时间。研究生（非正规生）是另一条路线：外国籍（区分3）走工学研究科国际交流室的页面，4月入学的出願在前一年9月初、10月入学在2月中旬，这不是修士入试的要求。
