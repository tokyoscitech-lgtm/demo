## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各轮次相同：不另设英语笔试，用外部成绩换算「英語」得分（100分）。建築学系·総合芸術系只收 TOEIC L&R 或 TOEFL iBT；I-AUD 另可交 IELTS（Academic Module，交 Test Report Form 复印件）。
- 换算：TOEIC L&R 730＝满分、230＝0分；TOEFL iBT 2026/1/20 以前受检的 80＝满分、25＝0分，2026/1/21 以后受检的（1–6分制）4.5＝满分、2＝0分；中间按比例换算。
- TOEFL iBT：由 ETS 直送（DI Code 5132，本専攻 Department Code 12），并在出願书类チェックリスト上写 Appointment number 和直送手续日；Home Edition、MyBest、本人收到的 Test Taker Score Report 不受理。TOEIC L&R：交纸质 Official Score Certificate 原件，或日本国内受检（2024年4月以后）带 QR 码的数字认定证打印件。
- 成绩须为出願截止日前2年以内受检，且必须在出願期间内送到；没送到、或成绩上的姓名等与志願者信息不一致、没有照片的，英语按0分处理。
- I-AUD 和総合芸術系志愿者中，学士课程全部用英语授课并取得学位的，可凭出身大学的证明免交外部成绩。
- 变更点：2027年度Ⅰ·Ⅱ期起不再接受考试当天提交成绩；総合芸術系改为提交外部英语成绩。

#### 日本語要件
- 要项没有要求提交日语成绩。建築学系·総合芸術系用日语授课；総合芸術系外国人留学生入学試験的小论文可选英文试题（在A票科目栏写「小論文（英文）」）。I-AUD 为英语授课，口头试问用英语进行。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 建築学系：基礎科目·専門科目（200分） | 「建築学全般」出题 | 9:00–11:00，120分钟 |
| 総合芸術系：小論文（100分） | 外国人留学生可选日文或英文试题 | 9:00–10:30，90分钟 |
| 国際建築都市デザイン系 | 不考笔试；A方式只有英语口头试问，B方式只审书类（作品集等） |  |

- 各系都按笔试或小论文、外部英语成绩、口头试问和书类选考综合判定（I-AUD 无笔试，B方式无口头试问）；一般、外国人留学生、社会人特别入试选拔方法相同。
- 建築学系2026年度Ⅰ期试题（官方公开）：基礎科目为8个建筑用语说明（如プレーリー·スタイル、DPG構法、アルゴリズミック·デザイン、15分都市），全部作答；専門科目出12题，选3题作答。

### 口述試験 / 面接
- **官方形式**：建築学系·総合芸術系·I-AUD A方式都在考试当天下午进行口头试问，开始时刻随受験票通知，迟到不能受验；総合芸術系作品创作志愿者可出示作品集（投影须自带 HDMI 转接头）；I-AUD A方式用英语，可带展板或模型补充说明作品集；I-AUD B方式没有口头试问。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：80名（建築学系、国際建築都市デザイン系、総合芸術系三个系及学内選考、Ⅰ期、Ⅱ期等年度内全部入试合计）。
- 出願资格：大学毕业（含2027/3/31预计）或外国16年学校教育等；外国人留学生入学試験要求非日本国籍、初中等教育全部在外国修完，在日者须能取得「留学」等在留资格；需个别资格审查的人须先申请（Ⅰ期 2026/4/15、Ⅱ期 10/15 必达、I-AUD Ⅱ期 8/21 必达，均已截止，非独立出願）；I-AUD 外国人留学生分A方式（在日本住民登录居住者，或在外国但难以取得2封推荐书者，来校受验）和B方式（住在国外、难以来日受验并能取得2封推荐书者，只审书类）。
- 要提前准备的书类：研究计划书（所定用纸A4 1页以内，写入学后的研究计划和将来去向）、外部英语成绩；外国籍者（本学理工学部·研究科出身者和特别永住者除外）另交出身大学指导教员等的推荐书1份（I-AUD 须2名不同推荐人各1份）（格式自由，日文或英文）和経費支弁計画書；中国（港澳台除外）的大学毕业者须申请 CHSI 学位和成绩认证并由 CHSI 直送 sst@mics.meiji.ac.jp；建築学系和 I-AUD 另交指導教員希望調査票（各系所定样式）；I-AUD 另交作品集（A4 或 Letter 尺寸1册，小组作品注明本人负责部分，不退还）并在最后一页贴由指导教员等非亲属签名的作品集证明书，他校出身者尽量附科目シラバス。
- 出願：只收邮寄（角2号信封贴所定封面，速達·簡易書留，国内邮戳有效；海外用 EMS 等，最后一天必达），不收窗口和网上出願；检定料 35,000 日元（金融机构窗口电汇、便利店、信用卡·银联或海外汇款；I-AUD B方式 15,000 日元；Ⅱ期缴纳期间 建築学系·総合芸術系 2026/10/1–12/4、I-AUD 9/21–10/9）。
- 并愿：I-AUD 的A方式和B方式不能并愿（海外在住者可改报A方式）；2027年度募集要项没有说明跨系、跨专攻并愿和Ⅰ期合格者再报Ⅱ期的规则。
- 咨询：明治大学理工学部事務室 大学院入試係，〒214-8571 神奈川県川崎市多摩区東三田1-1-1，Tel 044-934-7600，Fax 044-934-7901，sst@mics.meiji.ac.jp（平日 9:00–11:30、12:30–16:30，周六 9:00–12:00；8/1–9/19 时间不同）。
