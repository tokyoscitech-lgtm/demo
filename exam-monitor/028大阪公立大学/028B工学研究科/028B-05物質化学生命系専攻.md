## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 外国人留学生特別選抜不另设英语笔试，用外部成绩评价（第1次·第2次相同）：交 TOEIC L&R 公开测试公式认定证（数字版打印须能用 QR 码验真，海外受检者交纸质原件）、TOEFL iBT Test Taker Score Report（ETS 账户下载的 PDF 打印件，只用 Test Date Score 0–120 分，不用 1–6 分段和 MyBest，不接受 ETS 直送）或 IELTS Academic Test Report Form 原件三者之一。
- 有效期：第1次募集 2024/6/1 以后受检；第2次募集 2024/12/1 以后受检。IP 等团体考试和居家考试的成绩不受理。
- 出願时或考试当天开考前提交均可；出願时交不了的附「スコア未提出申出書」，当天仍未交的按科目缺考，不列入合否判定；当天有更好的成绩可以替换。
- 参考：2028年度春入学起原则上出願时提交，不能当天替换，TOEIC·TOEFL·IELTS 每种各可交1份。

#### 日本語要件
- 要项没有要求提交日语成绩。英文版要项写明考试可用日语或英语参加。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 応用化学分野：専門科目１ | 分析化学、无机化学、物理化学 | 9:30–12:00，150分钟 |
| 応用化学分野：専門科目２ | 有机化学、高分子化学 | 13:30–16:00，150分钟 |
| 化学工学分野：専門科目１ | 数学（微积分、常·偏微分方程）、物理化学（化学热力学）、移动速度论（流动、热移动、物质移动） | 9:30–12:30，180分钟 |
| 化学工学分野：専門科目２ | 扩散分离工学（蒸馏、吸收、萃取）、反应工学（反应速度、均相反应器）、粉体工学（粒子性状与运动、填充层、过滤） | 13:30–16:30，180分钟 |
| マテリアル工学分野：専門科目１ | 物质量子论、物质的结构、无机化学、物理化学 | 10:30–12:30，120分钟 |
| マテリアル工学分野：専門科目２ | 材料物理学、材料化学、材料组织·强度学中选2科（出願时申报） | 13:30–16:30，180分钟 |
| 化学バイオ工学分野：専門科目１ | 「无机化学·有机化学」或「分子生物学·细胞生物学」二选一（出願时申报） | 10:00–12:00，120分钟 |
| 化学バイオ工学分野：専門科目２ | 「物理化学」或「生化学·生物工学」二选一（出願时申报） | 13:30–15:30，120分钟 |

- 按笔试、口述、英语外部成绩和出願书类综合判定；包括英语在内缺任何一科都不列入合否判定。
- 可能根据出願书类免除笔试，免除者只考口述（开始时刻可能另行通知，可能以远程中继方式实施）。
- 第1次·第2次科目和时间相同；遇自然灾害等，第2次募集的预备日为 2027/2/7–2/8。
- 化学工学分野可带无编程功能的电池式函数计算器；化学バイオ工学分野専門科目２由考场借出函数计算器。

### 口述試験 / 面接
- **官方形式**：各轮次相同，考生1人对多名教员：応用化学·化学工学·マテリアル工学分野就志望的专门领域进行；化学バイオ工学分野就化学或生物化学进行。

### 出願資格 / 定員
- 募集人员：入学定员145名（応用化学·化学工学·マテリアル工学·化学バイオ工学4分野合计，出願时在入学願書上填写志望分野）；外国人留学生特別選抜第1次·第2次募集若干名，2026年度秋入学若干名。
