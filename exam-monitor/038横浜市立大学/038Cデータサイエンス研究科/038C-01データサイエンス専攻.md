## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 不另设英语笔试，用外部成绩评价：出願时提交 TOEIC（L&R、IP）、TOEFL（iBT、ITP）、IELTS（Academic）之一的成绩证明原件，换算为100分；只认2024/4/1以后受检的成绩。
- 换算基准：TOEFL iBT 61＝TOEIC 600＝IELTS 5.0（各部分4.5以上）＝本校换算65分；持有多份成绩的全部提交，取换算后最高的一份。
- TOEIC 交 Official Score Certificate/Report（2023年4月以后的数字认定证打印带 QR 码的 PDF）；TOEIC IP 在线版须另交「受験状況に関する証明書」（本校所定样式）。
- TOEFL 由 ETS 直送 Official Score Report（代码 0416），另交注明直送申请日期的 Test Taker Score Report 打印件；IELTS 由实施机构直送 Test Report Form，另交成绩单复印件或在线成绩打印件并注明申请日期。
- 出願截止后原则上不受理补交成绩原件。

#### 日本語要件
- 要项没有要求提交日语成绩。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 数学（基礎的数学）（100分） | 线性代数1题、微积分1题 |  |
| 统计検定成绩（100分） | 不另考，以统计検定2级的得分为判定分；准1级或1级「统计数理」合格者按100分计 |  |

- 总分：数学100＋统计検定100＋英语100＋面试200＝500分，综合判定合否。
- 统计検定2级成绩是必交出願书类：CBT 方式交试验结果报告原件，旧方式的结果证明书须直送大学；准1级·1级合格者交合格证原件、合格证明书或オープンバッジ。
- 官方「基礎的数学」サンプル問題：微积分（麦克劳林展开、二阶偏导数、用极坐标变换计算二重积分）＋线性代数（逆矩阵、行列式、特征值与特征向量、矩阵的幂）。

### 口述試験 / 面接
- **官方形式**：第1期有面试（200分），与笔试同日在金沢八景キャンパス进行，集合时刻出願后通知、迟到不能受验；不分文理，综合判断获得高度数据科学能力的能力和意欲。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：第1期一般选拔16名；社会人特别选拔若干名；第2期本年度不实施。
- 出願资格：要项把对象写为日本国籍、永住者及其他准此者，并满足大学毕业（含2027/3/31前预计）、外国16年学校教育、外国3年以上课程取得学士相当学位等ア–ク之一；ク（个别资格审查）须事先审查（非独立出願）；原则上不受理海外地址出願，受験票和合格通知的寄送地址须在日本国内；社会人特别选拔的外国籍考生限永住者。
- 要提前准备的书类：统计検定2级成绩（或准1级·1级合格证明）原件、英语成绩原件（直送须提前手配）、志望理由书（写志望本校和指导教员的理由及研究抱负，A4 1–2页，格式自由）；外国籍考生另交在留卡正反面复印件和护照照片页复印件（海外居住者只交护照复印件）。
- 出願：用官网下载的願書（A4白纸打印、黑色圆珠笔填写），在便利店缴检定料30,000日元（手续费自付），书类用簡易書留邮寄到アドミッションズセンター，邮戳有效；没有网上出願，窗口不受理。
