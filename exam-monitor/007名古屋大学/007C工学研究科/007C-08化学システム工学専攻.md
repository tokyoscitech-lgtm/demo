## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 一般選抜：英语不设笔试，用 TOEFL iBT（含 Home Edition）或 TOEIC Listening & Reading 公开考试的成绩判定，成绩单贴在指定的提交用纸上随出願书类一起寄出。
- TOEIC：只收公式认定证原件（Official Score Certificate）；一般選抜最晚可用 2026/5/31 以前实施的那一回。
- TOEFL：需要两样——由 ETS 直送大学的 Institutional／Official Score Report（Institution Code D377，Department Code 69），以及 Test Taker Score Report 的复印件。直送成绩要在出願期间最后一天（一般選抜为 2026/7/3）之前到达大学，寄送要 6–8 周。
- 有效期：只承认 2024/6/1 以后实施的考试成绩。不受理 TOEFL ITP 和 TOEIC IP（团体考试）。
- 没交成绩也可以出願和应考，但英语不予评价。
- 笔试免除者选拔：マテリアル工学系的免除希望者出願时也要交英语成绩（只有電気電子情報工学系3専攻免交）；没有获得免除而转入一般選抜的人，可以在 2026/7/29（周三）17:00 前重新提交成绩单（已截止）。
- 配点与换算：募集要项和专攻页都没有写英语的配点和换算方法，也没有最低分。
- 外国人留学生入试：专攻募集案内页写明 11 月的留学生入试英语全部用 TOEFL 或 TOEIC 的成绩评价，成绩单随出願书类提交。2025年度的留学生要项里本専攻还是考英语笔试，这一点以 2027年度留学生要项为准。

### 日本語要件
- 8月入试（笔试免除者选拔、一般選抜）：募集要项没有要求提交日语成绩，没有 JLPT／EJU 门槛。募集要项写明笔试和口頭試問都用日语进行，不提供英语出题。
- 外国人留学生入试：2025年度的留学生募集要项原则上要求提交日语教师等出具的「日本語能力証明書」，或 JLPT、JPT 的成绩（复印件可），本校工学部毕业预定者和本研究科研究生免交；专业科目笔试为日英两种语言出题。2027年度是否相同未核实。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 一般選抜：基礎部門（180分钟，配点官方未公布） | 数学和物理化学两科全部作答。数学：微分积分、常微分方程、线性代数、矢量分析（公开的 2025年度试题为 4 个大题，各对应一个领域）。物理化学：热力学基本定律与热力学量、相平衡（含相图）、化学平衡（含氧化还原） | 2027募集要项／过去问 |
| 一般選抜：専門部門（120分钟，配点官方未公布） | 4 个领域各出 1 题，选 2 题作答。固体物理学：晶体结构、X 射线衍射、薛定谔方程、声子、比热与热传导、电子结构与物性。流动与传热：流变学、流动的基本方程、管内流动、传热、总传热、热交换。反应工学：化学反应速度论、各类反应器、伴随物质移动的非均相反应、固体催化反应。材料力学：组合应力、梁的弯曲、应力与应变、位错与滑移变形、金属的强化机制 | 2027募集要项 |
| 笔试免除者选拔 | 没有笔试；书类选考后面接 | 2027募集要项 |
| 外国人留学生入试：专业科目笔试 | 2027年度的科目与范围未获取到 | 参考：2025年度外国人留学生募集要项 |

- 合否判定：募集要项和专攻页都没有公布各部门的配点、总分和判定公式。材料デザイン工学、物質プロセス工学、化学システム工学 3専攻用同一套试题，出願时必须给系内 3専攻全部排上第1–第3志望顺序。
- 专攻公开的「入試問題例」（非真题全套）：数学以极限、导数、重积分、回转体体积、参数表示的微分等计算题为主；固体物理学有晶体结构与填充率、Drude 模型的电导、化学键分类、一维晶格的运动方程、X 射线衍射（消光规律、密勒指数、晶格常数），计算推导之外还有说明题和选择·对应题。
- 作答只能用黑色铅笔或自动铅笔；计算器、词典、智能手表等可穿戴设备除专攻另有指示外不能使用（研究科要项的共通规定）。
- 变更点：2022年实施的专攻入试案内里専門部門是 90 分钟，2027年度要项为 9:00–11:00 的 120 分钟；科目和选答规则没有变。笔试免除者选拔是从令和7年度入试（2024年实施）起新设的。
- 题目倾向（体验记，非官方）：没有找到マテリアル工学系考生写的体验记。

### 口述試験 / 面接
- **官方形式**：一般選抜在笔试之后有口頭試問，2027年度入试为 2026/8/20（周四），集合时间和地点 7/31 以后在工学研究科网站或专攻案内公布；用日语进行。配点和提问内容官方没有公布；工学研究科公开的往年资料（令和6年度）写的是现场进行、每人约 3–10 分钟。笔试免除者选拔是书类选考加面接（2026/7/18），口頭試問的通知随面接结果一起寄出，免除者也要参加8月的口頭試問。外国人留学生入试也有口頭試問。
