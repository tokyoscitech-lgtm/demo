## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 建築学系·総合芸術系（Ⅰ期、Ⅱ期相同）：不设英语笔试，提交 TOEIC L&R 或 TOEFL iBT 的成绩，换算成「英语」的得分；要项没有写明英语一科在总分里占多少分。
- 换算方法：TOEIC L&R 730 分以上按满分、230 分以下按 0 分；TOEFL iBT 2026/1/20 以前受检的 80 分按满分、25 分以下按 0 分，2026/1/21 以后受检的（新分制）4.5 按满分、2 以下按 0 分；中间按比例换算。
- 国際建築都市デザイン系：可交 TOEIC L&R、TOEFL iBT 或 IELTS（Academic Module）三种之一，按分数计分而不是合否制；要项只给出 TOEIC 和 TOEFL 的换算表，没有公布 IELTS 的换算方法和最低分。
- TOEIC 提交 Official Score Certificate 原件或数字认定证的打印件；TOEFL iBT 必须由 ETS 直送，机构代码 5132，本専攻 Department Code 为 12；复印件和非官方成绩单无效。
- 有效期：以出願截止日为基准，过去 2 年以内受检的成绩有效。姓名、出生日期与出願信息不一致或成绩单上没有本人照片的，英语按 0 分处理。
- 不受理：TOEFL iBT Home Edition、MyBest スコア；建築学系·総合芸術系不能用 IELTS。
- 成绩必须在出願期间内送到；赶不上的，英语按 0 分处理。
- 免除：国際建築都市デザイン系和総合芸術系的志愿者，如果学士课程全部用英语授课并取得学位，可凭毕业学校出具的证明免交外部成绩；建築学系没有这一免除规定。
- 变更点：英语考试内容变更通知把総合芸術系列为从 2026 年度秋季·2027 年度Ⅰ期起改为提交外部成绩（TOEIC L&R 或 TOEFL iBT）的対象（研究科样题页注明総合芸術系的英语试题不公开，过去该系有自己的英语考试）；考试当天提交成绩的做法已废止。

### 日本語要件
- 要项没有要求提交日语成绩（JLPT、日本留学試験等都没有提及）。建築学系和総合芸術系的笔试、小论文、口头试问在生田キャンパス当面进行；総合芸術系的小论文可以选择用日文或英文写（用英文的须在 A 票上写明「小論文（英文）」）。国際建築都市デザイン系是英语授课项目（English Track），口头试问用英语进行，英文要项也没有日语要求；推荐书可用日文或英文。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 建築学系：基礎科目·専門科目（200分，120分钟，9:00–11:00） | 出题范围为「建築学全般」，要项没有细分计划·结构·环境等领域，也没有公布题数和是否选答；没有设计制图考试。Ⅰ期、Ⅱ期相同 | 2027募集要项 |
| 総合芸術系：小論文（100分，90分钟，9:00–10:30） | 题目和范围官方未公布，サンプル問題也不公开；可用日文或英文作答 | 2027募集要项 |
| 国際建築都市デザイン系 | 不考笔试；A 方式只考英语口头试问（100分），B 方式只做书类选考 | 2027募集要项／I-AUD Application Guideline |

- 合否判定：建築学系为笔试（200分）、外部英语成绩、口头试问（100分）加书类选考；総合芸術系为小论文（100分）、外部英语成绩、口头试问（100分）加书类选考；国際建築都市デザイン系 A 方式为英语口头试问（100分）、外部英语成绩、作品集等书类，B 方式只审书类。要项没有公布英语的满分和合格最低分。
- 社会人特別入学試験、外国人留学生入学試験（A 方式）的选拔方法与一般入学試験相同，没有免考笔试的规定。
- 题目倾向（体验记，非官方）：没有找到本専攻任何一个系的考生体验记；建築学系可参考 Web 公开的 2026年度Ⅰ期·Ⅱ期试题与解答、窗口阅览的过去 3 年试题和サンプル問題。

### 口述試験 / 面接
- **官方形式**：三个系的口头试问都是 100 分，在笔试当天下午进行（Ⅰ期 2026/7/18 已结束；Ⅱ期 2027/2/22），开始时刻见随受験票寄来的通知，迟到就不能受验。建築学系：要项没有写时长和提问内容。総合芸術系：修士研究里包含作品创作的人可以在口头试问时展示作品集，用电脑投影的要自带 HDMI 转接头。国際建築都市デザイン系 A 方式：用英语进行，可以带展板或模型补充作品集；B 方式没有口头试问。
- **実際に聞かれた内容**：没有找到本専攻的体验记（截至 2026-10-17）。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：博士前期課程 建築・都市学専攻入学定员 80 名，是建築学系、国際建築都市デザイン系、総合芸術系三个系以及本年度全部入试（学内選考、Ⅰ期、Ⅱ期）的合计；要项没有给出各系、各轮次的人数。
- 入试区分：一般入学試験、社会人特別入学試験、外国人留学生入学試験在Ⅰ期和Ⅱ期都实施。外国人留学生入学試験的 A 方式（来校受验）和 B 方式（渡日前方式，只审书类）之分只设在国際建築都市デザイン系，A·B 两方式不能并愿。飛び入学試験本専攻没有。学内選考（出願 2026/6/1–6/3，考试 7/4 口头试问，已结束）面向明治大学理工学部 4 年级学生；総合芸術系允许其他学部的学生凭指导教员推荐书出願学内選考。
- 出願资格（一般）：大学毕业或 2027/3/31 前预计毕业、取得学士学位、在外国完成 16 年学校教育等 ①–⑨ 之一；⑧⑨ 须先受个别资格审查。社会人特別入学試験：满足一般资格，并且（ア）在职 2 年以上并能交所属长承诺书，或（イ）有 3 年以上在职经验、2027/3/31 前满 25 岁并能交指导教员推荐书和在职证明。外国人留学生入学試験：非日本国籍、在外国完成初等中等教育，并符合在外国完成 16 年课程、取得 3 年以上的学士相当学位、日本大学毕业（预定）或经个别审查（满 22 岁）之一。I-AUD 的 A 方式面向在日本住民登录居住的人，或住在国外但难以取得 2 封推荐书的人；B 方式面向住在国外、难以来日受验并能取得 2 封推荐书的人。
- 出願书类（共通）：志願票·受験票（A 票）、振込連絡票（B 票）、入学志願書、研究計画書（规定用纸 A4 1 页以内，写入学后的研究计划和毕业后去向）、毕业（预定）证明书、成绩证明书、外部英语成绩、出願书类チェックリスト（I-AUD 用另一份）、照片（3 个月以内，4cm×3cm 彩色）。外国籍（明治大学理工学部出身者和特别永住者除外）另交护照复印件、在留卡复印件（在日者）、経費支弁計画書和推荐书（一般 1 封；I-AUD B 方式 2 封，来自不同推荐人；格式自由，日文或英文）。
- 各系附加书类：建築学系和国際建築都市デザイン系须交「指導教員希望調査票」（两系格式不同）；国際建築都市デザイン系须交作品集（A4 或 Letter 尺寸 1 册，页数和横竖不限，含小组作品的要写明本人负责部分，不退还）并在最后一页贴上由指导教员、推荐人等非家属签名的作品集证明书，必要时附履修科目的教学大纲；総合芸術系不要求事先提交作品集。
- 出願方式：只收邮寄，用角 2 号信封贴规定封面，以速達·簡易書留寄到理工学部事務室，国内为截止日邮戳有效；海外用 EMS 等，须最后一天必达。用纸从募集要项页（I-AUD 从英文入试页）下载，用黑色圆珠笔或电脑填写（不能用 Microsoft Edge 填写）。中国的学校毕业者须让 CHSI（学信网）把电子认证报告直送明治大学。
- 检定料 35,000 日元；国際建築都市デザイン系外国人留学生 B 方式为 15,000 日元。可在金融机构窗口电汇（现金，ゆうちょ银行不可）、便利店、信用卡·中国决济或海外汇款缴纳；原则上不退还。Ⅱ期缴纳期间：建築学系·総合芸術系 2026/10/1–12/4；国際建築都市デザイン系 2026/9/21–10/9（已截止）。
- 并愿、Ⅰ期合格者能否再报Ⅱ期：要项没有记载；只写明 I-AUD 的 A 方式和 B 方式不能并愿。
- 个别出願资格审查（必达）：Ⅰ期 2026/4/15（周三）（已过）；Ⅱ期 建築学系·総合芸術系 2026/10/15（周四）（已过）；Ⅱ期 国際建築都市デザイン系 2026/8/21（周五）（已过）。审查结束前不要缴检定料。
- 入学手续：2027/1/14（周四）–3/10（周三），在 UCARO 登录、在金融机构窗口汇款、邮寄书类，只能一次性缴纳；入学手続の手引预定 2026/12/18 在明治大学入試総合サイト公布。
- 学费（2027年度入学者用）：建築学系·総合芸術系与其他理工系専攻相同，入学金 200,000 日元（明治大学学部毕业生减半）、授業料 760,000 日元、教育充実料 140,000 日元、実験実習料 70,000 日元、諸会費 3,000 日元，第 1 年合计 1,173,000 日元；国際建築都市デザイン系在学费一览里单列一栏，实验实习料与其他系不同，但学费 PDF 文字层的列对齐有错位，两次读取得到的金额不一致（第 1 年合计读到 1,061,000 或 1,243,000 日元），以入学手続の手引为准。
