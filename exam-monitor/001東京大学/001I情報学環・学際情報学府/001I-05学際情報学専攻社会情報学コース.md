## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 须提交外部英语成绩，从 TOEFL iBT（含 Home Edition）、TOEIC L&R、IELTS Academic（含 Computer Delivered）三种里选一种，只能选一种；学府不自己出英语题。
- TOEFL iBT：由 ETS 直送官方成绩，Institution Code 0440、Department Code 99，出願时填写 Appointment Number；以前送过的也要重新申请寄送，冬季案内写明考生自留的 Test Taker Score Report 不受理。
- TOEIC L&R：上传 Official Score Certificate 的电子版或扫描 PDF。IELTS：上传 Test Report Form 扫描件，也可由日本英語検定協会直送。
- 不受理的种类：TOEFL ITP、TOEIC 的 S&W／Bridge／IP 团体考试、IELTS General Training。
- 有效期：夏季募集为 2024/9/1 以后受检；冬季募集为 2025/1/1 以后受检；都要在出願截止前取得。
- 原则上随出願一起提交。赶不上的须事先联系学府，夏季最迟 2026/7/24（周五）正午（已过），冬季最迟 2027/1/5（周二）正午到达。
- 配点和换算方法、最低分数线：官方未记载。

### 日本語要件
- 非日本大学毕业（或预计毕业）的外国人必须上传「日本語学力証明書」，原则上用入试案内所附的样式；用其他样式时须包含听、说、读、写四项的评价和评价方法。
- 没有规定必须提交 JLPT 等检定成绩或最低等级。但夏季笔试用日语作答，口述的问答也用日语进行，实际上需要能用日语写论述和答辩的水平。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 夏季募集：专门科目 | 考查与媒体、传播、社会信息有关的研究能力，以及法学、政治学、经济学、社会学、媒体·新闻研究、社会心理学等人文社会科学的知识；用日语作答。题数、时间、配点官方未记载 | 2027 夏季入试案内 |
| 冬季募集：无笔试 | 一次选考只看英语成绩和书类；须提交毕业论文（可交草稿）或同等的研究论文，日文或英文 | 2027 冬季入试案内 |

- 变更点：本コース从 2027 年度夏季募集起恢复一次选考的专门科目笔试，同时取消原来出願书类里的小论文（2025/6/27 官方予告）。因此 2021–2026 年度没有可参考的笔试题，能看的是 2020 年度以前的过去问，新形式的题型是否沿用旧形式官方未说明。
- 夏季的选拔流程：一次选考＝笔试＋英语成绩＋书类；二次选考＝线上口述，与一次的结果综合判定。
- 社会人特别选考枠（仅夏季）：笔试和英语与一般选拔相同，另交志望理由书。

### 口述試験 / 面接
- **官方形式**：线上进行，仅一次选考合格者参加，需要带摄像头并能联网的电脑。先做 7 分钟以内的发表，再用日语问答，考查基础与专门学力、研究能力和研究计划；案内写明可能就笔试专门科目的内容提问。社会人特别选考枠还会问社会经验和志望动机。
- **実際に聞かれた内容**：未获取到体验记（本次检索额度用尽，未能搜索），没有可归纳的一手记录。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员为夏季和冬季合计 16 名（人数为目安，可能增减）；専攻全体 100 名（含アジア情報社会コース 13 名）。冬季不设社会人特别选考枠。
- 出願资格：大学毕业或 2027 年 3 月前预计毕业等 (1)–(6) 项之一。资格(6)须事先个别审查：夏季书类 2026/6/1 必达（已过）；冬季 2026/10/16（周五）前書留寄出，结果 2026/11/16（周一）邮寄通知。
- 社会人特别选考枠（夏季）：满足出願资格且入学时社会经验累计 3 年以上；另交志望理由书（A4，相当于 400 字稿纸 15–20 张），写明工作·活动内容与学府学术内容的关系。
- 出願书类：入学願書、履历事项、学部 4 年的成绩证明书（含教养课程；研究生院毕业者也要交学部的，转学者加交转学前的）、毕业（预计）证明书、研究计划书、指導教員希望調査書、自己推薦書（有信息学相关业绩的填写业绩页面 URL）、英语成绩证明、检定料缴纳证明；冬季另交毕业论文等。本コース不需要推薦書。证明和论文原则上用日文或英文。
- 出願全部在指定网站上填写和上传。同一期募集内不能同时报多个コース，也不能同时报修士和博士。夏季不合格者能否再报冬季，要项没有明文限制，冬季要项也没有写夏季合格者的处理，需向学府确认。
- 检定料 30,000 日元（银行转账、便利店、Pay-easy、信用卡，手续费自付）；入学料 282,000 日元、授業料 年 535,800 日元（前期 267,900 日元），均为预定额。国费留学生免缴。
- 咨询：学際情報学府事務部学務チーム，〒113-0033 東京都文京区本郷7-3-1，Tel 03-5841-8769／8768，gakumu@iii.u-tokyo.ac.jp。

### 研究室 / 指導教員
- 事前連絡要否：不要。要项没有要求。募集要项和コース入试案内都没有写出願前必须联系教员，也没有写是否建议联系。
- 指導教員希望調査書只能从本コース的「学生受入教員」名单里选；指导教员在入学后正式决定，会尊重调查书的内容。
- 2027 年度学生受入教员（夏季、冬季案内相同，共 12 人）：李美淑（准教授）、大庭幸治（教授）、開沼博（准教授）、北田暁大（教授）、酒井麻千子（准教授）、澁谷遊野（准教授）、関谷直也（教授）、高木聡一郎（教授）、丹羽美之（教授）、三谷武司（准教授）、安本真也（講師）、山口いつ子（教授）。各人的研究领域见学府网站的教员页。
