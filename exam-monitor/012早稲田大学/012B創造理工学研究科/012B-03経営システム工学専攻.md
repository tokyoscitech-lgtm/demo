## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 不另设英语笔试，外部英语成绩是出願资格（一般入试、特別選考相同），须达到其一：TOEIC L&R 550、TOEFL iBT 57（或スコアバンド 3.5）、IELTS Academic 5.5；成绩不达标出願无效。
- 有效期：出願开始日前2年以内受检。
- TOEIC 交公式认定证（日本国内受检交数字认定证打印件，团体代码 00019702）；TOEFL iBT 由 ETS 直送（DI code 2874）并附 Test Taker Score Report；IELTS 电子送达研究科并附 Test Report Form。
- 不受理：TOEIC IP・S&W・Bridge，TOEFL ITP・PBT・Home Edition・Paper Edition・My Best scores，IELTS General Training・Online・One Skill Retake。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 笔试、面接原则上用日语进行。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 数理基礎（占总分2/5） | 微积分、线性代数、统计三个领域，全部必答 | 10:00–13:00，两科合计180分钟 |
| 経営システム工学（占总分3/5） | 7个分野各出1题，任选2题，其中1题须是第一志望研究指导所属分野 | |
| 　情報数理応用 | 机器学习（监督/无监督、聚类、强化学习、深度学习、自然语言处理、数据挖掘）、统计推断与贝叶斯统计、离散数学基础（进制、布尔代数、逻辑电路）、信息论（熵、压缩、纠错码） | |
| 　統計数理工学 | 实验设计（一元/二元/多元配置、乱块法、分割法、正交表、枝分实验）、多元分析（回归、判别、主成分、聚类、因子分析、数量化理论）、数理统计（概率分布、估计量与检定） | |
| 　システム論 | 系统思考与系统方法、系统建模、输入输出模型、状态迁移模型、合理决策过程、博弈论初步 | |
| 　経営数理工学 | 线性规划（单纯形法、对偶性、建模）、网络规划（最短路、最大流、运输问题）、整数规划（分枝限定法、建模） | |
| 　計画数理学 | 排队论、仿真、AHP、DEA、日程计划、库存管理、金融工学 | |
| 　生産システム工学 | 生产管理、作业研究（动作·时间研究）、库存·物流管理（定期/定量订货、MRP、供应链）、生产系统论（流水线、丰田生产、单元生产）、生产计划（调度、派工规则、进化计算） | |
| 　ソフトウェア工学 | 需求定义与设计、软件开发过程与管理、软件建模、过程建模、软件验证与确认 | |

- 合否按书类审查、笔试、面接综合判定。
- 特別選考（社会人・奨学生）以面接为主，可能事先通知后加考笔试。

### 口述試験 / 面接
- **官方形式**：一般入试：笔试次日面接选考（含口述试验），原则上用日语；特別選考：面接，社会人另有针对出願书类的口述试验，原则在西早稲田校区（教员判断可改线上），缺席即不合格。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：55名（一般入试4月入学，含其他入试名额）；9月入学若干名；特別選考（社会人・奨学生）另设名额。
- 出願资格：大学毕业（含预计）或外国16年学校教育等，并须满足英语成绩基准；只能报1个専攻，出願时须定好第一志望研究指导（决定笔试必答分野）；特別選考社会人须毕业后2年以上实务经验且出願时在职，奨学生须已获研究科认可、相当于在学期间学费总额的奖学金。
- 要提前准备的书类：志願票①（志望动机・研究计划，日语，A4 1页）；中国大陆毕业者须由 CSSD 直送学历·学位（在读者为学籍）Online Verification Report；特別選考另需所定样式推薦状（密封）、奨学生交奖学金受给证明原件。
- 出願：网上申请表＋检定料＋书类邮寄，三项在期限内完成，书类必达；检定料 30,000 日元。
