## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 一般入试（夏期·冬期共通）：用 TOEIC 或 TOEFL 的成绩评价英语能力，没有英语笔试。要项没有写最低分、换算方法和配点。
- 可用的成绩：TOEIC Listening & Reading（公開テスト或 IP テスト都可以，TOEIC IP オンライン不可）；公開テスト只受理デジタル公式認定証的打印件。TOEFL iBT（Home Edition 不可）和 TOEFL ITP 都可以。
- TOEFL iBT 必须由 ETS 直送大学，生命科学研究科的 Institution Code 是 **G381**（与理学研究科等用的 G277 不同）；用 My TOEFL Home 下载的 PDF 打印件也可以，但同样必须直送。
- 成绩须是出願截止日前2年以内考的，出願时提交原件；只能交1份，不退还，交了之后不能换。
- 推薦入学：要项只写书类审查和面接，没有要求英语成绩的记载这次没能确认，联系事務室时一并确认。
- 外国人留学生入试：只受理 TOEFL iBT（会场受験，Home Edition 和 ITP 不可）和 TOEIC L&R 公開テスト（IP 不可），成绩须是第二次選考出願截止日前2年以内考的；口頭試問还会考查用英语或日语交流的能力。
- 变更点：外国人留学生入试从2027年度起不再受理 TOEFL ITP 和 TOEIC IP（大学 2026/4/6 通知）；一般入试仍受理 IP 和 ITP。

### 日本語要件
- 一般入试：要项没有要求提交日语成绩（没有提到 JLPT 或日本留学試験）。出願书类用大学的日文所定用纸；试题和作答语言要项没有写明。
- 外国人留学生入试：修士課程志愿者须提交大学所定用纸的「日本語能力認定書」（由日语教师等填写），要项没有规定 JLPT 等级或分数；口頭試問和面接用日语或英语进行。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 夏期日程·冬期日程：専門科目「生命科学」（配点官方未公布，60分钟） | 考生命科学的基础知识和考察力，范围是分子細胞生物学、免疫学、遺伝学、生化学；题数和是否选答要项没有写 | 2027修士一般入试募集要项 |
| 推薦入学：无笔试 | 书类审查和面接 | 2027推薦·社会人特別選抜募集要项 |
| 外国人留学生入试第二次選考：无笔试 | 以生命科学的口頭試問考查专业知识（配点、时长官方未公布） | 2027外国人留学生入试募集要项 |

- 一般入试由专门科目、TOEIC/TOEFL 成绩和面接构成，夏期和冬期考法相同。要项没有公布各项配点、总分和合否判定方法。
- 出题范围与生命医科学研究所的研究方向（免疫、癌生物学、细胞运命等）一致，免疫学的比重值得重视。
- 题目倾向（体验记，非官方）：用日文和中文检索过，没有找到本研究科的受験体验记，无法归纳。

### 口述試験 / 面接
- **官方形式**：一般入试夏期·冬期都是在专门科目同一天 12:30 起面接，要项写的是“面接”而不是口頭試問；配点、时长、内容要项没有写。推薦入学只有面接（2026/7/4 10:00 起）。外国人留学生入试第二次選考有生命科学的口頭試問和面接，用日语或英语。
- **実際に聞かれた内容**：没有找到本研究科的体验记（日文和中文来源都查过），暂无可归纳的内容。

### 出願資格 / 定員
- 募集人员：生命科学専攻入学定員 15名（野田キャンパス生命医科学研究所）；一般入试夏期日程 15名（要项写法，含学内選考等名额）、冬期日程 若干名；他大学等からの推薦入学为定员15名中的若干名；外国人留学生入试若干名。
- 出願资格：大学毕业或 2027年3月前预计毕业、在外国完成16年学校教育等，符合要项所列任一项即可；大学3年级在籍成绩优秀者（飞级）这一资格本年度不适用于生命科学研究科。
- 出願书类（一般入试）：入学願書（所定用纸，贴照片）、成绩证明书原件、毕业（预定）证明书原件、履历书、志望理由書（所定用纸）、TOEIC/TOEFL 成绩单原件、寄受験票用明信片；住在日本国外的人另交「国外居住者用事前相談シート」，须请希望的指導教員填写。

- 检定料：一般入试 35,000 日元，银行窗口（電信扱，ATM 和网银不可）或便利店（セブン-イレブン、ローソン、ファミリーマート、ミニストップ，先在网上申请再到收银台付）缴纳，最后一天网上申请到 23:00、店头终端操作到 23:30，另收手续费，缴后不退。外国人留学生入试分两次缴：第一次選考 18,000 日元，第二次選考 17,000 日元。
- 并愿：笔试日期不同的専攻之间可以并愿。
- 社会人特別選抜：本専攻不实施（该选拔只设在薬学、工学、創域理工学（国際火災科学専攻）研究科）。
- 外国人留学生入试的出願资格：外国籍、没有在日本受过4年大学本科教育、能取得「留学」在留资格等，在日本读本科的留学生只能走一般入试。
- 学费（2027年度入学，生命科学研究科修士）：入学金 200,000 日元，授業料 年 960,000 日元，教育充実費 年 200,000 日元，学生傷害共済補償費 2,740 日元；第一年合计 1,362,740 日元（入学手续时缴 782,740 日元），第二年 1,162,740 日元，两年合计 2,525,480 日元。
