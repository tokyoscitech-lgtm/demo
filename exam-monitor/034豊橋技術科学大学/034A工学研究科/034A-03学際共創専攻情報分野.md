## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各轮次相同：不另设英语笔试，出願时全员提交外部英语成绩，计入综合判定：TOEIC L&R 公开考试（带照片的 Official Score Certificate 原件或数字公式认定证打印件）、TOEFL iBT（向 ETS 办理让大学在线确认，DI-CODE 9381）、IELTS（由实施机构在出願截止前把纸质 Test Report Form 直接寄到大学）三选一。
- 有效期：第1次募集收2024/7/1以后受检的成绩；第2次募集和外国人留学生入试收2024/12/1以后受检的成绩。提交的成绩证明不退还。

#### 日本語要件
- 一般入试（学力検査方式）：要项没有要求提交日语成绩。
- 外国人留学生入试：必须提交日语考试成绩证明原件，从 JLPT（成绩证明书）、J.TEST 実用日本語検定、BJT ビジネス日本語能力テスト、JPET 日本語能力評価試験、JPT 日本語能力試験 中任选一种；没有指定等级，成绩计入综合判定。
- 官方公开的过去问只有日文版。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 基礎科目 | 数学（解析学、代数学、確率論）及び情報；过去问为3道大题全部必答（数学1、概率1、情報1）；外国人留学生入试范围相同 | 10:30–12:00，90分钟 |
| 専門科目 | 不设笔试，以已修专门科目的口述试验代替 |  |

- 一般入试按学力检查、英语成绩、面接、成绩证明书等综合判定；外国人留学生入试另加日语成绩。
- 考场禁止使用计算器（含带计算功能的手表）。
- 官方过去问归纳：2027年度第1次——二次曲线（偏微分、梯度、特征值与对角化）、循环赛胜负的概率与期望、C语言哈希表程序阅读与计算量；2026年度第1次——特征值·对角化与联立微分方程、条件概率·期望方差·概率密度、C语言二叉搜索树；2026年度第2次——矩阵解二阶微分方程、三个骰子的概率·期望·方差、倒水操作的算法题。出题意图强调基础概念和算法·数据结构。

### 口述試験 / 面接
- **官方形式**：第1次募集、第2次募集：笔试当天13:00起，就已修专门科目进行口述试验，加个人面接；外国人留学生入试：形式相同，在豊橋技術科学大学校内进行。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：100名（情報・知能工学専攻＝情報分野，含書類選考方式、学力検査方式、社会人、外国人留学生、高専専攻科推薦全部区分）；第2次募集各区分若干名；外国人留学生入试情報分野若干名。
- 出願资格：大学毕业（含2027年3月预计）或外国16年学校教育等；个别入学资格审查（一般第2次 10/27–11/2、外国人留学生 10/27–11/4）已截止；外国人留学生入试须持有或能取得不妨碍入学的在留资格；書類選考方式只面向本校毕业生；外国人留学生要经安全保障出口管理审查。
- 要提前准备的书类：外部英语成绩（IELTS 须提前2个月以上申请寄送）；外国人留学生入试另需出身大学的推荐书（在职者由所属长出具）、日语成绩证明原件、学歴記入票；中国的大学毕业或在读者另交学信网英文版学历电子注册备案表或在线学籍验证报告（提交时在线验证有效期剩1个月以上）。
- 出願：先在 Web 出願系统登记并缴费，再把书类用簡易書留·速達寄到教務課入試室，或在指定窗口日亲自提交，期间内必达；检定料 30,000 日元（便利店、Pay-easy、网银、信用卡；海外只能用信用卡），国费留学生内定者免缴。
