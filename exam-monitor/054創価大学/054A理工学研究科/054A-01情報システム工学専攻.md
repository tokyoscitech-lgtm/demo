## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 一般选抜Ⅰ·Ⅱ期：必须提交过去4年内最高分的 TOEIC 成绩（原件），以此代替原来的学内英语题；要项没有最低分和换算方法。
- 变更点：2027年度入试起改为提交 TOEIC；2026年度以前本専攻考英语笔试（过去问页有 2023–2025 年度的英语试题）。
- 要项只写 TOEIC，TOEFL 和 IELTS 不在要项列出的范围内，不能代替。
- 外国人学生入试：只有书类审查和口述试验；英语能力证明书（成绩单或英语授课学历证明）"有则提交"，不是本専攻的必交项（必须在日语或英语证明二选一的是环境共生工学専攻，不适用于本専攻）。

### 日本語要件
- 一般选抜和外国人学生入试都没有要求提交日语成绩，持有日语能力考试合格证明者可在入学願書填写并提交原件（任意）。
- 外国人学生入试的书类须用日语或英语制作，其他语言的证明书须附日译或英译。要项没有写口述试验的语言。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 専門（配点官方未公布，45分钟） | 希望研究室的专门分野；EMaT（工学系数学统一试验）45分以上者可提交成绩代替笔试，提交 EMaT 者不能再参加専門笔试 | 2027募集要项 |
| 英语：不考笔试 | 提交过去4年内最高分的 TOEIC 成绩 | 2027募集要项 |
| 一般选抜Ⅱ期：専門（45分钟）＋口述 | 与Ⅰ期相同（専門分野笔试或 EMaT 代替，TOEIC 提交） | 2027募集要项 |

- 一般选抜按笔试（含语言能力评价）、口述试验和出願书类综合判断，达到合格基准六成以上者合格。外国人学生入试按书类审查和口述试验，同样以六成为基准。
- 考场只能带笔记用具，计算用电卓由考场出借；不能带有通信功能的设备。
- 题目倾向（据官方过去问）：2024年度Ⅱ期的専門在电磁学、信号理论、人工智能、计算机网络论、代数学5科中只答1科，45分钟。没有找到体验记。

### 口述試験 / 面接
- **官方形式**：一般选抜Ⅰ·Ⅱ期的口述试验就研究课题和计划提问，时间考前通过 TAO 通知；外国人学生入试只有书类审查和口述试验，在创价大学校内实施，可选线下或线上，日期按时差决定、约考前2周通知。配点官方未公布。
- **実際に聞かれた内容**：没有找到本専攻的体验记。

## 📝 详细信息
### 出願資格 / 定員
- 一般选抜的募集人员为10名程度（Ⅰ·Ⅱ期合计，未分轮次）；外国人学生入试为若干名。
- 出願资格（一般）：大学毕业或 2027年3月底前预计毕业、学位授与机构授予学士、在外国完成16年学校教育等(1)–(3)；(4)–(9)（外国通信教育、专修学校、大学在学3年以上成绩优秀、个别资格审查22岁以上等）须先申请出願资格认定：Ⅰ期 2026/5/8–5/29，Ⅱ期 2026/10/2–10/23，Ⅱ期结果12月下旬通知。
- 外国人学生入试：非日本国籍等，大学毕业或外国16年学校教育等；中国3年制大学的学位不被认可。
- 出願书类（一般）：入学願書［A票］（贴照片转 PDF）、志望理由及入学后希望的研究［B票］、成绩证明书（校外出身者用本校调查书［C票］，由出身大学厳封）、毕业（预计）证明书、JLPT 合格证（有者）、TOEIC 成绩原件、EMaT 成绩（代替専門笔试者）、毕业研究概要［D票］、经费支办书（外国人）、合格通知送付地址；外国人学生入试另需推荐书2份［E票］和指导教员受入承诺书［F票］。
- 出願方式：在 WEB 出願系统（TAO）注册账号后上传书类并付款；需要原件的证明书邮寄（截止日邮戳有效）或送理工学部事务室窗口。海外留学中等原因原件可后补，须在截止前联系 eng-grad@soka.ac.jp。
- 检定料 33,000 日元，在 TAO 上支付，手续费自负；已交书类和检定料原则上不退。
- 外国人学生入试只能报1个専攻，不能并愿；受理后书类内容不能修改。
- 外国人须证明1年的生活费和学费（约每月16万日元×12个月）；经费不足可能导致 COE 不交付而不能入学。
- 学费（2026年度参考额）：入学金 200,000 日元（本校学部毕业生等 100,000 日元），授业料 790,000 日元，实习费 110,000 日元，合计 1,100,000 日元，可分两期。一般选抜Ⅰ期合格者第1次手续 2026/10/1–10/22 交入学金，第2次手续 2027/2/16–2/26；Ⅱ期合格者 2027/2/16–2/26 一次办理。
- 奖学金：理工学研究科特待生（学内选考春季成绩上位者，共40万日元）；牧口奖学金（大学院生，20万日元一次，学内选考春季优先）；牧口奖学金（留学生，年60万日元，最多2年，须在外国人学生入试出願时申请，最多9名）。各奖学金不能并给。
- 研究生·科目等履修生是另外的路线，不是修士入试的要求。
- 需要考试照顾者在出願时联系；咨询：创价大学理工学部事务室大学院系（〒192-8577 东京都八王子市丹木町1-236），Tel 042-691-9400，eng-grad@soka.ac.jp。
