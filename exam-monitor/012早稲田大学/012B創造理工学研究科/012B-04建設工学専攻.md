## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 7月入试：英语不单独考试，外部考试成绩是出願资格之一。需达到以下任一项：TOEIC L&R 550 以上；TOEFL iBT 57 以上（新评分方式为スコアバンド 3.5 以上）；IELTS Academic 5.5 以上（Overall）。本専攻没有另外加码的英语要求。
- 有效期：出願开始日（2026/5/25）的2年前以后受检的成绩。
- 提交方式：TOEIC 交公式认定证（日本国内受检的交数字公式认定证 PDF 的打印件），申请代码 00019702；TOEFL iBT 由 ETS 直送（Institution code 2874）并提交 Test Taker Score Report；IELTS 由考试机构直送成绩数据并提交 Test Report Form。
- 不受理：TOEIC IP、TOEIC S&W、TOEIC Bridge；TOEFL iBT Home Edition、My Best scores、TOEFL ITP；IELTS Online、One Skill Retake、General Training。
- 提交的成绩不符合资格要求时出願无效。要项没有写英语成绩是否换算进总分。
- 飛び級入試的英语基准只有先進理工学研究科更高，不适用于本専攻。

### 日本語要件
- 要项没有要求提交 JLPT 等日语成绩。
- 选考（笔试和面接）原则上用日语进行；要项和問題一覧都没有写可以用英语作答。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：本専攻 70名（要项注明这个数字包含推薦入試等其他入试的名额）。要项的表格里这70名对应的是4月入学还是全年合计，本次读取没能分辨；同研究科其他専攻的写法是4月入学为具体人数、9月入学为若干名。飛び級入試一栏未能核实。
- 出願资格：大学毕业或预计毕业、学位授与机构授予学士学位、在外国完成16年学校教育、外国大学3年以上课程毕业、文部科学大臣指定者、个别审查认定且入学前满22岁——以上之一，并且同时满足英语外部考试的基准。
- 只能报1个専攻；本専攻不设第2志望（第2志望只适用于物理学及応用物理学専攻第1志望、共同原子力専攻第2志望的人）。笔试必须选1个志望部门对应的科目，所以出願时要确定志望的研究指导和所属部门。
- 出願书类：志願票①（志望动机、研究计划等，自己作成，A4 单面1页）、志願票③（写真票，选择检定料支付方式）、毕业（预计）证明书、成绩证明书、英语外部考试成绩、チェックリスト；外国籍者另交护照复印件，在日本居住的交在留卡，在国外居住的交 COE 交付申请书、经费支付书和存款余额证明；中国大陆的大学毕业者另需学历·成绩的 Online Verification Report。要项里没有只针对本専攻的额外书类。
- 出願方式：网上申请表登记＋缴检定料＋书类邮寄，三项都要在期间内完成。书类寄到：〒169-8555 東京都新宿区大久保3-4-1 西早稲田キャンパス51号館1階 早稲田大学理工センター入試・広報オフィス；国内用簡易書留，海外用 DHL 等可追踪的方式。
- 检定料 30,000 日元。日本国内在便利店支付，国外用信用卡。国籍或居住地属于特定的最贫国·低收入国的人可以申请免除。
- 受験票在7月上旬用邮件发送，自己打印带到考场；忘带或遗失时带公的身份证到51号館1階的入試・広報オフィス补发。考试当天正门附近施工，要从明治門（55号館一侧）或西門（63号館一侧）进校。
- 外国人留学生的教育研究内容要接受安全保障出口管理的审查，可能受限制。国外居住的外国籍合格者完成入学手续后由大学代办 COE；菲律宾、越南、印尼、尼泊尔、缅甸、中国籍者申请 COE 时需要结核非发病证明书。
- 需要考试或修学上照顾的人，出願前先联系研究科。
- 入学手续：9月入学为学费等缴纳和手续信息登记 2026/8/1–8/5，书类提交 8/1–9/4；4月入学为学费等缴纳 2026年10月前后–2027/2/18，手续信息登记 2027/2/1–2/18，书类提交 2/1–2/26。
- 入学金·学费（2027年度入学者，本専攻）：入学金 300,000 日元（只有其他大学出身者缴，早稲田出身者免除）；授業料每学期 495,500 日元，実験演習料每学期 47,000 日元，学生健康増進互助会費每学期 1,500 日元。第1年度合计：其他大学出身者 1,388,000 日元，早稲田出身者 1,088,000 日元。学费表的排版读取时有错位，各栏是按合计金额对出来的，缴费时以官方表为准。
- 科目等履修生（非学位）是另一条路线，冬季另有募集。这不是修士入试的要求，也不是修士的冬季募集。
- 咨询：早稲田大学理工センター入試・広報オフィス（西早稲田キャンパス51号館1階），fsegraduate@list.waseda.jp，Tel 03-5286-3808。
- 没有成绩开示制度的记载；要项写明不回答有关合否理由的询问。
