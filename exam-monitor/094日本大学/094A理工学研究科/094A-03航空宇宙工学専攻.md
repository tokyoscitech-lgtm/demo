## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般第1期·第2期：
  - 研究科共通的外国語（英語）笔试，60分钟，配点官方未公布。
  - 可在出願时任意提交 TOEIC L&R 或 TOEIC L&R-IP 成绩（原件或复印件），与本研究科英语考试的得分比较，取高者作为外国語成绩；这不是免考制度，提交了也要参加英语考试。换算按研究科规定，官方未公布换算式。
  - 成绩须为从入学考试日起算3年以内受检；数字公式认定证必须打印后提交，PDF 不受理。TOEFL、IELTS 等其他考试不在比较对象之列。
- 一般第3期、社会人入试、外国人留学生入试：不另设英语笔试，也不要求提交外部英语成绩。

#### 日本語要件
- 一般入试要项没有要求提交日语成绩。
- 外国人留学生入试：全学要项对理工学研究科不采用日本留学试验，也没有要求提交 JLPT 等日语成绩；网上出願时须填写日语·英语的学习经历。
- 笔试和口述以日语进行，要项没有写其他作答语言。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：博士前期课程入学定员25名（全入试区分合计，官方未按期拆分）；社会人入试若干名。
- 出願资格：大学毕业或2027/3/31前预计毕业、在外国完成16年学校教育、在外国取得相当于学士的学位（3年以上课程）等10项之一；以“预计”报考但到期未取得资格的不准入学。
- 个别出願资格认定：资格（10）须事先申请，一般第2期截止 2026/6/15 邮戳有效（已过），第3期的截止日随第3期要项公布；资格（9）须事先向理工学部入試事務室咨询。外国人留学生需要资格审查的，全学截止 2026/9/30（已过）。
- 出願方式（一般·社会人）：先在大学院入试Web出願系统登录志愿信息并上传照片，再把书类以简易书留邮寄（截止日邮戳有效）；只做 Web 登录或只寄书类都不算完成出願。准考证和考试案内在考试日前5天起从系统下载打印。
- 出願书类（一般）：入学志愿票（所定）、毕业（预定）证明书、成绩证明书、TOEIC 成绩（任意）、出願确认票（所定）、外国学校出身者用出願资格确认票（资格3·4·6者）、事前連絡確認書原件（外国人留学生，由指导预定教员交付）。社会人另交履历书等。
- 外国人留学生入试：网上出願登录从 2026/7/17 起，截止日 16:00 前完成登录且书类必达；毕业证明和成绩证明须交原件，日文或英文以外的要附公证翻译。
- 检定料 35,000 日元，汇款到三菱UFJ银行神保町支店 普通 0049691「ニホンダイガクリコウガクブ」，汇款人名前加入试区分代码；手续费自付，只有未提交书类或出願不受理时退还。
- 入学手续：一般第1期 7/29、第2期 9/30 截止（可选两段式，第2次截止 2027/1/29）；外国人留学生 2027/1/7（周四）截止（两段式第2次截止 2027/3/25）；第3期 2027/3/11–3/25；办完手续后辞退须在 2027/3/31（周三）17:00 前电话告知。
- 初年度学费：学外者 1,370,000 日元、本校出身者 1,170,000 日元（入学金 200,000 仅学外者；授業料 375,000、施設設備資金 150,000、実験実習料 40,000 为每学期额，另有后援会费·校友会费）。理工学研究科对自费留学生有按经济状况和修得学分减免授業料20%的制度（2027年度预定）。
