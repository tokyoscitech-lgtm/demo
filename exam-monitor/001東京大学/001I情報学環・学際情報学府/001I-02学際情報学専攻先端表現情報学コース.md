## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 须提交外部英语成绩，不另设英语笔试，用外部成绩评价；出願时在 TOEFL iBT（Home Edition 可）的官方 Score Report、TOEIC L&R 的公式认定证、IELTS Academic（机考可）的官方成绩证明三种里选一种。
- 不受理：TOEFL ITP、TOEFL 的 Test Taker Score Report（考生本人版）、TOEIC IP 的个人成绩表和 S&W、Speaking、Writing、Bridge、IELTS General Training。
- 有效期：2024/9/1 以后到出願受付结束（2026/7/10）之间受检的成绩。
- TOEFL：由 ETS 直送学府（Institution Code 0440，Department Code 99），原则上 2026/7/24（周五）前到达，以学府在线收到数据为准；出願时填 Appointment Number；以前寄过的也要重新申请送分。
- TOEIC：出願时上传 Official Score Certificate（数字版或扫描 PDF）。IELTS：出願时上传 Test Report Form 扫描件，或由英检协会管辖办公室直接寄到学府（2026/7/24 必达）。来不及在出願期间提交的，须事先联系，并在 2026/7/24（周五）正午前用邮件提交。
- 配点、最低分和换算方法，コース入学試験案内没有记载。

#### 日本語要件
- 要项没有要求 JLPT 等成绩。外国人（日本的大学毕业或预计毕业者除外）须提交「日本語学力証明書」，原则上用案内所附样式，由日语教员或相当的人就说、听、写、读四项评价；用其他样式时须写明四项评价及评价方法。
- 提交书类原则上用日文或英文。口述试验使用的语言，案内没有记载。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 一次选考：书类选考（配点官方未公布） | 英语成绩证明＋提交书类（研究計画書、自己推薦書、推薦書、成绩证明书、指導教員希望調査書；特別選考枠另加ポートフォリオ） | 2027夏季募集要项／コース入学試験案内 |
| 専門科目（不另设笔试，是口述可能试问的范围） | 一般选考：数学共通问题（线性代数、微分积分、微分方程式）＋情报相关选择问题（电子情報学／机械情報学／都市工学／社会基盤学，或人間・環境／歴史・文化／メディア・コミュニケーション等领域的基础学力）；特別選考枠：只看选择问题领域，不涉及数学共通问题 | コース入学試験案内 |

- 共通要项注3写明只有社会情報学、総合分析情報学、生物統計情報学三个コース实施笔试；コース入学試验案内写明一次选考按英语成绩证明和书类判定，并说明口述时可能就案内“筆記試験（専門科目）”栏的内容试问。因此本コース没有笔试，案内里的専門科目栏是口述可能问到的基础学力范围。
- 一次选考合格者进入二次选考（口述），最终结果与一次选考合并综合判定；配点、合格最低分官方未公布。
- 特別選考枠：占募集人员的三分之一左右以内，面向在媒体技术相关的设计、艺术表现领域有突出活动实绩或高度专业性的人（媒体艺术、媒体设计、产品设计、信息设计、娱乐内容、都市·防灾设计、教育内容等）。ポートフォリオ用 PDF 上传，书式自由；多人合作的作品最好说明本人的贡献；视频或网页 URL 只作参考，评价以 PDF 内容为准，URL 要保持可访问到二次选考的合格发表为止。

### 口述試験 / 面接
- **官方形式**：夏季：线上会议系统远程实施，需要能联网、带摄像头的电脑；本人用画面共享发表修士阶段的研究计划和以往研究实绩（特別選考枠还要讲ポートフォリオ），说明时间10分钟以内，之后可能试问基础和专门学力（含案内専門科目栏的内容）；只有一次选考合格者参加。
- **実際に聞かれた内容**：没有找到可核实的体验记。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：夏季28名（其中特別選考枠三分之一左右以内）；冬季不募集。学際情報学専攻全体100名（含另行募集的アジア情報社会コース13名），各コース人数是目安，录取人数可能达不到募集人员。
- 出願资格：日本的大学毕业或 2027/3/31 前毕业预定、在外国完成16年学校教育、在外国取得相当于学士的学位（3年以上课程）等(1)–(6)之一。按(6)个别入学资格审查出願的，须在 2026/6/1（周一）前用书留邮寄履历书、成绩证明书、教育设施资料等（当日邮戳有效，已截止）；大学3年级在读、2027/3/31 前不能毕业的人不能报。
- 出願书类：网上入学願書·履历事项；学部4年（含教养课程）的成绩证明书（大学院修了者也交学部的；编入学者加交编入前的）；毕业（预定）证明书；检定料缴纳证明；研究計画書（所定样式）；自己推薦書（自评基础学力和专门能力，可写信息学相关实绩及其 URL）；指導教員希望調査書（所定样式）；推薦書（所定样式）；英语成绩证明；日本語学力証明書（对象者）；特別選考枠另交ポートフォリオ。研究計画書和自己推薦書的页数，案内没有记载。

- 只能选一个コース出願；同一时期不能同时报修士和博士。
- 检定料 30,000 日元（银行转账、便利店、Pay-easy、信用卡，手续费自付；日本政府奖学金留学生免缴）。
