## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各轮次都不另设英语笔试，用 TOEFL iBT 成绩评价；修士出願者全员提交，英语母语者也要交。
- 只收 TOEFL iBT 和 TOEFL iBT Home Edition 的 Official Score Report（ETS 直送）。MyBest scores 不采用，考生手里的 Test Taker Score Report 不受理，其他考试一律不收。
- 送分代码：University of Tokyo IS&T，Institution Code 8445，Division 选 Graduate Organization，Department Code 99；送到其他代码研究科查不到。出願时填写 Appointment Number 和受检日，只采用所填那一次，出願后原则上不能更换；成绩一般在受检约两周后研究科才能查到。
- 夏入试：受检日在 2024/9/1 以后、出願截止日以前，成绩数据须在 2026/6/30 前到达（已截止）。
- 冬入试：受检日在 2025/3/1 以后、出願截止日（2026/11/17）以前，成绩数据须在 **2026/12/8（周二）** 前到达研究科。
- 成绩未按期到达或不符合要求的视为无效，失去笔试和口述的受験资格；没有有效期内成绩却填写虚假受检日的，不受理或不合格。
- 官方没有规定最低分，换算方法和配点官方未公布。

#### 日本語要件
- 要项和専攻入试案内书都没有要求提交日语成绩，对外国人考生也没有日语门槛；研究科没有另设外国人留学生特别选拔。
- 研究科为需要的考生提供笔试科目的英文版试题，専攻另有英文版入试案内书；口述使用的语言案内书未写。研究科自 2026年4月起大部分课程用英语授课。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：夏入试 38 名（另可能从本研究科其他専攻的合格者中接收若干名）；冬入试修士的人数要项和専攻案内书都没有写。
- 出願资格：大学毕业或预计毕业、在外国完成16年学校教育、在外国取得相当于学士的学位（修业3年以上）等6项之一；冬入试的毕业基准日按 2027年10月入学相应顺延。个别入学资格审查（第6项）的申请截止：夏入试 2026/5/13（已截止）；冬入试 2026/10/26（周一）。

- 研究科共通书类：入学願書（系统内填写）、证件照（jpeg）、成绩证明书、毕业（预计）证明书、TOEFL 成绩、检定料缴纳证明、外国籍者等须上传的出口管制审查用检查表、推荐书（另行提交，冬入试 2026/11/24 23:59 截止）；日文或英文以外的证明须附译文；全部做成 PDF 上传，没有邮寄出願。
