## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各轮次都不另设英语笔试，用外部成绩评价：只收 TOEFL iBT 的 Test Taker Score Report 或 TOEIC L&R 公式认定证。
- 8月入试：配点 50 分，TOEFL＝0.5×分数，TOEIC＝0.5×（0.134×分数－32.66）。例如 TOEFL 90＝45 分，TOEIC 860＝42 分。
- 第2次募集：配点 60 分，TOEFL＝0.6×分数，TOEIC＝0.6×（0.134×分数－32.66）。例如 TOEFL 90＝54 分，TOEIC 860＝50 分。
- 共通：小数点以下进位；成绩须为出願截止日前2年以内受检；Home Edition 可以，TOEFL Essentials、ITP、TOEIC IP 和 IELTS 不受理；考过多次的只交1份；出願时没交的英语按 0 分，不接受考试当天补交。2027年度实施的入试为止 TOEFL 用 0–120 分计算。
- 变更点：2026年度8月入试本コース只收 TOEFL，2027年度起 TOEFL 和 TOEIC 都可以。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 8月入试：笔试题日英并记，可用日语或英语作答。
- 第2次募集：数学日语出题、可用日语或英语作答；口头试问的发表和回答可用日语或英语，用英语时另加评价日语沟通能力的提问；外国学历者持有日语能力考试一级或二级证书的，在志望说明书里注明，并在考试时带原件或复印件。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 8月入试：情報学基礎（100分） | 线性代数·微分积分 2题＋算法与数据结构 2题，4题全答 | 9:30–11:30，120分钟 |
| 8月入试：専門科目（100分） | 统计学、模式识别与机器学习、信息理论、信号处理各1题，选2题 | 12:30–14:30，120分钟 |
| 第2次募集：数学（200分） | 微积分、线性代数等；専門科目不实施 | 10:00–12:00，120分钟 |

- 8月入试总分 250（情報学基礎 100＋専門 100＋英语 50），按得分和各志望区分可接收人数决定合格者。
- 第2次募集：志願者多时先按出願书类做一次选拔；通过者按数学、英语、口头试问的得分和出願书类综合判定。
- 变更点：2026年2月的第2次募集是数学 100＋复变函数和概率统计（各50分）、没有口头试问；2027年2月起改为数学 200＋口头试问 200。
- 题目倾向（体验记，非官方）：8月入试与知能情報学コース同日同题；算法常出堆排序、二叉搜索树、最短路径、动态规划；専門多数人准备3科、当天挑2科。

### 口述試験 / 面接
- **官方形式**：8月入试没有口头试问；第2次募集：口头试问 200 分，先用幻灯片做约5分钟发表（志望动机、本科所学或研究经过、希望领域、研究抱负）再提问，发表资料做成 PDF，数学考完后用 USB 等提交并带1份纸质打印件，日语或英语均可。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：16名（8月入试）；第2次募集6名；2027年10月入学若干名。
- 出願资格：大学毕业（含预计）或外国16年学校教育等；资格10须事先审查（第2次募集 2026/12/7 17:00 必达，非独立出願）；外国大学毕业（含预计）者须在出願截止前完成 AAO 学历验证申请；只能报一个コース，第2次募集不能与10月入学并愿，8月入试合格者不能再报；志望区分按顺序填写、数量不限，没填的不分配。
- 要提前准备的书类：志望说明书（A4 2页以内，写研究实绩和入学后研究计划，做过毕业研究的写题目和内容，不得使用生成 AI，日语或英语）、TOEFL/TOEIC 成绩单；书类须为日语或英语，其他语言附译文。
- 出願：第2次募集只能通过 WEB 出願系统上传书类，纸质成绩证明须原件连同打印的入学願書以書留速達等寄送、期限内必达（8月入试为纸质邮寄或窗口提交）；检定料 30,000 日元＋决济手续费。
- 咨询：情報学研究科教務掛（総合研究8号館1階），jyoho-kyomu@mail2.adm.kyoto-u.ac.jp，Tel 075-753-4894／5500（平日 9:00–17:00，12:00–13:00 除外）。
- 并愿：只能报一个コース，第2次募集不能与10月入学并愿，8月入试合格者不能再报。
