## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 出願时提交 TOEFL iBT 或 TOEIC L&R 公开考试成绩，只认出願截止日前2年以内（2024/9/29 以后）受检的成绩，成绩计入综合判定。
- TOEFL iBT：①ETS 直送（DI 9501）＋Test Taker Score Report 打印复印件，或 ②Test Taker Score Report 原件（PDF 自行打印的不算原件）；用 Test Date 成绩，不用 MyBest；Home Edition、ITP 不受理。
- TOEIC L&R：交デジタル公式認定証复印件；所在国家·地区不发数字认定证的，由考试机构把公式認定証原件直接寄到研究科；IP、S&W、Speaking、Bridge 不受理。
- 出願时成绩必须已出；成绩单来不及的，出願期内先交理由书＋Web 成绩 PDF 打印件（TOEFL 须四项都已评分），并在 2026/10/7（周三）17:00 前必达补交指定成绩单，否则不能受験；提交后不能更换。

#### 日本語要件
- 要项没有要求提交日语成绩。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 基礎生物学 | 细胞和动物个体的基本构成，程度以 Essential Cell Biology 等代表性教科书为准；从多道设问中任选2题 | 10:00–11:40，与小論文合计100分钟 |
| 小論文 | 以生命科学为轴，考文理两方面的广泛教养及综合运用的逻辑思考，1题 | 同上 |

- 合否判定：学力检查、口頭試問、外部英语成绩、志望理由书、研究提案书和成绩证明综合判定；不得携带词典。
- 第一段階選抜：出願者超过约70名时，按出願书类选出约70名进入考试。
- 变更点：旧修士課程（2026年度入学，2025年8月实施）笔试为基礎生物学1题＋生物学（专门）2题；本课程改为基礎生物学选2题＋小論文1题，不再考生物学专门题，并新增第一段階選抜。

### 口述試験 / 面接
- **官方形式**：有口頭試問，在笔试当天下午进行，成绩计入综合判定。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：25名（2027年4月入学，仅一轮）；旧修士課程上次为20名。
- 出願资格：大学毕业（含2027/3预计）或外国16年学校教育、外国3年以上课程取得学士相当学位等1–10项之一；外国大学毕业、经 AAO 后需确认资格的，2026/8/25 17:00 前交出願資格確認チェックシート（非独立出願）；资格9·10须 8/31 17:00 前必达申请个别审查（非独立出願）；不能在职常勤入学，在职者须于 2027/3/31 前离职。
- 要提前准备的书类：志望理由书、研究提案书（均用所定用纸，可贴打印稿，不能另附纸）、志望指导教员签名或记名盖章的受入承諾書（可交复印件）、TOEFL iBT/TOEIC L&R 成绩；毕业·成绩证明须为英文或日文原件，只有电子版的须带可验证真伪的 URL。
- 出願：京都大学 WEB 出願系统登录（9/15 起开放入力；上传照片，渡日前外国人另传护照页）＋缴检定料 30,000 日元（信用卡/便利店/Pay-easy，另付手续费）＋书类装角2信封以简易书留速达寄送或窗口提交，期内必达。
