## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 夏季、冬季募集相同：不另设英语笔试，用外部成绩评价，TOEFL iBT（含 Home Edition）、TOEFL ITP、TOEIC L&R、TOEIC-IP（L&R，纸笔版）、IELTS Academic 选1种提交，换算成100分满分的外语得分。TOEIC-IP 线上版不受理；有 TOEFL-PBT 成绩的留学生须事先咨询教務学生係。
- 换算：TOEFL iBT＝50＋（分数－50）×5/3，上限100（按旧 0–120 总分计算）；ITP＝分数×0.34－108，上限100；TOEIC、TOEIC-IP＝分数÷10，上限80；IELTS 6.0以上＝100、5.5＝82、5.0＝68。例如 iBT 80＝100分，TOEIC 750＝75分。
- 换算后不足60分直接不合格，检定料不退。
- 有效期：考试日前2年以内受检（夏季为 2024/8/25 以后，冬季为 2025/1/5 以后）。
- 提交方式：iBT 须 ETS 直送的 Official/Institutional Score Report（Institution Code D377，Department Code 无对应时填99，只采用 Test Date 成绩、不用 MyBest）＋Test Taker Score Report 打印件，两者都要在出願期间内到达；ITP 交受験者用控え原件；TOEIC 交公式认定证原件（数字版交 PDF 打印件），原件不退还；IELTS 交 TRF 原件，eTRF 须复印件加考试中心直送原件。出願期后不受理，提交后不能更换。
- G30：IELTS Academic 6.0以上（可 One Skill Retake）、TOEFL iBT 旧制80以上或新制4.0以上（可 Home Edition、MyBest）、Duolingo 110以上，或成绩单写明 CEFR C1以上；本科以英语授课的交授课语言证明可免交成绩。须 2025年1月以后受检，TOEIC、TOEFL ITP 不受理；TOEFL 送分代码 7256。
- 变更点：2028年度入学（2027年8月实施）起，英语成绩设最低分——TOEFL iBT 58以上（新制3.5以上）、ITP 495以上、TOEIC/TOEIC-IP 600以上，低于最低分不能出願；仍换算成100分（TOEIC上限80）。

#### 日本語要件
- 夏季、冬季募集要项都没有要求提交日语成绩。夏季募集专门科目只出日文题；冬季一般募集要项没有英文出题的规定，口述语言要项未写明。
- 冬季募集案内页标明面向日本人，本専攻也不在外国人留学生募集（只招动物科学3室）之列，所以外国籍考生报本専攻实际只能走夏季募集或 G30。
- G30 是英语授课课程，要项没有日语要求。

### 口述試験 / 面接
- **官方形式**：夏季募集：第1次合格者参加，多名考官个别口述约20分钟，考查对志望研究领域的明确志向、热情、研究执行能力和基础知识，远方考生可申请线上；冬季募集：形式同夏季，只进行第1志望口述；G30：书类合格者参加，多名考官个别口述约30分钟，对面或线上（海外原则用 Zoom 等），考查研究志向、热情和研究执行能力。
