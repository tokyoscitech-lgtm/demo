## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各日程相同：不另设英语笔试，用 TOEFL iBT（含 Home Edition）成绩评价。
- 送分：向 ETS 申请把 Institutional (Official) Score Report 送到研究科（DI code 1113），其他代码无效；出願时在 WEB 出願系统里填写 Appointment Number、受检日和分数，不必交 Test Taker Score Report。
- 有效受检期间（向 ETS 申请送分也须在此期间内完成）：A日程 2024/8/1–2026/6/13（已过）；B日程 2025/2/1–2026/11/15。
- 送过多次的，出願时只指定一次。TOEFL ITP 不受理，MyBest Scores 不采用，其他英语成绩不能代替。
- 要项和専攻案内都没有规定最低分、换算方法和配点。B日程的书类审查把 TOEFL 成绩和成绩证明书、研究计划书、参考资料一起看。

#### 日本語要件
- A日程：外国籍考生须在出願时上传日本语能力试验（JLPT）的「認定結果及び成績に関する証明書」（带各得分区分的分数）PDF；没有规定必须达到的级别或分数。
- B日程：JLPT 成绩改为任意提交（有的可以在出願时上传）。
- 日本的大学毕业或预计毕业者、本研究科的外国人研究生，两个日程都不用交。研究科不设单独的外国人留学生特别选拔。
- A日程専門科目试题日英并记；能否用英语作答，入试案内没有写明。
- 变更点：2026/10/16 修订前的入试案内写的是 A、B 两日程都要交 JLPT 成绩，修订后 B日程改为任意提交。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：A日程（2027年4月入学）20名，B日程（2027年4月入学）若干名；本専攻不实施 10月入学。
- 出願资格：日本的大学毕业或 2027/3/31 前预计毕业；在外国完成 16 年学校教育；在外国取得相当于学士的学位（3 年以上课程）；学位授与機構授予学士学位；经个别入学资格审查认定且 2027/3/31 满 22 岁等。个别入学资格审查和受验照顾申请截止：A日程 2026/5/7、B日程 2026/10/7（均已过）。
- 研究科共通书类：入学願書（WEB 填写，含照片）、出身大学成绩证明书、毕业（预定）证明书、检定料缴纳证明、国费留学生证明书（仅国费生）、TOEFL 成绩；本校农学部毕业者和本研究科外国人研究生免交成绩·毕业证明书，原件在入学手续时提交。
- 専攻指定书类（A日程）：第1志望教员的受入承諾書（専攻指定用纸，PDF 上传）、外国籍考生的 JLPT 成绩证明。
- 専攻指定书类（B日程）：
  - 出願时上传：受入承諾書、入学后的研究计划书（指定用纸）；JLPT 成绩证明任意。
  - 2027/1/21（周四）–1/26（周二）按受験者心得指定的方法提交 PDF：毕业论文（或相当成果）的摘要（日文或英文）、毕业论文或相当成果、参考资料（论文、报告等）。
- 志望填写：在 WEB 出願系统里按「教員並びに専門分野一覧」选专门分野和指导教员，最多填到第3志望；第2、第3志望可以填同一分野的其他教员，没有可以不填。
- 出願方式：只能通过 WEB 出願系统；受験票自己用 A4 纸打印，考试当天带上。B日程受験者心得到 2027/1/13 还没收到的要联系教務課。
- 检定料 30,000 日元，银行汇款（邮储银行除外）、便利店、信用卡、Pay-easy 均可；缴纳期间 A日程 2026/4/13–6/23（已过），B日程 2026/10/5–11/25。国费留学生免缴；缴后不退。
- 并愿：同一日程只能报研究科的一个専攻。
- 入学料 282,000 日元，授業料 年 535,800 日元（前期 267,900 日元），均为预定额；国费留学生免缴。入学许可通知 2027年2月下旬，3月上旬办手续。
- 咨询：専攻入试担当池田 紘士 教授（Tel 03-5841-5217，hiroikeda@g.ecc.u-tokyo.ac.jp）；出願手续问农学生命科学研究科教務課学生支援チーム大学院学生担当（〒113-8657 東京都文京区弥生1-1-1，Tel 03-5841-5010，daigakuin.a@gs.mail.u-tokyo.ac.jp）。
