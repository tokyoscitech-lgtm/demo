## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般入学·社会人特別選抜（夏期·春期相同）：
  - 不另设英语笔试，用出願时提交的 TOEFL iBT、TOEIC L&R、TOEFL ITP 或 TOEIC L&R（IP）成绩换算成150分计入合否；交多种成绩的取换算后最高的一个。
  - 出願门槛：TOEIC L&R（含IP）299分以下、TOEFL iBT 29分以下（2026/1/20以前受检）或 band 2 以下（2026/1/21以后受检）、TOEFL ITP 400分以下的不能出願。
  - 只认2024年4月以后受检的成绩。TOEIC 交デジタル公式認定証打印件或带二维码的公式認定証原件，TOEIC IP 在线版不可用；TOEFL iBT 须交 Test Taker Score Report 打印件，同时让 ETS 把 Official Score Report 直送同志社大学（代码 7078），截止前缺一不受理，MyBest 不可用；ITP、TOEIC IP 交成绩证明原件。
  - 同一份成绩入学后用于修士学位的语学资格认定。
- 飛び入学：英语门槛写在出願资格里，不另计分。
- 外国人留学生入试：交语学能力证明原件，四选一——TOEIC L&R 或 TOEFL iBT（4月入学要求2024年4月以后、9月入学要求2024年10月以后受检；Home Edition 不认，TOEFL 须直送代码 7078）；日语能力证明（EJU「日本語」2025或2026年度，或 N1 的认定结果及成绩证明书原件）；大学教育用英语进行的证明；大学教育用日语进行的证明。没有最低分；学内进学者免交。

#### 日本語要件
- 一般入学·社会人特別選抜·飛び入学：要项没有要求提交日语成绩；2026年度細胞生物学过去问为日文出题。
- 外国人留学生入试：日语证明只是语学能力证明的选项之一（见英語要件）；小論文须用日语和英语作答，面接也用日语和英语进行。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 一般入学·飛び入学：専門基礎科目「細胞生物学」（150分） | 细胞生物学；2026年度过去问为2大题：细胞膜与线粒体能量代谢、分子马达，细胞周期调控、细胞骨架、凋亡通路；有选择、正误、填空、计算和简短论述 | 10:00–11:30，90分钟 |
| 社会人特別選抜：関係論文（300分） | 与专攻领域相关的论述 | 10:00–11:30，90分钟 |
| 外国人留学生入试：小論文 | 用日语和英语作答 | 10:00–11:30，90分钟 |

- 一般入学：細胞生物学150＋英语150（换算），加面接（含口頭試問）综合判定。
- 社会人特別選抜：関係論文300＋英语150（换算），加面接综合判定。
- 飛び入学：細胞生物学150加面接综合判定，英语不计分。
- 外国人留学生入试：国内居住的正规学生按出願书类、小論文和面接综合判定；国外居住者只能报特别学生，书类选考。
- 専門基礎科目免除（只限夏期一般入学）：同志社大学医生命システム学科、同志社大学其他学部及同志社女子大学的应届毕业生中人物·成绩优秀者可申请；免除者想申请入学后的奖学金仍须考細胞生物学，分数不用于合否。

### 口述試験 / 面接
- **官方形式**：一般入学·社会人特別選抜·飛び入学：笔试当天 13:00 起面接，含口頭試問，问出願书类所写事项和专攻领域相关知识；外国人留学生入试（正规学生）：小論文当天 13:00 起面接（含口頭試問），用日语和英语进行，本専攻不设远程面接。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：夏期一般入学20名；夏期·春期社会人特別選抜各若干名；春期一般入学若干名；春期飛び入学若干名；外国人留学生入试（4月入学、9月入学）正规学生·特别学生各若干名。
- 出願资格：大学毕业（含2027年3月预计）或外国16年学校教育等，并满足英语门槛；外国3年制学士等须先做资格认定（春期 2026/11/26–12/4 必达，12/17 寄出结果，非独立出願）；社会人特別選抜须在研究·医疗机构或企业作为正式职员从事研究开发1年以上并有所属长推荐；飛び入学须在学满3年、修完3年次必修、取得毕业学分90%以上、所修科目五分之四以上为A（90分）以上，并有 TOEIC L&R（含IP，在线版除外）750分以上；外国人留学生入试限外国籍，正规学生只收日本国内居住者，需资格认定的9月入学者须在2026/11/25前联系研究科事務室（已过）。
- 要提前准备的书类：研究概要（所定用纸，2页以内单面）、志望研究室調査票（第1–3希望）、英语成绩（TOEFL iBT 须安排直送）；社会人另需所属长推荐书和職務経歴書；外国人留学生入试另需推荐信（所定样式，推荐人密封）、研究計画書（日文或英文，A4横写12号字，2页以内）、与第1志望教员往来的邮件。
- 出願：一般入学·社会人·飛び入学用纸质願書（志願票随纸质要项发放，不能下载），簡易書留速達邮寄（邮戳有效）或窗口提交，检定料35,000日元（金融机构電信扱或便利店，邮储银行和ATM不可）；外国人留学生入试先在网上出願系统登记再寄书类，检定料正规学生15,000日元、特别学生10,000日元。
- 并愿：夏期·春期一般入学、飛び入学和两期外国人留学生入试要项都没有写并愿或同年度再报的规定；出願受理后不能更改志望研究科·专攻·コース。
- 咨询：生命医科学部·生命医科学研究科事務室（京田辺校地，〒610-0394 京田辺市多々羅都谷1-3），Tel 0774-65-6020，Fax 0774-65-6019，jt-semjm@mail.doshisha.ac.jp；外国人留学生的出願资格疑问可问留学生課国際入学係（今出川校地）。
