## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 一般選抜・社会人特別選抜：不考英语笔试，用 TOEIC L&R 或 TOEFL iBT 成绩换算计分（据 2026年10月入学予告）。
- 有效期：TOEIC L&R 为 2024年4月以后（公开测试第350回以后）；TOEFL iBT 为 2024年4月以后。
- TOEIC 交公式认定证原件、数字版打印件或 IP 成绩单（在线 IP 须打印 PDF）；S&W 和 Bridge 不受理。TOEFL 只认 ETS 直接寄送的成绩（机构代码 7976，约需两个月），只看 Test Date 成绩，不认 MyBest，另附 Test Taker Score Report 复印件。
- 换算表和最低分：本年度要项未能读取，没有查到。官方没有说明设最低分。

### 日本語要件
- 外国人留学生特別選抜的外语可选英语或日语。选日语的，用 JLPT N1 或 N2（2024年第1回以后），或考试前2年内的 EJU 日本語成绩（据 2026年10月入学予告）。
- 一般選抜没有日语证明要求的记载。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 一般選抜 専門科目（機械知能工学プログラム，120分钟） | 从「材料力学・機械材料学」「熱と流れ」「機械力学と制御」「メカトロニクス」4 科目中当场选 2 科作答，9:30–11:30；配点未查到 | 上年度第1期・第2期要项 |
| 外国人留学生特別選抜 | 专门科目＋外语（英语或日语成绩）＋口述；国费外国人留学生、外国政府派遣留学生、JICA 留学生有免除规定，具体免哪一项本次未核实 | 上年度第2期要项・予告 |
| 社会人特別選抜 | 不考专门科目，外语（英语成绩）＋口述，须交研究计划书 | 上年度第2期要项・予告 |

- 一般選抜由专门科目、外语（成绩换算）、口述综合判定；各项配点和总分本次没有查到。
- 機械知能工学プログラム不设自己推薦型特別選抜（上年度第2期只在情報工学、データサイエンス、経営情報学设）。2026年10月入学不实施推薦特別選抜和学部3年次生特別選抜。

### 口述試験 / 面接
- **官方形式**：所有选拔都有口述试验，按プログラム进行。上年度要项写明评价基础学力和思考力、挑战新事物的意欲、对贡献地区社会的关心。一般選抜在笔试同日下午（上年度 13:00 起，陽東キャンパス），线下进行，要项没有写线上考试。
- **実際に聞かれた内容**：没有找到本プログラム的公开体验记。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：工農総合科学専攻入学定员 217 名（上年度 2026年4月入学：一般選抜 130、推薦特別選抜 87，社会人・外国人留学生・学部3年次生特別選抜各若干名）。機械知能工学プログラム标准定员约 47 名。2026年10月入学各区分只招若干名。
- 一般選抜出願资格：大学毕业或预定毕业、在外国完成16年学校教育、文科省指定机构、个别资格审查（入学前满22岁）等；部分资格须事先经出願资格审查。
- 外国人留学生特別選抜：无日本国籍，完成或入学前预定完成外国16年学校教育（或15年＋规定学分、个别审查）；在日本的大学毕业或预定毕业者不能报这一区分。
- 第1期分推薦特別選抜（6月）和一般選抜・社会人・外国人留学生・国際交流経験者・高専専攻科特別選抜（8月）两次；第2期（上年度）设一般、社会人、外国人留学生、学部3年次生、国際交流経験者、高専専攻科、自己推薦型特別選抜。
- 出願方式：网上出願。先在网上事前登录并缴费，再把打印的书类（A4 彩色）以書留・速達寄送，必须在截止日 16:00 前寄到；要项册子不发放纸本。
- 检定料 30,000 日元（便利店、Pay-easy/ATM、网银、信用卡）；书类受理后不退；受灾者可申请免除。
- 入学料、授業料：本次没有查到本年度金额。
- 过去问：入试课公开博士前期过去问；但事前咨询时不回答过去问内容。
- 需要考试照顾的须按入试页程序事先相談。
- 咨询：宇都宮大学入試課（9:00–17:00，周末节假日除外）。

### 研究室 / 指導教員
- 事前連絡要否：必须。上年度要项写明出願前要联系希望指导教员、商量研究计划并取得受入内诺；本年度要项未能读取，按同样要求准备。
- 機械知能工学プログラム的指导教员名单：要项附表和研究科网站本次都无法读取，没有核实到教员名单。出願前请在研究科网站的教员介绍页确认。
