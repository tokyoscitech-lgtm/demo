## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般選抜：不另设英语笔试，用 TOEIC Listening & Reading 公开考试成绩评价（配点见筆記試験）。
  - 只认出願最后一天往前2年内（2024/7/9–2026/7/8）已通知结果的成绩；考过但结果没出来的不算。
  - 两步都要做：在 WEB 出願时上传デジタル公式認定証（PDF），并在 TOEIC 会员页用申请代码 00010404 在线提交成绩。
  - TOEIC IP 不受理；在日本国外考的 TOEIC 须事先与教務学生係商量。
- Kobe Global Graduate Program：提交 TOEFL iBT、IELTS（Academic）成绩或英语授课学部出具的证明之一，限截止日前24个月内；TOEFL iBT Home Edition、IELTS Online 不受理。
- MEXT 国费项目：须达到 CEFR B2（如 TOEFL iBT 72、IELTS Academic 5.5 以上，四项分数也须 B2），限考场受检、截止日前2年内的成绩。

#### 日本語要件
- 一般選抜：要项没有要求提交日语成绩；试题用日语出题。
- Kobe Global Graduate Program、MEXT 国费项目：用英语授课，书类用英语提交。

### 口述試験 / 面接
- **官方形式**：一般選抜：笔试次日按講座进行口頭試問，与笔试成绩、成绩证明书综合判定；Kobe Global Graduate Program：书类综合评价后用线上会议软件或邮件面谈，详情由指导预定教员通知；MEXT 国费项目：书类审查＋面试（线下或线上），通过者由大学推荐给文部科学省。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：58名（研究科合计132名），含 Kobe Global Graduate Program 录取的外国人留学生（该项目若干名）；MEXT 国费项目研究科合计3名。
- 出願资格：大学毕业（含2027年3月预计）或外国16年学校教育等，资格(9)(10)(11)须先受审查（2026/5/25–5/29 受理，已截止，非独立出願）；外国人留学生特別選抜已废止，留学生报一般選抜；応用生命化学講座可在同講座内填第2志望，応用機能生物学講座不认第2志望，不能跨講座；Kobe Global Graduate Program 须为协定校在学或毕业、与本研究科教员已有密切联系、持外国政府或民间奖学金三者之一，并取得指导预定教员同意；MEXT 国费项目限居住在海外、指定国籍、1992/4/2 以后出生，合格后须读完博士课程。
- 要提前准备的书类：外国学历者交写明学位的毕业（预计）证明，英语以外的外文证明须附公的机关翻译证明的日语译文；中国的大学毕业者交 CHSI 英文学历·学位认证报告（在读者交学籍在线验证报告），出願时有效期须剩1个月以上；Kobe Global Graduate Program 另需推荐信、毕业论文摘要与研究计划（各200–300词）、指导教员承诺书（Form 3）和英语成绩。
- 出願：一般選抜只能在 WEB 出願网站登记并缴检定料 30,000 日元，书类書留速達邮寄（邮戳有效）或窗口提交；Kobe Global Graduate Program 检定料 30,000 日元，表格向教務学生係邮件索取；MEXT 国费项目免检定料。
- 咨询：神戸大学大学院農学研究科教務学生係（〒657-8501 神戸市灘区六甲台町1-1），ans-kyomu@office.kobe-u.ac.jp，Tel 078-803-5928。
- 并愿：尚未核实是否可同时报考其他专攻或选拔类别。请以本年度募集要项或招生窗口答复为准。
