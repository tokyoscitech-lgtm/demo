## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各轮次、一般入試和外国人留学生特別入試相同：不另设英语笔试，出願时交外部英语成绩，换算为100分计入总分。
- 可交：TOEIC（公开考试或 IP，Official Score Certificate，可打印数字认定证）、TOEFL iBT（Test Taker Score Report）、IELTS（overall，Test Report Form）；线上受检的成绩不收。
- 有效期：2022/4/1 以后受检；学部在读预计毕业者交入学后受检的成绩；出願时交不出须附理由书。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 外国人留学生特別入試的専門科目可选日文或英文试题，用日文或英文作答；考场指示用日语。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 物理 | 物理化学（热力学、平衡、电化学、反应速度论、量子化学、分子间相互作用、表面化学、光谱）、分析化学（容量分析、分配平衡、仪器分析、分离分析、放射性衰变） | 第1回：考2科 9:00–12:00，180分钟；考1科 10:30–12:00，90分钟；第2回：13:30–15:00，90分钟 |
| 化学 | 有机化合物（含天然物·药物）的命名、性质、结构、反应、合成，含仪器数据结构解析 | 同上 |
| 生物 | 生化学（蛋白质与酶、氨基酸、脂质、核酸、糖、能量代谢）、分子·细胞生物学（细胞结构、细胞器、细胞内输送、基因复制·修复·表达调控、细胞周期与细胞死亡） | 同上 |
| 薬理 | 药理总论、信号传导、通道与转运体、神经·循环·泌尿·免疫炎症·呼吸消化·内分泌·代谢疾病治疗药 | 同上 |
| 薬剤 | 物理药剂学、制剂学（含DDS）、生物药剂学、药物动态学 | 同上 |
| 臨床 | 药物治疗（含医疗信息）、临床药物动态（TDM、药效动力学）、生物统计、医药品开发 | 同上 |

- 选科：第1回一般入試的岡山大学薬学部出身者从6科选2科（至少1科为第一志望分野指定科目）；其他人（第1回其他大学出身者、第2回全员、外国人留学生特別入試）只考第一志望分野指定的1科；考了志願票上没写的科目即失格。
- 总分：専門科目200分（考2科各100分；考1科者100分换算为200分）＋外部英语100分；面接只判合否；合否按笔试、英语、面接和书类综合判定。

### 口述試験 / 面接
- **官方形式**：第1回：考2科的薬学部出身者为集团面接，其他人和外国人留学生为个人面接；第2回：个人面接；只判合格或不合格，不计分。
