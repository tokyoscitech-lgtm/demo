## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各轮次相同：不另设英语笔试，用 TOEIC Listening & Reading 公開テスト的成绩评价英语；本専攻按 Listening：Reading＝1：3 加权。最低分、换算方法和英语在总分中的配点官方没有公布。
- 成绩须为笔试日（2026/8/18）前2年以内受験的公開テスト，只能交1次成绩；IP テスト（団体特別受験）和 TOEFL 不受理。
- 在日本国内受験的：出願时交研究科所定的「TOEIC L&R 公開テスト受験情報確認票」，并在 2026/8/3（周一）前于 TOEIC 申込网站输入申请代码 00010402 在线送分（考试日17天后才能操作），不接受用公式認定証送分。
- 在海外受験的：交受験情報確認票和公式認定証原件，出願时来不及的最迟 2026/8/3（周一）补交。
- 变更点：2028年度入试（含2027年10月入学）起，送分期限提前到出願期间最后一天，期限内没交的不受理出願（研究科入试页予告）。

#### 日本語要件
- 一般選抜：要项没有要求提交日语成绩。
- 外国人留学生特別選抜：必须提交“日语水平足以不妨碍修学”的证明书，要项举例为日本語能力試験成绩证明书，没有规定等级或分数。
- 英語コース：英文要项没有日语要求。
- 试题语言和作答语言，要项对本専攻没有写明。

- 一般選抜综合学力检查（笔试、口头试问）和成绩证明书决定合格者，本専攻还会考虑考生希望的教育研究分野。第一次选考为笔试，只有第一次选考合格者能参加第二次选考（面接）。总分和合格线官方没有公布。
- 外国人留学生特別選抜、英語コース的科目和时间与一般選抜相同（物理Ⅰ、物理Ⅱ＋TOEIC＋面接）；英語コース另看成绩证明书。
- 题目倾向（第三方解答网站，非官方，仅1处来源）：物理Ⅰ、物理Ⅱ各3道大题。

- **官方形式**：夏季入试（一般選抜）笔试次日 2026/8/19 9:30 起面接，只面向第一次选考合格者，出願时交的入学理由书和希望的教育研究分野作为参考，内容、时长、配点和语言要项没有写明；外国人留学生特別選抜、英語コース同日 9:30 起面接，形式未写明；冬期追加募集未公布。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：夏季入试一般選抜24名，外国人留学生特別選抜若干名，英語コース若干名；冬期追加募集是否实施、人数均未公布。
- 一般選抜的出願资格共11项，满足其一即可：大学毕业或2027/3/31前预计毕业、在外国完成16年学校教育、在外国取得相当于学士的学位（3年以上课程）、经个别资格审查认定与大学毕业同等以上学力且2027/3/31前满22岁、大学在学3年以上且成绩优秀（跳级）等。个别资格审查的申请截止为 2026/6/5（周五）（已过）。
- 外国人留学生特別選抜：须持有在留资格「留学」（含预计2027年4月取得者），并满足大学毕业（含预计）、外国16年课程、外国3年以上课程的学士相当学位、个别审查认定之一。
- 英語コース（英语授课的修士课程）：须满足神戸大学在学或毕业、与理学研究科有交流协定或曾有交流的大学的在学或毕业、与理学研究科教员已有密切联系、取得外国政府或民间奖学金之一并有所属机构的推荐；须取得志望指导教员的同意；入学时能取得「留学」在留资格。需要个别资格审查的（15年教育＋优秀成绩等），本専攻截止 2026/5/29（周五），结果 6/5 通知（已过）。
- 志望的填写：一般選抜和外国人留学生特別選抜在 Web 出願时不填指导教员姓名，选拔时考虑希望的教育研究分野（理論物理学、粒子物理学、物性物理学）。
- 出願方式：先在 Web 出願网站登记、上传证件照数据（3个月内拍摄，2MB 以内）并缴纳检定料，再在书类提交期间内把纸质书类送达理学研究科教務学生係（邮寄用レターパックプラス或書留速達；窗口 9:00–12:00、13:00–17:00）。
- 出願书类（一般選抜）：入学願書·履历书（从 Web 出願网站打印）、成绩证明书、毕业（预计）证明书、TOEIC 受験情報確認票、入学理由书（只有物理学専攻要交，A4 1页，字数格式不限）；住在日本的外国人另交住民票复印件（30日以内）或在留卡复印件。中国大学毕业者须另交经 CHSI 认证的英文学历·学位报告（在读者交 Student Record）；日文、英文以外的证明书须附公的机关翻译证明的日文译文。
- 外国人留学生特別選抜另需：日语能力证明书、出身大学指导教员的推薦状（研究科所定样式；本研究科研究生等身份在籍者免）、国费外国人留学生证明书（仅该当者）。英語コース另需学部长和指导教员的推荐信、statement of purpose（A4，长度格式不限）。
- 检定料 30,000 日元，在 Web 出願网站支付，手续费自负。出願后不能修改登记内容，已交书类和检定料原则上不退。
- 并愿限制：不能与同日实施的理学研究科其他博士前期入试（10月入学、外国人留学生特別選抜、英語コース等）同时报考。
- 10月入学：2026年10月入学（已结束）本専攻一般選抜和外国人留学生特別選抜各招若干名，与4月入学同日考试；2027年10月入学的募集要项未公布，往年5月中旬与4月入学要项一起公开。
- 入学手续预定2027年3月中旬（一般選抜2月中旬、外国人留学生特別選抜3月上旬寄送通知）。入学料 282,000 日元，授業料 年 535,800 日元（2026年度金额）。
- 考场在神戸大学理学部学舎（神戸市灘区六甲台町1-1），考场和面接室当天贴在理学部Y棟1階掲示板；受験票从 Web 出願网站下载并彩色打印；手表只能用仅有计时功能的；需要特别照顾的须在出願2周前提出。
- 咨询：理学研究科教務学生係，〒657-8501 神戸市灘区六甲台町1-1，Tel 078-803-5767，sci-kyomu@office.kobe-u.ac.jp。
