## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 不另设英语笔试，用 TOEFL iBT 成绩评价外国语；修士出願者全员提交，英语母语者也要交。
- 只收 TOEFL iBT 和 TOEFL iBT Home Edition 的 Official Score Report（ETS 直送）。MyBest scores 不采用，考生手里的 Test Taker Score Report 不受理；IELTS、TOEIC 等不能代替。Home Edition 当天可能因故无法受检，官方提醒提早安排。
- 送分代码：University of Tokyo IS&T，Institution Code 8445，Division 选 Graduate Organization，Department Code 99；送到其他代码研究科查不到。出願时填写 Appointment Number 和受检日，只认所填那一次，出願后原则上不能更换。
- 有效期：受检日在 2024/9/1 以后、出願截止（2026/6/4）以前；成绩数据须在 2026/6/30 前到达研究科（已截止）。
- 成绩未按期到达或不符合要求的视为无效，失去数学和口述的受験资格。
- 官方没有规定最低分，换算方法和配点官方未公布。

#### 日本語要件
- 要项和専攻入试案内书都没有要求提交日语成绩，对外国人考生也没有日语门槛；研究科没有另设外国人留学生特别选拔。
- 数学试题有日英两版。口述的发表必须用英语，之后的试问可用日语或英语回答。出願书类只收日文或英文，其他语言须附译文。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 一般教育科目（数学）（配点官方未公布，150分钟） | 研究科共通题：线性代数、解析（微分积分、常微分方程等）、概率·统计三个领域各1题，3题全答 | 2027修士募集要项 |
| 専門科目（不设笔试） | 专业考查放在口述里：机械系（机械力学、控制、メカトロニクス、ロボティクス等）和情报系（情報基礎、数字电路、计算机、软件等） | 2027専攻入试案内书 |

- 选拔流程：书类选考 → 数学笔试 → 外国语（TOEFL 成绩）→ 専門·口述，综合判定。只有通过书类选考、参加了数学且 TOEFL 有效的人才能参加口述；各项配点和判定方法官方未公布。
- 専門科目笔试在 2021年度入试以后不再实施，改由口述考查；与上一年度相比没有变化。
- 题目倾向（体验记，非官方）：没有找到本専攻的考生体验记，数学部分以研究科共通过去问和出题意图为准。

### 口述試験 / 面接
- **官方形式**：夏入试 Zoom 线上，须用 Windows 或 Mac 电脑并外接摄像头；先用英语做7分钟发表（专业能力、志望领域、研究计划），事先做好幻灯片并共享屏幕，随后试问（日语或英语回答），可能问到机械系和情报系的专业内容；试问时长和配点官方未写；全程录像，房间里只能有本人，不能用虚拟背景、耳机、帽子、智能手表，考前要向监考展示房间，桌上只能放受験票、电脑及外设、A4 以上的笔记本或白板和笔；考试 URL 在 8/21（周五）前通知。
- **実際に聞かれた内容**：没有找到本専攻口述的考生体验记，实际提问内容不明。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：夏入试 56 名（含 2026年10月和 2027年4月入学）；本専攻修士没有冬入试。
- 出願资格：大学毕业或 2027/3/31 前预计毕业；在外国完成16年学校教育；在外国取得相当于学士的学位（修业3年以上）等。个别入学资格审查的材料截止为 2026/5/13（周三）（已截止）。
- 志望研究室：在 WEB 出願系统“志望研究室”栏用下拉菜单选第1至第10希望，只能选本年度可接收学生的教员；所选教员都排不进时，可能被分到其他有名额的教员。
- 専攻独有提交物（用専攻 Word 样式填写后转 PDF，与願書一起提交）：
  - 志望カード：1页以内，12pt 以上。
  - 専門能力調査カード：A4 2页，不能加页，12pt 以上，可用图表，写研究活动、课程或演习中的自主制作、课外活动等能说明专业能力的内容。
- 研究科共通书类：系统内填写的願書和证件照（jpeg）、成绩证明书、毕业（预计）证明书（上传 PDF，入学手续时交原件）、TOEFL 成绩（ETS 直送）、检定料缴纳证明、外国籍者等须上传的出口管制审查用检查表。
- 出願方式：只能通过 WEB 出願系统，没有邮寄或窗口受理。受験票用邮件发送，夏入试到 2026/7/17（周五）17:00 还没收到的要联系入试担当。
- 检定料 30,000 日元，用银行转账、便利店、Pay-easy 或信用卡支付，手续费自付，缴后不退；日本政府（文部科学省）奖学金留学生免缴，须上传证明。
- 并愿限制：同一期只能报一个専攻、课程或选拔区分。
- 入学时期：标准为 2027年4月入学，出願时提出希望的可 2026年10月入学。入学手续截止（预定）：2026年10月入学 2026/9/24（周四）（已截止）；2027年4月入学 2027/3/11（周四），入学许可通知约 2026年10月下旬发出。外国籍者须在入学手续前取得可在学的在留资格；在职者要交所属单位负责人的同意书。
- 入学料 282,000 日元，授業料 半年 267,900 日元（年额 535,800 日元），均为预定额；日本政府奖学金留学生免缴。
- 大学院外国人研究生是另一条路线，这不是修士入试的要求。
- 咨询：出願手续问情報理工学系研究科入试担当（johoriko.t@gs.mail.u-tokyo.ac.jp，Tel 03-5841-7926，平日 9:00–17:00，原则上用邮件）；専攻内容问知能機械情報学専攻事务室（kyoumu@office.mech.t.u-tokyo.ac.jp，Tel 03-5841-6302）。
