## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 推薦·一般·社会人·私費外国人留学生选拔：不另设英语笔试，也不评价外部英语成绩；研究科共通的 TOEIC/TOEFL 条款只适用于理工学専攻，不适用于本専攻。地球科学コース的口頭試問把英语能力列为评价项目。
- 英語SP：出願时提交 TOEFL、TOEIC 等成绩复印件，或在英语授课的高等教育机构学习的证明；要求具备良好的英语水平。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 私費外国人留学生选拔：志望理由書（様式7）须本人用日语亲笔书写；小論文课题用日语出题。
- 英語SP：授课和研究指导用英语，出願书类可用日语或英语。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 一般·社会人：无笔试 | 成绩证明书＋口頭試問·面接（满分100）综合判定 |  |
| 私費留学生·環境共生科学：小論文 | 出願后研究科寄日语课题，按期提交；与成绩证明、指导教员推荐书、志望理由書一起选考 |  |
| 私費留学生·物質化学：小論文 | 同上；提交后另用邮件就小論文内容试问（第2次 12/14–12/16） |  |

- 一般·社会人配点：地球科学、環境共生科学、建築デザイン学为口頭試問·面接100；物質化学为口頭試問70＋面接30。总分达到基准点（6成）者从高分起合格，同分同序；地球科学另要求面接（100）得60分以上。
- 推薦：地球科学只审书类（100）；環境共生科学、建築デザイン学只考面接（100）；物質化学书类70＋面接30。
- 私費外国人留学生选拔：地球科学只考面接，建築デザイン学只考口頭試問，均结合成绩证明、推荐书、志望理由書评价。
- 英語SP：凭出願书类和指导预定教员的面接选考，总分6成以上者按分数排序合格，同分同序。
- 题目倾向（官方过去问）：環境共生科学小論文围绕环境与农村议题论述，如近代河川工程对治水·利水·河川环境的影响、日本森林气候与火入维持的半自然草原、ため池的功能与管理问题；出题意图重视基础知识、逻辑和日语表达。

### 口述試験 / 面接
- **官方形式**：地球科学：约25分钟，自带PC用投影仪做约5分钟发表（毕业论文等及入学后研究计划），质疑约15分钟、面接约5分钟，评价地球科学基础知识、英语能力和研究能力；環境共生科学：约15分钟，口頭試問约10分钟说明毕业论文等和入学后研究并质疑，面接约5分钟；物質化学：约20分钟，先做5分钟投影发表（毕业研究等）后质疑，面接看进学目的和适性，社会人不做发表、改问化学专门基础；建築デザイン学：一般约20分钟口頭試問·面接，社会人只考面接10–15分钟；英語SP：数名指导预定教员校内或线上面接，线上受验须独处安静房间并提交网络面接确认书。
