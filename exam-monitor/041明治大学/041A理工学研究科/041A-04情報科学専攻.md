## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各轮次相同：不另设英语笔试，用外部成绩换算「英語」得分（100分），换算基准 TOEIC L&R 730＝满分、230＝0分；TOEFL iBT 2026/1/20 以前受检的 80＝满分、25＝0分，2026/1/21 以后受检的（1–6分制）4.5＝满分、2＝0分。
- TOEFL iBT：由 ETS 直送（DI Code 5132，本専攻 Department Code 78），并在出願书类チェックリスト上写 Appointment number 和直送手续日；Home Edition、MyBest、本人收到的 Test Taker Score Report 不受理。
- TOEIC L&R：交纸质 Official Score Certificate 原件，或日本国内受检（2024年4月以后）带 QR 码的数字认定证 PDF 打印件；提交后不能更换。
- 成绩须为出願截止日前2年以内受检，且必须在出願期间内送到；没送到、或成绩上的姓名等与志願者信息不一致、没有照片的，英语按0分处理。
- 变更点：2027年度Ⅰ·Ⅱ期起不再接受考试当天提交成绩。

#### 日本語要件
- 要项没有要求提交日语成绩。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 基礎科目·専門科目（200分） | 「数学」「プログラミング」「基礎」「ソフトウェア」「ハードウェア」「応用」6题选4题作答 | 9:00–11:00，120分钟 |

- 按笔试、外部英语成绩、口头试问和书类选考综合判定。
- 2026年度试题（官方公开）：数学考级数与广义积分的收敛、矩阵固有值与对角化（Ⅱ期为Γ函数、图的着色），プログラミング用C语言写函数，ソフトウェア考Java的继承与委托，ハードウェア考计算机体系结构基础概念，応用考决策树等机器学习模型的可解释性。

### 口述試験 / 面接
- **官方形式**：各轮次都在笔试当天下午进行口头试问，开始时刻随受験票通知，迟到不能受验。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：40名（学内選考、Ⅰ期、Ⅱ期等全部入试合计）。
- 出願资格：大学毕业（含2027年3月预计）或外国16年学校教育等；外国人留学生入试要求非日本国籍、初中等教育全部在外国修完；需个别资格审查的人须先申请（Ⅰ期 2026/4/15、Ⅱ期 10/15 必达，非独立出願）。
- 要提前准备的书类：研究计划书（所定用纸A4 1页以内，写入学后的研究计划和将来去向）、外部英语成绩、外国籍者（本学理工学部·研究科出身者除外）须交出身大学指导教员等的推荐书1份（格式自由，日文或英文）、経費支弁計画書；中国的大学毕业者须办 CHSI 认证并由 CHSI 直送。
- 出願：只收邮寄（速達·簡易書留，国内邮戳有效；海外用 EMS 等，最后一天必达），不收窗口和网上出願；检定料 35,000 日元。

- 事前連絡要否：必须。要项和教员一览写明本専攻志愿者出願前必须先和希望的指导教员事前相谈，并在入学志願書的确认栏打勾；教员邮箱见研究指导担当教员一览。
