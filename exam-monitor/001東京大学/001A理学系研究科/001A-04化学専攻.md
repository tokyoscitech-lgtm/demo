## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般选拔（2027年度入试）：
  - 可在本専攻考场当天考 TOEFL ITP（成绩只对本次入试有效），也可提交事先考好的 TOEFL iBT 或 TOEIC L&R 公开考试正式成绩；两种都做了的取高分。
  - TOEFL iBT：只认 2024/9/1 以后在考试中心受检的成绩，Home Edition 和 MyBest 不受理；出願时上传 Test Taker Score Report，并在出願期限前让 ETS 把 Official Score Report 送到本専攻（Dept. Description 填 Chemistry），两步都要做。
  - TOEIC L&R：只认 2024/9/1 以后在日本国内受检的公开考试；出願时上传デジタル公式認定証，并在期限前通过 IIBC「公開テストスコア確認サービス」送到本専攻。
  - WEB 出願系统只能上传一种成绩。
- 变更点：2028年度入试（2027年实施）起取消考场 TOEFL ITP，只收事先考好的 TOEFL iBT 或 TOEIC L&R 公开考试的正式成绩（二选一）。
- 外国人特別選考：TOEFL iBT（单次成绩，不收 MyBest，出願开始日前 2 年以内，机构代码 8002-01）和 GRE General Test。

#### 日本語要件
- 要项没有要求提交日语成绩。作文可用日语（约 400 字）或英语（约 200 词）写；専攻页说明修士、博士课程用英语授课。外国人特別選考全程英语。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 専門科目 | 化学 6 题（物理化学、有機化学、無機·分析化学各有「基礎」「標準」两题）＋数理科学 1 题＋地球科学 1 题＋生物化学 1 题，共 9 题任选 5 题，现场笔试 |  |
| 作文 | 写入学后想进入的领域和想做的研究，日语约 400 字或英语约 200 词 |  |
| 英語 | 考场 TOEFL ITP，或提交 TOEFL iBT／TOEIC L&R 成绩 |  |

- 出题方向（令和8年度「出題意図」）：物理化学以量子化学、热力学为基础；有機化学以结构式和有机电子论为基础，考反应与立体结构；無機·分析化学以配位化学、光谱法为基础；数理科学考物理化学所需的数学和物理；地球科学考矿物、岩石、水溶液等物质；生物化学考蛋白质、核酸等。
- 外国人特別選考按书类（TOEFL、GRE、推荐信 2 封、Personal Statement、Statement of Purpose、成绩）选考，研究科注明部分専攻会另加面试或线上笔试。

### 口述試験 / 面接
- **官方形式**：一般选拔：线上口述，问专门研究所需的基础学力、志望动机是否妥当和适应性；外国人特別選考以书类选考为主。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：一般选拔 2027年4月入学 72名，另有 2026年10月入学若干名；外国人特別選考另行选拔。
- 出願资格：大学毕业（含 2027/3/31 前预计；选 2026年10月入学的读作 2026/9/30）或外国 16 年学校教育等；个别入学资格审查 2026/5/11–5/15 申请（非独立出願，已过）；同年度不能报本研究科两个以上専攻，也不能与其他选拔路线并报同一入学期；10月和4月入学只能选一个；外国人特別選考限外国学历（16 年教育或外国学士相当学位，含预计）者。
- 要提前准备的书类：一般选拔：选成绩方式的交 TOEFL iBT／TOEIC 成绩（上传＋机构送分）；外国人特別選考：TOEFL iBT、GRE General、推荐信 2 封、Personal Statement 和 Statement of Purpose（英文，A4 1–2 页）、与希望教员事先商谈的证明。
- 出願：一般选拔只能通过研究科 WEB 出願系统，检定料 30,000 日元；外国人特別選考用 GSGC 网上系统，检定料 10,000 日元。
- 并愿：同一年度不能同时报本研究科的两个以上専攻；已通过其他选拔路线申请同一入学期的，不能再报一般选拔。
- 咨询：考试内容问化学専攻入試実施事務局（〒113-0033 東京都文京区本郷7-3-1），nyushi@chem.s.u-tokyo.ac.jp，Tel 03-5841-4321；出願手续问理学系研究科学務課大学院担当，daigakuin.s@gs.mail.u-tokyo.ac.jp，一般选拔 Tel 03-5841-4080，外国人特別選考 Tel 03-5841-4009。合否不接受电话询问。
