## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 一期·二期的一般入试：学内英语笔试「外国語（英語）」，100分。可以带纸质辞典，电子辞典不可。和专门科目同在 10:00–12:00 时段实施。
- 要项没有规定用 TOEIC、TOEFL、IELTS 等外部成绩代替英语笔试，也没有最低分要求。
- 社会人入试和推薦入试没有英语考试。
- 英语版 Application Guide 对留学生的规定与日文版相同，外语科目同样是英语。

### 日本語要件
- 要项没有要求提交 JLPT、EJU 等日语成绩。
- 要项里「以日语作为外语科目」的选项只设在其他研究科，本専攻的外语只能考英语。
- 要项没有写明专门科目和面试的试题语言及能否用英语作答。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 外国語：英語（100分，10:00–12:00 时段） | 英语笔试；可带纸质辞典，不可用电子辞典 | 2026秋・2027春 一般・社会人要项 |
| 専門科目（200分，10:00–12:00 时段） | 応用数学、制御工学、情報工学、電気工学、画像工学、メディアコンテンツ、メディアコミュニケーション 共7科目各1题，从中选3题作答；不可带任何资料 | 2026秋・2027春 一般・社会人要项 |
| 社会人入试 | 不考笔试，只有基于提交书类的面试（含专门领域的提问） | 同上 |

- 一般入试笔试合计 300 分（英語 100＋専門 200）；面试配点要项没有写明。合否按笔试、面试与书类综合判定，官方没有公布合格最低分。
- 题目倾向（体验记，非官方）：没有找到考生公开的体验记。

### 口述試験 / 面接
- **官方形式**：一般入试在笔试当天 13:00 起，约20分钟。先用自己的电脑做 5 分钟发表（毕业研究或入学后的研究计划），再进行包括专门领域在内的问答；需自带电脑，并带印好的幻灯片资料和 U 盘备份。社会人入试 10:00 起约20分钟，按提交书类提问，也包括专门领域。推薦入试没有面试。
- **実際に聞かれた内容**：没有找到考生公开的面试经验。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员 40 名（2026年10月入学和2027年4月入学合计，一般・社会人・推薦各区分合计）。各轮次没有分开的名额。
- 一般入试出願资格：大学毕业或预计在2026年9月（秋学期入学）／2027年3月（春学期入学）前毕业；在外国完成16年学校教育；大学在读3年以上并取得规定学分；以及经个别资格审查、年满22岁（秋学期 2004/10/1 以前出生、春学期 2005/4/1 以前出生）等。
- 社会人入试出願资格：大学毕业等，且毕业后有2年以上的社会经验。
- 推薦入试：需满足本専攻的推薦基準，只审书类。对象为本校同系列学科的预计毕业生（成绩前50%或 GPA 达标，学科长推荐）、本校其他学科学生、本校同系列毕业5年以内者（成绩前50%或累积 GPA 2.8 以上），以及日本国内其他大学的预计毕业生·毕业生（成绩前50%且累积 GPA 2.8 以上，需所在大学学部长或指导教员推荐，另需面谈）。GPA 门槛：2022年度以后入学者 3.5 以上，2021年度以前入学者 2.8 以上。
- 出願书类：WEB 登录并缴费后打印的志願登録票（2份）、最终学历的毕业（预计）证明书和成绩证明书（3个月以内开具）。一般入试和社会人入试另需事先提交入学后的研究计划书（格式和页数不限），寄到湘南校舍サイエンス・エンジニアリングカレッジオフィス，一期 2026/6/12（周五）必达，二期 2027/1/18（周一）必达。
- 出願方式：先在 WEB 出願网站登录、上传照片并缴费，再把书类用简易书留寄到所附信封标签上的地址。书类不齐不受理；出願后考试相关项目不能变更。
- 检定料 32,000 日元，在 WEB 出願网站支付。
- 出願资格审查：外国大学毕业等资格不在常规范围内的人必须事先受审，一期截止 2026/5/22（周五）（已过），二期截止 2026/12/11（周五）。需交履历书（大学规定格式）、学位证明、成绩证明等；中国的学校毕业者另需学位电子认证报告，开具约需1个月。
- 外国人留学生须注意安全保障出口管理：符合一定条件的人可能无法进入希望的课程，大学在合格时个别确认是否属于「みなし輸出」管理对象。
- 学费（2027年4月入学）：入学金 200,000 日元，春学期授業料 406,000 日元，入学时缴 606,000 日元；秋学期授業料 406,000 日元。另有学生教育研究灾害伤害保险 2,430 日元、同窗会费 12,000 日元（本校毕业者免）。本校毕业者免入学金，九州東海大学·北海道東海大学毕业者半额。2026年10月入学者入学时的授業料为 398,000 日元。
- 一期春学期入学的合格者，入学手续分两段：2026/7/15–7/24 17:00 与 2026/11/17（周二）–11/27（周五）17:00，7/25–11/16 不受理。
- 考场为湘南校舍（神奈川县平塚市），具体教室见受験票；一期受験票 2026/6/22（周一）起、二期 2027/1/29（周五）起在网上打印。
- 考试需要特别照顾的，一期 2026/5/15（周五）、二期 2026/12/4（周五）前向入试担当申请（0463-63-4660，nyushi@tokai.ac.jp）。
