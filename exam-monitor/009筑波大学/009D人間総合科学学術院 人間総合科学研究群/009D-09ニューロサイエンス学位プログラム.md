## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各轮次相同：プログラム自己出题的「外国語」（100分，90分钟），内容是与行动科学·神经科学有关的英语题目。
- 不需要提交 TOEIC、TOEFL、IELTS 等外部成绩；全学的外部英语成绩提交规定不适用于本プログラム。
- 能否带词典、具体题型（英译日、摘要等），要项没有写。

#### 日本語要件
- 要项没有要求提交 JLPT、EJU 等日语成绩，也没有外国人留学生的另设选拔；留学生与日本学生考同一套题。
- 研究计划可用日文（约2,000字）或英文（约800词）写；笔试的出题和作答语言要项没有写明。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 外国語（100分，90分钟） | 与行动科学·神经科学有关的英语题目；题数未写明 | 2027募集要项 |
| 専門科目（100分，90分钟） | 与行动科学·神经科学有关的题目，不论志望领域，从所出题目中选2题作答 | 2027募集要项 |

- 8月实施、1-2月实施的科目和配点相同；总分 250：外国語 100＋専門科目 100＋口述試験 50。根据书类和学力检查结果综合判定，没有公布合格最低分。
- 只有一般入学試験，没有推薦入试、社会人特別選抜和10月实施。
- 题目倾向（体验记，非官方）：没有找到本プログラム的考生体验记。

### 口述試験 / 面接
- **官方形式**：8月实施和1-2月实施相同，个别面接，50分，就研究领域的专业知识和研究计划试问，在笔试次日 10:00–17:00 之间个别进行；プログラム官网写每人约10分钟，形式和时间可能变更；面接语言没有写。
- **実際に聞かれた内容**：没有找到本プログラム的面接体验记。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：8月实施（一般入学試験）8名；1-2月实施（一般入学試験）2名；均含连携大学院（産業技術総合研究所）的名额。2027年4月入学。
- 出願资格：日本的四年制大学毕业或入学前一个月底前预计毕业；由大学改革支援·学位授与機構授予学士学位；在外国完成16年学校教育；在外国3年以上的课程取得相当于学士的学位（出願前先确认资格）；经个别出願资格审查认定有同等以上学力且满22岁。
- 个别出願资格审查和资格咨询的截止：8月实施 2026/7/3（周五）（已截止）；1-2月实施 2026/11/24（周二）。邮件标题写「出願資格審査希望」，写明住址、姓名、电话、邮箱、志望プログラム、最终学历，发给体育芸術エリア支援室大学院教務；以前通过审查的人每次仍要重新申请。
- 志望指导教员：在 Web 出願系统里选第1志望，第2志望可不填；填了的教员都要事先取得承诺。
- 出願书类：毕业（预计）证明书（已有硕士以上学位者也要交学士的证明）、外国大学毕业者的学位取得证明书、成绩证明书（读过大学院的也要交）、检定料收纳证明或信用卡支付结果画面复印件、在学或在职者的受験·就学承认书（样式不限）、国费留学生证明书（符合者）。姓名变更者附户籍抄本等。
- 研究计划：原则上直接填在 Web 表单里（日文约2,000字或英文约800词，参考文献计入字数）；只有必须用图表、符号时才用规定样式另交，不得超出规定栏或写“见别纸”。
- 出願方式：Web 出願系统注册邮箱 → 录入信息并上传证件照（JPEG，3个月以内）→ 选志望指导教员 → 填写みなし輸出的确认事项 → 支付检定料 → 点击「出願」（之后不能改）→ 打印受験票和收件人标签；书类装角形2号信封用書留寄到体育芸術エリア支援室，截止日必达。一个账号只能报一个学位プログラム。
- 检定料 30,000 日元，信用卡或便利店支付，手续费自付，缴纳后不退；国费外国人留学生免缴。
- 入学料 282,000 日元；授業料年额 535,800 日元（每学期 267,900 日元），在留资格为「留学」的外国人留学生年额 608,800 日元（每学期 304,400 日元）。入学手续说明在合格发表当天发到登记邮箱；外国籍合格者入学手续前须取得「留学」等不妨碍入学的在留资格。
- 试场：筑波大学筑波キャンパス（茨城県つくば市天王台1-1-1），建筑和可携带物品写在考试1周前掲載的「受験者心得」里。
- 咨询：出願手续和资格审查找体育芸術エリア支援室大学院教務（taigeiin.admission@un.tsukuba.ac.jp）；外国学历等出願资格的事先确认找入試課大学院入試（admission.grad@un.tsukuba.ac.jp）；プログラム内容用官网咨询表单。
