## 🎯 入試内容（考什么）

### 語学 / 英語要件

- 普通一般为学内英語試験（校内英语笔试），80分钟100点。留学生现场路线和在线路线另见下表。

| 路线 | 语学形式与条件 |
|---|---|
| 一般（日本国籍者） | 英语100点、80分钟；纸质词典最多2册，种类不限，电子词典不可；外部TOEIC／TOEFL不替代 |
| 留学生现场 | 外语100点、80分钟，英语或日语选1；母国以英语为共通语者必须选日语；英语纸质词典最多2册、电子词典不可，日语不得携词典 |
| 社会人 | 选考为小论文及面接，没有独立英语笔试 |
| 一般在线 | 演示、口头试问使用日语或英语，无现场外语笔试，不可据此免除研究计划书的日文要求 |

### 日本語要件

- 留学生现场路线面接为**日语口头试问**；申请材料须交可证明日语能力的复印件，但本大学院出身或拟指导方法为英语者免交该项。2027出願条文未统一指定证书等级／考试分数，不能擅自补出出願线。
- 在入学后新取得或更新“留学”在留资格时，要项另外要求下表任一证明。出願书类中的日语证明与在留手续的门槛须分别判断。

| 事项 | 官方要求 |
|---|---|
| 在留日语证明 | JLPT N2以上，或EJU日语读解＋听解＋听读解200以上，或BJT400以上，或JPT525以上，或日语学习600小时以上 |
| 证明不足 | 可能取消入学许可；并非所有考生同时提交所有考试成绩 |
| 在线留学生书类 | 同样须日语证明，本大学院出身或拟指导方法为英语者免交；在线可用日英并不自动免书类 |

### 筆記試験（专门科目）

| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 一般、留学生：専門科目（100点、80分钟） | 人間環境総合分野、文化環境分野、心身環境分野、都市・自然環境分野，共4科目选2 | 2027募集要项第6、9页 |
| 社会人：小論文（100点、80分钟） | 对指定主题作答，未给当年具体题目与字数 | 2027募集要项第7页 |
| 一般在线：无上述现场专业笔试 | 改为研究计划演示口头试问及研究成果审查，各100点 | 2027募集要项第10–11页 |

- 一般、留学生科目配点合计300点（外语100＋专业100＋面接100）；社会人200点（小论文100＋面接100）；在线200点（在线考试100＋研究成果100）。书类及相应考试综合判定，未公布合格最低总分。
- 题目倾向（体验记，非官方）：未获取可核验的本专攻原题正文或现场考生题型记述，不按专业名称虚构短答、论述的题数。

### 口述試験 / 面接

- **官方形式（现场）**：一般、社会人、留学生均面接100点，围绕出願书类口头试问；留学生明确日语。一般／留学生9:30集合，社会人11:00集合，中央校区16号馆6楼16606教室（以受验票最终通知为准）；13:30开始面接，个人时长未列。
- **官方形式（在线）**：Zoom或Google Meet，日语或英语演示10分钟，之后围绕演示与研究成果问答。PPT页数不限，约10页为建议；研究计划可含既往研究。PPT须出願期内交，7MB以内，另交毕业论文／学会论文等成果。考试前一天13:00日本时间连接测试并告知个别时刻；当天提前5分钟连线、共享幻灯片，学校不对考生网络设备问题负责。
- **実際に聞かれた内容**：尚未取得可确认属于本专攻、该路线的公开考生面接实录。

## 📝 详细信息

### 出願資格 / 定員

- 博士前期募集定员**10名**，为一般／社会人／留学生／在线等全部区分合计，不是每轮各10名。学制2年；博士后期3名及10月后期线上路线不能当作本修士独立秋入学。
- **一般**限日本国籍，大学毕业或2027/3/31前预计毕业、外国16年教育修了／预计、文科大臣指定、学位授予机构学士等；同等学力须个别资格审查。飞び级另按本研究科内规，须联系16号馆4楼研究科事务室确认，不能套工学飞び级科目。
- **社会人**为大学毕业、学士授予，或2027/4/1已满22岁的社会人，经同等学力认定；在职就学者须雇主签章承诺书。资格条文本身未统一规定工作经验必须若干年。
- **留学生**限非日本国籍，大学毕业／预计、学士授予、外国16年教育／预计；15年学历并经优秀成绩认定、同等学力等需资格审查。一般的同等学力、社会人个别资格、留学生及在线第4／6项，均须在出願截止**3周前**向拟导师或专攻主任提交个人调书及对应证明；不是工学的至少1个月。
- **在线**资格含大学毕业／预计、学士、16年教育、15年及同等学力认定等，并未沿用普通一般的日本国籍限定；但受官方10月“国外”、3月“国内”标注约束。须事先与研究科确认适用所在地及出願方式。
- 所有路线愿书邮寄前必须就研究主题与导师事前商议并取得承认，交「指導予定教員承諾書」，由导师确认、盖章、勾选指导方法；从2027正式博士前期16人名单选1人填愿书和研究计划封面。
- 基本材料：愿书及3个月内照片、履历书（高中起）、大学毕业或预计毕业证明原本、成绩原本、改名证明（如适用）、指定封面研究计划、推荐书、导师承诺书、个别资格合格证明（如适用）。留学生另交日语能力证明（有条件豁免）。一般及社会人推荐书无法提交时不强制；留学生及在线推荐书列为提交资料，不能套用前者豁免。
- **研究计划书**：一般／留学生／在线用样式2，日语横写、文档软件制作、A4 **1200字以上**，写①志愿理由②研究主题、目的意义及开展方法③修了后进路，附印刷23页封面。社会人用样式3（25页封面），1200字以上，写社会活动经历、动机及研究计划。没有统一“1200字以内”的上限。

### 学费减免、给付与贷款

- 本校学部毕业者可由专攻推荐入学前预约给付：本专攻博士前期1名，标准修业年限授业料等全额，约5月决定、不公开招募。普通给付为半期授业料等、1年，前期各专攻在籍人数2成以内，例年10月公募、12月决定，并非全员自动减免。
- JASSO第一种修士月5万／8.8万，第二种5／8／10／13／15万，依学业、家计及在留条件审查。授业料后付为无息贷款，须在入试出願时同时提交希望、延纳和除籍猶予3种表格，入学后正式申请；教育环境费、会费仍缴。持“留学”者不能按日本学生贷款资格自动申请。
- 2027预约采用初始材料及网填已经结束，已申请者的地方税同意书仍须2026/10/20必达；一般3月考生的出願时后付申请不可与这项10月预约截止混同。
- 2027独立学内推荐要项未取得；历史统计虽有学内推荐行，不能凭2024年表推定2027日期、资格与减考规则。

- 2024年度研究科入学宣誓式公告另记博士前期实际迎入1名；该人数不替换原入试表的手续2名。来源口径存在差异，须分开保留，不能把手续人数直接当作最终实际入学人数。
