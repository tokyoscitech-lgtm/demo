## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 一般選抜：没有英语笔试，出願时在网上出願系统上传「スコアシート」（英语外部考试成绩，细则见地学専攻別紙3），用它评价外国语（英语）。这一做法从 2025年8月实施的入试开始。
- 可以用的考试（専攻 2024/12/20 通知，针对 2025年8月入试）：TOEFL iBT（Home Edition 不行，不用 MyBest 分数）、TOEIC L&R 公开考试（IP 不行，线上 IP 也不行）、IELTS Academic（General Training 等不行）。团体考试的 TOEFL ITP、TOEIC IP 一律不受理。
- 有效期：以入学考试第一天为基准，往前2年以内受检的成绩。
- 提交的文件（同一通知）：TOEFL 交从 ETS 网站下载的 Test Taker Score Report PDF；TOEIC 交数字公式认定证或公式认定证；IELTS 交寄到本人手里的 Test Report Form。
- 可以同时交多种考试的成绩，一般選抜会换算后采用最有利的一个；换算表和配点官方没有公布。
- 出願时没有交成绩的不能参加考试，出願后不能补交或替换。
- 自己推薦：同样必须提交 TOEFL、TOEIC、IELTS 之一的成绩（入学考试第一天往前2年以内），作为学力评价的参考资料；日本国内的 TOEIC 公开考试只收数字公式认定证。
- 2027年度的細則写在地学専攻別紙3 里，本次没能读取该文件；上面的考试种类和文件要求来自 2024/12/20 的専攻通知，2027年度是否有改动未核实。
- 外国人留学生等特別選考：要项把英语技能列为评价项目之一，但没有规定成绩种类和最低分；是否加考外国语笔试由専攻判断。

### 日本語要件
- 要项没有要求提交日语成绩。外国人留学生等特別選考写明必要时会加考日语笔试，但没有给出等级或分数标准。
- 一般選抜的试题语言和可用的作答语言，要项正文没有写明。

- 合否判定：一般選抜综合书类选考、笔试、面接的结果决定，配点和合格线官方都没有公布。
- 志望分野在网上出願系统里选 (A)(B)(C) 之一，同一个講座可能同时出现在两个分野里（例如自然史科学在 A 和 C，環境動態論和自然災害学在 A 和 B），选哪个分野决定了笔试能选答哪些题。
- 题型和时间与上一年度（2025年8月实施）相同：同样是 90 分钟、共通 1 题＋志望分野 1 题。
- 题目倾向：没有找到地学専攻的受験体验记，这里不写非官方的出题倾向；専攻自己公布的 2025、2026年度出题意图可以在过去问页看到。

### 口述試験 / 面接
- **官方形式**：一般選抜对全体考生进行面接（2026/8/7），不按笔试成绩筛人；时长、语言、配点和提问内容要项都没有写。自己推薦的面接要考查的是不限于专业、也包括其他领域的基础学力，结合学部成绩、志望理由书、研究计划书综合判定。外国人留学生等特別選考的面接日期和方式在出願后通知。
- **実際に聞かれた内容**：没有找到地学専攻的面接体验记。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：一般選抜（2027年4月入学）地学専攻 32 名，这个数字包含外国人留学生等特別選考的名额；自己推薦为「若干人」，没招满的名额并入一般選抜；2026年10月入学只有外国人留学生等特別選考，募集「若干人」。第2次募集的人数未公布。
- 出願资格主要是：大学毕业或 2027年3月前预计毕业；取得学位授与機構的学士学位；在外国完成16年学校教育；在外国3年以上的课程取得相当于学士的学位（报一般選抜须在 2026/6/10 前联系大学院教務係）；在学3年以上成绩优秀者、飞入学者、个别审查认定且满22岁者须事前审查。
- 事前审查：一般選抜的申请书类 2026/6/17（周三）必达，6/25 通知结果（已过）；特別選考的事前审查截止日另行通知。
- 自己推薦的条件：学业成绩和人品都优秀；合格后确实入学；出願前必须和志望研究室的教员充分商量入学后的研究计划。東北大学理学部地圏環境科学科、地球惑星物質科学科的毕业（预定）者不能报自己推薦。没有 GPA 的数值门槛。可以和一般選抜并愿。
- 外国人留学生等特別選考的对象是没有日本国籍也没有永住许可的外国人留学生，以及在外国大学受教育的归国学生。出願前必须先得到受入志望教员的内诺，再由该教员联系専攻長，之后才能出願。
- 出願书类（一般選抜，网上出願系统上传 PDF）：入学願書（系统内填写）、照片数据、检定料汇款凭证、成绩证明书、毕业（预定）证明书、在职者的受験许可书、外国人的护照或在留卡复印件、地学専攻調査票（別紙2，填写方法见別紙1）、スコアシート（別紙3）。
- 出願书类（自己推薦）：除共通书类外，志望理由书（A4 1页，两部分各约400字，格式自定）、研究计划书（A4 1页，约800字，格式自定）、英语成绩。
- 別紙1（調査票填写方法）和別紙3 本次没能读取，調査票上要不要写志望研究室和教员名未核实。
- 出願方式：只能网上出願，必须在截止时刻前完成出願操作。受験票从系统下载打印，考试当天带去。
- 检定料 30,000 日元。国费外国人留学生和 2026年度日本国内风水害的受灾者可以申请免除。
- 入学料 282,000 日元；授業料日本人学生年 535,800 日元，外国人留学生年 900,000 日元（2027年4月入学，均为预定额）。
- 考场是東北大学大学院理学研究科（仙台市青葉区荒巻字青葉6番3号）。可带物品、迟到、缺考的处理要项没有写。
- 成绩开示：可以申请，截止 2027/3/18（周四），在开示请求表单里填写并上传受験票复印件；开示内容是把合格者、不合格者各自分成3档后告知本人所在的档。
- 咨询：東北大学理学部·理学研究科教務課大学院教務係，sci-in@grp.tohoku.ac.jp，Tel 022-795-6351；地学専攻事務室 Tel 022-795-6674。
