## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 8月入试：没有学内英语笔试，用外部英语考试成绩。本専攻只能提交 TOEFL iBT 或 IELTS（Academic）之一。TOEIC L&R 本専攻不受理（研究科里只有農学専攻和本専攻不受理）。考过多次也只能交1份。
- 出願门槛（最低分）：TOEFL iBT 旧形式（2026/1/20 以前受检）55 以上、新形式（2026/1/21 以后受检）3.5 以上；IELTS 4.5 以上。达不到就不能出願。
- 本専攻的英语成绩不只是出願门槛，在之后的选考中也作为评价对象；换算方法和配点官方没有公布。
- 成绩须为 2024/7/6（出願开始日的2年前）以后受检。
- 提交方式：TOEFL 从 ETS 账户指定 DI 代码 9501（Kyoto University AAO）送分并在出願截止前送达，同时打印 Test Taker Score Report 提交；只认 Test Date 成绩，不认 MyBest。本次募集如持有 Test Taker Score Report 原件，可以提交原件代替送分。IELTS 通过考试机构送分到 Kyoto University，同时打印 Test Report Form 提交。
- TOEFL iBT Home Edition 可以；IELTS Indicator、IELTS Online 不受理。
- 出願时正式成绩单还没发下来的，先交说明书面和网上成绩页面的复印件，正式成绩单最迟 2026/8/4（周二）补交。
- 英语母语者、或用英语接受大学教育的人可能免除英语，须在 2026/6/16（周二）前向大学院教務掛咨询（已过）。
- 第二次募集·私費外国人留学生特別選抜：同样要交外部英语成绩，最低分与8月入试相同；本専攻仍只收 TOEFL iBT 或 IELTS；成绩有效期的起算日以新要项为准。

### 日本語要件
- 要项和外国人留学生追加书类都没有要求提交 JLPT、EJU 等日语成绩。
- 8月入试对外国人留学生没有任何特别照顾（不能带词典）；私費外国人留学生特別選抜可以带1本母语—日语的纸质词典（电子词典不行）。要项没有写明试题语言和可用的作答语言。
