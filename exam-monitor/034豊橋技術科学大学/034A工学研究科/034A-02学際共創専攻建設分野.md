## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 第1次募集、第2次募集、外国人留学生入试：
  - 不另设英语笔试，出願时全员提交外部英语成绩，计入综合判定，没有最低分：TOEIC L&R 公开考试（带照片的 Official Score Certificate 原件或数字公式认定证打印件）、TOEFL iBT（向 ETS 办理让大学在线确认，DI-CODE 9381）、IELTS（由实施机构把纸质 Test Report Form 直接寄到大学，可能需2个月以上）三选一。
  - 有效期：第1次募集收2024/7/1以后受检的成绩；第2次募集和外国人留学生入试收2024/12/1以后受检的成绩。
- IMDP：上次要求 TOEIC L&R、TOEFL iBT 或 IELTS（General Training 不收）2024年5月以后的成绩，在全英语授课的学校取得学位的可凭证明免交。

#### 日本語要件
- 一般入试（学力検査方式）：要项没有要求提交日语成绩。
- 外国人留学生入试：必须提交日语考试成绩证明原件，从日本語能力試験、J.TEST 実用日本語検定、BJT ビジネス日本語能力テスト、JPET 日本語能力評価試験、JPT 日本語能力試験 中任选一种；没有指定等级，成绩计入综合判定。
- IMDP：英语授课，要项没有要求提交日语成绩。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 基礎科目 | 不设笔试，以口述代替，与已修专门科目口述·面接连续进行 |  |
| 専門科目 | 已修专门科目口述＋面接，参考口述用资料 |  |

- 一般入试按学力检查（口述）、英语成绩、面接、成绩证明书等综合判定；外国人留学生入试另加日语成绩；社会人入试另加推荐书，并就业绩报告书口述。
- 入学者受入方针：建設分野希望学生关心建成环境与社会课题，并具备建筑或土木方面的实践能力。

### 口述試験 / 面接
- **官方形式**：第1次募集、第2次募集：10:30 起连续进行基礎科目口述、已修专门科目口述和个人面接，参考出願时提交的口述用资料（毕业研究·毕业设计汇总等）；外国人留学生入试：形式相同，在豊橋技術科学大学校内进行，不交口述用资料；社会人入试：另就业绩报告书口述；IMDP：只审书类。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：55名（建築・都市システム学専攻＝建設分野，一般入试名额，含書類選考方式、学力検査方式、社会人、外国人留学生、高専専攻科推薦全部区分）；第2次募集各区分若干名；外国人留学生入试建設分野若干名。
- 出願资格：大学毕业（含2027年3月预计）或外国16年学校教育等；个别入学资格审查（一般第2次 2026/10/27–11/2、外国人留学生 10/27–11/4）已截止（非独立出願）；外国人留学生入试须持有或能取得不妨碍入学的在留资格；書類選考方式只面向本校毕业生；社会人入试要求到2027年3月底在职约2年以上；IMDP 不收日本国籍和永住者，须能取得「留学」在留资格。
- 要提前准备的书类：外部英语成绩（IELTS 须提前2个月以上申请寄送）；一般和社会人入试的口述用资料（资料1 毕业研究·毕业设计或其他作品汇总，A4 5页以内，构想汇总也可，不收作品实物；资料2 研究生院期间的活动与抱负，A4 1页；每页写姓名）；外国人留学生入试另需出身大学的推荐书（在职者由所属长出具）、日语成绩证明原件、学歴記入票；中国的大学毕业或在读者另交学信网英文版学历电子注册备案表或在线学籍验证报告；社会人入试另需所属长推荐书·受験承諾書和业绩报告书（1,000字以内）；IMDP 需研究计划书和推荐信。
- 出願：先在 Web 出願系统（e-apply.jp/ds/tut）登记并缴费，再把书类用簡易書留·速達寄到教務課入試室，或在指定窗口日亲自提交，期间内必达；检定料 30,000 日元（便利店、Pay-easy、网银、信用卡；海外只能用信用卡），国费留学生内定者免缴；IMDP 上次先用邮件提交扫描件、再网上登记并邮寄原件。
- 并愿：2027年度一般入试和外国人留学生入试两份要项都没有说明一般第2次募集与外国人留学生入试能否同时报、第1次募集合格者能否再报第2次募集；出願后不能更改记载内容。
- 咨询：教務課入試室（〒441-8580 豊橋市天伯町雲雀ヶ丘1-1），Tel 0532-44-6581（平日 8:30–12:00、13:00–17:15），Fax 0532-44-6582，nyushi@office.tut.ac.jp；入学资格审查 Tel 0532-44-6583；需要考试照顾的在出願前先联系入試室；IMDP 先与希望的指导教员联系。
