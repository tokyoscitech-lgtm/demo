## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般入试（A日程、B日程都要）：
  - 不另设英语笔试，用 TOEIC L&R 或 TOEFL iBT（含 Home Edition）成绩评价，B日程配点 100 分。
  - 本系要求出願时必须提交在线版成绩单打印件，交后不能更换、不退还；截止前没交的没有受験资格。
  - 只认 2024/6/11 以后受检的成绩。TOEIC 须为带真伪确认 QR 码的数字公式认定证 PDF 打印件；TOEFL 须为 Test Taker Score Report PDF 打印件，并在 ETS 账户为该成绩设定 DI code G179。ETS 邮寄的纸质成绩单、TOEFL ITP、TOEIC IP 等团体考试不受理。
  - 要项附録3的换算基准：TOEFL iBT 先按对照表换成 PBT，再用（PBT－296）÷0.348＝TOEIC L&R，例如 iBT 80→PBT 550→TOEIC 约 730，iBT 100→PBT 600–603→TOEIC 约 874–882（TOEIC 300 分以下不适用）。
- IGP(C)：申请材料不要求英语成绩；面试和考试用英语进行。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 筆答试题只用日文出题，可用日语或英语作答；A日程口述和 B日程口頭試問用日语提问，可用日语或英语回答；志望理由书可用日语或英语写。
- IGP(C) 全英语授课，不要求日语。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 数学（300分） | 微分積分 1 题＋線形代数 1 题，必答；写出推导过程，不能用计算器 | 9:30–11:00，90分钟 |
| 論述（200分） | 情報通信领域的论述题 1 题（含数个小问），必答；只写答题纸正面，至少用一个图或表，图表不超过纸面一半 | 11:30–12:30，60分钟 |
| 英语（100分） | 用外部成绩评价，见英語要件 | |

- A日程：系根据出願书类决定受験资格者（考生不能自选），凭出願书类和口述结果综合决定“合格内定”；A日程不合格可以考 B日程；出願资格(9)（飞级）只能考 B日程。
- B日程：总分 600，筆答成绩上位者获口頭試問资格，按筆答和口頭試問成绩综合判定，A日程口述结果不计入；每位教员的指导学生数有上限。
- 2025年实施的出题（出題の意図归纳）：微分積分以一组积分为线索，用到合成函数求导、奇偶对称、分部积分、不等式估计和极坐标二重积分，最后求高斯积分；線形代数考复向量内积与范数、二次式最小化并证明柯西–施瓦茨不等式；論述让考生就人工智能在情報通信领域的一个应用课题论述其重要性、解决方案、与其他方法比较、局限和社会影响。

### 口述試験 / 面接
- **官方形式**：A日程：口述試験，个人面试，考查学力和适性，日语提问、可用日语或英语回答；B日程：口頭試問，个人面试，考查学力和适性，日语提问、可用日语或英语回答，只有筆答成绩上位者参加，详细安排邮件通知；IGP(C)：系或志望导师安排的英语面试和/或考试，原则线上。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：情報通信系受入可能予定人数 71 名（2026年9月和2027年4月入学合计，工学院合计 477 名）；IGP(C) 各系若干名。
- 出願资格：大学毕业（含预计）或外国16年学校教育等，(9)(10)(11) 项须先做资格审查；只能报一个系，出结果前不能再报理工学系其他募集（含 IGP(C)）；外国籍考生选9月入学须出願时住在日本且在留资格有效到 2026/9/28，否则只能4月入学；志望教员最多10位，不愿分到所填以外教员的在「系・課程の指定する入力項目」写「志望しない」。
- 要提前准备的书类：志望理由书（所定样式，第一志望研究室的研究计划，约1,000字，日英均可）；载有 GPA 的成绩证明书（开不出的在入力項目写明）；TOEIC L&R 或 TOEFL iBT 成绩单（出願时必交）；IGP(C) 另需导师同意书（10/4 前交入試課）、研究计划和推荐人直接提交的推荐信。
- 出願：一般入试网上登记缴费后把书类以速達書留寄入試課（6/10 必达），检定料 30,000 日元＋手续费 990 日元；IGP(C) 全程网上提交，检定料 30,000 日元（信用卡）。
- 并愿限制：只能报一个系；同一入学期不能报理工学系修士的多个募集，一个出願结果出来之前不能再报理工学系其他募集。
- 咨询：出願手续问入試課大学院入試グループ（inquiries.grad.se@adm.isct.ac.jp）；本系入试内容问情報通信系入試担当 小池 康晴（ict_inquiry@ict.eng.isct.ac.jp）。
