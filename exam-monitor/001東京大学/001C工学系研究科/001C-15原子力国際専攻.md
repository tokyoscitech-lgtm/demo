## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 冬入试（日程B）：
  - 提交 TOEFL iBT（含 Home Edition）或 TOEIC L&R 公式成绩，专攻不另设英语笔试；提交截止 2027/1/19（周二）。
  - TOEFL iBT：按研究科 TOEFL 提交要项，ETS 送分（DI 代码 8596，Department 代码 99）、在 WEB 出願系统登记 Appointment Number 和受检日、上传 Test Taker Score Report；只认 2025年2月以后受检的 Test Date Scores，不用 MyBest，ITP 等团体成绩不受理。
  - TOEIC L&R：只认 2025年1月以后受检；数字公式认定证上传并登记 URL，纸质公式认定证上传扫描件并把原件邮寄到専攻事務室（期限内）。
- 夏入试：只收 TOEFL iBT，2024年9月以后受检（已截止）。

#### 日本語要件
- 要项没有要求提交日语成绩。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 数学 | 冬入试（日程B）：微分方程、线性代数、概率统计等领域出3题；夏入试：研究科共通试题6题选3 | 冬 10:00–12:00，120分钟；夏 13:00–15:30，150分钟 |
| 小論文 | 阅读给定文章、提取信息，针对设问写出逻辑一致的回答，考逻辑思考能力，不考原子力专业知识 | 冬 13:30–15:00，90分钟；夏 9:30–11:00，90分钟 |

- 按笔试、口述和提交书类（成绩证明、英语成绩等）综合判定；出願者多时先做书类选考，书类选考不合格也不退检定料。
- 冬入试笔试后 15:00–15:20 做研究グループ希望调查和口述说明。

### 口述試験 / 面接
- **官方形式**：冬入试（日程B）：约20分钟口头试问，问基础知识和学习意愿，地点在口述说明时指示；夏入试：同样约20分钟口头试问；特別口述試験（学力特别优秀、以本専攻为第一志望者自愿申请）通过者免笔试（已结束）。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：22名（研究科要项专攻别表）。
- 出願资格：大学毕业（含 2027/3/31 前预计）或外国16年学校教育等；冬入试个别入学资格审查 2026/10/27（周二）截止（非独立出願）；冬入试只能 2027年4月入学；夏入试合格者不辞退入学不能报冬入试，也不能同时报本研究科两个以上専攻。
- 要提前准备的书类：TOEFL 或 TOEIC 公式成绩；安全保障輸出管理チェックシート（外国籍、双重国籍或入学前所属机构在海外者）；日英以外语言的证明须附出身大学盖章的英译。
- 出願：只能在 WEB 出願系统上传 PDF；检定料 30,000 日元，日本政府奖学金留学生免缴。

### 研究室 / 指導教員
- 事前連絡要否：不要。修士考生可自愿向希望指导的教员咨询；入学后研究室按志望优先、成绩顺序配属，合格发表后通知。
