## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各日程相同：不另设英语笔试，用 TOEFL iBT（含 Home Edition）成绩评价。
- 送分：向 ETS 申请把 Institutional (Official) Score Report 送到研究科（DI code 1113），其他代码无效；出願时在 WEB 出願系统里填写 Appointment Number、受检日和分数，不必交 Test Taker Score Report。
- 有效受检期间（向 ETS 申请送分也须在此期间内完成）：A日程 2024/8/1–2026/6/13（已过）；B日程 2025/2/1–2026/11/15。
- 送过多次的，出願时只指定一次。TOEFL ITP 不受理，MyBest Scores 不采用，其他英语成绩不能代替。
- 要项和専攻案内都没有写最低分和配点。専攻可能按 TOEFL 成绩做事前选拔，是否实施写在受験者心得里；书类选考不合格检定料也不退。

#### 日本語要件
- 要项和専攻案内都没有要求提交日语成绩（JLPT 等），外国人考生走一般选拔也不用交；研究科不设单独的外国人留学生特别选拔（本専攻的外国人特別選抜实施到 2023年度为止）。
- 専門科目试题日英并记，除题目另有指定外可以用日语或英语作答；口述语言由考生在日语和英语中自选。
- 从初等、中等教育起都在日语以外的语言环境中受教育的课程毕业（预定）者，出願前须接受出願对象审查：B日程截止 2026/10/7（已过）。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：A日程（2026年10月入学＋2027年4月入学）17名，B日程（2027年4月入学＋2027年10月入学）若干名（要项募集人员表本専攻只有这两格）；成绩不足时可能录不满。
- 出願资格：大学毕业或 2027/3/31 前预计毕业、在外国完成 16 年学校教育、在外国取得相当于学士的学位（3 年以上课程）、经个别入学资格审查认定且 2027/3/31 满 22 岁等 6 项之一。个别入学资格审查申请截止：A日程 2026/5/7、B日程 2026/10/7（均已过）。
- 入学时期：A日程可选 2027年4月入学或 2026年10月入学（限 2026年9月前毕业者）；B日程可选 2027年4月或 2027年10月入学；在 WEB 出願系统里选择，出願后不能更改。
- 志望填写：参照「教員並びに専門分野一覧」选专门分野和指导教员，最多填到第2志望，没有第2志望可以不填。
- 専攻指定书类（出願期间内 PDF 上传）：志望理由書（A4，2,000 字以内或英文 1,000 words 以内，写问题意识和想研究的题目）；研究計画書（A4，4,000 字以内或英文 2,000 words 以内，写研究背景·目的·内容·方法·预期成果·参考文献）。社会人出願者另有追加书类。
- 共通书类：入学願書（WEB 填写，含照片）、出身大学成绩证明书、毕业（预定）证明书、检定料缴纳证明、国费留学生证明书（仅国费生）、TOEFL 成绩；日语、英语以外的证明书附译文，原件在入学手续时提交。只能通过 WEB 出願系统出願。
- 检定料 30,000 日元，银行汇款（邮储银行除外）、便利店、信用卡、Pay-easy 均可；缴纳期间 A日程 2026/4/13–6/23（已过），B日程 2026/10/5–11/25。国费留学生免缴；缴后不退。
- 并愿：同一日程只能报研究科的一个専攻；要项允许有资格的人 A、B 两日程都报，本専攻案内没有另设限制。
- 2027年度起取消社会人特別選抜，并入一般入试；在职入学者在入学手续时交勤务单位的承诺书。長期履修学生制度从 2027年度入学者开始适用，须事先取得志望教员的同意，在入学手续时申请。
- 入学料 282,000 日元，授業料 年 535,800 日元（前期 267,900 日元），均为预定额；国费留学生免缴。4月入学者 2027年2月下旬收到入学许可通知、3月上旬办手续；B日程 10月入学者 2027年9月上旬。
- 咨询：出願手续问农学生命科学研究科教務課学生支援チーム大学院学生担当（〒113-8657 東京都文京区弥生1-1-1，Tel 03-5841-5010，daigakuin.a@gs.mail.u-tokyo.ac.jp）；専攻事务按要项「各専攻のお問い合わせ先」联系専攻。
