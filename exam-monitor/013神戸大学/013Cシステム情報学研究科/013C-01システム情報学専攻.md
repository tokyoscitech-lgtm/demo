## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 一般入試、外国人留学生特別入試、推薦入試都不设英语笔试，用 TOEFL 或 TOEIC 的成绩评价，配点 100 分。要项没有写换算公式，也没有写最低分。
- 收的种类：TOEFL iBT，或在日本国内实施的 TOEIC Listening & Reading 公开考试。
- 不受理：TOEFL ITP、TOEFL iBT Home Edition、TOEIC IP、在日本国外实施的 TOEIC。
- 有效期：一般入試·外国人留学生特別入試为 2024/8/24 以后受检的成绩；推薦入試为 2024/7/6 以后受检的成绩（即各自考试日前2年以内）。
- 提交方式：TOEFL 交成绩单原件和 A4 复印件，或交从官网下载打印的 Test Taker Score Report，同时办理把 Institutional Score Report 送到神戸大学（DI 代码 B071）；TOEIC 通过「公開テスト スコア確認サービス」用申请代码 00010408 提交。
- 英语成绩是全员必交的出願书类；没交时怎么处理，要项没有另写。
- 冬入试（第二期外国人留学生特別入試）：未公布（截至 2026-10-07）。上次（2026年1月实施）同样提交 TOEFL iBT 或 TOEIC L&R，有效期从 2024/1/21 起算。

### 日本語要件
- 一般入試：要项没有要求提交日语成绩。
- 外国人留学生特別入試：必须提交「在修学上没有障碍程度地掌握日语」的证明书，由现在所属的机构或指导教员出具；要项没有指定 JLPT、EJU 的等级或分数，也没有写免除条件。2027年度入试方法变更公告注明日语在口头试问中评价。
- 试题用什么语言、能否用英文作答，要项没有写明。

- 一般入試总分 400（数学 150＋専門科目 150＋外国語 100），口头试问只判合格或不合格，不计入 400 分；按笔答试验和口头试问综合判定。要项没有写单科最低线。
- 外国人留学生特別入試：数学 150 分和英语 100 分两次读取一致。口头试问一栏的数字和配点合计（250 或 500）两次读取不一致，未核实；要项的注记写明口头试问按合格或不合格判定。

### 口述試験 / 面接
- **官方形式**：一般入試有口头试问（2026/8/25 14:00 起），只判合格或不合格，要项没有写具体问什么、用什么语言。外国人留学生特別入試有口头试问（2026/8/25 10:00 起），问志望动机，并从考生出身分野和システム情報学分野里问与入学后想做的研究有关的基础知识，日语能力也在这里评价。推薦入試只有口头试问（2026/7/6 13:30 起，100分）。考场是神戸大学大学院工学研究科学舎（神戸市灘区六甲台町1-1），集合时间随受験票用邮件通知。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：システム情報学専攻 103 名，这个数字包含推薦入試（20名左右）和外国人留学生特別入試（若干名）；一般入試没有单列人数。第二期外国人留学生特別入試的人数未公布（上次为若干名）。
- 出願资格（一般入試）：大学毕业或 2027年3月底前预计毕业、学位授与機構授予学士、在外国完成16年学校教育、在外国大学3年以上课程取得相当于学士的学位、専修学校4年以上专门课程毕业、个别审查认定（2027/3/31 前满22岁）、大学在学3年以上成绩优秀等 11 项之一。
- 外国人留学生特別入試只面向持有或 2027年4月预计取得「留学」在留资格的外国人，资格为大学毕业、外国16年教育修了、外国3年以上课程的学士相当学位、个别审查认定等 5 项之一。
- 推薦入試要求学业和人品优秀、已得到指导预定教员的内诺、由出身大学的校长或学部长或指导教员推荐，并承诺合格后一定入学；另有高専连携协定的名额。
- 志望講座（研究室）在 WEB 出願时登记：一般入試必须选满第6志望；外国人留学生特別入試只选1个。
- 出願书类（一般入試）：照片数据（3个月内）、TOEFL 或 TOEIC 成绩、研究計画書（所定样式，A4 1页以内，10.5 号字：写第一志望講座的编号、已学内容 300 字以内、在第一志望講座的研究计划 600 字以内）、出願登记及书类确认表、成绩证明书和毕业（预定）证明书原件、在读或在职者的受験许可书。外国人留学生特別入試另加日语修得证明书、指导预定教员出具的受入内諾書、指导教授推荐信，研究計画書要与指导预定教员商量后写。
- 出願方式：先在 WEB 出願网站登记并缴检定料，书类一部分以 PDF 上传（不收 Word），成绩证明书等原件用書留速達邮寄（截止日 17:00 必达）或在窗口提交（9:30–16:00，12:00–13:00 除外）。要项和样式只在网上公开，不发纸质册子。
- 检定料 30,000 日元，在 WEB 出願网站支付，手续费自付。出願时是国费外国人留学生且入学后继续是国费的免缴。
- 研究科不做追加合格；出现缺额时可能用2次募集补充。要项没有写并愿限制。
- 中国的大学毕业者：除毕业证明书原件外，要在中国高等教育学生信息网（CHSI）申请英文的学位在线验证报告，让认证邮件直接发到研究科（csi-kyomugakusei@office.kobe-u.ac.jp）；预计毕业者毕业后补办，入学前没收到的可能取消合格。
- 外国人留学生的教育和研究活动受安全保障出口管理的限制；教员出具受入内諾書之前要先通过学校的事前审查，联系晚了可能赶不上出願。
- 个别出願资格审查的受理期间：推薦入試 2026/5/7–5/11，一般入試·外国人留学生特別入試 2026/6/9–6/11（均已过）；上次第二期为 2025/11/25–11/27，只收書留邮寄。
- 入学料 282,000 日元，授業料年额 535,800 日元（前期 267,900 日元）；入学手续在 2027年3月中旬，2月下旬通知详情。
- 考场规则：带受験票和打印好的「受験者心得」；手表只能用仅有计时功能的。因身体障碍需要照顾的人要在出願2周前提出。迟到和缺考的处理写在受験者心得里，要项正文没有。
- 研究生（研究科另有研究生募集要项）是另一条路线，这不是修士入试的要求。
- 咨询：システム情報学研究科 学務課教務学生グループ（〒657-8501 神戸市灘区六甲台町1-1），csi-kyomugakusei@office.kobe-u.ac.jp，Tel 078-803-6002。
- 成绩开示：一般入試的不合格者本人可在 2027/5/1–5/31（必达）申请，开示内容是不合格者中的名次档和笔答总分的得分率；合格者不能申请。

### 研究室 / 指導教員
- 事前連絡要否：不要（留学生特别选拔必须）。一般入試的要项没有要求出願前联系教员；外国人留学生特別入試和推薦入試必须事先取得指导预定教员的受入内諾書，要项提醒要留出充足时间与教员商量。
