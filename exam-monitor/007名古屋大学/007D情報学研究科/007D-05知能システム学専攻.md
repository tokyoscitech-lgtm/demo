## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 8月实施：研究科不设英语笔试，用外部考试成绩。可用 TOEIC L&R 公开考试、TOEFL iBT（含 Home Edition）、IELTS、Duolingo English Test 四种，须为 2024/4/1 以后受检的成绩；TOEIC IP 和 TOEFL ITP 不受理。
- 成绩通知书随出願书类提交，也可以后交：2026/7/21（周二）16:00 必达，用簡易書留寄到教務学生係（已截止）。到期没交的，英语按缺考处理。交了之后不能退回或换一份。
- 交复印件要亲笔写明与原件一致并签名或盖章；TOEIC 的数字公式认定证打印后同样要亲笔写明是其副本并签名或盖章。
- 换算：各考试分数按要项的对照表换成 100 分制。对照表的档位（TOEIC／TOEFL iBT／IELTS／Duolingo → 换算分）：580／61／5／80 → 59；649／69／5.5／95 → 66；729／79／6／105 → 74；807／90／6.5／120 → 82；867／100／7／130 → 88；956／109／7.5／140 → 97；986／111／8–9／150 → 100。
- 要项没有写英语的最低分，也没有写英语在总评里占多少分。
- 2月实施（上年度）：同样不办英语笔试，用上述四种外部考试成绩换算；上年度后交期限为 2026/1/22（周四）16:00 必达。本年度未公布（截至 2026-10-08）。

### 日本語要件
- 要项没有日语能力的门槛（没有要求 JLPT 等级或分数）。只要求考过日本语能力试验的外国人把合格证或成绩通知书的复印件一并交上。
- 出願书类可以用英文填写；专门科目笔试可以用英文作答。口头试问用日语进行，可以用英语回答。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 8月实施：专门科目（180分钟，配点官方未公布） | 解析·线性代数、概率·统计、程序设计（以 Python 3 为准）3 个科目，全部作答 | 2027募集要项 |
| 2月实施（上年度，2026/2/12）：口述考试（配点官方未公布） | 解析·线性代数、概率·统计 2 个科目，口头作答；没有笔试，不考程序设计。本年度未公布（截至 2026-10-08） | 上年度2月实施募集要项 |

- 配点官方未公布。8月实施按笔试和口头试问的成绩加上提交书类（含英语外部考试成绩）综合评定；笔试后被判断为不需要口头试问的，按笔试成绩和提交书类评定。
- 考试不能用计算器类，电子词典不能带。外国人留学生可以带 1 本日语与另一种语言之间的纸质词典。
- 笔试开考后 30 分钟内可以入场。
- 过去问归纳（2026年度·2025年8月实施）：解析·线性代数 3 大题（二阶常微分方程、二次型的特征值与极值、换元积分与复积分），概率·统计 2 大题（分组的组合概率与条件概率、概率密度函数的期望·方差与最大值的分布），程序设计 1 题（读一段给二维数组做连通区域标记的 Python 程序，填空并写出运行结果，不用从头写代码）。全部是计算题，要写过程；每科一张答题纸，可用日文或英文作答。

### 口述試験 / 面接
- **官方形式**：8月实施在 2026/8/6（周四）13:00 起线下进行。笔试结束后发一份「课题」，口头试问时要就这份课题做说明，考查逻辑说明能力；说明用的资料只能是 1 张 A4 单面的手写稿，用实物投影仪投到屏幕上。用日语进行，可以用英语回答。要项没有写配点，没有要求交研究计划书。口头试问迟到原则上不能参加。没被列入口头试问对象不等于不合格，要看合格发表。2月实施（上年度）是 2 个科目的口述考试加对研究内容等的口头试问，要准备 A4 一页左右的概要，同样用日语进行、可用英语回答。
- **実際に聞かれた内容**：没有检索到本専攻的口头试问体验记（截至 2026-10-08）。

### 出願資格 / 定員
- 8月实施的募集人员为 40 名。2月实施的人数未公布（截至 2026-10-08）；上年度2月实施为若干名。
- 出願资格：日本的大学毕业或 2027 年 3 月底前预计毕业、被授予学士学位、在外国完成 16 年学校教育、在外国取得相当于学士的学位（3 年以上课程，学校须经认证评价）等（1）–（10）项之一。
- 资格（8）（大学在读 3 年以上、成绩优秀者）和资格（9）（个别审查，2027/3/31 前满 22 岁）须事先受审，8月实施的申请截止为 2026/6/5（周五）16:00 必达（已截止），结果在 2026/6/26 前通知本人。
- 出願分两步：先在网上出願系统登录并缴检定料（8月实施为 2026/6/12–7/1），再把书类用簡易書留·速達邮寄，受理期最后一天 16:00 前必须到达；不收窗口递交和电子邮件。
- 出願书类（8月实施）：志願票和写真票（从网上出願系统彩色打印）、证件照数据、志願理由書（样式1，按本専攻的规定填志望教员名或研究小组代码，并写入学目的、想学的领域、选择本専攻的理由）、履歴書（样式2，写到 2027 年 3 月为止，不留空白期）、毕业（预定）证明书、成绩证明书（都不收复印件）、英语外部考试成绩通知书、线上考试誓约书（别纸1，线下考试也要交）、类型该当性自己申告書（别纸2）。毕业论文等能说明研究能力的资料可以自愿提交，官方建议提交。
- 外国人另交：住在日本的交在留卡正反面复印件和住民票；住在海外的交护照照片页等国籍证明。外国大学的证明书不是日文或英文的要附英译；中国的 CHSI 认证不被接受。
- 在职者要交单位的受験承認書；入学后打算辞职的交申出書。
- 检定料 30,000 日元，另付支付手续费；可用便利店、Pay-easy 的 ATM、网银、信用卡支付，住在日本国外的用信用卡。国费外国人留学生不用缴。
- 入学料 282,000 日元，授業料 年 535,800 日元；国费外国人留学生免缴。入学手续的通知在 2027 年 3 月上旬寄到出願时登记的地址，手续日预定在 2027 年 3 月中旬。
- 要项没有另设外国人留学生的特别选拔，留学生与一般考生同一场考试；要项里也没有写能否同时报多个専攻、8月合格者能否再报2月实施。
- 外国人留学生等受安全保障出口管理的审查：审查不通过的，即使合格也可能不能入学或研究活动受限，已缴的检定料不退。
