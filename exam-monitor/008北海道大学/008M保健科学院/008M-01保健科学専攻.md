## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 8月入试（一般選抜）：考试当天在考场统一参加 TOEFL-ITP（9:00–11:30），出願时不用交英语成绩。配点和合格水准官方不公布（说明会问答写明“非公表”）。
- 8月入试（社会人特別選抜）：当天不考 TOEFL-ITP，改为出願时提交 TOEFL 或 IELTS（アカデミック・モジュール）的得点票原件，须是入试实施月（2026年8月）往前2年以内受检的成绩。要项没有写最低分。
- 8月入试（外国人留学生特別選抜）：出願时提交 TOEFL 或 IELTS（アカデミック・モジュール）的得点票原件，有效期同上（2026年8月往前2年以内）。新考 TOEFL iBT 的，要让 ETS 在出願期间之前把成绩直送北海道大学，Institution Code 为 G036。要项没有写最低分，也没有写 Home Edition 是否受理。英文版要项把留学生可交的考试写成 TOEFL-iBT 或 IELTS Academic。
- 社会人特別選抜的英语处理方式，募集要项的一次读取结果与说明会资料、英文版要项不一致（后两者都写“不考 TOEFL-ITP、提交成绩原件”），这里按后两者记载。
- 变更点：令和9年度入试起，提交的成绩种类明确写为 TOEFL 或 IELTS（アカデミック・モジュール）。

### 日本語要件
- 8月入试（外国人留学生特別選抜）：必须提交日语能力考试的成绩证明。认可的考试共10种：JLPT、BJTビジネス日本語能力テスト、J.TEST、日本語NAT-TEST、STBJ、TOPJ、J-cert、JLCT、PJC Bridge、JPT。要项没有规定最低等级或分数，也没有写有效期。
- 以研究生身份在籍北海道大学的人，可以用北海道大学日语课程的受讲修了证代替；实在无法参加上述考试的要事先与教務担当商量。
- 8月入试（一般選抜·社会人特別選抜）：要项没有要求提交日语成绩。
- 线上面接原则上用日语进行，面接员判断日语问答有困难时会改用英语。小論文的试题语言和可用的作答语言，要项和说明会资料都没有写。

- 科目群别笔试的开始时刻，日文要项的读取结果是 14:00，英文版要项是 13:50，两者不一致，未核实。
- 题目倾向（体验记，非官方）：没有找到本専攻考生公开的体验记，无法归纳。可以直接看官方公开的令和8年度小論文、公衆衛生看護学、助産学试题。

### 口述試験 / 面接
- **官方形式**：8月入试（一般選抜·社会人特別選抜）在笔试当天下午面接，日文要项写 15:00 起；英文版要项写保健科学コース 14:00 起、看護学コース 15:00 起，两者不一致，未核实。面接的时长、配点和内容要项没有写，说明会问答写明“面接内容的细节不予回答”。8月入试（外国人留学生特別選抜）为线上面接，原则上用日语，必要时改用英语，前一天做连接测试。
- **実際に聞かれた内容**：没有找到本専攻的面接体验记。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员为 40 名（保健科学コース和看護学コース合计，不分コース设定员）。这 40 名里包含社会人特別選抜和外国人留学生特別選抜的人数；看護学コース的公衆衛生看護学、助産学、高度実践看護学科目群各为若干名。本年度只有8月入试一轮。
- 出願资格（一般選抜）：大学毕业或2027年3月底前预计毕业、由学位授与机构授予学士学位、在外国完成16年学校教育等。报看護学コース的人必须持有日本的看護師免许（含预计取得）。
- 出願资格（社会人特別選抜）：满足上述资格，并且到2027年4月为止在医疗、保健、福祉机构等有2年以上（可累计）的专业实务经验，入学后继续保持该身份。
- 出願资格（外国人留学生特別選抜）：满足上述资格的外国人，希望以国费或私费留学生身份入学。必须事先直接联系志望领域的教员并取得接收的内诺，出願时提交受入内諾書或指导教员的推荐书。
- 出願书类（一般選抜）：入学願書、受験票·写真票、志望理由書（约1,000字，可用学院网站的格式或自制）、毕业（预计）证明书、成绩证明书、受験票邮寄用信封、宛名票。要项没有要求研究计划书。
- 出願书类（追加）：社会人特別選抜另交就学承諾書、在职期间证明书和英语得点票原件；外国人留学生特別選抜另交推荐书（亲笔签名）、受入内諾書或指导教员推荐书、英语得点票原件、日语能力成绩证明、学费保证书类、护照或在留卡复印件、检定料支付完成通知邮件。
- 出願方式：一般選抜·社会人特別選抜只能用冊子体募集要项里装订的出願用纸，只有 PDF 不能出願；提交方式是到保健科学研究院事務課窗口，或用書留速達邮寄并在出願期间内必达。外国人留学生特別選抜先在网上出願系统录入（登录密码要发邮件向教務担当索取），支付检定料，再把书类在期间内寄达。
- 检定料 30,000 日元，另收事务手续费 500 日元；可用信用卡、Pay-easy、便利店、中国银联网上支付、银行转账。国费外国人留学生不用缴。
- 个别出願资格审查：属于出願资格（9）（10）（11）的人（大学在学3年、在外国完成15年课程、经学院个别认定学力者等）须事先受审，申请期间 2026/6/15（周一）–6/19（周五）8:30–17:00（已过），结果 2026/7/3（周五）通知。
- 入学料 282,000 日元，授業料 前期 267,900 日元、年额 535,800 日元（均为预定额）。入学手续的日期随合格通知书告知。
- 长期履修制度：有职业、育儿或护理负担的人可以申请把标准2年的课程延长到最长4年修完，须事先申请。说明会资料写明有夜间开课，可以边工作边就读。
- 考场在北海道大学大学院保健科学研究院（札幌市北区北12条西5丁目），当天必须带受験票。要项没有写迟到和缺考的处理规定。
- 研究生（外国人留学生）是另一条路线，保健科学院另有研究生的募集要项。这不是修士入试的要求，但在籍研究生可以用校内日语课程修了证代替日语考试成绩。
- 咨询：北海道大学医学系事務部保健科学研究院事務課教務担当，〒060-0812 札幌市北区北12条西5丁目，kyomu@hs.hokudai.ac.jp，Tel 011-706-3318。
- 成绩开示的办法要项里没有查到记载。
