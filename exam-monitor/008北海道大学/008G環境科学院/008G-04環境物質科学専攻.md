## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 各轮都没有英语笔试，改为出願时提交外部英语考试成绩（自2024年度入试起实行）。
- 受理的种类：TOEFL iBT（含 Home Edition）、TOEIC Listening & Reading、IELTS Academic。不受理：TOEFL ITP、TOEIC IP、TOEIC Speaking & Writing、TOEIC Speaking、TOEIC Bridge、IELTS General Training。
- 成绩须为笔试日之前2年以内受检。只能交1份成绩，交多份的可能全部无效。
- 提交方法：TOEFL 要向 ETS 申请把 Official Score Report 直送北海道大学大学院环境科学院（DI code 8744），同时附 Test Taker Score Report 复印件；TOEIC 交 Digital Official Score Certificate 的打印件或公式认定证原件（原件考试当天归还）；IELTS 交 Test Report Form 复印件。
- 要项没有写最低分数线，也没有公布换算方法和配点；成绩作为书类审查的一部分用于综合判定。

### 日本語要件
- 要项没有要求提交日语成绩。出願书类用日文或英文书写。
- 要项和専攻入试页都没有写基礎化学试题和口述试验使用的语言（公开的过去问是日文），需要用英语受验的人在事前联系教员时确认。
- 学院的留学生说明页写明：修士课程可以只用英语完成学位；选修日语授课的科目需要 JLPT N2 以上。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 秋季入试·10月入学、春季入试的「基礎化学选拔」：基礎化学（120分钟，配点未公布） | 物理化学系3题＋有机化学系3题，共6题，全部作答 | 2027募集要项／専攻入试信息 |
| 秋季入试·10月入学、春季入试的「自己推荐选拔」 | 没有笔试。出願时交自己推荐书，考口述试验 | 2027募集要项 |
| 特别推荐入试、秋季推荐入试 | 没有笔试。自己推荐书、推荐信、成绩加口述试验 | 2027募集要项 |

- 秋季入试和春季入试可以在「基礎化学选拔」和「自己推荐选拔」里选一种，也可以两种都报（并愿）。4个コース用同一套选拔方式。
- 要项没有公布每题分值、总分和合格线；按笔试或口述、成绩证明书、英语成绩等书类综合判定。
- 2025年8月实施的基礎化学试题构成（据官方公开的过去问归纳）：试题为日文，每题一张答题纸，附常数和公式。第1题量子化学基础（光电效应、物质波、一维势箱、电子自旋）；第2题化学热力学与平衡（反应的 ΔH°·ΔS°·ΔG°、燃料电池电动势、解离平衡与 Kp）；第3题配位化学（Ni 配合物的结构与磁性、生成常数、立体异构、螯合效应）；第4题有机化合物的命名、构象与立体化学；第5题酸性·沸点·偶极矩的比较，以及用 IR、NMR 数据推定结构；第6题预测主产物和用箭头写反应机理。题型以计算、画结构式和简短说明为主。

### 口述試験 / 面接
- **官方形式**：自己推荐选拔、特别推荐入试、秋季推荐入试：根据自己推荐书发表7分钟，问答8分钟，问答里会考基础知识和研究意愿；发表用电脑和投影仪由校方准备，发表文件用 U 盘带去。基礎化学选拔：不做上述发表式口述，改为面接。
- **実際に聞かれた内容**：没有找到本専攻的公开体验记，实际问答内容不明。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：専攻入学定员 28 名。各轮人数（按要项募集人员表的栏位顺序读取）：秋季入试约20名；特别推荐入试（高专专攻科在学生）约5名；秋季推荐入试约5名；10月入学、春季入试各为若干名（要项注明“若干名”指数名至10名左右）。
- 専攻下设4个コース：生体物質科学、ナノ環境材料、光電子科学、環境触媒化学。
- 出願资格：日本的大学毕业或入学前一个月底前预计毕业；取得学位授与机构的学士学位；在外国完成16年学校教育；在外国取得相当于学士的学位（3年以上课程）；专修学校专门课程（4年以上）修了；大学在学3年以上的跳级者、满22岁经个别入学资格审查认定者等。后两类须事先接受资格审查，受理期间为 2026/5/8–5/14（已过）和 2026/11/6–11/12（春季入试用）；9月的审查期间不适用于本専攻。
- 各轮的对象：特别推荐入试只面向高专专攻科在学生；秋季推荐入试只面向日本国内大学的在学生·毕业生和高专专攻科修了者；9月底前毕业或取得学位的人可以在秋季入试里报“修士课程10月入学”。
- 共通出願书类：规定样式的入学願書（已定志望教员的写明研究组和コース）；照片2张（4×3 cm，3个月内）；成绩证明书原件；毕业（预定）证明书原件；TOEFL／TOEIC／IELTS 成绩；规定的回信信封（贴 410 日元邮票）和收件地址标签；检定料汇款凭证；在留卡复印件（在日者）或护照复印件；中国的大学毕业者要交学信网的学历认证报告（在读者交学籍在线验证报告）；居住在 EEA 的人另交个人信息处理同意书。
- 本専攻追加书类：选自己推荐选拔的人和推荐类入试都要交自己推荐书（A4，日文约1,500字；英文版要项写约600词），写至今的研究或学习经过和志望理由，所在学校没有毕业研究的可以写想做的研究课题；特别推荐入试要校长或学科长的推荐信，秋季推荐入试要学科长或指导教员（已毕业的为最后的指导教员）的推荐信，A4 1页左右，内容涉及化学学力、研究能力和态度。
- 出願方式：到窗口提交或用简易書留邮寄（期间内必达），信封上用红字写明是大学院出願书类。没有网上出願。书类不齐的不受理。
- 检定料 30,000 日元，用规定的汇款单缴纳，不退还。国费留学生、北海道大学特别助成项目的留学生、CSC 项目生免缴。
- 入学料 282,000 日元，授業料半年 267,900 日元（全年 535,800 日元），均为预定额。入学手续：10月入学者在9月上旬前办完；4月入学者的入学手续材料于2月中旬寄出，3月上旬前办完。
- 考场：札幌校区环境科学院（札幌市北区北10条西5丁目）。要项另列有东京会场（北海道大学东京办公室，千代田区丸之内 Sapia Tower 10楼），本専攻的部分轮次可用；秋季推荐入试想在东京受验的要事先联系，否则可能被安排在札幌。哪几轮设东京会场，在取得的要项文本里没能确认。
- 另有“海外在住外国人留学生特别选拔”（在本国在线受验；4月入学的在前一年11月考、10月入学的在6月考），只限指定的専攻·コース，本専攻是否在列要向志望教员确认，要项每年2月下旬公布。
