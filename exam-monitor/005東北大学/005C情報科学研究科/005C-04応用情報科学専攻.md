## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 上期入试的一般選抜和外国人留学生等選抜（2群·3群·6群）不设英语笔试，改为出願时提交 TOEFL iBT 或 TOEIC Listening & Reading 公开考试的成绩单，可以同时提交多种。1群（数学群）的一般選抜不需要英语成绩，只有外国人留学生等選抜需要。社会人選抜没有英语成绩要求。
- 成绩须为入学考试第一天起过去2年以内受检。TOEFL iBT Home Edition 在 2群·3群·6群都可以；团体考试 TOEFL ITP 和 TOEIC IP 不受理；IELTS 要项里没有提到。TOEFL 只用 Test Date 成绩，不用 MyBest 成绩。
- 提交方式：TOEFL 把 Test Taker Score Report 上传到 TAO，并让 ETS 把成绩直送研究科（DI code 2149），须在出願截止日的2天前送达；海外受检的 TOEIC 上传公式认定证并邮寄原件；日本国内受检的 TOEIC 上传数字公式认定证并填写其 URL。
- 配点和换算方法要项没有公布。出願截止日前没交的，2群·6群英语按0分处理；3群不交成绩单则不受理出願（或判不合格）。
- 3群的外国人留学生等選抜有最低线：Test Date 成绩低于 TOEFL iBT 79 分或 TOEIC 730 分的判不合格。2群·6群没有公布最低分。
- 英语为母语的考生须在出願截止2天前向教務係个别咨询。
- 下期入试：未公布（截至 2026-10-21）；上次下期同样是提交 TOEFL/TOEIC 成绩单。

### 日本語要件
- 要项没有要求提交日语成绩（没有 JLPT、EJU 的规定）。
- 作答语言：1群的専門科目有英文表记题和日英并记题，可以用日文作答；2群·3群·6群的要项没有写明试题和作答语言。出願书类接受日文或英文开具的证明。
