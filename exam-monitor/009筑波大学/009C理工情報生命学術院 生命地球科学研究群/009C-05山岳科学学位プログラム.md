## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 8月实施和1-2月实施的一般入学試験：不设英语笔试，必须提交外部英语检定成绩，配点 100 分。社会人特別選抜不需要英语成绩。
- 受理的考试：TOEIC Listening & Reading、TOEFL iBT（含 Home Edition）、IELTS Academic。不受理：TOEIC IP、TOEFL ITP 等团体考试、IELTS Online、成绩单的复印件。
- 提交方式：TOEIC 交公式認定証原件或デジタル公式認定証；TOEFL iBT 交受験者用スコア票；IELTS 用 Additional TRF（追加成績証明書）。
- 有效期：8月实施须为2024年8月以后受检，1-2月实施须为2025年1月以后受检。
- 换算：达到基准分的换算为英语满分 100 分——TOEIC L&R 860、TOEFL iBT 95、IELTS 7.0。低于基准分时怎样换算，要项没有公布公式。
- プログラム入试页提醒：一般入学試験的考生必须在出願前考完并拿到正式成绩。

### 日本語要件
- 要项没有要求提交 JLPT、EJU 等日语成绩，也没有针对外国人留学生的另设区分，留学生与日本学生参加同一场考试（募集人员里注明含外国人留学生）。
- 口述試験可以用日语或英语进行。専門科目试题的出题语言要项没有写明。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 8月实施·一般入学試験：専門科目（100分，60分钟） | 从地球科学、生物学、农学（生物资源）、环境科学各领域的多道题里选1题作答。プログラム规定每次只出当次考生志望领域的科目，所以考哪一科要在联系指导教员时确认。历年出过的科目：観光学、林政学、地形学、生態学、森林遺伝学·分子生態学、生物集団動態学、生態系生態学、森林生態学、草原生態学、土壌学、菌類学、大気科学、動物生態学、保全生態学、生物多様性学、水生植物学 | 2027募集要项英语版／プログラム入试页 |
| 1-2月实施·一般入学試験：専門科目（100分，60分钟） | 科目、配点、时间与8月实施相同；出哪些科目取决于当次出願者的志望领域（过去的1月期通常只出2–4科） | 2027募集要项英语版／プログラム入试页 |
| 社会人特別選抜（8月实施·1-2月实施） | 没有専門科目笔试，只有口述試験 | 2027募集要项英语版／プログラム入试页 |

- 一般入学試験的总分是 300 分：外国語 100＋専門科目 100＋口述試験 100。社会人特別選抜只有口述試験 100 分。要项没有公布合格最低分和具体判定方法。
- 専門科目笔试从2020年10月期入试开始实施。2026年8月实施出的科目是：林政学、地形学、生物集団動態学、生態系生態学、森林生態学、草原生態学、菌類学、動物生態学、保全生態学、生物多様性学。
- 题目倾向（体验记，非官方）：没有找到本プログラム的考生体验记，暂无可写的内容。

### 口述試験 / 面接
- **官方形式**：8月实施的一般入学試験先用3分钟发表研究计划，再就专业、基础知识和将来的打算接受提问；1-2月实施的一般入学試験是5分钟发表至今的研究和研究计划，之后同样提问。配点 100 分，可以用日语或英语。面接室里可以用白板或黑板，不能带资料和电脑。
- 社会人特別選抜（两个轮次相同）：每人约20分钟——8分钟发表社会经验、研究经历和研究计划，12分钟问答；用自己带的笔记本电脑投影（HDMI 或 15针 Mini D-Sub 接口），12:50–13:10 试机，并用查过毒的 U 盘带 PDF 备份。
- 住在海外的考生可以申请在线受验，须在出願期间内提交申告書和誓約書；附件的在线入试日程表没有写明各行对应哪个学位プログラム，本プログラム的具体做法没有读到。
- **実際に聞かれた内容**：没有找到本プログラム的面接体验记，实际提问内容不明。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：8月实施 一般入学試験9名、社会人特別選抜1名；1-2月实施 一般入学試験4名、社会人特別選抜1名（各项都含連携大学院方式和外国人留学生）。入学时期都是2027年4月。7月实施（推薦）本プログラム不举行。
- 变更点：8月实施一般入学試験的募集人员原为14名，本年度因学際創成学術院的设立改为9名。
- 出願资格：大学毕业或2027年3月底前预计毕业、被学位授与機構授予学士学位、在外国完成16年学校教育等全学共通的各项之一。属于资格(6)的要事先确认；属于资格(9)（个别出願资格审查）的须在期限前申请——8月实施为 2026/7/3（周五）（已截止），1-2月实施为 2026/11/24（周二）。
- 社会人特別選抜另外要求：到入学前一个月为止有1年以上的社会经验（在企业、官厅、教育机构工作，家务等也算）。报社会人枠的人要事先告诉志望指导教员。
- 出願书类：毕业（预计毕业）证明书、成绩证明书（原件）、外国大学毕业者的学位取得证明书、外部英语成绩（一般入学試験）、检定料缴纳证明、在学或在职者的受験·就学承認書、国费留学生证明书（符合者）。研究计划在 Web 出願时录入（一般和社会人都要）；有公式或图表录不进去时另交研究計画書——格式自由，开头写志望学位プログラム名、姓名、志望指导教员名，日文约2000字或英文约1000词。社会人还要交活动·研究业绩目录及证明材料。
- 外国人留学生要从指导教员处取得出口管理用的「リファレンス番号」，出願时录入。
- 书类装进角形2号信封、贴上 Web 出願后下载的宛名シート，用書留寄到；受験票要在 Web 出願期间内自己下载打印，考试当天带去。

- 受験者心得在考试前一周左右登在入试站的「お知らせ」栏。
- 咨询：山岳科学学位プログラム入试担当 sangaku-admissions@ml.cc.tsukuba.ac.jp，プログラム事务室 Tel 029-853-5812；出願资格方面问大学院入试担当 admission.grad@un.tsukuba.ac.jp。
