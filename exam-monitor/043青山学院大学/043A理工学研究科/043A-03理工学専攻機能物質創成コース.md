## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 9月入试：
  - 不收外部成绩，由大学自己出英语笔试（共通科目，90分钟）：以较长的英文阅读理解为中心，另有英作文、惯用语、词汇。
- 外国人留学生入试：
  - 出願时提交 TOEIC L&R Official Score Certificate/Report、IELTS Test Report Form、TOEFL iBT 之一，原件，2年以内取得；没有最低分。英语为母语者免交。
  - 用 TOEFL iBT 的，须让 ETS 把正式成绩寄到本校（DI Code G314），同时本人提交 Test Taker Score Report 复印件或从 ETS 账户打印的成绩。

#### 日本語要件
- 9月入试：要项没有要求提交日语成绩。
- 外国人留学生入试：须提交 JLPT N1 合格证明（载有得分的合否结果通知书等），或 EJU「日本語」（不含记述）240分以上的成绩确认书，二选一，原件，2年以内取得。理由是博士前期的讲义、演习、实验和研究指导都用日语进行。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 英語（共通科目） | 较长的英文阅读理解为中心，另有英作文、惯用语、词汇 | 10:00–11:30，90分钟 |
| 数学（共通科目） | 線形代数、一变量及二变量的微分·积分、微分方程式 | 13:00–14:30，90分钟 |
| 専門科目 | 选择必答：从物性物理学、固体化学、電子物性学中必选1题；选择题：从物理分野（力学、電磁気学、量子力学、熱・統計力学）、化学分野（有機化学、物理化学、無機・分析化学）、電気電子分野（電磁気学、電気回路、電波工学、情報・通信工学、電気電子計測、電子回路、制御工学、パワーエレクトロニクス）中合计选2题；除笔记用具外不能带其他物品 | 10:00–12:00，120分钟 |
| 外国人留学生入试：専門科目 | 第二次审查实施 |  |

- 9月入试：共通科目（英語、数学）＋専門科目（笔试、口述試問）＋书类审查综合选考；须参加全部科目，缺考1科即不合格。
- 外国人留学生入试：第一次审查（书类）通过者参加第二次审查（専門科目笔试＋口述試問），按书类、笔试、口述综合判定；须参加全部科目，缺考1科即不合格。

### 口述試験 / 面接
- **官方形式**：9月入试：口述試問，须就本人的毕业研究等做发表，10分钟以内，可用液晶投影仪；外国人留学生入试：第二次审查有口述試問。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：各コース若干名（9月入试、外国人留学生入试相同）。
- 出願资格：大学毕业（含2027年3月预计）或外国16年学校教育、外国3年以上课程取得学士相当学位等；9月入试按资格4–8出願的须先受资格审查（2026/6/24 截止，非独立出願）；外国人留学生入试限能取得或更新「留学」在留资格的外国人，资格3须先受资格审查（2026/8/28 截止，非独立出願），第一次审查合格后不能改志望コース；希望的指导教员属于其他コース时，出願时须向该教员说明（コース兼担）。
- 要提前准备的书类：中国的大学毕业者须交学位取得证明书，外国人留学生入试还须附 CHSI 英文认证书，并申请让 CHSI 在出願截止前把电子认证报告直接发到 in-rikou@aoyamagakuin.jp；外国人留学生入试另需推荐书（所定用纸）、研究计划书（日文约2000字或英文A4约1页）、JLPT/EJU 和英语成绩原件；非日英文证明须附公的机构认证的日文或英文译文。
- 出願：9月入试窗口（相模原校区）或書留邮寄，邮戳有效，没有网上出願；外国人留学生入试只收邮寄，邮戳有效；检定料 35,000 日元（9月入试可银行窗口汇款、便利店或信用卡，外国人留学生入试为便利店或信用卡）。
