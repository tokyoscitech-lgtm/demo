## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般・飛び級、特別選考：
  - 不另设英语笔试，外部英语成绩是出願资格，须满足其一：TOEIC L&R 550 以上、TOEFL iBT 57 以上（新评分为スコアバンド 3.5 以上）、IELTS Academic 5.5 以上；限出願开始日前2年以内受检。
  - 提交：TOEIC 交公式认定证（国内受检交数字认定证 PDF 打印件）；TOEFL iBT 由 ETS 直送（Institution code 2874）并交 Test Taker Score Report；IELTS 由考试机构直送并交 Test Report Form。
  - 不受理：TOEIC IP・S&W・Bridge；TOEFL iBT Home Edition・My Best scores・ITP；IELTS Online・One Skill Retake・General Training。成绩不达标时出願无效。
- 英语项目AO：
  - 交 TOEIC L&R、TOEFL iBT 或 IELTS Academic 成绩，没有最低分，建议 TOEIC 800、iBT 79（スコアバンド 4.5）、IELTS 6.5 以上；限出願开始日前2年以内。
  - 母语为英语者、英语为第一官方语言国家的大学毕业者免交；英语授课大学毕业者可交授课语言证明代替。Home Edition、My Best、ITP、IELTS Online 等不受理。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 一般・飛び級和特別選考的笔试、面接原则上用日语；特別選考的志願票须用日语填写。英语项目AO 用英语。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：一般・飛び級 90名（含其他入试名额）；特別選考（社会人・奨学生）若干名；英语项目AO 9月入学・4月入学各若干名。
- 出願资格：大学毕业（含预计）或外国16年学校教育等；本研究科只能报1个専攻；特別選考奨学生须已获研究科认可、覆盖所定在学期间全部学费的奖学金，社会人须大学毕业后2年以上实务经验且出願时在职；英语项目AO 中国专科毕业（未读本科）者不能报，修士正规课程与研究生不能同时报。
- 要提前准备的书类：一般：志願票①（志望动机・研究计划，A4 1页）、英语成绩、中国大陆毕业者由 CSSD 直接寄送的英文 Online Verification Report、日英以外语言证明附译文和公证文书；特別選考：所属长签名厳封推荐信、奨学金受給証明書（奨学生）；英语项目AO：两封厳封推荐信、英文申请表（2页以内）、CHSI 学历验证报告；国外居住的外国籍者另交 COE 申请书、经费支付书和存款证明。
- 出願：网上申请表（出願开始日10:00–截止日17:00）＋检定料＋书类邮寄，三项都须在期内完成，书类必达（国内简易书留，海外 DHL 等）；检定料 30,000 日元（英语项目AO 海外居住者 15,000 日元），OECD/DAC 名单最贫国・低收入国国籍且居住者可申请免除。
