## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 推薦·一般·社会人·私費外国人留学生选拔：不另设英语笔试，也不评价外部英语成绩；研究科共通的 TOEIC/TOEFL 条款只适用于理工学専攻，不适用于本専攻。
- 英語SP：出願时提交 TOEFL、TOEIC 等成绩复印件，或在英语授课的高等教育机构学习的证明；要求具备良好的英语水平。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 私費外国人留学生选拔：志望理由書（様式7）须本人用日语亲笔书写；小論文课题用日语出题，考查日语能力和专门学力。
- 英語SP：授课和研究指导用英语，出願书类可用日语或英语。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 一般·社会人：无笔试 | 成绩证明书、志望理由書＋口頭試問·面接（100）综合判定 |  |
| 私費留学生·生命科学：小論文 | 出願后研究科寄日语课题，按期提交；与成绩证明、指导教员推荐书、志望理由書一起选考 |  |
| 私費留学生·農林生産学：小論文 | 同上 |  |

- 一般·社会人：总分达到基准点（6成）者从高分起合格，同分同序。
- 推薦：農林生産学只审书类（100），要求专门科目「優」以上学分比率50%以上；生命科学的推薦只收本校生物資源科学部毕业预定者。
- 英語SP：凭出願书类和指导预定教员的面接选考，总分6成以上者按分数排序合格，同分同序。
- 题目倾向（官方过去问）：農林生産学小論文为农业主题论述，如土壤微生物与作物生产（氮循环、根圈微生物）、日本区域农业的特点与政策、花卉抗逆育种或东亚粮食安全（二选一）；2026年度附解答例。

### 口述試験 / 面接
- **官方形式**：生命科学：数名面接委员约20分钟口頭試問·面接（100），说明毕业论文等和入学后研究计划并质疑，看专门基础知识、学修意欲、理解力和表现力；農林生産学：约15分钟口頭試問·面接（100），评价项目相同；社会人与一般形式相同，均 13:00 开始；英語SP：数名指导预定教员校内或线上面接，线上受验须独处安静房间并提交网络面接确认书。
