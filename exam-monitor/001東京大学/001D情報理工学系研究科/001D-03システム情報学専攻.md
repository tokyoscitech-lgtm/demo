## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 夏入试、冬入试都必须提交 TOEFL iBT 成绩，研究科不另设英语笔试；TOEFL iBT Home Edition 可以，MyBest 分数不采用，其他种类的英语考试不受理。英语母语者也要交。
- 送分方式：必须由 ETS 直接送分（Institutional Score Report），考生自己的 Test Taker Score Report 不受理。收件方为 University of Tokyo IS&T，Institution Code 8445，Department Code 99。WEB 出願时填写该次考试的 Appointment Number 和受验日，只采用与之对应的那一次成绩；以前交过同一份成绩的也要重新送分。
- 截止：成绩须在出願截止前取得；成绩数据到达研究科的期限为夏入试 2026/6/30（已截止）、冬入试 2026/12/8。
- 有效期：夏入试为 2024/9/1 以后受验的成绩，冬入试为 2025/3/1 以后受验的成绩。
- 期限前研究科确认不到成绩或成绩不合规定的，TOEFL 提交视为无效，并失去口述试验等后续考试的受验资格。考后大约两周研究科才能收到数据，要留出余量。
- 官方没有公布最低分数线和英语的配点。

### 日本語要件
- 募集要项和専攻入试案内书都没有要求提交日语成绩。志望理由可以用日文或英文写；专门科目的过去问为日英并记。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 一般教育科目（数学）（夏入试，150分钟） | 线性代数、解析（微分积分、常微分方程等）、概率·统计三个领域共3题，全部作答 | 2027修士募集要项 |
| 专门科目“システム情報学”（夏入试，解答时间100分钟） | 信号処理、電子回路、制御 各1题，3题中选2题作答；对面考试 | 専攻入试案内书 |
| 专门科目的其他选择（夏入试） | 也可以改选“数理情報学”“コンピュータ科学”“電子情報学”之一代替“システム情報学”，日期、地点按对应専攻的入试案内书；本専攻的口述会尽量避开该科目的考试时间 | 専攻入试案内书 |
| 冬入试 | 不设笔试，数学改在口述试验里问 | 専攻入试案内书 |

- 夏入试的流程是：书类选考（志望理由）→ TOEFL、一般教育科目、专门科目、口述试验；只有书类选考合格的人才能参加后面的考试，缺考任何一项按弃考处理。
- 官方没有公布各科的配点和合格分数线。
- 出题倾向（体验记，非官方）：制御以古典控制为主，稳定性判别、奈奎斯特图、根轨迹常出，现代控制隔几年出一次；電子回路几乎每年都是运算放大器电路（滤波器、振荡电路，要能推导传递函数）；信号処理接近本校授课内容，外校考生较难预测，时间紧的人多选電子回路＋制御。数学里概率统计容易被忽视，建议至少把过去问的解法做熟。

### 口述試験 / 面接
- **官方形式**：夏入试在 2026/8/25 下午进行，详细时间表在考试期间掲示于専攻入试网站，会就志望理由等出願书类的内容提问；専攻入试案内页注明修士的口述试验在线上进行（案内书本身没有写线上还是对面，也没有写使用的工具）。冬入试的口述问数学和志望理由，范围包括微分积分、线性代数的基础、志望研究领域和システム情報学的基础，可能分多日进行，必须全部出席。
- **実際に聞かれた内容**：找到的体验记都没有记录口述的具体问题、时长和面试官人数（体验记，非官方）；按官方说明，应准备好把志望理由书的内容讲清楚，冬入试还要准备当场解答微积分和线性代数的基础题。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：夏入试 47 名；冬入试“若干名”。不分校内校外，没有校内优先。
- 出願资格：大学毕业或 2027/3/31 前预计毕业；在外国完成16年学校教育；在外国取得相当于学士的学位（修业3年以上的课程）；文部科学大臣指定者；取得学位授予机构的学士学位；经研究科个别入学资格审查认定且满22岁者等。个别资格审查的材料截止为夏入试 2026/5/13（已截止）、冬入试 2026/10/26（周一）。
- 入学时期：标准为 2027年4月入学；要项另有 2026年10月、2027年10月入学的资格日期规定。
- 出願书类（WEB 出願系统上传）：入学願書、证件照（JPEG）、大学成绩证明书、毕业（预定）证明书、TOEFL 送分、检定料缴纳凭证、安全保障出口管理检查表（外国籍等）、推荐书（冬入试的推荐人登记从 2026/11/11 开始，提交期限 2026/11/24 23:59）。日文、英文以外的文件要附译文。
- 専攻独有的提交物：志望理由，A4 或 Letter 约3页，日文或英文，字号约11pt，可用图表，每页写姓名；必须写第1志望的理由，第2志望以下可写可不写，可以列参考文献。夏入试、冬入试相同。
- 检定料 30,000 日元（手续费自付；国费留学生免缴）。冬入试的缴纳期间为 2026/11/3–11/17，检定料免除的申请期间为 2026/10/26–11/3。
- 入学料 282,000 日元，授業料 半年 267,900 日元（年 535,800 日元），均为预定额。2027年4月入学的手续期限预定为 2027/3/11（周四）。
- 同一次入试只能报一个専攻。夏入试合格者不放弃入学资格不能报冬入试。
- 受验票以邮件发送；冬入试到 2026/12/17（周四）17:00 还没收到的，才可以联系入试担当。
- 外国籍者须在入学手续前取得在留资格；受安全保障出口管理的限制，合格后也可能不能入学或研究内容受限。
- 咨询：研究科入试担当 johoriko.t@gs.mail.u-tokyo.ac.jp，Tel 03-5841-7926（平日 9:00–17:00）；専攻事务室只通过専攻入试案内页上的 Google 表单受理咨询。
