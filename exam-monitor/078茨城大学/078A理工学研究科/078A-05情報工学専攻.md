## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般入试、3年次特别入试、外国人留学生特别入试：
  - 不另设英语笔试，用外部成绩评价，配点 100 分；出願资格本身就要求在 2024/4/1 以后受验过 TOEIC 或 TOEFL。
  - 成绩单原件（附复印件）随出願书类提交，原件来不及的最迟在考试日前交齐；窗口出願当场退还原件，邮寄出願随受験票退回。
  - 接受 TOEIC 公开测试 Official Score Certificate（含数字认定证）、TOEFL iBT 的 Test Taker Score Report（只用 Test Date score，MyBest 不采用）、TOEIC IP、TOEFL ITP；IP 和 ITP 须附受验时做过本人确认的证明资料，本校实施的免附，出願期间内无法确认的不受理。
  - TOEIC IP 线上版还要附实施团体作成并盖公印的证明（载明姓名、生年月日、受験日、分数和防作弊措施）以及线上成绩 PDF 的打印件。
  - 换算：TOEIC 730 分以上为满分 100；未满 730 为 100×分数÷730。TOEFL ITP 先按（ITP－296）×2.874 换成 TOEIC 相当分；TOEFL iBT 先按研究科网站的「TOEFL-iBT→TOEFL-ITP 换算表」换成 ITP 再换算。没有出願最低分。
- 推薦入试、社会人特别入试：不需要提交外部成绩。

#### 日本語要件
- 一般选拔和外国人留学生特别选拔都不要求提交 JLPT、EJU 等日语成绩，要项也没有要求日本語能力証明書。
- 面接用日语进行；外国人留学生特别入试的判定项目含「日本語コミュニケーション能力」，为确认英语会话能力，面接中可能要求用英语回答一部分问题。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 専門科目（笔试） | 各轮次都不实施；专门学力改在面接的口頭試問中考查，总范围是算法、数据结构和 C 语言程序设计的基础与综合内容 | 2027博士前期募集要项 |
| 口頭試問（计入面接的 200 分） | 方程求解、数值积分等基础数值计算；排序、查找等基础算法；线性表·树·堆·栈·队列等基础数据结构；递归、数组操作、字符串操作、指针、结构体等编程技法 | 2027博士前期募集要项 |
| 英語（100 分） | 不另设英语笔试，按 TOEIC／TOEFL 的外部成绩换算 | 2027博士前期募集要项 |
| 推薦入试·社会人特别入试 | 面接不含口頭試問，不考专门科目；要项没有公布配点 | 2027博士前期募集要项 |

- 一般入试、3年次特别入试、外国人留学生特别入试：满分 300 分（面接含口頭試問 200＋英語 100），再结合学业成绩综合选考。

- **官方形式**：推薦入试和社会人特别入试为 10–15 分钟的个人面接、不含口頭試問；8月入试的一般入试、3年次特别入试、外国人留学生特别入试为 20–30 分钟的个人面接（含口頭試問）200 分，考查志望研究分野的理工学专门知识、学修·研究意欲以及含修了后进路在内的进学目的意识，用日语进行、可能要求用英语回答一部分问题，口頭試問提问时可能用文书等提示、作答时可能要求在黑板等处书写。
