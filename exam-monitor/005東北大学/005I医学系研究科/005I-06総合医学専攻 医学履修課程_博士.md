## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各轮次相同：不另设英语笔试，用外部成绩评价；可交 TOEIC L&R、TOEFL iBT（含 Home Edition）、IELTS Academic（纸笔或机考）、Duolingo English Test 之一。
  - 1月入试须为 2024/11/30 以后受检，2026/12/11 16:00 前提交（8月入试为 2024/6/29 以后受检）。
  - TOEIC 只收数字公式认定证 PDF，上传 TAO，纸质认定证扫描件不受理；TOEFL 指定 DI 代码 3332 送分并上传 Test Taker Score Report PDF，只用 Test Date 成绩，不用 MyBest；IELTS 寄 Test Report Form 原件；Duolingo 受检后选本研究科直送。
  - TOEFL ITP、TOEIC IP 不受理；可交多份，换算后取最高分；交后不能更换。截止前拿不到原件的，可先交网页成绩截图，之后只能换成同一成绩的原件。
  - 按一般换算方法计分，与口头试问综合判定。

#### 日本語要件
- 要项没有要求提交日语成绩。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：69名程度（1月入试要项，第1次·第2次·海外在住者合计）；8月入试按改组前医科学専攻实施，要项为130名程度。
- 出願资格：日本6年制医·歯·薬·獣医学毕业、外国18年课程（最终学历为6年制大学）、外国5年以上课程学士相当学位（须在资格审查期间请教务确认出身学校）、日本修士毕业经认定等；外国16年课程（须含医歯薬獣）或个别审查（满24岁）须先过入学资格审查（1月入试 2026/10/29–11/9 16:00，已截止，非独立出願）；外国人须事先向大学院教務係确认资格；海外在住者特别选拔限出願时住在海外者，不能与同期4月入学并报。
- 要提前准备的书类：志望分野指导教授的出願同意；外部英语成绩；志望动机·理由与抱负（所定用纸约1,000字）和学历·职历·研究历（TAO 输出），口试前交给指导教授；社会人特别选拔另交指導予定教授受入承諾書和所属长受験許可書。
- 出願：只能在 TAO 网上登录并上传书类；检定料 30,000 日元银行转账（原则上不接受海外汇款，海外在住者可事先申请信用卡支付），本校修士修了预定者和国费留学生免缴。
- 并愿：尚未核实是否可同时报考其他专攻或选拔类别。请以本年度募集要项或招生窗口答复为准。
- 咨询：具体招生窗口尚未核实。请从本页所列的募集要项或入试页面查找咨询方式。
