## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 8月入试（一般選考、特別選考相同）：
  - 不另设英语笔试，用 TOEFL iBT 成绩评价，配点 120 分，直接用 0–120 的得分（2026/1/21 以后受检的也取 0–120 素点）；只用 Test Date Scores，送了多份取最高分。
  - 只认 2024/8/2 以后受检的成绩；Home Edition、TOEFL ITP 不受理。
  - Test Taker Score Report 打印件 2026/7/16（周四）17:00 必达 Cクラスター事務区教務掛（機械工学群）；同时从 ETS 账户电子送分（DI 代码 B431），7/27（周一）前送达。
  - 没交成绩的英语按 0 分；英语母语者可事先咨询后交宣誓书（様式4）申请免交。
- 2月留学生入试：
  - 同样只用 TOEFL iBT，配点 120 分；只认 2025/2/9 以后受检的成绩，Home Edition、TOEFL ITP 不受理。
  - Score Report 打印件随機械工学群书类 1/26 必达；电子送分（B431）须在 2027/2/4（周四）前送达；没交按 0 分，英语母语者可申请免交。

#### 日本語要件
- 要项没有要求提交日语成绩。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 数学（180分） | 8月入试；体验记列出的复习范围：微积分、线性代数、常微分方程、傅里叶解析、复变函数、向量解析 | 9:30–11:30，120分钟 |
| 機械力学（150分） | 8月入试；工業力学、振動工学 | 13:00–14:30，90分钟 |
| 専門科目（400分） | 8月入试；流体力学、熱力学（含統計熱力学）、材料力学、制御工学 | 9:00–12:30，210分钟 |
| 2月留学生入试：専門科目（240分） | 機械力学、流体力学、熱力学、材料力学 | 9:00–11:00，120分钟 |

- 8月入试一般選考：总分 850（英语 120＋数学 180＋機械力学 150＋専門科目 400），原则上 425 分以上为有資格者（按难度调整），按成绩从高到低录取；有人辞退时由有資格者递补，最迟 2027/2/5 通知。
- 8月入试特別選考（只面向前後期連携教育プログラム高度工学コース志望者）：免笔试，英语 120＋口頭試問 730；予備選考没通过的可改考一般選考。
- 2月留学生入试：总分 600（英语 120＋専門科目 240＋口頭試問 240），原则上 300 分以上为有資格者，按成绩从高到低录取。
- 三専攻同一套题、统一判定；合格后按志望区分顺序和成绩分配研究室，进哪个専攻取决于分到的研究室。考场不能用尺、圆规、词典、计算器。
- 题目倾向（体验记，非官方）：近年试题题型相近，考生以十余年过去问为主准备；2025年8月整体难度上升，機械力学尤其难（1人提到）。

### 口述試験 / 面接
- **官方形式**：8月入试一般選考没有口试；8月入试特別選考：予備選考面接约20分钟，通过者参加口頭試問（730分），先发表研究计划，再就研究计划和专门知识提问，可事先接受指导预定教员的发表指导；2月留学生入试：口頭試問 240 分，问专门学识、志望理由和研究计划，可事先与指导预定教员讨论研究计划。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：本専攻 30 名（8月入试機械工学群三専攻合计 113 名，按群统一招生、合格后配属専攻，含前後期連携教育プログラム若干名）；2月留学生入试機械工学群若干名。
- 出願资格：大学毕业（含 2027/3 预计）或外国16年学校教育等；外国大学毕业者须先经 AAO 确认并邮件提交履历书（2月入试 2026/12/1 17:00 截止），资格(9)(10)个别审查 2026/12/8 17:00 必达（非独立出願）；2月入试只收外国籍、入学时持「留学」在留资格者；不能并报工学研究科多个入试区分；群方强烈建议日本的大学毕业的留学生考8月入试、其他留学生考2月入试。
- 要提前准备的书类：TOEFL iBT 成绩；有志望教员确认签名的「志望する指導教員調書」（8月入试留学生、2月入试都要）；2月入试另需指导预定教员作成的出願承諾書和教育プログラム志望調書；外国大学出身者须交推荐书（机构信头纸、亲笔签名）和学位证明。
- 出願：8月入试网上登记缴费后用書留速達邮寄书类；2月入试网上登记缴费并上传书类，機械工学群书类另寄 Cクラスター教務掛（書留）；检定料 30,000 日元＋手续费。
- 咨询：入试内容问 Cクラスター事務区教務掛（機械工学群），Tel 075-383-3521，090kckyomu2@mail2.adm.kyoto-u.ac.jp；出願手续问工学研究科教務課大学院掛，Tel 075-383-2040／2041，090kdaigakuin-nyushi@mail2.adm.kyoto-u.ac.jp。
- 并愿：旧版记录为「不能同时报工学研究科的多个入試区分」。本年度适用范围以对应募集要项为准。
