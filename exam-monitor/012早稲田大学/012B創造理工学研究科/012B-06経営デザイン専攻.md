## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 7月一般入试：英语不单独考试，外部考试成绩是出願资格之一。需达到以下任一项：TOEIC L&R 550 以上；TOEFL iBT 57 以上（新评分方式为スコアバンド 3.5 以上）；IELTS Academic 5.5 以上。
- 有效期：出願开始日（2026/5/25）的2年前以后受检的成绩。
- 提交方式（研究科共通，沿用 2026-10-07 的核对结果）：TOEIC 交公式认定证（日本国内受检的交数字公式认定证 PDF 的打印件），申请代码 00019702；TOEFL iBT 由 ETS 直送（Institution code 2874）并提交 Test Taker Score Report；IELTS 由考试机构直送成绩数据并提交 Test Report Form。
- 不受理：TOEIC IP、TOEIC S&W、TOEIC Bridge；TOEFL iBT Home Edition、My Best scores、TOEFL ITP；IELTS Online、One Skill Retake、General Training。
- 成绩不符合基准时出願无效。要项没有写英语成绩是否换算进总分。本専攻没有另设的英语要求。
- 特別選考入試（仅社会人・奨学生・社会人特別履修プログラム生）：英语基准与一般入试相同（TOEIC L&R 550／TOEFL iBT 57 或スコアバンド 3.5／IELTS 5.5），有效期为该轮出願开始日的2年前以后。

### 日本語要件
- 要项没有要求提交 JLPT 等日语成绩。
- 7月一般入试和特別選考入試的选考（笔试、面接）原则上都用日语进行；要项没有写可以用英语作答。
