## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 不另设英语笔试，用 TOEFL iBT 成绩评价；修士出願者全员提交，英语母语者也要交。
- 只收 TOEFL iBT 和 TOEFL iBT Home Edition 的 Official Score Report（ETS 直送）。MyBest scores 不采用，考生手里的 Test Taker Score Report 不受理；TOEIC、IELTS、TOEFL ITP 等其他成绩不能代替。
- 送分代码：University of Tokyo IS&T，Institution Code 8445，Division 选 Graduate Organization，Department Code 99；送到其他代码研究科查不到。出願时填写 Appointment Number 和受检日，只采用所填那一次的成绩，出願后原则上不能更换。
- 有效期：受检日在 2024/9/1 以后、出願截止日以前；成绩数据须在 2026/6/30 前到达研究科（已截止）。
- 成绩未按期到达或不符合要求的视为无效，失去数学、専門科目和口述的受験资格。
- 研究科和専攻入试案内书都没有规定最低分，配点和换算方法官方未公布。
- 配点（体验记，非官方）：2025年8月受验的内部生写 TOEFL 按 120 分计入；同年合格者自述成绩有 76、80、82 分。

#### 日本語要件
- 要项和専攻入试案内书都没有要求提交日语成绩（JLPT 等），一般选拔对外国人考生也没有日语门槛；研究科没有另设外国人留学生特别选拔。
- 数学试题日英对照；専門科目过去问有日文版和英文版。研究计划书可用日文或英文写。研究科写明只靠英语授课科目即可修满学分，研究指导也可用英语。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 一般教育科目（数学）（配点官方未公布，150分钟） | 线性代数、解析（微分积分、常微分方程等）、概率·统计三个领域各1题，3题全答；全研究科共通 | 2027修士募集要项 |
| 専門科目「コンピュータ科学」（配点官方未公布，180分钟） | 从情報数学、数値計算、離散数学、アルゴリズムと計算量、形式言語、論理学、プログラミング言語論、コンピュータアーキテクチャ、オペレーティングシステム、デジタル回路、機械学習中出4题左右，全部作答；题目可能用到 C 或 Java | 2027専攻入试案内书 |

- 选拔流程：书类选考 → 笔试（数学＋専門科目）与 TOEFL → 视需要进行口述，综合判定。书类选考不合格者不能参加笔试；各科配点、合格最低分和判定公式官方未公布。
- 配点（体验记，非官方）：2025年8月受验的三篇体验记一致写数学 300 分、専門科目 800 分（4题各 200 分）。
- 题目倾向（体验记，非官方）：2025年8月専門科目4题涉及形式语言、OS、硬件/电路、算法；数学当年偏难，微分方程题失分者多。
- 得分水平（体验记，非官方）：2025年8月合格的内部生一人成绩开示为数学 155/300、専門 356/800，另一人自估数学约 150/300、専門约 610/800；外部合格者称两科各六成左右可合格，合格线因志望研究室差别很大。

### 口述試験 / 面接
- **官方形式**：夏入试笔试后视需要进行口述，2026/8/27 线上，考查内容为専門科目；会议软件、每人时长、使用语言和配点官方未写，细节在 7 月下旬通知书类选考合格者。
- **実際に聞かれた内容**：（体验记，非官方）2025年8月两名内部生都写是 Zoom、3–5 分钟：一人被要求用1分钟说志望理由，再问研究抱负和毕业后出路；另一人被问自己研究的独特之处。2022年8月的外部生写几乎没被提问；2021年8月的外部生（文科出身）被问志望理由、本科经历、实习经历和确认算法知识的问题，研究计划书没被问到。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：夏入试 44 名（含 2026年10月和 2027年4月入学）；本専攻修士没有冬入试。
- 出願资格（满足一项）：日本的大学毕业或 2027/3/31 前预计毕业；在外国完成16年学校教育；在外国取得相当于学士的学位（修业3年以上）；文部科学大臣指定者；由大学改革支援·学位授与機構授予学士学位者；经个别入学资格审查认定、2027/3/31 时满 22 岁者。个别入学资格审查的材料截止为 2026/5/13（周三）（已截止）。
- 志望研究室：对照《各教員研究室紹介》，在 WEB 出願系统上最多填到第6希望。
- 出願书类：入学願書（系统内填写，上传3个月内拍摄的证件照数据）、出身大学成绩证明书、毕业证明书或预计毕业证明书、TOEFL 成绩（ETS 直送）、检定料缴纳证明、外国籍者等须上传的出口管制审查用检查表、専攻要求的研究计划书。修士不要求推荐信。日文或英文以外的证明书须附日文或英文译文。
- 研究计划书：A4 2页（参考文献不计入），日文或英文，写进入大学院后想做的研究内容；严禁剽窃。体验记（非官方）提到有人在书类选考阶段落选，研究计划书要认真写。
- 出願方式：全部在 WEB 出願系统完成，书类转成 PDF 上传，不需要邮寄；纸质原件在入学手续时提交。受験票用邮件发送，夏入试到 2026/7/17（周五）17:00 仍未收到的要联系入试担当。
- 检定料 30,000 日元，可用银行转账、便利店、Pay-easy 或信用卡支付，手续费自付，缴后不退；日本政府（文部科学省）奖学金留学生免缴，须上传证明。
- 并愿限制：同一期只能报研究科内一个専攻、课程或选拔区分；夏入试合格且不放弃入学的人不能报同年度冬入试。
- 入学时期：标准为 2027年4月入学；出願时提出希望的夏入试合格者可 2026年10月入学。入学手续截止（预定）：2026年10月入学 2026/9/24（周四）（已截止）；2027年4月入学 2027/3/11（周四）。外国籍者须在入学手续前取得可在大学院就读的在留资格。
- 入学料 282,000 日元，授業料 半年 267,900 日元（年额 535,800 日元），均为预定额；日本政府奖学金留学生免缴。
- 考场规则：考试开始 30 分钟前进入试验室；受験票一直放在桌上；手机关机。必须带黑色铅笔、自动铅笔、钢笔或圆珠笔，以及橡皮、卷笔刀（桌上式不可）、仅有计时功能的手表。
- 咨询：出願手续问情報理工学系研究科入试担当（〒113-8656 東京都文京区本郷7-3-1，johoriko.t@gs.mail.u-tokyo.ac.jp，Tel 03-5841-7926，平日 9:00–17:00，出願咨询原则上用邮件）；専攻内容问 admissions@is.s.u-tokyo.ac.jp。
