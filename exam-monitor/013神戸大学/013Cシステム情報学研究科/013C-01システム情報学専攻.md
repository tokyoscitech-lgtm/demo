## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各轮次都不另设英语笔试，用外部成绩评价，计 100 分：只收 TOEFL iBT 和在日本国内实施的 TOEIC L&R 公开考试；TOEFL ITP、iBT Home Edition、TOEIC IP、日本国外实施的 TOEIC 不受理。
- TOEFL 交成绩单原件和 A4 复印件（或打印的 Test Taker Score Report），并办理 Institutional Score Report 送到神戸大学（DI 代码 B071）；TOEIC 在出願期间内用「公開テスト スコア確認サービス」以申请代码 00010408 提交，没提交视为书类不全、不受理出願。
- 有效期：推薦入試为 2024/7/6 以后、一般入試·外国人留学生特別入試为 2024/8/24 以后、第二期为 2025/1/20 以后受检的成绩。

#### 日本語要件
- 一般入試、外国人留学生特別入試（第二期）：要项没有要求提交日语成绩。
- 外国人留学生特別入試（8月）：须提交能在修学上无障碍使用日语的证明书（现所属机构或指导教员出具，样式不限），日语能力也在口头试问中评价。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 数学（150分） | 线性代数、微积分、常微分方程、复变函数论；一般入試和外国人留学生特別入試（含第二期）共用 | 9:30–10:50，80分钟 |
| 専門科目（150分，仅一般入試） | 4分野选2（各75分）：制御工学（定常特性、稳定性、传递函数、波特图、时间响应、拉普拉斯变换等）、数理計画（线性规划、对偶、图论、博弈论、AHP、库存管理、动态规划等）、コンピュータシステム（数据表示、逻辑运算、组合·时序电路、计算机体系结构、操作系统等）、アルゴリズム・データ構造（计算量、哈希、堆、搜索树、排序、C语言等） | 12:30–13:50，80分钟 |
| 外国語（100分） | 用 TOEFL / TOEIC 成绩评价 | |

- 一般入試满分 400（数学 150＋専門科目 150＋外国語 100），外国人留学生特別入試（含第二期）满分 250（数学 150＋英语 100）；口头试问只判合格或不合格，按笔答和口头试问综合判定。
- 推薦入試不设笔试：英语成绩 100＋口头试问 100。

### 口述試験 / 面接
- **官方形式**：一般入試：口头试问，只判合否；外国人留学生特別入試（含第二期）：口头试问问志望动机，并从考生出身分野和システム情報学分野中问与入学后研究相关的基础知识，只判合否；推薦入試：只有口头试问（100分）。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：103名（含推薦入試20名程度、外国人留学生特別入試若干名）；外国人留学生特別入試（第二期）若干名；一般入試本年度不实施2次募集；变更点：2028年度（2027年实施）起推薦入試改为35名程度。
- 出願资格：大学毕业（含2027年3月预计）或外国16年学校教育等；外国人留学生特別入試（含第二期）只收持有或2027年4月前取得「留学」在留资格的外国人；短大·高专等学历须先受个别出願资格审查（第二期 2026/11/18–11/20 受理，已截止，非独立出願）；一般入試在 WEB 出願时须填满第6志望講座，外国人留学生特別入試只选1个講座；推薦入試须出身大学推荐、已得到内诺并确约入学。
- 要提前准备的书类：研究計画書（所定样式；一般入試为 A4 1页，写第一志望講座编号、已学内容300字以内、研究计划600字以内）；外国人留学生特別入試（含第二期）另需第一志望講座教员的受入内諾書（所定样式）和出身大学指导教授的推荐信，研究计划书须与指导预定教员商量后写；中国的大学毕业者须申请 CHSI 英文学位认证报告并让认证邮件直接发到研究科（预计毕业者毕业后补办，入学前未到可能取消合格）。
- 出願：先在 WEB 出願网站登记并缴检定料 30,000 日元，部分书类以 PDF 上传，原件书類用書留速達邮寄（截止日 17:00 必达）或窗口提交；国费外国人留学生免检定料。
- 并愿：要项没有写并愿限制。
- 咨询：システム情報学研究科 学務課教務学生グループ（〒657-8501 神戸市灘区六甲台町1-1），csi-kyomugakusei@office.kobe-u.ac.jp，Tel 078-803-6002。
