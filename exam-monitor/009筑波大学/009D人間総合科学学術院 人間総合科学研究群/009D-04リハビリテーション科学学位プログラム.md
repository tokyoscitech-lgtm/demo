## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 8月实施：没有英语笔试，也不需要提交 TOEIC、TOEFL、IELTS 等外部英语成绩；要项的试验科目只有书类审查、论述试验和口述试验三项。
- 因为不使用外部成绩，也就没有有效期、最低分一类的规定。

### 日本語要件
- 8月实施：外国人出願者（永住者、特别永住者除外）必须提交日本語能力試験 N1，或 J.TEST 実用日本語検定 特A级或A级的认定书原件。
- 论述试验和口述试验都用日语进行。
- 住在日本国内的外国人还要交住民票的抄本。
- 东京キャンパス不接收外国人研究生（FAQ 的说明），没有先当研究生再考的路线。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 書類審査（20分；8月实施） | 根据出願书类评分；评分的具体依据要项没有写 | 2027募集要项 |
| 論述試験（専門科目，100分，90分钟；8月实施） | 与リハビリテーション有关的课题，用日语作答 | 2027募集要项 |
| 論述試験的出题样子（2025年度、2026年度入试） | 2道大题、各2小问，共4问全部必答；每问一张600字格的答题纸。第1题给出政府调查的统计表，先读表归纳（400字以内），再结合自己的专业提出课题和对策（600字以内）；第2题给一段论说文，先归纳或梳理论点（400字以内），再联系自己参与的リハビリテーション实践举例论述（400–600字） | 过去问 PDF（2025年度、2026年度入试） |
| 口述試験（80分；8月实施） | 围绕研究计划进行试问 | 2027募集要项 |

- 8月实施的总分是 200 分：书类审查 20＋论述试验 100＋口述试验 80。要项没有公布合格最低分。
- 出题意图（2026年度入试，官方公开）：第1题看能否准确读取并概括数据，再从リハビリテーション专业的角度有条理地提出预防、早期发现和对策；第2题看能否准确把握论说文的逻辑，把抽象概念和自己的实践例子联系起来，并讨论怎样用科学方法验证或解决。
- 两年的素材都是社会性题目（独居老人的孤独死、孤独与孤立的实态、自我决定、社会公正教育），不是医学知识的默写题，要求在限定字数内写成文章。
- 论述试验能带什么、能否用词典，要项没有写，写在考前掲載的「受験者心得」里（本年度预定 2026/7/31 前后掲載），本次没有读到。
- 题目倾向（体验记，非官方）：没有找到本プログラム的考生体验记，暂无可写的内容。

### 口述試験 / 面接
- **官方形式**：8月实施 2026/8/23（周日）10:00–14:00 前后，配点 80 分，内容是关于研究计划的试问，用日语进行，试场在东京キャンパス文京校舎（東京都文京区大塚3-29-1）。每人的时长、面试官人数、是个别还是集团，要项没有写。
- **実際に聞かれた内容**：没有找到本プログラム的口述试验体验记，实际提问内容不明。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：8月实施 23名。只有这一轮，没有其他选拔区分。
- 出願资格①（不需要审查）：大学毕业或入学前预计毕业、取得学士学位、在外国完成16年学校教育等（1）–（8）项之一。其中符合（6）项的人要在出願前先咨询。
- 出願资格②（需要事先审查）：（9）项的跳级入学，（10）项经个别审查认定有大学毕业同等以上学力的人等。审查书类在 2026/6/16–6/20 邮寄（已截止），通过后拿到认证号码才能做 Web 出願。
- 共通条件：到入学为止有大约1年以上的工作经验，常勤、非常勤都算；主要身份是学生时打的工不算。没有工作经验的人不受理出願。要项没有指定在职证明一类的证明文件，工作经历写在「学歴·職歴調書」和「職務内容調書」里。
- 出願书类：毕业（预计）证明书和成绩证明书、学位授与证明书（符合者）、最终学历的证明书（符合者）、日语考试认定书原件（外国人）、住民票抄本（住在日本国内的外国人）、户籍个人事项证明书等（改过姓的人）、检定料收纳证明或支付结果画面、国费留学生证明书（符合者）；下载样式填写的有学歴·職歴調書、職務内容調書、研究計画書A、研究計画書B。研究計画書A和B各自的内容和字数，要项正文没有写，只说按下载文件里的记入例填写，本次没有打开 ZIP 核实。
- 没有要求推荐信，也没有要求所属单位的受験承认书。
- 出願方式：在东京キャンパス用的 Web 出願系统录入基本信息（上传3个月以内的证件照 JPEG）、出願资格和学历 → 支付检定料并填入受付号码 → 发送出願数据（之后不能改）→ 在 7/11 17:00 前下载打印受験票、收件人标签、检定料收纳证明粘贴纸和提出明细票 → 把证明书原件等装进角形2号信封，贴上标签用書留邮寄。只收邮寄，不能送到窗口。
- Web 出願系统里不需要填「指导教员」。
- 检定料 30,000 日元，信用卡或便利店支付，手续费自付，缴纳后不退；国费外国人留学生不收。
- 入学料 282,000 日元（2026年度入学者的金额，办完入学手续后退学也不退）。授業料每学期 267,900 日元（年额 535,800 日元）；外国人留学生每学期 304,400 日元（年额 608,800 日元）。授業料在入学后缴纳。
- 上课时间：平日夜间和周六的白天、晚上。东京キャンパス的 FAQ 写的是周二到周五第7、8节（18:20–21:00），周六第2–7节（10:20–19:35），周日和周一通常不上课。
- 课程安排：大部分学分在1年级修完，2年级主要写硕士论文，中间有构想发表会、中间发表会和最终发表会。学位是修士（リハビリテーション科学）。
- 长期履修制度：要项里没有记载。
- 需要受験上配虑的人：2026/6/16–6/20 邮寄申请书（规定样式）、3个月以内的诊断书、障害者手帳的复印件（持有者）（已截止）。
- 成绩开示：申请期间是 2027/5/1（周六）–5/31（周一），用规定的入试成绩开示请求书申请。
- 咨询：筑波大学东京キャンパス文京校舎 社会人大学院等支援室教務担当（〒112-0012 東京都文京区大塚3-29-1），邮箱 businessentrance@un.tsukuba.ac.jp；只接受邮件咨询，没有公布电话。
