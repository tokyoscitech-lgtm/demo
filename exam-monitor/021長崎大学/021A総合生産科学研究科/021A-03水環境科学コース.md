## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各轮次相同：不另设英语笔试，用考试日前3年以内的外部成绩换算，英语配点20分。
- 可用 TOEFL iBT（含 Home Edition，只认 Test Date 成绩）、TOEIC L&R 公开测试、IELTS；TOEFL ITP、TOEIC IP 不受理。
- 出願时交成绩证明原件（之后返还）或数字版公式认定证打印件；赶不上或想换用新成绩的须事先向大学院係申请。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 小论文用英语写，口述和面接用英语进行；日英以外语言的书类须附日文或英文译文。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 小論文・口述試験（60分） | 小论文：题目为入学后想做的研究计划，英文自由撰写，所定 A4 表格2页以内、800词以内，出願时提交；口述：就小论文内容用英语问答，考查基础学力和水环境领域的基础知识 | |
| 英語（20分） | 外部成绩换算 | |

- 总分100＝小論文・口述60＋面接20＋英語20，按总分从高到低录取；面接成绩极低可不合格。一般入试和外国人留学生入试配点相同。

### 口述試験 / 面接
- **官方形式**：小论文口述试验（与小论文合计60分）和面接（20分）都用英语；面接为多名考官的个人面试，参考出願书类评价志望动机、学习意欲、修学情况和社会性；外国人留学生入试可事先与指导予定教员商量改为网络考试。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：2027年4月入学 一般入试2名、外国人留学生入试5名；本コース不参加冬期一般入试、推荐入试和社会人入试。
- 出願资格：一般入试为大学毕业（含2027/3前预计）或外国16年学校教育等，资格(9)(10)(11)须 2026/8/21 前接受出願资格审查（非独立出願，已截止）；外国人留学生入试只限无日本国籍（永住者除外）且在外国完成16年教育或取得相当学士学位者，个别审查（资格5）同样 8/21 截止。
- 要提前准备的书类：英文小论文（研究计划，所定 A4 表格）；指导予定教员的受入内诺证明（邮件复印件等）；外部英语成绩。
- 出願：書留速達邮寄或窗口（9:00–17:00）提交，期限内必达；外国人留学生入试在截止前用邮件发送电子版也算按时出願，但原件必须寄到；另在研究科网站表单登记住所；检定料30,000日元，用 E-支払い 缴纳（英文版只能用信用卡），国费留学生免缴。

### 研究室 / 指導教員
- 事前連絡要否：必须。一般入试和外国人留学生入试要项都要求出願前联系希望的指导教员、充分商量并取得内诺，出願时须提交受入内诺证明。
