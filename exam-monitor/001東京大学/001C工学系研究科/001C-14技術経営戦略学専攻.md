## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 须提交 TOEFL iBT（或 TOEFL iBT Home Edition）的官方成绩，用于书类选考，同时代替外国语（英语）笔试；専攻不另设英语笔试。
- 本専攻的成绩送达期限是 2026/7/31（周五，已截止）。要趁早考，并在 ETS 账户里办好官方成绩的送付手续，以研究科能在线查到成绩为准。
- 送付对象：DI コード 8596、Department コード 99。出願时还要在 WEB 出願系统里登记受验信息，具体手续按 TOEFL 成绩提交要项办。
- 只认 Test Date Scores，不认 MyBest scores；TOEFL ITP 等团体受验的成绩不能用，考场也不举行 TOEFL ITP。
- 母语是英语的人也要提交。要项和専攻入试案内都没有写最低分数线和配点。
- 研究科共通表里其他専攻可用的 TOEIC L&R、IELTS，不适用于本専攻（本専攻只列了 TOEFL）。

### 日本語要件
- 募集要项和専攻入试案内都没有要求提交 JLPT、EJU 等日语成绩，也没有设日语的最低标准。
- 用日语、英语以外的语言写的证明书等，都要附日语或英语的译文。
- 笔试、口述用什么语言，専攻入试案内没有写（官方未记载）。専攻入试案内有英文版。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 書類選考（第一阶段，不是笔试） | 按 TOEFL iBT 成绩、出身大学的成绩证明书、调查票三项审查；合格者才能考笔试和口述 | 2027専攻入试案内 |
| 数理的及び論理的思考能力を見るための問題（120分钟） | 考数理思考和逻辑思考的能力；専攻会在考前把与本科目有关的论文寄给考生，考试在考场进行。官方没有公布出题范围、题数和配点 | 2027専攻入试案内 |
| 英語 | 用书类选考时提交的 TOEFL 成绩代替，不另考 | 2027専攻入试案内 |
| 一般教育科目 | 本専攻没有（研究科共通表中标为“なし”） | 2027修士募集要项 |

- 选拔按笔试、口述和提交书类综合评定；各项配点和合格线官方没有公布。书类选考不合格也不退检定料。
- 考场在本郷キャンパス，具体教室事先揭示；日程、时间段、地点有变动时在専攻网站上公布。
- 题目倾向（体验记，非官方）：2024、2025年度的考生都说，2小时里数学和基于事前论文的论述题一起考。数学约4大题，范围是微分方程、线性代数、概率、统计（2025年度还出了图论），单题不难但题量大。论述题围绕考前约一周收到的2篇英文论文，每小题写100–300字，题数多，时间很紧。两人都建议拿到论文后用一周精读，记住论点和结构。体验记里的配点（数学200分、论述每篇100分）是个人说法，官方没有公布。

### 口述試験 / 面接
- **官方形式**：在考场当面进行，只有书类选考合格者参加。考官就基础知识和研究意欲提问，并就调查票的内容提问。时长、考官人数、配点官方没有记载。
- **実際に聞かれた内容**：以下来自体验记，非官方。2024年度的考生说面接约20分钟，7位教员围成U字形对1人，问了志望动机和现在的研究、研究计划的细节（尤其是结果怎么解释）、研究成果的意义、留学经历和对留学国与日本的比较；研究计划写得笼统会被追问。2025年度的考生说面接约10分钟，没有写具体问题。2019年的体验记里问的是为什么报考本専攻、入学后想做的研究和理由、毕业后的去向、现在的研究和所属研究室，气氛平和。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员为14名（修士课程）。本専攻除2027年4月入学外，也接受2026年10月入学。
- 出願资格：日本的大学毕业或2027/3/31前预计毕业；在外国完成16年学校教育；在外国大学修完3年以上课程并取得相当于学士的学位；文部科学大臣指定的人；由大学改革支援·学位授与機構授予学士学位；经个别入学资格审查认定且到2027/3/31满22岁，共6项之一。2026年10月入学的，日期换成2026/9/30。
- 按第(6)项出願的人要事先接受个别入学资格审查，本年度的申请期限是 2026/4/21（周二，已截止）。
- 选拔分两段：先做书类选考（TOEFL iBT、成绩证明书、调查票），结果在 2026/8/14 12:00 前发表；合格者才参加 8/31 的笔试和 9/1–9/2 的口述。合否一律不接受电话、传真、邮件查询。
- 本専攻独有的提交物是调查票，样式从専攻网站下载（2027年度的样式与上年不同），出願时和成绩证明书一起提交。TOEFL 官方成绩的送达期限是 2026/7/31。
- 研究科共通的出願书类（全部做成 PDF 上传到 WEB 出願系统）：入学願書（在系统里填写）、照片数据、检定料的缴纳证明、出身大学的成绩证明书（东大工学部毕业或预计毕业的人免交）、毕业证明书（出願时已毕业的人；预计毕业证明书不用交）、安全保障输出管理チェックシート（外国籍、重国籍、入学前所属机构在海外的人）、国费留学生的证明（该当者）。合格后办入学手续时要交成绩和毕业证明的纸质原件。
- 检定料 30,000 日元，可用便利店、Pay-easy、网上银行、中国结算或信用卡支付，手续费自付；国费外国人留学生免缴。缴了以后不论什么理由都不退。
- 入学时的费用（2027年度预定额）：入学料 282,000 日元，授業料前期 267,900 日元（年额 535,800 日元）；国费外国人留学生免缴。
- 在职的人入学，要交上司出具的“不妨碍入学”的承诺书（样式不限）。
- 外国籍的人要在办入学手续前取得不妨碍入学的在留资格。新申请在留资格通常要2–3个月以上，要项提醒这类考生考虑选4月入学。
- 需要考试或修学上照顾的人，在出願期限前向学务课大学院チーム和専攻事务室提出。
- 研究科共通表里的“特别口述试验”制度（社会基盤学、機械工学等専攻）不适用于本専攻。
- 咨询：要项的问题走研究科网站的问询表单（东京大学大学院工学系研究科学务课大学院チーム，〒113-8656 东京都文京区本郷7-3-1）。専攻入试的问题找技術経営戦略学専攻入试担当：nyushi@tmi.t.u-tokyo.ac.jp，TEL 03-5841-8639。
