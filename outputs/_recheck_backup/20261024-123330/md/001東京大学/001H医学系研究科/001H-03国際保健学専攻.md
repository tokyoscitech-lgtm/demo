## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 须提交 TOEFL iBT（含 Home Edition）或 IELTS Academic 的成绩，以此代替外语考试；専攻不另出英语笔试。IELTS General Training 和 One Skill Retake 的成绩不受理。
- 有效期：必须是 2024/8/1 以后受检的成绩。考过多次的只能登记并上传 1 份。
- TOEFL 的送分方式（三步都要做）：①通过 ETS 账户把 Official Score Report 送到研究科（DI 代码 8426，Division 为 Graduate Organization，Department 为 42 Medicine）；②在 WEB 出願系统里登记 Appointment Number 和受检日；③上传对应的 Test Taker Score Report（PDF）。
- IELTS 的送分方式：在 WEB 出願系统上传 Test Report Form，并向 IELTS 事务局申请把同一次考试的成绩单另寄到研究科学务チーム大学院担当；出願前已办理追加寄送的，截止后寄到也受理。
- 送分没能确认、上传的成绩与官方成绩不一致、成绩早于有效期的，都按没有参加外语审查处理。
- 成绩提交的具体截止日在要项和英语说明里只写“所定期限”，日期在 WEB 出願系统里给出，本次未获取到。
- 官方没有公布最低分、换算方法和配点。
- 免除：在澳大利亚、加拿大、爱尔兰、新西兰、英国、美国的大学取得学士学位（含预计毕业），或母校出具全校用英语授课的证明的，可申请免交成绩；须在 2026/6/5（周五）前申请（已截止）。只看学士课程，英语母语者也要申请。

### 日本語要件
- 不需要日语成绩。本専攻是全部用英语授课、用英语取得学位的课程，官方写明从入学到毕业都不要求日语能力；要项里的“日本語能力証明書”只适用于另外两个専攻，不适用于本専攻。
- 笔试题目全部用英语出，答案可以用英语或日语写。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员为 21 名；成绩不够时合格者可能少于募集人员。
- 出願资格：大学毕业或 2027年3月底前预计毕业；在外国完成 16 年学校教育；在外国大学取得相当于学士的学位（修业 3 年以上）；由大学改革支援·学位授与机构授予学士学位；经个别资格审查认可且入学时满 22 岁等。
- 个别资格审查：须先发邮件给大学院担当，修士课程的联系截止为 2026/5/29，审查书类截止为 2026/6/5，结果约 6/12 邮件通知（均已截止）。
- 出願只能通过 WEB 出願系统。上传的书类：入学願書（网上填写）、证件照（jpg，3 个月内拍摄）、检定料缴纳凭证、成绩证明书、毕业（预计毕业）证明书（外国学位须为英文或附公证英译，写明学位名）、英语成绩、改姓证明（有的话）。成绩和毕业证明的原件在入学手续时提交。
- 本専攻独有的提交物：①志望理由书，英文 400–500 词，A4，格式自由；②研究计划书，A4 2 页，格式自由；③指导教员表示同意指导的邮件。前两份左上角写明书类名、姓名、页码。
- 逾期一律不受理；证明书来不及开具的要事先联系大学院担当。
- 检定料 30,000 日元，可用银行汇款、便利店、Pay-easy、信用卡缴纳，凭证上传到系统；日本政府（文部科学省）奖学金留学生免缴。
- 入学料 282,000 日元，授業料 前期 267,900 日元（年额 535,800 日元），均为预定额。
- 入学手续：手续要领于 2027年2月下旬用邮件通知，3月上旬的指定期间内办理，逾期视为放弃入学。入学许可书于 2026年9月上旬在 WEB 出願系统内领取。
- 外国人须在入学手续前取得不妨碍入学的在留资格。外国人留学生等须接受安全保障出口管理的事前审查，结果可能导致合格后不能入学或研究内容受限。
- 残障等需要考试照顾的，申请截止为 2026/6/5（已截止）。
- 另有面向亚洲开发银行·日本奖学金项目（ADB-JSP）对象者的入试案内（2027年4月入学修士课程，2026/4/1 掲載于専攻网站）；这是单独的路线，条件以该案内为准。
- 咨询：東京大学大学院医学系研究科 学務チーム 大学院担当（〒113-0033 東京都文京区本郷 7-3-1），in.m@gs.mail.u-tokyo.ac.jp；研究科网站另有咨询表单。
