## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 8月入试（飛び級入试相同）：
  - 出願时提交 TOEFL、TOEIC Listening & Reading、TOEIC Speaking & Writing 之一的成绩单原件1份，不收复印件；没有原件按书类不全处理。专攻不另设英语笔试，用外部成绩评价。
  - 有效期：出願时起2年以内受检，8月入试须为 2024/7/21 以后、飛び級入试须为 2025/1/27 以后的考试。
  - TOEFL：交从 ETS 账户下载的 Test Taker Score Report（PDF），或让 ETS 直送 Official Score Report（Institution Code 0773，Department Code 没有对应的填 99），直送须出願截止日必达。TOEIC：交公式认定证，或数字公式认定证 PDF 的打印件。
  - TOEIC L&R IP 原则上不受理；例外是慶應义塾内团体特别受验的指定回次（2024/11/8–12 线上、2025/7/10–16 线上、2025/7/12 日吉对面、2025/11/7–11 线上、2026/7/9–15 线上），可代替公式认定证。IELTS 不在可提交之列；Home Edition 要项没有写。
  - 要项没有写最低分、换算方法和配点。成绩单不退还，不接受分数查询和替换。
- 6月入试：不需要提交英语成绩。
- IGP 留学生入试：
  - 须由 ETS 或 British Council 直送 TOEFL iBT 或 IELTS（Academic Module）官方成绩（TOEFL 机构代码 0773；IELTS 没有代码），并在网上上传 Test Taker Score Report 复印件；须为出願截止日前2年以内受检。
  - 在全英语授课的大学取得学位、并提交该校出具的授课语言证明的，免交 TOEFL/IELTS。
  - 另须提交 GRE General Test 官方成绩（ETS 直送，机构代码 3843），以 Quantitative Reasoning 为主要评价，期望 160 分以上；鼓励提交相关领域的 GRE Subject Test。
  - 要项没有写 TOEFL/IELTS 的最低分。

#### 日本語要件
- 一般入试（6月入试、8月入试、飛び級入试）：要项没有要求提交 JLPT、EJU 等日语成绩，也不要日语能力证明书；但記述試問和口述試問原则上用日语进行，实际需要能用日语读题、作答和应答。
- 本専攻三个分野的出题说明都没有提到用英语出题。
- IGP 留学生入试：英语授课，不要求日语成绩；日语达到所需水平的可以选修日语授课的科目。申请书类须用英文或日文。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 8月入试·D）分子・生物化学：記述試問（配点官方未公布，120分钟） | 物理化学、无机化学、有机化学各领域的基础题，加关于毕业研究或相关内容的小论文，全部作答 | 2027入试要项 |
| 8月入试·E）創発理化学：記述試問（配点官方未公布，120分钟） | 物理化学、无机化学、有机化学的基础题，加就毕业研究或相关学术领域考察逻辑说明力和思考力的题，全部作答 | 2027入试要项 |
| 8月入试·F）生命システム情報：記述試問（配点官方未公布，120分钟） | 分子细胞生物学、生物有机化学·生物化学、生物物理化学、信息基础·生物信息学，全部作答 | 2027入试要项 |
| 6月入试·飛び級入试·IGP 留学生入试 | 没有笔试：6月入试是书类审查（必要时加口述試問）；飛び級入试是口述試問；IGP 只看书类 | 2027入试要项／IGP Application Guide |

- 記述試問按所报分野出题（所报分野由希望指导教员所属分野决定），内容是该分野的基础科目和与毕业研究有关的内容，原则上用日语出题；120分钟是整场时间，各题配点官方未公布。
- 8月入试按記述試問、口述試問和入学志願者調書等出願书类综合判定，各评价项目的权重按分野设定，配点和合格线未公布。
- 6月入试的书类审查把考生分成三类：只凭书类合格、参加口述試問后判定、转8月入试判定。
- 2025年8月实施的试题（官方公开）：D、E 各4题全答，前3题大体相同（物理化学：吉布斯能·平衡·电池·稳态动力学；无机化学：周期性·分子轨道·光电效应；有机化学：含 Diels–Alder 的多步合成·氨基酸合成），第4题为毕业研究论述；F 为4题全答（分子细胞生物学、有机化学与生物化学、生物物理化学、信息基础与生物信息学含 C 语言程序）。
- 题目倾向（体验记，非官方）：没有找到新体制下本専攻考生的体验记。

### 口述試験 / 面接
- **官方形式**：8月入试：有，口述試問内容为記述試問范围的提问、志望专门分野的提问、适性和意欲等，原则上用日语，可能要求在黑板上作答，配点和每人时长未公布；6月入试：仅书类审查后被指定者参加，考察志望分野的学力和意欲；飛び級入试：以口述試問为主，可能另课事先课题或口述发表（出願后个别通知）；IGP：没有面试，只看书类。
- **実際に聞かれた内容**：没有找到本専攻考生写的体验记，暂无可归纳的提问。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：本専攻修士课程 130 名（6月入试、8月入试、飛び級入试合计，要项不按轮次、入学时期和分野拆分）；IGP 留学生入试的名额要项没有写。研究科四个専攻为先端数物科学 100 名、化学・生命情報科学 130 名、総合デザイン工学 220 名、人間・社会システム情報科学 150 名。
- 一般入试：
  - 出願资格（6月入试和8月入试相同）：大学毕业或2027年3月前预计毕业；由大学改革支援·学位授与机构取得学士学位；在外国完成16年学校教育（含预计）；文部科学大臣指定者；在外国大学完成3年以上课程并取得相当于学士的学位（含预计）；或经个别审查认定有同等以上学力、入学时满22岁者。外国大学毕业生也可以报6月入试和8月入试。
  - 入学时期：2027年4月入学对所有合格者开放；2026年9月入学只限已大学毕业或2026年9月预计毕业者。
  - 教育研究分野：本専攻设 D）分子・生物化学、E）創発理化学、F）生命システム情報 三个教育研究分野，出願时从教員リスト选定希望指导教员，所报分野随教员而定；只能报1个分野，教员属多个分野也只能选其一。
  - 出願书类：入学志願票（贴检定料缴纳证明）、履历书（彩色打印，照片在 Web エントリー上传）、入学志願者調書（在 Web エントリー填写打印，须与希望指导教员商量后再写）、成绩证明书、大学毕业（预定）证明书和单位修得证明书（本校理工学部以外的考生，用所定用纸由出身大学证明），8月入试另加写真カード和英语成绩单原件；证明书类先扫描上传到 Web エントリー，再寄原件。日文、英文以外的书类须附译文和出身大学的翻译正确性证明；中国大陆大学毕业者另交「教育部学歴証書電子注冊備案表」（英文）。要项没有要求研究计划书或推荐信。
  - 出願方式：先在 Web エントリー（web-entry.st.keio.ac.jp/master/）录入并打印书类，再装角形2号信封、贴所定收件标签，在邮局窗口用简易書留·速達寄出；国外用 EMS、FedEx、DHL 等可追踪国际快递并在截止日必达。没有窗口受理，书类寄出后不能更换。
  - 检定料 35,000 日元（另收手续费）：金融机构窗口用所定汇款依赖书缴纳（不能用ゆうちょ银行和 ATM），或在ローソン、ミニストップ、ファミリーマート、セブン-イレブン 事先登记后缴纳。只有没出願或重复缴纳时才退还，须在出願截止日起1个月内联系 AO。
  - 并愿与再报：6月入试被判定“转8月入试”的人须在8月入试期间重新办 Web エントリー，同専攻免检定料，换専攻按新出願缴费。
  - 个别出願资格审查（只适用于“同等以上学力”资格，用邮件提交认定申请书、申请用履历书等，审查免费）：6月入试 2026/4/9–4/15，8月入试 2026/6/22–6/25（均已截止）；飛び級入试 2026/11/25（周三）–11/27（周五），结果12月中旬邮件通知。
