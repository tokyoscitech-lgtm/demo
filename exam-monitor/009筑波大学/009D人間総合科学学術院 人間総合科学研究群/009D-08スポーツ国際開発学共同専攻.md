## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 9月实施：不设英语笔试，必须提交外部英语检定成绩，换算成 100 分满分的英语得分。
- 受理的考试：TOEIC Listening & Reading（公式认定证，须带照片）、TOEFL iBT（Test Taker Score Report，须带照片）、IELTS Academic。三者交一种，交给自己出願的那所大学。
- 不受理：TOEIC IP、TOEIC Speaking & Writing、TOEIC Bridge、TOEFL ITP、IELTS General Training、IELTS Academic 在线版。
- 有效期：须为本専攻考试日之前2年以内受检的成绩（本年度考试日是 2026/9/19）。
- 提交方式：TOEIC 在日本受检的必须用デジタル公式認定証，在 Web 出願系统里填写其 URL，再把打印件贴在指定用纸上邮寄；只有在不发行数字证书的国家受检的才交纸质原件。TOEFL iBT 交 Test Taker Score Report 原件；赶不上的可让 ETS 直送 Official Score Report（筑波大学机构代码 9995、部门代码 99；鹿屋体育大学机构代码 G272），再把 PDF 版成绩单打印贴在指定用纸上邮寄。IELTS 须让考试机构把 Additional TRF 数据直送大学，并邮寄成绩单复印件。直送可能要几周，须在书类截止日前到达。
- 换算：要项说按换算表折算为 100 分，但能读到的官方资料里没有列出换算表和各考试的基准分，也没有写最低分要求。
- Home Edition 是否受理，本専攻的资料里没有写明。

### 日本語要件
- 要项没有要求提交 JLPT、EJU 等日语成绩。本専攻全部用英语授课，募集要项本身也是英语的。
- 口述考试中研究计划的发表必须用英语；之后的问答可以选英语或日语，在出願时选定，出願后不能更改。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 9月实施：没有笔试 | 不设专门科目和小論文的笔试；专业基础知识在口述考试里考查 | 2027募集要项 |
| 9月实施：外部英语成绩（100分，无考试时间） | TOEIC L&R、TOEFL iBT、IELTS Academic 的成绩按换算表折算，换算表未公开 | 2027募集要项／英语成绩 PDF |
| 9月实施：口述考试（200分，时长未公布） | 体育·运动·健康方面的基础知识，研究计划的发表与问答 | 2027募集要项 |

- 9月实施总分 300 分：口述考试 200＋英语 100。根据考试成绩和出願书类综合判断是否具备完成修士论文或特定课题研究报告的能力；合格最低分没有公布。
- 研究计划书在出願时提交：英语约 600 词（含参考文献），直接在 Web 出願系统里输入；只有需要公式、希腊字母等无法输入的特殊符号时才改用指定的1页样式，且不能改动样式。
- 题目倾向（体验记，非官方）：没有找到本専攻考生的体验记，暂无可写的内容。

### 口述試験 / 面接
- **官方形式**：9月实施有口述考试，配点 200 分，2026/9/19（周六）10:00–17:00 之间进行（每人的具体时段写在考前一周以上在専攻网站公布的受験者须知里）。内容是体育·运动·健康的基础知识考查、研究计划发表和问答。发表必须用英语，问答用英语或日语（出願时选定）。每人的时长、发表用不用幻灯片，要项里没有读到。海外居住的外国人在指导教员同意下可申请在线考试，须另交在线考试申请书和同意书。
- **実際に聞かれた内容**：没有找到本専攻的口述考试体验记，实际提问内容不明。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：9月实施 筑波大学5名、鹿屋体育大学3名，合计8名，2027年4月入学。没有其他轮次，也没有另设的推薦、社会人或外国人留学生名额。
- 共同専攻的规则：学生同时在两校有学籍，以指导教员所在的大学为主校，可使用两校设施、选修两校开设的科目，并由另一校的副指导教员指导；毕业时授予两校联名的修士学位。出願只能投指导教员所在的那一所大学，不能两校都报。
- 出願资格：日本四年制大学毕业或入学前一个月底前预计毕业、由大学改革支援·学位授与機構授予学士学位、在外国完成16年学校教育、在外国3年以上的课程取得相当于学士的学位等。其中“外国3年以上课程的学位”这一项须在截止日前先做资格确认；22岁以上、希望被认定为与大学毕业同等学力的人须接受个别出願资格审查。
- 个别出願资格审查和资格咨询的截止日：9月实施 2026/7/24（周五）（已过）。先发邮件向出願的那所大学索取指定样式；审查通过后会得到在 Web 出願系统里输入的通行码。以前通过的审查不能沿用，每次报考都要重新审查，拿到结果前不要缴检定料。
- 指导教员：出願前必须联系志望的教员并取得同意，提交由该教员签字的受入承诺书；可以再填一位第二志望教员（任选），同样要先取得其同意。
- 出願书类：毕业（预计）证明书原件（已有修士、博士学位的人也要交学部的）、外国大学出身者的学位证明书、学部成绩证明书（读过或在读大学院的另交大学院成绩）、指导教员受入承诺书、外部英语成绩（贴在指定用纸上）、检定料缴纳凭证（信用卡支付者交“出願完成”页面打印件，便利店支付者和鹿屋体育大学的全部出願者交收据）、在学或在职者的受験·入学承认书（所属长或上司出具；在职者也可交“考试不影响工作”的本人声明）、国费外国人留学生证明书（在其他大学就读的国费生）、在线考试相关的申请书和同意书（仅选择在线考试的海外居住者）。证明书只收英语或日语的，原则上交原件，不退还。
- 中国学历的特别说明：可以用 CHSI（日本）出具的英语认证报告代替；自学考試毕业者要交发证机构的成绩单和学位证，尚未取得的不受理。
- 出願方式：在 Web 出願系统注册邮箱并激活账号 → 录入出願信息、输入研究计划、上传证件照（JPEG，500KB 以下，长宽均不超过 2000 像素，3个月内拍摄，不戴帽子）→ 支付检定料 → 点击提交（之后不能修改）→ 在出願期间内下载打印受験票、收件人标签等。书类装入能平放 A4 纸的信封、贴上收件人标签，用挂号邮寄或送到窗口，截止日 17:00 必达。一个账号只能报一个专业，建议用电脑操作。
- 检定料 30,000 日元，缴纳后原则上不退（未受理、缴费后未出願、重复缴纳可在 2026/9/17 前申请退款）。向筑波大学出願的用信用卡（VISA、Mastercard、JCB、AMEX）或便利店（ローソン、セブン-イレブン、ファミリーマート、ミニストップ，限日本国内居住者）支付；向鹿屋体育大学出願的用该校寄来的缴费单在邮局窗口缴纳，海外居住者可银行汇款。国费外国人留学生免缴。
- 外国人等出願者须按安全保障出口管理的规定确认「みなし輸出」的特定类型，并在 Web 出願系统里勾选；属于限制对象的可能无法入学。
- 需要受験上配虑（残疾等）的人要在规定期限前提交申请书、诊断书和残疾证明复印件；具体截止日没有读到。
- 入学料 282,000 日元（缴纳后不退）。筑波大学的授業料每学期 267,900 日元（年额 535,800 日元），以“留学”在留资格在籍的外国人留学生每学期 304,400 日元（年额 608,800 日元）；鹿屋体育大学的授業料年额 535,800 日元（预定额），另有后援会入会费、保险费等杂费。筑波大学的入学手续资料在合格发表当天发到登记邮箱；鹿屋体育大学的资料在 2027年1月中旬寄出，入学手续期间是 2027/3/15–3/23。
