## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 各轮通用：必须提交英语成绩，可用 TOEFL iBT、TOEIC Listening & Reading、IELTS Academic（含 UKVI）、実用英語技能検定（英検）四种之一。要项没有规定最低分，也没有公布英语的配点或换算方法，成绩作为书类审查的材料之一。
- 有效期：出願受理开始日之前2年以内受验的成绩。
- 提交方式：TOEFL iBT 要邮寄 Test Taker Score Report（从 ETS 账户下载的 PDF 打印件），同时让 ETS 把 Official Score Report 直送大学（DI code：C804，Department code 任选，没有对应的填 99）；TOEIC L&R 要通过“公開テスト スコア確認サービス”的“向大学・企业提交成绩”功能提交（申请代码 00019706），同时邮寄デジタル公式認定証的 PDF 打印件；IELTS 邮寄 Test Report Form（可复印件）并办理成绩电子直送（收件方 Waseda University – Graduate School of Information, Production and Systems (IPS)，Department：IPS Office）；英検邮寄能确认 CSE 分数的成绩表（可复印件）并提交英検デジタル証明書。DI code 和 TOEIC 申请代码已在 2026-10-10 再次对照要项确认。
- 不受理：TOEFL iBT Home Edition、IELTS Online、IELTS One Skill Retake 等，TOEFL ITP／PBT、TOEIC IP、TOEIC S&W、TOEIC Bridge、IELTS General Training。TOEIC 只收日本国内公開テスト的成绩；IELTS 看 Overall Band Score。
- 免除：英语为第一官方语言的国家的出身者；在英语为第一官方语言的国家的教育课程毕业（预定）者；在以英语为教学语言的课程毕业（预定）者（可能需要大学出具的正式证明）；本研究科修士課程修了者以一般入試或社会人入試报考时也可免除。
- 变更点：从 2027年4月入学的入试（2026年7月实施）起，TOEIC 成绩必须通过“公開テスト スコア確認サービス”提交，这项服务只在日本国内提供，所以在海外考的 TOEIC 不能用。有效期的规定从 2026年度入试起改为现在的写法。

### 日本語要件
- 要项没有要求提交日语成绩。持有日本語能力試験（JLPT）等资格的人可以提交证明（请主办机构把“認定結果及び成績に関する証明書”直送大学，或邮寄原件），没有有效期和分数的限制。
- 面接試問用日语或英语进行；出願书类可用日文或英文写。研究科的授课用英语和日语两种语言开设。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 没有笔试（7月实施、11月实施、冬入试〔2月实施〕、5月实施各轮相同） | 第1次选考是书类审查：根据提交的志願者信息、成绩证明书、研究計画書（样式2）、論文等報告書（样式4）、语言成绩，综合审查专业知识和学习·研究实绩。配点官方未公布 | 2027年4月入学要项／2027年9月入学要项 |

- 判定方法：书类审查的结果分三种——仅凭书类直接最终合格、进入第2次选考（面接試問）、不合格。最终按研究計画書等书类和面接試問的结果综合判断，官方没有公布分数构成和合格线。
- 评价的着眼点（官方的选拔方法说明）：学习意愿、研究遂行能力、研究计划的妥当性、对研究伦理的理解、课题解决能力。
- 题目倾向（体验记，非官方）：没有找到本研究科修士入试的考生体验记，无法归纳。

### 口述試験 / 面接
- **官方形式**：第2次选考为面接試問，只对第1次选考中被判断需要面接的人实施，原则上用 Zoom 线上进行，使用日语或英语。对象者通过 TAO 或邮件收到个别通知。需要自备摄像头、麦克风、耳机或扬声器，全程打开视频和声音，不能使用虚拟背景。要项没有写面接的时长、配点，也没有要求准备发表资料；重点考察专业知识、学习意愿和问题意识。各轮形式相同。
- **実際に聞かれた内容**：没有找到本研究科修士面接的考生体验记（日文和中文都检索过），实际提问内容不明。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：修士課程 200 名，这是4月入学和9月入学、各入试区分合计的数字；要项没有按轮次或按分野分配人数。
- 出願资格（2027年4月入学）：大学毕业或 2027年3月31日前预计毕业；由大学改革支援・学位授与機構授予学士学位；在外国完成16年学校教育；在外国修完3年以上课程取得相当于学士的学位；文部科学大臣指定者；在大学就读3年以上（或在外国完成15年课程）且被本研究科认定成绩优秀者；经本研究科个别入学资格审查认定具有大学毕业同等以上学力、且 2027年3月31日前满22岁者。满足其中一项即可。9月入学的资格条目相同，日期以 9月入学要项为准。
- 社会人入試另外要求：在企业、官公厅、教育机构等在职或曾经在职，并且有业务上值得特别记述的业绩。
- 国内出願指出願时居住在日本国内，国外出願指出願时居住在日本国外；两者用同一份要项、同一日程，区别在检定料、书类邮寄方式和身份证明书类。
- 网上提交的书类：志願者信息（学历、职历、成绩、语言能力）、研究計画書（样式2，单面1页，写希望的研究课题和研究计划概要，含图表也不能加页或另附纸）、論文等報告書（样式4，单面1页；一般入試写毕业论文，社会人入試写业绩报告）、检定料缴纳证明、彩色照片（3个月内拍摄，不可修图）、在留卡（外国籍国内出願者）或护照（外国籍国外出願者）。
- 邮寄提交的书类：チェックリスト（所定样式）、毕业（预定）证明书、学部以上的全部成绩证明书、语言成绩证明；日本籍的国外出願者另交国外居住证明。书类用日文或英文。一般入試和社会人入試都不需要推薦书。
- 出願方式：只能通过 TAO 网上出願，截止日 16:59（日本时间）前点击“完成出願”才算提交。邮寄书类寄到 〒808-0135 福岡県北九州市若松区ひびきの2-7 早稲田大学大学院情報生産システム研究科事務所；国内用簡易書留并在信封上用红字写“出願書類在中”，国外用可追踪的最快方式；出願期间最后一天必达。
- 检定料：国内出願 35,000 日元（便利店或信用卡支付）；国外出願 15,000 日元（信用卡，或银行汇款时加手续费 2,500 日元共 17,500 日元）。特定国家（最不发达国家名单上的国家）的出身者可申请免除。支付期间与出願期间相同。
- 并愿：FAQ 说明可以与其他研究科并愿。要项没有写同一年度内各轮之间能否重复报考、合格后能否再报下一轮。
- 外国人留学生的教育研究内容要按外汇及对外贸易法接受安全保障出口管理的审查，属于管制事项时教育研究活动可能受限。
- 学费（2027年度入学，修士課程）：入学时缴纳 907,500 日元（入学金 300,000＋授業料 581,000＋実験演習料 25,000＋学生健康増進互助会費 1,500），第2期 607,500 日元，初年度合计 1,515,000 日元；第2年度每期 757,500 日元（授業料 731,000＋実験演習料 25,000＋互助会費 1,500），全年 1,515,000 日元。放弃入学时只退还学费和诸会费的第1期部分，入学金不退。
- 入学手续：7月实施入试合格者的第1次入学手续书类必达期限为 2026/10/15，11月实施入试合格者为 2026/12/12（要项日程表写作“10月上旬”“12月上旬”；要项所附星期与 2026 年日历不符——2026/10/15 实为周四、12/12 实为周六——以合格者收到的手续书类为准）。第2次入学手续的案内都在 2027年2月中旬前后寄出。
- 需要考试或就学方面照顾（残障等）的人，出願前先联系研究科。奖学金方面，要项列有校内奖学金、民间奖学金、日本学生支援機構的贷与奖学金，以及面向外国人留学生的“私費外国人留学生授業料減免奨学金”等。
