## 🎯 入試内容（考什么）

### 語学 / 英語要件
- A日程和 B日程都要英语成绩。本系不自己考英语，用外部考试成绩代替：TOEIC L&R 或 TOEFL iBT（Home Edition 也可以）。
- 提交时点：出願时和其他书类一起交，交了以后不能换成更高的分数，也不能事后补寄（2026/4/18 说明会资料）。截止前没交就没有受験资格。
- 成绩须为 2024/6/11 以后受检。只收从网上下载的 PDF 打印件：TOEIC 是带 QR 码的デジタル公式認定証，TOEFL 是 PDF 版 Test Taker Score Report，同时要在 ETS 账户里把送分对象设为 DI code G179。
- 不受理的种类：ETS 寄来的纸质成绩单、TOEFL ITP、TOEIC IP、TOEIC S&W。要项没有列 IELTS。
- 配点：系在 2022/12/21 的通知里写的是筆答専門試験 900 分、英语 100 分（从 2023 年夏季的考试起适用）。2027年度是否原样沿用、TOEIC 和 TOEFL 怎样换算成 100 分、有没有最低分，这次都没能从要项原文核实。
- A日程是按出願书类综合判断，英语成绩作为书类的一部分一起看（2025年度说明会 FAQ）。

### 日本語要件
- 要项的共通部分没有要求提交 JLPT 等日语成绩；情報理工学院的说明会 FAQ（2025年度）也写明不用提交日本語能力試験的结果。
- 口頭試問原则上用日语进行，也可以用英语应对（同 FAQ）。
- 试题语言：官方过去问页注明，情報理工学院从 2024 年起不再出英文试题，也就是笔试题只有日文。能否用英文作答，这次没有查到官方说明。
- 留学生和日本人按同样标准选拔，国籍不影响合否（同 FAQ）。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| B日程 筆答専門試験 グループA（三组合计 900 分；时长没能核实） | 微分积分、线性代数、概率与统计，出 1 题 | 系 2022/12/21 通知 |
| B日程 筆答専門試験 グループB | 数理逻辑、自动机与形式语言，出 1 题 | 系 2022/12/21 通知 |
| B日程 筆答専門試験 グループC | 数据结构与算法、程序设计，出 1 题 | 系 2022/12/21 通知 |
| 英语（100 分） | 外部成绩换算，不另外考 | 系 2022/12/21 通知 |
| A日程 | 没有笔试，按出願书类和口述試験决定合格内定 | 2027募集要项 |

- 上表的科目和配点来自系在 2022/12/21 发的变更通知（对象是 2024年4月及2023年9月入学的考试，之后系页没有再发变更通知）。2027年度要项 p52–54 的原文这次没能读到，各组的配点、考试时长、三题是否全部必答请以要项为准。
- 合否判定：B日程按筆答試験、英语成绩、口頭試問和出願书类综合判定。笔试后先公布有资格参加口頭試問的受験番号，不在名单上的人不能参加口頭試問。2026 年有 42 人进入口頭試問。
- A日程由系根据出願书类挑选对象，考生不能自己选择；7/2（周四）12:00 左右在マイページ得知自己适用 A日程还是 B日程。A日程没有拿到内定的人可以继续考 B日程。出願资格(9)（飞び入学）的人只适用 B日程。
- A日程的书类选考（2025年度说明会 FAQ）：全部提交书类综合判断，GPA 作为不分学校的统一标准使用，成绩证明书上最好印有 GPA；出身学校和休学经历不作考虑；没有要求提交的材料（如获奖论文）不会加分。A日程占受入人数的比例每年不同，不公布。
- 题目倾向（体验记，非官方）：这次没有找到可用的考生体验记，暂时没有可归纳的内容。

### 出願資格 / 定員
- 募集人员：情報理工学院（数理·計算科学系＋情報工学系）合计 135 名，是 2026年9月入学和 2027年4月入学的总数。本系单独的“受入可能予定人数”写在要项 p52，这次没能读到原文。本年度没有第2次募集。
- 出願资格：大学毕业或 2027/3/31 前预计毕业、在外国完成 16 年学校教育等 (1)–(11) 项之一；其中 (9)(10)(11) 要先过出願资格审查，书类 2026/5/11（周一）必达（已截止）。
- 志望指导教员：本系在出願时填写志望的指导教员，入学后的研究室按入试结果决定，原则上不能更换。说明会资料强烈建议至少到第3志望的研究室都要弄清实际研究内容。能填几名、不填怎样处理写在要项 p52，这次没能核实。
- 课程：情報工学コース、知能情報コース，以及人間医療科学技術コース、エネルギー·情報コース；后两个只有被分到担当教员的研究室时才能选。各コース不单设定员。
- 出願书类：宛名标签、入学志願票、志望理由書（指定样式 A4 1 张；本系有没有指定题目没能核实，说明会资料提醒要特别注意这一份，教员不会帮忙修改）、成绩证明书、毕业（预定）证明书、英语成绩的 PDF 打印件、外国人的在留卡复印件等。日文、英文以外的证明要附译文。
- 出願方式：先在网上出願系统登记，再把书类用速達書留寄到入試課，2026/6/10 必达；不收窗口提交。
- 检定料 30,000 日元＋手续费 990 日元，可用信用卡、网银、便利店、Pay-easy 支付。国费留学生等免缴，要在 5/27 前事先申请。
- 并愿限制：只能报一个系，不同的系不能并愿；同一入学期不能报理工学系修士的多个募集，一个出願的结果出来之前不能再报理工学系的其他募集。
- 外国人注意事项：9 月入学只限出願时住在日本、在留资格有效到 2026/9/28 的外国人，住在海外的外国人只能 4 月入学。按安全保障出口管理的审查，可能被要求变更想做的研究内容。
- 入学料 282,000 日元，授業料半年 317,700 日元（可能修订）。4 月入学的手续预定在 2027/3/4（周四）前办完。
- 考场：B日程在大岡山校区。口頭試問当天从上午持续到下午，午饭自带或用校内食堂。
- 其他路线：留学生另有国際大学院プログラム(C)，募集和选拔单独进行。这不是修士一般入试的要求。
- 咨询：考试内容问情報工学系入試担当 cs-exam-inquiry@comp.isct.ac.jp；书类和出願资格问入試課大学院入試グループ inquiries.grad.se@adm.isct.ac.jp（〒152-8550 東京都目黒区大岡山2-12-1）。
- 成绩开示：2026/10/1–2027/5/28 必达，邮寄申请。A日程开示口述评价（A–E），B日程开示笔试得分、英语得分和口頭試問评价。
