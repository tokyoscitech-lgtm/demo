## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各日程相同：不另设英语笔试，用 TOEFL iBT（含 Home Edition）成绩评价。
- 送分：向 ETS 申请把 Institutional (Official) Score Report 送到研究科（DI code 1113），其他代码无效；出願时在 WEB 出願系统里填写 Appointment Number、受检日和分数，不必交 Test Taker Score Report。
- 有效受检期间（向 ETS 申请送分也须在此期间内完成）：A日程 2024/8/1–2026/6/13（已过）；B日程 2025/2/1–2026/11/15。
- 送过多次的，出願时只指定一次。TOEFL ITP 不受理，MyBest Scores 不采用，其他英语成绩不能代替。
- 要项和専攻案内都没有写最低分、配点和换算方法。
- B日程综合型选考：在美国、英国、爱尔兰、加拿大、澳大利亚、新西兰的大学或研究机构取得（或预计取得）学士学位的人可以免交；笔试型没有免除规定。
- 变更点：2026年度 A日程是考试当天由研究科统一实施 TOEFL ITP，2027年度起改为事前提交 iBT 成绩。

#### 日本語要件
- 要项和専攻案内都没有要求提交日语成绩（JLPT 等），外国人考生走一般选拔也不用交；研究科不设单独的外国人留学生特别选拔。
- A日程的笔试用日语出题，可用日语或英语作答；B日程笔试型用英语出题，可用英语或日语作答。综合型选考口述的语言官方没有写明。
- 从初等、中等教育起都在日语以外的语言环境中受教育的课程毕业（预定）者，出願前须接受出願对象审查：B日程截止 2026/10/7（已过）。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 基礎化学（必答；A日程 55 分钟；配点官方未公布） | 大学低年级程度的一般化学、基础生物化学、基础有机化学；参考书为 McMurry 等《Fundamentals of General, Organic, and Biological Chemistry》 | 2027専攻入试案内／出题范围页 |
| 选择科目（7 科选 3 科；A日程合计 165 分钟；配点官方未公布） | ①分析化学：经典化学分析与仪器分析（色谱、光谱、电化学）；②生物化学：生物分子结构与功能、代谢及调节；③有機化学·天然物化学：立体化学、反应与合成、生理活性天然物的生合成与作用机制；④微生物学：分类、代谢、遗传、食品相关应用；⑤分子生物学：复制·转录·翻译、表达调控、细胞周期；⑥植物生理学·植物栄養学·土壌学：土壤构成与功能、养分吸收、光合作用、环境应答；⑦食品科学：食品成分的结构与化学性质、劣化、功能性与安全性 | 2027専攻入试案内／出题范围页 |
| B日程笔试型：科目同 A日程 | 基礎化学＋出願时选定的 3 科，英语出题；各科时间在受験者心得里通知 | 2027専攻入试案内 |

- A日程选择科目在考场当场选，出願时不用填；B日程在出願时就要选定 3 科。

- 各科题数、配点、总分和合否判定公式官方都没有公布。两専攻用同一套试题，报哪个専攻由第1志望研究室所属决定，录取标准没有差别。
- 题目倾向（体验记，非官方）：没有找到本専攻考生公开的体验记。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：A日程（2026年10月入学＋2027年4月入学）34名，B日程（2027年4月入学＋2027年10月入学，含笔试型和综合型选考）若干名（要项募集人员表本専攻只有这两格）；成绩不足时可能录不满。
- 出願资格：日本的大学毕业或 2027/3/31 前预计毕业、在外国完成 16 年学校教育、在外国取得相当于学士的学位（3 年以上课程）、经个别入学资格审查认定且 2027/3/31 满 22 岁等 6 项之一。个别入学资格审查申请截止：A日程 2026/5/7、B日程 2026/10/7（均已过）。
- 变更点：2027年度起，国内外已取得或预计取得学士学位的人都可以报 B日程（研究科 2026/3/17 变更通知）。
- 入学时期：A日程可选 2026年10月（限 2026年9月前毕业者）或 2027年4月入学；B日程可选 2027年4月或 2027年10月入学，出願后不能更改。
- 志望填写：A日程填第1、第2志望，两个志望须是不同专门分野；4月入学的第1志望须在本専攻，第2志望可以选応用生命工学専攻的分野；10月入学的两个志望须在同一専攻。B日程只能填第1志望。
- 専攻指定书类：志望指導教員签名的志望確認書（研究科指定样式，PDF 上传）；A日程第1、第2志望教员各一份（没有第2志望就只交一份），B日程一份。
- B日程综合型选考另交：记有 GPA 的成绩证明书（开不出来的事先问専攻）；推荐书 1 份（格式自由，日英均可，推荐人须熟悉本人研究且不是志望指导教员，在系统「その他」栏填推荐人姓名和邮箱，系统向推荐人发上传链接）；自己アピール（2026/10/15 修订为英文约 800–1,200 词或日文约 2,000 字，写获奖名称与日期、奖学金名称与期间、研究活动、论文和学会发表）。
- 共通书类：入学願書（WEB 填写，3 个月内照片）、成绩证明书、毕业（预定）证明书、检定料缴纳证明、国费留学生证明书（仅国费生）、TOEFL 成绩；日语和英语以外的证明书附译文，原件在入学手续时提交。只能通过 WEB 出願系统出願。
- 检定料 30,000 日元，银行汇款（邮储银行除外）、便利店、信用卡、Pay-easy 均可；缴纳期间 A日程 2026/4/13–6/23（已过），B日程 2026/10/5–11/25。国费留学生免缴；缴后不退。
- 并愿：同一日程只能报研究科的一个専攻；2027年度 A日程已合格本専攻或応用生命工学専攻的人，不能再报 B日程的这两个専攻。
- 2027年度起取消社会人特别选拔，在职者用同一份要项出願，入学手续时交雇主同意书。
- 入学料 282,000 日元，授業料 年 535,800 日元（前期 267,900 日元），均为预定额；国费留学生免缴。4月入学者 2027年2月下旬收到入学许可通知，3月上旬办手续。
