## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 须提交 TOEFL iBT 或 TOEIC L&R 的公式成绩，按専攻规定的方法换算成 300 分满分。具体换算式入试案内没有公布。
- TOEFL iBT：通过研究科 WEB 出願系统提交，须完成三步（ETS 官方送分，DI 代码 8596、Department 代码 99；登记 Appointment Number 和受检日；上传 Test Taker Score Report）。采用 Test Date Scores，不采用 MyBest scores；Home Edition 可以，TOEFL ITP 不可；英语母语者也要交。有效期：受检日在2024年9月以后。
- TOEIC L&R：在専攻的提交表单里填写数字公式认定证的 URL。纸质成绩单、没有数字认定证的成绩不受理；TOEIC IP、Bridge、S&W 不受理。TOEIC 的有效期入试案内没有记载。
- 提交期限：希望参加特别口述试验的人为 2026/6/4 15:00；不希望的人为 2026/7/21（周二）15:00（均已截止）。
- 研究科共通规定里的 IELTS 不适用于本専攻（本専攻只收 TOEFL iBT 和 TOEIC L&R）。

### 日本語要件
- 要项和入试案内都没有要求提交日语成绩。事前提出课题可用日文或英文作答，口述试验的使用语言可在日语和英语中选择。
- 留学生的另一条路线（国际大学院项目）在専攻页面另行说明，本笔记只记一般入试。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 一般教育科目 | 不实施（本専攻不考研究科共通的数学·物理学·化学） | 2027募集要项 |
| 社会基盤学（専門）事前提出课题 | 从11个试验领域中选1个，阅读指定的论文等资料后回答设问，在家完成后提交；口述试验时就该课题接受试问。领域：1 交通工学、2 空间情报、3 计算科学、4 水理学、5 水文学、6 地盘工学、7 结构工学、8 混凝土工学、9 管理·国际项目、10 景观学·土木设计·都市计划、11 防灾工学 | 2027専攻入试案内 |
| 书类审查 | 自己推薦書、成绩集计表、英语成绩；出願者多时用学业成绩、英语成绩和事前提出课题等做书类选考，决定谁进入口述试验（2026年8月中旬通知） | 2027専攻入试案内 |

- 配点：英语 300 分＋社会基盤学（専門）与（一般）合计 1000 分。（専門）与（一般）各占多少分，入试案内没有写。合否按英语、书类选考和口述试验的结果综合判定。
- 所选的试验领域不必与志望的指导教员组一致。
- 2026年度以前是笔试「社会基盤学」＋口述；2021年度起笔试用英语出题、专业术语附日文，可用日语或英语作答。旧题可用来复习各领域的基础。

### 口述試験 / 面接
- **官方形式**：一般入试口述试验为线下，按若干人一组指定集合时间，拘束时间最长约3小时。分两部分：「社会基盤学（専門）」就事前提出课题试问，看所选领域的基础知识、对课题的理解、向学术和社会课题应用的能力；「社会基盤学（一般）」参考自己推薦書等试问，看结合自身经历的构想力和修士阶段学习研究的适性。特别口述试验（7月，线上约20分钟）没有配点，考察基础学力、志望领域的基础能力和工学贡献的构想力；合格者免除（専門），只考（一般），并在最大定员范围内优先配属；不合格也能参加一般入试，且不影响合否。
- **実際に聞かれた内容**：新形式（2027年度）还没有找到体验记。旧形式的体验记（2026年度入学，体验记，非官方）说口述以自己推薦書为参考，围绕志望动机、至今的学习研究、入学后的研究计划、自身的适性和长处。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员为52名（修士课程，含特别口述试验合格者）。
- 出願资格：日本的大学毕业或2027年3月31日前预计毕业、在外国完成16年学校教育、在外国取得相当于学士的学位（3年以上课程）、文部科学大臣指定者、学位授与机构授予学士者、经个别入学资格审查认定者，共6项之一。个别入学资格审查的申请截止为 2026/4/21（已过）。
- 研究科共通书类（全部以 PDF 上传到 WEB 出願系统）：入学願書、证件照数据、检定料缴纳证明、毕业证明书（已毕业者）、成绩证明书、安全保障输出管理检查表（外国籍者等）。日语和英语以外的证明要附出身大学盖章的英译。
- 専攻独有书类：①自己推薦書（按専攻网站的样式，写现在的学习研究、修士阶段想做的研究和将来展望；有日文版和英文版样式）；②成绩集计表（専攻网站下载 Excel，按填写要领汇总成绩）。字数等以样式上的说明为准，入试案内正文没有写。
- 另须在出願期间内填写専攻的「追加数据在线输入票（修士课程）」：联系方式、指导教员组的志望顺序、TOEIC 数字认定证 URL（该当者）。
- 检定料 30,000 日元（便利店、Pay-easy、网银、中国决济或信用卡；手续费自付）。日本政府奖学金留学生免缴。缴纳后不退。
- 受験票于 2026/7/3（周五）15:00 前后在 WEB 出願系统发放，自行打印带到考场。
- 10月入学：已毕业或2026年9月30日前预计毕业者可申请2026年10月入学，在 WEB 出願系统里填写；出願后原则上不能改入学时期。需要新申请在留资格的外国籍者，官方建议选4月入学。
- 入学料 282,000 日元，授業料 年 535,800 日元（前期 267,900 日元），均为预定额。
- 不能同时报考本研究科的两个以上専攻。
- 咨询：専攻入试担当 gsao@civil.t.u-tokyo.ac.jp；研究科要项的问题用研究科网站的问询表单（工学系研究科学務課大学院チーム，〒113-8656 東京都文京区本郷7-3-1）。専攻另有入试 FAQ 表格，链接在専攻入试信息页。

- 事前連絡要否：不要。要项没有要求。入试案内没有规定出願前必须联系教员；志望填的是「指导教员组」，具体指导教员在合格后于组内决定。
