## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般選抜·私費外国人留学生選抜（两者相同）：
  - 不另设英语笔试，用 TOEFL-iBT 或 TOEIC L&R 成绩换算为英语得分（100分）；两种都交时取换算后较高的一个。
  - 按要项换算表在 TOEIC L&R 10–990、TOEFL-iBT 0–120 的范围内换算为 0–100 分（TOEIC 990＝TOEFL-iBT 120＝100分）；2026年1月起的 TOEFL-iBT 新分数（1–6）仍按旧的 0–120 分制换算，不用 MyBest scores。
  - TOEFL-iBT 由 ETS 直接送分（DI code 8549，考试前一天晚上前申请免费）；TOEIC L&R 交公式認定証原件（数字认定证打印件也可），TOEIC S&W 不认。成绩须在出願书类受理期内到达，未到按书类不备处理。
  - 有效期为出願期间前2年以内；TOEFL-ITP、TOEIC-IP 等团体受验成绩不受理。
- 推薦選抜：不收英语成绩。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 一般選抜的専門試験用日语出题，可用日语或英语作答（英文版要项）；私費外国人留学生選抜的试题日英并记，可用日语或英语作答。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 制御工学A（問題17） | 拉普拉斯变换、传递函数、方框图、响应、频率响应、稳定性；必答 | 9:00–12:00，180分钟（4题合计） |
| 電気回路（問題18） | 直流电路、交流电路（不含三相交流）、暂态现象；必答 | 同上 |
| 電磁気学（問題19） | 静电场、恒定电流、静磁场、电磁感应（不含电磁波）；必答 | 同上 |
| 電子回路（問題20） | 含晶体管和运算放大器的电路；必答 | 同上 |
| 私費外国人留学生選抜：専門試験（300分） | 問題9 電気回路＋問題10 電磁気学（范围同上），2题必答；日英并记 | 10:00–12:00，120分钟 |

- 一般選抜：問題17–20 四题全部必答，専門試験合计300分，各题时间自由分配。
- 一般選抜·私費外国人留学生選抜：専門試験 300＋英语 100，结合面接（5级）和成绩证明书按 A·B·C 三级评定，A 为合格；须参加全部科目和面接。推薦選抜按口述試験、推荐书、成绩证明书和志望理由书综合判定。
- 题目倾向（体验记，非官方）：仅1人提及——2026年度考生称单题配点约为制御工学50、電気回路100、電磁気学100、電子回路50；备考以约15年份过去问反复练习为主。

### 口述試験 / 面接
- **官方形式**：一般選抜：个人面接，考查研究意欲、适性、人物等，按5级评价，不计分，面接中会再确认希望的指导教员；社会人（不在大学就读者）可事先申请（2026/6/19 16:00 截止）以社会人口述試験（专门科目、业绩报告书、英语，8/20 进行）代替専門試験和英语成绩；私費外国人留学生選抜：个人面接，内容和评价方法与一般選抜相同；推薦選抜：口述試験，先用5分钟以内发表毕业研究进展（可用投影仪），再问发表内容和专业基础知识并面接，按5级评价。
