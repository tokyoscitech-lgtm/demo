## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 一般入学試験（夏季·春季）：本専攻没有英语笔试，以出願时提交的英语外部考试成绩判定，配点100分。
- 可交的成绩：TOEFL（PBT 或 iBT）的 Examinee Score Report 或 Test Taker Score Report；TOEIC L&R 公式认定证（2023年度以后受检的也可交デジタル公式认定证的打印件）；中央大学校内实施的 TOEIC-IP（仅限对面实施）成绩单。本専攻 IELTS 不受理（IELTS 只限都市人間環境学、電気電子情報通信工学、応用化学専攻）。
- TOEFL iBT Home Edition / Special Home Edition 不受理。
- 成绩须为考试日前5年以内受检，交原件；考过两种以上的全部提交。换算式由専攻自定，不公布，也没有最低分。
- 自己推薦入学試験：要项没有要求提交英语成绩。外国人留学生入学試験：本専攻没有外语科目，要项没有要求英语成绩。
- 社会人特別入学試験：同样以成绩判定（100分），希望者也可以选择在考场作答英文试卷（可带英和、和英词典各1本）。

### 日本語要件
- 一般入学試験·自己推薦：要项没有要求提交日语成绩；笔试、发表和口述都用日语进行。
- 外国人留学生入学試験：须提交日本語能力試験 N2（或旧2級）以上合格，或日本留学試験（EJU）日语合计200分以上的证明原件；EJU 限2年以内（最近4次）；日本的大学·大学院毕业者可以不交。専門科目用日语作答；论文用英文写的还要附日文论文概略（A4 1页）。
- 自己推薦入学試験：外国籍考生只限日本的大学毕业或在读者。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|

- 一般入试总分300分（英语100＋専門100＋口述100），由研究科委员会综合书类、笔试、口述的结果判定，没有公布合格线。
- 题目倾向（2026年度官方公开题与出题意图）：数学部分考线性代数、微积分、概率统计的基础，情報部分固定有 SQL（查询、视图、ER 图）和 Python 编程题，可以挑自己擅长的4题。

### 口述試験 / 面接
- **官方形式**：一般入试和留学生入试都有口述，配点100分，笔试结束后当天对全员实施，会场·时间当天公布；评价视点是理工系学部毕业程度的基础学力、专门知识与应用力、沟通力和研究意欲。自己推薦入学試験是对自己正在做的毕业研究或研讨课研究作10分钟以内的发表（可用电脑和配布资料，学校备 Windows＋Office 电脑，数据存外部媒体带去并附打印稿1份），之后就发表内容和基础知识提问，并面接人物、研究意欲、适性。
- **実際に聞かれた内容**：没有找到本専攻的口述体验记。

## 📝 详细信息
### 出願資格 / 定員
- 一般入学試験的募集人员为20名（夏季和春季合计）；自己推薦、外国人留学生、社会人特別入学試験各为若干名。博士前期课程入学定员30名。
- 出願资格（一般）：大学毕业（含2027年3月预计毕业）、在外国完成16年学校教育并取得学士学位等 (a)–(h) 之一；中国大学专科（3年制）毕业生须先通过个别入学资格审查。夏季合格者可选2027年4月或2026年9月入学，春季合格者只能2027年4月入学。
- 自己推薦的资格：大学毕业或2027年3月预计毕业（外国籍者限日本的大学），且 GPA 3.00 以上（S=4、A=3、B=2、C=1 加权平均，在读生按2025年度为止的成绩计算）。书类另需履历书和小论文（专攻想学的内容、研究计划、将来想从事的工作，约2,000字，所定用纸，4份）。
- 志願票的“指导教员”栏要填第1、第2希望教员的姓名、联系·商谈日期和方式；不能选其他専攻、兼任和2027年度休讲的教员。出願后不能更改専攻、课程和科目。
- 出願书类（一般）：志願票等（様式Ⅰ–Ⅲ，A4 白纸自行打印）、毕业（预计）证明书和成绩证明书原件（日英以外语言须附公证译文；中国学历可用 CHSI 认证报告直送）、外国籍者的在留卡或护照复印件、英语成绩原件、角2信封出願标签。一般入试不要求研究计划书。
- 出願方式：先缴检定料，再把书类装入角2信封以简易书留邮寄（截止日邮戳有效），也可窗口提交；海外出願须由在日代理人邮寄。没有网上出願。
- 检定料 35,000 日元（便利店或信用卡，E-支払サービス）；已成立的出願不退费。
- 外国人留学生入学試験另需：入学願書、论文（A4 5页以内）、研究计划书（A4 1页）、经费支付能力证明、日语能力证明；出願前须取得希望指导教员签名·盖章或邮件承认。
- 社会人特別入学試験：本専攻要求大学毕业满2年以上（不要求实务经验）；研究计划书 A4 约5页（含图表）；根据书类内容可能免除笔试（事前通知）。
- 个别入学资格审查的申请截止：夏季 2026/5/27（已过）、春季 2026/11/30（周一）必达、外国人留学生 2026/8/19（已过）。
- 学费（理工学研究科）：入学金 240,000 日元，在学料 806,800 日元，实验实习料 75,200 日元，施设设备费 183,700 日元，初年度合计 1,305,700 日元；本校学部毕业者入学金减半。
- 考场规则：後楽園キャンパス，开考前20分钟集合；电卓、尺规、带计算或词典功能的手表原则上禁止，手机和可穿戴设备不能使用。
- 入学手续：A手续夏季合格者 2027/1/14、春季合格者 2027/2/12；B手续 2027/3/8。
- 本校学生另有特別選考（学内推薦·学内選考，含面向他学部生的学内选考），这不是外部考生的路线。
- 咨询：理工三学部事務室 大学院担当（後楽園キャンパス，东京都文京区春日1-13-27），Tel 03-3817-1740，gsse-all-grp@g.chuo-u.ac.jp；不回答合否和成绩问题。
