## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 一般入试、外国人留学生特别入试、3年次特别入试（8月入试和第2次募集相同）：提交 TOEIC 或 TOEFL 成绩原件和复印件，配点 100 分；不考英语笔试。社会人特别入试不用英语成绩。
- 接受：TOEIC 公开测试 Official Score Certificate、TOEFL iBT Score Report（只用 Test Date score，MyBest 不用）、TOEIC IP、TOEFL ITP（IP/ITP 须附本人确认资料，本校实施的免附）；TOEIC IP 线上版须附实施团体盖章的监考·本人确认证明和结果 PDF 打印件。
- 有效期：2024/4/1 以后受验。
- 换算：TOEIC 730 以上满分；未满 730 为 100×分数÷730。TOEFL ITP 先按 (ITP－296)×2.874 换成 TOEIC 相当；TOEFL iBT 先按研究科网站的换算表换成 ITP。没有出願最低分。

### 日本語要件
- 所有区分都不要求提交 JLPT、EJU 等日语成绩。
- 面接用日语进行；为确认英语能力，部分问题可能要求用英语回答（外国人留学生特别入试要项明记）。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 专门科目笔试 | 不实施；在面接的口头试问中考数学（线性代数、微积分、微分方程、复变函数）、材料力学、编程基础 | 2027募集要项·第2次募集要项 |
| 面接（含口头试问）200分，20–30分钟 | 个人面接；可能书面出题或要求在黑板上解答 | 第2次募集要项 |
| 英语 100分 | TOEIC/TOEFL 外部成绩换算 | 第2次募集要项 |

- 一般入试、外国人留学生特别入试总分 300（面接 200＋英语 100），结合学业成绩综合判定。社会人特别入试为面接（10–15分钟）＋成绩＋推荐书＋志望理由书，要项未写配点。
- 缺席面接者不予合格。

### 口述試験 / 面接
- **官方形式**：个人面接（含口头试问）20–30 分钟，确认志望领域的理工专门知识、进学目的、学修·研究意欲、毕业后去向等；口头试问范围为数学（线性代数、微积分、微分方程、复变函数）、材料力学、编程基础，可能书面出题或在黑板上作答。用日语进行，部分问题可能要求英语回答。
- **実際に聞かれた内容**：未找到本専攻的受验体验记，暂无。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：第2次募集 機械システム工学専攻 一般·社会人·外国人留学生特别入试各“若干名”。8月入试的2025年度实绩为推薦 58、一般 28，社会人·3年次·外国人留学生各若干名（入学定员 86）。
- 第2次募集参加専攻：外国人留学生特别入试只有機械システム工学和都市システム工学；電気電子システム工学、情報科学本轮不招留学生。
- 一般入试出願资格：大学毕业或 2027年3月前预计毕业等，并须 2024/4/1 以后受验过 TOEIC 或 TOEFL；个别资格审查者须在 10/20–10/21 申请。
- 社会人特别入试：出願时有1年以上工作经历，并满足大学毕业、学位、文部科学大臣指定或个别审查（2027/3/31 前满 22 岁）之一。
- 外国人留学生特别入试：非日本国籍，持有或将取得可就学的在留资格，并满足外国 16 年教育、外国学士相当学位等 7 项之一；**日本的大学毕业或预计毕业者不能报此区分**，应报一般入试；资格5–7须事先审查。
- 出願方式：纸质书类窗口提交或书留速达邮寄，必达；没有网上出願，检定料可通过 e-apply 网上或便利店缴纳。寄送地址：〒316-8511 日立市中成沢町4-12-1 茨城大学工学部学務グループ（入試担当），Tel 0294-38-5010。
- 检定料 30,000 日元；入学料 282,000 日元（另加学生教育研究災害傷害保険 2,430 日元同时缴纳）；授業料 半期 267,900 日元（年 535,800 日元）。
- 第3次募集：部分専攻可能实施，12月下旬在研究科网站公告。
- 外国籍申请者（含研究生）都要接受安全保障出口管理事前审查，约需1周。
- 合格发表不接受电话询问。
- 咨询：ao.gsse@ml.ibaraki.ac.jp；日立地区（工学）Tel 0294-38-5010。
