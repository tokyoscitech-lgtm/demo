## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 不另设英语笔试，用 TOEFL iBT 成绩评价；修士出願者全员提交，英语母语者也要交。
- 只收 TOEFL iBT 和 TOEFL iBT Home Edition 的 Official Score Report（ETS 直送）。MyBest scores 不采用，考生手里的 Test Taker Score Report 不受理，其他考试一律不收。
- 送分代码：University of Tokyo IS&T，Institution Code 8445，Division 选 Graduate Organization，Department Code 99；送到其他代码研究科查不到。出願时在系统里填受检日和 Appointment Number，出願后原则上不能更换。
- 有效期：受检日在 2024/9/1 以后、出願截止日以前；成绩数据须在 2026/6/30（周二）前到达研究科（已截止）。
- 没有有效成绩就不能完成出願；成绩被判无效的，失去笔试和口述的受験资格。
- 官方没有规定最低分，配点和换算方法官方未公布。

#### 日本語要件
- 要项和専攻案内书都没有要求提交日语成绩，对外国人考生也没有日语门槛；研究科没有另设外国人留学生特别选拔。
- 専門科目过去问有日文版和英文版，数学日英并记；研究计划书可用日文或英文写。作答语言和口述使用的语言案内书没有写明。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 一般教育科目（数学）（配点官方未公布，150分钟） | 研究科共通题：线性代数、解析（微分积分、常微分方程等）、概率·统计三个领域各1题，3题全答 | 2027修士募集要项 |
| 専門科目（配点官方未公布，150分钟） | 从电气电子电路、计算机体系结构、逻辑电路、算法与数据结构、最优化·机器学习、信息通信、信号处理、信息论8个领域出5题，选3题作答 | 2027専攻入试案内书 |

- 选拔分三步：书类选考（成绩证明、TOEFL、研究计划书、推薦書等）→ 笔试（数学＋専門科目）→ 按笔试成绩选出口述对象进行口述，综合判定。各项配点和权重官方未公布。
- 题目倾向（体验记，非官方）：5题对应的领域每年会变，考生一般准备4个左右自己学过的领域，当天挑3题；计算机体系结构常见缓存、有限状态机，算法题结合具体程序。
- 配点（体验记，非官方，仅1人提及，2020年度冬入试成绩开示）：英语120、数学300、専門300、面试100；现行配点是否相同无法确认。

### 口述試験 / 面接
- **官方形式**：夏入试 2026/8/31 线上，只面向按数学和専門科目成绩选出的人；内容是针对笔试答卷的提问、目前的研究题目、入学后的打算等；每人时长、使用语言、配点案内书未写。
- **実際に聞かれた内容**：没有找到近年本専攻修士口述的公开体验记（2024年度入学的一篇合格记把口述部分放在付费段落）。参考：工学系研究科電気系工学専攻（教员有重合，但不是同一场考试）的体验记提到面试官5人，问志望动机、毕业后去向、选研究室理由、毕业研究的新颖性、为什么选那几道题、当场解释笔试里的公式（仅1人提及）。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：夏入试 60 名（含 2026年10月和 2027年4月入学）；本専攻修士没有冬入试。
- 出願资格：日本的大学毕业或 2027/3/31 前预计毕业；在外国完成16年学校教育；在外国取得相当于学士的学位（修业3年以上）；文部科学大臣指定者；经个别入学资格审查认定、2027/3/31 满22岁者等。个别入学资格审查的材料截止为 2026/5/13（周三）（已截止）。
- 志望教员：在 WEB 出願系统里填 10 名教员，不足 10 名视为接受任何教员；提交后原则上不能改顺位，顺位无明显差别时可在专攻指定栏注明（如“第3位到第10位相同”）。另可从清单里最多选3个志望研究领域（人工智能、元启发式、图像处理、自然语言处理、处理器架构、高性能计算、量子计算、通信·网络、IoT、数据库、用户界面、VR·AR、信息安全），也可不选。
- 研究科共通书类：入学願書（系统内填写）、证件照（jpeg，3个月内拍摄）、出身大学成绩证明书、毕业或预计毕业证明书、TOEFL 成绩、检定料缴纳证明、外国籍者等须上传的出口管制审查用检查表；全部扫描成 PDF 上传，纸质原件在入学手续时提交。
- 専攻独有书类：
  - 研究计划书：全员提交，用専攻 2027 版样式；第1页写研究题目、姓名、入学目的（A4 1页以内），第2–4页写研究计划（背景与目的、构想、领域动向与定位等）、参考文献、其他特记事项（A4 3页以内）；字号 11pt 以上，保留样式的标题和说明，引用须注明出处，可用日文或英文。
  - 推薦書（业绩评价书）：用専攻 2027 版样式，推荐人签名或盖章后由推荐人本人上传到指定网站；推荐人不一定是指导教员，了解本人即可。
- 出願方式：只有 WEB 出願，没有邮寄和窗口受理；书类不齐不受理，提交后不能更改。受験票用邮件发送，夏入试到 2026/7/17（周五）17:00 仍未收到的要联系入试担当；考试变更通知发在带密码的専攻入试网站和 WEB 出願系统里。
- 检定料 30,000 日元，可用银行转账、便利店、Pay-easy、信用卡支付，手续费自付，缴后不退；日本政府（文部科学省）奖学金留学生免缴。
- 并愿限制：同一期只能报一个専攻、课程或选拔区分。
- 入学时期：标准为 2027年4月入学，出願时提出希望的可 2026年10月入学。入学手续截止（预定）：2026年10月入学 2026/9/24（周四）（已截止）；2027年4月入学 2027/3/11（周四），入学许可通知约 2026年10月下旬用邮件发出。外国籍者须在入学手续前取得可在学的在留资格；在职者要交所属机构负责人的同意书。
- 入学料 282,000 日元，授業料 半年 267,900 日元（年额 535,800 日元），均为预定额；日本政府奖学金留学生免缴。
- 咨询：専攻入试事务室（工学部2号館4楼電気系事務室内），ice-admission@ee.t.u-tokyo.ac.jp，Tel 03-5841-6712；研究科入试担当，johoriko.t@gs.mail.u-tokyo.ac.jp，Tel 03-5841-7926（平日 9:00–17:00，出願咨询原则上用邮件），〒113-8656 東京都文京区本郷7-3-1。
