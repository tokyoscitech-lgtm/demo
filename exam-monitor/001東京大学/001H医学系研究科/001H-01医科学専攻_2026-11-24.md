## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 不考英语笔试，提交 TOEFL iBT（含 Home Edition）或 IELTS Academic 成绩；只认 2024/8/1 以后受检的成绩。IELTS General Training 和 One Skill Retake 成绩不受理。
- TOEFL：①在 ETS 账户把 Official Score Report 送到研究科（DI Code 8426 University of Tokyo Faculty MED，Division: Graduate Organization，Department 42 Medicine）；②在 WEB 出願系统登记 Appointment Number 和受检日；③上传同一次的 Test Taker Score Report PDF。三步缺一或上传件与官方成绩不一致都按无效处理；以前已用同一代码送过有效成绩的不必再送。
- IELTS：在 WEB 出願系统上传 Test Report Form，并在出願前向 IELTS 事务局申请把同一次的成绩单寄到研究科学務チーム大学院担当（寄到晚于出願截止也受理）。
- 考过多次也只能上传 1 份。
- 免交：学士毕业于澳大利亚、加拿大、爱尔兰、新西兰、英国、美国的大学，或毕业大学出具全校英语授课证明的，须事先联系研究科并在 2026/6/5 前提交审查材料（已截止）；逾期即使母语是英语也不免除。

#### 日本語要件
- 外国人出願者须提交研究科所定样式的「日本語能力証明書」：请指导教员或同等人员按说、听、写、读四项（优／良／可／无）评价填写，也可用日语学校等出具的证明代替；没有规定等级门槛。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：20名（只有 8 月入试一次）。
- 出願资格：大学毕业（含 2027/3/31 前预计）或外国 16 年学校教育等；走个别入学资格审查的须先邮件联系研究科（研究科页写 5/29 前），审查材料 2026/6/5 前提交、6/12 前后通知（非独立出願，已截止）。
- 要提前准备的书类：志願理由書（A4 2 页，左上写「志願理由書」、姓名和页码）、TOEFL 或 IELTS 成绩、日本語能力証明書（外国人，所定样式）、指導教員受入確認票（仅事先定好指导教员者，须访问研究室取得签名）；海外大学的成绩和毕业证明须英文版，否则附公证英译，毕业证明须写明学位名。
- 出願：2027年度起只能通过 WEB 出願系统（要项只在网上公布）；检定料 30,000 日元（银行汇款、便利店、Pay-easy 或信用卡，手续费自付；国费留学生免缴），凭证在截止前上传。
