## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般入试（A日程、B日程都要）：
  - 不另设英语笔试，用 TOEIC L&R 或 TOEFL iBT（含 Home Edition）成绩评价，B日程配点 100 分；A日程作为出願书类的一部分综合判断（说明会 FAQ）。
  - 本系要求出願时必须提交在线版成绩单打印件，出願截止后一律不收，交后不能更换、不退还；截止前没交的没有受験资格。
  - 只认 2024/6/11 以后受检的成绩。TOEIC 须为带真伪确认 QR 码的数字公式认定证 PDF 打印件；TOEFL 须为 Test Taker Score Report PDF 打印件，并在 ETS 账户为该成绩设定 DI code G179。ETS 邮寄的纸质成绩单、TOEFL ITP、TOEIC IP 等团体考试不受理。
  - 要项附録3的换算基准：TOEFL iBT 先按对照表换成 PBT，再用（PBT－296）÷0.348＝TOEIC L&R，例如 iBT 80→PBT 550→TOEIC 约 730（TOEIC 300 分以下不适用）。
- IGP(C)：申请材料不要求英语成绩；面试和考试用英语进行。

#### 日本語要件
- 要项没有要求提交日语成绩，留学生和日本人按同样标准选拔（说明会 FAQ）。
- B日程筆答専門試験必须用日语作答；口頭試問原则用日语，也可以用英语应对（说明会 FAQ）；志望理由书可用日语或英语写。
- IGP(C) 全英语授课，不要求日语。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 筆答専門試験（900分） | A群 微积分、线性代数、概率统计；B群 数理逻辑、自动机与形式语言；C群 数据结构与算法、程序设计；各群出1题，共3题全答 | 9:30–12:00，150分钟 |
| 英语（100分） | 用外部成绩评价，见英語要件 | |

- B日程：总分 1000，笔试和英语成绩上位者才参加口頭試問，合否按笔试、英语和口頭試問综合判定，不考虑 A日程口述的结果；各教员可接收的学生数有上限。
- A日程：不分领域，以学部成绩等优秀者为口述对象（考生不能自选，2026/7/2 マイページ通知）；GPA 作为统一标准使用，出身学校不作考虑（说明会 FAQ）；A日程不合格的可接着考 B日程；出願资格(9)（飞级）只能考 B日程。
- 题目倾向（体验记，非官方）：近年各群都是覆盖整个领域的小题，2023年较易、2024年较难（1人）；合格线传闻每年7成多（1人），另有人转述数学约6成、其他约8成（1人）；建议把约20年的过去问反复做。

### 口述試験 / 面接
- **官方形式**：A日程：口述試験试问毕业研究、志望研究分野和入学后的研究题目以及专门知识，与学部成绩等书类综合判定；B日程：口頭試問只对笔试和英语成绩上位者实施，与笔试、英语一起综合判定；原则用日语、可以用英语；IGP(C)：系或志望导师安排的英语面试和/或考试，原则线上。
- **実際に聞かれた内容**：
  - 2023年8月 B日程（1人提到）：按笔试名次叫号，用30秒介绍毕业研究，其余是确认志望研究室，几乎没有追问。
  - 2021年7月 A日程（对面，1人提到）：5位教员；先用5分钟讲毕业研究并被追问方法和先行研究调查，再问 KL 散度、梯度下降/随机梯度/牛顿法的收敛、内核态与用户态、图灵机、正定矩阵与特征值，以及研究中重要的是什么、研究以外的成绩、印象最深的课程。

- 募集人员：情報工学系受入可能予定人数 97 名（2026年9月和2027年4月入学合计）；IGP(C) 各系若干名。

- 要提前准备的书类：志望理由书（所定样式，日语约1,500字或英语约500词：学士论文研究概要、选第1志望研究室的理由、入学后研究计划、修了后计划）；学部成绩证明尽量印有 GPA；TOEIC L&R 或 TOEFL iBT 成绩单（出願时必交）；IGP(C) 另需导师同意书、研究计划和推荐人直接提交的评价表兼推荐信。

- 咨询：先看大学院入試 FAQ；书类和出願资格问入試課大学院入試グループ（inquiries.grad.se@adm.isct.ac.jp，〒152-8550 東京都目黒区大岡山2-12-1）；其他问题问情報工学系入試担当（cs-exam-inquiry@comp.isct.ac.jp）。
