- AO及外国人AO前期已于2026/10/1（周四）考试、10/15发榜；合格者入学金办理为 **2026/10/16（周五）–10/26**，剩余学费另在2027/3/1（周一）–3/15办理。

## 🎯 入試内容（考什么）
### 語学 / 英語要件
- **一般及外国人一般：学内英語笔试75分钟、100分**，2027/2/15（周一） 9:30–10:45。纸质词典可带，电子词典不可。
- 年度要项没有规定以外部英语成绩替代上述笔试，也未规定外部英语换算表、有效期或不提交外部成绩扣分规则。
- AO、外国人AO、推荐及社会人按展示、面接、出願材料评价；未设置一般路线的英语笔试。不可理解为一般也免英语。

### 日本語要件
- **外国人AO、外国人一般：须提交日本語能力試験2級以上合格证明，并以日语面接审查语言能力**。年度要项沿用“2級以上”措辞；没有列EJU替代，不能自行把其他日语分数换算为免除。
- 在日外国人走普通一般时另须在留卡双面或住民票、留学同意书、国内联系人表；与外国人专门路线的日语证书要求分开判断。

### 筆記試験（专门科目）
一般/外国人一般专业为200分、90分钟，**以下6科选2科**，以事前提交样式12选科为准：

| 科目 | 官方范围 | 依据 |
|---|---|---|
| 工業数学 | 行列、行列式、微分积分 | 2027要项正文8、12 |
| 応用物理学 | 力学、电磁气学及其融合 | 同上 |
| 電気回路 | 电路解析 | 同上 |
| ディジタル回路 | 布尔代数、组合电路、顺序电路 | 同上 |
| 情報工学 | 信息表示、算法与程序设计、计算机结构 | 同上 |
| 制御工学 | 传递函数、时域响应、频率响应 | 同上 |

- 计分构成：英语100、专业200、面接10，结合出願书类综合选拔；未列统一合格最低分或科目足切线。
- 本专攻禁用计算器。考试9:00前入室，用铅笔或自动铅笔，携带受验票；能源/移动的非编程函数计算器规则不适用本专攻。
- 未取得可核验的本专攻修士历年试题或真实考生复盘，不据学部公开题推测院试难度。

### 口述試験 / 面接
- **官方形式**：一般/外国一般2027/2/15（周一） 14:00起面接，配点10，未列每人时长；外国人另用日语审查语言能力。
- AO、外国人AO、推荐：约10分钟展示，围绕志望理由、大学院想学的内容、将来目标，结合面接与书类综合评价；面接本身时长、统一配点未列。
- 社会人：约10分钟展示、面接及书类；日程与校方协商。其展示不是一般的专业笔试。
- **実際に聞かれた内容**：未取得可核验的本专攻应试者一手经验。

## 📝 详细信息
### 出願資格 / 定員
- 专攻总体入学定员 **20名**。年度推荐表列20（前15/后5），学内推荐表列15（前12/后3），AO、一般、外国AO、外国一般、社会人为若干名；表格分配与重叠须向入试课确认，不能累计成独立35名以上总额。
- AO允许大学毕业/2027年3月预计毕业、学位授予、外国16年教育、指定专业学校、文科大臣指定或个别资格审查等路径；个审者须在2027/4/1（周四）满22岁。一般也有相应资格条目；外国路线要求非日本国籍且符合日本大学毕业、外国16年等资格。境外学历或同等认定者须提前咨询入试课。
- 推荐须推荐书，学内生另读学内推荐章。社会人在入学后继续为正规雇员并取得所属长许可；同等资格第5项者须2026/11月底前联系，长修可2–4年。
- **出願前导师联系必须**：志愿票样式1要求取得拟导师承诺并勾选承诺済。研究主题、接受年度、研究室容量须直接确认。
- 所有路线共同核心：志愿票、毕业/预计毕业证明、成绩或学分证明、受验票、照片票、检定料纳入票；使用要项内相应样式，不以学部WEB表替代。
- AO另需自荐书样式2、卒研报告及研究计划样式4、志望理由样式5；推荐以推荐书样式3及研究计划等相应材料办理；一般/外国一般须受验科目届样式12。
- 外国AO另交日语证明、最终学历、成绩、相应学位授予证明、留学同意样式6、国内联系人样式7、国籍/在留证明；外国一般按其清单提交日语证书及在留、联系人等。正式出願前均联系入试课。
- 国内联系人须为定居日本的成年人；外国籍者至少在学生在学期间不归国且能联系母国家长，**没有经济担保责任**，勿混同家长留学同意。
- 在职普通一般者附所属长受验许可；社会人另按所属长推荐、履历与研究计划等相应清单办理。外国原文材料是否另需统一译文语言、个别学历补件，应先向入试课确认。
- **本条上述外部选拔仅邮寄简易书留，末日邮戳有效**；出願后不准改志望专攻或书类内容，受理后材料及检定料不退。检定料30,000日元，本校毕业者10,000，使用指定银行转账单并在指定期付款。

### 入学手续 / 学费 / 支援
- 一般/外国一般入学手续 **2027/3/3（周三）–3/15**；AO/外国AO后期3/1–3/15。前期AO/外国AO10/15合格者，入学金2026/10/16（周五）–10/26、其余学费2027/3/1（周一）–3/15，勿等到3月再缴入学金。

- 入学辞退须2027/3/31（周三） 17:00前完成；手续后缴款按规定扣入学金返还。

- 成绩开示具体申请期、缺考/迟到细则及各导师接收上限尚未取得明确规定，联系入试课确认。
