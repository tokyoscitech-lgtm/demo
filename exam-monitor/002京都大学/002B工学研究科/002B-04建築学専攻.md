## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 8月入试：英语用 TOEFL iBT 成绩计分，配点 100 分（总分 800 分），専攻自己不出英语题。只认 TOEFL iBT 的 Test Date Scores；MyBest Scores、Home Edition、TOEFL ITP 都不受理；TOEIC、IELTS 不在受理范围内。
- 提交方式：向 ETS 申请把 Institutional Score Report 直接寄送到京都大学工学研究科建築学専攻，Institution Code 填 B472；8月入试须在 2026/7/31（周五）17:00 前送达（已截止）。専攻不回答“成绩是否已到”的查询。
- 有效范围：8月入试只认 2024/8/1 以后受检的成绩。交了多份的取最高分。
- 换算：换算成 100 分满分；2026/1/21 以后受检的（新的成绩刻度）按 0–120 的原始分计算。官方没有公布更细的换算式。
- 没有在期限内送达成绩的，英语按 0 分处理。因故无法受检的要事先联系教務掛（建築系）。
- 2月入试（仅外国人留学生，上次的规定）：同样只认 TOEFL iBT（Test Date Scores，Institution Code B472），配点 100 分（总分 400 分），2024/2/1 以后受检，2026/2/6（周五）17:00 必达。
- 研究科共通规定里的 TOEIC 公式认定证本専攻不受理，那是别的専攻的提交书类，不适用于本専攻。

### 日本語要件
- 要项没有要求提交日语成绩（JLPT 等）。试题语言和可用的作答语言，要项里没有写明。

- 8月入试总分 800：英语（TOEFL）100＋設計製図 100＋計画系·構造系·環境系科目 600。三个系各自的配点、题数和选答方式，要项没有写明。
- 合否判定（8月入试）：总分 400 分以上为有资格者。有资格者中，各志望区分第1志望者里总分最高的人，加上总分排前 75 名的人，为优先合格者；其余有资格者按总分从高到低、按志望顺序分配到还有名额的志望区分。同分时先比計画·構造·環境三系合计分，再比第1志望区分对应科目的得分率。
