## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 须提交 TOEFL iBT（含 TOEFL iBT Home Edition）的公式成绩，専攻不另设英语笔试。TOEIC、IELTS 本専攻不收；研究科共通规定里的 TOEIC L&R·IELTS 提交办法不适用于本専攻。
- 提交要做三件事：让 ETS 把公式成绩送到研究科（DI 代码 8596，Department 代码 99）；在 WEB 出願系统的マイページ登记 Appointment Number 和受验日；上传 Test Taker Score Report 的 PDF。
- 本専攻的提交期限：报特別口述選考的人 2026/6/4（周四）必须到位；不报特別口述選考的修士考生，専攻推荐同样在 6/4 前提交。因特殊情况交不出公式成绩的，须在 2026/5/29 前向机械系事務室咨询。
- 只采用 Test Date Scores，不采用 MyBest Scores。TOEFL ITP 等团体受验成绩不受理，考场也不举行 TOEFL ITP。母语是英语的人也要交。
- 有效期：受验日在 2024年9月以后的成绩有效。考过多次的可以全部送分，但只有在マイページ登记的那一次被采用，期限内可以反复更改。
- 最低分数线、换算方法和英语的配点，官方都没有公布。

### 日本語要件
- 要项和専攻入试案内都没有要求提交 JLPT 等日语成绩。
- 数学的试题同时发日文版和英文版。機械工学的试题为日文，留学生和提出希望的人另发英文的说明。作答语言官方没有写明。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 数学（一般教育科目，150分钟，配点官方未公布） | 微积分与微分方程、级数·傅里叶分析·积分变换、线性代数、曲线·曲面、复变函数、概率统计·信息数学等领域共出6题，本専攻要求选3题作答 | 2027修士募集要项／専攻入试案内 |
| 機械工学（第1部）（60分钟，配点官方未公布） | 以热工学、流体工学为主；题数官方未写明 | 専攻入试案内 |
| 機械工学（第2部）（90分钟，配点官方未公布） | 以材料力学、机械力学·控制、机械设计·生产工学为主；题数官方未写明 | 専攻入试案内 |

- 合否判定：按笔试、面接和提交书类综合评价；总分构成和各科配点官方没有公布。笔试合格者才进入面接。
- 特別口述選考合格者免笔试（数学和機械工学都免），但面接不能免。
- 配点（体验记，非官方，仅1人提及）：機械工学合计 900 分，热力学（含传热）、流体力学、机械力学（含控制）、材料力学、生产工学各 180 分；数学 300 分。
- 题目倾向（体验记，非官方）：都是学部必修课程度的基础题，难题大家都做不出、不太拉开差距；热力学多为气体循环，传热多为列能量平衡、解热传导方程，材料力学多为梁，机械力学多为列转动运动方程。2025年8月的数学和四力据称比往年容易。

### 口述試験 / 面接
- **官方形式**：一般选考在笔试之后对笔试合格者进行面接，内容是询问希望的专门分野、研究课题、指导教员等；按点名顺序进行，点到时不在场即不合格。配点和时长官方没有公布。特別口述選考是另一条路线：出願时选择并提交専攻书式，6月下旬出书类审查结果，通过者在7月下旬以前接受线上口述；被选上的人免笔试并同时得知指导预定教员，没选上的人自动转入8–9月的一般笔试。特別口述選考合格者也必须参加 9/4 的面接，缺席即不合格。
- **実際に聞かれた内容**：体验记（非官方）只有1人提到，称面接只是简短交谈几句、不直接左右合否，没有写具体问题。特別口述選考的口述内容没有找到公开的体验记。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员为52名（修士課程，出願日程A）。本年度没有冬入试，所以没有第二轮名额。
- 出願资格：日本的大学毕业或 2027年3月31日前预计毕业；在外国完成16年学校教育；在外国取得相当于学士的学位（3年以上的课程，且该校受过所在国政府或有关机构的评价）；文部科学大臣指定者；学位授与機構授予学士学位者；经个别入学资格审查认定且届时满22岁者。走个别资格审查的须在 2026/4/21（周二）前向学務課大学院チーム提交书类（已过）。
- 10月入学：出願时已经毕业、或 2026年9月30日前预计毕业的人可以选 2026年10月入学，仅限出願日程A。
- 志望教员的填写：在志望調査票上写希望的指导教员。报特別口述選考的人在出願时一并提交（书式B，可填到第10志望，每个志望写教员和研究课题各1项）；其他考生用随受験票一起发来的调查票，在指定期限内提交，具体期限専攻入试案内没有写。指导教员按考试成绩和志望综合决定，不一定是第一志望。
- 出願书类（研究科共通）：入学願書（在 WEB 出願系统填写）、证件照数据（3个月内、正面、无修图）、检定料缴纳证明、毕业证明书（已毕业者；毕业预定证明不用交）、学部成绩证明书、安全保障出口管理チェックシート（外国籍、双重国籍、入学前所属机构在海外的人）、国费留学生证明（该当者）。全部做成 PDF 上传；日语和英语以外的文件要附日译或英译，外国大学的证明须附该校出具的带公章的英译。合格后入学手续时交纸质原件。
- 特別口述選考的専攻独自书类（出願时交给機械工学専攻）：书式A（须亲笔签名）、成绩证明书（预定毕业者交1–3年级成绩；东大机械系预定毕业者免交，已毕业者要交）、到4年级为止可取得毕业学分数的证明（成绩证明书上有记载可省略，已毕业者免交）、书式B（志望調査票）、书式C（A4横向、含封面4页以内，修士研究计划、毕业研究的进展与计划、学部学习情况与自我评价各1页）、TOEFL 公式成绩。书式在専攻入试信息页下载。
- 出願方式：只能通过 WEB 出願系统，没有邮寄和窗口受理。书类不齐不受理，出願后不能更改、不退还。
- 检定料 30,000 日元，可用便利店、Pay-easy、网上银行、中国决济或信用卡支付，手续费自付；国费留学生免缴。缴纳后不退。
- 并愿限制：同一时间不能报工学系研究科的两个以上専攻或课程；不能与其他大学、本校其他研究科重复入学。
- 外国籍考生：入学手续前须取得不妨碍大学院入学的在留资格。新申请在留资格通常要2–3个月以上，要项建议需要新办在留资格的人考虑4月入学。按安全保障出口管理规定，即使最终合格，也可能不被许可入学或研究活动受限。
- 受験票 2026/7/3（周五）15:00 左右在マイページ交付，自行打印后考试当天带去。
- 入学料 282,000 日元，授業料前期 267,900 日元（年额 535,800 日元），均为2027年度预定额；国费留学生不收。
- 考场规则：各科目的考场在 2026/8/28（周五）10:00 前公布；开考前20分钟入场；迟到30分钟以内可以入场；考试中途不能离场。可带黑色铅笔或自动铅笔、橡皮、非台式的削笔器、只有计时功能的表；不能用圆珠笔。能否用计算器官方没有写。
- 在职入学者须在入学手续时提交单位的承诺书。需要受验·修学上照顾的人在出願期限前向学務課大学院チーム和専攻事務室提出。
- 咨询：専攻层面是機械系事務室（〒113-8656 東京都文京区本郷7-3-1，Tel 03-5841-6301，kyoumu@office.mech.t.u-tokyo.ac.jp）；要项层面通过研究科网站的咨询表单联系学務課大学院チーム。合否不接受电话、邮件查询。
- 成绩开示：要项和専攻入试案内都没有记载。
