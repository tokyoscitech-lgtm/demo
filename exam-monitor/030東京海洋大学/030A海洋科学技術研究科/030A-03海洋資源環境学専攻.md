## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 第1次募集一般選抜（口述試験による選抜）：出願时必须提交 TOEIC L&R 的成绩单原件。公开テスト和 IP テスト都可以，线上的 IP テスト不行。成绩须在出願受理最终日之前2年以内取得。要项没有写最低分数线。
- 第1次募集一般選抜（学力試験による選抜）：外国語（英语）笔试，满分100分，90分钟。可以提交 TOEIC L&R、TOEFL iBT 或 IELTS 的成绩，换算分和笔试分取高的一方。
- 换算：TOEIC 的换算分＝（分数－220）÷6，小数点以下舍去，上限100分，下限0分。例如 TOEIC 700＝80分，TOEIC 820＝100分。TOEFL iBT 和 IELTS 由研究科先换算成相当的 TOEIC 分数，再套用同一公式；对应表官方没有公布。这套规则适用于博士前期課程的全部専攻。
- 免考：TOEIC L&R 700 分以上、TOEFL iBT 72 分以上（2026/1/20 以前受检）或 Overall Score 4 以上（2026/1/21 以后受检）、IELTS Overall 5.5 以上的，可以免考外国語，得分一律按80分计。
- TOEFL 除了邮寄从 ETS 账户打印的成绩单，还要让 ETS 直接寄送公式成绩（DI Code G283，Department code 不用填）；只采用 Test Date 成绩，不用 MyBest。所有成绩都须是出願受理最终日前2年以内受检、能在出願期间提交原件的。
- 第2次募集：未公布（截至 2026-10-17）。大学的外部英语考试利用页没有区分轮次，预计规则相同，以新要项为准。

### 日本語要件
- 一般選抜的要项没有要求提交 JLPT 等日语成绩。
- 外国人留学生特別選抜：共通科目和専門科目可以在日语和英语之间选择考试语言；外国語这一科只考日语。日本留学試験（EJU）日本語（不含記述）300分以上的可以免考外国語，按80分计；上面的英语成绩也同样可以用来免考。
- 社会人特別選抜的小論文可以选日语或英语，但有的専攻的口頭試問仍用日语进行。官网公开的本専攻共通科目过去问有日语版和英语版两种。
