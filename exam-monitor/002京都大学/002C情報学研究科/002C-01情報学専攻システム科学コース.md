## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各轮次都不另设英语笔试，用外部成绩评价：只收 TOEFL iBT 的 Test Taker Score Report 或 TOEIC L&R 公式认定证，配点 60 分。
- 换算：TOEFL＝0.6×分数；TOEIC＝0.6×（0.134×分数－32.66）；小数点以下进位，上限 60 分。例如 TOEFL 90＝54 分，TOEIC 860＝50 分。
- 成绩须为出願截止日前2年以内受检；Home Edition 可以，TOEFL Essentials、ITP、TOEIC IP 和 IELTS 不受理；考过多次的只交1份。2027年度实施的入试为止 TOEFL 用 0–120 分计算。
- 出願时没交的英语按 0 分，不接受考试当天补交。8月入试为复印件邮寄，第2次募集上传到 WEB 出願系统。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 8月入试：笔试日语出题、可用日语或英语作答；口头试问用日语进行，可用英语回答。
- 第2次募集：数学日语出题、可用日语或英语作答；口头试问的发表和回答可用日语或英语，用英语时另加评价日语沟通能力的提问；外国学历者持有日语能力考试一级或二级证书的，在志望说明书里注明，并在考试时带原件或复印件。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 8月入试：数学（200分） | 微积分、线性代数 | 9:30–11:30，120分钟 |
| 8月入试：専門科目（200分） | 复变函数论、概率统计、控制工学（古典控制，不含非线性和采样控制）、信号处理（傅里叶分析、Z变换、线性滤波器）4个领域选2个，各100分 | 12:30–14:30，120分钟 |
| 第2次募集：数学（200分） | 微积分、线性代数等；専門科目不实施 | 10:00–12:00，120分钟 |

- 8月入试：数学 200＋専門 200＋英语 60，口头试问对象者另加口头试问 80 分，按得分、出願书类和各志望区分可接收人数决定合格者。
- 第2次募集：志願者多时先按出願书类做一次选拔；通过者按数学、英语、口头试问的得分和出願书类综合判定。
- 变更点（2028年度入学）：2027年8月入试起视志願者人数可能先按志望说明书、成绩证明、英语成绩做书类选拔，通过者才参加学力检查。
- 题目倾向（体验记，非官方）：数学时间紧、偏难，専門科目相对好拿分；备考以过去问为主（2020–2021年内部生2人，当时配点不同）。

### 口述試験 / 面接
- **官方形式**：8月入试：笔试第二天口头试问 80 分，只叫按笔试、英语得分和出願书类选出的对象者，问与志望区分相关的学识和希望的研究，日语进行、可用英语回答；第2次募集：口头试问 200 分，先用幻灯片做约5分钟发表（志望动机、本科所学或研究经过、希望领域、研究抱负）再提问，发表资料做成 PDF，数学考完后用 USB 等提交并带1份纸质打印件。
- **実際に聞かれた内容**：
  - 2–3 名教员对 1 名考生，其中有第一志望区分的教员（2020年、2021年，2人提到）。
  - 现在的研究、研究生阶段想做的研究、毕业后的打算，研究目的和必要性被追问得较深（2020年、2021年，2人提到）。
  - 时长约 7 分钟（2020年，1人提到）。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：28名（8月入试）；第2次募集若干名；2027年10月入学若干名。
- 出願资格：大学毕业（含预计）或外国16年学校教育等；资格10须事先审查（第2次募集 2026/12/7 17:00 必达，非独立出願）；外国大学毕业（含预计）者须在出願截止前完成 AAO 学历验证申请；只能报一个コース，第2次募集不能与10月入学并愿，8月入试合格者不能再报；志望区分按顺序填写、数量不限，没填的不分配，シ－９ 须写到细目如「シ－９(a)」。
- 要提前准备的书类：志望说明书（A4 2页以内，写研究实绩和入学后研究计划，做过毕业研究的写题目和内容，不得使用生成 AI，日语或英语）、TOEFL/TOEIC 成绩单；书类须为日语或英语，其他语言附译文。
- 出願：第2次募集只能通过 WEB 出願系统上传书类，纸质成绩证明须原件连同打印的入学願書以書留速達等寄送、期限内必达（8月入试为纸质邮寄或窗口提交）；检定料 30,000 日元＋决济手续费。
- 咨询：情報学研究科教務掛（総合研究8号館1階），jyoho-kyomu@mail2.adm.kyoto-u.ac.jp，Tel 075-753-4894／5500（平日 9:00–17:00，12:00–13:00 除外）；コース方面找コース長 石井 信 教授（shushoku@sys.i.kyoto-u.ac.jp）。
- 并愿：只能报一个コース，第2次募集不能与10月入学并愿，8月入试合格者不能再报。
