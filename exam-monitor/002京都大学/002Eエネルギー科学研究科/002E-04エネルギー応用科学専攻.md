## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 第1回、第2回選抜：
  - 専攻不另设英语笔试，用 TOEFL 或 TOEIC 成绩换算评价：第1回配点200分，第2回配点100分；换算公式和最低分官方没有公布。
  - 有效成绩为 2024/8/1 以后受检的。TOEFL 只收 TOEFL iBT（含 Home Edition），只用 Test Date Scores、不用 MyBest Scores，TOEFL ITP 等团体考试无效；TOEIC 只收在日本举行的 TOEIC L&R 公开考试，Bridge、S&W、团体考试（IP）无效。IELTS 不受理。
  - TOEFL 要交两样：出願时随书类交 Test Taker Score Report（网上下载的 PDF 打印件也可以），并请 ETS 把 Official Score Report 寄到京都大学（DI 代码 9501，Department 代码 69），到达期限为第1回 2026/7/17、第2回 2026/9/18。
  - TOEIC 在出願时交数字公式认定证（PDF 打印件），并须在出願日前在 TOEIC 报名网站把本専攻登记为成绩提交对象（申请代码 00013704）。
  - 要项一处写没交公式成绩按0分，另一处写没有提交 TOEFL 或 TOEIC 成绩证明书即不合格；按“不交成绩就不合格”准备。
- 外国人留学生特別選抜：
  - 当天考学内英语笔试（9:30–11:30 一场），不收外部成绩，配点官方未公布。
- 变更点（官方予告）：2028年度起外国人留学生特別選抜改用 TOEFL 或 IELTS 的外部成绩评价英语，不再考学内英语。

#### 日本語要件
- 一般选拔和外国人留学生特別選抜的要项都没有要求提交日语成绩（JLPT、EJU 都没有规定）。
- 要项只有日文版，没有写明试题语言、作答语言和口头试问用的语言；通常课程用日语授课和指导。
- 英语授课的 IESC 在本専攻只招博士，修士不能走这条路线。

### 口述試験 / 面接
- **官方形式**：第1回選抜有口头试问（200分，问志望理由、配属希望、研究经历、学习内容及理解程度、将来展望等）；第2回選抜有口头试问（100分，内容同第1回）；外国人留学生特別選抜有口头试问（问以往研究·学习内容、进修士的动机、入学后的研究计划和展望，配点未公布）；每人时长和使用语言官方未公布。
