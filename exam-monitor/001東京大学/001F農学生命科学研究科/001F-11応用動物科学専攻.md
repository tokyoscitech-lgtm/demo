## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 须提交 TOEFL iBT 成绩（iBT Home Edition 也可以），A日程、B日程相同；研究科自己不举办英语考试。
- 送分方式：通过 ETS 把 Institutional（Official）Score Report 送到 DI code 1113（東京大学大学院農学生命科学研究科），用别的代码送的无效；出願时在 WEB 系统里填 Appointment Number、受检日和分数。Test Taker Score Report 不用交。
- 有效的受检日：A日程为 2024/8/1–2026/6/13；B日程为 2025/2/1–2026/11/15。
- 不采用 MyBest 分数；除 iBT 以外的考试种类一律不受理。
- 官方没有公布最低分数线和换算方法。
- 变更点：上一年度（2026年度入试）A日程是在研究科内考 TOEFL ITP，只有 B日程交 iBT；本年度两个日程都改为交 iBT 成绩。

### 日本語要件
- 募集要项和専攻入试案内都没有要求提交日语成绩。
- 笔试 A日程是日英并记出题，B日程只用英文出题；两个日程都可以用日文或英文作答。

- 选拔由英语（TOEFL 成绩）、专门科目笔试、口述和书类审查组成；各项的配点和合格标准官方没有公布。
- WEB 出願时必须在“専門科目”栏填上科目名「応用動物科学」，不填按书类不全处理。
- 题目倾向：本次没有查到可用的体验记，不作归纳；请直接看募集要项页上 2026年度实施的试题和出题意图。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：A日程 19 名，B日程若干名。合格人数可能少于募集人员。
- 出願资格：日本的大学毕业或 2027年3月31日前预计毕业；在外国完成16年学校教育；在外国大学修完3年以上课程并取得相当于学士的学位；文部科学大臣指定者；取得学位授与机构的学士学位；经个别入学资格审查认定且到 2027年3月31日满22岁者，以上任一项。
- 个别入学资格审查的申请截止：A日程 2026/5/7（已截止），B日程 2026/10/7（已截止）。有跳级或在日本以外受过教育的人，出願前要先联系教務課。
- 入学时期：A日程可选 2026年10月或 2027年4月，B日程可选 2027年4月或 2027年10月；出願后不能更改。
- 出願只能通过 WEB 出願系统（https://webentry.ofc.a.u-tokyo.ac.jp/）。提交物：入学願書（系统内填写，上传3个月内的照片）、大学入学以来全部成绩的成绩证明书、毕业（预定）证明书（写明学位名和授予日期）、検定料缴纳证明、TOEFL 成绩、国费留学生证明（符合者）。本校农学部毕业者等可以免交成绩和毕业证明。合格后办入学手续时要交纸质原件。
- 専攻独有提交物：推荐书至少1份，由了解本人研究情况的人撰写。在 WEB 系统的“その他”栏填推荐人姓名和邮箱，系统把上传链接和期限发给推荐人，由推荐人自己上传 PDF。
- 志望填写规则：对照《教員並びに専門分野一覧》填专门分野和教员名，最多填到第3志望；第2、第3志望可以填同一分野的其他教员，没有可以不填。一览表会因人事变动更新，出願前看最新版。
- 検定料 30,000 日元，可用便利店、信用卡、Pay-easy、银行汇款等支付（不能用邮局）；缴纳期间 A日程 2026/4/13–6/23，B日程 2026/10/5–11/25。国费留学生免缴，缴后不退。
- 入学料 282,000 日元，授業料 年 535,800 日元（前期 267,900 日元），均为预定额。
- 在职者入学须提交雇主的同意书（社会人特別選抜已取消）。
- 可以申请得分开示，申请书在募集要项页下载。
- 咨询：出願手续问农学生命科学研究科教務課学生支援チーム大学院学生担当（〒113-8657 東京都文京区弥生1-1-1，daigakuin.a@gs.mail.u-tokyo.ac.jp，Tel 03-5841-5010）；専攻的事问専攻主任·入试担当 田中 智 教授（Tel 03-5841-5472）或入试担当 片岡 直行 准教授（Tel 03-5841-5372）。
