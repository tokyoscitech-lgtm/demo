# 信息源与提取指南（info-sources）

判断"该抓哪个页面、字段藏在哪、日文原词是什么"时读本文件。SKILL.md 已给出流程，这里补充领域细节。

## 目录
- 1. 各类信息的常见位置

## 1. 各类信息的常见位置

日本大学院的入试信息通常分散在这些层级，优先看**官方**、越靠上越权威：

- **大学院 / 研究科 官网的「入試情報 / 入学案内 / 受験生の方へ」页**：最权威的日程与募集要項入口，`watch_urls` 首选放这里。
- **「募集要項」PDF**：出願資格・出願期間・必着日・提出書類・入試日程・定員最详细，但是 PDF 且长——抓取务必截断（`fetch_token_limit`），只提关键字段，别整份拉进来。
- **「入試日程 / 選抜スケジュール」页**：筆記・口述・面接日期与合格発表日。
- **「説明会 / オープンキャンパス / 進学説明会」页**：说明会日期与报名截止，常与入试信息分开。
- **专攻 / 研究室 / 指導教員 页**：研究室訪問可否、事前連絡要否、过去問領取方式，有时只在这里写。
- **过去問（過去問題）页**：是否公開、線上下载 or 需到窗口领取。

一个目标建议在 `watch_urls` 里放 1 个主页面（入試情報页），最多再加 1 个（募集要項 PDF 或说明会页）作为次要；**默认每次只抓 `watch_urls[0]`**，主页面显示有更新时才追加抓次要页。

## 2. 日文术语对照（提取时按这些词定位）

- 募集要項 → 招生简章 / 报考指南
- 出願（しゅつがん）→ 提交申请；出願期間 / 出願受付 → 申请受理期
- 必着（ひっちゃく）→ （邮寄）必须送达日；≠ 邮戳日（消印有効）
- 消印有効 → 以邮戳日为准
- Web 出願 / インターネット出願 → 网络报名
- 入学者選抜 / 選抜 → 招生选拔
- 筆記試験 → 笔试；口述試験 → 口试；面接 → 面试；小論文 → 小论文
- 合格発表（ごうかくはっぴょう）→ 放榜 / 结果公布
- 定員 / 募集人員 → 招生名额
- 出願資格 → 报考资格
- 提出書類 → 需提交材料；研究計画書 → 研究计划书；成績証明書 → 成绩单
- 語学 / 英語外部試験（TOEFL・TOEIC・IELTS）→ 语言成绩要求
- 説明会 / 進学説明会 → 招生说明会；オープンキャンパス → 校园开放日
- 研究室訪問 → 实验室 / 研究室拜访；事前連絡 → 提前联系（导师）
- 過去問題 / 過去問 → 历年真题
- 一般選抜 / 特別選抜 / 外国人留学生特別選抜 → 普通/特别/留学生特别选拔
- 春季 / 秋季入試、第 1 次 / 第 2 次募集 → 春/秋季考、第一/二次招生

## 3. 检索式模板（仅在页面失效需重新定位时用，消耗 max_search_per_run）

按目标信息拼，尽量带上年度与"大学院"：

- 定位入试信息页：`<大学名> <研究科> <専攻> 大学院 入試情報`
- 定位募集要項：`<大学名> <研究科> 募集要項 <年度>`（如 2027）
- 定位日程：`<大学名> <研究科> 入試日程 出願期間 <年度>`
- 定位说明会：`<大学名> <研究科> 大学院 説明会 <年度>`
- 优先官方域名（`*.ac.jp`、`*.u-tokyo.ac.jp` 等）；找到官方页就更新该目标的 `watch_urls`，别停留在聚合站/中介站。

## 4. 提取与判重要点

- 只提 SKILL.md「关键字段」列表里的东西；一个字段有多来源时以**官方页 > 募集要項 PDF > 说明会页**为准。
- 事件判重：同类型（如"出願期間"）+ 同年度视为同一事件。日期变了 → 记为"变化"；首次出现 → 记为"新增"；文字微调但日期不变 → 视为无变化，不提醒。
- 记录每个事件的 `source`（页面类型 + 链接）、`first_seen` 时间、以及是否已 `notified`，避免跨运行重复提醒。
- 日期一律规范成 YYYY/MM/DD；注意区分**必着**与**消印有効**——两者含义不同，别混。

## 5. 常见坑

- **年度混淆**：页面常同时挂着上一年度和本年度要項，务必用年度（如"2027 年度")锚定，别把去年的日期当新消息。
- **必着 ≠ 邮戳**：报出願截止时标明是"必着"还是"消印有効"。
- **PDF 很长**：务必截断抓取，只取含日程/資格的段落；不要整份塞进上下文，也不要照抄原文（版权）。
- **春秋两季**：很多研究科一年两次招生，注意别把秋季日程报成用户关心的春季（或反之），必要时在事件里标季次。
- **聚合站过时**：塾/中介/论坛的信息可能滞后或有误，一律回官方页核对。

## 6. 経験談 · 内部信息 · 面接内容：去哪找、怎么鉴别（常规巡检）

**每次运行都查**（受经验专用小预算约束，默认 ≤4 fetch / ≤3 search；`deep_dive: weekly` 目标加大预算）。目的是把"笔试真考什么范围、面接实际问什么、研究室/教员内部实情"提炼进 md 正文，**用自己的话，不搬原文**，每条带 `〔平台·年度·几人〕`。**优先内部/一手信息**（研究室訪問·在校生/OB·教员直接沟通），其次公开体験記，最后聚合站。孤证一律标 `要検証`，与官方冲突以官方为准并注明分歧。

### 常见来源（按可信度粗排）
- **公开過去問本身**（官方）：反推题型/范围/难度最可靠，优先于任何经验帖。
- **note / 個人ブログ の合格体験記**：常写面接被问内容、准备时长、日程细节；署名年度较清楚。
- **知乎 / 小红书 的日本读研经验**：中文考生视角，面接氛围、导师联系、语言要求实操多；注意时效与真伪。
- **研究室/ゼミ 学生的博客、研究室主页「メンバー/进学実績」、5ch/したらば 等匿名板**：可能有一手信息但**噪声大、需交叉验证**，孤证一律标 `要検証`。
- 塾/中介文章：可作线索，但结论回官方核对，别当事实。

### 内部信息（一手·最优先，但最需鉴别）
- **研究室訪問/事前面談纪要**：教员对出题范围、录取倾向、名额松紧的口径——往往只此处可得；写入时标〔研究室訪問·年度〕。
- **在校生 / 直近合格者 / OB·OG**：面接实际流程、笔试难度体感、内部推荐/特别选拔实操。
- **教员倾向**：近年研究方向、是否招人、对外部生态度（据研究室主页更新、论文、说明会问答归纳）。
- 鉴别：内部信息优先于公开体験記，但**孤证必标 `要検証`**，尽量交叉≥2 源；涉及个人隐私/未公开数据只记结论方向、不搬细节。

### 检索式（消耗经验帖专用 search 预算）
- 面接内容：`<大学名> <研究科> <専攻> 大学院 面接 聞かれた` / `… 口述試験 体験`
- 合格体验记：`<大学名> <専攻> 大学院 合格体験記` / `… 院試 対策 note`
- 笔试范围：`<大学名> <研究科> 院試 過去問 難易度` / `… 専門科目 対策`
- 中文视角：`<大学名> <専攻> 修士 面试 经验`（知乎/小红书）

### 鉴别与写入规则
- **标年度**：往年被问的题≠今年会问，必注年度让用户自判参考价值。
- **数人头**：同一说法几人提及决定分量——`複数一致` > `2人が言及` > `1人のみ·要検証`。
- **交叉验证**：经验说法与官方/过去問冲突时以官方为准，并在正文注明分歧。
- **不搬原文**：过去問题目、经验帖长段一律归纳成"范围/方向"，直接引用极短（15 词内）且注出处；链接进底部参考表，正文只留短标签。
- **官方不带标签、经验必带标签**，二者不混入同一结论行。
