## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各轮次都不另设英语笔试，用外部成绩评价：只收 TOEFL iBT 的 Test Taker Score Report 或 TOEIC L&R 公式认定证；成绩须为出願截止日前2年以内受检；Home Edition 可以，TOEFL Essentials、ITP、TOEIC IP 和 IELTS 不受理；考过多次的只交1份；出願时没交的英语按 0 分，不接受考试当天补交。
- 8月入试·推薦選抜：配点 50 分，TOEFL＝0.5×分数，TOEIC＝0.5×（0.134×分数－32.66）；例如 TOEFL 90＝45 分，TOEIC 860＝42 分；口头试问对象者按笔试和英语得分选出。
- 第2次募集（国際プログラム）：配点 100 分，TOEFL＝1.0×分数，TOEIC＝0.134×分数－32.66；例如 TOEFL 90＝90 分，TOEIC 860＝83 分；2027年度实施的入试为止 TOEFL 用 0–120 分计算。
- 变更点：2026年2月的国際プログラム还收 IELTS 并用另一套换算式，2027年2月起只收 TOEFL/TOEIC，按研究科统一公式换算。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 8月入试：笔试题日英并记，可用日语或英语作答；口头试问用日语或英语。
- 第2次募集（国際プログラム）：口头试问用英语，志望説明書必须用英语写；国際プログラム只用英语即可修完。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 8月入试：情報学基礎（100分） | 线性代数·微分积分 2题＋算法与数据结构 2题，4题全答 | 9:30–11:30，120分钟 |
| 8月入试：専門科目（100分） | 統計学、パターン認識と機械学習、情報理論、信号処理、形式言語理論、認知神経科学·知覚·認知心理学 6个领域各1题，选2题；认知神经科学以 Ward《The Student's Guide to Cognitive Neuroscience》第4版为参考范围 | 12:30–14:30，120分钟 |

- 8月入试：情報学基礎 100＋専門 100＋英语 50；口头试问对象者另加口头试问 200 分；按笔试、英语、口头试问得分和各志望区分可接收人数决定合格者。
- 推薦選抜：不考笔试，按学业成绩、英语成绩、推荐信、志望説明書和口头试问选拔。
- 第2次募集（国際プログラム）：不考笔试，先按出願书类做一次选拔，书类审查 100＋口头试问 200＋英语 100，结合各志望区分可接收人数决定合格者。
- 变更点（2028年度入学）：2027年8月入试起视志願者人数可能先按志望説明書、成绩证明、英语成绩做书类选拔，通过者才参加学力检查。
- 题目倾向（体验记，非官方）：専門多选統計学＋情報理論，不少人另备信号処理、当天挑2科；情報学基礎得分普遍低于専門，动态规划被认为难（2022–2025年，4人提到）。

### 口述試験 / 面接
- **官方形式**：8月入试：笔试第二天口头试问 200 分，只叫按笔试和英语得分选出的对象者（名单 8/2 13:00 前掲示），问与志望区分相关的学识和希望的研究，日语或英语；推薦選抜：口头试问，日语或英语；第2次募集（国際プログラム）：英语口头试问 200 分，就志望区分相关学识和希望的研究做约5分钟发表再质疑，只能用书画相机，须自备 A4 纸发表资料。
- **実際に聞かれた内容**：
  - 约10名教授在场，问一两个问题；该考生递补合格（2022年8月，1人提到）。
  - 体验记作者多数没被叫去口头试问即合格，一人称 2025年8月约叫了6人（2022–2025年，3人提到）。
