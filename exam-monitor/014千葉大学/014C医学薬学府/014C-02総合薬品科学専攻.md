## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 不另设英语笔试，出願时提交外部成绩，换算成100分计入（外国語）。
- 可用 TOEFL iBT、TOEFL ITP Level 1、TOEIC L&R、TOEIC L&R-IP（线上实施的除外），只认2023年4月以后受检的成绩，交成绩单原件和复印件。
- TOEFL iBT 用 Test Date 成绩（不用 MyBest），ETS 邮寄的 Test Taker Score Report 和 My TOEFL Home 直送（Institution Code 9154，出願截止前送达）两种手续都要办，并在 PDF 版成绩单右上角写上直送日期一并寄出；TOEIC 打印 PDF 版数字公式认定证（A4 一张）提交。

#### 日本語要件
- 要项没有要求提交日语成绩。2025年8月的基礎生物试题为日英并记的选择题。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 基礎科目（200分） | 基礎生物（必答，生化学领域）＋基礎化学（必答，有机化学领域），按大学教养课程程度出题；另在考场从有機化学、生物化学中选1题作答 | 10:00–11:30，90分钟 |
| 外国語（100分） | 出願时提交的 TOEFL／TOEIC 成绩换算 | |

- 总分400（基礎科目200＋外国語100＋面接100），结合成绩证明书等综合判定；各科有基准点，任一科不到即不合格，也可能因志望研究领域的接收人数而不合格。
- 过去问归纳（2025年8月）：基礎化学4题（命名与立体构型、芳香性、药物合成中间体、羰基反应机理）；基礎生物25道四选一（糖、脂质、蛋白质、维生素、酶动力学、核酸等）；有機化学5题（结构推断、反应条件、主产物、多步反应机理）；生物化学3大题22小问（生物膜与转运、ATP与能量代谢、DNA结构与复制，填空、计算和60–80字简答）。
- 文部科学省国費外国人留学生免考基礎科目和外国語。

### 口述試験 / 面接
- **官方形式**：8月入试在笔试当天 13:00 起面接，100分；按官方出题意图，根据出願书类考查是否理解医药品的社会性侧面、是否有基础知识支撑的广阔视野和灵活的思考力。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：50名（2027年4月入学）；2026年10月入学若干名；两者都在8月入试中选拔，没有第2次募集。
- 出願资格：大学毕业（含2027年3月前预计，10月入学为2026年9月）或外国16年学校教育等；大学在学3年以上成绩优秀、外国15年课程修了、个别审查认定且满22岁者须先过出願资格审查（2026/7/1–7/3，已截止，非独立出願）。
- 要提前准备的书类：外部英语成绩原件及复印件（TOEFL iBT 另须办直送）；外国人志願者用所定履历书、住民票（没有住民登记的交护照复印件）、护照复印件。
- 出願：邮寄（簡易書留）或窗口提交，最后一天 17:00 必达，没有网上出願；检定料30,000日元，用 E-支払いサービス缴纳（2026/6/15–7/16，海外只能用信用卡），国費外国人留学生免缴。
