## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 夏季入试：
  - 不另设英语笔试，用 TOEFL iBT（含 Home Edition）成绩评价，配点 100 分。本専攻只收 TOEFL，不收 TOEIC、IELTS。
  - 换算：得分＝(TOEFL 总分－45)×2，低于 0 记 0，上限 100。例如 TOEFL 80＝70 分，95 以上＝100 分，45 以下＝0 分。
  - 采用 Test Date Scores，不采用 MyBest Scores；TOEFL ITP 等团体成绩不受理；母语是英语的人也要交。
  - 有效成绩：受检日在 2024年9月–2026/7/14 之间；提交截止 2026/8/1（周六）（已截止）。
  - 提交要完成三步：经 ETS 把官方成绩寄到研究科（DI 代码 8596，Department 代码 99）；在 WEB 出願系统的マイページ登记 Appointment Number 和受检日；上传 Test Taker Score Report 的 PDF。期限内可以反复更换登记的那一次成绩。
  - 没有最低分数线的规定。
- 英语项目 UBE-UPN/ENV：
  - 须交英语标准化考试成绩，或由出身大学教务出具的“本科课程以英语授课”的证明；没有最低分。GRE 推荐但不是必须。

#### 日本語要件
- 夏季入试：
  - 要项没有要求提交日语成绩。
  - 笔试原则上用日语作答。认为难以用日语作答的人，可在出願截止前把自由格式的履历书发到専攻的考试邮箱申请用英语作答（都市工学専門与計画·設計·論文两科），由専攻判断是否批准，收到回信才算受理。过去问附有英文版。
  - 入学后有日语和英语两种授课，只修英语授课也能凑够修了所需学分。
- 英语项目 UBE-UPN/ENV：不要求日语能力，授课与指导用英语。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：夏季入试 25 名（都市環境工学、都市計画两个専攻分野合计，2027年4月入学和2026年10月入学合计；含英语项目等外国人留学生特別選考，不另设名额）；本年度没有冬入试。面向社会人的都市持続再生学コース（東大まちづくり大学院）是另一份要项，不在此内。
- 出願资格：日本的大学毕业或 2027/3/31 前预计毕业、在外国完成 16 年学校教育、在外国取得相当于学士的学位（3 年以上课程）等 6 项之一；不限本科专业。个别入学资格审查（资格 6）的书类截止为 2026/4/21（周二）（已过）。
- 専攻分野在受験申告票上勾选，它决定都市工学専門的选科范围和計画·設計·論文考哪一种；修士的受験申告票没有指导教员一栏。
- 夏季入试：
  - 専攻独有的提交物：受験申告票［修士］（从専攻网站下载样式，写専攻分野、希望入学时期和研究计划，只能一页），出願时以 PDF 上传。
  - 共通书类：入学願書（WEB 填写）、证件照数据、检定料缴纳证明、成绩证明书（东大工学部出身者免）、毕业证明书（已毕业者）、出口管制检查表（外国籍、重国籍或入学前所属机构在海外的人）、国费留学生证明（该当者）。日语和英语以外的文件要附译文，非日英文的证明书还要有出身大学盖章的英译本。
  - 出願只能通过 WEB 出願系统，全部书类转 PDF 上传；合格后在入学手续时交成绩证明书等纸质原件。受験票 2026/7/3（周五）15:00 左右经マイページ交付。
  - 可选 2027年4月入学或 2026年10月入学，希望10月入学的人要在受験申告票和入学願書两处都勾选。外国籍者新办在留资格通常要 2–3 个月，要项建议考虑 4 月入学。
- 英语项目 UBE-UPN/ENV：
  - 对象是出願期间住在日本以外的人（不问国籍），日本的大学毕业者不能报；不要求工学背景。
  - 经 T-cens 网上出願；书面审查通过者须在 2026/12/18（周五）前把原件寄到専攻事務室（未接到通知不要寄）；ADB-JSP 奖学金申请者另交 ADB_UBE_Form。检定料不能减免。
- 检定料 30,000 日元，可用便利店、Pay-easy、网银、中国决济或信用卡支付，手续费自付；国费留学生免缴。缴纳后不退。
- 不能同时报工学系研究科的两个以上専攻；提交后书类不能更改。
- 入学料 282,000 日元，授業料 年 535,800 日元（前期 267,900 日元），均为预定额；国费留学生不收。4月入学者的入学手续截止 2027/3/9（周二，预定）。
- 考场规则：开考 20 分钟前进入指定考室；迟到 30 分钟以内可入场；手机等电子设备关机收进包里，不能当表用。
- 咨询：募集要项的问题用研究科网站的咨询表单（工学系研究科学務課大学院チーム）；専攻事務室 Tel 03-5841-6216；申请英语作答用 exam2027@ue.t.u-tokyo.ac.jp。合否不接受电话、邮件查询。
