## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般入试（A日程、B日程都要）：
  - 不另设英语笔试，用 TOEIC L&R 或 TOEFL iBT（含 Home Edition）成绩评价，B日程配点 100 分。
  - 本系要求出願时必须提交在线版成绩单打印件，出願截止后一律不收，交后不能更换、不退还；截止前没交的没有受験资格。
  - 只认 2024/6/11 以后受检的成绩。TOEIC 须为带真伪确认 QR 码的数字公式认定证 PDF 打印件；TOEFL 须为 Test Taker Score Report PDF 打印件，并在 ETS 账户为该成绩设定 DI code G179。ETS 邮寄的纸质成绩单、TOEFL ITP、TOEIC IP 等团体考试不受理。
  - 要项附録3的换算基准：TOEFL iBT 先按对照表换成 PBT，再用（PBT－296）÷0.348＝TOEIC L&R，例如 iBT 80→PBT 550→TOEIC 约 730（TOEIC 300 分以下不适用）。
- IGP(C)：申请材料不要求英语成绩；面试和考试用英语进行。

#### 日本語要件
- 要项没有要求提交日语成绩。
- A日程口述試験和 B日程口頭試問都用日语进行（要项本系案内）。
- IGP(C) 全英语授课，不要求日语。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 专门科目（400分） | 生化学2题、生物学2题、有机化学2题、物理化学2题，共8题选4题作答，每题100分 | 9:30–11:00，90分钟 |
| 英语（100分） | 用外部成绩评价，见英語要件 | |

- B日程：总分 500，只有被公布为口頭試問受験资格者的人参加口頭試問，再结合出願书类综合判定；口頭試問成绩提供时按 A–E 五档。
- A日程：系根据出願书类决定受験资格者（考生不能自选，2026/7/2 マイページ通知），凭出願书类和口述試験决定“合格内定”；内定者不再考 B日程，没内定的可接着考 B日程；出願资格(9)（飞级）只能考 B日程。
- 每位教员可接收的合格人数可能有上限；最终合否和指导教员由口述試験，或笔试成绩加口頭試問综合决定。
- 题目倾向（体验记，非官方）：2025年8月1人选生化学和生物学题，称以基础题为主，用《エッセンシャル細胞生物学》《基礎から学ぶ生化学》备考、考前约1个月做过去问。

### 口述試験 / 面接
- **官方形式**：A日程：口述試験以专门知识、英语能力、学士论文研究内容和修士研究计划为中心提问，用日语进行，评价 A–E 五级；B日程：口頭試問用 Zoom 线上进行，只对受験资格者，以专门知识、学士论文研究内容和修士研究计划为中心提问，用日语进行，须在前一天 17:00 前完成 Zoom 事前登记并上传签名的誓约书，迟到30分钟以上失去资格；IGP(C)：系或志望导师安排的英语面试和/或考试，原则线上。
- **実際に聞かれた内容**：2025年8月 B日程（1人提到）：Zoom 约5分钟，主要确认志望理由和入学后想做的研究，几乎没有追问。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：生命理工学系受入可能予定人数 184 名（2026年9月和2027年4月入学合计）；IGP(C) 各系若干名。
- 出願资格：大学毕业（含 2027/3/31 前预计）或外国16年学校教育等，(9)–(11) 项须先审查出願资格；只能报一个系，结果出来前不能再报理工学系其他募集（含 IGP(C)）；外国籍选9月入学须出願时住在日本且在留资格有效到 2026/9/28；出願登记住址限日本国内；志望教员最多填到第5志望；选地球生命コース的须在志望理由书写明并事先与第1志望教员商量；IGP(C) 须先取得本系教员的指导同意。
- 要提前准备的书类：志望理由书（所定样式，结合现在的研究和第一志望研究室写入学后的研究和将来希望，约1,000字）；TOEIC L&R 或 TOEFL iBT 成绩单（出願时必交）；IGP(C) 另需导师同意书、研究计划和推荐人直接提交的评价表兼推荐信。
- 出願：网上登记缴费后把书类以速達書留寄到入試課（6/10 必达，不收窗口提交），检定料 30,000 日元＋手续费 990 日元；IGP(C) 全程网上提交，检定料 30,000 日元。
- 并愿限制：只能报一个系；同一入学期不能同时报理工学系修士的多个募集，一个出願的结果出来前不能再报理工学系的其他入试。可同时报清华大学大学院合同项目（バイオコース，须出願前联系コース长和志望教员；中国籍考生不能走这条）。
- 咨询：入试整体问入試課（inquiries.grad.se@adm.isct.ac.jp）；本系入试内容问生命理工学院事務グループ（Tel 045-924-5944，2026grad.exam@life.isct.ac.jp）。
