## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各轮次相同：出願时提交 TOEIC L&R（限公开考试或会津大学实施的 IP）、TOEFL、IELTS、Duolingo English Test 之一的成绩证明，须为出願前2年以内受检。
- 外国人留学生须至少相当于 TOEIC 500（TOEFL iBT 40、IELTS 3.5、Duolingo 45），希望达到相当于 TOEIC 600。
- 英语母语者和用英语完成学士以上学位课程的人免交，后者交学位授予大学出具的授课语言证明。
- 不另设英语笔试；面接用英语发表和问答，英语能力在面接中评价。

#### 日本語要件
- 要项没有要求提交日语成绩。研究计划书和推荐书须用英语写，样式用日语或英语填写；日英以外的证明须附经公证的译文。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 一般選抜各回：无笔试 | 面接＋成绩证明书等书类 |  |
| 海外居住者選抜：无笔试 | 书类选考（研究计划书、推荐书、成绩证明书、英语成绩） |  |

- 一般選抜把面接结果和成绩证明书等综合判定，评价コンピュータ理工学专业知识、英语能力等。
- 2027年10月入学第2回（1274）的考试内容可能变更，以最新要项为准。

### 口述試験 / 面接
- **官方形式**：一般選抜：用英语就所学专业和研究计划相关的专业知识（擅长领域）发表约5分钟，再问答约10分钟，可发资料、用投影仪；他领域出身者、资格(11)(12)者和需要确认基础学力者约30分钟（发表5–10分钟、问答20–25分钟）；海外居住者選抜：书类选考，预定指导教员有时线上面谈确认基础学力和英语。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：100名（一般選抜各回合计，不按轮次分配）；海外居住者選抜若干名。
- 出願资格：大学毕业（含 2027/3/31 预计；10月入学读作 9/30）或外国16年学校教育、外国3年以上课程取得学士相当学位等；资格(9)(10)(11)（含外国15年课程）须事前审查（1272·1273 为 2026/10/30 17:00 必达，已过，非独立出願），(9)(11)(12)只能报第2回；1272 和 1273 不能同时报；海外居住者選抜只限出願到入学手续期间都住在海外的人。
- 要提前准备的书类：研究计划书（样式 M3，英语，2页以内，须有指导教员签名或附教员同意邮件）、推荐书（样式 M4，出身大学指导教员等用英语写并封缄）、英语成绩证明、英文毕业（预定）证明和成绩证明、外国人留学生的 Request for Research Advisor Acceptance、资格(9)(11)者的英文教育课程表。
- 出願：邮寄（可追踪方式）或直接送交学生课，期限内必达，没有网上出願；检定料 30,000 日元，一般選抜汇入東邦銀行会津営業部大学账户（手续费自负）。
