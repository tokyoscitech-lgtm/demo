## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 8月入试：
  - 不另设英语笔试，用外部成绩评价：出願时提交 TOEFL iBT 或 TOEIC L&R 的成绩，计入综合判定；要项没有写英语的配点和换算分数，也没有最低分。
  - 要项给的 TOEFL 与 TOEIC 对照（换算的大致标准）：TOEFL 新分制 6＝旧分制 102 以上＝TOEIC 900 以上；5＝88–101＝800–899；4＝76–87＝700–799；3＝62–75＝600–699；2.5＝52–61＝500–599；2＝40–51＝400–499；再往下每档约差 100 分 TOEIC。
  - 只认 2024/7/1 以后受检的成绩；考过多次的只交自认为最有利的1份；出願后不能换成新成绩；来不及取得成绩也可以出願，但英语按 0 分计。
  - TOEFL：只认 iBT（含 Home Edition、Special Home Edition），只用 Test Date Scores；须在 ETS 账户向理学研究科电子送分（Institution Code G112，2026/7/9 截止）并提交 Test Taker Score Report 或 Examinee Score Record 的 PDF 打印件，只交 PDF 不受理。
  - TOEIC：提交纸质公式认定证（L&R）原件，数字版不受理；实在交不出时本専攻可以交 TOEIC IP 的 Score Report（与其他専攻不同）；TOEIC Bridge 不受理。
- 特別選抜：同样提交 TOEFL 或 TOEIC 成绩，没有最低分。
- 第2次募集：
  - 研究科在一般選抜要项第13节预告：须提交 TOEFL iBT（含 Home Edition、Special Home Edition）或 TOEIC 公开考试的成绩，IP 无效；有效期从出願期间首日所在月份往前推2年的同月1日起算。
  - 上一年度第2次募集要项写的是 2024/1/1 以后的成绩有效，TOEFL 原则上用 iBT（无法参加 iBT 时可用 ITP），TOEIC 交纸质公式认定证原件。今年以新要项为准。

#### 日本語要件
- 各轮次的要项都没有要求提交日语成绩（JLPT、EJU 都没有提及），一般選抜对外国人也没有日语门槛。过去问题面只有日文；可用的作答语言要项没有写明。研究分野等希望調書只收黑色笔手写，不能用 Word 录入。第2次募集的毕业研究发表和口头试问使用什么语言，上一年度要项没有写。
