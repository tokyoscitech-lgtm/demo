## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 各次募集都考英语。可以用外部成绩代替，或在考试当天参加 TOEIC L&R IP 考试；出願后不能更改所用的考试种类。
- IELTS：只认 Academic Module 的 Test Report Form，须由实施机构直接寄给大学；General Training、UKVI、Life Skills、Online 不受理。
- TOEFL iBT（含 Home Edition）：须向 ETS 申请把 Official Score Report 直送大学（DI コード 2598，不需要专攻代码），同时提交 Test Taker Score Report 的打印件，采用 Test Date Scores；TOEFL Essentials、ITP、Junior、Primary 不受理。
- TOEIC L&R 公开考试：提交 IIBC 的数字公式认定证打印件或公式认定证原件；复印件、网页下载的成绩证明、IP 考试（含在线）、Speaking/Writing、Bridge 不受理。
- 三种外部成绩都限 2025年4月以后受检，须在出願期间最终日前送达。需要退还原件的，附角形2号回邮信封（朱书「簡易書留」，贴490日元邮票）。
- 外部成绩没有按时送达的，必须在考试当天参加 TOEIC L&R IP 考试。
- 要项没有公布英语的配点、最低分和换算方法；アドミッション・ポリシー表里英语在2个评价项目上标 ◎，只表示重点，和配点无关。

### 日本語要件
- 要项没有要求提交 JLPT 等日语成绩。外国人留学生只要求在留资格不妨碍入学。
- 要项和提交书类确认表都有英文版，出願用的邮寄封面也有英文版；日语以外的证明书须附日文译文。面接使用的语言要项没有写明。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 英語（配点官方未公布，9:00–11:30） | 提交 TOEIC/TOEFL/IELTS 外部成绩，或当天参加 TOEIC L&R IP 考试 | 2027募集要项 |
| 専門科目·小論文 | 不实施 | 2027募集要项 |

- 选拔方法：综合英语、面接、志望的动机、成绩证明书判定合格者。所有科目都要参加，缺考不合格，不设追试。
- 考试规则：说明开始 20 分钟后不能入场，考试中不能退场；桌上只能放受験票、黑色铅笔/自动铅笔、橡皮和手表（不可用手机、计时器、可穿戴设备）。
- 题目倾向（体验记，非官方）：没有找到公开的体验记。

### 口述試験 / 面接
- **官方形式**：各次募集都有面接，配点官方未公布；アドミッション・ポリシー表里面接在4个评价项目上标 ◎，是比重最大的部分。原则上和英语同日，可能另定日期，具体时间和形式要项没有写。
- **実際に聞かれた内容**：没有找到公开的体验记。
