## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 第1次募集（8月入试）和第2次募集（2月入试）都不在考场考英语，而是在出願时提交外部考试成绩：TOEIC L&R、TOEFL iBT、IELTS（Academic Module）三选一，须为 2024年4月以后受检的成绩。
- 提交形式：TOEIC 交公式认定证的纸质原件，或把数字公式认定证 PDF 打印出来；TOEFL iBT 交 Test Taker Score Report 的 PDF 打印件（只认 0–120 分制的成绩）；IELTS 交 Test Report Form 原件，网页打印的不行。
- 出願时正式成绩单还没到手的，可以先交网上成绩画面的打印件作为“仮提出”，正式成绩单的补交期限：第1次募集为 2026/7/3（周五）上午（已截止）；第2次募集为 2027/1/29（周五）上午。
- 没有提交有效成绩证明的，英语按 0 分处理。要项没有写最低分数线，也没有公布换算公式和配点。
- 不受理的成绩：参考 2025年度要项，TOEIC IP 等团体考试、机构直送的成绩不受理；2027年度要项只读到上面的形式要求，这一条未核实。
- 变更点：成绩有效期的起点逐年后移（2025年度要项为“2022年4月以后”，2027年度为“2024年4月以后”）。

### 日本語要件
- 一般選抜的要项没有要求提交 JLPT、EJU 等日语成绩。
- 要项写明出願时要选择出题语言（日语或英语）。要项没有写作答语言的规定。
- 本専攻另有外国人留学生特別選抜（2027年度春入学·2026年度秋入学）和英文版 Admission Guidelines for International Students，但这份要项没能打开，其考试内容和语言要求未核实。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 専門科目《知識情報システム学》（配点官方未公布，与数学合计120分钟） | 计算机系统、信息网络、算法与程序设计。要项只列出这3个领域，没有写题数和选答规则 | 2027一般選抜募集要项 |
| 基礎科目《数学》（配点官方未公布，与専門科目同一场） | 线性代数、统计学。题数没有写 | 2027一般選抜募集要项 |
| 第2次募集（2027年2月）：科目与第1次募集相同 | 2027/2/9 上午同一场笔试，下午口头试问；另须提交毕业论文或代替论文 | 2027一般選抜募集要项 |

- 合否判定：按笔试（含英语外部考试成绩）、口头试问、出願书类综合判定。各科配点和总分官方都没有公布。
- 变更点：2025年度要项的试验区分A考“计算机体系结构、信息网络、信息系统工学”＋数学（线性代数、统计），试验区分B考《生産システム科学》（设计工学·制图、优化方法、生产管理、运筹学）；2027年度要项没有区分B，専門科目的3个领域也改了名称。从哪一年度开始变更没有核实。
- 题目倾向（体验记，非官方）：没有找到体验记，过去问也没能看到，无法归纳。

### 口述試験 / 面接
- **官方形式**：第1次募集和第2次募集都有口头试问，在笔试当天下午 13:30 开始，围绕研究计划书等（包括研究内容）提问。配点、每人时长、是否要做发表，要项都没有写。住在日本国外的人可能改用远程中继方式考口头试问。口头试问（笔试免除）只对大阪公立大学、大阪府立大学、大阪市立大学、大阪公立大学工業高等専門学校専攻科的在籍者和学术交流协定校的在籍者开放（需要个别资格认定的人里也可能有获准者），由出願书类综合判断谁可以免笔试，名单在 2026/6/26 公布；普通外校考生走不了这条路。
- **実際に聞かれた内容**：没有找到体验记，实际被问到的内容不明。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：2027年度春入学 30 名（第1次募集与第2次募集合计；第1次招满就不办第2次）。一般選抜没有秋入学。
- 出願资格：大学毕业或 2027年3月底前预计毕业、在外国完成 16 年学校教育、在外国取得相当于学士的学位等（要项第(1)–(8)项）。第(9)项（飞级：在大学就读3年以上或在外国完成15年课程且成绩优秀）和第(10)(11)项（没有学士学位、由本研究科个别认定学力者）必须先通过出願资格审查。已有学士学位的人不需要资格审查（入试FAQ）。
- 出願资格审查的受理期间：第1次募集·秋入学为 2026/5/11（周一）–5/13（周三）必达（已截止），结果 5/22 寄出；第2次募集为 **2026/11/9（周一）–11/11（周三）必达**，结果 11/20 寄出。申请材料有资格审查申请书、学修成果报告书（日语约2,000字或英语约1,000词）、毕业或在学证明书原件、成绩证明书原件；第(9)项另需课程大纲等说明授课内容的资料。
- 出願书类：出願确认票（A4打印）、入学願書（贴3个月内的 4cm×3cm 照片）、写真票、履历书（已通过资格审查者不用交）、毕业（见込）证明书原件、成绩证明书原件（两者都不收复印件）、研究计划书（规定样式，无字数限制，写至今的研究经过和入学后想做的研究）、英语成绩证明。第2次募集另交毕业论文或代替它的论文 3 份（可用复印件，写明题目和姓名）。
- 书类语言：日语、英语以外的文件要附 A4 的日语或英语译文。没有纸质版募集要项，样式从研究科入试信息页下载 PDF 或 Word 自己打印。
- 出願方式：先在网上出願系统登记并缴检定料，再把书类用简易書留寄到入试课（截止日邮戳有效），或在受理期间的平日 10:00–17:00 直接交到中百舌鳥キャンパス A3棟3階入试课。只做网上登记和缴费不算完成出願。
- 检定料 30,000 日元＋支付手续费 990 日元，可用信用卡、便利店、ATM（Pay-easy）、网上银行支付。只有书类未被受理、重复缴费、缴费后没有出願这三种情况可以退还。
- 并愿：推薦入試和一般選抜可以同时报（入试FAQ）。要项没有写两个専攻之间能否并愿，也没有写第1次募集合格者能否再报第2次募集。
- 口头试问（笔试免除）不合格的人，可以改为参加同一轮的笔试＋口头试问。
- 有科目缺考的，不列入合否判定。受験票不邮寄，要从邮件里的链接登录门户网站，自己用 A4 白纸打印。要项没有写可带物品和迟到的规定。
- 外国人留学生的教育研究内容受《外汇及外国贸易法》下的安全保障出口管理限制，可能无法接受所希望的教育，必要时要补交材料。
- 需要考试或修学上照顾（残障等）的，要在出願前尽早向入试课提出（gr-nyu-ask4@omu.ac.jp）。
- 入学手续：第1次募集合格者为 2026/10/1（周四）11:00–10/6（周二）12:00；第2次募集合格者为 2027/3/11（周四）11:00–3/15（周一）12:00。入学日 2027/4/1。
- 入学料：大阪府民及其子女 282,000 日元，其他人 382,000 日元；授業料年 535,800 日元（入学后分前后期缴纳）。有长期履修制度（面向在职、育儿、护理者，入学后申请）。
- 研究生（非正规生）是另一条路线，咨询窗口是教育推進課情報学研究科教務担当（入试FAQ）。这不是修士入试的要求。
- 咨询：大阪公立大学入试课（中百舌鳥キャンパス，〒599-8531 大阪府堺市中区学園町1-1），Tel 072-254-8319（周一至周五 9:00–17:00，节假日和大学休业日除外），gr-nyu-informatics@omu.ac.jp。
- 成绩开示：考生本人可登录门户网站查看。第1次募集·秋入学为 2026/11/5（周四）10:00–11/27（周五）15:00；第2次募集为 2027/5/7（周五）10:00–6/4（周五）15:00。
