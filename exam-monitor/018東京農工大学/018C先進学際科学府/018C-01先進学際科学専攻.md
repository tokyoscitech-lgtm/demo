## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 8月入试一般选拔：不另设英语笔试，出願时交外部英语成绩单原件和复印件（缺一不可），按 TOEIC 分数换算成100分；笔试免除者不交（免除未通过的再交）。
- 可交：TOEIC L&R 公开考试公式认定证、TOEIC-IP（限农工大实施）、TOEFL iBT（含 Home Edition）Test Taker Score Report、TOEFL ITP（限农工大实施）；TOEFL 的换算向小金井地区学生支援室入学試験係询问；TOEFL iBT 只认 Test Date 成绩。
- 只认出願截止日前2年以内受检的成绩；ETS 网站下载的 PDF 版不受理；提交后不能更换。
- 外国人留学生特别选拔、社会人特别选拔不交英语成绩。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 公开的基礎试题和解答例为日文。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 基礎（200分） | 13题中任选4题：解析学及線形代数学、フーリエ及びラプラス変換、確率及び統計学、力学、電磁気学、情報基礎、物理化学、有機化学、無機化学、細胞生物学、生理・生化学、生態学、環境学 | 10:00–11:40，100分钟 |
| 英語（100分） | 用外部英语成绩换算 |  |
| 専門（100分） | 口述试验，见下节 |  |

- 8月入试一般选拔：各科综合，按4段阶评价判定合否。
- 笔试免除：出願资格①②、2027年3月预计毕业、以本学府为第一志愿的人可申请（仅4月入学），按口述和成绩证明判定；未通过者仍可参加8月笔试和口述。

### 口述試験 / 面接
- **官方形式**：8月入试一般选拔：専門口述100分，问志望コース的专门内容（志望跨两个コース的两边都要考）；外国人留学生特别选拔：口述＋成绩证明综合判定；社会人特别选拔：口述＋成绩证明＋业绩内容综合判定。

## 📝 详细信息

- 募集人员：2027年4月入学99名（予測情報学コース30名、資源・エネルギー科学コース23名、健康・福祉科学コース23名、食料・環境科学コース23名，含外国人留学生特别选拔和社会人特别选拔）；2026年10月入学各コース若干名；第2次募集未公布。
