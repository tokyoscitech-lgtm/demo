## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各轮次都只认 TOEFL iBT 成绩，不另设英语笔试，换算成 100 分；2026/1/21 以后受检的按 0–120 的原始分计算。
- 只用 Test Date Scores；MyBest Scores、Home Edition、TOEFL ITP 无效。
- 向 ETS 申请把 Institutional Score Report 寄到本専攻（Institution Code B472，Department Code 任意）；考前一天 22 时前申请免费，考后申请收费。交了多份的取最高分，没有送达的英语按 0 分；専攻不回答是否送达的查询。受验资格所限难以参加 TOEFL 的，事先联系 Cクラスター教務掛（建築系）。
- 8月入试：2024/8/1 以后受检，2026/7/31（周五）17:00 前送达（已截止）。
- 2月入试：2025/2/1 以后受检，2027/2/5（周五）17:00 前送达。

#### 日本語要件
- 要项没有要求提交日语成绩。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 8月入试：設計製図（100分） | 小规模建筑的设计，在指定用纸上画一般图；制图工具自带（原则上不借出），另带订书机把 A3 描图纸答卷钉到 A1 肯特纸上 | 8/1 13:00–17:00，240分钟 |
| 8月入试：計画系科目（与構造系、環境系合计600分） | 建築計画、都市·地域計画、建築史·都市史、建築論、建築生産、建築設計論、建築意匠 | 8/1 9:00–11:30，150分钟 |
| 8月入试：構造系科目 | 建築構造力学、鉄筋コンクリート構造、鉄骨構造、建築振動、木構造、構造材料、基礎工学 | 8/2 9:00–11:30，150分钟 |
| 8月入试：環境系科目 | 建築環境工学、建築設備システム、建築光·音環境学、建築温熱環境設計、都市環境工学、建築安全設計、建築設備計画法 | 8/2 13:00–14:30，90分钟 |
| 2月入试：専門科目（300分） | 按志望区分从計画、構造、環境中选1科 | 2/9 15:00–16:15，75分钟 |

- 8月入试总分 800（英语 100＋設計製図 100＋三系科目 600），400 分以上为有資格者。各志望区分以第1志望有資格者中总分最高、且在全体前75名以内者为优先合格者；其余有資格者按总分从高到低、依志望顺序分配到还有名额的区分。同分先比三系合计分，再比第1志望区分对应科目的得分率。
- 2月入试总分 400（英语 100＋専門科目 300），200 分以上为有資格者，再综合得分和志望区分决定合格者。
- 考试在桂キャンパス（8月 C1 棟，2月 C2 棟）；迟到30分钟以上不能入场，手表只能有计时功能。

### 口述試験 / 面接
- **官方形式**：8月入试和2月入试都没有口头试问或面试，只按 TOEFL 和笔试（8月含設計製図）的总分判定。
