## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 8月实施和1-2月实施相同：「外国語」100分，不另设英语笔试，用 TOEIC L&R、TOEFL iBT（含 Home Edition）或 IELTS Academic 成绩评价；英语成绩单全员必交，社会人特別選抜也要交。
- 受检时期：8月实施须2024年7月以后；1-2月实施须2025年1月以后。
- 不受理 TOEIC IP、TOEFL ITP、IELTS General、IELTS Academic 线上版、IELTS One Skill Retake；截止日前没交有效成绩的不受理出願或按缺考处理。
- 提交方式：TOEIC 在 Web 出願系统填デジタル公式認定証 URL 并打印提交（日本国内受检者必须用这种方式）；TOEFL 交 Test Taker Score Report 原件，没有纸质版的让 ETS 直送 Official Score Report（DI 代码 9995，Department 代码 99）并交 PDF 打印件；IELTS 把 Additional TRF 数据直送大学并交 Test Report Form 复印件。直送可能要几周。
- 换算方法和最低分要项没有写（TOEIC 850／TOEFL 96／IELTS 6.5 按满分的规定只写在フロンティア医科学下）。
- 海外居住者特別選抜：英语非母语且大学不是全英语授课的人交 TOEFL、TOEIC 或 IELTS 成绩（入学前2年以内，可交复印件，没有最低分）；全英语完成学位的可改交授课语言证明。

#### 日本語要件
- 要项没有要求提交 JLPT、EJU 等日语成绩，一般入学試験也没有外国人留学生的另设区分。
- 试验语言在 Web 出願时从日语和英语中选一种，専門科目和口述試験都按所选语言进行，出願后和考试当天都不能改。必修科目用英语开课；海外居住者特別選抜全程英语。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 外国語（100分） | 用 TOEIC L&R、TOEFL iBT、IELTS Academic 成绩评价 | 2027募集要项 |
| 専門科目·一般入学試験（100分，60分钟） | 「公衆衛生学基礎」或「統計学」选一科，出願时选定不能改；题数未写明 | 2027募集要项 |
| 専門科目·社会人特別選抜（100分，60分钟） | 「公衆衛生学応用」或「統計学」选一科，出願时选定不能改 | 2027募集要项 |

- 8月实施和1-2月实施相同；总分 400：外国語 100＋専門科目 100＋口述試験 200。综合书类和学力检查结果判定，没有公布合格最低分。社会人特別選抜配点表的外国語、口述两栏空白，プログラム官网写明同样考外国語、専門科目和口述。
- 「統計学」水平相当于統計検定2级（含数学）（プログラム官网）；选統計学的只能用大学发的计算器。
- 海外居住者特別選抜不考笔试，按书类和口述（含英语能力）选拔。
- 题目倾向（体验记，非官方）：没有找到本プログラム的考生体验记。

### 口述試験 / 面接
- **官方形式**：8月实施和1-2月实施相同，个别面接，200分，就公共卫生和志望动机提问，在専門科目当天 13:00–18:00 之间进行，用出願时选定的语言（日语或英语），时长没有写；海外居住者特別選抜原则上线上口述，书类审查通过后用邮件约时间。
- **実際に聞かれた内容**：没有找到本プログラム的面接体验记。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：8月实施 一般入学試験 7名、社会人特別選抜 若干名；1-2月实施 一般入学試験 3名、社会人特別選抜 若干名；海外居住者特別選抜 少数；均为2027年4月入学，没有10月入学和推薦入试。
- 出願资格：日本的四年制大学毕业或入学前一个月底前预计毕业；大学改革支援·学位授与機構授予学士学位；在外国完成16年学校教育；在外国3年以上课程取得相当于学士的学位（出願前先向入試課确认）；经个别出願资格审查认定且满22岁。
- 社会人特別選抜：到入学前一个月底累计2年以上社会经验（常勤、非常勤都算，预计达到也可；打工不算）；联系指导教员时要说明报社会人名额。
- 个别出願资格审查截止：8月实施 2026/7/3（已截止）；1-2月实施 2026/11/24（周二），向医学医療エリア支援室大学院教務申请。
- Web 填写内容：证件照、指导教员（第1志望必填，第2志望可不填）、専門科目选考科目、试验语言、英语成绩、学历职历。一般入学試験写小論文约800字（至今所学和经验如何在志望プログラム里运用发展），不得使用生成 AI；社会人特別選抜写研究計画書约800字，并填写生成 AI 的使用情况。
- 邮寄或窗口提交的书类：毕业（预计）证明书原件（外国大学网上发行的附页面截图和 URL）、外国大学毕业者的学位取得证明书、成绩证明书、英语成绩单、在学或在职者的受験·就学承认书（2027年3月预计毕业者除外）、检定料收纳证明或信用卡支付明细截图、国费留学生证明书（符合者）；附 Web 系统打印的受験票、收件人标签、粘贴用纸、书类明细票。
- 出願方式：Web 录入、填写みなし輸出确认事项、支付检定料后提交，再把书类寄到或送到医学医療エリア支援室大学院教務，截止日必达。
- 检定料 30,000 日元（信用卡或便利店，缴纳后不退；国费外国人留学生免缴）。入学料 282,000 日元；授業料年额 535,800 日元，「留学」在留资格的外国人留学生年额 608,800 日元。
- 社会人可在夜间（18:00–20:35）上课，也可申请长期履修（3年或4年）。
- 海外居住者特別選抜（另一条路线）：面向住在海外的外国人和日本人；交规定样式申请书和履历书、2封推荐信（推荐人直接邮件发送）、照片、毕业和成绩证明、英语成绩或授课语言证明、护照复印件、检定料 30,000 日元（信用卡）证明，原件国际快递；出願前同样须取得志望教员承诺。
- 咨询：出願手续和资格审查找医学医療エリア支援室大学院教務（medgra-nyushi@un.tsukuba.ac.jp，Tel 029-853-3013／029-853-5668，平日 9:00–12:15、13:15–17:00）；外国学历资格事先确认找入試課大学院入試（admission.grad@un.tsukuba.ac.jp）；海外居住者特別選抜找 iga-in@un.tsukuba.ac.jp。
