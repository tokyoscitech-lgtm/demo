## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 一般選抜：英语不设笔试，用 TOEFL iBT（含 Home Edition）或 TOEIC Listening & Reading 公开考试的成绩判定，成绩单贴在指定的「スコアシート提出用紙」上随出願书类一起寄出。两种可以只交一种，也可以都交。
- TOEIC：只收公式认定证原件（Official Score Certificate）；没有该证书的国家可交 Official Score Report 和 Certificate of Achievement。
- TOEFL：需要两样——由 ETS 直送大学的 Institutional／Official Score Report（Institution Code D377，Department Code 69），以及 Test Taker Score Report 的复印件。直送成绩要在出願期间最后一天（一般選抜为 2026/7/3）之前到达大学；两样缺一就按没有提交处理。
- 有效期：只承认 2024/6/1 以后实施的考试成绩。不受理 TOEFL ITP 和 TOEIC IP（团体考试）。交上去的成绩单不退还，过期的成绩按没有提交处理。
- 没交成绩也可以参加考试，但英语不计分。
- 配点与换算：募集要项和専攻资料都没有写英语的配点和换算方法。
- 専攻页的答疑补充：TOEIC 只需要 Listening & Reading Test；想申请笔试免除的人出願期间在6月上旬，要更早考完。
- 笔试免除者选拔：出願时要交英语成绩单；没有获得免除而转入一般選抜的人，可以在 2026/7/29（周三）17:00 前重新提交成绩单（已截止）。

### 日本語要件
- 8月入试（笔试免除者选拔、一般選抜）：募集要项没有要求提交日语成绩，没有 JLPT／EJU 门槛。笔试和口頭試問用日语进行。
- 外国人留学生入试：2027年度的留学生募集要项没有读到，日语要求未核实。2025年度的留学生募集要项原则上要求提交日语教师等出具的「日本語能力証明書」，2027年度是否仍要求以新要项为准。
