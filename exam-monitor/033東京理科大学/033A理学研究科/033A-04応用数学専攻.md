## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 一般入试（8月入试）：用 TOEIC 或 TOEFL 的成绩选考。TOEIC 的公開テスト和 IP テスト都可以，Bridge 不可；TOEFL 的 iBT 和 ITP 都可以，iBT Home Edition 不可。
- 提交方式：出願时随願書提交成绩单原件（TOEIC 公開テスト交デジタル公式認定証的打印件）；TOEFL iBT 另用理学研究科的 Institution Code G277 直送。提交后不退还、不能更换。
- 有效期：出願截止日的2年前以后受检的成绩。
- 出願时来不及、但考试日前能拿到成绩单的，可以在笔试当天带来提交。
- 要项没有公布英语的配点、换算方法和最低分。
- 外国人留学生入试：只收 TOEFL iBT 或 TOEIC Listening & Reading 公開テスト的成绩单；TOEFL ITP、iBT Home Edition、TOEIC IP 都不受理；须为第二次選考出願截止日的2年前以后受检，2026/12/2（周三）前邮寄必达。
- 2026/8/3 大学发布的“TOEFL iBT 成绩证明的处理”通知，对象是経営学·国際火災科学·生命科学的冬期日程等，不适用于本専攻。

### 日本語要件
- 一般入试（8月入试）：要项没有要求提交日语成绩（JLPT、日本留学試験都不需要）。要项没有写明试题和作答语言；出願书类用大学的日文所定用纸，考试按日语进行来准备。
- 外国人留学生入试：修士志愿者必须提交大学所定用纸的“日本語能力認定書”，由日语教师、日本驻外使领馆人员或精通日语的人填写；不需要、也不能用 JLPT 合格证明代替。专门科目（数学）和面接可以用日语或英语。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 一般入试：専門基礎科目（配点官方未公布，90分钟） | 微积分、线性代数；全部题目必答 | 2027修士一般入试募集要项 |
| 一般入试：専門科目（配点官方未公布，90分钟） | 数理统计学、计算数学、微分方程、最优化理论、代数学等；共出4题以上，选2题作答 | 2027修士一般入试募集要项 |
| 外国人留学生入试第二次選考：数学（配点官方未公布，时长另行通知） | 笔试加口头试问，可用日语或英语 | 2027外国人留学生入试募集要项 |

- 一般入试按専門基礎科目、専門科目、英语外部成绩和面接综合判定；要项没有公布各项配点、总分和合格线。
- 外国人留学生入试的第一次選考只审书类，第二次選考由数学、英语外部成绩、面接构成。
- 题目倾向（体验记，非官方）：没有找到本専攻的院试体验记，暂无可归纳的内容；出题范围请直接看大学公开的2025、2026年度过去问。

### 口述試験 / 面接
- **官方形式**：一般入试在笔试当天 15:00 起面接，只有笔试当天公布的面接对象者参加；要项没有公布面接的配点、时长和提问内容。外国人留学生入试第二次選考有数学的口头试问和面接，可用日语或英语。
- **実際に聞かれた内容**：没有找到本専攻的体验记（日文、中文来源都查过），暂无记录。

## 📝 详细信息
### 出願資格 / 定員
- 一般入试的募集人员为35名（神楽坂キャンパス）。外国人留学生入试为若干名。本専攻没有他大学推薦入学和社会人特別選抜（理学研究科的推薦入学只有化学専攻）。
- 一般入试的出願资格：有学士学位或2027年3月前预计取得者；在外国完成16年课程者；修完4年以上専修学校専門课程者；文部科学大臣指定者；大学3年级在籍且成绩优秀者（只限部分専攻）；2027/3/31 前满22岁并经本研究科认定与大学毕业同等学力者（须在出願前先咨询）。
- 外国人留学生入试的出願资格须同时满足：外国国籍；在外国完成16年以上课程（含2027/3/31 前预计完成）；没有在日本接受过4年大学本科教育；入学时能取得“留学”在留资格。没有报第一次選考或第一次選考不合格的人不能报第二次選考。
- 一般入试的出願书类：入学願書（所定用纸，照片 4cm×3cm、3个月内拍摄的彩色照片）、成绩证明书原件、毕业（预计毕业）证明书原件、履歴書（所定用纸）、志望理由書（所定用纸，800字左右）、寄送受験票用的明信片1张（贴速达邮资385日元）、英语成绩单；住在国外的人另交“国外居住者用事前相談シート”（含指导希望教员填写栏）。
- 外国人留学生入试的出願书类：入学願書、日本語能力認定書、毕业证明书、成绩证明书、出身学校校长或指导教员的推荐信（3个月内出具）、护照复印件、参考資料（所定样式，理学研究科修士志愿者全员提交）、检定料缴纳票、チェックシート。日语和英语以外的文件要附经公的机构等证明的日文或英文译文。
- 出願方式：只能邮寄，没有网上出願。一般入试寄到理学事務課；外国人留学生入试国内用簡易書留速达、国外用 EMS 等可追踪的方式寄到入試課（〒162-8601 東京都新宿区神楽坂1-3）。
- 检定料：一般入试 35,000 日元，在银行窗口汇款或便利店（セブン-イレブン、ローソン、ファミリーマート、ミニストップ）缴纳，不能用 ATM 和网上银行。外国人留学生入试第一次選考 18,000 日元、第二次選考 17,000 日元，国外可用信用卡；第二次選考的缴纳期限为便利店 2026/11/25–12/2、银行窗口 11/30–12/2、信用卡 11/1–12/2 23:00（日本时间）。
- 并愿：一般入试允许并愿笔试日期不同的専攻；本専攻与数学専攻、物理学専攻同在 8/1 考试，不能同时报。
- 安全保障出口管理：研究内容属于管制对象时，研究活动可能受限或无法指导，住在国外的人要在出願前请指导希望教员填写事前相談シート确认。
- 学费（2027年度新入生，修士）：入学金 200,000 日元，授業料年额 880,000 日元，教育充実費年额 200,000 日元，学生傷害共済補償費 2,740 日元，初年度合计 1,282,740 日元（入学手续时 742,740 日元，后期 540,000 日元）；第二年起年额 1,082,740 日元。本学出身者入学金和教育充実費减半。
- 考场规则：考试开始（面接为集合时间）后30分钟内不能进入指定会场的，该场考试不能参加。因残障或疾病需要特别照顾的，须在出願开始日的1个月前联系。
- 咨询：一般入试找理学事務課（東京都新宿区神楽坂1-3，Tel 03-5228-8120，窗口受理 9:00–12:00、14:00–16:00，周六日和节假日除外）；外国人留学生入试找入試課，通过大学的咨询表单 https://faq.admissions.tus.ac.jp/hc/ja/requests/new 联系。
- 要项中能读到的部分没有成绩开示的说明。
