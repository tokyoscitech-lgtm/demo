## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般选拔·国際コース：
  - 设学内英语笔试 10:50–12:20；出願时交 TOEIC、TOEFL 或 IELTS 成绩单原件，判定英语能力充分的可免考英语笔试，判定不充分或没交的必须参加笔试。
  - 成绩须为出願截止日前2年内受检：TOEIC 交 Official Score Certificate；TOEFL 交 Test Taker Score Report 或 Institutional Score Report（TOEFL ITP 也可）；IELTS 交 Test Report Form。原件确认后退还。
- 社会人特别选拔：入学选拔不要求英语考试，面试时口头确认研究所需的英语能力；在学期间提交论文前须通过英语考试（可用成绩单申请免考）。

#### 日本語要件
- 要项没有要求提交日语成绩。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 志望専攻分野 | 志望专攻分野及相关科目 | 9:30–10:30，60分钟 |
| 英語 | 交成绩单并被判定英语能力充分者免考 | 10:50–12:20，90分钟 |

- 一般选拔按学力试验（笔试、面试）和成绩证明书综合判定；社会人特别选拔只考面试（由志望专攻分野教授实施），结合成绩证明书判定。
- 国際コース考法相同，海外居住者原则上用 Zoom 线上参加笔试和面试。

### 口述試験 / 面接
- **官方形式**：第1次·第2次相同：13:30–15:30 面试；社会人特别选拔的面试由志望专攻分野教授实施，同时口头确认专门内容和研究所需英语能力；国際コース海外居住者原则上经 Zoom 面试。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：43名（含社会人特别选拔若干名、歯学博士国際コース若干名，第1次·第2次共用）；要项注明可能另行实施第3次募集。另有10月入学募集（2026年10月入学为2026年5月出願、6/2考试）。
- 出願资格：日本6年制医·歯·薬·獣医学毕业、外国18年课程、外国5年以上课程学士相当学位、修士毕业（含预计）等；外国16年课程（须含医歯薬獣）或个别审查（满24岁）须先过出願资格审查（第2次 2026/11/5 17:00 必达，已截止，非独立出願）；国際コース限外国籍，外国16年课程毕业者另须有2年研究经历并经教员评价。
- 要提前准备的书类：志望专攻分野指导教员的事前确认（国際コース须取得内诺）；英语成绩单原件（申请免考英语者）；在职者交所属长受験承諾書。
- 出願：书类持参或挂号邮寄，期限 17:00 必达；检定料 30,000 日元经 e-支払い 用便利店或信用卡支付（海外只能信用卡，国際コース也可银行汇款），本校修士直升者和国费留学生免缴。
- 并愿：尚未核实是否可同时报考其他专攻或选拔类别。请以本年度募集要项或招生窗口答复为准。
- 咨询：具体招生窗口尚未核实。请通过[歯学府 入学試験案内（入试信息）](https://www.dent.kyushu-u.ac.jp/admissions/centers/)查找联系方式。
