## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 须提交 TOEFL iBT（含 iBT Home Edition）成绩，研究科和専攻都不另外举行英语笔试；A日程、B日程相同。
- 送分方式：在有效期间内向 ETS 申请把 Institutional (Official) Score Report 送到机构代码（DI）1113，送到其他代码的无效。出願时在 WEB 出願系统里填写 Appointment Number、受检日和分数，不需要另交 Test Taker Score Report。
- 有效的受检日：A日程为 2024/8/1–2026/6/13（已过）；B日程为 2025/2/1–2026/11/15。
- 团体实施的 ITP 和 MyBest 分数不受理。成绩可以多次送，但出願时只能选定一次的分数填写。
- 要项和専攻入試案内都没有写最低分数，也没有写换算方法和配点。

### 日本語要件
- 要项没有要求提交日语成绩。
- A日程的专门科目用日语出题、日语作答，口述到场进行；B日程的专门科目用英语出题、英语作答，口述在线上进行。
- 中小学阶段起都在日语以外的语言环境中受教育的课程毕业（预定）者，出願前须先接受出願对象审查（研究科共通规定）。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：A日程 30 名，B日程若干名；两个日程都只招 2027年4月入学，本専攻不实施 10月入学。
- 出願资格：日本的大学毕业或 2027/3/31 前预计毕业、在外国完成 16 年学校教育、在外国大学修完 3 年以上课程并取得相当于学士的学位等 6 项之一。按第 6 项（个别入学资格审查）出願的须事先受审，申请期限 A日程为 2026/5/7、B日程为 2026/10/7（均已过）。
- 志望填写：在 WEB 出願系统里对照「教員並びに専門分野一覧」选择志望专门分野和指导教员，最多填到第3志望；第2、第3志望可以选同一分野的其他教员，没有可以不填。教员可能因人事调动变化，出願前要看最新版一览。
- 专门科目的 2 科在出願时选定。出願期间结束后原则上不能修改出願内容。
- 出願书类（要项第10条的ア–カ）：入学願書（含 3 个月内拍摄的照片）、出身大学的成绩证明书、毕业（预定）证明书（须写明学位名和授予日）、检定料缴纳证明、国费留学生证明书（仅该当者）、TOEFL 成绩。本専攻的入試案内没有追加専攻独有的提交物。证明书为日语、英语以外的须附日文或英文翻译；证明书以 PDF 上传，合格后提交原件。
- 出願方式：只能通过 WEB 出願系统（https://webentry.ofc.a.u-tokyo.ac.jp/），没有邮寄或窗口出願。受験票在考试前一天之前自行从系统打印（A4），考试当天带上。
- 检定料 30,000 日元，缴纳期间 A日程为 2026/4/13–6/23（已过）、B日程为 2026/10/5–11/25；可用银行汇款、便利店、信用卡、Pay-easy 等，可能另有手续费，缴后不退。国费留学生免缴。
- 并愿限制：同一日程不能报本研究科的 2 个以上専攻；本専攻同一年度只能报一次，报了 A日程就不能再报 B日程。
- 外国人须在入学前取得不妨碍就读的在留资格，B日程合格后 4月入学的要注意入境时间。按安全保障出口管理规定，入学前和在学期间会受审查，属于管制对象时即使合格也可能不能入学或研究内容受限。
- 没收到「受験者心得」时，A日程须在 2026/7/15、B日程须在 2027/1/13 之前联系教務課。
- 入学料 282,000 日元，授業料 年 535,800 日元（前期 267,900 日元），均为 2027年度预定额；国费留学生免缴。入学手续在 2027年3月上旬，入学许可通知在 2027年2月下旬发出。
- 成绩开示：可以申请，A日程的申请期间为 10/1–10/31 必达，B日程为 5/1–5/31 必达，申请书在研究科募集要项页下载。
- 研究生（外国人留学生等）另有单独的出願要项，这不是修士入试的要求。
- 咨询：研究科入试一般事项找農学生命科学研究科 教務課 学生支援チーム 大学院学生担当（〒113-8657 東京都文京区弥生1-1-1，daigakuin.a@gs.mail.u-tokyo.ac.jp）；専攻事项找第1志望教员或専攻担当 濱崎 恒二 教授（Tel 04-7136-6171，hamasaki@g.ecc.u-tokyo.ac.jp）。
