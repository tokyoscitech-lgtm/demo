## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各日程相同：不另设英语笔试，用 TOEFL iBT（含 Home Edition）成绩评价。
- 须在有效期内受检并向 ETS 申请把 Institutional (Official) Score Report 送到研究科（DI code 1113）：A日程 2024/8/1–2026/6/13，B日程 2025/2/1–2026/11/15；出願时在 WEB 出願系统填写 Appointment Number、受检日和分数，送过多次也只指定一次。
- TOEFL ITP 不受理，MyBest Scores 不采用。
- 变更点：2026年度还要上传 Test Taker Score Report，2027年度改为只填 Appointment Number、由 ETS 直送。

#### 日本語要件
- 要项没有要求提交日语成绩。
- A日程専門科目只用日语出题，可用日语或英语作答；B日程日英并记出题，可用日语或英语作答。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 専門科目 第1群（9科选2） | 農地環境工学、水利環境工学、環境地水学、生物環境工学、生物機械工学、生物プロセス工学、生物環境情報工学、生態調和工学、エコロジカル・セイフティー学；后两科只有以该分野为第1志望的人才能选 | 13:30–16:30，180分钟（含第2群） |
| 専門科目 第2群（4科选1） | 数学、物理学、化学、生物学的基础问题，出在専門科目试卷里 |  |

- 科目在出願时选定；A、B 两日程科目和选法相同，B日程考试时间见受験者心得。
- 2026年度出题（出题意图）：第1群各科 2 问，多为一道计算或论述题加一道专业用语说明（如农地水收支与盐类积累、明渠段波、土壤透水与入渗、植物工厂能量收支、农机设计与生物质能、冷冻除湿与稻米干燥制粉、遥感与图像处理）；数学考微积分、线性代数、统计（B日程含微分方程、固有值）；物理考旋转坐标系与惯性力；化学考卡尔·费休滴定；生物考植物光应答和基本用语。

### 口述試験 / 面接
- **官方形式**：A日程 2026/8/7、B日程在 2027/1/28–2/5 的指定日，对面或线上进行，日时等详细内容见受験者心得。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：A日程（2027年4月入学）17名；B日程（2027年4月入学）若干名；本専攻不实施10月入学。
- 出願资格：大学毕业（含 2027/3/31 前预计）或外国 16 年学校教育等 6 项之一；B日程只限在外国完成 16 年学校教育或在外国取得学士相当学位（含预计）的人，日本的大学毕业者中从初中等教育起都在日语以外语言环境受教育的，须在 2026/10/7 前申请出願对象审查（非独立出願，已截止）；个别入学资格审查 A日程 2026/5/7、B日程 2026/10/7 截止（已过）；同一日程只能报本研究科一个専攻；志望专门分野和教员最多填到第3志望。
- 要提前准备的书类：TOEFL 送分；本専攻没有另外指定的书类。
- 出願：只能通过 WEB 出願系统上传 PDF；检定料 30,000 日元（银行汇款、便利店、信用卡、Pay-easy，B日程缴纳期间 2026/10/5–11/25），日本政府奖学金留学生免缴。
- 并愿：同一日程只能报研究科的一个専攻。
- 咨询：専攻的问题问専攻主任 松田 怜 教授（Tel 03-5841-5355，bee.shunin@mail.en.a.u-tokyo.ac.jp）；出願手续问农学生命科学研究科教務課学生支援チーム大学院学生担当（〒113-8657 東京都文京区弥生1-1-1，Tel 03-5841-5010，daigakuin.a@gs.mail.u-tokyo.ac.jp）。
