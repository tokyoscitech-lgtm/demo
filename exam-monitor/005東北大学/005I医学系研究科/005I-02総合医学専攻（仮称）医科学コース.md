## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 2027年度8月一般要项PDF第10页明确：TOEIC仅收デジタル公式認定証PDF，纸质扫描件不受理；TOEFL除指定DI 3332使学校在出願截止前可阅外，还须把Test Taker Score Report PDF上传TAO。以下夏季规定不直接作为尚未公布的1月入试条件。
- 8月入试：没有英语笔试，用外部试验成绩评定。可用 TOEIC L&R、TOEFL iBT（含 Home Edition）、IELTS（Academic，纸笔或机考）、Duolingo English Test；须为 2024/6/29 以后受检的成绩，成绩单 7/10 16:00 必达。
- 各试验的提交方式：TOEIC 交デジタル公式認定証的 PDF（纸质扫描件不行）；TOEFL 指定 DI code 3332 并交 Test Taker Score Report 的 PDF，只用 Test Date 成绩，不用 MyBest；IELTS 交 Test Report Form 原件；Duolingo 在受检后选择本研究科由考试方直接发送。
- 团体受检的 TOEFL ITP 和 TOEIC IP 不受理。可以交多份，换算后取最高分；交了以后不能更换。
- 要项没有写最低分数线和换算表，只说明按一般的方法换算，并要求相当于大学毕业生的英语水平。
- 1月入试：英语的要求未公布（截至 2026-10-21），以10月下旬的要项为准。

### 日本語要件
- 要项没有要求提交日语成绩。过去问的题目是日英并记。
- コース里有用英语修读的方向（8月入试要项列的是 ヒューマンセキュリティ国際教育コース、Basic Medicine コース）。
- 外国人出願前要先向大学院教務係确认出願资格。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 小論文（60分钟，8月入试） | 论述题，题目日英并记；公开的2025年度1次过去问为2道论述题，内容偏生命科学和健康·公共卫生的一般话题。配点、选答规则要项没有写 | 2027募集要项／过去问 |
| 英语 | 没有笔试，用外部试验成绩代替 | 2027募集要项 |
| 1月入试 | 入试日程页只列了书类等审查·口头试问，有没有小论文未公布 | 入试日程 |

- 8月入试的选拔是书类等审查、小论文、英语外部试验成绩三项综合判定；要项写明医科学専攻特别重视书类等审查的结果。各项配点没有公布。
- 没有专门科目笔试。专业基础学力在各分野的书类等审查里评价。
- 分野配属不按募集人员而按各分野的接收上限决定，志望集中时按入试成绩排序。

### 口述試験 / 面接
- **官方形式**：8月入试没有全体统一的面试，由各志望分野在 2026/7/21–8/5 之间分别实施书类等审查，评价基础学力、志望动机和适性，日期和内容要在 7/21 以后向志望分野询问。1月入试预定为各志望分野实施的书类等审查·口头试问。
- **実際に聞かれた内容**：本次没有找到可核实的体验记；官方也没有公布各分野审查时的提问内容。

## 📝 详细信息
### 出願資格 / 定員
- 専攻改组：2027年4月起，医科学·保健学·障害科学·公衆衛生学各専攻改组为総合医学専攻。博士課程前期2年の課程募集人员为 110 名（医科学コース、看護学コース、公衆衛生学コース三个コース合计），官方没有公布医科学コース单独的人数。现行医科学専攻修士課程对应新専攻的医科学コース前期2年課程，学位为修士（医科学）。
- 8月入试是按改组前的名义募集的：医科学専攻修士課程 30 名，包含一般选拔、海外在住者対象特別選抜（第1次·第2次）、公衆衛生·遺伝カウンセリングコース特別選抜（第1次·第2次）的人数。1月入试的募集人数未公布。
- 8月入试要项列的方向：一般コース、ヒューマンセキュリティ国際教育コース（英语修读）、量子生命・分子イメージング教育コース、医学物理士養成コース、災害保健医療コース、Basic Medicine コース（英语修读）。改组后各方向归入新専攻的对应プログラム。
- 出願资格：大学毕业或 2027年3月底前预计毕业、取得学士学位、在外国完成16年学校教育、在外国大学完成3年以上课程并取得相当于学士的学位、专修学校专门课程修了等。其中第(9)(10)(11)项（含个别入学资格审查，须在2027年3月底前满22岁）要在出願前接受入学资格审查。
- 海外在住者対象特別選抜：出願时住在海外的人可以报。8月入试的日程与一般选拔相同，小论文改为线上，同样要事先得到指导教授同意。1月入试的海外在住者用要项未公布。
- 出願方法：网上出願系统 TAO 登记，同时缴纳检定料 30,000 日元（银行汇款，原则上不能从外国汇款），两项都完成才算出願。国费外国人留学生免缴。
- 出願书类（8月入试）：照片数据、成绩证明书、毕业（预计）证明书、受験情報届（TAO）、在留卡复印件（在留期间超过90天的外国人）、检定料汇款凭证、志望动机·理由与抱负（规定用纸，约1,000字）、学历·职历·研究历、英语成绩单。志望动机和学历研究历要在书类等审查前交给志望分野的指导教授。
- 志望分野可以填第一到第三志望，填的每一个分野都要事先得到指导教授同意。
- 2026年10月入学的选拔、同日实施的海外在住者対象特別選抜等，不能和本选拔同时出願。
- 入学料 282,000 日元；授業料：日本人学生等年额 535,800 日元，外国人留学生年额 900,000 日元（均为预定额）。外国人留学生有面向成绩前约三分之一者的奖学金（授業料全额或半额相当）。
- 在职入学者需要所属长的承诺书。入学日 2027/4/1，入学手续的通知在 2027年3月上旬。
- 咨询：医学部·医学系研究科教務課大学院教務係（仙台市青葉区星陵町2-1），m-daigakuin@grp.tohoku.ac.jp，Tel 022-717-8010（平日 8:30–12:45、13:45–17:15）。

### 研究室 / 指導教員
- 事前連絡要否：必须。要项写明出願前要直接联系全部志望分野的指导教授，告知受験希望并得到同意。
- 各分野的教员和联系方式在分野一览和教员检索里查；官方另有一份専門（募集）分野一览（外部表格），列出本年度募集的分野。
- 改组后讲座重新归组为基礎医学、臨床医学、情報健康医学、公共健康医学、創生応用医学等；官方说明里没有列出的讲座名称不变。
- 本次没有逐一整理各分野的教员和研究内容。
