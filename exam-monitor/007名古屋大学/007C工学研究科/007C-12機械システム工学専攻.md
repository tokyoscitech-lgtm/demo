## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 8月入试（笔试免除者选拔、一般選抜）：
  - 不另设英语笔试，用 TOEFL iBT（含 Home Edition）或 TOEIC Listening & Reading 公开考试的成绩评价；成绩单贴在「TOEFL/TOEICスコアシート提出用紙」上随出願书类寄出，两种可交其一或都交。
  - TOEIC 只收公式认定证（Official Score Certificate）原件，数字版公式认定证的打印件按原件处理；一般選抜最晚可用 2026/5/31 实施的那一回。
  - TOEFL 要交两样：由 ETS 直送大学的 Institutional／Official Score Report（Institution Code D377，Department Code 69），和 Test Taker Score Report 的复印件；直送成绩须在出願期间最后一天前到达。只采用 Test Date Scores，不采用 MyBest。
  - 只承认 2024/6/1 以后实施的成绩；TOEFL ITP、TOEIC IP（团体考试）不受理；交上去的成绩单不退还。
  - 没交成绩也可以出願和应考，但英语不评价。募集要项没有公布英语的配点、最低分和换算方法。
  - 笔试免除者选拔出願时就要交成绩（只有電気電子情報工学系 3専攻免交，不适用于本専攻）；没有获得免除而转入一般選抜的人可在 2026/7/29（周三）17:00 前换交新成绩（已截止）。
- 外国人留学生入试：
  - 本専攻实施学内英语考试（语学考试：英語），在 2026/11/18–11/20 期间进行，时长和配点要项没有公布；这条路线不要求提交 TOEFL/TOEIC 成绩（要项只对化学生命·マテリアル·電気電子情報工学系要求スコアシート）。

#### 日本語要件
- 8月入试：募集要项没有要求提交日语成绩。笔试和口頭試問都用日语进行，不提供英语出题。
- 外国人留学生入试：
  - 须提交「日本語能力を証明するもの」：日语任课教师或相当者出具的证明书（原件），或 JLPT／JPT 成绩（复印件可）；要项没有规定最低等级。通过日语教育课程从日本的大学毕业（或预计毕业）的人免交。
  - 専門科目笔试的题目日英并记；要项写明可能在语学考试、口頭試問等环节检定日语能力。
