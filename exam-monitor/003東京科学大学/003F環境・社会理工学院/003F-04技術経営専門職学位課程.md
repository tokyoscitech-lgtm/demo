## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般募集（A日程、B日程都必须）：
  - 本课程不另设英语笔试，用外部成绩评价；成绩单须在出願时随书类提交（6/10 必达），提交后不能更换；截止前没交的即使拿到受験票也没有受験资格。
  - 收 TOEIC L&R、TOEFL iBT、TOEFL iBT Home Edition，须为 2024/6/11 以后受检；TOEFL ITP、TOEIC IP 等团体特别受验无效。
  - 只收网上下载 PDF 的打印件：TOEIC 须带真伪确认 QR 码（デジタル公式認定証等）；TOEFL 交 PDF 版 Test Taker Score Report，并在 ETS 账户给所用成绩设定 DI code G179；ETS 寄给本人或学校的纸质成绩单不受理。
  - 学校把成绩换到 TOEFL-PBT 尺度：TOEIC L&R＝（PBT－296）÷0.348（TOEIC 300 分以下不适用）；TOEFL iBT 按对照表，例如 iBT 80＝PBT 550，iBT 100＝PBT 600–603。
- 社会人募集：
  - 出願书类里交外部成绩，收 TOEIC L&R、TOEFL iBT、TOEFL iBT Home Edition，须为 2024/10/30 以后受检；团体特别受验无效。
  - TOEIC 须带 QR 码；TOEFL 交 PDF 版并设定 DI code G179，Department Code 没有对应项时选「99」。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 一般募集的口述試験·口頭試問和社会人募集的口頭試問都只用日语进行。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 无（不实施笔答试验） | 一般募集按出願书类、英语外部成绩和日语口试选拔；社会人募集按英语外部成绩、口頭試問、成绩证明书、志望理由書选拔 |  |

- 一般募集：A日程或B日程由课程按出願书类决定（2026/7/2 12:00 前后在マイページ通知，考生不能自选，资格9只能考B日程）；A日程按口述和出願书类决定合格内定，未内定者转考B日程；B日程先做书类选考定出口頭試問资格者（2026年为43人），再按口頭試問和出願书类判定；每位教员的指导学生数有上限。
- 社会人募集：可能先按出願书类决定口頭試問资格者。

### 口述試験 / 面接
- **官方形式**：一般募集A日程：口述試験，问学力、学习意愿、今后的学习主题等，只用日语；一般募集B日程：口頭試問，只面向书类选考通过者，内容同A日程，只用日语，具体时间地点邮件通知资格者；社会人募集（仅社会人）：口頭試問，围绕志望理由書内容问答，只用日语，个人时间和地点由课程另行通知。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：40名（2026年9月和2027年4月入学合计），其中15名由11月社会人募集（仅社会人）另行选拔；课程案内的受入可能予定人数为43名（含社会人募集）。
- 出願资格：大学毕业（含2027/3/31前预计）或外国16年学校教育等；资格(9)–(11)须先做出願资格审查（非独立出願）；资格(10)三只适用于本课程：専修学校専門課程、高専、短大毕业或大学在学2年以上退学，且在企业等有合计2年以上（社会人募集为3年以上）职务经验；社会人募集只招出願时在企业等有合计3年以上职务经验者；理工学系只能报一个系或课程，同一入学期不能并报，前一个出願结果出来前不能再报；外国籍考生选9月入学须出願时住在日本且在留资格有效到2026/9/28。
- 要提前准备的书类：志望理由書（各轮次相同：①为什么想在本课程学习约500字，②至今活动中学到的特别值得一提的内容约500字，③本课程的研究计划约1,500字，各项注明字数，参考文献编号列在末尾、不计字数）；英语外部成绩打印件；社会人募集另需直接上司填写的就学確認書（交不了时自写理由书）；非日英证明书附公的机关证明的日/英译文；有 GMAT 成绩的可在口试时交复印件作参考，不用于判定。
- 出願：一般募集先在网上出願系统登记、上传照片、缴检定料30,000日元＋手续费990日元，再把书类用速達書留寄到入試課（必达，不收窗口）；社会人募集用网上表单登记（只能一次），检定料30,000日元在E-支払い缴纳，书类装角形2号信封朱书「技術経営（社会人募集）出願書類在中」速達書留寄送（必达，不收窗口）。
