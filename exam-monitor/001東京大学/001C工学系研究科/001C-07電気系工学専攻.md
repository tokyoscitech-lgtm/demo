## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 只有夏季一轮。不另设英语笔试，用 TOEFL 成绩评价；只收 TOEFL iBT 和 TOEFL iBT Home Edition，要项没有把 TOEIC、IELTS 列为可提交的考试。
- 提交三步：①通过 ETS 把官方成绩寄送到工学系研究科（DI コード 8596，Department コード 99）；②在 WEB 出願系统的マイページ登记 Appointment Number 和受検日；③把 Test Taker Score Report 上传到マイページ。
- 本専攻的 TOEFL 提交截止为 2026/8/20（周四）（已截止）；截止前可反复更改登记。没有提交 Appointment Number 的，可能仅因此不合格。
- 有效期：受検日在 2024年9月以后。只采用 Test Date Scores，不采用 MyBest Scores；TOEFL ITP 等团体成绩不能用；母语是英语的人也要交。
- 要项和専攻入试案内都没有写 TOEFL 的配点、换算方法和最低分。
- 免除：东京大学大学院工学系研究科修士课程的修了（预定）者不需要英语；修士特別口述試験合格者免英语和専門科目笔试（普通口述試験仍要参加）。

#### 日本語要件
- 要项和専攻入试案内都没有要求提交 JLPT、EJU 等日语成绩，外国人考生走一般选拔不交日语证明。
- 専門科目试题日语和英语并记，可用日语或英语作答；口述試験用什么语言，専攻入试案内没有写。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 専門科目（電気電子工学·情報工学）（配点官方未公布，2题合计150分钟） | 6个出题范围各1题，选2题作答：①電磁気学（静电场、电介质、电流、磁场、磁性体、电磁感应、麦克斯韦方程、电磁波）；②電気回路（线性电路的直流·交流分析、过渡响应、拉普拉斯变换、频率响应、分布常数线路；电子电路的小信号等效电路、放大器、振荡器、反馈）；③情報工学Ⅰ（信息理论、信号处理：傅里叶变换、采样定理、z变换、数字滤波器、调制）；④情報工学Ⅱ（逻辑电路、算法与编程：搜索、排序、数据结构）；⑤固体物性（量子力学基础、费米–狄拉克统计、能带、pn结、MOS结构）；⑥制御·電気エネルギー工学（传递函数、稳定性、反馈设计；交流电路、能量变换） | 2027専攻入试案内／専攻试验科目页 |
| 一般教育科目（数学） | 本年度不举行笔试 | 2027専攻入试案内 |

- 各范围列出的关键词只表示重点，不限定出题范围。各科目配点和总分未公布。
- 合否判定和配属：按笔试和口述試験的成绩、提交书类的内容、志望的指导教员等综合决定；専門科目笔试和口述試験必须两项都参加，否则受験无效。
- 预备选拔：志願者多时按専攻調査票的内容和成绩表进行预备选拔，有没有实施及其结果在 2026/8/14（周五）前掲載在専攻入试网页（受験者専用页），审查标准不接受询问。
- 笔试免除：本専攻、電気·電子工学専攻、新領域創成科学研究科基盤情報学専攻和先端エネルギー工学専攻、情報理工学系研究科電子情報学専攻的修士课程修了（预定）者，只参加口述試験。
- 背景：为了让电气系以外出身的人也能报考，从2020年度入试起调整了専門科目构成、减少了题数。
- 题目倾向（体验记，非官方）：外部生两类选法都有——有人选電磁気学＋電気回路，也有情报系出身的人选情報工学Ⅰ＋情報工学Ⅱ（理由是電気回路计算量大）。一位2023年受験者认为基础题约占八成，重点在于弄清东大本科讲到哪里；専攻Q&A 提到内部升学者多数准备一个月左右。

### 口述試験 / 面接
- **官方形式**：夏季入试的口述試験 2026/8/31–9/3 线上进行（自备电脑、摄像头和宽带网络），问志望分野及理由、该分野的基础事项，并让考生口头介绍毕业研究，指定时间不参加视为放弃，配点、时长和使用语言未写；修士特別口述試験（2026/7/18，线上）面向书类选考判定为成绩优秀、且以本専攻为第一志望的人，问志望分野及理由和该分野的基础知识。
- **実際に聞かれた内容**：（体验记，非官方）一位2023年8月受験的外部生：约25分钟，约5名教员轮流提问；问了为什么选东大、想做的研究、笔试的自我评价、専攻調査票里写到的技术、本科研究和研究生阶段研究的不同（仅1人提及）。一位2024年受験的外部生写到特別口述不合格，之后走普通笔试＋口述并合格。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：夏季入试（出願日程A，2027年4月入学和2026年10月入学合计）70 名；本専攻修士课程本年度不实施出願日程B（冬入试）。
- 出願资格：日本的大学毕业或 2027/3/31 前预计毕业；在外国完成16年学校教育（含预计）；取得相当于学士的学位（含预计）；文部科学大臣指定的教育设施修了；由学位授与机构授予学士学位；或通过个别入学资格审查且到 2027/3/31 满22岁，共6项之一。个别入学资格审查的申请截止为 2026/4/21（周二）（已截止）。
- 入学时期：2027年4月入学；满足研究科要件的合格者也可在出願时申报 2026年10月入学，与合否无关。新办在留资格通常要约3个月，専攻建议这类考生选4月入学。
- 指导教员的填写：出願时在线上登记希望指导教员的优先顺序，变更期间内可在 WEB 出願系统的マイページ修改。
- 出願书类：入学願書（线上填写）、证件照数据、检定料、毕业证明书（已毕业者）、成绩证明书（本専攻对东京大学工学部毕业（预定）者也要求）、出口管制检查表（外国籍者等）、専攻調査票和成绩集计表。外国大学毕业者的证明书上要写明学位，没有写明的另交学位取得证明书；日英以外语言的证明附出身大学盖章英译。
- 専攻調査票：下载専攻指定表格，写修士阶段希望做的研究内容、毕业研究题目、毕业后的打算，用于预备选拔和口述試験；成绩证明书的内容要按各区分的取得学分汇总到成绩集计表（教养科目也算；高専编入者把高専4、5年级成绩全部算入）。
- 出願方式：只有 WEB 出願，没有邮寄和窗口。受験票于 2026/7/3（周五）15:00 左右在マイページ发放，自己打印带去考场。
- 检定料 30,000 日元，可用便利店、Pay-easy、网络银行、中国决济或信用卡支付；日本政府（文部科学省）奖学金留学生免缴。已缴的检定料不论什么原因都不退，预备选拔不合格也不退。
- 并愿限制：不能同时报工学系研究科的两个以上専攻或课程。
- 入学料 282,000 日元，授業料 年 535,800 日元（前期 267,900 日元），均为预定额；日本政府奖学金留学生不征收。4月入学者的入学手续截止 2027/3/9（周二，预定）。
- 考场规则：带受験票、黑色铅笔或自动铅笔、橡皮、卷笔刀、尺、只有计时功能的手表；不能带圆珠笔，不能用手机、可穿戴设备、计算器和词典；开考后即使答完也不能离场。需要考试照顾的人要在出願截止前向学務課大学院チーム申请。
- 咨询：募集要项的问题用研究科网站的咨询表单（工学系研究科学務課大学院チーム）；専攻入试咨询 eeis-nyushi27-group@g.ecc.u-tokyo.ac.jp。
