## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各轮次相同：不另设英语笔试，用 TOEIC Listening & Reading 公開テスト的成绩评价英语；本専攻按 Listening：Reading＝1：3 加权。最低分、换算方法和英语在总分中的配点官方没有公布。
- 成绩须为学力检查日前2年以内受験的公開テスト（一般入试以 2026/8/25、自己推薦入试以 2026/7/10 为准），只能交1次成绩；IP テスト（団体特別受験）和 TOEFL 不受理。
- 在日本国内受験的：出願时交研究科所定的「TOEIC L&R 公開テスト受験情報確認票」，并在 TOEIC 申込网站输入申请代码 00010402 在线送分（考试日17天后才能操作），不接受用公式認定証送分；在海外受験的交公式認定証原件。期限：自己推薦入试 2026/6/22（周一），夏季一般入试 2026/8/3（周一）（均已过）。
- 变更点：2028年度入试（含2027年10月入学，自己推薦入试也一样）起，送分期限提前到出願期间最后一天，期限内没交的不受理出願（研究科入试页予告）。

#### 日本語要件
- 一般選抜、自己推薦入试：要项没有要求提交日语成绩。
- 外国人留学生特別選抜：必须提交“日语水平足以不妨碍修学”的证明书，要项举例为日本語能力試験成绩证明书，没有规定等级或分数。
- 英語コース：英文要项没有日语要求。
- 试题语言和作答语言，要项没有写明；已公开的过去问为日文。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 専門科目「惑星学」或「基礎科学」（180分钟，配点要项未公布） | 按2026年度试卷：5道大题选2题，每题150分（合计300分），每题用单独答题纸；5题为数学、物理学（相当于「基礎科学」）和岩石学·矿物学、地质学、固体地球物理学（相当于「惑星学」）；以计算、推导、读图作图和简答论述为主 | 2027募集要项／2026年度过去问 |
| 英語（TOEIC L&R 成绩，配点官方未公布） | 不设笔试，按 Listening：Reading＝1：3 加权评价 | 2027募集要项 |
| 自己推薦入试 | 无笔试：第一次选拔为书类审查（自己推薦書约4,000字等），第二次选拔为口头试问 | 2027自己推薦募集要项 |
| 英語コース | 不考专门科目，看出願书类和口头试问 | 英文要项 |

- 夏季一般入试综合学力检查（笔试、口头试问）和成绩证明书决定合格者：第一次选考看専門科目和 TOEIC，只有第一次选考合格者能参加第二次选考。配点、总分和合格线官方没有公布。出于教育上的考虑，各教育研究分野的合格者数可能受限。外国人留学生特別選抜的科目与一般選抜相同。
- 题目倾向（据公开过去问归纳，非官方）：数学题涉及向量运算、线积分与格林定理、用傅里叶变换解扩散方程；物理题涉及力学和电磁学；地学三题分别考岩浆与相图、应力应变与构造地质、地震波与地球内部构造。物理·数学背景的考生可只选基礎科学的2题。

### 口述試験 / 面接
- **官方形式**：夏季一般入试一般選抜 2026/8/26 9:30 起口头试问，只面向第一次选考合格者，以笔试日集合时提交的 A4 1页毕业研究内容或研究计划书面和出願书类为依据，时长、配点和语言要项没有写明；外国人留学生特別選抜同日 9:00 起面接；英語コース同日 9:00 起口头试问，经专攻同意可用 Zoom 等网络通话；自己推薦入试第二次选拔为口头试问，内容按志望分野个别通知第一次选拔合格者；冬期追加募集未公布。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：一般選抜24名（含自己推薦入试12名），外国人留学生特別選抜若干名，英語コース若干名；冬期追加募集是否实施、人数均未公布。
- 一般選抜的出願资格共11项，满足其一即可：大学毕业或2027/3/31前预计毕业、在外国完成16年学校教育、在外国取得相当于学士的学位（3年以上课程）、经个别资格审查认定与大学毕业同等以上学力且2027/3/31前满22岁、大学在学3年以上且成绩优秀（跳级）等。个别资格审查的申请截止：夏季一般入试 2026/6/5（周五），自己推薦入试 2026/5/8（周五）17:00 必达（均已过）。
- 自己推薦入试：在学历条件之外，须受过与惑星学相关的教育、学业和人品优秀、已得到志望指导教员的内诺，并保证合格后一定入学（最终合格后2周内交入学確約書，本年度 2026/8/4 必达）。不限出身大学，神戸大学理学部惑星学科以外的考生须另交「主要科目成績表」。
- 外国人留学生特別選抜：须持有在留资格「留学」（含预计2027年4月取得者），并满足大学毕业（含预计）、外国16年课程、外国3年以上课程的学士相当学位、个别审查认定之一。
- 英語コース（英语授课的修士课程）：须满足神戸大学在学或毕业、与理学研究科有交流协定或曾有交流的大学的在学或毕业、与理学研究科教员已有密切联系、取得外国政府或民间奖学金之一并有所属机构的推荐；须取得志望指导教员的同意；入学时能取得「留学」在留资格。
- 志望的填写：一般入试的 Web 出願不填指导教员姓名，但出願前必须联系第1志望、第2志望的教育研究分野的教员；志望「惑星地球変動史」「応用惑星学」（※分野）的须在出願前先与专攻长商量。
- 出願方式：先在 Web 出願网站登记、上传证件照数据（3个月内拍摄，2MB 以内）并缴纳检定料，再在书类提交期间内把纸质书类送达理学研究科教務学生係（邮寄用レターパックプラス或書留速達；窗口 9:00–12:00、13:00–17:00）。
- 出願书类（一般選抜）：入学願書·履历书（从 Web 出願网站打印）、成绩证明书、毕业（预计）证明书、TOEIC 受験情報確認票；住在日本的外国人另交住民票复印件（30日以内）或在留卡复印件。A4 1页研究内容书面不是出願书类，而是笔试当天集合时提交。中国大学毕业者须另交经 CHSI 认证的英文学历·学位报告（在读者交 Student Record）；日文、英文以外的证明书须附公的机关翻译证明的日文译文。
- 自己推薦入试另需：自己推薦書（约4,000字，A4，格式自由，可用图表；写感兴趣的地球·惑星科学、毕业研究、选择志望分野的理由、自己的适性、入学后的抱负5项）和主要科目成績表（仅该当者）。
- 外国人留学生特別選抜另需：日语能力证明书、出身大学指导教员的推薦状（研究科所定样式；本研究科研究生等身份在籍者免）、国费外国人留学生证明书（仅该当者）。英語コース另需学部长和指导教员的推荐信。
- 检定料 30,000 日元，在 Web 出願网站支付，手续费自负。出願后不能修改登记内容，已交书类和检定料原则上不退。
