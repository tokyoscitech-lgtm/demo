## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 夏季入试（一般選抜·特別選抜·国費外国人留学生特別選抜）：英语不设笔试，用 TOEIC Listening & Reading Test（公开考试）或 TOEFL iBT（含 Home Edition）的成绩换算，配点 100 分。
- 提交方式：TOEIC 交 Official Score Certificate（公式认定证）；TOEFL 要通过 ETS 把 Official Score Report 直送大学（横浜国立大学的机构代码为 0410），并在考试当天交 Test Taker Score Report。成绩单在考试当天回收：一般選抜在学科試験Ⅰ的考试时间内，特別選抜在口述试验时间内。
- 有效期：受检日距提交日2年以内，且成绩单须带本人照片。TOEIC IP、TOEFL ITP 等团体考试成绩不受理；要项没有把 IELTS 列为可用成绩。
- 换算：TOEIC 801分及以上＝100分；500–800分＝（分数－500）÷6＋50；350–500分＝（分数－350）÷3；349分以下＝0分。例如 TOEIC 740＝90分，650＝75分，500＝50分。TOEFL iBT 按要项的对照表换算：90分及以上＝100分，89＝99分，79–80＝88分，69–70＝75分，59–60＝63分，49–50＝43分，40＝15分，35分以下＝0分（对照表中间各档以要项原表为准）。
- 考试当天没有交有效成绩单的，不会成为合格者。FAQ 明确：以英语为母语或用英语取得学位的人也必须交 TOEIC 或 TOEFL 成绩；在中国受检的 TOEIC Official Score Report 视同 Official Score Certificate，可以使用。
- 数理科学ユニット的一般選抜可以二选一：用 TOEIC／TOEFL 成绩，或参加独自英语考试（数学方面英文的读解与作文的笔试，2026/8/21 10:30–11:30）；选了独自考试而缺考的不会成为合格者。物理工学ユニット和電子情報システムユニット只能用 TOEIC 或 TOEFL 成绩。

### 日本語要件
- 要项没有要求提交日语成绩（JLPT、EJU 等都没有规定）。
- 学科试验和面接的作答只能用日语或英语。学科试验可以带纸质的语言词典，电子词典不行。
- FAQ 提到研究生院的授课大多用英语进行，但入学后的各种文件是日语，日语不足时可能需要チューター等支援。这是入学后的说明，不是出願条件。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：夏季入试（2027年4月入学）数物・電子情報系理工学専攻整体 146 名，这是一般選抜与特別選抜合计的数字，要项不按ユニット或教育分野拆分；社会人特別選抜若干名；2026年10月入学的国費外国人留学生特別選抜若干名。第2次募集的人数未公布（上次 2023年度为各ユニット若干名）。
- 専攻构成：数理科学ユニット（数学教育分野）、物理工学ユニット（物理工学、半導体物理工学教育分野）、電子情報システムユニット（情報システム、電気電子ネットワーク、集積エレクトロニクス教育分野）。電子情報システムユニット的三个教育分野各自再选 TED 或 PED 项目。専攻介绍页还列有「応用物理」教育分野，但本年度要项的募集表里没有列出。
- 出願资格：大学毕业或入学前预计毕业、在外国完成16年学校教育、取得学位授与机构的学士学位（预计）、专修学校专门课程修了、跳级（大学3年级结束时成绩前5%等条件）等之一。按资格（5）之2、（8）–（10）出願的人要先通过出願资格认定审查（夏季入试的书类提交为 2026/5/11–5/13 必达，可邮寄或窗口提交）。
- 特別選抜的追加条件：由出身大学等推荐，且3年级结束时成绩在前1/3以内（或80分以上的学分占总学分一半以上等同等条件）；出願时要在 Web 出願系统里做入学确约。
- 社会人特別選抜：面向有学士学位、在同一企业等有1年以上相关专业经历的在职技术人员，只进行面接。
- 志望的填写：在 Web 出願系统里填専攻、ユニット、教育分野、项目和志望指导教员；要项没有设第2志望以下的栏目。
- 出願书类（一般選抜）：入学願書（在 Web 系统里录入）、照片数据（3个月以内拍摄，2MB 以下）、毕业（预计）证明书、成绩证明书；外国人还要交在留资格的证明、外国人留学生履历书（書式19-1）和有志望指导教员签名的受入内諾書（書式19-2，签名不必是原件）。特別選抜另交推荐书（書式15）和志望理由书（書式18）。本専攻的一般選抜不要求研究计划书（要项里只有先端化学ユニット要交）。证明书不是日文或英文的，要附日文或英文译文。

- 入学料 282,000 日元，授業料年额 535,800 日元；入学手续完成后入学料不退。国費外国人留学生不用缴纳。
- 考场在横浜国立大学常盤台校区内（要项没有写具体建筑）。考试开始20分钟前进入考场，考试开始后不能入场；手机须关机；学科试验、面接缺任何一项都不会成为合格者。本専攻的学科试验不能带计算器（要项只允许先端化学、化学応用·バイオユニット带函数计算器）。
