## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 1-2月实施：
  - 不另设英语笔试；出願时提交 TOEIC、TOEFL 或 IELTS 成绩（2025年1月以后受检）并在 Web 系统填分数，英语能力在口述試験1里考查。
  - 种类限制按全学共通办法：TOEIC 只认 L&R（IP 不受理）；TOEFL 认 iBT 和 Home Edition（ITP 不受理）；IELTS 只认 Academic（General、Online、One Skill Retake 不受理）。TOEFL 无纸质报告时由 ETS 直送（Institution 代码 9995，Department 代码 99）。
  - 没有最低分，也没有单独配点或换算方法。英语为母语或用英语接受高等教育的人不用交；没有英语成绩的人，推薦書里必须评价英语能力。

#### 日本語要件
- 要项没有要求提交 JLPT、EJU 等日语成绩，可以只用英语受験。研究计划书用英语写（约1,000词）；口述試験1 用英语出题作答、问答可用日语；口述試験2 英语或日语均可。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 笔试 | 两轮都不设笔试 | 2027募集要项 |
| 口述試験1（100分；1-2月实施） | 医学·人間生物学与理工情報学·物質科学两方面专业知识的口头试问，用英语 | 2027募集要项 |
| 口述試験2（200分；1-2月实施） | 融合研究计划和职业规划的发表加问答，英语或日语 | 2027募集要项 |

- 1-2月实施总分 300（口述試験1 100＋口述試験2 200），按书类和学力检查结果综合判定；缺考任一科不进入选拔。
- 题目倾向（体验记，非官方）：没有找到考生体验记。

### 口述試験 / 面接
- **官方形式**：8月实施（已结束）为口述試験Ⅰ（试问约20分钟）与口述試験Ⅱ（发表约10分钟＋问答约10分钟）；1-2月实施为口述試験1（100分，英语专业试问）与口述試験2（200分，研究计划与职业规划发表加问答，英语或日语），2027/1/25（周一）为予備日，自带存好发表资料的笔记本电脑（HDMI，转接器自备），海外居住者在出願期限内交申告书可线上受験。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：一貫制博士課程（1年次入学）全年8名；1-2月实施要项写若干名；没有修士課程的募集。
- 课程性质：5 年一貫制博士課程，只招1年次入学，没有单独的修士課程，要项没有3年次編入学；1-2月实施可选 2027年4月或10月入学。
- 出願资格：日本四年制大学毕业（预计）；学位授与機構授予学士；在外国完成16年学校教育；在外国3年以上课程取得相当于学士的学位；经个别审查认定同等学力且满22岁等。
- メンター：在 Web 出願系统填主メンター和副メンター各1名（分属医学·人間生物学和理工情報学·物質科学两侧），出願前都要取得同意；副メンター入学后正式确定。
- 出願书类：英文研究计划书（约1,000词）、英语成绩、毕业（预计）证明书、学位取得证明书（外国大学毕业者）、成绩证明书、受験·就学承认书（在学或在职者）、国费留学生证明书（符合者）等；推薦書1份由推荐人直接用書留或邮件寄到 SIGMA 事務室，12/11 前未到不受理。
- 检定料 30,000 日元（国费外国人留学生免缴）；入学料 282,000 日元；授業料年额 535,800 日元，外国人留学生年额 608,800 日元。
