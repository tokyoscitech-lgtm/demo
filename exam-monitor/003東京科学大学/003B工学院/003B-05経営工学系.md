## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般入试（A日程、B日程都要）：
  - 不另设英语笔试，用 TOEIC L&R 或 TOEFL iBT（含 Home Edition）成绩评价，B日程配点 50 分。
  - 本系要求出願时随书类提交在线版成绩单打印件，直接带来等其他方式一律不收，交后不能更换、不退还；没交的没有受験资格。
  - 只认 2024/6/11 以后受检的成绩。TOEIC 须为带真伪确认 QR 码的数字公式认定证 PDF 打印件；TOEFL 须为 Test Taker Score Report PDF 打印件，并在 ETS 账户为该成绩设定 DI code G179。ETS 邮寄的纸质成绩单、TOEFL ITP、TOEIC IP 等团体考试不受理。
  - 要项附録3的换算基准：TOEFL iBT 先按对照表换成 PBT，再用（PBT－296）÷0.348＝TOEIC L&R，例如 iBT 80→PBT 550→TOEIC 约 730，iBT 100→PBT 600–603→TOEIC 约 874–882（TOEIC 300 分以下不适用）。
- IGP(C)：申请材料不要求英语成绩；面试和考试用英语进行。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 本系写明考试用日语进行（A日程口述、B日程筆答和口頭試問），2025年实施的筆答试题只有日文；志望理由须用日语写约500字，研究计划书可用日语或英语。
- IGP(C) 全英语授课，不要求日语。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 専門科目（200分） | 数理分野 1 问：线性代数、微积分、基础数理、数理工学、概率·统计；2025年实施的试卷为线性代数、微分积分、数理工学、概率·统计各 1 大题，全答 | 10:00–11:20，80分钟 |
| 英语（50分） | 用外部成绩评价，见英語要件 | |

- A日程：系根据出願书类决定受験资格者（考生不能自选），口述考专门知识和学士论文研究内容，凭出願书类和口述决定“合格内定”；没有内定的照常考 B日程；出願资格(9)（飞级）只能考 B日程。
- B日程：总分 250，按筆答结果选出口頭試問受験资格者，综合筆答、口頭試問和出願书类判定；每位教员的指导学生数有上限；筆答中止时改按出願书类评分选口頭試問受験资格者。
- 参考文献（系公布，2026年3月版）：松坂和夫《線型代数入門》、難波誠《微分積分学》、宮川雅巳·水野眞治·矢島安敏《経営工学の数理 I·II》、久保川達也·国友直人《統計学》；系注明不保证只从这些书出题。
- 2025年实施的出题（出題の意図归纳）：线性代数考正交投影、最小二乘、迹与秩、正定矩阵；微分积分考连续与导数的定义及一阶微分方程；数理工学考等价关系、等价类和行列式；概率·统计考回归分析与逻辑回归。
- 变更点：2026年实施的筆答为 80 分钟（2025年的试卷为 60 分钟）。
- 题目倾向（体验记，非官方）：时间紧、拼速度（2人提及）；2025年8月约20道小问、最后一题考逻辑回归，2024年8月统计部分超出预期、比前一年难（各1人）。

### 口述試験 / 面接
- **官方形式**：A日程：口述試験，考专门知识和学士论文研究内容，日语，对面；B日程：口頭試問，考查学力、研究能力和适性，日语，对面，只有受験资格者名单上的人参加，不必穿正装；IGP(C)：系或志望导师安排的英语面试和/或考试，原则线上。
- **実際に聞かれた内容**：
  - B日程每人约15分钟，第1志望教员主问，先问研究计划的固定问题，再围绕研究计划和相关专门知识追问（2024年8月、2025年8月，2人提到）。
  - 面试官多名：2024年8月为5名（含第1–3志望教员），2025年8月按研究分野分房间、约7名（各1人提到）。
  - 候场时不能用电子设备，建议带纸质资料（2024年8月、2025年8月，2人提到）。
  - 口頭試問也会刷人（2024年8月、2025年8月，2人提到）。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：経営工学系受入可能予定人数 62 名（2026年9月和2027年4月入学合计，工学院合计 477 名）；IGP(C) 各系若干名。
- 出願资格：大学毕业（含预计）或外国16年学校教育等，(9)(10)(11) 项须先做资格审查；只能报一个系，出结果前不能再报理工学系其他募集（含 IGP(C)）；外国籍考生选9月入学须出願时住在日本且在留资格有效到 2026/9/28，否则只能4月入学；志望教员不必填满10位，推荐填3位以上。
- 要提前准备的书类：志望理由书（推荐用系样式 IEEForm2026，含学士 GPA 及算法、日语约500字的志望理由、A4 3页以内的研究计划书（日英均可，引用先行研究，可按第一志望研究室设想））；TOEIC L&R 或 TOEFL iBT 成绩单（出願时必交）；IGP(C) 另需导师同意书（10/4 前交入試課）、研究计划和推荐人直接提交的推荐信。
- 出願：一般入试网上登记缴费后把书类以速達書留寄入試課（6/10 必达），检定料 30,000 日元＋手续费 990 日元；IGP(C) 全程网上提交，检定料 30,000 日元（信用卡）。
- 并愿限制：只能报一个系；同一入学期不能报理工学系修士的多个募集，一个出願结果出来之前不能再报理工学系其他募集。
- 咨询：出願手续问入試課大学院入試グループ（inquiries.grad.se@adm.isct.ac.jp）；本系入试内容问経営工学系入試担当（admission@iee.eng.isct.ac.jp）。
