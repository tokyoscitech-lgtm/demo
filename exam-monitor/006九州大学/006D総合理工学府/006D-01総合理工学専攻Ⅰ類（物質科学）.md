## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各轮次都不另设英语笔试，用外部成绩评价：出願时上传 TOEIC L&R 公式認定証原件（原则上带本人照片）、TOEIC L&R デジタル公式認定証（QR码须可读）、TOEFL iBT Test Taker Score Report 原件三者之一的 PDF；TOEIC-IP、TOEIC Speaking & Writing、TOEFL ITP 不受理。
- 受验日：一般選抜须在 2024/7/4 以后；第2次募集、国際コース4月入学须在 2024/12/5 以后。
- 出願时成绩还没出的，先交能看出姓名和受验日的报名证明（受験票复印件或マイページ截图），考试当天带原件（数字版带打印件）；考试当天还确认不了公式成绩的可能不能受験。
- 国際コース：英、美、加、澳、新西兰、爱尔兰等英语国家出身者免交（其他英语官方语言国家须先问教務課）；在外国大学用英语受课的，可用校长或研究科长出具的 CEFR B2 以上证明信代替。

#### 日本語要件
- 要项没有要求提交日语成绩。一般選抜和第2次募集全部用日语进行，笔答只能用日语作答，面接和口头试问也用日语；要项建议日语不熟练、在留资格为「留学」的考生改报国際コース。
- 国際コース的笔试、面接、口述全部用英语进行。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 一般選抜·筆答試験（Ⅰ類） | 数学Ⅰ（线性代数、微分方程）和固体物性学、力学、物理化学、無機化学、有機化学、基盤化学、金属材料学、電磁気学、電気回路論各1题，共10题选3题；有機化学出3个小问＋生化1个小问，从中选3个小问；基盤化学3个小问选2个 |  |
| 第2次募集、国際コース4月入学（Ⅰ類）：専門1科目 | 金属材料学、無機化学、物理化学、有機化学4科选1，出願时用試験科目申告票申告，之后不能更改；国際コース用英语出题、作答 |  |

- 一般選抜出题范围：数学Ⅰ为矩阵、联立一次方程与逆矩阵、向量空间、行列式、线性映射、特征值与特征向量、（联立）常微分方程；物理化学为化学热力学、化学平衡、反应速度论；無機化学为化学键、分子结构、简单固体结构、配位化学（晶体场·配位场理论）、元素与无机化合物；有機化学为烷烃到羧酸衍生物的立体化学·反应机理·合成、周环反应、生物分子、酶反应、基因表达、糖代谢；基盤化学为原子结构与周期表、酸碱·氧化还原·电化学·溶液平衡、有机分子的结构·物性·功能；金属材料学为晶体结构、晶格缺陷、相图、凝固、扩散、相变、热处理、组织、弹塑性变形、位错、强化机制；固体物性学为键合、晶体结构、结构因子与衍射、晶格振动与热性质、金属与半导体的电性质；力学为质点·质点系·刚体；電磁気学为静电场、恒定电流、静磁场、电磁感应；電気回路論为直流·交流电路、电路定理、二端口网络、过渡现象、三相交流、基础电子电路。
- 一般選抜跨類限制：只志望Ⅰ類研究室时数学Ⅰ不是必答；志望里含Ⅱ類或Ⅲ類研究室时数学Ⅰ必答，并且至少答1题共通専門科目（Ⅰ・Ⅱ類共通：固体物性学、力学、電磁気学、電気回路論；Ⅰ・Ⅲ類共通：力学、電磁気学），不满足条件的類的研究室不论志望顺位都不分配。化学工学没有笔试题，只在口述試験里对应。
- 合否判定：筆答試験、第2次募集、国際コース按出願书类和学力检查（笔试＋面接）综合判定；口述試験按出願书类（含志望动机·研究计划书）和口头试问综合判定。

### 口述試験 / 面接
- **官方形式**：一般選抜·口述試験：不考笔试，口头试问専門科目、毕业研究、志望动机和入学后研究计划（日语），对象由専攻按出願书类决定、6月下旬在マイページ通知，前提是第1志望研究室属于Ⅰ類且出願前与该教员面谈过（可线上），不合格的可再考筆答試験但不能改志望研究室；一般選抜·筆答試験：面接含学问领域的提问（日语）；第2次募集：笔试日有面接（日语）；国際コース4月入学：Ⅰ類不实施口述試験，12/5 笔试日有面接（英语）。
