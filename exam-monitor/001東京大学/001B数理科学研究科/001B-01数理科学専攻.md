## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 修士入试：由研究科自出英语笔试（科目「外国語」，见筆記試験），不另收外部英语成绩。
- 国外在住者特別選抜：不考英语；有英语或日语能力证明的可以随申请书一起交。

#### 日本語要件
- 修士入试：外国人出願者须上传一份由指导教员或相当于指导教员的人出具的日语学力证明书（样式自由）；日本的大学毕业者和 2027年3月预计毕业者免交。
- 试题用日文出题；希望者出願时申请，数学笔试可以用英文进行（外国人留学生入学手引）。
- 国外在住者特別選抜：入学时对日语能力要求不高，但参加セミナー和做研究需要日语。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 専門科目A | 线性代数、微分积分、复分析、常微分方程、集合·位相等基础内容 | |
| 専門科目B | 各专门领域的问题，十几题选3题 | |
| 外国語 | 数学相关英文的读解与英文写作 | |

- 按笔试、口述、出身学校学业成绩和提出书类（含アンケート）综合判定；先定笔试合格者，再对其口述；成绩不够时录取人数可少于募集人员。
- 出題の意図：専門科目A 看各分野共通的基础知识及运用能力；専門科目B 看修士研究所需的专门知识；外国語 看读数学英文文献和用英文写作的能力。
- 题目倾向（体验记，非官方）：2023年8月入试第1天考外国語（约80分钟，英译日2题、日译英1题）和専門科目A（180分钟，线代、微积分各1题必答，另5题选2），第2天考専門科目B（240分钟）；考生多押志望领域的题，再备一个相邻领域。

### 口述試験 / 面接
- **官方形式**：修士入试：只对笔试合格者进行，就専門科目做一般性提问，日程和分组在笔试合格发表时公布；国外在住者特別選抜：不设统一口述，必要时远程考试。
- **実際に聞かれた内容**：
  - 在黑板前回答教员提问，内容是学部基础课程和自己セミナー学过的内容（2023年8月入试，2人提到）。
