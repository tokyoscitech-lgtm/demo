## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各日程相同：不另设英语笔试，用 TOEFL iBT（含 Home Edition）成绩评价；所属团体实施的 ITP 不受理，MyBest Scores 不采用。
- 在有效期间内受检，并在同期间内向 ETS 申请把 Institutional (Official) Score Report 送到研究科（DI code 1113，其他代码无效）；出願时在 WEB 系统填写 Appointment Number、受检日和分数，不必交 Test Taker Score Report。送过多份的只指定其中一次。
- 有效期间：A日程 2024/8/1–2026/6/13；B日程 2025/2/1–2026/11/15（均已过）。

#### 日本語要件
- A日程：外国籍考生须在出願时上传日本语能力试验（JLPT）的「認定結果及び成績に関する証明書」（带得分区分）PDF，没有规定级别或分数。
- B日程：JLPT 成绩证明任意提交。
- 日本的大学毕业（含预计）者和本研究科外国人研究生两个日程都不用交。
- A日程専門科目日英并记出题。
- 变更点：2026/10/16 修订前的入试案内要求B日程也提交 JLPT 成绩，修订后改为任意。

| 科目 | 范围·题型 | 时间 |

| B日程：书类审查 | 看出身大学成绩证明书、TOEFL 成绩、入学后的研究计划书和参考资料（论文、报告、摘要等，有的才交）；不合格检定料不退 |  |

- 2026年度A日程每科2道大题（出题意图）：森林経理学为森林计测·计划用语＋抽样调查理论；造林学为用语说明＋森林生态系统功能与造林技术论述；森林政策学为林政学基本概念＋森林多面功能与政策手段；森林生物地球科学为微气象·水文用语＋能量和水汽输送的数式推导；森林利用学为林道、林业机械、作业系统的基础与应用；森林植物学为树木分类·生理·生态及病原菌·共生菌；森林動物学为动物生态学知识＋进化；森林風景計画学为景观基础知识＋风景规划课题论述。

### 口述試験 / 面接
- **官方形式**：A日程在笔试次日进行，围绕志望动机、毕业研究（含进行中的研究）、入学后的研究计划和提交书类问答；B日程只限书类审查合格者，先口头报告志望动机、毕业论文或相当研究、入学后的研究计划，再就论文和提交资料问答，并结合研究计划口头试问森林科学专门知识和农学生命科学基础知识。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：20名（A日程，2027年4月入学）；B日程若干名（2027年4月入学）；本専攻不实施10月入学。
- 出願资格：大学毕业（含2027/3/31前预计）或外国16年学校教育等；个别入学资格审查 A日程 2026/5/7、B日程 2026/10/7 截止（非独立出願，已过）；同一日程只能报研究科一个専攻；志望最多填到第3志望，可填同一分野的其他教员。
- 要提前准备的书类：第1志望教员签的受入承諾書（専攻样式）；A日程外国籍考生的 JLPT 成绩证明；B日程出願时交入学后的研究计划书（指定用纸），书类审查合格后 2027/1/21–1/26 提交毕业论文（或相当成果）、其日文或英文要旨和参考资料 PDF；日英以外的证明书附译文。
- 出願：只能通过 WEB 出願系统上传 PDF；检定料 30,000 日元（银行汇款〔邮储除外〕、便利店、信用卡、Pay-easy），日本政府奖学金留学生免缴。
- 并愿：同一日程只能报研究科的一个専攻。
