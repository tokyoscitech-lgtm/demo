## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各轮次相同：不另设英语笔试，用外部成绩换算「英語」得分，换算基准 TOEIC L&R 730＝满分、230＝0分；TOEFL iBT 2026/1/20 以前受检的 80＝满分、25＝0分，2026/1/21 以后受检的（1–6分制）4.5＝满分、2＝0分，中间按比例换算。
- TOEFL iBT：由 ETS 直送（DI Code 5132，本専攻 Department Code 76），并在出願书类チェックリスト上写 Appointment number 和直送手续日；Home Edition、MyBest、考生自己寄的成绩单不受理。
- TOEIC L&R：交 Official Score Certificate 原件或数字认定证打印件。
- 成绩须为出願截止日前2年以内受检，且必须在出願期间内送到；没送到、或成绩上的姓名等与志願者信息不一致、没有照片的，英语按0分处理。
- 变更点：2027年度Ⅰ·Ⅱ期起不再接受考试当天提交成绩。

#### 日本語要件
- 要项没有要求提交日语成绩。出願书类用日文或英文填写；外国大学的证明须为日文或英文，其他语言须附公的机关认证的译文。

- 按笔试、外部英语成绩、口头试问（100分）和书类选考综合判定；一般、社会人特别、外国人留学生（A方式）入试的科目相同。

- **官方形式**：各轮次都在笔试当天下午、生田キャンパス进行口头试问（100分），开始时刻随受験票通知，迟到不能受验。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：16名（学内選考、Ⅰ期、Ⅱ期等全部入试合计）。
- 出願资格：大学毕业（含2027年3月预计）或外国16年学校教育等；外国人留学生入试要求非日本国籍、初中等教育全部在外国修完，日本在住者须能取得「留学」等在留资格，海外出願者可申请受験许可证办理考试签证；需个别资格审查的人须先申请（Ⅰ期 2026/4/15、Ⅱ期 10/15 必达，非独立出願）。
- 要提前准备的书类：研究计划书（所定用纸A4 1页以内，写入学后的研究计划和将来去向）、外部英语成绩、外国籍者（本学理工学部·研究科出身者和特别永住者除外）须交出身大学指导教员等的推荐书1份（格式自由，日文或英文）和経費支弁計画書；中国的大学毕业者须办 CHSI 学历学位认证并由 CHSI 直送。
- 出願：只收邮寄（速達·簡易書留，国内邮戳有效；海外用 EMS 等，最后一天必达），不收窗口和网上出願；检定料 35,000 日元，Ⅱ期 2026/10/1–12/4 缴纳。
- 并愿：2027年度理工学研究科募集要项没有写跨专攻并愿和Ⅰ期合格者再报Ⅱ期的规定；外国人留学生B方式（不能与A方式并报）只在建築·都市学専攻国際建築都市デザイン系实施，不适用于本専攻。
- 咨询：明治大学理工学部事務室 大学院入試係（〒214-8571 神奈川県川崎市多摩区東三田1-1-1），Tel 044-934-7600，Fax 044-934-7901，sst@mics.meiji.ac.jp；检定料·学费问财務部財務課学費係，Tel 03-3296-4096。
