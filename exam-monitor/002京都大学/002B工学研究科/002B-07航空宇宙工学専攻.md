## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 8月入试（一般選考、特別選考相同）：
  - 不另设英语笔试，用 TOEFL iBT 成绩评价，配点 120 分，直接用 0–120 的得分；2026/1/21 以后受检的成绩也取 0–120 标度的素点。只用 Test Date Scores，送了多份的取最高分。
  - 只认 2024/8/2 以后受检的 TOEFL iBT；Home Edition、TOEFL ITP 不受理；要项不受理 TOEIC、IELTS。
  - 提交两步：①从 My TOEFL Home 下载 Test Taker Score Report 打印，2026/7/16（周四）17:00 前寄到 Cクラスター事務区教務掛（機械工学群）（7/14 以前日本邮戳的書留速達可受理）；②从 ETS 账户电子送分，Institution Code 填 B431（不用填 Department Code），2026/7/27（周一）前送达。官方不回答“成绩是否已到”。
  - 没交成绩的英语按 0 分。英语为母语者可事先咨询后交「英語を母国語とする旨の宣誓書」（様式4）申请免交；因受験资格限制难以参加 TOEFL 的，须事先联系教務掛。
- 2月入试（仅外国人留学生，2026年2月实施时的规定）：
  - 同样用 TOEFL iBT（Home Edition 除外）代替，须为考试日前2年以内受检，配点 120 分；Test Taker Score Report 打印件随専攻书类提交，没交为 0 分。
- 研究科共通部分提到的 TOEIC 公式认定证是别的入試区分的书类，不适用于本専攻。

#### 日本語要件
- 各轮次相同：共通要项和機械工学群入学試験詳細都没有要求提交日语成绩（JLPT、EJU 等），也没有要求日语能力证明书。
- 试题语言、可用的作答语言以及口头试问使用的语言，要项都没有写明。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 数学（180分，120分钟） | 出题范围和题数要项没有写明，可参考公开的过去问 | 2027機械工学群入学試験詳細 |
| 機械力学（150分，90分钟） | 工業力学、振動工学 | 2027機械工学群入学試験詳細 |
| 専門科目（400分，210分钟） | 流体力学、熱力学（含統計熱力学）、材料力学、制御工学 | 2027機械工学群入学試験詳細 |
| 2月入试（仅外国人留学生，2026年2月实施时）：専門科目（240分，120分钟） | 機械力学、流体力学、熱力学、材料力学 | 2026年2月実施 機械工学群入学試験詳細 |

- 8月入试一般選考总分 850（英语 120＋数学 180＋機械力学 150＋専門科目 400）。原则上总分 425 分以上为有資格者（会按难度调整基准分），从有資格者中按成绩从高到低定合格者；有人辞退时从有資格者中递补，递补通知最迟 2027/2/5（周五）。
- 8月入试特別選考（只面向前後期連携教育プログラム 高度工学コース志望者）免笔试，总分 850＝英语 120＋口头试问 730；予備選考没通过的可以改考一般選考。
- 2月入试（2026年2月实施时）总分 600＝英语 120＋専門科目 240＋口头试问 240，原则上 300 分以上为有資格者，按成绩从高到低定合格者。
- 三専攻同一套题、同一条合格线；合格后按「志望研究区分申告票」的志望顺序和成绩分配研究室，进哪个専攻取决于分到的研究室。
- 各科目的题数和必答/选答方式要项没有写明；考场不能用尺、圆规、词典、计算器。
- 题目倾向（体验记，非官方）：没有找到可核实的考生体验记。

### 口述試験 / 面接
- **官方形式**：8月入试一般選考没有口头试问和面试；8月入试特別選考先做约20分钟的予備選考面接（结果邮寄通知），通过者参加口头试问（730分），先发表研究计划，再就研究计划和专门知识提问，允许事先接受指导预定教员的发表指导；2月入试（仅外国人留学生，2026年2月实施时）口头试问 240 分，问专门学识、志望理由和研究计划；使用语言要项没有写明。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：8月入试機械工学群合计 113 名（機械理工学専攻 59 名、マイクロエンジニアリング専攻 30 名、航空宇宙工学専攻 24 名，含前後期連携教育プログラム若干名，按群统一招生、合格后再配属専攻）；2月入试（仅外国人留学生）未公布（2026年2月实施时为機械工学群若干名）。
- 出願资格：大学毕业或 2027/3 底前预计毕业、在外国完成16年学校教育、在外国取得相当于学士的学位（3年以上课程）等10项之一。外国大学出身者（资格3–6）须先把履歴書用邮件发给大学院掛确认资格，8月入试截止 2026/5/11（周一）17:00（已过）；资格9、10的审查书类截止 2026/5/18（周一）17:00 必达（已过）。
- 留学生的路线：日本的大学毕业（含预定）的留学生，機械工学群强烈建议考8月入试；其他留学生强烈建议考2月入试。两种情况都必须在出願前先向 Cクラスター事務区教務掛问清楚。
- 8月入试：
  - 志望研究区分申告票（様式1）：把機械工学群三専攻全部 26 个区分按第1–第26志望不重复地填满，有重复或空栏时由機械工学群决定顺位；願書上的志望区分栏不用填。
  - 留学生加交「志望する指導教員調書」（様式6，须有志望教员的确认印或签名，复印件可），期限与研究科书类相同（2026/6/10 17:00 必达）。
  - 特別選考加交（2026/5/18 17:00 必达，已过）：指导预定教员签发的「受入承諾書」（様式2）、最新学部成绩证明书、「希望研究コース·区分·分野等調査票」（様式3）、予備選考结果用回信信封。
- 2月入试（2026年2月实施时）：出願资格加一条“已与指导预定教员充分面谈并获得受入推薦書”；専攻书类为教育プログラム志望調書、TOEFL 成绩单复印件、有教员签名的「志望する指導教員調書」；志望区分在网上出願系统里按志望顺序选。
- 研究科共通书类：入学願書（网上登记后打印）、履歴書（规定样式，不能有空白期）、受験票和合格者番号一览寄送用信封、在留卡正反面复印件（外国人）；京大工学部以外出身者加成绩证明书和毕业（预定）证明书原件，外国大学出身者再加学位证明和推荐书。専攻书类寄 Cクラスター事務区教務掛，和願書寄送地址不同。
- 出願方式：先网上出願登记并缴费，再用書留速達邮寄书类（海外用 EMS 等可追踪邮件）或平日 9:00–17:00 投入桂キャンパス Bクラスター事務管理棟1楼专用箱；受理后不能改出願内容。
- 检定料 30,000 日元＋手续费 671 日元（便利店、信用卡、Pay-easy、网银）；国费留学生入学后退还。
- 不能同时报工学研究科的多个入試区分。
- 入学料 282,000 日元，授業料 年 535,800 日元（半期 267,900 日元），均为预定额；国费外国人留学生免缴。外国人留学生须在 2027/4/1 前取得“留学”在留资格。
- 教育プログラム：修士課程教育プログラム（2年），或前後期連携教育プログラム（5年；高度工学コース，或融合工学コース的応用力学、物質機能·変換科学、生命·医工融合、融合光·電子科学創成、デザイン学各分野）。
- 考场规则：桂キャンパス Cクラスター，开考 20 分钟前入室；迟到 30 分钟以上不能入场，原则上不能中途离场；手表只能有计时功能，手机关机放进包里。
- 咨询：入试内容问 Cクラスター事務区教務掛（機械工学群），Tel 075-383-3521，090kckyomu2@mail2.adm.kyoto-u.ac.jp；出願手续问工学研究科教務課大学院掛，Tel 075-383-2040／2041，090kdaigakuin-nyushi@mail2.adm.kyoto-u.ac.jp。
