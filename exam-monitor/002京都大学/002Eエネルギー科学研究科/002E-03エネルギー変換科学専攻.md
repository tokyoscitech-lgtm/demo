## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 第1回选拔（配点 100 分）、第2回选拔（配点 100 分）都不设英语笔试，用 TOEFL iBT 或 TOEIC L&R 的成绩换算成满分评价。换算公式和最低分官方没有公布。
- 有效成绩：2024/8/1 以后受检的成绩。
- TOEFL：只收 TOEFL iBT（含 Home Edition）；须同时提交 Test Taker Score Report（出願时随书类提交，网站下载的 PDF 打印件也可以）和 Official Score Report（由 ETS 直送，机构代码 9501、Department 代码 69）。直送的到达期限：第1回选拔 2026/7/17（周五），第2回选拔 2026/9/18（周五）。只采用 Test Date Scores，不采用 MyBest Scores。TOEFL ITP 等团体考试无效。
- TOEIC：只收在日本举行的 TOEIC L&R 公开考试；出願时提交从 TOEIC 报名网站下载的数字公式认定证（PDF 打印件），并在出願日之前在 TOEIC 报名网站上把本専攻登记为成绩提交对象（申请代码 00013703，团体名称「京都大学エネルギー科学研究科エネルギー変換科学専攻」）。TOEIC Bridge、S&W、团体考试（IP）无效。
- 没有提交 TOEFL 公式成绩单或 TOEIC 数字公式认定证的，英语按 0 分处理。IELTS 不在受理范围内。
- 外国人留学生特別選抜（冬季）：上次（2026年2月）是当天考英语笔试，不用外部成绩。

### 日本語要件
- 要项没有要求提交日语成绩（JLPT、EJU 等都没有提及）。
- 募集要项只有日文版，试题语言和作答语言要项没有写明。想用英语修读的人另有 IESC（国際エネルギー科学コース，10月入学，书类＋面试）这条路线。

- 所有科目都不能带计算器。
- 变更点（预告）：官方已预告 2028年度和 2029年度入试的第1回·第2回选拔专门科目数要变更，本年度（2027年度）不受影响。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：第1回选拔 18 名，第2回选拔 7 名（第1回选拔合格者不足时第2回可能增员）；社会人特別選抜若干名；外国人留学生特別選抜（冬季）上次为若干名，本年度未公布。
- 出願资格：大学毕业或 2027 年 3 月底前预计毕业；在外国完成 16 年学校教育；在外国取得相当于学士的学位（3 年以上课程）等 1–10 项之一。以资格 3–8（外国学历等）出願的人，须在 2026/5/29（周五）前就提交书类向研究科事务室咨询（已过）。
- 志望分野：入学願書的「志望分野」栏要把 H-1 到 H-7 共 7 个分野记号按第1到第7志望全部填满。第1志望不合格也可能以后面的志望合格；有没填的分野时，即使成绩靠前也可能不合格。
- 出願书类：入学願書（在 Web 出願系统登记后打印）和照片（JPEG 上传）、卒業（見込）証明書或学位授与（見込）証明書（上传并交原件，非日英文的附日文译文）、受験承諾書（其他大学院在学者或在职者，学部生不需要）、在留卡复印件（外国人留学生，上传；没有的先传护照照片页）、检定料收纳证明书、TOEFL 或 TOEIC 成绩。要项的书类清单里没有成绩证明书和研究计划书。
- 出願方式：京都大学 Web 出願系统登记＋缴纳检定料＋原件书类邮寄或窗口提交，三项都在出願期间内完成才算出願；只做网上登记不算完成。邮寄须用書留，封面朱书「エネルギー科学研究科修士課程出願書類」。
- 检定料 30,000 日元＋手续费 650 日元，通过京都大学 WEB 决济系统支付，不退还；国费留学生不需要缴。
- 一次只能报一个専攻。本年度已合格研究科内任一専攻的人不能报第2回选拔（只有辞退了社会·環境、基礎、応用専攻合格的人可以再报同一専攻）。
- 外国大学毕业（预定）者在联系希望的指导教员之前，必须先办京都大学 AAO（アドミッション支援室）的申请手续。外国人留学生的教育研究内容受安全保障出口管理的限制。
- 资格 9、10（个别出願资格审查）者须事先受审：书类截止 2026/5/25（周一）17:00 必达，审查 6/10，结果 6/19 邮寄通知（均已过）。
- 入学料 282,000 日元，授業料 年 535,800 日元（均为预定额）；国费留学生免缴。入学手续的详情在 2027 年 2 月底左右邮寄通知。
- 受験票在 Web 出願系统下载打印：第1回选拔 2026/7/21 起，第2回选拔 2026/9/15 起。遇暴风警报等可能改到预备日（第1回 8/17，第2回 9/28），当天 8:00 前在研究科主页告知。
- 合格发表后如有辞退，可能从有资格者（补欠）中递补，递补者在 2027/2/5（周五）前接到联系。
- 社会人特別選抜：各専攻若干名，面向入学后仍保留官公厅·企业身份的在职者，另交推荐书和实务实绩调书，与一般选拔同一日程。
- 咨询：エネルギー科学研究科教務掛（総合研究8号館1階），energykyoumu@mail2.adm.kyoto-u.ac.jp，Tel 075-753-9212。
