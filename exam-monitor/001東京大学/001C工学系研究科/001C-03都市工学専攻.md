## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 须提交 TOEFL iBT（含 Home Edition）成绩，以此代替英语笔试，配点 100 分。本専攻只收 TOEFL，不收 TOEIC、IELTS。
- 换算：得分＝(TOEFL 总分－45)×2，低于 0 记 0，上限 100。例如 TOEFL 80＝70 分，95 以上＝100 分，45 以下＝0 分。
- 采用 Test Date Scores，不采用 MyBest Scores；TOEFL ITP 等团体考试成绩不受理；母语是英语的人也要交。
- 有效成绩：受检日在 2024年9月–2026/7/14 之间。提交截止 2026/8/1（周六）（已截止）。
- 提交要完成三步：经 ETS 把官方成绩寄到研究科（DI 代码 8596，Department 代码 99）；在 WEB 出願系统的マイページ登记 Appointment Number 和受检日；上传 Test Taker Score Report 的 PDF。期限内可以反复更换登记的那一次成绩。
- 没有最低分数线的规定；没交成绩怎么处理，専攻入試案内没有写。

### 日本語要件
- 要项没有要求提交日语成绩。
- 笔试原则上用日语作答。认为难以用日语作答的人，可在出願截止前把自由格式的履历书发到専攻的考试邮箱申请用英语作答（都市工学専門与計画·設計·論文两科），是否批准由専攻判断，收到回信才算受理。过去问附有英文版。
- 入学后有日语和英语两种授课，只修英语授课也能凑够修了所需学分。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员 25 名（都市環境工学、都市計画两个専攻分野合计，不分别设名额）。面向社会人的都市持続再生学コース（東大まちづくり大学院，12 名）是另一份要项，不在此内。
- 出願资格：日本的大学毕业或 2027/3/31 前预计毕业、在外国完成 16 年学校教育、在外国取得相当于学士的学位（3 年以上课程）等 6 项之一。本専攻不限本科专业和取得学位的年份。
- 専攻分野在受験申告票上勾选，它决定都市工学専門的选科范围和計画·設計·論文考哪一种。修士的受験申告票没有指导教员一栏。
- 専攻独有的提交物：受験申告票［修士］（从専攻网站下载样式，写専攻分野、希望入学时期和研究计划，只能一页，不可跨页），出願时以 PDF 上传。
- 共通书类：入学願書（在 WEB 出願系统填写）、证件照数据、检定料缴纳证明、成绩证明书（东大工学部出身者免）、毕业证明书（已毕业者；预计毕业者不用交）、安全保障輸出管理チェックシート（外国籍、重国籍、或入学前所属机构在海外的人）、国费留学生证明（该当者）。日语和英语以外的文件要附日文或英文译文，非日英文的证明书还要有出身大学盖章的英译本。
- 出願只能通过 WEB 出願系统，所有书类转成 PDF 上传；合格后在入学手续时交成绩证明书等的纸质原件。
- 检定料 30,000 日元，可用便利店、Pay-easy、网银、中国决济或信用卡支付，手续费自付；国费留学生免缴。缴纳后不退。
- 受験票 2026/7/3（周五）15:00 左右经マイページ交付，自己打印带去考场。
- 可选 2027年4月入学或 2026年10月入学。希望10月入学的人要在受験申告票和入学願書两处都勾选，且内容一致。
- 不能同时报工学系研究科的两个以上専攻。提交后书类不能更改。
- 外国籍者入学手续前须有可以入学的在留资格；新办在留资格通常要 2–3 个月，要项建议这类人考虑 4 月入学。即使合格，按安全保障出口管理的审查结果也可能不能入学或研究受限。
- 个别入学资格审查（资格 6）的书类截止为 2026/4/21（周二）（已过）。
- 入学料 282,000 日元，授業料 年 535,800 日元（前期 267,900 日元），均为预定额；国费留学生不收。
- 考场规则：开考 20 分钟前进入指定考室；迟到 30 分钟以内可入场；手机等电子设备关机收进包里，不能当表用。
- 英语项目 UBE-UPN/ENV（没有日本国籍者的另一条路线，这不是修士一般入试的要求）：英语授课和指导，以书面审查和教员面谈选拔，不考上述笔试；不要求日语；须交英语标准化考试成绩或英语授课证明，没有最低分。2027年10月入学的日程：网上出願 2026/9/1–10/31 15:00，11 月下旬一次审查结果，通过者 12/18 前寄到原件，2027年1月前面谈，3 月出结果。
- 咨询：募集要项的问题用研究科网站的咨询表单（工学系研究科学務課大学院チーム，〒113-8656 東京都文京区本郷7-3-1）；専攻事務室 Tel 03-5841-6216；申请英语作答用 exam2027@ue.t.u-tokyo.ac.jp。合否不接受电话、邮件查询。
