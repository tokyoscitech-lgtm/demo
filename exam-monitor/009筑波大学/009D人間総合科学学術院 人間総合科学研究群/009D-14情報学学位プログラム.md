## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 8月实施和1-2月实施的一般入学試験、1-2月实施的英語受験者特別選抜：出願时提交外部英语成绩，配点 100 分。7月实施的推薦入学試験和两轮的社会人特別選抜不计英语、不用交成绩。
- 收的考试：TOEIC Listening & Reading（公式认定证）、TOEFL iBT（含 Home Edition；要项还写了 Paper Edition）、IELTS Academic。
- 不受理：TOEIC IP、TOEFL ITP、IELTS General Training、IELTS Academic 线上版（Online）、IELTS One Skill Retake。TOEFL 的 MyBest Scores 是否采用，要项和全学共通办法都没有写。
- 换算：在0分和100分之间线性插值。TOEIC L&R 465 分＝0分、830 分＝100分；TOEFL iBT 新计分 3.0＝0分、5.0＝100分（旧计分 60＝0分、100＝100分）；IELTS Academic 4.5＝0分、7.5＝100分。例如 TOEIC 648 分约合50分，IELTS 6.0 合50分，TOEFL 旧计分 80 合50分。
- 有效期：口述試験日之前2年以内受检的成绩。
- 提交方式：Web 入力时填写成绩信息，另外在书类必达日前交到——TOEIC 在系统里填 Digital Official Score Certificate 的 URL，并把该证书打印出来随书类寄送（在日本受检的必须这样做；只有在不发行数字证书的国家受检的人才交纸质原件）；TOEFL 交 Test Taker Score Report，2026年1月起没有纸质成绩单的人要让 ETS 直送成绩数据（机构代码 9995、部门代码 99），同时打印 PDF 版成绩单寄送；IELTS 要把 Additional TRF 的成绩数据送到 University of Tsukuba，同时交 Test Report Form 的复印件。交的原件不退还。
- 截止：8月实施 2026/7/23（周四）（已截止）；1-2月实施 2026/12/11（周五），都以到达为准。到期没到按书类不备处理，不备没有补齐就不受理出願、不能应试。
- 免除：毕业（含预计毕业）于美国教育部认可的大学的人，或毕业（含预计毕业）于以英语授课的大学并提交该大学出具的正式证明的人，免交成绩，英语按100分计。
- 口述試験里的英语：一般入学試験的口述有一部分用英语问答；英語受験者特別選抜全程英语。
- 变更点：TOEFL iBT 的换算同时列出新计分（1–6 段）和旧计分（0–120）两套标准；与上一年度要项的具体差异没有核对。

### 日本語要件
- 要项没有要求提交 JLPT、EJU 等日语成绩，也没有单设外国人留学生区分。
- 推薦入学試験、一般入学試験、社会人特別選抜的研究计划和口述試験都用日语（一般入学試験的口述有一部分是英语问答），留学生走这几条路线需要能用日语发表和答问。
- 英語受験者特別選抜（仅1-2月实施，2027年10月入学）的研究计划和口述試験都用英语，不需要日语。
- 研究计划书用的语言必须和口述試験用的语言一致，不一致按书类不备处理。

### 口述試験 / 面接
- **官方形式**：全部轮次原则上线上进行，2027年度预定用 Zoom 或 harutaka，不要求交线上受験的誓约书。7月实施的推薦入学試験每人约20分钟，先用日语发表约5分钟，再就相关领域的基础知识提问；8月实施和1-2月实施的一般入学試験每人约30分钟，先用日语发表约7分钟，再就相关领域的基础知识提问，其中一部分用英语问答；两轮的社会人特別選抜每人约30分钟，日语发表约7分钟后提问；1-2月实施的英語受験者特別選抜每人约30分钟，英语发表约7分钟后用英语问答。配点都是 300 分。
- 考试当天用的说明资料要事先上传：A4 10页以内的 PDF 一个。1-2月实施的上传期限预定到 2027/1/20（周三），线上预演预定在 2027/1/19（周二）；8月实施的上传期限是 2026/8/5（周三），预演是 8/18（周二）上午（均已结束）。
- 参考上一年度（2026年度入学）8月实施的受験者心得：用 Zoom 应用版，要用带摄像头的电脑，手机、平板和 Chromebook 不行；一个人在安静明亮的房间里应试，开始时用摄像头环视四周并出示受験票；不能用耳机、虚拟背景和多显示器；发表时可以共享画面，不能播放事先录好的内容；集合时刻按受験番号分到各试场，每30分钟一组；过了集合时刻10分钟还没连上又没联系的按缺考处理；因大学方面的故障没考完的另设再试验。本年度1-2月实施的规定以 2027/1/7 掲載的受験者心得为准。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：博士前期課程合计 75 名。7月实施的推薦入学試験 20 名；8月实施的一般入学試験 40 名、社会人特別選抜若干名；1-2月实施的一般入学試験 15 名、社会人特別選抜若干名、英語受験者特別選抜若干名（2027年10月入学）。
- 出願资格：日本的四年制大学毕业或入学前一个月底前预计毕业；由大学改革支援·学位授与機構授予学士学位；在外国完成16年学校教育；在外国3年以上的课程取得相当于学士的学位（要事先向入試課确认，最好赶在资格审查截止日前咨询）；经本大学院个别出願资格审查认定与大学毕业同等以上学力、且满22岁的人。
- 推薦入学試験的条件：符合上面第1或第2项资格，并且到出願时取得的学分里 A（優）大约占70%以上，或者在特定研究领域有突出表现并能拿出客观依据；要有校长、学部长等负责人的推荐，并保证合格后一定入学。符合推荐条件不等于保证合格。
- 社会人特別選抜的条件：符合出願资格（预计取得的人除外），到 2027/4/1 有3年以上的社会经验；联系教员时要说明报的是社会人特別選抜。
- 英語受験者特別選抜：要项没有另列资格条件，按一般的出願资格；只在1-2月实施，2027年10月入学，研究计划和口述都用英语。
- 志望指导教员：所有人都要在 Web 出願系统里填志望指导教员；可以填几位、有没有志望顺序，要项没有读到。
- 出願书类（邮寄）：毕业（预计）证明书、成绩证明书、外国大学毕业者或機構学位者的学位取得证明、检定料收纳证明（便利店支付）或信用卡支付确认画面的打印件；一般入学試験和英語受験者特別選抜要交英语成绩（免除者交授课语言为英语的正式证明）；推薦入学試験要交所定样式的推薦書（由出身大学的校长等密封），按研究业绩条件报推薦的人还要交业绩一览和依据材料；英語受験者特別選抜要交指导教员等签名或盖章的推薦書（不收电子签名，要写明职位）；在学者（2027年3月毕业预定者除外）和全职在职者要交受験·就学承认书（样式不限）；在其他大学就读的国费留学生交国费外国人留学生证明书。
- 研究计划书：直接在 Web 出願表单里填，日文约1,000字或英文约500词，不能插入图表。证件照是3个月以内的上半身正面照（JPEG，500KB 以内）。要项写明制作出願数据时不得使用生成式 AI。
- 出願方式：在 Web 出願系统注册邮箱 → 录入出願信息、上传照片 → 支付检定料 → 点「出願」。书类装进角形2号信封、贴上系统打印的收件人标签，用書留寄到図書館情報エリア支援室，截止日必达；不接受窗口递交，也不答复书类是否寄到的查询。建议用电脑操作，不建议用手机或平板。
- 检定料 30,000 日元，信用卡或便利店支付，缴纳后不退；国费外国人留学生不收。支付期间与 Web 入力期间相同（1-2月实施：2026/11/30–12/10）。
- 并愿限制：一个账号只能报一个学位プログラム，一个邮箱只能注册一个账号；出願期间结束后不能改志望的プログラム和入学时期。前一轮合格的人能否再报下一轮，要项没有读到。
- 所有出願者都要在系统里填写安全保障出口管理（みなし輸出）的确认事项。
- 个别出願资格审查和出願资格咨询的截止日：7月实施 2026/5/20（周三）（已过）；8月实施 2026/7/3（周五）（已过）；1-2月实施 2026/11/24（周二）。用邮件向図書館情報エリア支援室大学院教務申请，要交出願者調書、履历书·职历调书、毕业证明书、成绩证明书等；通过后拿到认定号码，出願时要交审查通过通知的原件。
- 入学料 282,000 日元。授業料每学期 267,900 日元（年额 535,800 日元）；外国人留学生每学期 304,400 日元（年额 608,800 日元）。入学手续的具体期限写在合格当天发出的邮件里，要项没有给日期。
- 长期履修制度：博士前期課程可以申请用3年或4年修完，授業料按年数分摊。
