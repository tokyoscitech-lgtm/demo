## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 7月入试：英语不单独考试，外部考试成绩是出願资格之一。需达到以下任一项：TOEIC L&R 550 以上；TOEFL iBT 57 以上（新评分方式为スコアバンド 3.5 以上）；IELTS Academic 5.5 以上。
- 有效期：出願开始日（2026/5/25）的2年前以后受检的成绩。
- 提交方式：TOEIC 交公式认定证（日本国内受检的交数字公式认定证 PDF 的打印件），申请代码 00019702；TOEFL iBT 由 ETS 直送（Institution code 2874）并提交 Test Taker Score Report；IELTS 由考试机构直送成绩数据并提交 Test Report Form。
- 不受理：TOEIC IP、TOEIC S&W、TOEIC Bridge；TOEFL iBT Home Edition、My Best scores、TOEFL ITP；IELTS Online、One Skill Retake、General Training。
- 提交的成绩不符合资格要求时出願无效。要项没有写英语成绩是否换算进总分。
- 飛び級入試的英语基准只有先進理工学研究科更高（TOEIC 640／TOEFL iBT 68 或スコアバンド 4.0／IELTS 6.0），不适用于本専攻。

### 日本語要件
- 要项没有要求提交 JLPT 等日语成绩。
- 选考（笔试和面接）原则上用日语进行；要项没有写可以用英语作答。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：本専攻 4月入学 55名（这个数字包含推薦入試等其他入试的名额），9月入学 若干名。飛び級入試一栏两次读取结果不一致（一次为若干名，两次为空栏/不实施），未核实。
- 出願资格：大学毕业或预计毕业、学位授与机构授予学士学位、在外国完成16年学校教育、外国大学3年以上课程毕业、文部科学大臣指定者、个别审查认定且入学前满22岁——以上之一，并且同时满足英语外部考试的基准。
- 只能报1个専攻；本専攻不设第2志望（志願票②只给物理学及応用物理学専攻第1志望、共同原子力専攻第2志望的人用）。笔试専門科目里必须有1题选第一志望研究指导所属的分野，所以出願时要确定志望的研究指导。
- 出願书类：志願票①（志望动机、研究计划等，自己作成，A4 单面1页）、志願票③（写真票，选择检定料支付方式）、毕业（预计）证明书、成绩证明书、英语外部考试成绩、チェックリスト；外国籍者另交护照复印件，在日本居住的交在留卡，在国外居住的交 COE 交付申请书、经费支付书和存款余额证明；中国大陆的大学毕业者另需学历·成绩的 Online Verification Report。
- 出願方式：网上申请表登记＋缴检定料＋书类邮寄，三项都要在期间内完成。书类寄到：〒169-8555 東京都新宿区大久保3-4-1 西早稲田キャンパス51号館1階 早稲田大学理工センター入試・広報オフィス；国内用簡易書留，海外用 DHL 等可追踪的方式。海外出願可以先寄书类再缴费、登记。
- 检定料 30,000 日元。日本国内在便利店支付，国外用信用卡。国籍或居住地属于 OECD/DAC 名单中最贫国·低收入国的人可以申请免除。
- 受験票在7月上旬用邮件发送，自己打印带到考场；遗失时带公的身份证到51号館1階的入試・広報オフィス补发。
- 外国人留学生的教育研究内容要接受安全保障出口管理的审查，可能受限制。国外居住的外国籍合格者完成入学手续后由大学代办 COE；签证自己申请，大学不做担保人。菲律宾、越南、印尼、尼泊尔、缅甸、中国籍者申请 COE 时需要结核非发病证明书。不能以短期滞在的资格在学。
- 需要考试或修学上照顾的人，出願前先联系研究科。
- 入学手续：9月入学为学费等缴纳和手续信息登记 2026/8/1–8/5，书类提交 8/1–9/4；4月入学为学费等缴纳 2026年10月前后–2027/2/18，手续信息登记 2027/2/1–2/18，书类提交 2/1–2/26。
- 入学金·学费：要项里没有写金额，金额在学费页的「2027年度入学者向け入学金・学費・諸会費」PDF 里（2026/9/18 更新），本次没有读到具体数字。

- 咨询：早稲田大学理工センター入試・広報オフィス（西早稲田キャンパス51号館1階），fsegraduate@list.waseda.jp，Tel 03-5286-3808。
