## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 不另设英语笔试，用外部成绩评价；TOEFL iBT（含 Home Edition）、TOEIC L&R、IELTS Academic（含 Computer Delivered）三选一，願書上只能勾选一种。
- 冬季：
  - 有效期：2025/1/1 以后到出願截止前受检。
  - TOEFL iBT：由 ETS 直送官方成绩（Institution Code 0440，Department Code 99），2027/1/5（周二）前到达；願書填 Appointment Number，以前寄过的也要重新申请。
  - TOEIC L&R：上传 Official Score Certificate（数字版或扫描 PDF）。IELTS：上传 Test Report Form 扫描件，或由 IELTS 机构直送（1/5 前到达）。来不及随出願提交的，事先联系学府，2027/1/5（周二）正午前用邮件提交。
- 不受理：TOEFL ITP、TOEFL Test Taker Score Report、TOEIC S&W／Speaking／Writing／Bridge／IP、IELTS General Training。

#### 日本語要件
- 外国人（日本的大学毕业或预计毕业者除外）须提交「日本語学力証明書」，原则上用コース入试案内所附样式，由日语教员等就说、听、写、读四项评价；用其他样式时须写明四项评价及评价方法。
- 出願书类原则上用日文或英文，其他语言须附译文；研究成果物用日文或英文。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 一次选考：书类选考 | 英语成绩＋研究计划书、自己推薦書、推薦書、研究成果物（毕业论文等学术论文必交）、成绩证明书、指導教員希望調査書 | |

- 一次选考合格者进入二次选考（口述），最终结果与一次选考合并综合判定。
- 没有刊登在论文志等处的业绩，须请推荐人在推薦書里写上客观评价。
- 作品集（任意）并入一个 PDF 上传；写了网址的视频·网页只作参考，要保持可访问到 2027年2月底，评价以 PDF 为准；合作作品要写明本人贡献。

### 口述試験 / 面接
- **官方形式**：冬季：只有一次选考合格者参加，用线上会议系统远程进行（需带摄像头、能联网的电脑），本人说明15分钟以内，之后就基础与专门学力、研究能力和研究计划综合提问；夏季：同样形式（已结束）。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：15名（夏季、冬季合计，夏季含社会人特別選抜枠；冬季不设特别选考枠），学際情報学専攻全体100名（含アジア情報社会コース13名），合格人数可能不足募集人员。
- 出願资格：大学毕业（含 2027/3/31 前预计）或外国16年学校教育等；资格(6)个别审查书类 2026/10/16 截止（已截止，非独立出願）；同一时期只能报学府一个コース，也不能同时报修士和博士。
- 要提前准备的书类：研究计划书（所定样式）；自己推薦書（所定样式）；推薦書（上司或毕业论文指导教员等撰写，本人取得受付番号后委托其直接上传）；研究成果物（毕业论文等学术论文必交，日文或英文，夏季案内以10页以上为目安，赶不上出願的按要项期限补交）；英语成绩；日本語学力証明書（外国人）。
- 出願：只能在指定网站填写和上传，12/4 12:00 前上传完成；检定料 30,000 日元（日本政府奖学金留学生免缴）。
