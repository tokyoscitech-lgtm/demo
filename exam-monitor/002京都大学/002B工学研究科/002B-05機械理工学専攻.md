## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 各轮次都不另设英语笔试，用 TOEFL iBT 成绩评价，配点 120 分，直接用 0–120 的得分（2026/1/21 以后受检的也用 0–120 原始分）；只用 Test Date Scores，送了多份的取最高分；Home Edition、TOEFL ITP 不受理。
- 提交两步：①从 My TOEFL Home 下载 Test Taker Score Report 打印，寄 Cクラスター教務掛（機械工学群）；②从 ETS 账户电子送分，Institution Code B431（不用填 Department Code）。官方不回答成绩是否送达。
- 8月入试：2024/8/2 以后受检；打印件 2026/7/16 17:00 必达，电子送分 7/27 前送达（已截止）。
- 2月入试：2025/2/9 以后受检；打印件随機械工学群书类 2027/1/26（周二）17:00 必达，电子送分 2027/2/4（周四）前送达。
- 没交成绩的英语按 0 分；英语母语者事先咨询后可申请免交；因受验资格所限难以参加 TOEFL 的须事先联系教務掛。

#### 日本語要件
- 要项没有要求提交日语成绩。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 8月入试：数学（180分） |  | 8/2 9:30–11:30，120分钟 |
| 8月入试：機械力学（150分） | 工業力学、振動工学 | 8/2 13:00–14:30，90分钟 |
| 8月入试：専門科目（400分） | 流体力学、熱力学（含統計熱力学）、材料力学、制御工学 | 8/3 9:00–12:30，210分钟 |
| 2月入试：専門科目（240分） | 機械力学、流体力学、熱力学、材料力学 | 2/9 9:00–11:00，120分钟 |

- 8月入试一般選考总分 850（英语 120＋数学 180＋機械力学 150＋専門科目 400），原则上 425 分以上为有資格者（按难度可能调整），按成绩从高到低定合格者；有人辞退时从有資格者中递补，最迟 2027/2/5 通知。
- 8月入试特別選考（只面向前後期連携教育プログラム高度工学コース志望者）免笔试，总分 850＝英语 120＋口头试问 730；予備選考没通过的可以改考一般選考。
- 2月入试总分 600＝英语 120＋専門科目 240＋口头试问 240，原则上 300 分以上为有資格者，按成绩从高到低定合格者。
- 三専攻同一套题、同一条合格线；8月入试合格后按「志望研究区分申告票」的志望顺序和成绩分配研究室，进哪个専攻取决于分到的研究室。考场不能用尺、圆规、词典、计算器。
- 题目倾向（体验记，非官方）：数学考微积分、线性代数、常微分方程、傅里叶分析、复变函数、矢量分析；2025年8月的考试被认为比此前13年都难，第一天的機械力学尤其难（1人提到）。

### 口述試験 / 面接
- **官方形式**：8月入试一般選考没有口头试问；8月入试特別選考先做约20分钟的予備選考面接，通过者参加口头试问（730分，先发表研究计划，再就研究计划和专门知识提问，可事先接受指导预定教员的发表指导）；2月入试有口头试问（240分，问专门学识、志望理由、研究计划等，可事先与指导预定教员商量研究计划）。
