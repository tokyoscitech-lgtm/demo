## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 第1期、第2期相同：不设学内英语考试，出願时提交外部英语考试成绩，配点100分。
- 可用的考试：TOEIC（L&R 公开考试、IP）、TOEFL（iBT、ITP）、IELTS（Academic）。
- 有效期：只承认 2024/4/1 以后受检的成绩（上一年度要项为 2023/4/1 以后，逐年顺延一年）。
- 换算：要项只给出一个基准点——TOEFL iBT 61＝TOEIC 600＝IELTS 5.0（各部分4.5以上）＝本校换算点65分；完整的换算表和最低分数线官方没有公布。持有多份成绩的要全部提交，取换算后最高的一份。
- 提交方式：TOEIC 交成绩证明原件；TOEFL 由实施机构直送大学（机构代码 0416），同时自己另交 Test Taker Score Report；IELTS 由考试机构把 Test Report Form 直送大学，同时自己另交成绩单复印件或在线成绩查询页面。
- TOEIC-IP 在线版因防作弊的可信度无法保证，必须同时提交实施团体出具的“受験状况证明书”（证明是在监考下受检），否则不被承认；纸笔（マークシート）版的 IP 没有这个附加要求。
- 没有提交英语成绩时如何处理，要项没有写明；但英语成绩证明列在必交的出願书类里。

### 日本語要件
- 要项没有要求提交 JLPT、EJU 等日语成绩，也没有设外国人留学生特别选拔，留学生和日本学生走同一个一般选拔。
- 要项、願書、志望理由书、面试都以日语为前提（サンプル問題也是日文出题）；面试使用的语言要项没有明文规定。
- 外国籍考生要另交在留卡正反面复印件（已在日本居住者）和护照照片页复印件。第2期要求出願时已持有日本的在留资格（短期滞在除外）。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 第1期：数学（基礎的数学）（100分，考试时长要项未记载、出願后通知） | 线性代数1题＋微积分1题，共2题。官方サンプル問題的构成：微积分大题含3小问（麦克劳林展开、二阶偏导数、用极坐标变换计算二重积分），线性代数大题含2小问（逆矩阵、行列式的性质、特征值与特征向量、矩阵的幂） | 2027募集要项／サンプル問題 |
| 第1期·第2期：统计検定成绩（100分，书面评价，不另行考试） | 提交统计検定2级的成绩，直接以2级的得分作为判定得分；持有准1级或1级「统计数理」合格的按100分计。CBT 方式交“試験結果レポート”原件，旧的纸笔方式交“試験結果証明書”（可由实施方直送大学），上位级交合格证原件或オープンバッジ | 2027募集要项 |
| 第2期：没有笔试 | 只用统计検定成绩（100分）＋英语资格成绩（100分）＋面试（200分） | 2027募集要项 |

- 总分构成：第1期＝数学100＋统计検定100＋英语100＋面试200，共500分；第2期＝统计検定100＋英语100＋面试200，共400分。根据各项成绩综合判定合否，合格最低分官方没有公布。
- 统计検定2级的成绩单列在必交的出願书类里，也就是说没有2级以上成绩实际上无法出願；但要项的“出願资格”条文本身（学历要件ア–ク）没有把它写成资格条件。统计検定成绩有没有受检日期限制，两次读取结果不一致，未核实。
- 可带物品（能否用计算器等）要项没有记载，随受験票的通知另行告知。
- 社会人特别选拔是另一条路线（面向有2年以上数据科学相关工作经验、入学后保留在职身份的人）：书类审查200分＋面试300分，不考数学，募集人员若干名，日程与一般选拔相同。
- 题目倾向（体验记，非官方）：没有找到本専攻的公开体验记（截至2026-10-06）。

### 口述試験 / 面接
- **官方形式**：第1期、第2期都有面试，配点200分（占第1期总分的40%、第2期总分的50%），在金沢八景キャンパス线下进行。要项只说明评价的方向——不分文理，综合判断考生获得高度数据科学能力的能力和意愿；面试时长、是个人面试还是集体面试、是否要发表研究计划、使用什么语言，要项都没有记载。面试在所定集合时刻未到者不能受验。
- **実際に聞かれた内容**：没有找到本専攻的公开体验记（截至2026-10-06）。按出願书类推测不了具体问题，只能确定志望理由书（志望本校和指导教员的理由、今后的研究抱负）是面试的书面基础。
