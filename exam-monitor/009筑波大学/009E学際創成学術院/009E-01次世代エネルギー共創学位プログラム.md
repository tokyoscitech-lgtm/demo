## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 10月实施和1-2月实施相同：英语配点 100 分，放在口述試験的 500 分里，根据提交的外部英语成绩和口述試験中的表现来评价。没有另外的英语笔试。
- 可用的考试：TOEIC L&R、TOEFL iBT（含 Home Edition）、IELTS Academic。不受理：TOEIC IP、TOEFL ITP、IELTS General、IELTS Academic 的线上版、IELTS One Skill Retake。
- 有效期：10月实施只认 2024年10月以后受检的成绩；1-2月实施只认 2025年1月以后受检的成绩。
- 提交方式（全学共通办法）：TOEIC 在 Web 出願系统里填デジタル公式認定証的 URL，并把认定证打印出来随书类提交（在日本受检的必须用这种方式；只有在不发行数字认定证的国家受检的人才交纸质公式認定証原件）。TOEFL 交 Test Taker Score Report 原件；纸质报告从2026年1月起废止，没有纸质的要让 ETS 把 Official Score Report 直送筑波大学（Institution 代码 9995，Department 代码 99），同时交打印的 PDF 版 Score Report。IELTS 要把 Additional TRF 的成绩数据直送筑波大学，并交 Test Report Form 的复印件。
- 直送的数据要在书类截止日前到达，处理可能要几周。没按期交齐、书类不备没有补正的，出願不算受理，不能参加考试。
- 免除：母语是英语的人，或已取得（预计取得）以英语为主要教学语言的课程学位的人，可能免交，要事先向 SIGMA 事務室确认。
- 要项没有规定最低分，也没有公布外部成绩换算成 100 分的方法；同时有多份成绩时怎么处理也没有写。

### 日本語要件
- 要项没有要求提交 JLPT、EJU 等日语成绩，也没有针对外国人留学生另设区分。
- 口述試験可以用日语或英语进行；研究计划书可以用日文（约2,000字）或英文（约1,000词）写。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 笔试（10月实施·1-2月实施） | 不实施。两轮都只有口述試験，没有外国語和専門科目的笔试 | 2027募集要项 |
| 口述試験·英语（100分；两轮相同） | 按提交的 TOEIC／TOEFL iBT／IELTS 成绩和口述試験中的表现评价；换算方法官方未公布 | 2027募集要项 |
| 口述試験·个别面接（400分；两轮相同） | 约10分钟的发表之后问答，问研究计划、基础学力、专业知识等；每人的总时长没有写 | 2027募集要项 |

- 两轮的总分都是 500 分：英语 100＋个别面接 400。根据口述試験和提交书类综合判定，要项没有公布合格最低分。
- 专业知识不通过笔试考查，基础学力和专业知识都在面接的问答里问，所以研究计划书和发表资料是准备的重点。
- 题目倾向（体验记，非官方）：本项目首届尚未实施首次考试，未取得可验证的本项目应试体验；其他筑波理工或能源项目的经历不直接套用。

### 口述試験 / 面接
- **官方形式**：10月实施在 2026/10/27（周二）、2026/10/28（周三），1-2月实施在 2027/1/29（周五），都是 9:00–17:00 之间，每人的具体时段另行通知。先做约10分钟的发表，再问答，内容是研究计划、基础学力、专业知识等；发表资料要存在自己的电脑里当天带来。用日语或英语。配点 500 分（英语 100＋个别面接 400）。试场在筑波大学筑波キャンパス；海外居住者可以线上受験，要在出願期间内提交「海外居住者対象のオンライン入試に係る申告書」。该专属申告PDF进一步要求：考试时仍住海外，最迟前1日完成Zoom连接测试并提供应急电话；面试前20分钟进候室，向工作人员展示独立房间、确认无他人；自行共享PowerPoint，且事前按另行指定截止将发表文件交SIGMA，考试日外观应与证件照可核对。
- **実際に聞かれた内容**：本年度是第一届入试，未取得可验证的本项目实际问答记录；首轮尚未举行，不制造往届口述题。

## 📝 详细信息
### 出願資格 / 定員
- 博士前期年度定员10名；募集人员（2027年4月入学）：10月实施（一般入学試験）7名；1-2月实施（一般入学試験）3名；年度博士前期定员10名（官方2026/8/31新闻及9月版leaflet）。2027年10月入学：10月实施不招，1-2月实施若干名。入学时期须在该轮实际募集的2027年4月和10月中选择，10月实施不能选2027年10月入学。
- 出願资格：日本的四年制大学毕业或入学前一个月底前预计毕业；由大学改革支援·学位授与機構授予学士学位；在外国完成16年学校教育；在外国3年以上的课程取得相当于学士的学位（出願前要先确认资格）；经本大学院个别审查认定与大学毕业同等以上学力、且满22岁的人（要先申请个别出願资格审查）。
- 个别出願资格审查的申请截止：10月实施 2026/9/10（周四）（已过）；1-2月实施 2026/11/24（周二）。用邮件向 SIGMA 事務室（g-sigma@un.tsukuba.ac.jp）申请。
- 志望指导教员：在 Web 出願系统里填写志望的指导教员，所有人必填；要事先和该教员商量并取得内諾。能选的教员以要项附件「参画予定教员一览」为准。
- 出願书类：毕业（预计）证明书（交取得学士的大学的证明；海外大学在线发行的，要附上能在官方网站确认真伪的页面复印件和 URL）、学位取得（预计）证明书（外国大学毕业者等）、成绩证明书（读过大学院的还要交大学院的）、外部英语成绩、研究计划书、检定料收纳证明（便利店支付者，贴在指定台纸上）或信用卡支付结果画面的复印件、适用在学者或常勤在职者的受験·就学承认书（样式不限；按要项可由本人不影响业务的申立、退职/退学预定说明等替代）、国费留学生证明书（在筑波大学以外就读的国费留学生）、线上入试申告书（希望线上受験的海外居住者）。证明书原则上不退还。
- 研究计划书：本プログラム要用指定样式（Word 文件，日文约2,000字或英文约1,000词）填写，和证明书一起邮寄（适用海外学历PDF邮件例外见下）；Web 出願表单里的研究计划栏本プログラム不用。指定Word又明确入学后研究计划须**1页以内，不得图表、不得改样式或超出框格**，※受験番号栏勿填；网页约日文2000字/英文1000词与指定样式页面限制应同时注意。
- 出願方式：在 Web 出願系统注册并录入出願信息 → 支付检定料 → 提交出願 → 打印受験票和收件人标签，把书类寄到或送到 SIGMA 事務室，截止日必达。受験票考试当天必须带。
- 海外大学毕业/预计毕业且邮寄困难者，可在Web系统勾选邮件提交，将成绩、毕业、学位（含预计）、英语成绩及缴费证明PDF邮件交g-sigma@un.tsukuba.ac.jp；本项目研究计划也可同时邮件交。成绩、毕业及学位三类原件仍必须在入学手续前邮寄或窗口核验，否则不能作为入学者。普通国内大学毕业者原则书留或窗口；海外居住原件难按期提交应提前咨询。
- 非日英文证明应由大学发行日/英文版本；大学不能发行时，提交原件与大使馆/公证机构等认证的译文。CHSI（日本）英文学历认证报告原本可按注记代用；自考本科的成绩/学位证明须实施机构原本，自考不接受预计毕业。不可自行把普通复印件当原件。
