## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般選抜（第1回·第2回）、特別選抜：不另设英语笔试，出願时交 TOEIC L&R 公式成绩证明书原件（原则上带照片）或数字公式认定证打印件，计 100 分；须为 2023/4/1 以后受检，金沢大学主办的 TOEIC IP 个人成绩表原件也可；不受理 TOEIC S&W、TOEIC Bridge、TOEIC IP Online 和网页成绩截图；原件考试当天归还。
- 外国人留学生特別選抜：不要求提交英语成绩。

#### 日本語要件
- 要项没有要求提交日语成绩（一般選抜、特別選抜、外国人留学生特別選抜都一样）。
- 英语以外的外文证明书须附日译或英译。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 口頭試問（専攻科目）（100分） | 出题范围按志望研究室分别设定，须直接问志望研究室 | 约10分钟 |
| 口述試験（研究プレゼンテーション）（100分） | 用 PowerPoint 发表至今的研究成果，发表5分钟＋质疑5分钟 | 约10分钟 |
| TOEIC（100分） | 出願时提交的成绩 |  |

- 各轮都不设笔试。一般選抜：上表三项合计 300 分综合判定。
- 特別選抜：口述試験 100＋GPA 100＋TOEIC 100，结合出願书类综合判定。
- 外国人留学生特別選抜：按口述试验和成绩证明书综合判定。

### 口述試験 / 面接
- **官方形式**：一般選抜第1回·第2回：同一天依次进行口頭試問（専攻科目，约10分钟）和研究发表（发表5分钟＋质疑5分钟），发表资料存 U 盘带去拷到考场电脑；特別選抜：口述試験 100分；外国人留学生特別選抜：口述试验，结合成绩证明书综合评价。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：17名（一般選抜，含特別選抜约4名）；外国人留学生特別選抜若干名。
- 出願资格：大学毕业（含 2027/3/31 前预计）或外国16年学校教育等，出身学部不限；以资格(8)（外国15年课程且成绩优秀）、(9)（个别审查，2027/3/31 前满22岁）报考的须先过出願资格审查（第2回·留学生：2026/11/10–11/13 17:00 必达，書留邮寄，已截止，非独立出願）；特別選抜要求 GPA 2.5 以上并确约入学（已结束）。
- 要提前准备的书类：志望研究室（様式1，可填第1–3志望，每个志望都须该指导教员亲笔签名，远方可附教员同意邮件复印件代替）、TOEIC 成绩原件（一般選抜）；在日外国人交在留卡正反面和护照姓名页复印件。
- 出願：只能 Web 出願（登记→缴费→上传照片→打印出願確認票和宛名ラベル），书类用角形2号信封書留速達寄或送窗口，期内必达；检定料 30,000 日元，另付手续费。
