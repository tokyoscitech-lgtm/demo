## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般入試、社会人入試、外国人留学生入試：不考英语，也不收英语成绩。
- SDGプロフェッショナルコース：须交 2024年11月以后受检、能测四技能的 TOEFL、TOEIC 或 IELTS 成绩（TOEFL 由 ETS 送分，DI Code G255），或最终学位全英文授课的证明；MEXT 奖学金推荐和本校 SDG 奖学金要求 CEFR B2 以上。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 外国人留学生入試的口述试验和面接可选日语或英语；SDGプロフェッショナルコース全英文授课，面接用英语。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 口述试验 | 機械工学的基础内容，不指定科目，口头试问 | |

- 按口述试验、面接结果和志望調書等提交书类综合判定；第1–3回和外国人留学生入試选拔方法相同。

### 口述試験 / 面接
- **官方形式**：一般入試·外国人留学生入試：口述试验（内容见上表，可能要求板书或书面补充说明）＋面接（评价人物与适性），同日进行；社会人入試：口述试验另问業績報告書，面接含专攻领域基础学力的试问；外国人留学生入試可选日语或英语，海外居住者经研究科判断可远程；SDGプロフェッショナルコース：书类审查＋英语面接（可线上），含专业领域口试。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：第1回94名（含学内推薦·学内学力，为大致标准）；第2回、第3回、社会人入試、外国人留学生入試、SDGプロフェッショナルコース各若干名。
- 出願资格：大学毕业（含预计）或外国16年学校教育等；资格③④⑥（外国学历等）须先向入試課照会、资格⑧–⑩须申请资格审查（第3回均 2026/12/4 截止，非独立出願）；外国人留学生入試须非日本国籍、持有或能取得可就读的在留资格，第3回只限已持有者；SDGプロフェッショナルコース限指定国籍，资格确认 2026/9/11 截止。
- 要提前准备的书类：志望調書（写志望讲座和「特に研究したいテーマ」）；外国籍者交载明在留资格的住民票（海外居住者交护照复印件）；SDGプロフェッショナルコース另需研究计划、系主任以上推荐信、健康证明和英语证明。
- 出願：一般入試·社会人入試只能用纸质要项所附願書（先资料请求），外国人留学生入試用网页版；簡易書留·速達邮寄或平日9:00–17:00持参，期间内必达，寄出后发邮件到 nyushigroup@jcom.nagaokaut.ac.jp；检定料30,000日元，金融机构窗口汇款（邮局、ATM不可），海外可电汇；SDGプロフェッショナルコース网上提交。
