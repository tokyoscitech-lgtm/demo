## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 不另设英语笔试，用外部成绩评价。
- 一般入试：
  - 交 TOEIC 或 TOEFL 成绩单原件一份：TOEIC L&R 公开考试（只收 Digital 公式認定証打印件）或 IP 均可，TOEIC Bridge 不可；TOEFL iBT（Home Edition 不可）和 ITP 均可。
  - TOEFL iBT 须由 ETS 直送大学（理学研究科 Institution Code G277）。
  - 须为出願截止前2年以内受验；只能交一份，交后不退还、不能更换；出願时来不及的可在笔试当天带来。
- 外国人留学生入试：
  - 只收 TOEFL iBT（考场受验）或 TOEIC L&R 公开考试；Home Edition、TOEFL ITP、TOEIC IP 不受理。须为第二次選考出願截止前2年以内受验，2026/12/2（周三）前必达入試課。
  - TOEFL iBT 交 Test Taker Score Report 和已向大学直送（Institution Code 0438）的画面或邮件打印件；TOEIC 在日本考的交 Digital 公式認定証打印件，在国外考的交 Official Score Certificate 原件和考场证明。
  - 变更点：从2027年度起外国人留学生入试不再受理 TOEFL ITP 和 TOEIC IP（2026/4/6 通知）。

#### 日本語要件
- 一般入试：要项没有要求提交日语成绩。
- 外国人留学生入试：
  - 第一次選考须交大学所定样式的「日本語能力認定書」，请日语教师、日本驻外使领馆人员或日语熟练者填写，不能用日语能力测试的证书代替。
  - 専門科目只用日语出题；面接用日语或英语。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：50名（専攻入学定员，含学内選考等2027年度全部入试）；外国人留学生入试若干名。
- 出願资格：大学毕业（含2027年3月预计）或外国16年学校教育等，资格⑹个别审查者须出願前咨询理学事務課；本専攻另实施大学3年级在籍者（或外国15年课程修完）的特别选拔，按另行发布的特別選抜出願要项办理；外国人留学生入试限外国籍、没在日本读过4年本科、入学时能取得「留学」在留资格者，15年学制等须在出願开始1个月前交齐资格审查材料（非独立出願）；在日本读完本科的留学生只能报一般入试。
- 要提前准备的书类：一般入试为志望理由書（所定用纸，800字左右）、外部英语成绩单、「指導教員の推薦書および受入教員との面談記録（物理学専攻用）」（请毕业研究指导教员写推荐、与希望的受入教员面谈后填写，交不出推荐的写明理由）；外国人留学生入试为日本語能力認定書、出身大学校长或指导教员的推荐信（所定用纸）、参考資料；国外居住者两条路线都要请希望指导教员填写「事前相談シート」。
- 出願：一般入试简易书留·速达邮寄或窗口提交（学科事務センター），邮戳有效（国外寄出须最后一天必达），检定料 35,000 日元（银行窗口电汇或便利店）；外国人留学生入试只能邮寄（国外用 EMS 等可追踪方式），两次都必达，检定料第一次 18,000 日元＋第二次 17,000 日元。
- 并愿：一般入试可以并愿笔试日不同的専攻；理学研究科各専攻笔试都在 2026/8/1，本専攻与同日笔试的専攻不能并愿；外国人留学生入试只能报1个専攻；出願后不能变更研究科·専攻。
- 咨询：理学事務課（〒162-8601 東京都新宿区神楽坂1-3，Tel 03-5228-8120，窗口 9:00–12:00、14:00–16:00，周末节假日除外；r1@admin.tus.ac.jp）；外国人留学生入试的出願手续问入試課（官网问询表单 https://faq.admissions.tus.ac.jp/hc/ja/requests/new）；需要考试特别照顾的，须在出願开始1个月前联系。
