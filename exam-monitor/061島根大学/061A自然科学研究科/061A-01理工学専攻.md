## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 不另设英语笔试，各轮次相同。
- 一般选拔·社会人：
  - 知能情報デザイン学、物理·応用物理学コース可交 TOEIC 公开测试、TOEIC-IP、TOEFL-PBT、TOEFL-iBT 之一的成绩证明复印件（TOEIC 可交数字公式认定证及 URL 打印件），2023/4/1 以后受检有效；也可用出身大学外国语教育中心等出具的成绩证明代替。
  - 成绩折算加进口頭試問：知能情報デザイン学最多10分，物理·応用物理学最多20分，口頭試問合计不超过60分；不交也可以出願。
  - 数理科学、機械·電気電子工学コース不评价英语成绩。
- 私費外国人留学生选拔：只有知能情報デザイン学コース收 TOEFL-PBT 或 TOEFL-iBT（2023/4/1 以后），用于口頭試問·面接评价，不交也可以出願。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 私費外国人留学生选拔：志望理由書（様式7）必须本人用日语亲笔书写；履历书、成绩证明、推荐书等用日语或英语；选拔时评价日语能力，数理科学コース的小論文考日语读解和表达。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 一般选拔：无笔试 | 按成绩证明书、口頭試問和面接综合审查 | |
| 私費留学生·数理科学：小論文 | 出願后研究科寄题，考日语读解与表达；与面接、成绩证明、推荐书、志望理由書一起评价 | |
| 私費留学生·物理·応用物理学：小論文 | 出願后寄来日语课题，提交后就小論文内容做网络面谈 | |

- 一般选拔配点（满分100）：数理科学 口頭試問·面接100；知能情報デザイン学 口頭試問60＋面接40；物理·応用物理学 口頭試問60＋面接40；機械·電気電子工学 口頭試問80＋面接20。
- 合否：总分达到基准点（6成）以上者从高分起合格，同分同序；物理·応用物理学另要求面接40分中得24分以上。
- 私費外国人留学生选拔：機械·電気電子工学、知能情報デザイン学按成绩证明、推荐书、志望理由書和口頭試問·面接选拔。

### 口述試験 / 面接
- **官方形式**：機械·電気電子工学：约15分钟，自带PC用投影仪做约5分钟口头发表（毕业论文或入学后的研究计划），之后质疑并可能问相关科目基础，面接看对志望研究室的意欲、适性和修了后展望；数理科学：约15分钟，问数学基础与专门知识、热情、思考力、适性；知能情報デザイン学：约15分钟，问专门分野基础与专门内容，可能要求研究发表；物理·応用物理学：约20分钟，自带PC做约5分钟发表后质疑，并可能问相关科目基础。
