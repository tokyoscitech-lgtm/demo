## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 不另设英语笔试，用外部成绩评价。
- 一般入试：
  - 只收 TOEIC L&R 公开考试或 L&R IP 的成绩单原件一张（公开考试只收打印的数字公式认定证），须为出願截止前2年以内受验，出願时提交，不退还；不收 TOEFL。
- 社会人特別選抜：
  - TOEIC L&R（公开或 IP，Bridge 不可）或 TOEFL iBT（Home Edition 不可）成绩单原件一张，须为出願截止前2年以内受验；TOEFL 也可交 My TOEFL Home 下载的 PDF 打印件，此时须向大学直送（工学研究科 Institution Code G386）。
- 外国人留学生入试：
  - 只收 TOEFL iBT（考场受验）或 TOEIC L&R 公开考试一张，须为第二次选考出願截止（2026/12/2）前2年以内受验，12/2 前必达入試課。
  - TOEFL iBT 交 Test Taker Score Report 和已向大学直送（Institution Code 0438）的画面或邮件打印件；TOEIC 在日本考的交带 QR 码的数字公式认定证打印件，在国外考的交 Official Score Certificate 原件和能看出考场的受验票等复印件。
  - 变更点：从2027年度起不再受理 TOEFL ITP 和 TOEIC IP。

#### 日本語要件
- 一般入试、推薦入学、社会人特別選抜：要项没有要求提交日语成绩。
- 外国人留学生入试：
  - 第一次选考须交大学所定样式的「日本語能力認定書」，请日语教师、日本驻外使领馆人员或日语熟练者填写，不能用日语能力考试的证书代替；入学願書须全部用日语填写。
  - 第二次选考的专门科目只用日语出题，面接只用日语。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 電磁気学 | 静电场、静磁场、静电容量、电感、电磁感应、电磁波 | 10:00–11:00，60分钟 |
| 電気回路 | 直流电路、交流电路、过渡现象、分布参数电路 | 11:30–12:30，60分钟 |
| 電子回路 | 模拟电路、数字电路 | 13:30–14:30，60分钟 |

- 一般入试：按出願书类、三科笔试、面接和 TOEIC 成绩综合判定。
- 外国人留学生入试：第二次选考考同样三科（日语出题），加外部英语成绩和面接判定；第一次选考只审书类。
- 社会人特別選抜：同样三科加面接；本校工学部毕业者可能免笔试。
- 推薦入学：只有书类审查和面接。

### 口述試験 / 面接
- **官方形式**：一般入试：笔试次日面接；推薦入学：书类审查＋面接；社会人特別選抜：笔试当天 15:30 起面接；外国人留学生入试：第二次选考面接，只用日语。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：70名（専攻入学定员，含学内选考等2027年度全部修士入试）；推薦入学、社会人特別選抜、外国人留学生入试各若干名。
- 出願资格：学士学位（含2027年3月预计）或外国16年学校教育等，资格(6)个别审查者须出願前咨询工学事務課；推薦入学须所属学部长或指导教员推荐、合格后确定入学；社会人特別選抜须入学时有1年以上企业等工作经历，资格エ须 2026/10/9 前交资格审查材料（非独立出願）；外国人留学生入试限外国籍、没在日本读过4年本科、入学时能取得「留学」在留资格者，15年学制等须在出願开始1个月前交齐资格审查材料（非独立出願）；在日本读完本科的留学生只能报一般入试。
- 要提前准备的书类：一般入试为志望理由書（所定用纸，800字左右）和 TOEIC 成绩单；推薦入学为推薦書（所定用纸）；社会人特別選抜为志望理由书（A4一页，1,000字左右，写工作内容与研究的关系）和外部英语成绩单；外国人留学生入试为日本語能力認定書、出身大学校长或指导教员的推荐信（所定用纸，3个月内，亲笔签名）、参考資料（所定样式⑦）；国外居住者都要请希望指导教员填写「事前相談シート」。
- 出願：一般入试、推薦入学、社会人特別選抜可简易书留·速达邮寄或到工学事務課窗口提交，邮戳有效（国外寄出须最后一天必达），须附レターパックライト2个，检定料 35,000 日元（银行窗口或日本国内便利店，不能用 ATM·网银）；外国人留学生入试只能邮寄到入試課（国外用 EMS 等可追踪方式），两次都必达，检定料第一次 18,000 日元＋第二次 17,000 日元（国外居住者用信用卡）。
- 并愿：一般入试可并愿笔试日不同的専攻，本専攻笔试 8/1，与同日考试的工学研究科其他専攻不能并报，并愿时面接时间由各専攻指示；出願后不能变更研究科·専攻；推薦入学须合格后确定入学；外国人留学生入试只能报1个専攻。
- 咨询：一般入试、推薦入学、社会人特別選抜为工学事務課（〒125-8585 東京都葛飾区新宿6-3-1，Tel 03-5876-1571，邮箱 k1_tus（at）admin.tus.ac.jp，出願期间窗口 9:00–12:00、14:00–16:00，周末节假日除外）；外国人留学生入试为入試課（Tel +81-3-3260-4271，[咨询表单](https://faq.admissions.tus.ac.jp/hc/ja/requests/new)）。
