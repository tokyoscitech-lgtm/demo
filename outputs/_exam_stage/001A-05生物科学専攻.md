## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 一般入试不在考场考英语，改为提交外部成绩。可用的只有三种：TOEFL iBT、TOEFL iBT Home Edition、在日本国内受检的 TOEIC L&R 公开考试。TOEFL 和 TOEIC 只能二选一，且只能登记一份成绩。
- 两个手续都要在 2026/7/23（周四）前完成（已截止）：一是让考试机构把成绩送到本専攻（TOEFL 的机构代码 B380，Department Code 任选；TOEIC 用「公開テストスコア確認サービス」，申请代码 00027402）；二是在 WEB 出願系统上传成绩文件（TOEFL 为 Test Taker Score Report，TOEIC 为デジタル公式認定証）。
- 有效期：受检日在 2024/10/1 以后的成绩。2026年1月起的新版 TOEFL 成绩单可以用。
- 不受理：日本国外受检的 TOEIC L&R、TOEFL 的 MyBest 成绩、TOEIC IP 等上面没列出的考试。官方认可 Home Edition，但强烈建议去考场考。
- 换算：TOEIC 成绩按専攻的换算表折成 TOEFL iBT 分数，三个基准点是 TOEIC 250＝TOEFL 18、650＝55、970＝100，中间线性插值，超出范围取端点值。例如 TOEIC 800 约等于 TOEFL 76。
- 官方没有公布最低分、英语的配点和合格者平均分；没交成绩会怎样处理，専攻页也没有写。

### 日本語要件
- 専攻页和 FAQ 都没有要求提交 JLPT 等日语成绩。
- 一般入试的専門科目用日语出题、用日语作答，口述试验也用日语进行。官方建议希望用英语应试的外国人改走外国人特別選考（英语面试）。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 専門科目（配点官方未公布，150分钟） | 共 5 大题，答 3 题。第1–4题（分子生物学·生物化学 2题、细胞生物学 1题、遗传学 1题）任选 2 题；第5题由 5 个小问（生物化学·生物信息、动物学、植物学、人类学、进化·自然史）任选 1 个。以限定行数的记述题为主，夹有读图表数据和少量计算·推导 | 2026年度过去问（题目构成以当年试卷为准） |
| 英語（配点官方未公布，无考场考试） | 提交 TOEFL iBT 或 TOEIC L&R 成绩，TOEIC 换算为 TOEFL 分数 | 専攻入试英语成绩提交说明 |
| 外国人特別選考：线上生物学笔答（约20分钟） | 分子生物学、生物化学、细胞生物学、遗传学的基础，在线上面试中进行，用英语 | 専攻大学院入试信息 |

- 出题范围：官方说明専門科目原则上可以用两本教科书的知识作答，即《Molecular Biology of the Cell》第7版和《Campbell Biology》第11版。
- 作答量：题目要求“3～5行”时，官方给的标准是每行 40～50 字。
- 合否判定：先按専門科目和英语成绩决定笔试合格者，再对笔试合格者进行口述试验。各科目的比重、合格标准、英语是否用于筛人，官方明确表示不回答。
- 2020年度（2019年8月实施）起専門科目的出题形式有过变更，用过去问时要注意年度。
- 题目倾向（体验记，非官方）：有考生认为部分题目与《理系総合のための生命科学》的专栏内容相近（仅1人提及，本人也说可信度有限）。

### 口述試験 / 面接
- **官方形式**：一般入试只有笔试合格者参加，用日语进行，内容是确认志望动机和对研究的适应性等；能否进入口述由専門科目和英语成绩决定，结果另行通知。配点、每人时长、2026年的具体日期官方页面都没有写。外国人特別選考是英语线上面试：先做约20分钟的生物学笔答，再用约10分钟的幻灯片介绍以往的研究和打算在志望研究室做的研究，之后就发表和笔答内容提问。
- **実際に聞かれた内容**：没有找到可以公开阅读的本専攻口述体验记（找到的一篇正文为付费内容），未获取到。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：2027年度以要项为准（要项 PDF 无法读取，未能核实），令和8年度为84名，令和4～8年度一直是84名。
- 出願资格的条文在研究科要项里，本次未能读取。専攻 FAQ 补充了两点：通过学位授与机构取得学位的人可以报考，但要先和第一志望教员联系；在日本的大学就读的外国人，自己对照一般入试和外国人特別選考两边的资格来判断，有疑问问研究科学務課。
- 志望研究室：本専攻内最多填 3 个。出願前要先和第一志望的教员商量，并明确告知是第一志望；第二、第三志望的教员也要告知。官方建议把第二、第三志望填上。
- 専攻独有的提交物是「志望調書」：下载専攻的 Word 模板填写，限 1 页，转成 1 页 PDF 后在出願期间上传到 WEB 出願系统。本専攻不要求研究计划书。
- 研究科共通书类（提出書類確認一覧表）：WEB 出願系统的入学願書、成绩证明书、检定料缴纳证明、専攻指定的其他书类。东京大学理学部应届毕业并报考与所属学科对应専攻的人可以不交成绩证明书；毕业过多所大学的人要交全部大学的成绩证明书。
- 海外大学的成绩单必须是正式版本（不收选课系统截图），附 GPA 的说明；不是英文或日文的，要由发行大学或正式翻译机构译成英文或日文。
- 出願方式：只能通过 WEB 出願系统，不收邮寄和窗口提交。
- 检定料：一般入试的金额未获取到（要项 PDF 无法读取）；外国人特別選考为 10,000 日元。在本校就读的日本政府（文部科学省）奖学金留学生不用缴检定料。
- 并愿：理学系研究科内不能同时报两个専攻。志望研究室同时属于其他研究科时，本専攻不禁止另外报考其他研究科。合格后可以辞退入学。
- 入学料 282,000 日元，授業料 半年 267,900 日元（年 535,800 日元），金额可能修订。
- 入学时期：一般入试为 2027年4月入学，专攻页没有提到一般入试的10月入学；外国人特別選考可选 2027年4月或10月入学。
- 外国人特別選考（另一条路线，面向在外国完成教育等符合资格的人）：提交 TOEFL iBT 和 GRE General Test 成绩（GRE 可用数学·物理·化学的 Subject Test 代替，写作分不计入），按书类分成直接合格、参加线上面试、不合格三种；出願前要早早联系志望教员。研究科对这条路线的 TOEFL 要求是出願开始日前 2 年以内的单次成绩，由 ETS 寄送（代码 8002-01）。
- 设有长期履修制度，对象是在职、育儿、护理或有障碍的人。已在本校当研究生的人想转为修士，同样要出願并参加考试。
- 咨询：出願手续、检定料、WEB 出願系统的问题找理学系研究科学務課大学院担当；専攻层的问题找生物科学専攻事务室（电话 03-5841-4080／4018，或専攻网站的咨询表单）。受理时间和邮箱未获取到。
- 成绩开示：专攻页和研究科页没有记载。
