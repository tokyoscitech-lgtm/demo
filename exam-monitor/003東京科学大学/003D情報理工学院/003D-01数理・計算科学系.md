## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般入试（A日程、B日程都要）：
  - 不另设英语笔试，用 TOEIC L&R 或 TOEFL iBT（含 Home Edition）成绩评价，B日程配点 20 分。
  - 本系要求出願时提交在线版成绩单打印件，交后不能更换；截止前没交的没有受験资格。
  - 只认 2024/6/11 以后受检的成绩。TOEIC 须为带真伪确认 QR 码的数字公式认定证 PDF 打印件；TOEFL 须为 Test Taker Score Report PDF 打印件，并在 ETS 账户为该成绩设定 DI code G179。ETS 邮寄的纸质成绩单、TOEFL ITP、TOEIC IP 等团体考试不受理。
  - 要项附録3的换算基准：TOEFL iBT 先按对照表换成 PBT，再用（PBT－296）÷0.348＝TOEIC L&R，例如 iBT 80→PBT 550→TOEIC 约 730（TOEIC 300 分以下不适用）。
  - 参考（体验记，非官方）：2025年8月1人 TOEIC 555 分开示英语 12/20，并转述约 750 分可得满分。
- IGP(C)：申请材料不要求英语成绩；面试和考试用英语进行。

#### 日本語要件
- 要项没有要求提交日语成绩，留学生和日本人按同样方式选拔（说明会 FAQ）。
- B日程笔试只出日文题，可以用日语或英语作答；口述試験和口頭試問原则用日语，也可以用英语应对（说明会 FAQ）。
- IGP(C) 全英语授课，不要求日语。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 筆答専門試験「数理・計算科学」（100分） | 数学、计算机科学的多道题中选答数题；2025年实施：基础3题（线性代数、微积分、算法）选2题＋专门9题（群论、一般拓扑、解析、线性规划、概率论、数理统计、形式语言与自动机、算法与计算量、计算机体系结构）选3题，共答5题，选题与志望研究无关 | 9:00–12:30，210分钟 |
| 英语（20分） | 用外部成绩评价，见英語要件 | |

- B日程：总分 120，按笔试、英语、口頭試問和出願书类综合判定，只有受験资格者参加口頭試問；各教员可接收的学生数有上限。
- A日程：系根据出願书类决定受験资格者（考生不能自选，2026/7/2 マイページ通知），凭学部成绩等出願书类和口述試験判定；A日程不合格的可接着考 B日程；出願资格(9)（飞级）只能考 B日程。
- 题目倾向（体验记，非官方）：每题20分，合格线传闻6–7成；基础题是大学一二年级水平，数理统计和自动机有本系特色，要靠过去问熟悉；自动机多证明题，算法以读伪代码为主。

### 口述試験 / 面接
- **官方形式**：A日程：口述試験对面进行，试问毕业研究、志望研究分野和入学后的研究题目以及专门知识，与学部成绩等书类综合判定；B日程：口頭試問对面进行，只对受験资格者，试问数学、计算机科学等的学力和研究能力；两者原则用日语、可以用英语；IGP(C)：系或志望导师安排的英语面试和/或考试，原则线上。
- **実際に聞かれた内容**：
  - 2025年8月 B日程（1人提到）：5人一组指定集合时间，每人10–20分钟，问志望理由、入学后的研究计划、毕业研究内容。
  - 2020年8月 B日程（线上，1人提到）：约20分钟、6位左右教员，问志望动机、本科做过什么、修了后读博还是就业、笔试的解法和错处、第2志望以后的研究室。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：数理・計算科学系受入可能予定人数 51 名（2026年9月和2027年4月入学合计）；IGP(C) 各系若干名。
- 出願资格：大学毕业（含 2027/3/31 前预计）或外国16年学校教育等，(9)–(11) 项须先审查出願资格；只能报一个系，结果出来前不能再报理工学系其他募集（含 IGP(C)）；外国籍选9月入学须出願时住在日本且在留资格有效到 2026/9/28；出願登记住址限日本国内；志望教员最多填10位，没填的不会被分配，出願后不能更改；IGP(C) 须先取得本系教员的指导同意。
- 要提前准备的书类：志望理由书（所定样式，写志望研究室、研究分野等志望理由，1,000字左右）；学部成绩证明尽量印有 GPA；TOEIC L&R 或 TOEFL iBT 成绩单（出願时必交）；IGP(C) 另需导师同意书、研究计划和推荐人直接提交的评价表兼推荐信。
- 出願：网上登记缴费后把书类以速達書留寄到入試課（6/10 必达，不收窗口提交），检定料 30,000 日元＋手续费 990 日元；IGP(C) 全程网上提交，检定料 30,000 日元。
- 并愿限制：理工学系只能报一个系；一个出願的结果出来之前不能再报理工学系的其他募集，同一入学期不能报理工学系修士的多个募集。
- 咨询：书类和出願资格问入試課大学院入試グループ（inquiries.grad.se@adm.isct.ac.jp，〒152-8550 東京都目黒区大岡山2-12-1）；考试内容问数理・計算科学系入試担当（is-exam-inquiry@comp.isct.ac.jp）。
