## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 一般選抜（第1期一般枠試験、第2期募集）：必须提交公的語学検定試験结果，自然科学専攻只收 TOEIC 或 TOEFL。可用的是 TOEIC L&R（含团体考 TOEIC-IP）的 Official Score Certificate 或 Score Report、TOEFL iBT 的 Test Taker Score Report、TOEFL ITP 的 Score Report。德语·法语·俄语·中文·朝鲜语检定只有人文社会科学専攻认，不适用于本専攻；要项没有列 IELTS。
- 有效期：考试实施日在 2024/4/1 以后的成绩。
- 提交期限：出願时一起交；出願时拿不到成绩的，先交「未提出理由書」（所定样式），再在期限前邮寄补交——第1期 2026/8/3（周一）必达（已截止），第2期 2027/2/1（周一）必达。
- 用法：要项只写用这份成绩评价英语交流能力、与书类和口頭試問一起综合判定；没有公布最低分、换算公式和配点。
- 第1期的学業成績優秀者特別枠試験：合格内定者不用交语言成绩；没有拿到内定而转考一般枠的人要在上面的期限前补交。第1期不合格再报第2期的，可以沿用第1期交过的成绩。
- 社会人特別選抜、外国人留学生特別選抜：不用交 TOEIC/TOEFL，英语（留学生为日语或英语）交流能力在口頭試問里确认。
- 沿革：2026年度（研究科第一届）的要项同样要求一般選抜提交 TOEIC 或 TOEFL，今年没有变化。

### 日本語要件
- 自然科学専攻没有要求提交日语成绩。「出願时须已通过 JLPT N1」只是人文社会科学専攻对外国人留学生特別選抜的要求，不适用于本専攻，本専攻无需提交。
- 外国人留学生特別選抜的口頭試問用日语或英语确认交流能力。志望理由書、研究計画書、出願资格审查调书、研究业绩书等样式都有日文版和英文版；英语以外的外文证明文件必须附日语译文。

| 一般選抜·第1期一般枠試験：无笔试（配点官方未公布） | 书类审查（志望理由書、研究計画書、履歴書、成绩证明书、TOEIC/TOEFL 成绩）＋口頭試問 | 2027募集要项 |
| 一般選抜·第2期募集：无笔试（配点官方未公布） | 与第1期一般枠試験相同；不设学業成績優秀者特別枠 | 2027募集要项 |

- 合否判定：按书类审查和口頭試問的结果综合判定；各项的配点、口頭試問的时长和合格线要项都没有公布，细节随受験案内通知。
- 本プログラム只有一个出題分野（MH），口頭試問里确认的专业知识范围取决于志望教员的研究领域，要项没有列出具体科目。
- 沿革：2026年度（研究科第一届）的要项也是同样的选拔方法——全研究科只有臨床心理学分野考笔试，其余都是书类＋口頭試問。
- 题目倾向（体验记，非官方）：没有找到本専攻的公开体验记（截至2026-10-06）。

### 口述試験 / 面接
- **官方形式**：一般選抜的一般枠試験和第2期募集，口頭試問以志望理由書和研究計画書为中心，并包含对所报出題分野专业知识的确认；学業成績優秀者特別枠試験是书类审查加口頭試問。社会人特別選抜围绕研究計画書，确认专业知识和英语交流能力。外国人留学生特別選抜围绕志望理由書和研究計画書，确认专业知识以及日语或英语的交流能力。实施方式（本プログラム）：一般選抜（特別枠、一般枠、第2期）为对面；社会人特別選抜为线上；外国人留学生特別選抜为「対面※」（原则对面，住在海外的可申请线上；这一项两次读取里有一次读成线上，未核实，以受験案内为准）。配点、时长、是否要做发表，要项都没有写。
- **実際に聞かれた内容**：没有找到本専攻（含改组前的自然科学研究科对应専攻）的公开体验记（截至2026-10-06）；研究科2026年4月才新设，新方式下只考过两届。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：情報社会デザイン科学プログラム的目安为 59 名（自然科学専攻合计 507 人）（各学位プログラム的人数是目安，不是硬性名额）。这是第1期和第2期合在一起的人数，要项没有给第1期·第2期各自的人数，也没有按选拔区分拆分；10月入学另行选拔，若干名。
- 出題分野只有一个：MH 情報社会デザイン科学分野。研究领域包括信息通信·信息学基础、数据科学·人工智能、医疗福祉设备开发、机器人·机电一体化、生物信息学、控制·系统工程。
- 出願资格（一般選抜、社会人特別選抜共通）：大学毕业或 2027年3月底前预计毕业；取得学士学位或预计取得；在外国完成16年学校教育（含在日本修读外国学校的函授课程、在日本的外国大学日本校）；外国大学修业年限3年以上并取得相当于学士的学位；专修学校4年以上的专门课程毕业；文部科学大臣指定者；已入其他大学院并被本研究科认可者；大学在学3年以上且成绩优秀（跳级）；经个别审查认定有大学毕业同等学力、2027/3/31 前满22岁。外国人留学生特別選抜另含「外国15年课程修了」等项。
- 社会人特別選抜另需 2027/4/1 时有2年以上在职经历。
- 学業成績優秀者特別枠試験（仅第1期）：成绩排名在所属学科等的上位二分之一以内，提交所属学科出具的证明书和入学確約書（合格即确定入学）；没有拿到内定的可以转考 8 月的一般枠試験。这个枠是否要交研究計画書，两次读取结果不一致，未核实。
- 个别出願资格审查（外国3年制学位、跳级、无学位的个别审查等）：第1期 2026/6/3（周三）必达（已截止），结果 6/12 通知；第2期 **2026/11/13（周五）必达**，结果 2026/12/7（周一）以速達通知。只收邮寄。跳级的标准是在学3年以上、修得100学分以上、其中五分之四以上为最高评价或80分以上。
- 出願书类：入学願書和履歴書（在 e-apply 上录入后打印）、毕业（预定）证明书、学业成绩证明书、志望理由書（所定样式）、研究計画書（所定样式）、TOEIC/TOEFL 成绩（仅一般選抜）、照片数据（上半身正面免冠、3个月内拍摄、纵4:横3、2MB 以内）、外国籍者的护照或在留卡复印件。特別枠另交证明书和入学確約書。要项没有规定志望理由書和研究計画書的字数或页数，按所定样式的栏填写，A4 单面打印。
- 出願方式：先在 e-apply 网上登录并缴费，再把书类用書留速達寄到「新潟大学大学院自然科学研究科学務係」（〒950-2181 新潟市西区五十嵐2の町8050番地），期限当天必达。书类不全可能不被受理，受理后只能改联系方式，书类不退。
- 检定料 30,000 日元，须在网上登录当天起4天内缴清；可用便利店、Pay-easy（ATM／网上银行）、信用卡、Flywire（海外汇款）。国费外国人留学生不用缴。缴费后原则上不退，只有期限内没交书类或被判定没有出願资格时可在5年内申请退还。
- 志望与并愿：一次报一个学位プログラム、一个出題分野。本プログラム属于「新潟学際型」学位プログラム，以它为第1志望的人可以把指导预定教员兼任研究指导的システム創成科学プログラム填为第2志望；第1志望合格就不再判定第2志望，考试只按第1志望进行，志望理由書和研究計画書只写第1志望的。
- 第1期不合格的人可以再报第2期（要重新出願、重新缴检定料）。
- 外国人留学生特別選抜的线上受験：标「対面※」的プログラム，住在海外、来校受験有困难的人可以申请线上口頭試問；须在出願时提交「Online Examination Request Form」（所定样式，要先取得志望教员同意），批准后不能再改。
- 考场：新潟大学五十嵐キャンパス（线上实施的除外）。集合时间、携带物、迟到处理要项没有写，都在受験案内里通知。
- 入学手续：第1期合格者 2027/3/8（周一）–3/15（周一）必达，第2期合格者 2027/3/16（周二）–3/18（周四）必达。
- 入学料 282,000 日元，授業料 年 535,800 日元（前期·后期各 267,900 日元）；这是大学学费页 2025/4/1 时点的现行额，要项本身没有写金额，在学中改定时按新额。有入学料·授業料免除和缓缴制度。
- 外国人留学生的教育研究内容受安全保障出口管理的限制；有障碍等需要考试照顾的人要在出願前先商量。
- 成绩开示：一般選抜、社会人特別選抜、外国人留学生特別選抜的受験者本人可以用「入試情報開示請求書」申请开示自己的成绩；2027年度入试的申请期间本次没有读到，未核实。
- 取得学位：修士（工学）或修士（学術）。
