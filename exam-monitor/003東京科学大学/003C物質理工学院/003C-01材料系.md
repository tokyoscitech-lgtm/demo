## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般入试（A日程、B日程都要）：
  - 不另设英语笔试，用 TOEIC L&R 或 TOEFL iBT（含 Home Edition）成绩评价，B日程配点 150 分。
  - 本系要求出願时必须提交在线版成绩单打印件，出願截止后一律不收，交后不能更换；截止前没交的没有受験资格。
  - 只认 2024/6/11 以后受检的成绩。TOEIC 须为带真伪确认 QR 码的数字公式认定证 PDF 打印件；TOEFL 须为 Test Taker Score Report PDF 打印件，并在 ETS 账户为该成绩设定 DI code G179。ETS 邮寄的纸质成绩单、TOEFL ITP、TOEIC IP 等团体考试不受理。
  - 要项附録3的换算基准：TOEFL iBT 先按对照表换成 PBT，再用（PBT－296）÷0.348＝TOEIC L&R，例如 iBT 80→PBT 550→TOEIC 约 730（TOEIC 300 分以下不适用）。
- IGP(C)：申请材料不要求英语成绩；面试和考试用英语进行。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 过去问为日文出题；IGP(C) 全英语授课，不要求日语。

- A日程：系根据出願书类决定受験资格者（考生不能自选，2026/7/2 マイページ通知），凭出願书类和口述試験决定“合格内定”；内定者不再考 B日程，没内定的可接着考 B日程；出願资格(9)（飞级）只能考 B日程。
- B日程：总分 550，先按筆答结果决定口頭試問受験资格者，再综合出願书类、筆答和口頭試問判定合否；每位教员的接收人数有上限。
- 变更点：2026年实施起改为上面的两ブロック编排并新设「材料力学」，它包含原「金属物理学」的内容，系建议参考 2021、2022年的过去问。
- 题目倾向（体验记，非官方）：2025年8月1人选了高分子科学、無機化学、無機固体、熱力学，称無機化学常出络合物和能带理论，熱力学以套公式为主、最容易。

### 口述試験 / 面接
- **官方形式**：A日程：口述試験对面进行，试问专门知识、学士论文研究内容、适性等，评价 A–E 五级；B日程：口頭試問线上进行，只有受験资格者参加，试问专门知识、学士论文研究内容、志望分野·适性等，评价 A–E 五级；IGP(C)：系或志望导师安排的英语面试和/或考试，原则线上。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：材料系受入可能予定人数 190 名（2026年9月和2027年4月入学合计）；IGP(C) 各系若干名。
- 出願资格：大学毕业（含 2027/3/31 前预计）或外国16年学校教育等，(9)–(11) 项须先审查出願资格；只能报一个系，结果出来前不能再报理工学系其他募集（含 IGP(C)）；外国籍选9月入学须出願时住在日本且在留资格有效到 2026/9/28；出願登记住址限日本国内；志望教员第5志望前必填；IGP(C) 须先取得本系教员的指导同意。
- 要提前准备的书类：志望理由书（所定样式 A4 1张：①进大学院的动机约200字；②想做的研究和志望教员的理由约400字；③是否并报其他大学及本系的志望顺位）；TOEIC L&R 或 TOEFL iBT 成绩单（出願时必交）；IGP(C) 另需导师同意书、研究计划和推荐人直接提交的评价表兼推荐信。
- 出願：网上登记缴费后把书类以速達書留寄到入試課（6/10 必达，不收窗口提交），检定料 30,000 日元＋手续费 990 日元；IGP(C) 全程网上提交，检定料 30,000 日元。
- 并愿限制：只能报一个系；结果出来前不能再报理工学系的其他募集，同一入学期不能报多个修士募集。本系考生可同时申请清華大学（中国）大学院合同项目。
- 咨询：系入试担当 mat.adm@mct.isct.ac.jp；出願手续问入試課大学院入試グループ inquiries.grad.se@adm.isct.ac.jp。
