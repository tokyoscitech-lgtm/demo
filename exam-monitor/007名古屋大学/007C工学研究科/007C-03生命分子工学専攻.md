## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 一般選抜：英语不设笔试，用 TOEFL iBT（含 Home Edition）或 TOEIC Listening & Reading 公开考试的成绩判定，成绩单贴在指定的提交用纸上随出願书类一起寄出。
- TOEIC：只收公式认定证原件（Official Score Certificate）。
- TOEFL：需要两样——由 ETS 直送大学的 Institutional／Official Score Report（Institution Code D377，Department Code 69），以及 Test Taker Score Report 的复印件。直送成绩要在出願期间最后一天（一般選抜为 2026/7/3）之前到达大学，寄送要 6–8 周。
- 有效期：只承认 2024/6/1 以后实施的考试成绩。不受理 TOEFL ITP 和 TOEIC IP（团体考试）。
- 没交成绩也可以出願和应考，但英语不予评价。
- 笔试免除者选拔：専攻说明资料要求出願时就提交 TOEIC／TOEFL 成绩（出願期早，要提前考）；没有获得免除而转入一般選抜的人，可以在 2026/7/29（周三）17:00 前向工学研究科重新提交成绩单（已截止）。
- 配点与换算：募集要项和専攻说明资料都没有写英语的配点和换算方法，也没有最低分。
- 外国人留学生入试：化学生命工学系3専攻同样用 TOEFL 或 TOEIC 成绩判定、不设英语笔试（2025年度留学生要项的规定；2027年度是否相同未核实）。

### 日本語要件
- 8月入试（笔试免除者选拔、一般選抜）：募集要项没有要求提交日语成绩，没有 JLPT／EJU 门槛。募集要项写明笔试和口頭試問都用日语进行，不提供英语出题。
- 外国人留学生入试：2025年度的留学生募集要项原则上要求提交日语教师等出具的「日本語能力証明書」，或 JLPT、JPT 的成绩（复印件可），本校工学部毕业预定者和本研究科研究生免交；2027年度是否仍要求未核实。

### 出願資格 / 定員
- 募集人员：生命分子工学専攻 28 名（化学生命工学系：有機・高分子化学 34 名、応用物質化学 34 名、生命分子工学 28 名；工学研究科合计 603 名）。这是笔试免除者选拔和一般選抜的合计，其中约 10 名（约三分之一）给笔试免除者。外国人留学生入试的募集人员为「若干名」。
