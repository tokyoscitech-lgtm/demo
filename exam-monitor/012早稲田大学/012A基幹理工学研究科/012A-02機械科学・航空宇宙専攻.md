## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 7月入试没有英语笔试，英语外部考试成绩是出願资格的一部分，不达标不能出願。官方没有公布英语成绩是否换算进总分。本専攻没有另外的英语要求。
- 一般入试的门槛（三选一）：TOEIC L&R 550 以上；TOEFL iBT 57 以上（新计分方式为 3.5 以上）；IELTS Academic 5.5 以上。飛び級入试在基幹理工学研究科的门槛相同。
- 成绩须为出願开始日（2026/5/25）前2年以内受检。
- 提交方式：TOEIC 国内受检者通过报名网站提交数字版公式认定证，国外受检者交原件；TOEFL 由 ETS 直送并附 Test Taker Score Report；IELTS 由考试机构直送并附 Test Report Form（可复印件）。
- 不受理的种类：TOEIC IP、TOEIC S&W、TOEIC Bridge；TOEFL iBT Home Edition、MyBest Scores、TOEFL ITP、PBT；IELTS Online、One Skill Retake、General Training。
- 直送用的机构代码未读取到，出願时须按要项原文操作。

### 日本語要件
- 要项没有要求提交 JLPT、EJU 等日语成绩。
- 笔试和面接原则上用日语进行；志願票须用日语在电脑上填写，各类证明书只收日文或英文。
- 用英语授课取得学位的 English-based Graduate Program 是另一套入试（另有英文要项），不在这份要项之内。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 共通科目：数学（1题，必答；配点官方未公布） | 微分积分、线性代数、复变函数、向量分析、微分方程，以及以这些为基础的应用数学 | 2027問題一覧 |
| 共通科目：力学（1题，必答；配点官方未公布） | 静力学、质点及质点系的力学、刚体的运动与力学、达朗贝尔原理、能量与变分原理、振动与稳定性 | 2027問題一覧 |
| 選択科目：熱力学（1题；配点官方未公布） | 热力学第一、第二定律，热力学循环，热力学函数与平衡系的能量守恒，传热基础 | 2027問題一覧 |
| 選択科目：流体力学（1题；配点官方未公布） | 静止流体的力学、势流、粘性流、可压缩流、流体机械与管内流动 | 2027問題一覧 |
| 選択科目：材料力学（1题；配点官方未公布） | 应力、应变、材料的力学性质、截面内力、拉伸、压缩、扭转、弯曲、组合应力、能量原理、屈曲 | 2027問題一覧 |
| 選択科目：制御工学（1题；配点官方未公布） | 控制理论、电路论、工学系统的动力学、建模、类比、稳定判别、补偿、状态方程等基础 | 2027問題一覧 |

- 専門科目试验共 180 分钟（10:00–13:00），一共作答4题：共通科目的数学、力学 2题必答，選択科目从熱力学、流体力学、材料力学、制御工学 4科里选2科各答1题。
- 選択科目作答超过2题时，全部答案无效。
- 可以用计算器，但带程序功能的计算器不能用。
- 配点、总分和合否判定方法官方都没有公布；要项只写按笔试和面接（含口述試験）选拔。
- 过去问：入学センター公开 2024–2027年度的専門科目 PDF，但都是扫描件，本次没能读出文字，所以这里没有归纳各题的小题形式。
- 题目倾向（体验记，非官方）：没有找到本専攻考生的体验记。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：7月入试（一般入试）4月入学 115 名；9月入学和飛び級入试（仅4月入学）的人数，本次读取要项的募集人员表时列对不上，没能确认（同研究科其他専攻为若干名）。115 名这个数字包含推薦入试等其他入试的名额。本年度没有冬季募集。
- 出願资格（一般入试）：大学毕业或入学前一日之前预计毕业、取得学士学位、在外国完成16年学校教育、在外国取得3年以上课程的学士相当学位、文部科学大臣指定者、经个别入学资格审查认定且入学前满22岁者，六项之一；同时必须持有达标的英语外部考试成绩。
- 飛び級入试：出願时为4年制大学3年级在学（休学除外），2年级结束时修得毕业所需学分的二分之一以上且其中三分之二以上为最高评价、3年级结束时预计修得四分之三以上，并取得出願専攻和指导教员的许可。飛び級合格入学者拿不到学士学位。
- 只能报1个専攻。出願时要填写研究指導代码（1个字母＋2位数字）；要项里没有针对本専攻的特别规定（填3个志望的要求只适用于情報理工・情報通信専攻，不适用于本専攻）。同一教员兼任多个研究指導的主担当时，实际指导教员可能是副担当，出願前要向教员确认。
- 出願书类：志願票①②③（所定样式，A4 单面，电脑填写，日语）、毕业（预定）证明书或在学证明书原件、成绩证明书原件、英语成绩、チェックリスト；外国籍者加交护照复印件，在日本居住者加交在留卡正反面复印件；需要申请在留资格认定证明书的国外居住者加交申请书、経費支弁書、存款余额证明原件；飛び級者加交学部要项复印件和受験许可书原件。要项的书类清单里没有单独的研究计划书，研究相关内容写在志願票里，没有规定字数。本専攻没有另外要求的书类。
- 中国大陆的大学毕业（预定）者不交学校开具的毕业证明，改为由 CSSD（学信网）把 Online Verification Report（英文）直接发送给大学。
- 出願方式：在线申请表登录＋检定料缴纳＋书类邮寄三步都要完成。书类国内用簡易書留，国外用 DHL 等，寄到「〒169-8555 東京都新宿区大久保3-4-1 西早稲田キャンパス51号館1階 早稲田大学理工センター入試・広報オフィス」。从国外出願可以先寄书类再缴费和登录。
- 检定料 30,000 日元，通过 e-shiharai.net 支付：日本国内居住者在便利店缴纳，国外居住者用信用卡。缴费时登记的邮箱必须和在线申请表的邮箱相同。最不发达国家等一部分国家的国籍者或居住者可以申请免除。
- 个别入学资格审查：须在出願书类提交开始日的1个月前联系理工センター入試・広報オフィス。
- 外国籍注意事项：国外居住者自行申请短期滞在签证来日应考，大学不做招聘人或保证人，拿不到签证缺考的不退检定料；入学手续完成后大学只代办「留学」的在留资格认定证明书。中国、越南、尼泊尔等六国国籍者申请在留资格认定证明书时要交結核非発病証明書。留学生的教育研究内容要接受安全保障出口管理审查，可能受限制（航空宇宙相关研究尤其要留意）。
- 入学金 300,000 日元（早稲田大学的在学・毕业・修了者免除）。基幹理工学研究科 2027年度入学者第1年度：春学期 授業料 495,500＋実験演習料 35,000＋学生健康増進互助会費 1,500，秋学期 授業料 495,500＋実験演習料 48,000＋互助会費 1,500；外校出身者第1年度合计 1,677,000 日元（含入学金），本校出身者 1,077,000 日元。实验演习料是否各専攻相同本次没有重新核对，以学费 PDF 为准。
