## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 按分野不同（一般入学試験和外国人留学生入学試験相同）：
  - 数学分野：学内英语笔试「外国語（英語）」，13:30–15:00，一般 100分、外国人留学生 50分。
  - 物理・応用物理学分野、機械工学分野：不另设英语笔试，交 TOEIC 或 TOEFL 成绩换算 100分。
  - 電気電子情報工学分野：不考英语，也不交英语成绩。
- 可用成绩：TOEIC L&R 公开考试（通过 TOEIC「公開テスト スコア確認サービス」提交）；TOEFL iBT（向 ETS 直送，DI Code G128，并交 Test Taker Score Report）。
- 只认各轮出願开始日前2年以内的成绩；TOEIC IP、TOEFL ITP 等团体考试、TOEFL iBT Home Edition 和 MyBest 成绩不受理。
- 社会人入学試験和特別選抜入学試験不考外语。

#### 日本語要件
- 要项没有要求提交日语成绩；外国人留学生入学試験的志望理由书、研究计划书可用日文或英文写。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 数学分野 専門科目（一般 250分；外国人留学生 250分） | 微积分、线性代数必答；集合与拓扑、解析、微分方程、群·环四领域中选2题 | 10:00–12:00，120分钟 |
| 数学分野 外国語（英語）（一般 100分；外国人留学生 50分） | 英语笔试 | 13:30–15:00，90分钟 |
| 物理・応用物理学分野 専門科目（一般 250分；外国人留学生 200分） | 力学、电磁学、数学（微积分·线性代数）各1题必答；量子力学、波动、物性物理、流体力学中选1题 | 10:00–12:00，120分钟 |
| 機械工学分野 専門科目（仅一般 250分） | 应用数学、热力学、流体力学、材料力学、机械力学5科，各科問1全答，再从問2中选2题 | 10:00–12:00，120分钟 |
| 電気電子情報工学分野 専門科目（仅一般 300分） | 电路、电磁学、数据结构与算法3科中选2科，每科2题 | 10:00–12:00，120分钟 |

- 一般入学試験（8月）各分野总分 450：数学、物理・応用物理学、機械工学为 専門 250＋英语 100＋口头试问 100；電気電子情報工学为 専門 300＋口头试问 150。
- 外国人留学生入学試験（10月·2月·秋学期7月）各分野总分 400：数学为 専門 250＋英语 50＋口头试问 100；物理・応用物理学为 専門 200＋英语 100＋口头试问 100；機械工学没有笔试，为 TOEIC/TOEFL 100＋口头试问 300；電気電子情報工学只有口头试问 400。
- 综合书类、笔试、口头试问按总分高低决定合格者，未达基准分的可能不合格；電気電子情報工学分野的留学生入试、社会人和特別選抜入试按口头试问得分决定。

### 口述試験 / 面接
- **官方形式**：一般入学試験：笔试当天笔试后口头试问（数学、物理、機械 100分，電気電子情報 150分）；外国人留学生入学試験 機械工学分野（300分）：从应用数学、热力学、流体力学、材料力学、机械力学中出願时选2科提问，再问此前研究和入学后的研究计划；外国人留学生入学試験 電気電子情報工学分野（400分）：从电路、电磁学、信息基础（数据结构与算法、C语言）中出願时选2科提问，再问志望研究领域；外国人留学生入学試験 数学、物理：口头试问 100分；特別選抜入学試験（2月，不招電気電子情報工学分野）：问出願书类、志望研究领域的基础科目，并做5–10分钟自我介绍发表；社会人入学試験：只有口头试问。
