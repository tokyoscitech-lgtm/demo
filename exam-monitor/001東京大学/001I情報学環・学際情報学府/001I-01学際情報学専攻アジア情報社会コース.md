## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 非英语母语者须提交 TOEFL iBT 或 IELTS Academic 的官方成绩；所有出願者另须提交 GRE General Test 成绩。其他种类的成绩不受理。不另设英语笔试。
- TOEFL iBT：由 ETS 直送，Institution Code D175、Department Code 99；考生本人手里的成绩单不收。须为2年以内受检，MyBest 成绩可以，新旧两种计分形式都收。出願表里填 Appointment Number，但填号码不能代替送分。
- IELTS Academic：通过 IELTS Results Service 电子直送 ITASIA，原件和 eTRF 本人提交都不收；有效期2年；出願表里填 TRF Number；One Skill Retake 的成绩不收。
- TOEFL iBT Home Edition、IELTS Online 等居家考试可以，前提是考试机构能把官方成绩直送 ITASIA（ITASIA FAQ）。
- GRE General Test：由 ETS 直送，Institution Code 3560、Department Code 0000，有效期5年，出願表里填 Registration Number。只有 ITASIA 在读生、M.A.S 毕业2年内报 ITASIA 博士的人可以免交，一般出願者没有免除。
- 英语母语者（英语为第一语言，或到高中为止主要以英语接受教育）免交英语成绩；不完全符合这一定义而申请免交的，须在出願表里说明理由。
- GRE、TOEFL、IELTS 都没有最低分数线，综合审查；GRE 平均分不公开。
- 所有官方成绩须在出願截止前到达；没有收到官方成绩的申请不予审查，没有例外。

#### 日本語要件
- 不要求日语能力，要项没有要求提交日语成绩。必修课全部用英语授课，论文用英语写。
- JLPT 成绩可以自愿附上扫描件（不需要认证），作为研究计划的补充；日语开设的选修课可以选，学分计入毕业要求。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 笔试 | 不实施 | ITASIA 募集要项（2027年10月入学） |
| 书类选考（配点官方未公布） | 网上出願表（含分段填写的 Research Proposal 等文字栏）、2份学术评价、学位证明与成绩单、英文写作样本（毕业论文、研究论文或未完成稿）、GRE、英语成绩，综合审查 | ITASIA 募集要项（2027年10月入学） |

- 选考只看书类，必要时会要求补充信息。
- 英文写作样本须由本人直接用英语写作，不接受由其他语言翻译的文章（包括本人翻译）；必须是可检索文字的 PDF，不能是扫描件。
- 出願表的文字栏每段最多3,000字符，Research Proposal 最多4段；表单60分钟超时、不能存草稿、没有确认画面，应先在本地写好再粘贴。

### 口述試験 / 面接
- **官方形式**：2027年10月入学募集：修士不实施面试，面试只在需要时针对博士出願者进行。
- **実際に聞かれた内容**：没有面试。体验记（非官方，2018年，仅1人）也说当年没有面试，准备的重点是出願表里的多段短文、研究计划和推荐信。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：2027年10月入学募集13名（修士，Master of Arts and Sciences，2年；学際情報学専攻全体100名中包含这13名）；本コース没有夏季、冬季募集。
- 出願资格：持有学士学位或同等学力（日本的大学毕业、在外国完成16年学校教育、在外国取得相当于学士的学位等）；2027/9/30 前预计毕业的可以报，须提交毕业预定证明。
- 个别出願资格审查：2027/9/30 时满22岁、不符合上述各项的人可以申请，须提交 CV、最终学校的成绩单和该校概要，结果预计2026年11月前后通知（截止日见日程表）。
- 须具备用英语听研究生课程、接受指导的能力。
- 出願书类：网上出願表（英文）；2份网上评价（评价人须有机构邮箱和机构网页，至少1位来自学府以外，评价可用英文或日文）；学士学位证明或毕业预定证明（盖章 PDF）；成绩单（盖章 PDF，GPA 和排名可选填）；TOEFL iBT 或 IELTS Academic（非母语者）；GRE；JLPT（任意）；英文写作样本；护照身份页扫描件；证件照（彩色 JPEG，6个月内，300dpi 以上，308×236 像素）；检定料缴纳证明。证书原件在入学后提交。
- 出願步骤：先提交基本表取得 Receipt Number 和 My Page 网址（不发确认邮件）→ 在 My Page 上传书类（每项1个文件）→ 登记2位评价人 → 提交详细表。评价也必须在截止前到达。不接受窗口提交。
- 检定料 10,000 日元，须在提交出願之前缴纳（2026/10/6 以后可缴）；可用信用卡网上支付，或银行汇款（交 C 联证明）。国费（MEXT）留学生免缴，改交奖学金证明扫描件；2027年3月取得东大修士学位后报读的也要缴。不退还。
- 入学料 282,000 日元，授業料 年 535,800 日元（要项记载额）；国费留学生免缴，东京大学另有少量按经济情况减免的名额。
- 奖学金：成绩特别优秀的出願者可能在合格通知时一并获得捐赠奖学金，须在指定日期前确认入学意向；大学推荐的 MEXT 奖学金不公开征集，在出願表里勾选即视为候选。
- 入学时期为2027年10月。外国籍者入学手续前须取得可以就读研究生院的在留资格；在职者须提交雇主同意全日制就读的信函。
- 需要考试上的照顾的，建议在 2026/10/16 前联系 Admissions Office，之后仍可相谈，但可能来不及安排。
- 咨询：ITASIA Admissions Office，itasiaao2027@iii.u-tokyo.ac.jp（只受理咨询，不收书类；官方要求先看 FAQ）。
