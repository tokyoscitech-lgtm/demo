## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 10月实施·一般入学試験：科目名「外国語」，配点 150 分，不设笔试，只按 TOEIC L&R 或 TOEFL iBT 的成绩评分。
- 换算：基准分是 TOEIC 879、TOEFL iBT 100，达到基准分记满分 150，低于基准分的按分数换算；要项没有给出换算公式。
- 提交：成绩单贴在大学指定的台纸（英語検定試験スコア票貼付用纸）上，交原件；TOEIC 的デジタル公式認定証可以交打印件。全学共通办法规定：在日本考 TOEIC 的人打印デジタル公式認定証并在 Web 出願系统里填它的 URL；TOEFL iBT 交 Test Taker Score Report 原件，没有纸质成绩单的人（2026年1月起纸质版已废止）请考试机构把 Official Score Report 直送大学，同时交 PDF 版的打印件。
- 不受理：TOEIC IP、TOEFL ITP 等团体考试成绩。TOEFL iBT Home Edition 按全学共通办法可以。全学共通办法里列有 IELTS Academic，但体育学的评分只写了 TOEIC 和 TOEFL iBT 两种，IELTS 在本プログラム不能用来算分。
- 成绩的有效期（几年以内）在要项和全学共通办法里都没有读到；没交成绩单时怎样处理也没有写。
- 10月实施·社会人特別選抜：不考外国語，不需要英语成绩。
- 7月实施·推薦入学試験（一般、社会人）：不考外国語，不需要英语成绩。

### 日本語要件
- 要项没有要求提交 JLPT、EJU 等日语成绩，也没有为外国人留学生另设选拔区分，留学生与日本学生参加同一场考试。
- 10月实施的専門科目规定用日语作答，过去问的题目也全部是日文。研究计划可以用日文（约2,000字）或英文（约800词）写，个人調書可以用日文或英文。口述試験使用的语言要项没有写。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 10月实施·一般入学試験：外国語（150分，无笔试） | 按 TOEIC L&R 或 TOEFL iBT 成绩评分；TOEIC 879／TOEFL iBT 100 以上记满分，以下换算 | 2027募集要项 |

| 10月实施·社会人特別選抜：専門科目（200分，90分钟） | 论述题，与一般入学試験同一时段（10:00–11:30）；出题方式和选题规则要项没有另外写明，试题也没有公开 | 2027募集要项 |

- 总分：10月实施·一般入学試験 400 分（外国語 150＋専門科目 200＋口述試験 50）；10月实施·社会人特別選抜 300 分（専門科目 200＋口述試験 100）；7月实施·推薦（一般）200 分（提出書類 100＋口述試験 100）；7月实施·推薦（社会人）200 分（提出書類 150＋口述試験 50）。根据提交的书类和学力检查的结果综合判定，合格最低分没有公布。
- 过去问的样子（令和8年度専門科目·一般）：共38题，编号 A-1～A-10、B-1～B-11、C-1～C-17，全部是「说明」「论述」型的小论述题；有的题限定要点个数（如举出3点、用5个要件说明），有的要求从给出的指标或动作里选一个来论述，或要求举具体例子。试题上没有标字数限制。
- 题目倾向（体验记，非官方）：没有找到本プログラム的考生体验记，暂无可写的内容。

### 出願資格 / 定員
- 募集人员（2027年4月入学，合计120名）：7月实施·推薦入学試験（一般）30名；7月实施·推薦入学試験（社会人特別選抜）5名；10月实施·一般入学試験 75名；10月实施·社会人特別選抜 10名。8月实施、1-2月实施和7月的自薦型推薦在体育学都不实施。
- 出願资格（各区分共通）：日本的四年制大学毕业或入学前一个月底前预计毕业；由大学改革支援·学位授与機構授予学士学位；在外国完成16年学校教育；在外国3年以上的课程取得相当于学士的学位（出願前要先向入試課确认资格）；经本大学院个别审查认定与大学毕业同等以上学力、且满22岁的人（要先申请个别出願资格审查）。
- 10月实施·社会人特別選抜：在上述资格的基础上，必须是已经毕业（已取得资格）的人，「预计毕业」的人不能报。要项对工作年数没有另设条件。
- 7月实施·推薦（一般）的要件：由在学（出身）大学的校长或所属长推荐，并确约合格后入学；并且满足其一：(a) 已取得学分中成绩 A（优）以上的科目学分占70%以上；(b) A 以上占40%以上，且有显著的竞技经历或指导经历。只计算学士课程期间取得的学分。
