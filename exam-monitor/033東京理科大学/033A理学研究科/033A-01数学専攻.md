## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 一般入试：用 TOEIC 或 TOEFL 的成绩评价英语能力。要项没有写最低分，也没有写换算方法和配点。
- 一般入试可用的成绩：TOEIC L&R 公開テスト和 IP テスト都可以，TOEIC Bridge 不可以；TOEFL iBT 和 TOEFL ITP 都可以，TOEFL iBT Home Edition 不可以。
- 一般入试的提交方式：出願时提交成绩单原件（TOEIC 公開テスト交デジタル公式認定証的打印件）；TOEFL iBT 也可以由 ETS 直接寄送，要项给出的 Institution Code 是 G277。成绩须是出願截止日前2年以内考的。出願时来不及的可以在考试当天带来。交过之后不能换成别的成绩。
- 外国人留学生入试：同样用 TOEIC 或 TOEFL 的成绩评价，但只受理 TOEFL iBT（会场受験，Home Edition 和 ITP 不可）和 TOEIC L&R 公開テスト（IP 不可）；成绩须是第二次選考出願截止日前2年以内考的。该要项给出的 Institution Code 是 0438，与一般入试要项的 G277 不同，两个代码哪个适用这次没能核实，寄送前请向理学事務課确认。
- 变更点：外国人留学生入试从2027年度起不再受理 TOEFL ITP 和 TOEIC IP（2026/4/6 通知）。

### 日本語要件
- 一般入试：要项没有要求提交日语成绩（JLPT、日本留学試験都没有提到），也没有写试题和作答可以用什么语言；出願书类（志望理由書等）用大学的日文所定用纸。
- 外国人留学生入试：修士課程的志愿者必须提交大学所定用纸的「日本語能力認定書」，请日语教师、日本驻外使领馆人员或日语熟练的人填写；不需要、也不能用 JLPT 的证书代替。要项没有规定 JLPT 等级或分数。
- 外国人留学生入试的専門科目「数学」用日语或英语出题，面接用日语或英语进行。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| 一般入试：専門基礎科目（配点官方未公布，90分钟） | 微分積分、線形代数、集合と位相；全部题目必答。题数要项没有写 | 2027修士一般入试募集要项 |
| 一般入试：専門科目（配点官方未公布，90分钟） | 分三个系出题——代数系：群、環、体、加群、ガロア理論；幾何系：曲線·曲面論、微分幾何、位相幾何；解析系（含確率解析）：無限級数、関数論、微分方程式、関数解析。从希望的指導教員所属的那个系的题目里选2题作答 | 2027修士一般入试募集要项 |
| 外国人留学生入试第二次選考：専門科目「数学」（配点、时长官方未公布） | 用日语或英语出题；出题范围要项没有细写 | 2027外国人留学生入试募集要项 |

- 一般入试由笔试两科、TOEIC/TOEFL 成绩、口頭試問和面接构成。要项没有公布各项的配点、总分和合否判定方法。
- 专门科目按希望指導教員的系来选题，所以出願前定下指導教員，实际上也就定了专门科目的备考范围。
- 题目倾向（体验记，非官方）：没有找到本専攻的受験体验记，无法归纳。

### 口述試験 / 面接
- **官方形式**：一般入试在笔试当天公布口頭試問及び面接的对象者，同一天 15:00 起进行。口頭試問的范围是笔试出题范围的全部，加上志望研究室的研究领域。配点和每人时长要项没有写。外国人留学生入试第二次選考有面接，用日语或英语进行。
- **実際に聞かれた内容**：没有找到本専攻的体验记（日文和中文来源都查过），暂无可归纳的内容。

## 📝 详细信息
### 出願資格 / 定員
- 一般入试的要项写的数学専攻入学定員为25名（神楽坂キャンパス），这是専攻的入学定員，其中包含学内選考的名额，一般入试单独招多少人没有公布。外国人留学生入试的募集人员为若干名。大学的TUSデータ集（2021–2025年度）里本専攻的入学定員是15名，与要项的25名不一致，以本年度要项为准。
- 一般入试的出願资格：大学毕业或2027年3月前预计毕业（取得学士学位）、在外国完成16年学校教育、修完4年以上的専修学校専門課程、文部科学大臣指定者、大学3年级在籍且成绩优秀者（本専攻适用）、经个别审查认定有同等以上学力且2027/3/31前满22岁者，符合其中一项即可。
- 外国人留学生入试的出願资格须同时满足四条：外国籍；在外国完成16年课程，或满22岁并有研究经历等；没有在日本受过4年的大学本科教育；入学时能取得「留学」在留资格。
- 一般入试的出願书类：入学願書（所定用纸，贴3个月内拍的 4cm×3cm 彩色照片）、成绩证明书原件、毕业（预定）证明书原件（都要3个月内开具的）、履历书（所定用纸）、志望理由書（所定用纸，800字左右）、TOEIC/TOEFL 成绩单、寄受験票用的明信片1张（贴速达邮资385日元）；住在日本国外的人另交「国外居住者用事前相談シート」。
- 外国人留学生入试的出願书类：入学願書、日本語能力認定書、最终学校的毕业证明书、成绩证明书、推荐信、护照复印件、参考资料、選択科目届、检定料缴纳票、チェックシート；住在国外的另交事前相談シート。
- 出願方式：邮寄到理学事務課，要项里没有网上出願。一般入试邮戳有效（国外寄出须最后一天必达），外国人留学生入试两次選考都要求必达。
- 检定料：一般入试 35,000 日元，通过银行窗口（電信扱）或便利店（セブン-イレブン、ローソン、ファミリーマート、ミニストップ）缴纳，缴后不退。外国人留学生入试分两次缴：第一次選考 18,000 日元，第二次選考 17,000 日元（银行窗口 2026/11/30–12/2，便利店 2026/11/25–12/2）。
- 并愿：笔试日期不同的専攻之间可以并愿。
- 学费（2027年度入学，修士）：入学金 200,000 日元，授業料 年 880,000 日元，教育充実費 年 200,000 日元，学生傷害共済補償費 2,740 日元，第一年合计 1,282,740 日元，第二年 1,082,740 日元。东京理科大学本科毕业生入学金和教育充実費减半。
- 考场规则：笔试开始后（面接是集合时间后）30分钟内没有进入指定会场的，不能参加该场考试。具体会场在考试前一天公布。可带物品要项前21页没有写到。
- 咨询窗口：理学事務課，〒162-8601 東京都新宿区神楽坂1-3，Tel 03-5228-8120，窗口时间 9:00–12:00、14:00–16:00（周六日和节假日除外）。
- 成绩开示：要项已读到的部分没有记载。
