## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 须提交 TOEFL iBT 成绩（Home Edition 也可以），研究科自己不出英语题；A日程、B日程①、B日程②都一样。
- 送分方式：向 ETS 申请把 Institutional (Official) Score Report 直接送到研究科，机构代码（DI）1113，用别的代码送的无效。本人手里的 Test Taker Score Report 不用交。
- 有效的受检期间：A日程 2024/8/1–2026/6/13（已过）；B日程 2025/2/1–2026/11/15。受检和向 ETS 申请送分都必须在这个期间内完成。
- 不受理 TOEFL ITP 和 MyBest Scores，其他英语考试也不受理。
- 送过多次成绩的，在 Web 出願系统里只指定一次的成绩，填写 Appointment Number、受检日和分数。
- 要项和専攻案内都没有写最低分数线、配点和换算方法。
- B日程②综合型选考：在美国、英国、爱尔兰、加拿大、澳大利亚、新西兰的大学或研究机构取得（或预计取得）学士学位的人可以免交。B日程①没有免除规定。

### 日本語要件
- 要项没有要求提交日语成绩。
- A日程笔试用日文出题，可用日文或英文作答；B日程①笔试用英文出题，可用英文或日文作答。B日程②口述使用的语言，専攻案内没有写。
- 日文、英文以外的证明书须附日译或英译。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：応用生命工学専攻 43 名（要项表中另有“若干名”一栏，对应 B日程等；応用生命化学専攻为 34 名）。専攻 Q&A 称两个専攻合计每年约 100 人入学，其中 3–4 成来自其他大学。
- 出願资格：大学毕业或 2027/3/31 前预计毕业；在外国完成 16 年学校教育；在外国大学取得相当于学士的学位；经个别入学资格审查认定并在 2027/3/31 时满 22 岁等 6 项之一。
- 志望教员的填写：按「教员及专门分野一览」填专门分野和教员姓名。A日程填第1、第2志望，两者须属于不同的专门分野；2027年4月入学者的第2志望可以选応用生命化学専攻的教员，2026年10月入学者的第1、第2志望必须在同一専攻。B日程（①②）只能填第1志望。
- 専攻独有的提交物：志望指導教員による志望確認書。用研究科指定样式，请志望教员签名后把 PDF 上传到 Web 出願系统。A日程要第1、第2志望两位教员的（没有第2志望就只交第1志望的），B日程只要第1志望的。
- B日程②综合型选考另须提交：记有 GPA 的成绩证明书（开不出来的事先问専攻）；推荐信 1 封（格式不限，日文或英文，推荐人不能是志望指导教员；在 Web 系统“その他”栏填推荐人姓名和邮箱，系统向该邮箱发上传链接）；自己アピール（英文约 800 词或日文约 2000 字的 PDF，写获奖、奖学金、研究活动、论文、学会发表等）。
- 共通出願书类：入学願書（Web 填写，3 个月内的照片）、成绩证明书、毕业（预定）证明书、检定料缴纳证明、国费留学生证明书（符合者）、TOEFL 成绩。出願时上传的证明书，入学手续时要交纸质原件。
- 出願方式：只能通过 Web 出願系统（https://webentry.ofc.a.u-tokyo.ac.jp/）。受験票自己用 A4 纸打印。
- 检定料 30,000 日元。缴纳期间：A日程 2026/4/13–6/23（已过），B日程 2026/10/5–11/25。可用银行汇款（ゆうちょ銀行·郵便局不行）、便利店、信用卡、Pay-easy。国费留学生免缴；缴后不退。
- 并愿限制：同一日程内不能报研究科的两个以上専攻。A日程已合格応用生命化学専攻或応用生命工学専攻的人，B日程两个専攻都不能报。
- 入学时期：A日程可选 2026年10月入学（限 2026年9月前毕业或预计毕业者）或 2027年4月入学；B日程为 2027年4月入学或 2027年10月入学。在 Web 系统里选定后不能改。
- 个别入学资格审查与受験上的配虑申请截止：A日程 2026/5/7（已过），B日程 2026/10/7（已过）。
- 外国人须注意在留资格和入境时间；涉及安全保障出口管理规定的，即使合格也可能不能入学或研究活动受限。在职者入学须交雇主的同意书。
- 入学料 282,000 日元，授業料 年 535,800 日元（前期 267,900 日元），均为预定额；国费留学生免缴。
- 受験者心得的发送：B日程①在 2027年1月上旬邮件发送，1/13 前没收到要联系研究科。可带物品、迟到等考场规则写在受験者心得里，要项和専攻案内没有写。
- 成绩开示：只收邮寄申请，A日程为考后 10/1–10/31 必达，B日程为考后 5/1–5/31 必达。
