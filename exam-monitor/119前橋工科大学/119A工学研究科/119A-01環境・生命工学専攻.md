## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 各选拔区分（進学者·一般·社会人·外国人留学生）、7月日程和2月日程都用英语外部检定成绩，出願时提交，计入总分。
- 可交其一：TOEIC（L&R 与 S&W 合算，L&R 占80%、S&W 占20%）或 TOEFL iBT。只交 TOEIC S&W 不行；本校实施的 TOEIC-IP 成绩单也认可。
- TOEFL iBT 只认 ETS 直接寄给大学的公式成绩单（DI code D073，Department code 00），须预留寄送时间。
- 成绩须为考试日起2年以内的成绩。
- 官方没有公布英语的配点、最低分和换算表。

### 日本語要件
- 外国人留学生特别选拔须持有日本语能力试验（JLPT）N2 以上，提交成绩通知书复印件。一般选拔等其他区分没有日语成绩要求，但面接和口头试问用日语进行。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：環境・生命工学専攻合计50名（包含7月日程、2月日程和所有选拔区分，不按コース分配）。2月日程为若干名，取决于7月日程的入学手续人数。
- 选拔区分：進学者选拔（本校工学部毕业或预计毕业者，含2026年9月预计毕业）、一般选拔（大学毕业或2027年3月底前预计毕业、学位授与机构学士、外国16年课程修了等；经个别审查认定同等学力并满22岁者也可）、社会人特别选拔（具备一般选拔资格且不含预计毕业者，到2027/3/31有1年以上社会经验）、外国人留学生特别选拔（无日本国籍、JLPT N2 以上并满足一般选拔学历条件）。
- 外国人留学生特别选拔：7月日程可以由在日代理人代为出願（须能取得入学所需在留资格）；2月日程只接受已有在留资格的在日居住者出願。海外居住者须通过日本国内的代理人办理出願。
- 在外国未取得4年制大学学位等情况，须先接受出願资格审查（7月日程 2026/5/18–5/22，已过；2月日程 2026/11/16–11/20）。
- 出願书类：入学願書、受験票·写真票（4cm×3cm，出願前3个月以内）、志望理由书、研究计划书（须有指导教员亲笔签名或记名盖章）、成绩证明书（原件，须有 GPA；在读者另附正在修读科目的证明）、毕业（预计）证明书、英语成绩（TOEIC 公式认定证或 TOEFL iBT 公式成绩单）、受験票回邮信封、角2出願信封；外国籍另交身元保证书、住民票（记载在留资格）、护照复印件；社会人和留学生另交职务·研究经历书或毕业论文；留学生另交 JLPT 成绩通知书复印件。用纸从大学院入试信息页下载（docx/pdf）。
- 日语、英语以外语言的证明书须事先联系，并附译文。
- 出願方式：速達簡易書留邮寄（期内必达）或到学務課窗口提交（平日 9:00–12:30、13:30–17:00）；没有网上出願。
- 检定料 30,000 日元（另付汇款手续费），用专用振込依頼書（7月日程／2月日程各一份）汇款；原则上不退还。
- 需要考场照顾的残障等事前咨询：7月日程 2026/5/25–5/29（已过），2月日程 2026/11/24（周二）–11/30（周一）。
- 入学料：前橋市内居住者 141,000 日元，市外居住者 282,000 日元；授業料 年 535,800 日元（分两期）。另有后援会费、同窗会费、学生自治会费、灾害伤害保险费 2,430 日元等。
- 入学手续：7月日程 2026/7/28–8/7（已结束），2月日程 2027/2/23（周二）–3/5（周五）；期内未办即视为辞退。
- 考试当天 9:00–9:30 进入候考室，开考前30分钟须就座。
- 研究生（非学位）是另一条路线（2月日程同期出願），这不是修士入试的要求。
- 咨询：前橋工科大学 学務課入試広報係（〒371-0816 群馬県前橋市上佐鳥町460番地1），Tel 027-265-7361，nyushi@maebashi-it.ac.jp。
- 要项没有提到成绩开示。
