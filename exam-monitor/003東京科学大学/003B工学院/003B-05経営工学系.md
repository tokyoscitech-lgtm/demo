## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 夏季入试（A日程·B日程共通）：不在考场考英语，改为提交外部英语成绩。收 TOEIC L&R 和 TOEFL iBT（含 Home Edition）。
- 只认 2024/6/11 以后受检的成绩。提交的是网上下载的 PDF 的打印件：TOEIC 须是带 QR 码的デジタル公式認定証；TOEFL 是 PDF 版 Test Taker Score Report，并在 ETS 账户里把送分对象设为 DI code G179。
- 不受理：ETS 邮寄来的纸质成绩单、TOEFL ITP、TOEIC IP、TOEIC S&W。
- 提交时点各系不同（出願时必交／原则出願时交、系可指定后补／系指定日交三种）。本系属于哪一种、英语的配点、最低分和换算方法，写在要项本系案内页（p40–41），本次没能读到该页，未获取（截至 2026-10-10）。截止前没交的人没有受験资格，所以稳妥做法是出願时一并提交。
- 英语配点（体验记，非官方）：有考生说换算不是简单的“分数÷990×配点”；具体算法没有公开资料可核对。

### 日本語要件
- 理工学系要项的共通部分没有要求提交 JLPT、EJU 等日语成绩。本系案内页有没有另加日语要求，本次未能确认（截至 2026-10-10）。
- 上一年度（2025年8月实施）的筆答試験题只有日文，没有日英并记。作答语言的规定未获取。

### 筆記試験（专门科目）
| 科目 | 范围 · 题型 | 依据 |
|---|---|---|
| B日程 筆答専門試験科目「経営工学」（上一年度试卷封面：200分，60分钟，10:00–11:00；2027年度的配点和时长未能从要项本系案内页确认） | 数理：线性代数、微分积分、数理工学（集合·等价关系·行列式等基础数学）、概率·统计，各1大题，共4大题全部必答；每题用单独的答题纸，有的小题要写推导过程、有的只写答案 | 2025年实施试卷与出題の意図 |
| 参考文献（系公布，2026年3月版） | 松坂和夫《線型代数入門》、難波誠《微分積分学》、宮川雅巳·水野眞治·矢島安敏《経営工学の数理 I》《経営工学の数理 II》、久保川達也·国友直人《統計学》。系注明不保证只从这些书出题，题型和范围可能有出入 | 参考文献（2026年3月版） |
| A日程 | 没有笔试，只看出願书类和口述試験 | 2027募集要项 |

- 判定方法：A日程由系根据出願书类挑选对象（考生不能自己选），用出願书类＋口述試験决定“合格内定”；内定者不再参加 B日程，没有内定的人可以考 B日程。B日程按筆答試験、外部英语成绩、口頭試問和出願书类综合判定。各项的配点与合格线，本次未获取。
- 变更点：2024年度起专门科目只考“数理”（之前是“数理”“经济学”二选一），时间和配点不变；2027年度相对上一年度有没有新变更，系入学案内页上没有新的变更通知。
- 2025年实施的出题内容（官方出題の意図归纳）：线性代数考正交投影、最小二乘、迹与秩、正定矩阵；微分积分考连续与导数的定义及一阶微分方程；数理工学考等价关系、等价类和行列式；概率·统计考回归分析与逻辑回归。
- 题目倾向（体验记，非官方）：难度是基础到标准，重在把典型题稳定做对；2024年8月的考生说那年比前一年明显变难、统计部分超出预期、60分钟做不完。有外部生说笔试阶段被刷的人不少。

### 口述試験 / 面接
- **官方形式**：A日程口述試験在 2026/7/10–7/15 中由系指定日期，成绩提供时给 A–E 评价；B日程口頭試問在 2026/8/18–8/25 中由系指定，成绩提供时给评价。本系口述/口頭試問的具体内容、时长和使用语言写在要项本系案内页，本次未获取（截至 2026-10-10）。
- **実際に聞かれた内容**：（体验记，非官方，仅1人提及）2024年8月的 B日程口頭試問每人约15分钟，面试官5人，其中3人是第1–3志望的教员，问题基本由第1志望教员提出；先问研究计划的固定问题，再围绕研究计划的内容追问。候场时不能用电子设备。该考生说口頭試問也刷掉了一部分人。另有体验记提到 2024年起面试改为到场进行，内容是研究内容、志望动机、入学后的研究计划。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：工学院合计 477 名（2026年9月入学＋2027年4月入学，各系合计）。本系的“受入可能予定人数”写在要项本系案内页（p40–41），本次没能读到，未获取（截至 2026-10-10）。
- 出願资格：大学毕业或 2027/3/31 前预计毕业、在外国完成16年学校教育等 (1)–(11) 项之一；(9)(10)(11) 须先通过出願资格审查（书类 2026/5/11 必达，已截止）。资格(9)（飞び入学）的人只适用 B日程。
- A日程还是 B日程由系决定，2026/7/2（周四）12:00 左右和受験票一起在マイページ通知。
- 志望指导教员：体验记（非官方）说入学志願票上填第1–3志望的教员。官方的填写规则在本系案内页，未获取。
- 出願书类：宛名标签、入学志願票、志望理由書（指定样式 A4 1张；本系有没有指定题目未获取）、成绩证明书、毕业（见込）证明书、外部英语成绩、外国人的在留卡复印件等。日文、英文以外的证明要附译文。
- 出願方式：先在网上出願系统登记，再把书类用速達書留寄到入試課，不收窗口提交。
- 检定料 30,000 日元＋手续费 990 日元（信用卡、网银、便利店、Pay-easy）。国费留学生等免缴，须在 2026/5/27 前事先申请。
- 并愿限制：只能报一个系；同一入学期不能报理工学系修士的多个募集；一个出願的结果出来之前不能再报理工学系的其他募集。
- 留学生注意：9月入学只限出願时住在日本、在留资格有效到 2026/9/28 的外国人；人在海外的外国人只能 4 月入学。因安全保障出口管理，研究内容可能被要求变更。
- 入学料 282,000 日元；授業料半年 317,700 日元（可能修订）。4月入学的手续预定在 2027/3/4（周四）前办完。
- 成绩提供：2026/10/1–2027/5/28 必达，邮寄申请。A日程给口述评价（A–E），B日程给笔试得分、英语得分和口頭試問评价。
- 咨询：入試課大学院入試グループ inquiries.grad.se@adm.isct.ac.jp，〒152-8550 東京都目黒区大岡山2-12-1；系里的联系邮箱是 chair@ml.me.titech.ac.jp（说明会页所载）。
