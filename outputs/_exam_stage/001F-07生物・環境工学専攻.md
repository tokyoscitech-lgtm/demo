## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 须提交 TOEFL iBT 成绩（iBT Home Edition 也可以），A日程、B日程相同；研究科和専攻都不自己出英语题。
- 提交方式：向 ETS 申请把公式成绩（Institutional / Official Score Report）直接送到东京大学农学生命科学研究科，机构代码（DI code）为 **1113**，用其他代码申请的无效；同时在 WEB 出願系统里填写 Appointment Number、受检日和分数。自己手里的 Test Taker Score Report 不需要提交。
- 有效的受检日：A日程为 2024/8/1–2026/6/13；B日程为 2025/2/1–2026/11/15。
- TOEFL ITP（所属团体实施的）和 MyBest Scores 不受理，只看单次考试的成绩。可以送多次成绩，但出願时只能填一个。
- 要项和専攻入试案内都没有写最低分、换算方法和英语的配点。

### 日本語要件
- 要项和専攻入试案内都没有要求提交日语成绩（JLPT 等）。
- 试题语言：A日程的専門科目用日语出题；B日程日英并记。两个日程都可以用日语或英语作答。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：A日程（2027年4月入学）17 名；B日程（2027年4月入学）若干名。本専攻不实施 10月入学（A日程的 2026年10月入学和 B日程的 2027年10月入学都不招）。成绩不够时录取人数可能达不到募集人员。
- 出願资格（A日程）：（1）日本的大学毕业或 2027/3/31 前预计毕业；（2）在外国完成16年学校教育；（3）在外国取得相当于学士的学位（修业年限3年以上、经该国政府等评价的学校）；（4）文部科学大臣指定者；（5）由大学改革支援·学位授与机构授予学士学位；（6）经个别入学资格审查认定、2027/3/31 时满22岁。
- B日程的出願资格只限（2）和（3）。属于（1）但包括初等·中等教育在内都以日语以外的语言受教育的人，须在 2026/10/7（周三）前向教務課大学院学生担当提出，经审查许可后才能报（已截止）。
- 个别入学资格审查（资格6）的截止日：A日程 2026/5/7（已截止），B日程 2026/10/7（已截止）。
- 志望教员的填写：在 WEB 出願系统里从要项的“教员及专门分野一览”中选专门分野和教员，最多填到第3志望；第2、第3志望可以选同一分野的其他教员，没有可以不填。教员名单会因人事变动更新，出願前要看最新版。
- 出願书类（都在 WEB 出願系统里填写或上传 PDF）：入学願書（含3个月内的证件照）、出身大学的成绩证明书、毕业（预定）证明书（写明学位名和授予日；上过多所大学·大学院的全部要交）、检定料缴纳证明、国费留学生证明书（仅该当者）、TOEFL 成绩。本専攻没有另外要求研究计划书等専攻独有的书类。证明书不是日文或英文的要附译文；合格后入学手续时提交原件，交不出会被取消合格。
- 出願方式：只能通过 WEB 出願系统，没有邮寄或窗口受理。书类不齐的不受理，出願期间结束后不能改。
- 检定料 30,000 日元（国费留学生免缴）。缴纳期间：A日程 2026/4/13–6/23（已截止）；B日程 2026/10/5（周一）–11/25（周三）。可用银行汇款（邮储银行·邮局不行）、便利店、Pay-easy、网上银行、信用卡。最后一天网上申请到 23:00 为止。缴纳后不退。
- 同一日程内不能同时报本研究科的两个以上専攻。要项没有写 A日程不合格者能否再报 B日程；本専攻 B日程的资格限制对所有人同样适用。
- 外国人须在入学前取得不妨碍入学的在留资格；住在国外、报 B日程 4月入学的人，合格到入学的时间很短，可能来不及入境。外国人留学生入学前要接受安全保障出口管理的审查，结果可能导致不许可入学或研究内容受限。
- 入学料 282,000 日元，授業料 年 535,800 日元（前期 267,900 日元），均为 2027年度预定额；国费留学生不收。
- 受験票要自己从 WEB 出願系统打印（A4），考试当天带去。受験者心得：A日程 2026年7月上旬、B日程 2027年1月上旬以邮件发送；B日程到 2027/1/13（周三）还没收到的要联系教務課。
- 需要考试照顾（残障等）的，B日程须在 2026/10/7 前申请（已过，过期也会研究，但能提供的照顾有限）。
- 入学手续：B日程 4月入学者在 2027年2月下旬收到通知，3月上旬的指定期间内办理。
- 成绩开示：可以申请。A日程在 10/1–10/31、B日程在 5/1–5/31 之间向教務課提交“得点開示申請書”（必达），用纸在入试案内·募集要项页下载。
- 咨询：入试手续问教務課学生支援チーム大学院学生担当（〒113-8657 東京都文京区弥生1-1-1，daigakuin.a@gs.mail.u-tokyo.ac.jp，Tel 03-5841-5010）；専攻的问题问専攻主任 松田 怜 教授（Tel 03-5841-5355，bee.shunin@mail.en.a.u-tokyo.ac.jp）。受理时间要项没有写。
