## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般入试：
  - 専攻不另设英语笔试，只收 TOEFL iBT（含 Home Edition）公式成绩；TOEIC、IELTS 不受理。
  - 2026/8/12（周三）前完成三步（已截止）：ETS 送分（DI 代码 8596，Department 代码 99）、在 WEB 出願系统登记 Appointment Number 和受检日、上传 Test Taker Score Report。
  - 只用 2024年9月以后受检的 Test Date Scores，不用 MyBest，TOEFL ITP 等团体成绩不受理，英语母语者也要交；考过多次的只认登记的那一次，截止前可修改。
- IME：交 TOEFL（优先）或 IELTS 成绩（书类截止时2年内），或出身大学的英语授课证明；GRE General 必交（5年内）。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 一般入试：専攻公开了専門科目试题的英文版（2026年度），数学试题也有英文版；説明会和 Q&A 只有日语。IME 全英文授课。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 専門科目（航空宇宙工学） | 4科选3科：流体力学（流体力学、高速空气力学）／固体力学（材料力学、结构力学）／航空宇宙システム学（飞行力学、控制）／推進工学（机械力学、热力学、电磁学） | 8:30–11:30，180分钟 |
| 数学（一般教育科目） | 研究科共通题6题选3：微积分与微分方程、级数·傅里叶分析·积分变换、向量·矩阵·特征值、曲线·曲面、复变函数、概率统计·信息数学等 | 13:00–15:30，150分钟 |
| IME：无笔试 | 书类审查＋教员接收函 |  |

- 一般入试按 TOEFL 成绩、数学、専門科目、口述和提交书类综合判定，原则上全部科目都须参加；不设书类选考和特別口述試験。
- 可带物品：受験票、黑色铅笔或自动铅笔、橡皮、卷笔刀（台式不行）、笔芯、只能计时的手表，不能带圆珠笔；考场在 2026/8/28 前于研究科网站、専攻网站和工学部7号館大厅公布。
- 题目倾向（体验记，非官方）：各科都可能出难题，不少人4科都准备、当天挑3科；流体常考支配方程的推导变形（含可压），固体的材料力学计算量大、结构力学为薄壁加强结构；推進的热力学常结合喷气发动机，机械力学以振动为主（2020–2021年的体验记）。

### 口述試験 / 面接
- **官方形式**：一般入试：口述，问入学后想研究的领域和本科毕业论文相关事项，缺考即不合格；IME：书类审查，必要时教员线上面试。
- **実際に聞かれた内容**：
  - 面试官3名，问毕业研究的内容和进展、志望航空宇宙的理由、入学后想做的研究（2021年8月，1人提到）。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：37名（一般入试，2027年4月入学和2026年10月入学合计）；IME 另行选拔。
- 出願资格：大学毕业（含 2027/3/31 前预计）或外国16年学校教育等；个别入学资格审查 2026/4/21 截止（非独立出願）；不能同时报本研究科两个以上専攻；可选 2026年10月入学（出願后不能改，只有名单上17位教员可接收；需新办签证者建议4月入学）；IME 只限非日本国籍、网上出願期间不住在日本的人，日本的大学毕业·在读者（含研究生）不能报。
- 要提前准备的书类：TOEFL 公式成绩；日本国籍以外的考生出願时交「指導教員希望調査書」（指定样式）；安全保障輸出管理チェックシート（外国籍、双重国籍或入学前所属机构在海外者）；日英以外语言的证明须附出身大学盖章的英译；IME 须2封推荐信（推荐人网上提交）、学习计划书、毕业论文概要、GRE 成绩和教员接收函。
- 出願：一般入试只能在 WEB 出願系统上传 PDF，检定料 30,000 日元，日本政府奖学金留学生免缴；IME 用 T-cens 网上出願后邮寄纸质书类（9月募集 2026/11/4、1月募集 2027/3/10 必达），检定料 10,000 日元。
- 并愿限制：不能同时报工学系研究科的两个以上専攻或课程。
- 咨询：募集要项的问题用研究科网站的问询表单（工学系研究科学務課大学院チーム）；専攻的问题找航空宇宙工学専攻事務室（工学部7号館，Tel 03-5841-6610，koku@office-aero.t.u-tokyo.ac.jp）。
