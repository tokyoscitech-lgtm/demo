## 🎯 入試内容（考什么）

### 語学 / 英語要件
- 一般選抜：英语不设笔试，用 TOEFL iBT（含 Home Edition）或 TOEIC Listening & Reading 公开考试的成绩判定，成绩单贴在指定的「スコアシート提出用紙」上随出願书类一起寄出。
- 笔试免除者选拔：本専攻出願时同样要交英语成绩（要项里只有電気工学·電子工学·情報·通信工学 3専攻免交，这条免交规定不适用于本専攻）。没有获得免除而转入一般選抜的人，可以在 2026/7/29（周三）17:00 前换交新的成绩单（已截止）。
- TOEIC：只收公式认定证原件（Official Score Certificate），数字版公式认定证的打印件也按原件处理；一般選抜最晚可用 2026/5/31 实施的那一回。
- TOEFL：需要两样——由 ETS 直送大学的 Official Score Report（Institution Code D377，Department Code 69），以及 Test Taker Score Report 的复印件；直送成绩要在出願期间最后一天（一般選抜为 2026/7/3）之前到达大学。只采用 Test Date Scores，不采用 MyBest。
- 有效期：只承认 2024/6/1 以后实施的考试成绩。不受理 TOEFL ITP 和 TOEIC IP（团体考试）。
- 没交成绩也可以出願和应考，但英语不计分。
- 配点与换算：募集要项和専攻页都没有公布英语的配点、最低分和换算方法。
- 外国人留学生入试：専攻的募集案内页写明留学生入试的英语全部用 TOEFL 或 TOEIC 的成绩评价，成绩单随出願书类一起提交；2027年度留学生募集要项的正文未获取到。

### 日本語要件
- 8月入试（笔试免除者选拔、一般選抜）：募集要项没有要求提交日语成绩，没有 JLPT／EJU 门槛。笔试用日语出题，要项写明不提供英语出题；口頭試問也用日语进行。
- 外国人留学生入试：2027年度留学生募集要项的正文未获取到，对日语成绩的要求未能核实。参考2025年度留学生要项：原则上要交日语教师等出具的「日本語能力証明書」，专业笔试日英两种语言出题。
