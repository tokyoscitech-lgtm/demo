## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- A日程：
  - 不另设英语笔试，用 TOEFL iBT（含 Home Edition）成绩评价；须在 2024/8/1–2026/6/13 之间受检并向 ETS 申请把 Institutional (Official) Score Report 送到研究科（DI code 1113），出願时在 WEB 出願系统填写 Appointment Number、受检日和分数。
  - TOEFL ITP 不受理，MyBest Scores 不采用。
  - 变更点：2026年度还要上传 Test Taker Score Report、不得已时可交 TOEFL Essentials，2027年度改为只认 ETS 直送的 TOEFL iBT。
- IPADS：
  - 交 TOEFL iBT（含 Home Edition）或 TOEFL Essentials（ETS 直送，DI code C351，只认单次成绩）、IELTS（Test Report 或 Indicator，One Skill Retake 不受理）；Duolingo 只限英语授课学位或英语工作环境满足条件的人。
  - 有效受检期间：第1轮 2024/12/1–2026/10/18，第2轮 2025/4/1–2027/2/14。
  - 在澳大利亚、加拿大、爱尔兰、新西兰、南非、英国、美国完成全英语学士课程，或在这些国家英语环境全职工作满过去6年中的3年的人免交。
  - IPADS 页面给出的参考水平是 TOEFL 98、IELTS 7.0 以上，不设正式最低分。

#### 日本語要件
- 要项没有要求提交日语成绩。
- A日程専門科目的出题语言在出願时从日语和英语中选一种，出願后不能更改；IPADS 全英语授课。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|

- 只在 A日程实施，线上笔答；科目和出题语言在出願时选定。
- 2026年度出题（出题意图）：各科多为 2 道论述大题，如水产品流通与渔业管理、研究计划立案加动物学分领域选答、水稻育种与农业生态系、木质素化学、森林碳汇与卫星监测、基因组编辑、环境技术与塑料问题、微观经济学计算与因果推断；小论文为围绕贫困与差距问题表明立场并论证。

### 口述試験 / 面接
- **官方形式**：A日程 2026/8/7 线上进行，具体时间和做法由7月上旬的受験者心得或専攻邮件通知；IPADS 以书类审查为主，只对部分入围者做视频面试，事先通知。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：A日程（2027年4月入学）43名，不实施 B日程和10月入学；IPADS（2027年10月入学）第1轮约8名、第2轮约7名。
- 出願资格：A日程为大学毕业（含 2027/3/31 前预计）或外国 16 年学校教育等，个别入学资格审查 2026/5/7 截止（非独立出願，已过），同一日程只能报本研究科一个専攻；IPADS 要求 2027/9/30 前取得学士学位，不限国籍，军人（含文职）不能报，个别入学资格审查第1轮 2026/10/1、第2轮 2027/2/1 截止（非独立出願），第1轮落选可再报第2轮。
- 要提前准备的书类：A日程只需 TOEFL 送分；IPADS 预筛交毕业论文摘要（300 words 以内）和作文（800–1,000 words），入围后交毕业论文或 1,000 words 以上的报告、两封由推荐人从机构邮箱直接发给 IPADS 的推荐信。
- 出願：A日程只能通过 WEB 出願系统上传 PDF，检定料 30,000 日元，日本政府奖学金留学生免缴；IPADS 检定料 10,000 日元（入围后缴纳）。
- 并愿：同一日程只能报研究科的一个専攻。
- 咨询：専攻的问题问農学国際専攻（Tel 03-5841-7575）；出願手续问农学生命科学研究科教務課学生支援チーム大学院学生担当（〒113-8657 東京都文京区弥生1-1-1，Tel 03-5841-5010，daigakuin.a@gs.mail.u-tokyo.ac.jp）。
