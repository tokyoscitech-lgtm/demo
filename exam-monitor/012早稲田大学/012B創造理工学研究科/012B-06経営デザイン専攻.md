## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 不另设英语笔试，外部英语成绩是出願资格（一般入试、特別選考相同），须达到其一：TOEIC L&R 550、TOEFL iBT 57（或スコアバンド 3.5）、IELTS Academic 5.5；成绩不达标出願无效。
- 有效期：出願开始日前2年以内受检。
- TOEIC 交公式认定证（日本国内受检交数字认定证打印件，团体代码 00019702）；TOEFL iBT 由 ETS 直送（DI code 2874）并附 Test Taker Score Report；IELTS 电子送达研究科并附 Test Report Form。
- 不受理：TOEIC IP・S&W・Bridge，TOEFL ITP・PBT・Home Edition・Paper Edition・My Best scores，IELTS General Training・Online・One Skill Retake。

#### 日本語要件
- 要项没有要求提交日语成绩。
- 笔试、面接原则上用日语进行；特別選考的志願票、業績報告書须用日语填写。

- 只能用考场准备的计算器，自带计算器、电脑、手机不能用。
- 合否按书类审查、笔试、面接综合判定。
- 専攻公布受験用参考図書：永田靖《入門統計解析法》、森・松井《オペレーションズリサーチ》、田村等《新版生産管理システム》、真壁肇《信頼性工学入門》、千住・伏見《新版 経済性工学の基礎》等。
- 特別選考以面接为主，社会人・奨学生可能事先通知后加考笔试，社会人特別履修プログラム生只面接。

### 口述試験 / 面接
- **官方形式**：一般入试：笔试次日面接选考（含口述试验），原则上用日语；特別選考：面接，社会人另有针对出願书类的口述试验，原则在西早稲田校区（教员判断可改线上），缺席即不合格。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：45名（一般入试4月入学，含其他入试名额）；特別選考（社会人・奨学生）另设名额，社会人特別履修プログラム生 9月・4月入学各若干名。
- 出願资格：大学毕业（含预计）或外国16年学校教育等，并须满足英语成绩基准；只能报1个専攻，出願时填志望研究指导；特別選考社会人须毕业后2年以上实务经验且在职，奨学生须已获研究科认可、相当于在学期间学费总额的奖学金，社会人特別履修プログラム生（1.5年制）须5年以上实务经验且在职。
- 要提前准备的书类：志願票①（志望动机・研究计划，日语，A4 1页）；中国大陆毕业者须由 CSSD 直送学历·学位（在读者为学籍）Online Verification Report；特別選考另需所定样式推薦状（密封），社会人另交業績報告書、在職証明書和毕业论文（或概要），奨学生交奖学金受给证明原件。
- 出願：网上申请表＋检定料＋书类邮寄，三项在期限内完成，书类必达；检定料 30,000 日元。
