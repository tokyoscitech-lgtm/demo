## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般入试：不另设英语笔试，用外部成绩评价，本コース外语配点 100 分。
  - 可提交 TOEIC（公开考试或 IP 考试）、TOEFL（含 ITP 和 iBT Home Edition）、IELTS（只限 Academic，纸笔版和机考版都可以），可交多份；TOEIC IP 线上版的成绩证明不受理。
  - 只认考试日前2年以内的成绩，提交成绩证明原件；TOEIC 公开考试的数字公式认定证可打印 PDF 提交。
- 外国人留学生特別入试：不收英语成绩。
- 推薦入试·社会人特別入试：不收英语成绩。

#### 日本語要件
- 要项没有要求提交日语成绩。

### 筆記試験（专门科目）
| 科目 | 范围·题型 | 时间 |
|---|---|---|
| 専門科目－1 | 力学、電磁気学 | 10:00–12:00，120分钟 |
| 専門科目－2 | 量子力学、統計力学 | 13:00–15:00，120分钟 |

- 一般入试：外语（外部成绩）100＋専門科目 400＋面接 100；外国人留学生特別入试：専門科目 400＋面接 100，科目和时间与一般入试相同。
- 成绩证明书作为面接资料，综合评价为良／可／不可；専門科目不能带计算器。

### 口述試験 / 面接
- **官方形式**：一般入试·外国人留学生特別入试：面接 100 分，按コース进行，评价报考动机和入学后的学习研究意欲；推薦入试：口述試験 100＋面接 100，问专门分野内容，推荐书和成绩证明书作为面接资料；社会人特別入试：口述試験 100＋面接 100，另问研究业绩和想研究的课题。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：12名：推薦入试4名、一般入试8名（含社会人·外国人留学生特別入试），2026年10月入学若干名。
- 出願资格：大学毕业（含2027年3月预计）或外国16年学校教育等；资格(9)–(13)须在 2026/6/26（周五）前提交出願资格认定申请（非独立出願，已截止）；外国人留学生特別入试限无日本国籍者。
- 要提前准备的书类：英语外部成绩原件（一般入试）；外国人留学生特別入试另需学部长或指导教员填写的推荐书（様式M1-4）和履历书（様式M2-4）；一般入试资格(3)–(6)者交履历书（様式M2-2）；无日本国籍者交在留卡正反面或护照复印件。
- 出願：银行窗口缴检定料30,000日元取得C票→在 J-Bridge System 网上登记并上传C票→打印登记内容连同书类以速達簡易書留寄出，截止日17:00必达（平日9:00–17:00也可窗口提交）；国费留学生免缴。
