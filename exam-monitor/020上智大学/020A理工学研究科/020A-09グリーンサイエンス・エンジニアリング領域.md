## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 不另设英语笔试，只认 TOEFL iBT 或 IELTS（Academic）成绩，须为出願期间开始日前2年以内受检（2025/3/10 以后），3/31 前由考试机构直接送达上智：TOEFL 机构代码 0819，网上出願时填 MyBest 成绩；IELTS 只收 e-delivery，可用 One Skill Retake。
- 机构直送之外，本人还须在上传网站提交成绩单 PDF 或截图（TOEFL Test Taker Score Report；IELTS 带 TRF 号的 Test Report Form）。
- 不受理：TOEFL Home Edition、TOEFL ITP、TOEFL Essentials、IELTS Online、IELTS Indicator。
- 免交：非英语母语者已取得全英语授课、英语为官方教学语言的学士或硕士学位，且为此用英语学习超过2年的，由原学校直接向入学センター寄证明；上智英语授课本科在读生免交。

#### 日本語要件
- 要项没有要求提交日语成绩。授课和研究指导全部用英语；出願书类用英语或日语，其他语言须附学校或使领馆等认证的英译和原文。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：20名（只招2027年9月入学；博士春秋合计3名）。
- 出願资格：日本的大学毕业（含预计）、外国16年以上学校教育、外国3年制以上学士学位等，入学前须取得学士学位；预计毕业者须在 2027/9/20 前补交学位证明。
- 要提前准备的书类：Statement of Purpose（英语500–750词，官方表格，写明拟研究方向及与以往经历的关系，并从机械、电气电子、应用化学、化学、数学、物理、生物科学、信息科学中选1个方向）；推荐信3封（英文或日文，至少2封来自教过本人的教员，由推荐人上传）；成绩单和学位（预定）证明须学校直接上传或直送，中国大陆高校考生须由 CHSI 把成绩和学位认证报告直接发到 admission-g-co@sophia.ac.jp；书类严禁用生成式AI撰写。
- 出願：在 MyPage 网上出願并缴费后，用同一邮箱和 Receipt Number 在上传网站提交书类并点最终 Submit；检定料 35,000 日元＋手续费 1,100 日元，海外无日本银行账户的只能用信用卡。
- 咨询：出願手续问上智大学入学センター（admission-g-co@sophia.ac.jp，Tel +81-3-3238-3517）；不回复书类是否送达的询问。事前联系教员通过理工学専攻事務室（f-scitec@sophia.ac.jp）。
- 并愿：尚未核实是否可同时报考其他专攻或选拔类别。请以本年度募集要项或招生窗口答复为准。
