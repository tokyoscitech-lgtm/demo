## 🎯 入試内容（考什么）

### 語学

#### 英語要件
- 一般入试：不另设英语笔试，用 TOEIC 成绩换算评分（200分）。
  - 交 TOEIC 公开测试或 IP 测试的スコア証明書原件；IP 线上版不受理；公开测试的数字公式认定证可交打印件。
  - 须为考试日前2年以内受检；出願时交不出的在 J-Bridge 注明、考试当天提交，当天也交不出的不能受验。
- 推薦入试、社会人特別入试、外国人留学生特別入试：不要求英语成绩。
- AEPAT·IEPAD：要求良好的英语工作能力，在推荐信·参考信里写明英语水平，有 TOEFL 等成绩可附上；考试和面试全部用英语。

#### 日本語要件
- 要项没有要求提交日语成绩；AEPAT·IEPAD 授课和研究指导用英语。

| 専門科目-2 医科学系 | 免疫学·分子生物学、アレルギー学、分子遺伝学、エピジェネティクス、酵素化学、実験動物学、発生工学 | 13:00–14:30，90分钟 |

- 出願时在志願书上选择学系；一般入试总分 800：専門科目 500（两科合计）＋英语（TOEIC换算）200＋面接 100；按良·可·不可判定，面接评价低时可能不合格；不能带计算器。
- 推薦入试：面接 50＋成绩证明书 50＋口頭試問 100；社会人特別入试与外国人留学生特別入试：面接 100＋口頭試問 100，没有笔试。
- 题目倾向（官方出題意図，2026年度入学）：理学系専門科目-1 考过渡金属配合物与磁性、无机结构（路易斯结构、VSEPR、晶格能）、量子力学和热力学计算，専門科目-2 考有机反应机理、化学平衡与螯合滴定、仪器分析、生物膜、化学工学计算；農学系専門科目-1 是英文科学文章阅读理解，専門科目-2 按领域出名词解释和论述。

### 口述試験 / 面接
- **官方形式**：一般入试：面接 100分，评价志望动机、学习意欲、积极性、协调性、沟通能力；推薦入试：面接 50＋口頭試問 100（另计成绩证明书 50），口頭試問考在本专业开展学习研究的能力和适性；社会人特別入试与外国人留学生特別入试：面接 100＋口頭試問 100，就想做的研究课题和专攻领域提问；AEPAT·IEPAD：专业科目的笔试和/或口试加面试，全部用英语。

## 📝 详细信息
### 出願資格 / 定員
- 募集人员：约21名（推薦入试约14名、一般入试约7名）；社会人特別入试与外国人留学生特別入试各若干名（2026年10月与2027年4月入学合计）；AEPAT·IEPAD 在日私費若干名；AEPAT·IEPAD 在外私費 AEPAT 4名、IEPAD 3名（与理工学研究科等合计，含10月入学）。
- 出願资格：大学毕业（含 2027年3月预计）或外国 16 年学校教育等；资格(9)–(14)须在 2026/6/5 17:00 前申请事前审查（已过，非独立出願）；推薦须出身大学校长等推荐、合格必入学，推荐教员即主指导教员、不能自行更换；社会人须到入学前有 2 年以上现业经历；外国人留学生特別入试限非日本国籍者；AEPAT·IEPAD 限非日本国籍者，在日私費须在日本居住、在外私費为从海外来日者，资格 e–h 须在出願截止1个月前提交资格审查材料。
- 要提前准备的书类：TOEIC 成绩原件（一般）；推荐书（推薦，出身大学校长等厳封）；履歴书（所定样式 M2-2）和任意推荐书（外国人留学生特別入试）；研究计划书和研究业绩书（社会人）；AEPAT·IEPAD 的英文毕业论文摘要（A4 4页以内）、学部长级推荐信和参考信。
- 出願：银行窗口缴检定料 30,000 日元（国费留学生免）取得 C票 → J-Bridge System 网上登记并上传 C票照片 → 打印登记信息，与书类用速達簡易書留寄学务部入试课或窗口提交，截止日 17:00 必达；AEPAT·IEPAD 用 Flywire 缴费，挂号邮寄必达。
- 并愿：一般·推薦要项没有说明能否同时报多个コース或推薦与一般并报；AEPAT 与 IEPAD 可以同时出願，每个项目各交一套书类（一套原件、一套复印件）并各缴检定料。
- 咨询：佐賀大学学務部入試課（〒840-8502 佐賀市本庄町1，Tel 0952-28-8178，contact@mail.admin.saga-u.ac.jp，平日 9:00–17:00）；AEPAT 为 aepat@mail.admin.saga-u.ac.jp，IEPAD 为 iepad@mail.admin.saga-u.ac.jp。
